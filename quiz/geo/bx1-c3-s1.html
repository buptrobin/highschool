1六个环节、三种类型，先分清

环节：蒸发（海洋、湖泊、土壤水面）→ 蒸腾（植物叶片）→ 水汽输送（水汽随大气水平运动）→ 降水 → 地表径流、下渗、地下径流。类型：海陆间循环（水最终回到海洋，使陆地水不断更新）、陆地内循环（内流区，水量少）、海上内循环（水量最大）。

2蒸发与蒸腾：水汽从哪来

影响蒸发的三件事：气温（越高越快）、水面面积（越大越快）、风速与空气湿度（风大、干燥则快）。植被茂密处蒸腾强，所以造林既涵养水源，也会增加蒸腾耗水——这两句不矛盾，落点不同。

3降水与下渗：水往哪里去

降水强度大、坡度陡、地表板结、植被差 → 下渗少、地表径流多；植被和枯枝落叶层、疏松土壤、缓坡、覆盖物 → 下渗多。下渗的水一部分留在土壤中（土壤水分），一部分继续下渗形成地下径流。注意：下渗 ≠ 地下径流。

4地表径流与地下径流：快与慢

地表径流汇流快、涨落猛，是洪水和内涝的直接原因；地下径流汇流慢、变化平缓，是枯水期河流的稳定补给。人类活动大多在加地表径流、减地下径流（硬化、填塘），或是反过来（修梯田、蓄水、回灌）。

5水量平衡：一条式子解释所有水位变化

收入 − 支出 = 蓄水变化。湖泊：降水 + 入湖径流 − 蒸发 − 出湖径流 − 下渗 = ΔS。ΔS > 0 水位上升，ΔS < 0 水位下降。内流湖“有进无出”，盐分只进不出，长期蒸发浓缩 → 咸水湖。

6人类活动：把措施翻译成环节

修水库：总量基本不变，削峰补枯，下游季节变化变小，拦沙使含沙量下降。城市化：不透水面增加 → 下渗↓、地表径流↑、汇流加快 → 内涝。海绵城市：透水铺装、下凹绿地、雨水花园 → 下渗↑、蓄存↑、径流峰值↓。植树造林：下渗↑、地表径流↓、蒸腾↑。填塘造田：调蓄↓ → 洪涝加重。

一句话串起来：太阳让水蒸发、植物让水蒸腾，水汽被气流带走，遇冷凝结成降水落回地面；落地之后，一部分沿地表流走（地表径流），一部分渗进土壤（下渗）再缓慢流向海洋（地下径流）。收入与支出的差额决定湖泊、水库、湿地的水位，人类修的每一项工程、铺的每一块水泥，改的都是这条链上的某一环。

02 / 收口

六个最容易丢分的点

考前五分钟扫一遍，比再刷十道题管用。

✕

把“水汽输送”和“径流”混为一谈。水汽输送是水汽随大气水平运动，发生在空中；径流是水在地表或地下水平流动，发生在地面以下或地表。方向像，位置完全不同。

“我国东南沿海水汽主要来自海洋”答的是水汽输送；“长江水注入东海”答的是地表径流。

✕

认为内流区也有海陆间循环。内流区的河水最终消失在内陆（蒸发或下渗），水没有回到海洋，属于陆地内循环，水量少、循环慢。

判断只看终点：回到海洋＝海陆间；始终在陆地上＝陆地内；只在海洋上空＝海上内。

✕

把“下渗”和“地下径流”当成一回事。下渗是水从地表进入土壤（垂直向下），地下径流是渗下去的水沿岩层水平流动。

答“增加下渗”之后要能接一句“土壤水分增加、地下径流增加”，两步不能并成一步。

✕

以为修水库能增加河流总水量。水库不造水，只把汛期洪水蓄起来、枯水期放出去，年径流总量基本不变，变的是时间分配和含沙量。

“削峰补枯、季节变化变小、下游含沙量减少”是水库的三句标准答案。

✕

城市内涝只答“排水不畅”。完整的链条是：不透水面增加、坑塘被填 → 下渗减少、调蓄能力下降 → 地表径流增大、汇流加快 → 同样降水更容易积水。

只写“排水管网差”最多拿一半分，必须回到水循环环节。

✕

湖泊水位变化只答“降水少”。要列水量平衡：降水、入湖径流是收入；蒸发、出湖径流、下渗、人类引水是支出。

干旱区内流湖水位下降，往往是“降水少 + 蒸发强 + 灌溉引水多”三者叠加，缺一条就少一个得分点。
