02 / 收口

六个最容易丢分的点

考前五分钟扫一遍，比再刷十道题管用。

✕

等比中项只写一个。2、a、8 成等比得 a² = 16，a = ±4；除非题目说正项数列，否则不能舍负。等差中项才只有一个。

✕

Sₙ 反求 aₙ 不验首项。Sₙ = 3ⁿ + t 这类，aₙ = Sₙ − Sₙ₋₁ 只对 n ≥ 2 成立，a₁ 必须等于通项在 n = 1 时的值，否则整个数列不是等比。

✕

求和公式忘记 q = 1。q = 1 时 Sₙ = na₁，代 a₁(1−qⁿ)/(1−q) 会除零。判断 q 是否可能为 1，是等比求和的第一步。

✕

把 S₃、S₆、S₉ 直接当等比。成等比的是 S₃、S₆−S₃、S₉−S₆（公比 q³）；直接写 S₉ = 3S₆ 之类是错的，只有 q = 1 时才碰巧成立。

✕

「aₙ₊₁ = 3aₙ」直接宣布公比 3。这个式子若只对 n ≥ 2 成立，还要用 a₁ 定出 a₂ = 3a₁ 才能说整个数列等比（2023 天津第 6 题）。

✕

错位相减的符号。减完得到的是 −Tₙ = …，最后除以 −1；再把 n = 1 代进去验，符号错了立刻能发现。

怎么用这份材料

  • 第 1 关两道题各 1 分钟：一道算 q 的幂，一道专门练「等比中项有正负」，都是送分题。
  • 第 2 关两道真题都靠「比式相除」，做完把「相除消 a₁」抄在草稿第一行。
  • 第 3 关先做 Sₙ = 3ⁿ + t 那道原创题，记住 t = −A；再去做天津第 6 题，体会递推式里 Sₙ 的相减。
  • 第 4 关的片段和题是本页最难的一步，做完立刻回看右图，把 S₃、S₆−S₃、S₉−S₆ 三段写在同一行。
