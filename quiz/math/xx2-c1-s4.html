数学归纳法北京真题 1 道 · 外地真题 0 道 · 原创 11 道 · 5 关 12 题

数学归纳法只有两步：验证起点、由 n = k 推出 n = k+1。但高考从不直接问「两步是什么」，而是把这两步藏进等式、不等式、整除和数列里——考的是第二步有没有真的用上假设。北京卷近五年没有单独考它的选择题，所以本页以原创题为主，只收一道原卷详解通篇用归纳法的北京真题。

00 / 先看地图

一句话记住本节：归纳法 = 多米诺骨牌，推倒第一块 + 保证每块都能带倒下一块

左图：只推倒第一块（只验证 n = n₀）不够，只证明「k 能带倒 k+1」也不够——两件事缺一不可。右图：第二步的写法固定成三步——写出假设、代入 n = k+1、把假设用掉。两张都是示意图，不是原卷配图。

02 / 收口

六个最容易丢分的点

归纳法的错都错在「少做一步」，这六条就是那六步。

✕

只验证几个特例就下结论。n = 1,2,3 成立不代表全成立：n² + n + 41 在 n = 1—39 时都是质数，n = 40 时等于 41²，是合数。归纳法必须「起点 + 传递」两步都做。

✕

第二步没用上假设。如果推 n = k+1 时一次都没用到「n = k 时成立」，那不叫归纳，只叫「对某个 k 算了一遍」，得 0 分。

✕

初始值取错。命题写「当 n ≥ 5 时」，第一步就必须验 n = 5；验 n = 1 既不在范围内，也证明不了后面的传递能启动。

✕

把所有命题都当成「k 推 k+1」。定义域是正奇数时，第二步要从 k 推到 k+2；定义域是 n ≥ 2 且步长 1 时，起点就取 2。跨度永远看定义域。

✕

「增加的项」数错。和式的通项里 n 出现几次，代换时就要全换；1/[(2n−1)(2n+1)] 换成 k+1 得到 1/[(2k+1)(2k+3)]，分母两个因子都变。

✕

整除题硬凑不出「假设的倍数」。先把指数拆开（如 32k+3 = 9·32k+1），再加减同一块凑出假设，剩下的部分必须是除数的倍数——凑不出来就别硬写，回头检查指数拆分。

怎么用这份材料

  • 第 1 关两道题各 1 分钟：一道找「增加的项」，一道定初始值——都是送分题，错了说明还没分清「n 的范围」和「n 的取值」。
  • 第 2 关两道题是本页的地基：归纳假设长什么样、跨度怎么定。做完把「假设 → 目标 → 用掉假设」六个字写在草稿上。
  • 第 3 关的分式通项题和猜想题，正好对应综合题第 1、2 题的写法，先做选择再做大题，衔接更顺。
  • 第 4 关的北京真题（2023 第 10 题）不要一开始就硬算，先看四个选项只差什么（初始值和 M 的范围），再决定往哪个方向证。
