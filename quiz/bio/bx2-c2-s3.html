伴性遗传的全部内容都是“基因在性染色体上”这句话的推论：位于 X 染色体上的基因，随 X 走“交叉遗传”——男孩的 X 来自母亲、父亲的 X 只传给女儿；因此隐性病“男多女少”，显性病“女多男少”。做题时先把基因型写成“X 上带角标”的形式，再画一次 X 的传递路径，比例自然出来。

一句话记住本节：基因在 X 上，X 从母亲来、往女儿去

左图是交叉遗传的全部含义：男孩的 X 一定来自母亲，父亲的 X 一定传给女儿。所以伴 X 隐性病“男多女少”，伴 X 显性病“女多男少”，且男性患者的母亲和女儿一定患病（显性病）。右图是系谱判断的落点：先定显隐（无中生有/有中生无），再看是否伴性（女患者的父亲与儿子、男患者的女儿与母亲）。

02 / 收口

六个最容易丢分的点

考前五分钟扫一遍，比再刷十道题管用。

✕

把伴 X 显性病的“男患者女儿必患病”记反。父亲的 X 只能给女儿，所以男患者的女儿 100% 患病、儿子 100% 正常（母亲正常时）。

✕

“无中生有”就直接判定伴 X 隐性。它只能说明是隐性；是常染色体还是 X 染色体，还要看女患者的父亲/儿子是否患病。

✕

ZW 型套用 XY 型的结论。ZW 型中雌性为异配性别（ZW），“隐性雌×显性雄”子代显性全为雄性、隐性全为雌性，与 XY 型相反。

✕

“患病男孩”与“男孩患病”不分。前者分母是全部孩子（常为 1/4），后者分母是男孩（常为 1/2）。

✕

复制后的基因数忘记乘 2。杂合子（如 AaXᴮXᵇ）复制后含 2 个 b；纯合子复制后含 4 个（2024 贵州第 6 题）。

✕

看到“雄性∶雌性＝2∶1”还去套 X 染色体隐性致死。XY 型中父本若为 XᵇY 会先死亡，与题意矛盾；这种情况应改判 ZW 型（2025 安徽第 12 题）。

怎么用这份材料

  • 先看地图 ①，把“男孩 X 来自母亲、父亲 X 只给女儿”默写一遍，再进第 1 关。
  • 第 4 关的两道真题都要配合原卷图看：2022 北京题先认出 XXY 与 XO 哪个是雌、哪个是雄。
  • 第 5 关第 3 题把“全部孩子／男孩／女孩”三个分母各算一遍，是最划算的复习。
