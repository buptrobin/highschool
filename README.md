# 俯瞰太阳系

数学 / 地理 / 生物 / 政治 四门功课的分册分章分节复习导航。
纯静态页面，双击 `index.html` 就能用，不需要服务器、不需要联网。
桌面和手机浏览器都适配（手机端搜索框 16px 字号，避免 iOS 聚焦自动放大）。

## 目录结构

```
index.html            首页（选科目）
subject.html          科目目录页（?s=math|geo|bio|pol）
assets/
  app.css             全站样式
  data.js             目录数据（脚本自动生成，别手改）
  site.js             首页 / 科目页逻辑
  page.js             内容页逻辑（把 Markdown 渲染成正文）
pages/
  math/  geo/  bio/  pol/      每一节一个静态 html
content/
  math.txt  geo.txt  bio.txt  pol.txt        大纲（改这里）
  *.extra.txt                                特别知识点清单
tools/
  build.py            读大纲 → 生成 data.js + 缺失的页面
```

## 给某一节写内容

用任意编辑器打开 `pages/geo/bx1-c1-s1.html`，滑到文件最底部：

```html
<script type="text/markdown" id="md">
<!-- 内容写在这里 -->
</script>
```

在中间写 Markdown 即可，刷新页面就自动排版：

```markdown
## 一、地球在宇宙中的位置
天体系统的层级：**地月系 → 太阳系 → 银河系 → 可观测宇宙**。

- 行星：自身不发光，绕恒星公转
- 卫星：绕行星公转

| 行星 | 距日顺序 |
|---|---|
| 水星 | 1 |
| 金星 | 2 |

> 记忆口诀：水金地火木土天海
```

支持：标题、无序/有序列表、**加粗**、*斜体*、`行内代码`、表格、
引用、分割线、链接、图片、代码块。

也支持直接写 HTML —— 如果 `id="md"` 里开头就是标签，会原样输出。

页面右上角有「标记已复习」，进度存在浏览器本地（localStorage），不上传。

## 改目录

1. 编辑 `content/geo.txt`（格式见下）
2. 运行：

```bash
python tools/build.py
```

**已存在的内容页不会被覆盖**，只补新建的。

### 大纲格式

```
# [bx1] 必修第一册（自然地理基础）     ← 册，[内的 key 用于生成文件名
## 第一章 宇宙中的地球                 ← 章
### 第一节 地球的宇宙环境              ← 节（标签会自动识别「第X节/第X框/第X课」）
### 问题研究：火星基地应该是什么样子    ← 以「问题研究」开头 = 探究条目，样式不同
```

文件名规则：`<册key>-c<章序>-s<节序>.html`，探究为 `-r<序号>.html`，
特别知识点为 `extra-<序号>.html`。

### 特别知识点

`content/geo.extra.txt`，一行一个：

```
- 等高线地形图的判读
- 时区、区时与日期计算
```

改完同样跑一次 `build.py`。

> 注意：`extra-*.html` 是按序号命名的，**在清单中间插条目会导致后面的页面串位**。
> 要插入就重新整理一遍清单，并把对应页面内容跟着挪；或者只在末尾追加。
