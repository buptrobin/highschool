# 生物讲义施工记忆

## 生物必修2（18 页）
pages/bio/bx2-c1-s1 … bx2-c6-s4，施工件 .workbuddy/bio2/。18/18 一次体检通过。
两个错是规格自己的：
1. **减Ⅱ后期染色体数**：我按 2n=4 写成 8（那是 2n=8 的数）。按每个细胞数，2n=4 时减Ⅱ后期是 4 条、DNA 4 个。子代理发现并顶了回来。
2. **s=1 递推终点**：手算逐步取整得 0.989，真值是 0.9913。凡是「手算 specs 里的迭代结果」都要用代码跑一遍。
经验：复制工作区做 udit-all.mjs 时，记得改 **glob 前缀**（^xx3- → ^bx2-）和 **audit.mjs 路径**，两处都写死在工作区名之外；改漏会去体检另一个学科的页。

## 生物选择性必修1（18 页）
`pages/bio/xx1-c1-s1 … xx1-c5-s4`，施工件 `.workbuddy/bio3/`。18/18 一次体检通过。
这一册的坑几乎都在「复制工作区」上：
1. `build-page.mjs` 的过滤条件是写死的 `if (book !== 'bx2') continue;`，复制后必须改成 `xx1`，否则每个 slug 都报「大纲里没有这个 slug」；同一处还有面包屑/页脚的册名（会变成「分子与细胞」）。
2. `audit-all.mjs` 的 glob 前缀（^bx2- → ^xx1-）和它调用的 audit.mjs 路径也要改，改漏会跑去体检另一个学科的页（白跑 10 分钟）。
3. 静态检查会抓「SVG 的 <text> 里出现 <b>」，这是本次唯一的静态失败。
4. 窄量程滑块的反复坑：audit 的判据是两次采样（约 2.0s / 4.6s）的**绝对值差 ≥ 0.3**。0–1 或 1–5 的滑块必须让位移在整个量程里穿过，不能只挪到停留帧。

## 生物选择性必修2（14 页）+ 选择性必修3（13 页）
`pages/bio/xx2-*`（生物与环境，施工件 `.workbuddy/bio4/`）、`pages/bio/xx3-*`（生物技术与工程，施工件 `.workbuddy/bio5/`）。
两册 27 页最终全部 PASS。踩到的坑，按痛的顺序：
1. **磁盘写满（ENOSPC）**：并发 4 个子代理 + 每个都开 headless Chrome，TEMP 里攒了 1911 个 `chrome_chrome_Unpacker_*` 残留目录，把盘吃到 0，多个子代理静默崩掉。
   清理后释放 2.9 GB。**并发上限就定 3**，且每批跑完清一次 TEMP。
2. **复制工作区必须改四处**：`build-page.mjs` 的 `book !== 'xxN'` 过滤、面包屑册名、**页脚「对应 人教版…《…》」那行的册名**（最容易漏，脚本里是另一套写法）、`static.mjs`/`audit-all.mjs` 的 glob 前缀。
3. **spec 的「通用约定」头是硬编码的**：`split-spec.mjs` 里那句「出处一律写…选择性必修1」会漏改，子代理会照着它写错册名——要连 split-spec.mjs 一起改，改完再 split。
4. **AutoPilot 两个致命写法**：脚本必须在 `DOMContentLoaded` 里跑；`loop` 必须是 `[{t,v}]` 对象数组。写成 `loop: 13` 或 `[[0,1],…]` 会静默挂不上 `__ap`。
5. `render()` 里给 `input[type=range]` 反向赋值会自触发 input 事件、形成死循环，整页 audit 卡死（单页跑 150 s 不返回，同批别的页 28 s）。这是最难查的一个：页能打开、能看，但体检永远超时。
6. 静态检查会抓：`<section>` 开闭不等、SVG `<text>` 里出现 `<b>`、`loop 帧 < 4`。

## 政治必修1 中国特色社会主义（9 页）
`pages/pol/bx1-c1-s1 … bx1-c4-s3`，施工件 `.workbuddy/pol1/`（从 bio5 复制后改成 政治/必修1/pages/pol/content/pol.txt/「课·框」标签/政治红 #e11d48）。
9/9 静态 + 9/9 体检 PASS。
**最有价值的一条（解释了两册里两次「体检卡死」）**：互动脚本里清空画布必须每帧做——
`el.textContent = ""` 要放在 draw 每帧的开头，不能放在 `geom()` 里只做一次。否则 AutoPilot 每帧往同一个 `<g>` 里追加节点，
几秒钟就能涨到几千个 `<text>`，而 `audit-fn.js` 的「文字两两重叠」检测是 O(n²)，直接卡死：
表现为单页体检 150–1000 秒不返回、各宽度统一报「页面没有返回体检数据 / console 不干净 / 没有 window.__ap」。
排查方法：注释掉 AutoPilot 整块再跑；或在 draw 里打印节点数。
复制工作区时的固定清单（这次又踩到第 3、4 条）：
1. `build-page.mjs` 的 `book !== 'xxN'`、面包屑/页脚册名、`content/*.txt` 路径；
2. `static.mjs`/`audit-all.mjs` 的目录与 glob 前缀；
3. `split-spec.mjs` 里硬编码的「通用约定」出处口径；
4. 章节正则：政治是「第一课 / 第一框」，不是「第X章 / 第X节」——要改成 `第[一二三四五六七八九十]+课`；
5. 断言对象名：生物模板用 `window.__bio`，政治页用 `window.__model`，`static.mjs` 要同时接受两者。
