# 2026-10-17

## 高中复习站（highschool）首版搭建

- 需求：给高中孩子复习用的本地静态站，4 门课（数学/地理/生物/政治），每门课「册 → 章 → 节」目录 + 特别知识点列表，每个节/知识点 = 一个独立静态 html 页。
- 采用**大纲文本 + 生成脚本**的架构，避免手写 300+ 个页面：
  - `content/<科目>.txt`、`content/<科目>.extra.txt` 是大纲真源
  - `tools/build.py` 解析大纲 → 生成 `assets/data.js` + `pages/<科目>/<slug>.html`（**已存在页面不覆盖**，保护手写内容）
  - slug 规则：`<册key>-c<章序>-s<节序>.html`，问题研究为 `-r<n>.html`，专题为 `extra-<序号>.html`
- 前端：`index.html`（选科目）+ `subject.html?s=<id>`（目录，details 折叠 + 关键词搜索，章名也能命中）+ `pages/**` 内容页；`assets/site.js`、`assets/page.js`、`assets/app.css` 全手写零依赖，file:// 双击可用。
- 内容写入方式：每页底部 `<script type="text/markdown" id="md">`，`page.js` 内置迷你 Markdown 渲染器（标题/列表/表格/引用/代码/链接/图片/分割线）。`#`→h2 起映射（h1 留给页面标题）。
- 进度追踪：localStorage `hs.done.<科目>/<slug>`，首页按科目算百分比，目录页行内打勾。
- 规模：数学 81、地理 101、生物 89、政治 102，合计 373 个条目 / 373 个页面。
- 地理目录按用户提供原文精确录入（69 节 + 24 问题研究）；数学=人教A版2019、生物=人教版2019、政治=统编版2019，**均为初稿，待 Robin 核对**；特别知识点清单目前是示例条目。
- 验证：无头 Chrome 在本机截不了图（静默无输出），改用 jsdom 做了三轮渲染测试（首页/科目页/内容页 + 搜索 + 进度开关），全部通过。
