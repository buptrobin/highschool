## bx1-c1-s1 原始社会的解体和阶级社会的演进

**课本原话**
1. 原始社会是人类社会发展的最初阶段，也是最低阶段。原始社会生产力水平极端低下。
2. 随着生产力的发展，原始社会末期出现了剩余产品，个体劳动逐渐盛行，生产资料由氏族公有变为家庭私有。
3. 私有制的产生和阶级的出现，使人类社会进入阶级社会；国家是阶级矛盾不可调和的产物。

**三个扣分点**：原始社会**没有剩余产品**（不是「穷人很多」）；阶级产生的**根本原因是生产力发展**（不是暴力掠夺）；国家**随阶级产生而产生**（不是从来就有的，也不会永远存在）。

**四张图**：① 原始社会的生活与生产资料公有（结构图）；② 一条因果链：生产力发展→剩余产品→私有制→阶级→国家；③ 阶级社会的两大对立阶级；④ 三种社会形态（原始、奴隶、封建）的生产关系对照表。

```

Autopilot：`[{t:0,v:10},{t:1.2,v:10},{t:4,v:50},{t:6.5,v:50},{t:9,v:100},{t:11,v:72},{t:13,v:10}]`，keys `[10,50,72,100]`。
**停留帧在 p=50**（剩余产品刚出现、阶级随之产生——「私有制是阶级的根源」那一格）。
状态：p≤30「没有剩余产品，氏族公有」；30–45「出现剩余产品，私有制萌芽」；>45「阶级出现，进入阶级社会」。

**例题**：「运用生产力与生产关系的知识，说明原始社会为什么会被阶级社会取代。」答案：① 原始社会末期，生产工具改进、生产力发展，出现了剩余产品；② 剩余产品的出现使个体劳动成为可能，生产资料由氏族公有变为家庭私有，私有制产生；③ 私有制导致贫富分化，出现阶级对立；④ 阶级矛盾不可调和，国家产生，原始社会解体，人类进入阶级社会。可见，生产力的发展是根本原因。
**六问**：① 原始社会为什么没有剥削；② 剩余产品是怎么来的；③ 阶级产生的根本原因是什么；④ 国家是怎么产生的；⑤ 奴隶社会比原始社会进步在哪里；⑥ 三种阶级社会的共同点是什么。
**易错**：✗ 原始社会人人平等是因为道德高尚 / ✗ 阶级是暴力掠夺造成的 / ✗ 国家从来就有 / ✗ 私有制先于剩余产品 / ✗ 奴隶社会一无是处 / ✗ 阶级社会永远存在。

## bx1-c1-s2 科学社会主义的理论与实践

**课本原话**
1. 空想社会主义是科学社会主义的思想来源，但它没有找到实现理想社会的现实力量和正确道路。
2. 1848 年 2 月，《共产党宣言》发表，标志着科学社会主义的诞生。
3. 1917 年，俄国十月革命建立了世界上第一个社会主义国家，实现了科学社会主义从理论到现实的飞跃。

**三个扣分点**：**唯物史观和剩余价值学说**是科学社会主义的两大理论基石（不是「空想变成科学」这么笼统）；《共产党宣言》的**发表标志诞生**；十月革命的**意义是从理论到现实**（不是「第一次尝试」，巴黎公社才是尝试）。

## bx1-c2-s1 新民主主义革命的胜利

**课本原话**
1. 鸦片战争后，中国逐步成为半殖民地半封建社会，陷入内忧外患的黑暗境地。
2. 1919 年五四运动，标志着新民主主义革命的开端；1921 年中国共产党成立，中国革命的面貌焕然一新。
3. 1949 年中华人民共和国成立，标志着新民主主义革命取得基本胜利。

**三个扣分点**（注：新旧民主主义革命**性质相同**，都是反帝反封建的资产阶级民主革命，区别在领导阶级与前途）：**1919 五四运动是开端**（不是 1921 建党）；新民主主义革命的**领导阶级是无产阶级**（不是资产阶级）；**1949 年新中国成立**标志新民主主义革命胜利（不是社会主义制度确立，那是 1956）。

## bx1-c2-s2 社会主义制度在中国的确立

**课本原话**
1. 1949—1952 年，国家恢复国民经济，为社会主义改造创造了条件。
2. 1953 年提出过渡时期总路线，实行「一化三改」。
3. 1956 年，生产资料私有制的社会主义改造取得决定性胜利，标志着我国社会主义制度基本确立。

**三个扣分点**：**1956 年三大改造完成**才标志社会主义制度确立（不是 1949）；「一化三改」是**一体两翼**（工业化是主体）；新民主主义社会是**过渡性质**的社会（不是独立的社会形态）。

**四张图**：① 1949→1956 三个阶段；② 「一化三改」的结构（一体两翼）；③ 三大改造中公有制经济比重的上升（示意曲线）；④ 社会主义制度确立的意义。

done  = y >= 1956 ? 1 : 0;             // 是否基本确立社会主义制度
```
`cases`：`{v:1949,eq:{share:20}}`、`{v:1952,eq:{share:41.43}}`、`{v:1956,eq:{share:70,done:1}}`。

**停留帧在 y=1956**（三大改造完成，社会主义制度基本确立）。
状态：y≤1952「恢复国民经济」；1953–1955「一化三改进行中」；y=1956「社会主义制度基本确立」。

**例题**：「为什么说 1956 年三大改造的完成标志着我国社会主义制度基本确立？」答案：① 三大改造使生产资料私有制转变为社会主义公有制；② 公有制经济在国民经济中占主体地位；③ 社会主义经济制度的基础建立起来，与之相适应的政治制度也已确立。因此社会主义制度基本确立。
**六问**：① 过渡时期指哪一段；② 「一化三改」的内容；③ 三大改造的实质；④ 为什么说新民主主义社会是过渡性的；⑤ 社会主义制度确立的标志；⑥ 社会主义制度确立的意义。
**易错**：✗ 1949 年社会主义制度就确立了 / ✗ 三大改造只改造农业 / ✗ 「一化三改」就是工业化和合作化 / ✗ 新民主主义社会是独立社会形态 / ✗ 改造完成后还有私有制 / ✗ 社会主义改造是和平赎买个体农民。
