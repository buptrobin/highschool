这一框是全书的起点：先讲清人类社会为什么会长出私有制、阶级和国家，后面讲资本主义基本矛盾、讲科学社会主义才有落点。最容易错的一件事，是把「原始社会人人平等」讲成道德故事——课本的答案是生产力：原始社会生产力水平极端低下，没有剩余产品，也就没有可供私人占有的东西。

01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 原始社会的位置人教版（2019）必修1 · 第一课第一框

原始社会是人类社会发展的最初阶段，也是最低阶段。原始社会生产力水平极端低下。

→ 翻成人话：两个「最」定位置，一句「极端低下」定原因。生产力水平极端低下意味着没有剩余产品——全部劳动成果刚够维持生存；而原始社会没有剩余产品，就没有可供私人占有的对象，也就没有私有制、阶级和国家。答题时这三层要连着写，只写「生产力低」拿不到满分。

课本原话 · 解体是怎么开始的人教版（2019）必修1 · 第一课第一框

随着生产力的发展，原始社会末期出现了剩余产品，个体劳动逐渐盛行，生产资料由氏族公有变为家庭私有。

→ 翻成人话：这句话是一条四环因果链：生产力发展（原因）→ 剩余产品（前提）→ 个体劳动盛行（途径）→ 生产资料私有（结果）。四个环节顺序不能颠倒：先有剩余产品，才谈得上私有；先有私有，才谈得上阶级。凡把「私有制」写在「剩余产品」前面的，都是因果颠倒。

课本原话 · 阶级与国家的产生人教版（2019）必修1 · 第一课第一框

私有制的产生和阶级的出现，使人类社会进入阶级社会；国家是阶级矛盾不可调和的产物。

→ 翻成人话：两个判断。①阶级社会不是从来就有的，是私有制「产生」、阶级「出现」之后才进入的；②国家不是谁发明出来的，国家是阶级矛盾不可调和的产物——矛盾能调和，就不需要国家机器。所以国家随阶级产生而产生，也不会永远存在。

比什么原始社会阶级社会（奴隶社会、封建社会）
生产力水平极端低下，工具以石器为主生产工具有改进，出现剩余产品
剩余产品没有剩余产品有剩余产品，并且被占有
生产资料所有制生产资料归氏族公有生产资料归奴隶主、地主私人占有
阶级没有阶级，没有剥削两大对立阶级：奴隶主与奴隶、地主与农民
国家没有国家国家是阶级矛盾不可调和的产物

整张表只有一个「因」——生产力，其余四行都是「果」。表里的「原始社会没有剩余产品」指剩余产品出现之前；原始社会末期剩余产品一出现，解体过程就开始了。判断一句话错没错，先看它有没有把果当因：说阶级是暴力抢出来的、说国家从来就有，都是把果当因。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 原因类主观题必考

运用生产力与生产关系的知识，说明原始社会为什么会被阶级社会取代。（12 分）
陷阱提示：题目问「为什么被取代」，不是问「阶级社会好不好」；答案必须从生产力起笔，不能从暴力、道德、人口起笔。

  1. 第 1 步 · 审题定性

    知识范围锁死为「生产力与生产关系」，任务类型是「原因类」。原因类要找根本原因，并写出从原因到结果的传导链，只写一句「生产力发展」最多拿一半分。

    用到：生产力、生产关系、根本原因。

  2. 第 2 步 · 起点：生产力发展

    原始社会末期，生产工具改进，生产力发展。生产力水平极端低下的状况被打破，这是整条链的起点，也是根本原因。

    用到：生产力是生产方式中最活跃、最革命的因素。

  3. 第 3 步 · 中间：剩余产品 → 私有制

    生产力发展使劳动成果有了剩余，出现了剩余产品；剩余产品使个体劳动成为可能，生产资料由氏族公有变为家庭私有，私有制产生。

    用到：剩余产品是私有制产生的物质前提，顺序不能倒。

  4. 第 4 步 · 结果：阶级 → 国家

    私有制导致贫富分化，出现阶级对立；阶级矛盾不可调和，国家产生，原始社会解体，人类进入阶级社会。

    用到：阶级、国家是阶级矛盾不可调和的产物。

  5. 第 5 步 · 收口：回到规律

    整条链说明：生产力的发展是根本原因，生产关系一定要适合生产力的状况。原始社会的生产关系已不适合发展了的生产力，被阶级社会取代具有历史必然性。

    用到：生产关系一定要适合生产力状况的规律。

1 / 5

标准答案（可抄进答题卡）

① 原始社会末期，生产工具改进、生产力发展，出现了剩余产品。② 剩余产品的出现使个体劳动成为可能，生产资料由氏族公有变为家庭私有，私有制产生。③ 私有制导致贫富分化，出现阶级对立。④ 阶级矛盾不可调和，国家产生，原始社会解体，人类进入阶级社会。⑤ 可见，阶级产生的根本原因是生产力发展，生产关系一定要适合生产力的状况。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「原始社会没有剥削，是不是因为原始人道德特别高尚？」

不是。原始社会没有剩余产品，生产资料归氏族公有，只能共同劳动、平均分配，剥削根本没有物质前提。道德是结果，不是原因。

「剩余产品到底是怎么冒出来的？」

是生产力发展的结果：生产工具改进 → 劳动生产率提高 → 劳动成果超出维持生存所需 → 出现剩余产品。不是谁省吃俭用攒下来的。

「阶级产生的根本原因是什么？是暴力掠夺吗？」

阶级产生的根本原因是生产力发展。剩余产品 → 个体劳动 → 生产资料私有 → 贫富分化 → 阶级。暴力只是私有制形成过程中的现象，不是根本原因。

「国家是怎么产生的？是大家商量建起来的吗？」

不是。私有制产生阶级，阶级矛盾不可调和，才产生国家。国家是阶级矛盾不可调和的产物，随阶级产生而产生，也不会永远存在。

「奴隶社会那么残酷，凭什么说它比原始社会进步？」

判断进步的标准是是否有利于生产力发展，不是道德感受。金属工具、分工发展、文字和国家产生，俘虏被保留为奴隶也比被杀掉更有利于生产。

「三种阶级社会形态不一样，共同点到底是什么？」

三句：都是生产资料私有制；都存在两大对立阶级；都是少数人占有剩余产品、多数人被剥削。国家都是阶级矛盾不可调和的产物。

六问其实是一件事：从生产力出发，沿「剩余产品 → 私有制 → 阶级 → 国家」这条链往下推。凡是跳过生产力直接谈道德、暴力、人口的答案，都会在半路断掉。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 原始社会人人平等，是因为原始人道德高尚、没有私心。

✓ 原始社会生产力水平极端低下，没有剩余产品，生产资料归氏族公有，只能共同劳动、平均分配。

错在哪：把生产关系的结果说成道德原因。平等是「没有剩余产品」逼出来的，不是觉悟高。

✗ 阶级是暴力掠夺造成的，谁抢到归谁，就有了阶级。

✓ 阶级产生的根本原因是生产力发展：剩余产品出现，个体劳动盛行，生产资料私有，才产生阶级。

错在哪：暴力是现象和手段，不是根本原因。没有剩余产品，抢也没东西可抢。

✗ 国家从来就有，只要有人就有国家。

✓ 国家是阶级矛盾不可调和的产物，随阶级产生而产生，也不会永远存在。

错在哪：原始社会没有阶级，也没有国家；把阶段性的事物说成永恒的。

✗ 先有了私有制，然后才慢慢出现剩余产品。

✓ 剩余产品的出现是私有制产生的物质前提，顺序是：剩余产品 → 个体劳动 → 生产资料私有。

错在哪：因果颠倒。没有剩余，私有制没有可占有的对象。

✗ 奴隶社会一无是处，纯粹是历史倒退。

✓ 奴隶社会代替原始社会是历史的进步：金属工具广泛使用，分工发展，文字和国家产生。

错在哪：用道德评价代替历史评价，判断标准应是是否有利于生产力发展。

✗ 阶级社会从来就有，也会永远存在下去。

✓ 阶级社会只是人类社会发展的一个阶段，阶级和国家最终会消亡。

错在哪：把阶段性当永恒，混淆了「有阶级的社会」和「人类社会」。

✗ 原始社会没有剩余产品，所以原始人都很穷。

✓ 没有剩余产品指全部劳动成果刚够维持生存，没有可供占有的剩余，与「穷」不是一回事。

错在哪：把「无剩余」偷换成「贫困」，两个概念的内涵完全不同。
