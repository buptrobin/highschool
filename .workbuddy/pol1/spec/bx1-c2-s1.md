## bx1-c2-s1 新民主主义革命的胜利

**课本原话**
1. 鸦片战争后，中国逐步成为半殖民地半封建社会，陷入内忧外患的黑暗境地。
2. 1919 年五四运动，标志着新民主主义革命的开端；1921 年中国共产党成立，中国革命的面貌焕然一新。
3. 1949 年中华人民共和国成立，标志着新民主主义革命取得基本胜利。

**三个扣分点**（注：新旧民主主义革命**性质相同**，都是反帝反封建的资产阶级民主革命，区别在领导阶级与前途）：**1919 五四运动是开端**（不是 1921 建党）；新民主主义革命的**领导阶级是无产阶级**（不是资产阶级）；**1949 年新中国成立**标志新民主主义革命胜利（不是社会主义制度确立，那是 1956）。

**四张图**：① 近代中国社会性质与主要矛盾；② 时间轴 1840→1919→1921→1949；③ 旧民主主义革命与新民主主义革命的对照表；④ 三种政治力量、三条道路的失败与成功。

**互动模型**：滑块＝年份 y（1840–1949，step 1）
```js
left = 1949 - y;                      // 距新中国成立还有多少年
stage = y < 1919 ? 1 : y < 1921 ? 2 : y < 1945 ? 3 : 4;   // 1 旧民主主义 2 转折 3 新民主主义 4 解放战争
```
`cases`：`{v:1840,eq:{left:109,stage:1}}`、`{v:1919,eq:{left:30,stage:2}}`、`{v:1949,eq:{left:0,stage:4}}`。
Autopilot：`[{t:0,v:1840},{t:1.2,v:1840},{t:4,v:1919},{t:6.5,v:1919},{t:9,v:1949},{t:11,v:1921},{t:13,v:1840}]`，keys `[1840,1919,1921,1949]`。
**停留帧在 y=1919**（五四运动：新民主主义革命的开端，领导阶级在这里换人）。
状态：stage=1「旧民主主义革命时期」；stage=2「五四运动：新民主主义革命开端」；stage=3「新民主主义革命时期」；stage=4「解放战争，胜利前夜」。

**例题**：「为什么说五四运动是新民主主义革命的开端？」答案：① 五四运动中工人阶级登上政治舞台，成为运动主力；② 促进了马克思主义在中国的传播；③ 为中国共产党的成立作了思想上干部上的准备。领导阶级的变化，使中国革命进入新民主主义革命阶段。
**六问**：① 近代中国的社会性质；② 新旧民主主义革命的根本区别；③ 五四运动的意义；④ 中国共产党成立的意義；⑤ 新中国成立的意义；⑥ 为什么资本主义道路在中国走不通。
**易错**：✗ 五四运动是共产党领导的 / ✗ 新民主主义革命由资产阶级领导 / ✗ 1949 年就确立了社会主义制度 / ✗ 新旧民主主义革命性质相同，所以没有本质区别（性质确实相同，但领导阶级和前途不同，这就是本质区别） / ✗ 资本主义道路没试过 / ✗ 三座大山指封建主义一山。
