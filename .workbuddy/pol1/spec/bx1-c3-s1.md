# 本节规格（只读这一节，不要读 SPEC.md 全文）

## bx1-c3-s1 伟大的改革开放

**课本原话**
1. 1978 年党的十一届三中全会作出把党和国家工作中心转移到经济建设上来、实行改革开放的历史性决策。
2. 改革开放是决定当代中国命运的关键一招，也是决定实现「两个一百年」奋斗目标、实现中华民族伟大复兴的关键一招。
3. 改革开放极大改变了中国的面貌、中华民族的面貌、中国人民的面貌、中国共产党的面貌。

**三个扣分点**：改革开放**从 1978 年十一届三中全会开始**（不是 1979）；改革是**社会主义制度的自我完善和发展**（不是改变社会主义制度）；开放是**全方位、多层次、宽领域**的（不是只开放沿海）。

**四张图**：① 1978 年十一届三中全会的历史性决策；② 对内改革（农村→城市）与对外开放（特区→全方位）两条线；③ GDP 增长的长期曲线（对数感）；④ 改革开放「四个面貌」的改变。

**互动模型**：滑块＝年份 y（1978–2020，step 1），GDP 用锚点线性插值（万亿元）
```js
// 锚点：1978 0.37、1990 1.89、2000 10.0、2010 41.2、2020 101.6（国家统计局口径）
```
`cases`：`{v:1978,eq:{gdp:0.37}}`、`{v:2000,eq:{gdp:10}}`、`{v:2020,eq:{gdp:101.6}}`。
Autopilot：`[{t:0,v:1978},{t:1.2,v:1978},{t:4,v:2020},{t:6.5,v:2020},{t:9,v:2000},{t:11,v:2010},{t:13,v:1978}]`，keys `[1978,1990,2000,2010,2020]`。
**停留帧在 y=2020**（GDP 从 0.37 万亿到 101.6 万亿，同一个国家 42 年的变化）。
状态：y<1992「改革探索期」；1992–2001「市场经济体制建立」；2001–2012「加入 WTO 后高速增长」；>2012「新时代高质量发展」。

**例题**：「为什么说改革开放是决定当代中国命运的关键一招？」答案：① 十一届三中全会实现工作中心转移，开启了改革开放；② 改革开放极大解放和发展了社会生产力，使中国经济总量跃居世界前列；③ 它改变了国家、民族、人民和党的面貌。因此是关键一招。
**六问**：① 改革开放从哪次会议开始；② 改革的性质是什么；③ 对内改革从哪开始；④ 对外开放的格局特点；⑤ 改革开放的地位；⑥ 为什么说「只有改革开放才能发展中国」。
**易错**：✗ 改革开放 1979 年开始 / ✗ 改革就是改变社会主义制度 / ✗ 开放只指沿海 / ✗ 改革开放只是经济领域 / ✗ 农村改革从城市开始 / ✗ 改革开放已经完成。
**数据口径**：GDP 数值取自国家统计局年度数据（万亿元），图上标注来源；插值只用于滑块连续变化。
