## bx1-c3-s2 中国特色社会主义的创立、发展和完善

**课本原话**
1. 邓小平理论：回答了「什么是社会主义、怎样建设社会主义」的问题。
2. 「三个代表」重要思想、科学发展观，不断推进马克思主义中国化。
3. 习近平新时代中国特色社会主义思想是马克思主义中国化最新成果，是当代中国马克思主义、二十一世纪马克思主义。

**三个扣分点**：四个理论成果**各自回答的问题不同**（别混）；它们都是**马克思主义中国化**的成果（不是另起一套）；**习近平新时代中国特色社会主义思想**是*最新成果*、是全党全国人民为实现中华民族伟大复兴而奋斗的行动指南。

**四张图**：① 四个理论成果与对应回答的问题（对照表）；② 时间轴：1997 十五大、2002 十六大、2012 十八大、2017 十九大；③ 马克思主义中国化的「一脉相承、与时俱进」；④ 中国特色社会主义理论体系的范围。

**互动模型**：滑块＝年份 y（1978–2022，step 1）
```js
stage = y < 1997 ? 1 : y < 2002 ? 2 : y < 2012 ? 3 : y < 2017 ? 4 : 5;
// 1 探索 2 邓小平理论（1997 十五大写入党章）3 三个代表（2002）4 科学发展观（2012）5 习近平思想（2017）
```
`cases`：`{v:1997,eq:{stage:2}}`、`{v:2002,eq:{stage:3}}`、`{v:2017,eq:{stage:5}}`。
Autopilot：`[{t:0,v:1978},{t:1.2,v:1978},{t:4,v:1997},{t:6.5,v:1997},{t:9,v:2017},{t:11,v:2012},{t:13,v:1978}]`，keys `[1978,1997,2002,2012,2017]`。
**停留帧在 y=2017**（十九大把习近平新时代中国特色社会主义思想确立为党的指导思想）。
状态：按 stage 输出对应理论成果与「回答了什么、何时写入党章」。

**例题**：「中国特色社会主义理论体系包括哪些内容？它们共同的「脉」是什么？」答案：包括邓小平理论、「三个代表」重要思想、科学发展观、习近平新时代中国特色社会主义思想。它们都坚持马克思主义基本原理同中国具体实际相结合，都是马克思主义中国化的成果，一脉相承又与时俱进。
**六问**：① 四个理论成果各回答什么问题；② 什么是马克思主义中国化；③ 理论体系包括哪些；④ 最新成果是什么；⑤ 为什么说一脉相承；⑥ 理论创新与实践创新的关系。
**易错**：✗ 四个理论成果回答同一个问题 / ✗ 理论体系只包括邓小平理论 / ✗ 习近平思想与前面几个无关 / ✗ 马克思主义中国化就是照搬 / ✗ 科学发展观是二十一世纪马克思主义 / ✗ 理论成果没有写入党章。
