# 本节规格（只读这一节，不要读 SPEC.md 全文）

## bx1-c4-s3 习近平新时代中国特色社会主义思想

**课本原话**
1. 习近平新时代中国特色社会主义思想，是对马克思列宁主义、毛泽东思想、邓小平理论、「三个代表」重要思想、科学发展观的继承和发展。
2. 它是当代中国马克思主义、二十一世纪马克思主义，是中华文化和中国精神的时代精华。
3. 其核心内容可以概括为「十个明确」「十四个坚持」「十三个方面成就」。

**三个扣分点**：三者的**定位不同**：「十个明确」是**核心内容**（理论层面），「十四个坚持」是**基本方略**（实践层面），「十三个方面成就」是**实践成果**；它是**最新成果**而不是「又一个理论」；写定位时「当代中国马克思主义、二十一世纪马克思主义」两句要一起写。

**四张图**：① 三个板块的定位对照表；② 「十个明确」管什么；③ 「十四个坚持」管什么；④ 理论—实践—成就的关系图。

**互动模型**：滑块＝板块编号 k（1–3）
```js
name = ['十个明确','十四个坚持','十三个方面成就'][k-1];
role = ['核心内容（理论层面）','基本方略（实践层面）','实践成果（成就层面）'][k-1];
```
`cases`：`{v:1,eq:{k:1}}`、`{v:2,eq:{k:2}}`、`{v:3,eq:{k:3}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:2},{t:6.5,v:2},{t:9,v:3},{t:11,v:2},{t:13,v:1}]`，keys `[1,2,3]`。
**停留帧在 k=2**（「十四个坚持」：从理论到实践的中间那一层，最容易和「十个明确」混）。
状态：k=1「十个明确——管方向、管理论」；k=2「十四个坚持——管怎么做」；k=3「十三个方面成就——已经做成的事」。

**例题**：「如何理解习近平新时代中国特色社会主义思想是当代中国马克思主义、二十一世纪马克思主义？」答案：① 它坚持马克思主义基本原理，又回答了新时代坚持和发展什么样的中国特色社会主义、怎样坚持和发展中国特色社会主义等重大时代课题；② 它提出一系列原创性贡献，开辟了马克思主义新境界；③ 它指导中国实践取得历史性成就，因而既是当代中国的马克思主义，也是二十一世纪的马克思主义。
**六问**：① 三个板块各是什么；② 「十个明确」与「十四个坚持」的区别；③ 为什么说是最新成果；④ 为什么说是二十一世纪马克思主义；⑤ 它继承了哪些理论；⑥ 学习它有什么意义。
**易错**：✗ 十个明确=十四个坚持 / ✗ 它只是又一个理论成果，与前人无关 / ✗ 只写「当代中国马克思主义」漏掉「二十一世纪」 / ✗ 十三个方面成就是理论 / ✗ 它是凭空产生的 / ✗ 学不学都一样。
