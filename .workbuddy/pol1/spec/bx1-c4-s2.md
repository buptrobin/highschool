# 本节规格（只读这一节，不要读 SPEC.md 全文）

## bx1-c4-s2 实现中华民族伟大复兴的中国梦

**课本原话**
1. 实现中华民族伟大复兴是近代以来中华民族最伟大的梦想。
2. 中国梦的本质是国家富强、民族振兴、人民幸福。
3. 实现中国梦必须走中国道路、弘扬中国精神、凝聚中国力量；分两步走，到 2035 年基本实现社会主义现代化，到本世纪中叶建成社会主义现代化强国。

**三个扣分点**：中国梦的本质是**三句话**（国家富强、民族振兴、人民幸福），少一句就扣分；实现路径是**三个「必须」**；「两步走」的**时间点和目标不能错**（2035 基本实现现代化；本世纪中叶建成强国）。

**四张图**：① 中国梦的本质三句话；② 三个「必须」的路径图；③ 两步走时间轴（2020→2035→本世纪中叶）；④ 个人梦与中国梦的关系。

**互动模型**：滑块＝年份 y（2020–2050，step 1）
```js
left = 2035 - y;                              // 距「基本实现现代化」还有多少年（负值表示已过）
pct  = (y - 2020) / (2050 - 2020) * 100;      // 两步走进程（%）
```
`cases`：`{v:2020,eq:{left:15,pct:0}}`、`{v:2035,eq:{left:0,pct:50}}`、`{v:2050,eq:{left:-15,pct:100}}`。
Autopilot：`[{t:0,v:2020},{t:1.2,v:2020},{t:4,v:2035},{t:6.5,v:2035},{t:9,v:2050},{t:11,v:2040},{t:13,v:2020}]`，keys `[2020,2035,2040,2050]`。
**停留帧在 y=2035**（第一步目标达成：基本实现社会主义现代化）。
状态：y<2035「朝着基本实现现代化奋斗」；y=2035「第一步目标达成」；y>2035「向社会主义现代化强国迈进」。

**例题**：「怎样实现中华民族伟大复兴的中国梦？」答案：① 必须走中国道路，即中国特色社会主义道路；② 必须弘扬中国精神，即以爱国主义为核心的民族精神和以改革创新为核心的时代精神；③ 必须凝聚中国力量，即全国各族人民大团结的力量。分两步走：2035 年基本实现社会主义现代化，本世纪中叶建成社会主义现代化强国。
**六问**：① 中国梦的本质；② 三个「必须」；③ 两步走的时间点；④ 个人梦与中国梦的关系；⑤ 中国梦是不是轻轻松松就能实现；⑥ 为什么必须走中国道路。
**易错**：✗ 中国梦的本质只写「国家富强」 / ✗ 2035 年建成强国 / ✗ 本世纪中叶基本实现现代化 / ✗ 中国梦只是国家的事 / ✗ 可以不弘扬中国精神 / ✗ 中国梦是空想。
