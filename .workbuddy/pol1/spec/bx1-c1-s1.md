## bx1-c1-s1 原始社会的解体和阶级社会的演进

**课本原话**
1. 原始社会是人类社会发展的最初阶段，也是最低阶段。原始社会生产力水平极端低下。
2. 随着生产力的发展，原始社会末期出现了剩余产品，个体劳动逐渐盛行，生产资料由氏族公有变为家庭私有。
3. 私有制的产生和阶级的出现，使人类社会进入阶级社会；国家是阶级矛盾不可调和的产物。

**三个扣分点**：原始社会**没有剩余产品**（不是「穷人很多」）；阶级产生的**根本原因是生产力发展**（不是暴力掠夺）；国家**随阶级产生而产生**（不是从来就有的，也不会永远存在）。

**四张图**：① 原始社会的生活与生产资料公有（结构图）；② 一条因果链：生产力发展→剩余产品→私有制→阶级→国家；③ 阶级社会的两大对立阶级；④ 三种社会形态（原始、奴隶、封建）的生产关系对照表。

**互动模型**：滑块＝生产力水平指数 p（10–100，10 为原始社会早期）
```js
surplus = Math.max(0, (p - 30) / 70) * 100;   // 剩余产品率（%），p≤30 时没有剩余
cls     = p > 45 ? 1 : 0;                      // 是否出现阶级（阈值示意）
```
`cases`：`{v:20,eq:{surplus:0,cls:0}}`、`{v:50,eq:{surplus:28.57,cls:1}}`、`{v:90,eq:{surplus:85.71,cls:1}}`。
Autopilot：`[{t:0,v:10},{t:1.2,v:10},{t:4,v:50},{t:6.5,v:50},{t:9,v:100},{t:11,v:72},{t:13,v:10}]`，keys `[10,50,72,100]`。
**停留帧在 p=50**（剩余产品刚出现、阶级随之产生——「私有制是阶级的根源」那一格）。
状态：p≤30「没有剩余产品，氏族公有」；30–45「出现剩余产品，私有制萌芽」；>45「阶级出现，进入阶级社会」。

**例题**：「运用生产力与生产关系的知识，说明原始社会为什么会被阶级社会取代。」答案：① 原始社会末期，生产工具改进、生产力发展，出现了剩余产品；② 剩余产品的出现使个体劳动成为可能，生产资料由氏族公有变为家庭私有，私有制产生；③ 私有制导致贫富分化，出现阶级对立；④ 阶级矛盾不可调和，国家产生，原始社会解体，人类进入阶级社会。可见，生产力的发展是根本原因。
**六问**：① 原始社会为什么没有剥削；② 剩余产品是怎么来的；③ 阶级产生的根本原因是什么；④ 国家是怎么产生的；⑤ 奴隶社会比原始社会进步在哪里；⑥ 三种阶级社会的共同点是什么。
**易错**：✗ 原始社会人人平等是因为道德高尚 / ✗ 阶级是暴力掠夺造成的 / ✗ 国家从来就有 / ✗ 私有制先于剩余产品 / ✗ 奴隶社会一无是处 / ✗ 阶级社会永远存在。
