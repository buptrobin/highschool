# 本节规格（只读这一节，不要读 SPEC.md 全文）

## bx1-c4-s1 中国特色社会主义进入新时代

**课本原话**
1. 2012 年党的十八大以来，中国特色社会主义进入新时代，这是我国发展新的历史方位。
2. 新时代我国社会主要矛盾已经转化为人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾。
3. 我国仍处于并将长期处于社会主义初级阶段的基本国情没有变，我国是世界最大发展中国家的国际地位没有变。

**三个扣分点**：主要矛盾的**表述要一字不差**（「美好生活需要」对「不平衡不充分的发展」）；**两个「没有变」**必须一起写（初级阶段、最大发展中国家）；新时代是**历史方位**的判断，不是「进入了新社会形态」。

**四张图**：① 2012 年十八大与新时代的历史方位；② 主要矛盾表述的前后对照（1981 vs 2017）；③ 两个「没有变」；④ 新时代的「三个意味着」。

**互动模型**：滑块＝年份 y（1956–2035，step 1）
```js
ma = y < 2017 ? 1 : 2;     // 1 旧表述 2 新表述
```
`cases`：`{v:1981,eq:{ma:1}}`、`{v:2017,eq:{ma:2}}`、`{v:2035,eq:{ma:2}}`。
Autopilot：`[{t:0,v:1956},{t:1.2,v:1956},{t:4,v:1981},{t:6.5,v:1981},{t:9,v:2035},{t:11,v:2017},{t:13,v:1956}]`，keys `[1956,1981,2017,2035]`。
**停留帧在 y=2017**（十九大：主要矛盾的新表述正式提出）。
状态：ma=1「人民日益增长的物质文化需要同落后的社会生产之间的矛盾」；ma=2「人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾」。

**例题**：「如何理解新时代我国社会主要矛盾的变化？」答案：① 党的十八大以来，我国经济社会发展取得历史性成就，人民需要从「物质文化」扩展到「美好生活」；② 制约因素从「落后的社会生产」变为「不平衡不充分的发展」；③ 但基本国情和国际地位「两个没有变」仍然成立。所以主要矛盾变化没有改变我国社会主义初级阶段的判断。
**六问**：① 新时代从哪一年开始；② 主要矛盾新旧表述差别；③ 为什么说两个「没有变」；④ 主要矛盾变化是否意味着进入发达阶段；⑤ 新时代的「三个意味着」；⑥ 解决主要矛盾的根本途径。
**易错**：✗ 主要矛盾还是「落后的社会生产」 / ✗ 主要矛盾变了，初级阶段也变了 / ✗ 新时代就是新社会形态 / ✗ 只写「不平衡不充分」不带前半句 / ✗ 我国已不是发展中国家 / ✗ 新时代始于 2017 年十九大。
