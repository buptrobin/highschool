## bx1-c1-s2 科学社会主义的理论与实践

**课本原话**
1. 空想社会主义是科学社会主义的思想来源，但它没有找到实现理想社会的现实力量和正确道路。
2. 1848 年 2 月，《共产党宣言》发表，标志着科学社会主义的诞生。
3. 1917 年，俄国十月革命建立了世界上第一个社会主义国家，实现了科学社会主义从理论到现实的飞跃。

**三个扣分点**：**唯物史观和剩余价值学说**是科学社会主义的两大理论基石（不是「空想变成科学」这么笼统）；《共产党宣言》的**发表标志诞生**；十月革命的**意义是从理论到现实**（不是「第一次尝试」，巴黎公社才是尝试）。

**四张图**：① 空想社会主义与科学社会主义的对照表；② 两大理论基石各自解决了什么问题；③ 时间轴：1848《宣言》→1871 巴黎公社→1917 十月革命；④ 社会主义从一国到多国的发展。

**互动模型**：滑块＝年份 y（1840–1920，step 1）
```js
gap  = y - 1848;                          // 距《共产党宣言》发表多少年
era  = y < 1848 ? 1 : y < 1871 ? 2 : y < 1917 ? 3 : 4;   // 1 诞生前 2 诞生 3 尝试 4 现实
```
`cases`：`{v:1840,eq:{gap:-8,era:1}}`、`{v:1848,eq:{gap:0,era:2}}`、`{v:1917,eq:{gap:69,era:4}}`。
Autopilot：`[{t:0,v:1840},{t:1.2,v:1840},{t:4,v:1917},{t:6.5,v:1917},{t:9,v:1848},{t:11,v:1871},{t:13,v:1840}]`，keys `[1840,1848,1871,1917]`。
**停留帧在 y=1917**（十月革命：科学社会主义第一次从理论变成现实）。
状态：era=1「理论还在酝酿」；era=2「《宣言》发表，科学社会主义诞生」；era=3「巴黎公社：第一次伟大尝试」；era=4「十月革命：理论变为现实」。

**例题**：「为什么说《共产党宣言》的发表标志着科学社会主义的诞生？」答案：①《宣言》第一次系统阐述了唯物史观，揭示了社会发展规律；② 阐明了阶级斗争学说和无产阶级的历史使命；③ 指出了无产阶级革命的正确道路，使社会主义从空想变为科学。所以它的发表标志着科学社会主义的诞生。
**六问**：① 空想社会主义的局限在哪；② 两大理论基石是什么；③ 《宣言》发表的意义；④ 巴黎公社的地位；⑤ 十月革命的意义；⑥ 社会主义为什么能实现从理论到现实的飞跃。
**易错**：✗ 空想社会主义就是科学社会主义 / ✗ 科学社会主义只有唯物史观一个基石 / ✗ 巴黎公社建立了第一个社会主义国家 / ✗ 十月革命是第一次尝试 / ✗ 《宣言》只是宣传小册子 / ✗ 科学社会主义是凭空想出来的。
