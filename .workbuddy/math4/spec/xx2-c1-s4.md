## xx2-c1-s4 数学归纳法

**课本原话**
1. 证明一个与正整数 n 有关的命题，可按下列步骤进行：(1) 证明当 n=n₀ 时命题成立；(2) 假设 n=k（k≥n₀）时命题成立，证明 n=k+1 时命题也成立。
2. 完成这两步，就可以断定命题对从 n₀ 开始的所有正整数 n 都成立。
3. 这种证明方法叫做数学归纳法。

**三个扣分点**：两步**缺一不可**（只验证不递推、只递推不奠基都不行）；第二步必须**用上**归纳假设（不用就不是归纳法）；从 k 到 k+1 要写清**增加了哪一项**。

**四张图**：① 多米诺骨牌（两块：推倒第一块、每块都能推倒下一块）；② 两步的写法模板；③ 从 n=k 到 n=k+1 左边增加的那一项；④ 少了奠基或少了递推会怎样（两个反例）。

**互动模型**：滑块＝k（1 到 6，step 1），命题 1+3+5+…+(2k−1)=k²
```js
inc = 2 * k + 1;                        // 从 k 到 k+1，左边多出来的项
dl  = inc;                              // 左边增量
dr  = (k + 1) * (k + 1) - k * k;        // 右边增量，也等于 2k+1
same = dl === dr ? 1 : 0;
```
`cases`：`{v:1,eq:{inc:3,same:1}}`、`{v:3,eq:{inc:7,same:1}}`、`{v:6,eq:{inc:13,same:1}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:3},{t:6.5,v:3},{t:9,v:6},{t:11.5,v:4},{t:13.5,v:1}]`，keys `[1,3,6]`。
**停留帧在 k=3**（左边多出 7，右边 (k+1)²−k² 也等于 7，两边增量相等正是递推的关键）。
状态：k=1「奠基成立」；k≥2「用了归纳假设 k，才能走到 k+1」。

**例题**：「用数学归纳法证明 1+3+5+…+(2n−1)=n²。」答案：① n=1 时左边 1、右边 1，成立。② 假设 n=k 时 1+3+…+(2k−1)=k²，则 n=k+1 时左边 =k²+(2k+1)=(k+1)²，等于右边，成立。由①②知对一切正整数 n 成立。
**六问**：① 只验证前几项算证明吗；② 第二步能不用归纳假设吗；③ 奠基必须从 n=1 开始吗；④ k 到 k+1 增加了什么；⑤ 为什么要写「由①②」；⑥ 归纳法与反证法的区别。
**易错**：✗ 只验证不递推 / ✗ 递推时不用假设直接算 / ✗ k 的取值没有范围限制 / ✗ 增加项写错（写成 2k 或 2k+2）/ ✗ 结论不写「对一切正整数」 / ✗ 把 n=k 代入后又把 n=k+1 代回同一个式子。
