## xx2-c2-s2 导数的运算

**课本原话**
1. 基本初等函数的导数公式：(xⁿ)′=nxⁿ⁻¹，(sinx)′=cosx，(cosx)′=−sinx，(eˣ)′=eˣ，(lnx)′=1/x。
2. 运算法则：[f(x)±g(x)]′=f′(x)±g′(x)，[f(x)g(x)]′=f′(x)g(x)+f(x)g′(x)，[f(x)/g(x)]′=(f′g−fg′)/g²。
3. 复合函数求导：y=f(g(x))，则 y′=f′(g(x))·g′(x)。

**三个扣分点**：(fg)′ 不是 f′g′（要乘出来再求导）；商的求导顺序是**上导下不导减上不导下导**；复合函数**不能漏乘内层导数**。

**四张图**：① 基本导数公式表；② 和差与数乘法则；③ 乘积法则的对照（错误写法 vs 正确）；④ 复合函数求导的「剥洋葱」链条。

**互动模型**：滑块＝x（0.5 到 4，step 0.25），f(x)=x³+2x，f′(x)=3x²+2
```js
d  = 3 * x * x + 2;                    // 导数值 = 切线斜率
b  = (x * x * x + 2 * x) - d * x;      // 切线 y = d·x + b 的截距
```
`cases`：`{v:1,eq:{d:5,b:-2}}`、`{v:2,eq:{d:14,b:-16}}`、`{v:3,eq:{d:29,b:-54}}`。
Autopilot：`[{t:0,v:0.5},{t:1.2,v:0.5},{t:4,v:2},{t:6.5,v:2},{t:9,v:4},{t:11.5,v:3},{t:13.5,v:0.5}]`，keys `[0.5,2,3,4]`。
**停留帧在 x=2**（f′(2)=14，切线 y=14x−16，曲线与切线相切于 (2,12)）。
状态：d>0「曲线在该点上升」；d=0「切线水平」。

**例题**：「求 f(x)=x³+2x 在 x=2 处的切线方程。」答案：f′(x)=3x²+2，f′(2)=14，f(2)=12，切线 y−12=14(x−2)，即 y=14x−16。
**六问**：① (fg)′ 等于 f′g′ 吗；② 商的法则顺序；③ 复合函数为什么要乘内层导数；④ 常数的导数是多少；⑤ 系数能提到括号外吗；⑥ (xⁿ)′ 的指数怎么变。
**易错**：✗ (fg)′=f′g′ / ✗ 商的分子顺序反了 / ✗ 复合函数漏乘内层 / ✗ 忘记常数项导数为 0 / ✗ (xⁿ)' 写成 xⁿ⁻¹ / ✗ 切线方程漏用 f(x₀)。
