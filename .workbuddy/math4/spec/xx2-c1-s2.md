## xx2-c1-s2 等差数列

**课本原话**
1. 从第 2 项起，每一项与它的前一项的差等于同一个常数，这个数列叫等差数列，这个常数叫公差 d。
2. 通项公式：aₙ=a₁+(n−1)d。
3. 前 n 项和：Sₙ=n(a₁+aₙ)/2=na₁+n(n−1)d/2。

**三个扣分点**：公差是**后项减前项**（aₙ₊₁−aₙ，反了会得 −d）；aₙ 是 n 的**一次函数**（d=0 时退化）；Sₙ 是 n 的**二次函数且常数项为 0**。

**四张图**：① 公差 d 的几何意义（相邻两项的落差）；② aₙ 与 n 的一次函数图象（点都在一条直线上）；③ 倒序相加求 Sₙ；④ 等差中项 2a₂=a₁+a₃。

**互动模型**：滑块＝序号 n（1 到 12，step 1），a₁=2、d=3
```js
an = 2 + 3 * (n - 1);
sn = n * (2 + an) / 2;
mid = 2 * (2 + 3 * 1) - (2 + 3 * 0) - (2 + 3 * 2);   // 中项检验，恒为 0
```
`cases`：`{v:1,eq:{an:2,sn:2}}`、`{v:5,eq:{an:14,sn:40}}`、`{v:10,eq:{an:29,sn:155}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:5},{t:6.5,v:5},{t:9,v:10},{t:11.5,v:7},{t:13.5,v:1}]`，keys `[1,5,10]`。
**停留帧在 n=5**（a₅=14、S₅=40，且 2a₃=a₂+a₄=8+11，中项恒成立）。
状态：n=1「S₁=a₁」；n>1「Sₙ=n(a₁+aₙ)/2 在累加」。

**例题**：「等差数列中 a₃=7，a₇=15，求 a₁、d 与 S₁₀。」答案：d=(15−7)/(7−3)=2，a₁=7−2×2=3，a₁₀=3+9×2=21，S₁₀=10(3+21)/2=120。
**六问**：① 公差怎么算方向；② d=0 时是什么数列；③ aₙ 是 n 的几次函数；④ Sₙ 的常数项为什么是 0；⑤ 等差中项怎么用；⑥ 已知两个项能唯一确定数列吗。
**易错**：✗ 公差用前项减后项 / ✗ 项数算成 n+1 / ✗ Sₙ 写成 n(a₁+aₙ) / ✗ 把 aₙ 当二次函数 / ✗ d=0 说没有公差 / ✗ 中项写成 a₁+a₃=a₂。
