## xx2-c1-s3 等比数列

**课本原话**
1. 从第 2 项起，每一项与它的前一项的比等于同一个常数，这个数列叫等比数列，这个常数叫公比 q（q≠0）。
2. 通项公式：aₙ=a₁qⁿ⁻¹。
3. 前 n 项和：q≠1 时 Sₙ=a₁(1−qⁿ)/(1−q)；q=1 时 Sₙ=na₁。

**三个扣分点**：q=1 时**不能**套求和公式（必须分情况）；q 不能为 0，首项也不能为 0；aₙ=a₁qⁿ⁻¹ 的指数是 **n−1** 不是 n。

**四张图**：① 公比的几何意义（相邻两项的倍数）；② q>1 与 0<q<1 两种走势；③ 错位相减求 Sₙ 的过程；④ q=1 时公式失效（常数列）。

**互动模型**：滑块＝公比 q（0.5 到 2，step 0.1），a₁=1、n=6
```js
a6 = Math.pow(q, 5);
s6 = Math.abs(q - 1) < 1e-9 ? 6 : (1 - Math.pow(q, 6)) / (1 - q);
ok = Math.abs(q - 1) < 1e-9 ? 0 : 1;   // 能否用求和公式
```
`cases`：`{v:1,eq:{a6:1,s6:6,ok:0}}`、`{v:2,eq:{a6:32,s6:63}}`、`{v:0.5,eq:{a6:0.03125,s6:1.96875}}`。
Autopilot：`[{t:0,v:0.5},{t:1.2,v:0.5},{t:4,v:1},{t:6.5,v:1},{t:9,v:2},{t:11.5,v:1.5},{t:13.5,v:0.5}]`，keys `[0.5,1,1.5,2]`。
**停留帧在 q=1**（常数列，Sₙ=na₁=6，求和公式分母为 0 用不了——最容易被扣分的一格）。
状态：q=1「常数列，公式失效，Sₙ=na₁」；q>1「递增」；0<q<1「递减」。

**例题**：「等比数列 a₁=1，q=2，求 a₆ 与 S₆。」答案：a₆=1×2⁵=32；S₆=(1−2⁶)/(1−2)=63。
**六问**：① q 能为 0 吗；② q=1 时怎么求和；③ 指数是 n 还是 n−1；④ 公比怎么算方向；⑤ 等比中项有几个；⑥ 等比数列一定单调吗。
**易错**：✗ q=1 直接套公式 / ✗ 指数写成 n / ✗ 公比用前项除后项 / ✗ 等比中项只取正 / ✗ 认为 q<0 不存在 / ✗ 首项为 0 还叫等比数列。

- 出处一律写「人教A版选择性必修第二册 · 第X章第Y节」，**不写页码**。
