## xx2-c2-s1 导数的概念及其意义

**课本原话**
1. 函数 y=f(x) 从 x₀ 到 x₀+Δx 的平均变化率是 Δy/Δx=(f(x₀+Δx)−f(x₀))/Δx。
2. 当 Δx 无限趋近于 0 时，平均变化率趋近于一个确定的值，这个值叫做 f(x) 在 x₀ 处的导数，记作 f′(x₀)。
3. 导数的几何意义：曲线 y=f(x) 在点 (x₀,f(x₀)) 处的切线斜率。

**三个扣分点**：导数是一个**极限值**不是「两点斜率」；f′(x₀) 是**切线**斜率不是割线；Δx 可正可负但**不能等于 0**。

**四张图**：① 割线与平均变化率（两点）；② Δx 变小、割线逐渐贴近切线；③ 导数的定义式；④ 导数的几何意义（切线斜率）与物理意义（瞬时速度）。

**互动模型**：滑块＝Δx=h（0.1 到 2，step 0.1），f(x)=x²，x₀=1
```js
avg = ((1 + h) * (1 + h) - 1) / h;      // 平均变化率 = 2 + h
f1  = 2;                                // f′(1) = 2x|x=1
gap = avg - f1;                         // 与导数的差 = h
```
`cases`：`{v:1,eq:{avg:3}}`、`{v:0.5,eq:{avg:2.5}}`、`{v:0.1,eq:{avg:2.1}}`。
Autopilot：`[{t:0,v:2},{t:1.2,v:2},{t:4,v:1},{t:6.5,v:0.5},{t:9,v:0.1},{t:11.5,v:0.1},{t:13.5,v:2}]`，keys `[0.1,0.5,1,2]`。
**停留帧在 h=0.1**（平均变化率 2.1，已经贴着 2——割线几乎就是切线）。
状态：h 越大「割线离切线越远」；h→0「平均变化率→f′(1)=2」。

**例题**：「已知 f(x)=x²，求 f′(1)。」答案：Δy/Δx=((1+Δx)²−1)/Δx=2+Δx，当 Δx→0 时趋近 2，故 f′(1)=2，即曲线在 (1,1) 处切线斜率为 2。
**六问**：① 平均变化率与导数的区别；② Δx 能为 0 吗；③ 导数是点还是数；④ 切线斜率为负说明什么；⑤ 导数为 0 时切线什么样；⑥ f′(x₀) 与 f′(x) 有什么不同。
**易错**：✗ 把平均变化率当导数 / ✗ Δx 取 0 直接代 / ✗ 把切线斜率与割线斜率混 / ✗ 导数写成点坐标 / ✗ 忽略「在 x₀ 处」这个前提 / ✗ 认为导数一定存在（尖点不可导）。
