## xx2-c1-s1 数列的概念

**课本原话**
1. 按照确定的顺序排列的一列数叫做数列，数列中的每一个数叫做这个数列的项。
2. 如果数列 {aₙ} 的第 n 项与序号 n 之间的关系可以用一个式子表示，那么这个式子叫做通项公式。
3. 数列 {aₙ} 的前 n 项和 Sₙ=a₁+a₂+…+aₙ；当 n≥2 时 aₙ=Sₙ−Sₙ₋₁。

**三个扣分点**：数列是**有序**的（1,2,3 与 3,2,1 是两个数列）；aₙ=Sₙ−Sₙ₋₁ 只对 **n≥2** 成立（n=1 要单独算 a₁=S₁）；通项公式不唯一但**定义域是正整数集**。

**四张图**：① 数列与序号的一一对应（表格 + 点列图）；② 通项公式 aₙ=2n−1 的点列；③ 递推公式（后一项由前一项算）；④ Sₙ 与 aₙ 的关系（n≥2 的差）。

**互动模型**：滑块＝序号 n（1 到 10，step 1），数列 aₙ=2n−1，前 n 项和 Sₙ=n²
```js
an = 2 * n - 1;
sn = n * n;
gap = n >= 2 ? sn - (n - 1) * (n - 1) : an;   // Sₙ − Sₙ₋₁ = aₙ
```
`cases`：`{v:3,eq:{an:5,sn:9}}`、`{v:5,eq:{an:9,sn:25}}`、`{v:10,eq:{an:19,sn:100}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:5},{t:6.5,v:5},{t:9,v:10},{t:11.5,v:7},{t:13.5,v:1}]`，keys `[1,5,10]`。
**停留帧在 n=5**（a₅=9、S₅=25，且 S₅−S₄=25−16=9=a₅，正好演示 n≥2 那条恒等式）。
状态：n=1「a₁=S₁，不能减 S₀」；n≥2「aₙ=Sₙ−Sₙ₋₁」。

**例题**：「数列 {aₙ} 中 a₁=1，aₙ=aₙ₋₁+2（n≥2），求通项公式与前 5 项和。」答案：这是首项 1、公差 2 的等差数列，aₙ=2n−1；S₅=1+3+5+7+9=25=n²。
**六问**：① 改变顺序还是同一个数列吗；② aₙ=Sₙ−Sₙ₋₁ 对 n=1 成立吗；③ 通项公式唯一吗；④ 数列可以是无限项吗；⑤ 点列图的横坐标是什么；⑥ 递推公式需要给什么才能确定数列。
**易错**：✗ 认为顺序无关 / ✗ n=1 也套 Sₙ−Sₙ₋₁ / ✗ 通项公式的下标从 0 开始 / ✗ 把数列当成集合 / ✗ 点列图画成连线 / ✗ 递推公式不给首项。

## xx2-c1-s2 等差数列

**课本原话**
1. 从第 2 项起，每一项与它的前一项的差等于同一个常数，这个数列叫等差数列，这个常数叫公差 d。
2. 通项公式：aₙ=a₁+(n−1)d。
3. 前 n 项和：Sₙ=n(a₁+aₙ)/2=na₁+n(n−1)d/2。

**三个扣分点**：公差是**后项减前项**（aₙ₊₁−aₙ，反了会得 −d）；aₙ 是 n 的**一次函数**（d=0 时退化）；Sₙ 是 n 的**二次函数且常数项为 0**。

**四张图**：① 公差 d 的几何意义（相邻两项的落差）；② aₙ 与 n 的一次函数图象（点都在一条直线上）；③ 倒序相加求 Sₙ；④ 等差中项 2a₂=a₁+a₃。

**互动模型**：滑块＝序号 n（1 到 12，step 1），a₁=2、d=3
```js
an = 2 + 3 * (n - 1);
sn = n * (2 + an) / 2;
mid = 2 * (2 + 3 * 1) - (2 + 3 * 0) - (2 + 3 * 2);   // 中项检验，恒为 0
```
`cases`：`{v:1,eq:{an:2,sn:2}}`、`{v:5,eq:{an:14,sn:40}}`、`{v:10,eq:{an:29,sn:155}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:5},{t:6.5,v:5},{t:9,v:10},{t:11.5,v:7},{t:13.5,v:1}]`，keys `[1,5,10]`。
**停留帧在 n=5**（a₅=14、S₅=40，且 2a₃=a₂+a₄=8+11，中项恒成立）。
状态：n=1「S₁=a₁」；n>1「Sₙ=n(a₁+aₙ)/2 在累加」。

**例题**：「等差数列中 a₃=7，a₇=15，求 a₁、d 与 S₁₀。」答案：d=(15−7)/(7−3)=2，a₁=7−2×2=3，a₁₀=3+9×2=21，S₁₀=10(3+21)/2=120。
**六问**：① 公差怎么算方向；② d=0 时是什么数列；③ aₙ 是 n 的几次函数；④ Sₙ 的常数项为什么是 0；⑤ 等差中项怎么用；⑥ 已知两个项能唯一确定数列吗。
**易错**：✗ 公差用前项减后项 / ✗ 项数算成 n+1 / ✗ Sₙ 写成 n(a₁+aₙ) / ✗ 把 aₙ 当二次函数 / ✗ d=0 说没有公差 / ✗ 中项写成 a₁+a₃=a₂。

## xx2-c1-s3 等比数列

**课本原话**
1. 从第 2 项起，每一项与它的前一项的比等于同一个常数，这个数列叫等比数列，这个常数叫公比 q（q≠0）。
2. 通项公式：aₙ=a₁qⁿ⁻¹。
3. 前 n 项和：q≠1 时 Sₙ=a₁(1−qⁿ)/(1−q)；q=1 时 Sₙ=na₁。

**三个扣分点**：q=1 时**不能**套求和公式（必须分情况）；q 不能为 0，首项也不能为 0；aₙ=a₁qⁿ⁻¹ 的指数是 **n−1** 不是 n。

**四张图**：① 公比的几何意义（相邻两项的倍数）；② q>1 与 0<q<1 两种走势；③ 错位相减求 Sₙ 的过程；④ q=1 时公式失效（常数列）。

**互动模型**：滑块＝公比 q（0.5 到 2，step 0.1），a₁=1、n=6
```js
a6 = Math.pow(q, 5);
s6 = Math.abs(q - 1) < 1e-9 ? 6 : (1 - Math.pow(q, 6)) / (1 - q);
ok = Math.abs(q - 1) < 1e-9 ? 0 : 1;   // 能否用求和公式
```
`cases`：`{v:1,eq:{a6:1,s6:6,ok:0}}`、`{v:2,eq:{a6:32,s6:63}}`、`{v:0.5,eq:{a6:0.03125,s6:1.96875}}`。
Autopilot：`[{t:0,v:0.5},{t:1.2,v:0.5},{t:4,v:1},{t:6.5,v:1},{t:9,v:2},{t:11.5,v:1.5},{t:13.5,v:0.5}]`，keys `[0.5,1,1.5,2]`。
**停留帧在 q=1**（常数列，Sₙ=na₁=6，求和公式分母为 0 用不了——最容易被扣分的一格）。
状态：q=1「常数列，公式失效，Sₙ=na₁」；q>1「递增」；0<q<1「递减」。

**例题**：「等比数列 a₁=1，q=2，求 a₆ 与 S₆。」答案：a₆=1×2⁵=32；S₆=(1−2⁶)/(1−2)=63。
**六问**：① q 能为 0 吗；② q=1 时怎么求和；③ 指数是 n 还是 n−1；④ 公比怎么算方向；⑤ 等比中项有几个；⑥ 等比数列一定单调吗。
**易错**：✗ q=1 直接套公式 / ✗ 指数写成 n / ✗ 公比用前项除后项 / ✗ 等比中项只取正 / ✗ 认为 q<0 不存在 / ✗ 首项为 0 还叫等比数列。

## xx2-c1-s4 数学归纳法

**课本原话**
1. 证明一个与正整数 n 有关的命题，可按下列步骤进行：(1) 证明当 n=n₀ 时命题成立；(2) 假设 n=k（k≥n₀）时命题成立，证明 n=k+1 时命题也成立。
2. 完成这两步，就可以断定命题对从 n₀ 开始的所有正整数 n 都成立。
3. 这种证明方法叫做数学归纳法。

**三个扣分点**：两步**缺一不可**（只验证不递推、只递推不奠基都不行）；第二步必须**用上**归纳假设（不用就不是归纳法）；从 k 到 k+1 要写清**增加了哪一项**。

**四张图**：① 多米诺骨牌（两块：推倒第一块、每块都能推倒下一块）；② 两步的写法模板；③ 从 n=k 到 n=k+1 左边增加的那一项；④ 少了奠基或少了递推会怎样（两个反例）。

**互动模型**：滑块＝k（1 到 6，step 1），命题 1+3+5+…+(2k−1)=k²
```js
inc = 2 * k + 1;                        // 从 k 到 k+1，左边多出来的项
dl  = inc;                              // 左边增量
dr  = (k + 1) * (k + 1) - k * k;        // 右边增量，也等于 2k+1
same = dl === dr ? 1 : 0;
```
`cases`：`{v:1,eq:{inc:3,same:1}}`、`{v:3,eq:{inc:7,same:1}}`、`{v:6,eq:{inc:13,same:1}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:3},{t:6.5,v:3},{t:9,v:6},{t:11.5,v:4},{t:13.5,v:1}]`，keys `[1,3,6]`。
**停留帧在 k=3**（左边多出 7，右边 (k+1)²−k² 也等于 7，两边增量相等正是递推的关键）。
状态：k=1「奠基成立」；k≥2「用了归纳假设 k，才能走到 k+1」。

**例题**：「用数学归纳法证明 1+3+5+…+(2n−1)=n²。」答案：① n=1 时左边 1、右边 1，成立。② 假设 n=k 时 1+3+…+(2k−1)=k²，则 n=k+1 时左边 =k²+(2k+1)=(k+1)²，等于右边，成立。由①②知对一切正整数 n 成立。
**六问**：① 只验证前几项算证明吗；② 第二步能不用归纳假设吗；③ 奠基必须从 n=1 开始吗；④ k 到 k+1 增加了什么；⑤ 为什么要写「由①②」；⑥ 归纳法与反证法的区别。
**易错**：✗ 只验证不递推 / ✗ 递推时不用假设直接算 / ✗ k 的取值没有范围限制 / ✗ 增加项写错（写成 2k 或 2k+2）/ ✗ 结论不写「对一切正整数」 / ✗ 把 n=k 代入后又把 n=k+1 代回同一个式子。

## xx2-c2-s1 导数的概念及其意义

**课本原话**
1. 函数 y=f(x) 从 x₀ 到 x₀+Δx 的平均变化率是 Δy/Δx=(f(x₀+Δx)−f(x₀))/Δx。
2. 当 Δx 无限趋近于 0 时，平均变化率趋近于一个确定的值，这个值叫做 f(x) 在 x₀ 处的导数，记作 f′(x₀)。
3. 导数的几何意义：曲线 y=f(x) 在点 (x₀,f(x₀)) 处的切线斜率。

**三个扣分点**：导数是一个**极限值**不是「两点斜率」；f′(x₀) 是**切线**斜率不是割线；Δx 可正可负但**不能等于 0**。

**四张图**：① 割线与平均变化率（两点）；② Δx 变小、割线逐渐贴近切线；③ 导数的定义式；④ 导数的几何意义（切线斜率）与物理意义（瞬时速度）。

**互动模型**：滑块＝Δx=h（0.1 到 2，step 0.1），f(x)=x²，x₀=1
```js
avg = ((1 + h) * (1 + h) - 1) / h;      // 平均变化率 = 2 + h
f1  = 2;                                // f′(1) = 2x|x=1
gap = avg - f1;                         // 与导数的差 = h
```
`cases`：`{v:1,eq:{avg:3}}`、`{v:0.5,eq:{avg:2.5}}`、`{v:0.1,eq:{avg:2.1}}`。
Autopilot：`[{t:0,v:2},{t:1.2,v:2},{t:4,v:1},{t:6.5,v:0.5},{t:9,v:0.1},{t:11.5,v:0.1},{t:13.5,v:2}]`，keys `[0.1,0.5,1,2]`。
**停留帧在 h=0.1**（平均变化率 2.1，已经贴着 2——割线几乎就是切线）。
状态：h 越大「割线离切线越远」；h→0「平均变化率→f′(1)=2」。

**例题**：「已知 f(x)=x²，求 f′(1)。」答案：Δy/Δx=((1+Δx)²−1)/Δx=2+Δx，当 Δx→0 时趋近 2，故 f′(1)=2，即曲线在 (1,1) 处切线斜率为 2。
**六问**：① 平均变化率与导数的区别；② Δx 能为 0 吗；③ 导数是点还是数；④ 切线斜率为负说明什么；⑤ 导数为 0 时切线什么样；⑥ f′(x₀) 与 f′(x) 有什么不同。
**易错**：✗ 把平均变化率当导数 / ✗ Δx 取 0 直接代 / ✗ 把切线斜率与割线斜率混 / ✗ 导数写成点坐标 / ✗ 忽略「在 x₀ 处」这个前提 / ✗ 认为导数一定存在（尖点不可导）。

## xx2-c2-s2 导数的运算

**课本原话**
1. 基本初等函数的导数公式：(xⁿ)′=nxⁿ⁻¹，(sinx)′=cosx，(cosx)′=−sinx，(eˣ)′=eˣ，(lnx)′=1/x。
2. 运算法则：[f(x)±g(x)]′=f′(x)±g′(x)，[f(x)g(x)]′=f′(x)g(x)+f(x)g′(x)，[f(x)/g(x)]′=(f′g−fg′)/g²。
3. 复合函数求导：y=f(g(x))，则 y′=f′(g(x))·g′(x)。

**三个扣分点**：(fg)′ 不是 f′g′（要乘出来再求导）；商的求导顺序是**上导下不导减上不导下导**；复合函数**不能漏乘内层导数**。

**四张图**：① 基本导数公式表；② 和差与数乘法则；③ 乘积法则的对照（错误写法 vs 正确）；④ 复合函数求导的「剥洋葱」链条。

**互动模型**：滑块＝x（0.5 到 4，step 0.25），f(x)=x³+2x，f′(x)=3x²+2
```js
d  = 3 * x * x + 2;                    // 导数值 = 切线斜率
b  = (x * x * x + 2 * x) - d * x;      // 切线 y = d·x + b 的截距
```
`cases`：`{v:1,eq:{d:5,b:-2}}`、`{v:2,eq:{d:14,b:-16}}`、`{v:3,eq:{d:29,b:-54}}`。
Autopilot：`[{t:0,v:0.5},{t:1.2,v:0.5},{t:4,v:2},{t:6.5,v:2},{t:9,v:4},{t:11.5,v:3},{t:13.5,v:0.5}]`，keys `[0.5,2,3,4]`。
**停留帧在 x=2**（f′(2)=14，切线 y=14x−16，曲线与切线相切于 (2,12)）。
状态：d>0「曲线在该点上升」；d=0「切线水平」。

**例题**：「求 f(x)=x³+2x 在 x=2 处的切线方程。」答案：f′(x)=3x²+2，f′(2)=14，f(2)=12，切线 y−12=14(x−2)，即 y=14x−16。
**六问**：① (fg)′ 等于 f′g′ 吗；② 商的法则顺序；③ 复合函数为什么要乘内层导数；④ 常数的导数是多少；⑤ 系数能提到括号外吗；⑥ (xⁿ)′ 的指数怎么变。
**易错**：✗ (fg)′=f′g′ / ✗ 商的分子顺序反了 / ✗ 复合函数漏乘内层 / ✗ 忘记常数项导数为 0 / ✗ (xⁿ)' 写成 xⁿ⁻¹ / ✗ 切线方程漏用 f(x₀)。

## xx2-c2-s3 导数在研究函数中的应用

**课本原话**
1. 在某个区间内，如果 f′(x)>0，那么函数 y=f(x) 在这个区间内单调递增；如果 f′(x)<0，单调递减。
2. f′(x₀)=0 且左右两侧导数异号，x₀ 才是极值点。
3. 求极值的步骤：求导数 → 求 f′(x)=0 的根 → 判断两侧符号 → 定极大或极小。

**三个扣分点**：f′(x₀)=0 **不能**直接说是极值点（还要看两侧符号，如 f(x)=x³ 在 x=0）；单调区间要写成**区间**不能写成并集；极值是**局部**最值，最值要看端点和极值一起比。

**四张图**：① 导数正负与单调性；② 极值点的完整条件（f′=0 且变号）；③ f(x)=x³ 在 x=0 处 f′=0 但不是极值；④ 求极值的四步流程。

**互动模型**：滑块＝参数 a（0 到 3，step 0.25），f(x)=x³−3ax，f′(x)=3x²−3a
```js
n   = a > 0 ? 2 : 0;                    // 极值点个数
mx  = a > 0 ? 2 * a * Math.sqrt(a) : 0; // 极大值 f(−√a)
mn  = -mx;                              // 极小值 f(√a)
```
`cases`：`{v:0,eq:{n:0}}`、`{v:1,eq:{n:2,mx:2,mn:-2}}`、`{v:2.25,eq:{n:2,mx:6.75,mn:-6.75}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:1},{t:6.5,v:1},{t:9,v:2.25},{t:11.5,v:1.5},{t:13.5,v:0}]`，keys `[0,1,1.5,2.25]`。
**停留帧在 a=0**（f′(x)=3x²≥0，只在 x=0 处等于 0 但不改变符号，所以没有极值——最容易被扣分的一格）。
状态：a=0「f′=0 但无极值，函数单调递增」；a>0「有两个极值点 ±√a」。

**例题**：「求 f(x)=x³−3x 的单调区间与极值。」答案：f′(x)=3x²−3=3(x−1)(x+1)，令 f′=0 得 x=±1；x<−1 时 f′>0、−1<x<1 时 f′<0、x>1 时 f′>0，故增区间 (−∞,−1) 与 (1,+∞)、减区间 (−1,1)；极大值 f(−1)=2，极小值 f(1)=−2。
**六问**：① f′=0 就是极值点吗；② 单调区间能写并集吗；③ 极值与最值的区别；④ 极大值一定比极小值大吗；⑤ 闭区间最值怎么求；⑥ f′>0 的区间能含端点吗。
**易错**：✗ f′=0 就判极值 / ✗ 单调区间写成并集 / ✗ 极大值大于极小值 / ✗ 忽略定义域 / ✗ 最值只看极值不看端点 / ✗ 极值点写成极值。
