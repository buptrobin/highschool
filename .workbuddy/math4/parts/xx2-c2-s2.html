01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 基本初等函数的导数公式人教A版选择性必修第二册 · 第5章第2节

(xⁿ)′ = nxⁿ⁻¹，(sinx)′ = cosx，(cosx)′ = −sinx，(eˣ)′ = eˣ，(lnx)′ = 1/x。

→ 翻成人话：这是 5 组「查表即得」的公式，前提是①函数已经是基本初等函数 ②自变量就是 x 本身（不是 2x、不是 x²）。条件②一破，就得先用下一段的复合函数法则，不能直接套。

课本原话 · 导数的运算法则人教A版选择性必修第二册 · 第5章第2节

[f(x) ± g(x)]′ = f′(x) ± g′(x)，[f(x)g(x)]′ = f′(x)g(x) + f(x)g′(x)，[f(x)/g(x)]′ = (f′g − fg′)/g²。

→ 翻成人话：三条法则各有三个必须同时成立的条件——①f、g 都在同一点可导 ②分母法则要求 g(x) ≠ 0 ③乘积/商法则不能「逐个求导再相乘」。尤其第三条：(fg)′ ≠ f′g′。

课本原话 · 复合函数的导数人教A版选择性必修第二册 · 第5章第2节

若 y = f(g(x))，则 y′ = f′(g(x))·g′(x)。

→ 翻成人话：两层结构要乘以两层导数：先对外层在「内层的值」处求导，再乘内层自己的导数。少乘 g′(x) 是最常见的残缺答案，只对了一半。

用哪条法则成立的条件条件缺了会怎样
基本公式表被求导的正是 xⁿ、sinx、eˣ、lnx 这种「光秃秃」的形式遇到 sin2x、e³ˣ 直接套表，答案必错，差一个内层导数
和差法则f、g 在 x₀ 处都可导，中间只有 ±把 x³+2x 当成整体硬算，白费时间还容易算错
乘积、商法则f、g 都可导；商还要求 g(x) ≠ 0写成 (fg)′ = f′g′ 或把商的分子顺序写反，整题零分
复合函数法则y = f(u)，u = g(x)，且 g 的值落在 f 的可导区间内漏乘 g′(x)，或里外层认反，导数结构全错

口诀按「先拆结构、再套公式」走：一题先问自己「这是和差、乘积、商、还是复合」，结构认对了，法则自然选对；结构认错，公式背得再熟也没用。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 求曲线在某点处的切线方程必考

已知 f(x) = x³ + 2x，求曲线 y = f(x) 在 x = 2 处的切线方程。（陷阱：切点纵坐标要用 f(2) 算，不能把 (2, 0) 当切点）

  1. 第 1 步 · 审题定位

    切线方程要两个量：切点坐标与切线斜率。切点横坐标已给 x₀ = 2，所以纵坐标要算 f(2)，斜率要算 f′(2)。

    用到：导数的几何意义——f′(x₀) 就是曲线在 (x₀, f(x₀)) 处切线的斜率。

  2. 第 2 步 · 先求导函数

    按和差法则拆成两项，再用数乘法则把系数提到求导号外：f′(x) = (x³)′ + (2x)′ = 3x² + 2·1 = 3x² + 2。

    用到：和差法则、数乘法则、(xⁿ)′ = nxⁿ⁻¹，以及 (2x)′ = 2 而不是 0。

  3. 第 3 步 · 代入求斜率

    把 x = 2 代入导函数：f′(2) = 3·2² + 2 = 12 + 2 = 14，所以切线斜率 k = 14。

    用到：先求导函数、再代点的顺序，不能反过来先代点再求导。

  4. 第 4 步 · 算切点纵坐标

    f(2) = 2³ + 2·2 = 8 + 4 = 12，切点为 (2, 12)，不是 (2, 0)。

    用到：切点在曲线上，纵坐标必须用原函数算。

  5. 第 5 步 · 写点斜式并化简

    y − 12 = 14(x − 2)，展开得 y = 14x − 16。

    用到：点斜式 y − y₀ = k(x − x₀)，最后化成斜截式或一般式。

1 / 5

标准答案（可抄进答题卡）

① 求导：f′(x) = 3x² + 2。
② 斜率：f′(2) = 3×2² + 2 = 14。
③ 切点：f(2) = 2³ + 2×2 = 12，切点为 (2, 12)。
④ 由点斜式：y − 12 = 14(x − 2)，即切线方程为 y = 14x − 16。
⑤ 结论：所求切线方程为 y = 14x − 16。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「(fg)′ 直接把两个导数乘起来不就行了？」

不行，(fg)′ ≠ f′g′，正确是 (fg)′ = f′g + fg′。取 f = x²、g = x³ 验一次：(x⁵)′ = 5x⁴，而 f′g′ = 6x⁵，两者不等。

「商的求导，分子是 fg′ − f′g 还是 f′g − fg′？」

是 f′g − fg′：念「上导下不导，减，上不导下导」，分母再平方。顺序一颠倒，整个分子符号全反，是零分与满分的差别。

「复合函数为什么非得再乘一个内层导数？」

因为内层变化被放大了：内层每变快一倍，外层结果就跟着变快一倍。复合函数不能漏乘内层导数，(sin2x)′ = cos(2x)·2，漏了 2 就只对了一半。

「常数的导数到底是多少？常数的系数呢？」

常数求导是 0（图象是水平线，斜率为 0）；但常数乘函数是系数，按数乘法则提到求导号外面保留：(2x³)′ = 2·3x² = 6x²，不是 0。

「括号里的常数系数，能先提到求导号外面吗？」

能，(c·f)′ = c·f′，但只对乘除常数成立；加减常数要按和差法则处理——那个常数自己的导数是 0，所以 (x³ + 2)′ 正好等于 3x²。

「(xⁿ)′ 的指数到底怎么变？」

两步：原指数搬到系数位，指数减 1，所以 (xⁿ)′ = nxⁿ⁻¹。别写成 xⁿ⁻¹——那样只做了减法、丢了系数。

六问其实是同一件事：先认清「结构」，再选「法则」。(fg)′ ≠ f′g′ 管的是乘积结构，商法则顺序管的是商结构，复合函数漏乘内层导数管的是嵌套结构——结构认对，三条法则都不会串。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ (fg)′ = f′g′

✓ (fg)′ = f′g + fg′，即「前导后不导 + 前不导后导」

错在哪：把乘积当成两个单函数各自求导再相乘，漏了交叉项；用 x²·x³ 一验就露馅（5x⁴ ≠ 6x⁵）。

✗ (f/g)′ = (fg′ − f′g)/g²

✓ (f/g)′ = (f′g − fg′)/g²，顺序是「上导下不导 − 上不导下导」

错在哪：把分子两项的次序写反，等于整体差一个负号，后面所有代入全部错。

✗ (sin2x)′ = cos2x

✓ (sin2x)′ = cos(2x)·2 = 2cos2x

错在哪：复合函数漏乘内层导数 g′(x)，只剥了外层；链条有几层就要乘几个因子。

✗ (2x)′ = 2x，常数项也照抄

✓ (2x)′ = 2，(x³ + 2)′ = 3x²，常数项求导为 0

错在哪：把「常数乘 x」与「x 的某次幂」混为一谈，也忘了纯常数项求导归零。

✗ (xⁿ)′ = xⁿ⁻¹

✓ (xⁿ)′ = nxⁿ⁻¹，原指数要搬到系数位

错在哪：只做了「指数减 1」，漏了把原指数 n 提到前面的系数位。

✗ f(x) = x³ + 2x 在 x = 2 处切线为 y = 14x

✓ y − 12 = 14(x − 2)，即 y = 14x − 16

错在哪：只用了斜率、没把切点纵坐标 f(2) = 12 代进点斜式，截距丢了。

✗ 先把 x = 2 代进去得 12，再对 12 求导得 0

✓ 先求导函数 f′(x) = 3x² + 2，再把 x = 2 代入得 f′(2) = 14

错在哪：先代点就把函数变成了常数，导数自然为 0；求导与代点的顺序不能颠倒。
