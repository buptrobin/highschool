## bx1-c3-s1 细胞膜的结构和功能

**课本原话**
1. 细胞膜的功能：将细胞与外界环境分隔开；控制物质进出细胞；进行细胞间的信息交流。
2. 细胞膜主要由脂质和蛋白质组成，此外还有少量的糖类；磷脂双分子层构成了膜的基本支架。
3. 细胞膜的结构特点是具有一定的流动性，功能特性是选择透过性。

**三个扣分点**：糖蛋白只分布在膜的外侧（可用来判断内外）；「流动性」是结构特点，「选择透过性」是功能特性；磷脂双分子层是支架，蛋白质不是。

**四张图**：① 流动镶嵌模型（磷脂双分子层 + 镶/嵌/贯穿的蛋白质 + 外侧糖链）；② 三大功能（分隔/控制/信息交流）；③ 温度与膜流动性（低温变「僵」、高温结构受损）；④ 结构特点 vs 功能特性对照。

**互动模型**：滑块＝温度 T（0–60℃）
```js
flu = clamp((T - 2) / 38 * 100, 0, 100);                 // 流动性（示意）
func = T <= 40 ? 100 - Math.max(0, 10 - T) * 3
               : Math.max(0, 100 - (T - 40) * 4.5);      // 功能完整性（示意）
```
状态：T<10「低温：膜变「僵」，运输慢」；10–40「正常」；>45「过热：结构受损，选择透过性下降」。
`cases`：`{v:0,eq:{flu:0,func:70}}`、`{v:20,eq:{flu:47.4,func:100}}`、`{v:40,eq:{flu:100,func:100}}`、`{v:55,eq:{flu:100,func:32.5}}`。
Autopilot：`[{t:0,v:20},{t:3,v:37},{t:5.5,v:37},{t:8,v:55},{t:10.5,v:55},{t:13,v:20}]`，keys `[5,20,37,55]`——停留帧在 37℃（流动性够用、结构完好，这是「正常」的那一帧）。

**例题**：「人鼠细胞融合实验中，用荧光染料分别标记人细胞和鼠细胞的膜蛋白，融合后 40 分钟两种荧光均匀分布，说明什么？」答案：说明膜蛋白能运动、细胞膜具有一定的流动性；若低温下融合，均匀分布需要更长时间，说明流动性受温度影响。
**六问**：① 怎么判断哪一侧是膜外侧；② 流动性与选择透过性是不是一回事；③ 磷脂双分子层为什么能形成；④ 温度升高流动性一定更好吗；⑤ 膜蛋白都有哪些功能；⑥ 细胞膜把细胞与外界隔开，为什么还要「控制物质进出」。
**易错**：✗ 糖蛋白在膜内侧 / ✗ 选择透过性是结构特点 / ✗ 蛋白质是膜的基本支架 / ✗ 温度越高膜越好 / ✗ 细胞膜是静止不动的 / ✗ 所有物质都能自由通过细胞膜。
