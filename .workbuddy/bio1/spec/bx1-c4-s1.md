# 本节规格（只读这一节，不要读 SPEC.md 全文）

## bx1-c4-s1 被动运输

**课本原话**
1. 物质以扩散方式进出细胞，不需要消耗细胞内化学反应所释放的能量，这种物质跨膜运输方式称为被动运输。
2. 被动运输分为自由扩散和协助扩散两类；借助膜上转运蛋白进出细胞的物质扩散方式叫作协助扩散。
3. 水分子（或其他溶剂分子）通过半透膜的扩散，称为渗透作用。

**三个扣分点**：协助扩散需要载体但不消耗能量（这是最爱考的一句）；载体数量有限 → 会饱和；水既能自由扩散也能经水通道蛋白协助扩散。

**四张图**：① 自由扩散（直接穿过磷脂双分子层）；② 协助扩散（载体蛋白发生构象变化）；③ 两条速率曲线（自由扩散直线、协助扩散饱和）；④ 影响因素（浓度差、载体数量、温度）。

**互动模型**：滑块＝浓度差 c（0–20 mmol/L）
```js
free = 2 * c;              // 自由扩散速率（示意）
facil = 10 * c / (3 + c);  // 协助扩散速率：Vmax=10, Km=3
```
状态：c<2「低浓度：协助扩散更快（有载体帮忙）」；c=2「两者相等（交叉点）」；c>2「高浓度：自由扩散反超，协助扩散已饱和」。
`cases`：`{v:2,eq:{free:4,facil:4}}`、`{v:6,eq:{free:12,facil:6.67}}`、`{v:18,eq:{free:36,facil:8.57}}`。
Autopilot：`[{t:0,v:1},{t:3,v:2},{t:5.5,v:2},{t:8,v:8},{t:10.5,v:18},{t:13,v:1}]`，keys `[1,2,8,18]`——停留帧在 c=2（两条线交叉，最容易看错的一格）。

**例题**：「葡萄糖进入红细胞和进入小肠上皮细胞，分别属于哪种跨膜运输方式？」答案：进入红细胞是协助扩散（顺浓度梯度、需载体、不耗能）；进入小肠上皮细胞是主动运输（逆浓度梯度、需载体、耗能）。
**六问**：① 协助扩散要不要能量；② 载体饱和意味着什么；③ 自由扩散和协助扩散的共同点；④ 水只靠自由扩散吗；⑤ 温度怎么影响被动运输；⑥ 渗透作用的方向怎么判断。
**易错**：✗ 协助扩散消耗能量 / ✗ 自由扩散需要载体 / ✗ 葡萄糖进细胞都是协助扩散 / ✗ 浓度差越大协助扩散越快（会饱和）/ ✗ 水的运输只有自由扩散 / ✗ 被动运输只能从低浓度到高浓度。
