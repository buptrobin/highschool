## bx1-c3-s3 细胞核的结构和功能

**课本原话**
1. 细胞核控制着细胞的代谢和遗传，是细胞代谢和遗传的控制中心。
2. 细胞核的结构包括核膜、核仁和染色质；染色质主要由 DNA 和蛋白质组成。
3. 核孔是实现核质之间频繁的物质交换和信息交流的通道。

**三个扣分点**：染色质与染色体是同一种物质在不同时期的两种形态（不是两种物质）；核孔有选择性（mRNA、蛋白质能过，DNA 不过）；核仁与核糖体的形成有关，不是 DNA 复制的场所。

**四张图**：① 细胞核结构（核膜双层、核孔、核仁、染色质）；② 核孔的「选择性通道」；③ 染色质 ⇄ 染色体（螺旋化程度不同）；④ 细胞核功能的证据（变形虫去核、核移植）。

**互动模型**：滑块＝螺旋化程度 h（0–100）
```js
len = 100 - 0.72 * h;   // 相对长度（%）
dia = 1 + 0.9 * h;      // 相对直径
```
状态：h<25「间期：细长丝状的染色质」；25–75「螺旋化中（前期）」；≥75「短粗的染色体（中期最典型）」。
`cases`：`{v:0,eq:{len:100,dia:1}}`、`{v:50,eq:{len:64,dia:1.45}}`、`{v:100,eq:{len:28,dia:1.9}}`。
Autopilot：`[{t:0,v:0},{t:3,v:0},{t:5.5,v:50},{t:8,v:100},{t:10.5,v:100},{t:13,v:0}]`，keys `[0,25,60,100]`——停留帧在 100（最粗最短，和「间期细丝」形成强对比）。

**例题**：「为什么说染色质和染色体是同一种物质？」答案：两者都由 DNA 和蛋白质组成，只是螺旋化程度不同：间期为细长的染色质，分裂期高度螺旋化成染色体；化学本质相同、形态不同。
**六问**：① 染色质和染色体是不是两种物质；② 核孔是不是什么都放行；③ 核仁和核糖体的关系；④ 哺乳动物成熟红细胞为什么没有细胞核；⑤ 细胞核控制代谢，那它自己需不需要能量；⑥ 核膜与细胞膜在结构上的共同点。
**易错**：✗ 染色质和染色体是两种物质 / ✗ 核孔无选择性 / ✗ 核仁是 DNA 复制场所 / ✗ 所有细胞都有细胞核 / ✗ 细胞核是细胞的「大脑」所以能独立完成生命活动 / ✗ 核膜是单层膜。
