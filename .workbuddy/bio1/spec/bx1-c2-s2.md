# 本节规格（只读这一节，不要读 SPEC.md 全文）

## bx1-c2-s2 细胞中的无机物

**课本原话**
1. 水在细胞中主要以两种形式存在：自由水和结合水。自由水是细胞内良好的溶剂，结合水是细胞结构的重要组成成分。
2. 自由水与结合水的比值越高，细胞代谢越旺盛；比值越低，细胞抗逆性越强。
3. 细胞中大多数无机盐以离子的形式存在，它们对维持细胞和生物体的生命活动有重要作用。

**三个扣分点**：结合水不是「没用的水」，它是结构的一部分；抗逆（抗旱抗寒）对应的是结合水比例高；无机盐不提供能量。

**四张图**：① 自由水 vs 结合水（一个能流动当溶剂，一个被「绑」在结构上）；② 两条反向曲线（自由水比例↑ → 代谢↑、抗逆↓）；③ 无机盐的三种作用（构成化合物 / 维持生命活动 / 维持渗透压和酸碱平衡）；④ 实例表（缺 Mg 叶发黄、缺 Ca 抽搐、缺 Fe 贫血、缺 I 甲状腺肿）。

**互动模型**：滑块＝结合水占比 b（0–40%，占细胞总水的百分比）
```js
met = 100 * (1 - b / 40);   // 代谢强度（示意）
res = 100 * (b / 40);       // 抗逆性（示意）
ratio = (100 - b) / b;      // 自由水 : 结合水
```
状态：b<10「代谢旺盛（如正在萌发的种子）」；10–30「正常」；≥30「抗逆型（越冬植物、休眠种子）」。
`cases`：`{v:0,eq:{met:100,res:0}}`、`{v:20,eq:{met:50,res:50,ratio:4}}`、`{v:40,eq:{met:0,res:100,ratio:1.5}}`。
Autopilot：`[{t:0,v:10},{t:3,v:35},{t:6,v:35},{t:8.5,v:5},{t:11,v:35}]`，keys `[5,20,35]`——停留帧在 35%（越冬植物：水少反而能活，这是最反直觉的一格）。

**例题**：简答「冬天来临前，冬小麦细胞内自由水与结合水的比值会怎样变化？有什么意义？」答案：比值降低（结合水比例升高），代谢减弱、抗寒能力增强。
**六问**：① 自由水多了代谢快还是慢；② 抗旱与结合水的关系；③ 无机盐为什么不能提供能量；④ 缺 Mg 为什么叶片发黄；⑤ 输液为什么用 0.9% 生理盐水；⑥ 「水是生命之源」在细胞层面怎么解释。
**易错**：✗ 结合水是废物 / ✗ 抗逆性与自由水比例正相关 / ✗ 无机盐是能源物质 / ✗ 自由水只当溶剂没有别的功能 / ✗ 干旱时细胞结合水比例下降 / ✗ 无机盐都以化合物形式存在。
