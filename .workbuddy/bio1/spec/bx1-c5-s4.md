## bx1-c5-s4 光合作用与能量转化

**课本原话**
1. 光合作用是指绿色植物通过叶绿体，利用光能，把二氧化碳和水转化成储存着能量的有机物，并且释放出氧气的过程。
2. 光反应在类囊体薄膜上进行，水的光解产生 O₂ 和 NADPH，同时生成 ATP；暗反应在叶绿体基质中进行，CO₂ 被固定形成 C₃，C₃ 被还原。
3. 光合作用释放的 O₂ 中的氧全部来自水。

**三个扣分点**：O₂ 来自水、不来自 CO₂；光反应给暗反应提供 ATP 和 NADPH；净光合 = 总光合 − 呼吸。

**四张图**：① 叶绿体结构与两阶段位置；② 光反应与暗反应的物质联系（ATP/NADPH/C₃）；③ 光照强度—净光合速率曲线（补偿点、饱和点）；④ CO₂ 浓度与温度的影响。

**互动模型**：滑块＝光照强度 I（0–200，相对值）
```js
gross = 20 * I / (I + 30);   // 总光合速率（示意）
net = gross - 4;             // 净光合 = 总光合 − 呼吸（呼吸按 4 计）
```
状态：I<7.5「净光合为负：消耗有机物」；I=7.5「光补偿点」；7.5<I<120「净光合随光强上升」；≥120「接近光饱和点」。
`cases`：`{v:0,eq:{gross:0,net:-4}}`、`{v:7.5,eq:{gross:4,net:0}}`、`{v:30,eq:{gross:10,net:6}}`、`{v:120,eq:{gross:16,net:12}}`、`{v:200,eq:{gross:17.39,net:13.39}}`。
Autopilot：`[{t:0,v:0},{t:3,v:0},{t:6,v:7.5},{t:9,v:7.5},{t:11.5,v:60},{t:14,v:200},{t:16,v:0}]`，keys `[0,7.5,30,120]`——停留帧在 7.5（补偿点：光合恰好抵消呼吸，净光合为 0）。

**例题**：「将某植物置于光照强度为光补偿点的条件下，一段时间后植物能否正常生长？为什么？」答案：不能长期正常生长。此时光合速率等于呼吸速率，净光合为 0，没有有机物积累；要正常生长必须大于光补偿点。
**六问**：① 释放的 O₂ 来自水还是 CO₂；② 光反应为暗反应提供什么；③ 光补偿点和光饱和点的含义；④ 突然停止光照 C₃ 和 C₅ 怎么变；⑤ 为什么净光合要用「总光合 − 呼吸」；⑥ 阴生植物与阳生植物的曲线差别。
**易错**：✗ O₂ 来自 CO₂ / ✗ 暗反应在类囊体薄膜上进行 / ✗ 净光合可直接用总光合比较 / ✗ 光补偿点就是不再光合 / ✗ 光反应不需要酶 / ✗ 停止光照后 C₃ 立刻减少（实际先增多）。
