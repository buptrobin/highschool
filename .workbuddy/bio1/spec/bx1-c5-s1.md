## bx1-c5-s1 降低化学反应活化能的酶

**课本原话**
1. 酶是活细胞产生的具有催化作用的有机物，其中绝大多数酶是蛋白质。
2. 酶能降低化学反应的活化能；与无机催化剂相比，酶降低活化能的作用更显著，催化效率更高。
3. 过酸、过碱或温度过高，会使酶的空间结构遭到破坏，使酶永久失活；低温时酶活性很低，但酶的空间结构稳定。

**三个扣分点**：低温「抑制」不变性（升温可恢复），高温/过酸碱「变性」不可逆；酶只加快反应速率，不改变平衡点；大多数酶是蛋白质，少数是 RNA。

**四张图**：① 活化能与能垒（无催化剂 / 无机催化剂 / 酶）；② 温度—活性曲线（最适温度、低温段与高温段的本质不同）；③ pH—活性曲线（胃蛋白酶、唾液淀粉酶最适 pH 不同）；④ 高效性与专一性实验设计。

**互动模型**：滑块＝温度 T（0–60℃）
```js
function calc(T) {
  var act = T <= 37 ? 100 * Math.pow(T / 37, 1.8)
                    : 100 * Math.exp(-Math.pow((T - 37) / 8, 1.6));
  return { act: act };
}
```
状态：T<10「低温抑制：结构没坏，升温可恢复」；35–39「最适温度」；40–48「活性下降，开始变性」；>50「变性失活，不可逆」。
`cases`：`{v:0,eq:{act:0}}`、`{v:20,eq:{act:33.0}}`、`{v:37,eq:{act:100}}`、`{v:45,eq:{act:36.8}}`、`{v:50,eq:{act:11.4}}`、`{v:60,eq:{act:0.4}}`。
Autopilot：`[{t:0,v:5},{t:3,v:5},{t:5.5,v:37},{t:8.5,v:37},{t:11,v:55},{t:13,v:5}]`，keys `[5,25,37,55]`——停留帧在 37℃（最适），过后立刻掉下去，正好演「高温不可逆」。

**例题**：「将唾液淀粉酶分别放在 0℃ 和 100℃ 下处理 10 分钟，再恢复到 37℃，两者的催化能力如何？」答案：0℃ 处理的恢复活性（低温只抑制，结构未破坏）；100℃ 处理的不能恢复（高温使空间结构破坏，永久失活）。
**六问**：① 低温为什么杀不死酶；② 酶能不能改变反应平衡点；③ 酶为什么有专一性；④ 酶与无机催化剂的共同点；⑤ 过酸过碱为什么使酶失活；⑥ 酶一定要在细胞内起作用吗。
**易错**：✗ 低温使酶变性失活 / ✗ 酶提供能量 / ✗ 酶能改变平衡点 / ✗ 酶都是蛋白质 / ✗ 高温失活后降温可恢复 / ✗ 酶只在细胞内起作用。
