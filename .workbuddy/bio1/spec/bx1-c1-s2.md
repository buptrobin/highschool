## bx1-c1-s2 细胞的多样性和统一性

**课本原话（A 区照抄）**
1. 原核细胞与真核细胞的主要区别：细胞内有无以核膜为界限的细胞核。
2. 蓝细菌细胞内含有藻蓝素和叶绿素，是能进行光合作用的自养生物。
3. 细胞的统一性：细胞都具有细胞膜、细胞质和核糖体，都以 DNA 作为遗传物质。

**三个扣分点**：放大倍数是「长度/宽度」的放大，不是面积；蓝细菌是原核但能光合（没有叶绿体）；原核生物不都有细胞壁（支原体没有）——这条只作提示，别当必考。

**四张图**：① 原核 vs 真核结构对比（有无核膜）；② 显微镜放大倍数与视野（同一块视野里细胞变少变大）；③ 蓝细菌与植物细胞都能光合，但一个有叶绿体一个没有；④ 统一性三件套（膜/质/核糖体 + DNA）。

**互动模型**：滑块＝放大倍数 n（100–1000，step 50）
```js
视野直径 d = 200000 / n;            // μm，100× → 2000
一行细胞数 = Math.floor(d / 10);     // 设细胞直径 10 μm
相对亮度 = Math.pow(100 / n, 2) * 100; // 100× → 100%
```
状态：n<200「低倍镜：视野大、细胞多、亮」；200–600「中倍」；>600「高倍镜：视野小、细胞少、暗」。
`cases`：`{v:100,eq:{d:2000,cells:200,bright:100}}`、`{v:400,eq:{d:500,cells:50,bright:6.25}}`、`{v:1000,eq:{d:200,cells:20,bright:1}}`。
Autopilot：`[{t:0,v:100},{t:3,v:100},{t:5.5,v:400},{t:9,v:400},{t:11.5,v:1000},{t:14,v:100}]`，keys `[100,400,1000]`——停留帧在 400×（能同时看清细胞数目和亮度变化）。

**例题**：显微镜操作题——「由低倍镜换高倍镜后，视野亮度、细胞数目、物像大小怎么变？为什么？」答案要点：变暗（进光量少）、细胞数目变少、物像变大；只调细准焦螺旋、不提升镜筒。
**六问**：① 原核与真核「本质区别」写哪句；② 蓝细菌能光合，所以它是真核？③ 细菌有没有线粒体；④ 放大 400 倍是不是面积放大 400 倍；⑤ 换高倍镜后视野变暗的原因；⑥ 为什么说细胞有统一性（举三个证据）。
**易错**：✗ 原核生物没有细胞器（有核糖体）/ ✗ 蓝细菌是植物（是原核）/ ✗ 放大倍数=面积倍数 / ✗ 高倍镜下先升镜筒再换物镜 / ✗ 原核细胞没有 DNA / ✗ 真核细胞都有细胞壁。
