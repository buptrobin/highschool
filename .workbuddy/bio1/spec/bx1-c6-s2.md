## bx1-c6-s2 细胞的分化

**课本原话**
1. 细胞分化是指在个体发育中，由一个或一种细胞增殖产生的后代，在形态、结构和生理功能上发生稳定性差异的过程。
2. 细胞分化是基因选择性表达的结果；细胞分化具有普遍性、持久性和稳定性。
3. 细胞的全能性是指已经分化的细胞，仍然具有发育成完整个体的潜能。

**三个扣分点**：分化不改变遗传物质（同一个体不同细胞的基因相同）；全能性大小：受精卵 > 生殖细胞 > 体细胞，植物 > 动物；分化程度越高，全能性越低。

**四张图**：① 一个受精卵 → 多种细胞（分化树）；② 基因选择性表达（同一套基因、不同的「开关」）；③ 分化程度与全能性的反向关系；④ 植物组织培养（脱分化 → 再分化）。

**互动模型**：滑块＝分化程度 d（0–100）
```js
pot = 100 - 0.85 * d;    // 全能性（示意）
expr = 90 - 0.7 * d;     // 表达的基因比例（示意，%）
```
状态：d<20「受精卵级：全能性最高」；20–70「干细胞：多向分化」；>70「高度分化：如神经细胞、肌肉细胞」。
`cases`：`{v:0,eq:{pot:100,expr:90}}`、`{v:50,eq:{pot:57.5,expr:55}}`、`{v:100,eq:{pot:15,expr:20}}`。
Autopilot：`[{t:0,v:0},{t:3,v:0},{t:5.5,v:50},{t:8,v:100},{t:10.5,v:100},{t:13,v:0}]`，keys `[0,30,60,100]`。

**例题**：「同一个人的神经细胞和肌肉细胞，形态功能差别很大，它们的遗传物质相同吗？为什么？」答案：相同（除非发生突变）。因为它们由同一个受精卵经有丝分裂产生，遗传物质相同；差异来自基因的选择性表达。
**六问**：① 分化后遗传物质变了吗；② 全能性大小怎么排；③ 为什么植物细胞比动物细胞容易表现全能性；④ 干细胞是什么；⑤ 分化一定是不可逆的吗；⑥ 细胞分化与细胞分裂的关系。
**易错**：✗ 分化后基因发生了改变 / ✗ 全能性最高的是体细胞 / ✗ 动物细胞没有全能性 / ✗ 分化程度越高全能性越强 / ✗ 脱分化就是分化 / ✗ 所有细胞都能表现全能性。
