## bx1-c4-s2 主动运输与胞吞、胞吐

**课本原话**
1. 物质逆浓度梯度进行跨膜运输，需要载体蛋白的协助，同时还需要消耗细胞内化学反应所释放的能量，这种方式叫作主动运输。
2. 主动运输保证了活细胞能够按照生命活动的需要，主动选择吸收所需要的营养物质，排出代谢废物和对细胞有害的物质。
3. 大分子物质进出细胞的方式是胞吞和胞吐，它们依赖于细胞膜的流动性，需要消耗能量。

**三个扣分点**：主动运输是「逆」浓度梯度；胞吞胞吐不是跨膜运输（物质不穿过膜，靠膜包裹）；三种方式里只有自由扩散、协助扩散不耗能。

**四张图**：① 主动运输（载体 + ATP，逆梯度）；② 胞吞与胞吐（膜凹陷/融合）；③ 三种方式对照表（方向/载体/能量/实例）；④ ATP 供应与运输速率。

**互动模型**：滑块＝ATP 供应 p（0–100%）
```js
rate = 8 * p / 100;        // 主动运输速率（示意，最大 8）
ratio = 1 + 2 * p / 100;   // 细胞内/细胞外浓度比
```
状态：p=0「没有 ATP：只能被动运输，细胞内外浓度趋于相等」；0<p<100「部分维持浓度差」；p=100「稳定逆浓度梯度，主动选择吸收」。
`cases`：`{v:0,eq:{rate:0,ratio:1}}`、`{v:50,eq:{rate:4,ratio:2}}`、`{v:100,eq:{rate:8,ratio:3}}`。
Autopilot：`[{t:0,v:0},{t:3,v:0},{t:5.5,v:50},{t:8,v:100},{t:10.5,v:100},{t:13,v:0}]`，keys `[0,50,100]`。

**例题**：「某植物根细胞吸收 K⁺ 的量随氧气浓度升高而增加，超过一定氧浓度后不再增加，原因是什么？」答案：K⁺ 吸收是主动运输，需要 ATP；氧气浓度升高 → 有氧呼吸增强 → ATP 增多 → 吸收加快；载体蛋白数量有限，达到饱和后不再增加。
**六问**：① 主动运输和协助扩散只差一个「能量」吗；② 胞吞胞吐体现膜的什么特点；③ 为什么大分子只能靠胞吞胞吐；④ 缺氧为什么影响主动运输；⑤ 主动运输对细胞有什么意义；⑥ 胞吞胞吐需不需要载体。
**易错**：✗ 主动运输顺浓度梯度 / ✗ 胞吞胞吐也是跨膜运输 / ✗ 胞吞胞吐不需要能量 / ✗ 抑制呼吸不影响主动运输 / ✗ 大分子通过载体进入细胞 / ✗ 主动运输只吸收营养物质。
