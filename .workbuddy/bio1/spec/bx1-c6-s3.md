## bx1-c6-s3 细胞的衰老和死亡

**课本原话**
1. 细胞衰老的特征：细胞内水分减少，细胞萎缩，体积变小；多种酶的活性降低；色素逐渐积累；呼吸速率减慢，细胞核体积增大，染色质收缩，染色加深；细胞膜通透性改变，使物质运输功能降低。
2. 细胞凋亡是由基因所决定的细胞自动结束生命的过程。
3. 细胞坏死是在种种不利因素影响下，由于细胞正常代谢活动受损或中断引起的细胞损伤和死亡。

**三个扣分点**：衰老细胞的细胞核体积「增大」（不是变小）；凋亡是程序性的、对个体有利，坏死是病理性的、有害；多细胞生物个体的衰老 ≠ 细胞的衰老，但二者有关。

**四张图**：① 衰老细胞的五个特征；② 凋亡 vs 坏死对照；③ 个体衰老与细胞衰老的关系；④ 细胞生命历程全景（增殖→分化→衰老→凋亡）。

**互动模型**：滑块＝衰老程度 a（0–100，示意）
```js
water   = 100 - 0.45 * a;   // 细胞内水分（相对）
enzyme  = 100 - 0.60 * a;   // 酶活性（相对）
pigment = 0.8 * a;          // 色素积累（相对）
nucleus = 100 + 0.50 * a;   // 细胞核体积（相对）
```
状态：a<20「年轻细胞」；20–60「衰老早期」；>60「明显衰老」；=100「濒临凋亡」。
`cases`：`{v:0,eq:{water:100,enzyme:100,pigment:0,nucleus:100}}`、`{v:50,eq:{water:77.5,enzyme:70,pigment:40,nucleus:125}}`、`{v:100,eq:{water:55,enzyme:40,pigment:80,nucleus:150}}`。
Autopilot：`[{t:0,v:0},{t:3,v:0},{t:5.5,v:50},{t:8,v:100},{t:10.5,v:100},{t:13,v:0}]`，keys `[0,20,60,100]`——停留帧在 100（核体积反而最大，和「细胞萎缩」形成反差）。

**例题**：「老年人皮肤上出现老年斑，从细胞衰老角度解释原因。」答案：衰老细胞内色素（脂褐素）逐渐积累，随年龄增长积累增多并沉积在皮肤细胞中，形成老年斑。
**六问**：① 衰老细胞核体积变大还是变小；② 凋亡和坏死怎么区分；③ 细胞凋亡对个体有害吗；④ 多细胞生物衰老与细胞衰老是一回事吗；⑤ 为什么老年人伤口愈合慢；⑥ 被病原体感染的细胞被清除属于凋亡还是坏死。
**易错**：✗ 衰老细胞核体积变小 / ✗ 凋亡就是细胞坏死 / ✗ 凋亡对机体有害 / ✗ 个体衰老等于所有细胞都衰老 / ✗ 细胞衰老后水分增多 / ✗ 细胞死亡都是病理性的。
