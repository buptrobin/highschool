## bx1-c5-s2 细胞的能量「货币」ATP

**课本原话**
1. ATP 是细胞内的一种高能磷酸化合物，其结构简式为 A—P~P~P，其中 A 代表腺苷，P 代表磷酸基团。
2. ATP 与 ADP 可以相互转化：ATP ⇌ ADP + Pi + 能量。
3. ATP 是细胞生命活动的直接能源物质。

**三个扣分点**：ATP 不是「能量仓库」，细胞内含量很少但周转极快；ATP 与 ADP 的相互转化不是可逆反应（酶不同、能量来源不同、场所不同）；「~」不是普通化学键。

**四张图**：① ATP 结构 A—P~P~P（标出远离 A 的高能磷酸键）；② ATP ⇄ ADP 循环（放能/吸能两侧）；③ 存量恒定 vs 周转速率（两条线，一条平一条升）；④ 糖类脂肪 → ATP → 各项生命活动。

**互动模型**：滑块＝耗能强度 e（0–100%）
```js
turn = e;                    // ATP 周转速率（相对）
stock = 100;                 // 细胞内 ATP 存量（示意：基本不变）
ratio = 0.2 + 0.008 * e;     // ADP/ATP 比值
```
状态：e<20「安静状态：周转慢」；20–60「中等活动」；>60「剧烈运动：周转极快，但 ATP 总量几乎不变」。
`cases`：`{v:0,eq:{turn:0,stock:100,ratio:0.2}}`、`{v:50,eq:{turn:50,stock:100,ratio:0.6}}`、`{v:100,eq:{turn:100,stock:100,ratio:1.0}}`。
Autopilot：`[{t:0,v:10},{t:3,v:10},{t:5.5,v:100},{t:8.5,v:100},{t:11,v:10}]`，keys `[10,50,100]`——停留帧在 100（周转拉满而存量纹丝不动，这是全篇最反直觉的一格）。

**例题**：「剧烈运动时，肌细胞内 ATP 的含量会大幅增加吗？为什么？」答案：不会。ATP 在细胞内含量很少，但 ATP 与 ADP 转化极快，消耗多少就再生多少；剧烈运动时增加的是转化速率，不是总量。
**六问**：① ATP 为什么叫「直接」能源物质；② ATP 与 ADP 的转化是可逆反应吗；③ ATP 里的「~」是什么键；④ 细胞为什么不能大量储存 ATP；⑤ 光反应产生的 ATP 用在哪；⑥ 剧烈运动时 ATP 从哪来。
**易错**：✗ ATP 是可大量储存的能源物质 / ✗ ATP⇄ADP 是可逆反应 / ✗ ATP 由三个高能磷酸键组成（是两个）/ ✗ ATP 是主要能源物质（是直接能源物质，主要能源是糖类）/ ✗ 剧烈运动后 ATP 含量大增 / ✗ A 代表腺嘌呤。
