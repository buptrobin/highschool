## bx1-c3-s2 细胞器之间的分工合作

**课本原话**
1. 线粒体是细胞进行有氧呼吸的主要场所，是细胞的「动力车间」。
2. 核糖体是「生产蛋白质的机器」；内质网是蛋白质等大分子物质的合成、加工场所和运输通道。
3. 分泌蛋白的合成与运输：核糖体 → 内质网 → 高尔基体 → 细胞膜；细胞膜、核膜以及细胞器膜共同构成生物膜系统。

**三个扣分点**：分泌蛋白路径里没有线粒体（线粒体只供能，不算经过）；核糖体没有膜；高尔基体在植物细胞里与细胞壁形成有关。

**四张图**：① 八种细胞器一览（有无膜、功能、分布）；② 分泌蛋白路径箭头（旁边标线粒体供能）；③ 生物膜系统（膜之间的转换）；④ 同位素标记的时间—放射性曲线（静态示意）。

**互动模型**：滑块＝时间 t（0–45 min），同位素标记后各结构的放射性强度按高斯峰依次出现
```js
function calc(t) {
  var pk = [3, 11, 20, 30, 40];           // 核糖体/内质网/高尔基体/细胞膜/细胞外
  var I = pk.map(function (p) { return 100 * Math.exp(-Math.pow(t - p, 2) / 32); });
  var main = I.indexOf(Math.max.apply(null, I));
  return { i0: I[0], i1: I[1], i2: I[2], i3: I[3], i4: I[4], main: main };
}
```
状态：t<5「正在合成」；5–15「内质网加工」；15–25「高尔基体分类包装」；>25「运到细胞膜并分泌」。
`cases`：`{v:3,eq:{main:0}}`、`{v:11,eq:{main:1}}`、`{v:20,eq:{main:2}}`、`{v:33,eq:{main:3}}`、`{v:40,eq:{main:4}}`。
Autopilot：`[{t:0,v:0},{t:3,v:3},{t:5.5,v:3},{t:8,v:11},{t:11,v:20},{t:14,v:40}]`，keys `[0,3,11,20,40]`。

**例题**：「用 ³H 标记亮氨酸培养胰腺腺泡细胞，3 min 时放射性主要出现在核糖体，20 min 时主要出现在高尔基体。这说明什么？写出分泌蛋白的运输路径。」答案：说明蛋白质在核糖体合成后依次经过内质网、高尔基体；路径：核糖体→内质网→高尔基体→细胞膜→细胞外（线粒体供能，不经过）。
**六问**：① 线粒体算不算分泌蛋白路径；② 核糖体为什么没有膜；③ 植物细胞的高尔基体做什么；④ 溶酶体的功能；⑤ 中心体在什么细胞里有；⑥ 生物膜系统包括哪三层膜。
**易错**：✗ 分泌蛋白经过线粒体 / ✗ 核糖体有膜 / ✗ 高尔基体只和动物细胞有关 / ✗ 所有细胞器都有膜 / ✗ 叶绿体只存在于植物所有细胞 / ✗ 内质网只加工蛋白质。
