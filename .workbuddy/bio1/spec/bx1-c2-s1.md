## bx1-c2-s1 细胞中的元素和化合物

**课本原话**
1. 组成细胞的化学元素，常见的有 20 多种。
2. 细胞中含量最多的化合物是水；含量最多的有机化合物是蛋白质。
3. C 是构成细胞的最基本元素（生物大分子以碳链为骨架）。

**三个扣分点**：鲜重第一是 O、干重第一是 C（同一块材料两个答案）；「最基本元素」是 C，但「含量最多」不是 C；斐林试剂要水浴加热，双缩脲试剂不需要。

**四张图**：① 大量元素/微量元素分组（C H O N P S K Ca Mg + Fe Mn Zn Cu B Mo）；② 鲜重与干重的元素含量条（O 与 C 换位）；③ 化合物含量占比条（水 85–90、蛋白质 7–10、脂质 1–2、糖类和核酸 1–1.5）；④ 三个检测实验对照（斐林→砖红、苏丹Ⅲ→橘黄、双缩脲→紫）。

**互动模型**：滑块＝含水量 w（0–100%，100 = 鲜重、0 = 完全烘干）
```js
O = 65 * w/100 + 23.7 * (1 - w/100);   // 鲜重 O65%、干重 O23.7%
C = 18 * w/100 + 48.4 * (1 - w/100);   // 鲜重 C18%、干重 C48.4%
```
状态：w>50「鲜重：O 第一」；10–50「过渡：C 追上来」；w<10「干重：C 第一」。交叉点 w≈34%。
`cases`：`{v:100,eq:{o:65,c:18}}`、`{v:0,eq:{o:23.7,c:48.4}}`、`{v:34,eq:{o:37.7,c:38.1}}`。
Autopilot：`[{t:0,v:100},{t:3,v:100},{t:5.5,v:34},{t:8.5,v:34},{t:11,v:0},{t:13,v:100}]`，keys `[100,34,0]`——停留帧在 34%（两条线交叉，「谁第一」在这里换人）。

**例题**：「人体细胞干重中含量最多的元素是____，含量最多的化合物是____」+ 追问「为什么鲜重和干重答案不同」。答案：C；蛋白质；鲜重里水占 85–90%，水的 O 把 O 顶上第一，烘干后水没了，C 才第一。
**六问**：① 最基本元素与含量最多元素分别是谁；② 为什么干重没有水；③ 微量元素是不是不重要；④ 检测还原糖为什么必须水浴加热；⑤ 蛋白质检测为什么先加 A 液再加 B 液；⑥ 组成细胞的元素在无机自然界都能找到，说明什么。
**易错**：✗ 含量最多的元素是 C / ✗ 最基本元素是 O / ✗ 微量元素含量少所以不重要 / ✗ 斐林试剂直接加不用加热 / ✗ 双缩脲试剂要水浴 / ✗ 细胞中含量最多的有机物是水。
