## bx1-c5-s3 细胞呼吸的原理和应用

**课本原话**
1. 有氧呼吸的总反应式：C₆H₁₂O₆ + 6O₂ + 6H₂O →(酶) 6CO₂ + 12H₂O + 能量。
2. 有氧呼吸的第一阶段在细胞质基质中进行，第二阶段在线粒体基质中进行，第三阶段在线粒体内膜上进行。
3. 无氧呼吸在细胞质基质中进行，产物是酒精和 CO₂，或者乳酸；无氧呼吸只在第一阶段释放少量能量。

**三个扣分点**：第一阶段在细胞质基质，不在线粒体；无氧呼吸第二阶段不产生 ATP；有氧呼吸生成的水中的氧来自 O₂，CO₂ 中的氧来自葡萄糖和水。

**四张图**：① 有氧呼吸三阶段（位置/反应物/产物/ATP 量）；② 有氧 vs 无氧的能量对比；③ O₂ 浓度与呼吸方式（无氧受抑制、有氧上升）；④ 应用（中耕松土、包扎伤口、酿酒、慢跑）。

**互动模型**：滑块＝O₂ 浓度 o（0–21%）
```js
aer = 100 * o / (2 + o);        // 有氧呼吸 CO₂ 释放（相对，饱和型）
ana = 80 * Math.exp(-o / 4);    // 无氧呼吸 CO₂/酒精（受 O₂ 抑制）
total = aer + ana;
```
状态：o<1「无氧呼吸为主（酒精 + CO₂）」；1–5「两者并存」；>10「有氧呼吸为主，无氧几乎停止」。
`cases`：`{v:0,eq:{aer:0,ana:80}}`、`{v:5,eq:{aer:71.4,ana:22.9}}`、`{v:21,eq:{aer:91.3,ana:0.4}}`。
Autopilot：`[{t:0,v:0},{t:3,v:0},{t:5.5,v:5},{t:8,v:21},{t:10.5,v:21},{t:13,v:0}]`，keys `[0,3,10,21]`——停留帧在 o=0（纯无氧，酒精产量最高）。

**例题**：「储存粮食时要先晒干并保持低温、低氧，从细胞呼吸角度分析原因。」答案：晒干降低自由水含量，呼吸速率下降；低温降低酶活性；低氧抑制有氧呼吸且不至于缺氧进行无氧呼吸（产生酒精）。三点都是为了减少有机物消耗。
**六问**：① 有氧呼吸第一阶段的场所；② 无氧呼吸为什么产生乳酸或酒精；③ 为什么水淹后根会烂；④ 有氧呼吸生成的水中的氧从哪来；⑤ 无氧呼吸释放的能量去哪了；⑥ 为什么慢跑比剧烈冲刺「省 ATP」。
**易错**：✗ 有氧呼吸三个阶段都在线粒体 / ✗ 无氧呼吸第二阶段产生大量 ATP / ✗ 无氧呼吸不产生 CO₂（产乳酸时不产 CO₂）/ ✗ 有氧呼吸的水中氧来自葡萄糖 / ✗ 呼吸作用只在白天进行 / ✗ 低温让酶变性从而抑制呼吸。
