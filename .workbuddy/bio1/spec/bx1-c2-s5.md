## bx1-c2-s5 核酸是遗传信息的携带者

**课本原话**
1. 核酸包括脱氧核糖核酸（DNA）和核糖核酸（RNA）两大类。
2. 核苷酸是核酸的基本组成单位，一分子核苷酸由一分子磷酸、一分子五碳糖和一分子含氮碱基组成。
3. 核酸是细胞内携带遗传信息的物质，在生物体的遗传、变异和蛋白质的生物合成中具有极其重要的作用。

**三个扣分点**：DNA 特有 T、RNA 特有 U；A=T、G=C 只适用于双链 DNA；原核细胞既有 DNA 也有 RNA（DNA 是遗传物质）。

**四张图**：① 核苷酸的三层结构（磷酸—五碳糖—碱基）；② DNA 双链（反向平行、碱基互补）vs RNA 单链；③ DNA 与 RNA 对照表（五碳糖/碱基/链数/分布）；④ 核酸的功能链（DNA → RNA → 蛋白质）。

**互动模型**：滑块＝双链 DNA 中 A 占全部碱基的比例 a（10–40%）
```js
T = a; G = 50 - a; C = 50 - a; GC = 100 - 2 * a;
```
状态：a<15「AT 丰富（GC 含量低）」；15–35「GC 中等」；>35「GC 丰富」。
`cases`：`{v:10,eq:{T:10,G:40,C:40,gc:80}}`、`{v:20,eq:{T:20,G:30,C:30,gc:60}}`、`{v:30,eq:{T:30,G:20,C:20,gc:40}}`。
Autopilot：`[{t:0,v:10},{t:3,v:10},{t:5.5,v:20},{t:8,v:30},{t:10.5,v:30},{t:13,v:10}]`，keys `[10,20,30]`。

**例题**：「某双链 DNA 分子中，A 占全部碱基的 20%，则 G 占____，该 DNA 的 GC 含量为____；若其中一条链上 A 占该链的 30%，能否确定另一条链上 A 的比例？」答案：30%、60%；不能单凭一条链定另一条链的 A（双链总量才能定）。
**六问**：① DNA 与 RNA 的碱基差异；② 为什么 A=T、G=C 只能用于双链 DNA；③ 原核生物的遗传物质是什么；④ 核苷酸有几种（DNA 4 种 + RNA 4 种 = 8 种）；⑤ 病毒只有一种核酸吗；⑥ 核酸为什么能携带遗传信息（碱基排列顺序）。
**易错**：✗ DNA 和 RNA 的碱基完全相同 / ✗ A=T 适用于所有核酸 / ✗ 原核生物只有 RNA / ✗ 核苷酸有 5 种 / ✗ 核酸的基本单位是氨基酸 / ✗ 遗传信息储存在五碳糖里。
