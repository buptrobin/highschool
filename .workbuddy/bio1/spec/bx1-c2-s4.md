## bx1-c2-s4 蛋白质是生命活动的主要承担者

**课本原话**
1. 氨基酸是组成蛋白质的基本单位；每种氨基酸分子至少都含有一个氨基和一个羧基，并且都有一个氨基和一个羧基连接在同一个碳原子上。
2. 氨基酸分子之间通过脱水缩合形成肽键（—CO—NH—）。
3. 蛋白质的结构多种多样，与氨基酸的种类、数目、排列顺序以及肽链的空间结构有关；蛋白质是生命活动的主要承担者。

**三个扣分点**：肽键数 = 氨基酸数 − 肽链数（环状肽例外，等于氨基酸数）；相对分子质量要减掉脱去的水；「约 21 种」是新教材数法，旧题里的「20 种」是旧版——按教材写 21，并说明这个差异。

**四张图**：① 氨基酸通式（中心 C 连氨基、羧基、H、R）；② 脱水缩合（两个氨基酸 → 二肽 + 一分子水，标出肽键）；③ 肽键数与肽链数的关系（一条链 n−1，两条链 n−2）；④ 结构多样性四个来源 + 功能举例（催化/运输/免疫/调节/结构）。

**互动模型**：滑块＝氨基酸数 n（2–30，step 1），肽链数用三个按钮选 1/2/3
```js
function calc(n, m) { m = m || 1;
  var bond = n - m;                 // 肽键数
  var water = n - m;                // 脱去水分子数
  var mw = 128 * n - 18 * (n - m);  // 平均相对分子质量按 128 计
  return { bond: bond, water: water, mw: mw };
}
```
状态：m=1「一条肽链」；m=2「两条肽链」；m=3「三条肽链」，并提示「链越多，肽键越少，分子量越大」。
`cases`（m 固定 1）：`{v:10,eq:{bond:9,water:9,mw:1118}}`、`{v:20,eq:{bond:19,water:19,mw:2218}}`、`{v:30,eq:{bond:29,water:29,mw:3318}}`。
Autopilot：`[{t:0,v:4},{t:3,v:10},{t:6,v:10},{t:9,v:20},{t:12,v:10}]`，keys `[4,10,20]`——停留帧在 10 个氨基酸（正好能数清肽键）。

**例题**：「某蛋白质由 2 条肽链组成，共 100 个氨基酸，平均相对分子质量 128。求肽键数、脱去水分子数、该蛋白质的相对分子质量。」答案：98、98、128×100 − 18×98 = 11036。
**六问**：① 肽键数怎么算；② 两条链为什么比一条链少一个肽键；③ 脱水缩合脱的是哪部分；④ 21 种还是 20 种；⑤ 蛋白质变性后肽键断了吗；⑥ 为什么蛋白质功能多样。
**易错**：✗ 肽键数=氨基酸数 / ✗ 分子量不减水 / ✗ 变性就是肽键断裂 / ✗ 组成蛋白质的氨基酸有 20 种（按新教材应为 21 种）/ ✗ 氨基酸种类由 R 基以外决定 / ✗ 一条肽链至少含 2 个游离氨基和 2 个游离羧基（链两端各 1 个）。
