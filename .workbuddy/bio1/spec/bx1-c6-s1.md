# 本节规格（只读这一节，不要读 SPEC.md 全文）

## bx1-c6-s1 细胞的增殖

**课本原话**
1. 细胞周期是指连续分裂的细胞，从一次分裂完成时开始，到下一次分裂完成时为止。
2. 一个细胞周期包括分裂间期和分裂期两个阶段；分裂间期占细胞周期的绝大部分时间。
3. 细胞体积越大，其相对表面积越小，物质运输的效率越低。

**三个扣分点**：细胞周期从「分裂完成」开始算，不是从分裂开始；间期时间最长（约 90%）；后期着丝点分裂 → 染色体数目加倍、染色单体消失，但 DNA 总数不变。

**四张图**：① 细胞周期（间期 vs 分裂期的时长比例）；② 有丝分裂四期形态（前期/中期/后期/末期）；③ 染色体数、DNA 数、染色单体数的变化曲线；④ 相对表面积与物质运输效率（琼脂块实验）。

**互动模型**：滑块＝细胞周期进度 t（0–100%，以 2N=4 的细胞为例）
```js
// 间期 0–90（G1 0–44、S 44–66、G2 66–90）；前期 90–93.5；中期 93.5–96.5；后期 96.5–98.5；末期 98.5–100
function calc(t) {
  if (t < 44) return { chr: 4, dna: 4, chd: 0 };
  if (t < 66) { var k = (t - 44) / 22; return { chr: 4, dna: 4 + 4 * k, chd: 8 * k }; }
  if (t < 96.5) return { chr: 4, dna: 8, chd: 8 };
  if (t < 98.5) return { chr: 8, dna: 8, chd: 0 };
  var q = (t - 98.5) / 1.5; return { chr: 8 - 4 * q, dna: 8 - 4 * q, chd: 0 };
}
```
状态：t<90「间期（G1/S/G2）」；90–93.5「前期」；93.5–96.5「中期」；96.5–98.5「后期」；≥98.5「末期」。
`cases`：`{v:20,eq:{chr:4,dna:4,chd:0}}`、`{v:55,eq:{chr:4,dna:6,chd:4}}`、`{v:75,eq:{chr:4,dna:8,chd:8}}`、`{v:95,eq:{chr:4,dna:8,chd:8}}`、`{v:97.5,eq:{chr:8,dna:8,chd:0}}`、`{v:100,eq:{chr:4,dna:4,chd:0}}`。
Autopilot：`[{t:0,v:20},{t:3,v:44},{t:5.5,v:90},{t:7.5,v:90},{t:9.5,v:97.5},{t:11.5,v:97.5},{t:13.5,v:100},{t:15,v:20}]`，keys `[20,44,75,97.5,100]`——停留帧在 97.5（后期：染色体数目突然加倍，曲线最直观的一格）。

**例题**：「某细胞（2N=4）完成一次有丝分裂，后期时染色体数、DNA 数、染色单体数分别是多少？为什么？」答案：8、8、0。着丝点分裂，姐妹染色单体分开成为两条染色体，染色体数暂时加倍；每条染色体只含 1 个 DNA；染色单体因着丝点分裂而消失。
**六问**：① 细胞周期从什么时候开始算；② 间期为什么时间长；③ 后期染色体数为什么加倍；④ 有丝分裂的意义；⑤ 细胞为什么不能无限长大；⑥ 染色单体在哪个时期出现和消失。
**易错**：✗ 细胞周期从分裂开始算 / ✗ 分裂期时间最长 / ✗ 后期 DNA 数目加倍（加倍的是染色体）/ ✗ 间期细胞不活动 / ✗ 有丝分裂使染色体数目减半 / ✗ 染色单体数一直等于 DNA 数。
