## bx1-c1-s2 细胞的多样性和统一性

**课本原话（A 区照抄）**
1. 原核细胞与真核细胞的主要区别：细胞内有无以核膜为界限的细胞核。
2. 蓝细菌细胞内含有藻蓝素和叶绿素，是能进行光合作用的自养生物。
3. 细胞的统一性：细胞都具有细胞膜、细胞质和核糖体，都以 DNA 作为遗传物质。

**三个扣分点**：放大倍数是「长度/宽度」的放大，不是面积；蓝细菌是原核但能光合（没有叶绿体）；原核生物不都有细胞壁（支原体没有）——这条只作提示，别当必考。

**四张图**：① 原核 vs 真核结构对比（有无核膜）；② 显微镜放大倍数与视野（同一块视野里细胞变少变大）；③ 蓝细菌与植物细胞都能光合，但一个有叶绿体一个没有；④ 统一性三件套（膜/质/核糖体 + DNA）。

**互动模型**：滑块＝放大倍数 n（100–1000，step 50）
```js
视野直径 d = 200000 / n;            // μm，100× → 2000
一行细胞数 = Math.floor(d / 10);     // 设细胞直径 10 μm
相对亮度 = Math.pow(100 / n, 2) * 100; // 100× → 100%
```
状态：n<200「低倍镜：视野大、细胞多、亮」；200–600「中倍」；>600「高倍镜：视野小、细胞少、暗」。
`cases`：`{v:100,eq:{d:2000,cells:200,bright:100}}`、`{v:400,eq:{d:500,cells:50,bright:6.25}}`、`{v:1000,eq:{d:200,cells:20,bright:1}}`。
Autopilot：`[{t:0,v:100},{t:3,v:100},{t:5.5,v:400},{t:9,v:400},{t:11.5,v:1000},{t:14,v:100}]`，keys `[100,400,1000]`——停留帧在 400×（能同时看清细胞数目和亮度变化）。

**例题**：显微镜操作题——「由低倍镜换高倍镜后，视野亮度、细胞数目、物像大小怎么变？为什么？」答案要点：变暗（进光量少）、细胞数目变少、物像变大；只调细准焦螺旋、不提升镜筒。
**六问**：① 原核与真核「本质区别」写哪句；② 蓝细菌能光合，所以它是真核？③ 细菌有没有线粒体；④ 放大 400 倍是不是面积放大 400 倍；⑤ 换高倍镜后视野变暗的原因；⑥ 为什么说细胞有统一性（举三个证据）。
**易错**：✗ 原核生物没有细胞器（有核糖体）/ ✗ 蓝细菌是植物（是原核）/ ✗ 放大倍数=面积倍数 / ✗ 高倍镜下先升镜筒再换物镜 / ✗ 原核细胞没有 DNA / ✗ 真核细胞都有细胞壁。

## bx1-c2-s1 细胞中的元素和化合物

**课本原话**
1. 组成细胞的化学元素，常见的有 20 多种。
2. 细胞中含量最多的化合物是水；含量最多的有机化合物是蛋白质。
3. C 是构成细胞的最基本元素（生物大分子以碳链为骨架）。

**三个扣分点**：鲜重第一是 O、干重第一是 C（同一块材料两个答案）；「最基本元素」是 C，但「含量最多」不是 C；斐林试剂要水浴加热，双缩脲试剂不需要。

**四张图**：① 大量元素/微量元素分组（C H O N P S K Ca Mg + Fe Mn Zn Cu B Mo）；② 鲜重与干重的元素含量条（O 与 C 换位）；③ 化合物含量占比条（水 85–90、蛋白质 7–10、脂质 1–2、糖类和核酸 1–1.5）；④ 三个检测实验对照（斐林→砖红、苏丹Ⅲ→橘黄、双缩脲→紫）。

**互动模型**：滑块＝含水量 w（0–100%，100 = 鲜重、0 = 完全烘干）
```js
O = 65 * w/100 + 23.7 * (1 - w/100);   // 鲜重 O65%、干重 O23.7%
C = 18 * w/100 + 48.4 * (1 - w/100);   // 鲜重 C18%、干重 C48.4%
```
状态：w>50「鲜重：O 第一」；10–50「过渡：C 追上来」；w<10「干重：C 第一」。交叉点 w≈34%。
`cases`：`{v:100,eq:{o:65,c:18}}`、`{v:0,eq:{o:23.7,c:48.4}}`、`{v:34,eq:{o:37.7,c:38.1}}`。
Autopilot：`[{t:0,v:100},{t:3,v:100},{t:5.5,v:34},{t:8.5,v:34},{t:11,v:0},{t:13,v:100}]`，keys `[100,34,0]`——停留帧在 34%（两条线交叉，「谁第一」在这里换人）。

**例题**：「人体细胞干重中含量最多的元素是____，含量最多的化合物是____」+ 追问「为什么鲜重和干重答案不同」。答案：C；蛋白质；鲜重里水占 85–90%，水的 O 把 O 顶上第一，烘干后水没了，C 才第一。
**六问**：① 最基本元素与含量最多元素分别是谁；② 为什么干重没有水；③ 微量元素是不是不重要；④ 检测还原糖为什么必须水浴加热；⑤ 蛋白质检测为什么先加 A 液再加 B 液；⑥ 组成细胞的元素在无机自然界都能找到，说明什么。
**易错**：✗ 含量最多的元素是 C / ✗ 最基本元素是 O / ✗ 微量元素含量少所以不重要 / ✗ 斐林试剂直接加不用加热 / ✗ 双缩脲试剂要水浴 / ✗ 细胞中含量最多的有机物是水。

## bx1-c2-s2 细胞中的无机物

**课本原话**
1. 水在细胞中主要以两种形式存在：自由水和结合水。自由水是细胞内良好的溶剂，结合水是细胞结构的重要组成成分。
2. 自由水与结合水的比值越高，细胞代谢越旺盛；比值越低，细胞抗逆性越强。
3. 细胞中大多数无机盐以离子的形式存在，它们对维持细胞和生物体的生命活动有重要作用。

**三个扣分点**：结合水不是「没用的水」，它是结构的一部分；抗逆（抗旱抗寒）对应的是结合水比例高；无机盐不提供能量。

**四张图**：① 自由水 vs 结合水（一个能流动当溶剂，一个被「绑」在结构上）；② 两条反向曲线（自由水比例↑ → 代谢↑、抗逆↓）；③ 无机盐的三种作用（构成化合物 / 维持生命活动 / 维持渗透压和酸碱平衡）；④ 实例表（缺 Mg 叶发黄、缺 Ca 抽搐、缺 Fe 贫血、缺 I 甲状腺肿）。

**互动模型**：滑块＝结合水占比 b（0–40%，占细胞总水的百分比）
```js
met = 100 * (1 - b / 40);   // 代谢强度（示意）
res = 100 * (b / 40);       // 抗逆性（示意）
ratio = (100 - b) / b;      // 自由水 : 结合水
```
状态：b<10「代谢旺盛（如正在萌发的种子）」；10–30「正常」；≥30「抗逆型（越冬植物、休眠种子）」。
`cases`：`{v:0,eq:{met:100,res:0}}`、`{v:20,eq:{met:50,res:50,ratio:4}}`、`{v:40,eq:{met:0,res:100,ratio:1.5}}`。
Autopilot：`[{t:0,v:10},{t:3,v:35},{t:6,v:35},{t:8.5,v:5},{t:11,v:35}]`，keys `[5,20,35]`——停留帧在 35%（越冬植物：水少反而能活，这是最反直觉的一格）。

**例题**：简答「冬天来临前，冬小麦细胞内自由水与结合水的比值会怎样变化？有什么意义？」答案：比值降低（结合水比例升高），代谢减弱、抗寒能力增强。
**六问**：① 自由水多了代谢快还是慢；② 抗旱与结合水的关系；③ 无机盐为什么不能提供能量；④ 缺 Mg 为什么叶片发黄；⑤ 输液为什么用 0.9% 生理盐水；⑥ 「水是生命之源」在细胞层面怎么解释。
**易错**：✗ 结合水是废物 / ✗ 抗逆性与自由水比例正相关 / ✗ 无机盐是能源物质 / ✗ 自由水只当溶剂没有别的功能 / ✗ 干旱时细胞结合水比例下降 / ✗ 无机盐都以化合物形式存在。

## bx1-c2-s3 细胞中的糖类和脂质

**课本原话**
1. 糖类是主要的能源物质。
2. 脂肪是细胞内良好的储能物质；与糖类相比，脂肪分子中氧的含量远远低于糖类，而氢的含量更高。
3. 磷脂是构成细胞膜和细胞器膜的重要成分；固醇类物质包括胆固醇、性激素和维生素 D 等。

**三个扣分点**：糖类不都甜、不都是能源（纤维素、核糖、脱氧核糖）；脂肪 ≠ 脂质（脂质还包括磷脂和固醇）；脂肪「储能多」的代价是耗氧多。

**四张图**：① 糖的分类树（单糖/二糖/多糖 + 代表物）；② 脂质三类（脂肪/磷脂/固醇）；③ 等质量糖与脂肪的能量柱对比（约 1 : 2.3）；④ 磷脂在膜上的排布（亲水头朝外、疏水尾朝内）。

**互动模型**：滑块＝质量 m（5–100 g），对比糖与脂肪
```js
eSugar = 17 * m;    // kJ，教材常用 17 kJ/g
eFat   = 39 * m;    // kJ，教材常用 39 kJ/g
o2Sugar = 0.75 * m; // L，按葡萄糖完全氧化算
o2Fat   = 2.05 * m; // L，按三硬脂酸甘油酯算
```
状态：不随 m 变，写「脂肪单位质量放能约为糖的 2.3 倍，但耗氧也约为 2.7 倍」。
`cases`：`{v:10,eq:{eSugar:170,eFat:390}}`、`{v:50,eq:{eSugar:850,eFat:1950}}`、`{v:100,eq:{eSugar:1700,eFat:3900}}`。
Autopilot：`[{t:0,v:10},{t:3,v:10},{t:6,v:50},{t:8.5,v:100},{t:11,v:100},{t:13,v:10}]`，keys `[10,50,100]`。

**例题**：「驼峰里储存的主要是脂肪而不是糖类，从能量和代谢角度分析原因。」答案：脂肪单位质量储能约为糖的 2.3 倍，同样质量带的能量更多；脂肪氧化还会产生较多水，对缺水环境有利；代价是耗氧更多、动员慢。
**六问**：① 纤维素不是能源物质为什么还必需；② 糖原与淀粉的区别；③ 脂肪与磷脂的共同点；④ 为什么脂肪耗氧多；⑤ 胆固醇是不是都对身体有害；⑥ 单糖、二糖、多糖怎么区分。
**易错**：✗ 糖类都是甜的 / ✗ 脂肪就是脂质 / ✗ 磷脂属于脂肪 / ✗ 纤维素能被人体消化 / ✗ 脂肪氧化放能多且耗氧少 / ✗ 胆固醇只有坏处。

## bx1-c2-s4 蛋白质是生命活动的主要承担者

**课本原话**
1. 氨基酸是组成蛋白质的基本单位；每种氨基酸分子至少都含有一个氨基和一个羧基，并且都有一个氨基和一个羧基连接在同一个碳原子上。
2. 氨基酸分子之间通过脱水缩合形成肽键（—CO—NH—）。
3. 蛋白质的结构多种多样，与氨基酸的种类、数目、排列顺序以及肽链的空间结构有关；蛋白质是生命活动的主要承担者。

**三个扣分点**：肽键数 = 氨基酸数 − 肽链数（环状肽例外，等于氨基酸数）；相对分子质量要减掉脱去的水；「约 21 种」是新教材数法，旧题里的「20 种」是旧版——按教材写 21，并说明这个差异。

**四张图**：① 氨基酸通式（中心 C 连氨基、羧基、H、R）；② 脱水缩合（两个氨基酸 → 二肽 + 一分子水，标出肽键）；③ 肽键数与肽链数的关系（一条链 n−1，两条链 n−2）；④ 结构多样性四个来源 + 功能举例（催化/运输/免疫/调节/结构）。

**互动模型**：滑块＝氨基酸数 n（2–30，step 1），肽链数用三个按钮选 1/2/3
```js
function calc(n, m) { m = m || 1;
  var bond = n - m;                 // 肽键数
  var water = n - m;                // 脱去水分子数
  var mw = 128 * n - 18 * (n - m);  // 平均相对分子质量按 128 计
  return { bond: bond, water: water, mw: mw };
}
```
状态：m=1「一条肽链」；m=2「两条肽链」；m=3「三条肽链」，并提示「链越多，肽键越少，分子量越大」。
`cases`（m 固定 1）：`{v:10,eq:{bond:9,water:9,mw:1118}}`、`{v:20,eq:{bond:19,water:19,mw:2218}}`、`{v:30,eq:{bond:29,water:29,mw:3318}}`。
Autopilot：`[{t:0,v:4},{t:3,v:10},{t:6,v:10},{t:9,v:20},{t:12,v:10}]`，keys `[4,10,20]`——停留帧在 10 个氨基酸（正好能数清肽键）。

**例题**：「某蛋白质由 2 条肽链组成，共 100 个氨基酸，平均相对分子质量 128。求肽键数、脱去水分子数、该蛋白质的相对分子质量。」答案：98、98、128×100 − 18×98 = 11036。
**六问**：① 肽键数怎么算；② 两条链为什么比一条链少一个肽键；③ 脱水缩合脱的是哪部分；④ 21 种还是 20 种；⑤ 蛋白质变性后肽键断了吗；⑥ 为什么蛋白质功能多样。
**易错**：✗ 肽键数=氨基酸数 / ✗ 分子量不减水 / ✗ 变性就是肽键断裂 / ✗ 组成蛋白质的氨基酸有 20 种（按新教材应为 21 种）/ ✗ 氨基酸种类由 R 基以外决定 / ✗ 一条肽链至少含 2 个游离氨基和 2 个游离羧基（链两端各 1 个）。

## bx1-c2-s5 核酸是遗传信息的携带者

**课本原话**
1. 核酸包括脱氧核糖核酸（DNA）和核糖核酸（RNA）两大类。
2. 核苷酸是核酸的基本组成单位，一分子核苷酸由一分子磷酸、一分子五碳糖和一分子含氮碱基组成。
3. 核酸是细胞内携带遗传信息的物质，在生物体的遗传、变异和蛋白质的生物合成中具有极其重要的作用。

**三个扣分点**：DNA 特有 T、RNA 特有 U；A=T、G=C 只适用于双链 DNA；原核细胞既有 DNA 也有 RNA（DNA 是遗传物质）。

**四张图**：① 核苷酸的三层结构（磷酸—五碳糖—碱基）；② DNA 双链（反向平行、碱基互补）vs RNA 单链；③ DNA 与 RNA 对照表（五碳糖/碱基/链数/分布）；④ 核酸的功能链（DNA → RNA → 蛋白质）。

**互动模型**：滑块＝双链 DNA 中 A 占全部碱基的比例 a（10–40%）
```js
T = a; G = 50 - a; C = 50 - a; GC = 100 - 2 * a;
```
状态：a<15「GC 丰富（AT 少）」；15–35「GC 中等」；>35「AT 丰富（GC 低）」。
（注意 GC=100−2a：a 越小 GC 越高，别把两端的标签写反。）
`cases`：`{v:10,eq:{T:10,G:40,C:40,gc:80}}`、`{v:20,eq:{T:20,G:30,C:30,gc:60}}`、`{v:30,eq:{T:30,G:20,C:20,gc:40}}`。
Autopilot：`[{t:0,v:10},{t:3,v:10},{t:5.5,v:20},{t:8,v:30},{t:10.5,v:30},{t:13,v:10}]`，keys `[10,20,30]`。

**例题**：「某双链 DNA 分子中，A 占全部碱基的 20%，则 G 占____，该 DNA 的 GC 含量为____；若其中一条链上 A 占该链的 30%，能否确定另一条链上 A 的比例？」答案：30%、60%；不能单凭一条链定另一条链的 A（双链总量才能定）。

## bx1-c3-s1 细胞膜的结构和功能

**课本原话**

## bx1-c4-s1 被动运输

**课本原话**
1. 物质以扩散方式进出细胞，不需要消耗细胞内化学反应所释放的能量，这种物质跨膜运输方式称为被动运输。
2. 被动运输分为自由扩散和协助扩散两类；借助膜上转运蛋白进出细胞的物质扩散方式叫作协助扩散。
3. 水分子（或其他溶剂分子）通过半透膜的扩散，称为渗透作用。

**三个扣分点**：协助扩散需要载体但不消耗能量（这是最爱考的一句）；载体数量有限 → 会饱和；水既能自由扩散也能经水通道蛋白协助扩散。

**四张图**：① 自由扩散（直接穿过磷脂双分子层）；② 协助扩散（载体蛋白发生构象变化）；③ 两条速率曲线（自由扩散直线、协助扩散饱和）；④ 影响因素（浓度差、载体数量、温度）。

**互动模型**：滑块＝浓度差 c（0–20 mmol/L）
```js
free = 2 * c;              // 自由扩散速率（示意）
facil = 10 * c / (3 + c);  // 协助扩散速率：Vmax=10, Km=3
```
状态：c<2「低浓度：协助扩散更快（有载体帮忙）」；c=2「两者相等（交叉点）」；c>2「高浓度：自由扩散反超，协助扩散已饱和」。
`cases`：`{v:2,eq:{free:4,facil:4}}`、`{v:6,eq:{free:12,facil:6.67}}`、`{v:18,eq:{free:36,facil:8.57}}`。
Autopilot：`[{t:0,v:1},{t:3,v:2},{t:5.5,v:2},{t:8,v:8},{t:10.5,v:18},{t:13,v:1}]`，keys `[1,2,8,18]`——停留帧在 c=2（两条线交叉，最容易看错的一格）。

**例题**：「葡萄糖进入红细胞和进入小肠上皮细胞，分别属于哪种跨膜运输方式？」答案：进入红细胞是协助扩散（顺浓度梯度、需载体、不耗能）；进入小肠上皮细胞是主动运输（逆浓度梯度、需载体、耗能）。
**六问**：① 协助扩散要不要能量；② 载体饱和意味着什么；③ 自由扩散和协助扩散的共同点；④ 水只靠自由扩散吗；⑤ 温度怎么影响被动运输；⑥ 渗透作用的方向怎么判断。
**易错**：✗ 协助扩散消耗能量 / ✗ 自由扩散需要载体 / ✗ 葡萄糖进细胞都是协助扩散 / ✗ 浓度差越大协助扩散越快（会饱和）/ ✗ 水的运输只有自由扩散 / ✗ 被动运输只能从低浓度到高浓度。

## bx1-c4-s2 主动运输与胞吞、胞吐

**课本原话**
1. 物质逆浓度梯度进行跨膜运输，需要载体蛋白的协助，同时还需要消耗细胞内化学反应所释放的能量，这种方式叫作主动运输。
2. 主动运输保证了活细胞能够按照生命活动的需要，主动选择吸收所需要的营养物质，排出代谢废物和对细胞有害的物质。
3. 大分子物质进出细胞的方式是胞吞和胞吐，它们依赖于细胞膜的流动性，需要消耗能量。

**三个扣分点**：主动运输是「逆」浓度梯度；胞吞胞吐不是跨膜运输（物质不穿过膜，靠膜包裹）；三种方式里只有自由扩散、协助扩散不耗能。

**四张图**：① 主动运输（载体 + ATP，逆梯度）；② 胞吞与胞吐（膜凹陷/融合）；③ 三种方式对照表（方向/载体/能量/实例）；④ ATP 供应与运输速率。

**互动模型**：滑块＝ATP 供应 p（0–100%）
```js

ratio = 1 + 2 * p / 100;   // 细胞内/细胞外浓度比
```
状态：p=0「没有 ATP：只能被动运输，细胞内外浓度趋于相等」；0<p<100「部分维持浓度差」；p=100「稳定逆浓度梯度，主动选择吸收」。
`cases`：`{v:0,eq:{rate:0,ratio:1}}`、`{v:50,eq:{rate:4,ratio:2}}`、`{v:100,eq:{rate:8,ratio:3}}`。
Autopilot：`[{t:0,v:0},{t:3,v:0},{t:5.5,v:50},{t:8,v:100},{t:10.5,v:100},{t:13,v:0}]`，keys `[0,50,100]`。

**例题**：「某植物根细胞吸收 K⁺ 的量随氧气浓度升高而增加，超过一定氧浓度后不再增加，原因是什么？」答案：K⁺ 吸收是主动运输，需要 ATP；氧气浓度升高 → 有氧呼吸增强 → ATP 增多 → 吸收加快；载体蛋白数量有限，达到饱和后不再增加。

**易错**：✗ 主动运输顺浓度梯度 / ✗ 胞吞胞吐也是跨膜运输 / ✗ 胞吞胞吐不需要能量 / ✗ 抑制呼吸不影响主动运输 / ✗ 大分子通过载体进入细胞 / ✗ 主动运输只吸收营养物质。

## bx1-c5-s1 降低化学反应活化能的酶

**课本原话**
1. 酶是活细胞产生的具有催化作用的有机物，其中绝大多数酶是蛋白质。
2. 酶能降低化学反应的活化能；与无机催化剂相比，酶降低活化能的作用更显著，催化效率更高。
3. 过酸、过碱或温度过高，会使酶的空间结构遭到破坏，使酶永久失活；低温时酶活性很低，但酶的空间结构稳定。

**例题**：「将唾液淀粉酶分别放在 0℃ 和 100℃ 下处理 10 分钟，再恢复到 37℃，两者的催化能力如何？」答案：0℃ 处理的恢复活性（低温只抑制，结构未破坏）；100℃ 处理的不能恢复（高温使空间结构破坏，永久失活）。

## bx1-c5-s2 细胞的能量「货币」ATP

**课本原话**
1. ATP 是细胞内的一种高能磷酸化合物，其结构简式为 A—P~P~P，其中 A 代表腺苷，P 代表磷酸基团。
2. ATP 与 ADP 可以相互转化：ATP ⇌ ADP + Pi + 能量。
3. ATP 是细胞生命活动的直接能源物质。

**三个扣分点**：ATP 不是「能量仓库」，细胞内含量很少但周转极快；ATP 与 ADP 的相互转化不是可逆反应（酶不同、能量来源不同、场所不同）；「~」不是普通化学键。

**四张图**：① ATP 结构 A—P~P~P（标出远离 A 的高能磷酸键）；② ATP ⇄ ADP 循环（放能/吸能两侧）；③ 存量恒定 vs 周转速率（两条线，一条平一条升）；④ 糖类脂肪 → ATP → 各项生命活动。

**互动模型**：滑块＝耗能强度 e（0–100%）
```js
turn = e;                    // ATP 周转速率（相对）
stock = 100;                 // 细胞内 ATP 存量（示意：基本不变）
ratio = 0.2 + 0.008 * e;     // ADP/ATP 比值
```
状态：e<20「安静状态：周转慢」；20–60「中等活动」；>60「剧烈运动：周转极快，但 ATP 总量几乎不变」。
`cases`：`{v:0,eq:{turn:0,stock:100,ratio:0.2}}`、`{v:50,eq:{turn:50,stock:100,ratio:0.6}}`、`{v:100,eq:{turn:100,stock:100,ratio:1.0}}`。
Autopilot：`[{t:0,v:10},{t:3,v:10},{t:5.5,v:100},{t:8.5,v:100},{t:11,v:10}]`，keys `[10,50,100]`——停留帧在 100（周转拉满而存量纹丝不动，这是全篇最反直觉的一格）。

**例题**：「剧烈运动时，肌细胞内 ATP 的含量会大幅增加吗？为什么？」答案：不会。ATP 在细胞内含量很少，但 ATP 与 ADP 转化极快，消耗多少就再生多少；剧烈运动时增加的是转化速率，不是总量。
**六问**：① ATP 为什么叫「直接」能源物质；② ATP 与 ADP 的转化是可逆反应吗；③ ATP 里的「~」是什么键；④ 细胞为什么不能大量储存 ATP；⑤ 光反应产生的 ATP 用在哪；⑥ 剧烈运动时 ATP 从哪来。
**易错**：✗ ATP 是可大量储存的能源物质 / ✗ ATP⇄ADP 是可逆反应 / ✗ ATP 由三个高能磷酸键组成（是两个）/ ✗ ATP 是主要能源物质（是直接能源物质，主要能源是糖类）/ ✗ 剧烈运动后 ATP 含量大增 / ✗ A 代表腺嘌呤。

## bx1-c5-s3 细胞呼吸的原理和应用

**课本原话**
1. 有氧呼吸的总反应式：C₆H₁₂O₆ + 6O₂ + 6H₂O →(酶) 6CO₂ + 12H₂O + 能量。
2. 有氧呼吸的第一阶段在细胞质基质中进行，第二阶段在线粒体基质中进行，第三阶段在线粒体内膜上进行。
3. 无氧呼吸在细胞质基质中进行，产物是酒精和 CO₂，或者乳酸；无氧呼吸只在第一阶段释放少量能量。

**三个扣分点**：第一阶段在细胞质基质，不在线粒体；无氧呼吸第二阶段不产生 ATP；有氧呼吸生成的水中的氧来自 O₂，CO₂ 中的氧来自葡萄糖和水。

**四张图**：① 有氧呼吸三阶段（位置/反应物/产物/ATP 量）；② 有氧 vs 无氧的能量对比；③ O₂ 浓度与呼吸方式（无氧受抑制、有氧上升）；④ 应用（中耕松土、包扎伤口、酿酒、慢跑）。

**互动模型**：滑块＝O₂ 浓度 o（0–21%）
```js
aer = 100 * o / (2 + o);        // 有氧呼吸 CO₂ 释放（相对，饱和型）
ana = 80 * Math.exp(-o / 4);    // 无氧呼吸 CO₂/酒精（受 O₂ 抑制）
total = aer + ana;
```
状态：o<1「无氧呼吸为主（酒精 + CO₂）」；1–5「两者并存」；>10「有氧呼吸为主，无氧几乎停止」。
`cases`：`{v:0,eq:{aer:0,ana:80}}`、`{v:5,eq:{aer:71.4,ana:22.9}}`、`{v:21,eq:{aer:91.3,ana:0.4}}`。
Autopilot：`[{t:0,v:0},{t:3,v:0},{t:5.5,v:5},{t:8,v:21},{t:10.5,v:21},{t:13,v:0}]`，keys `[0,3,10,21]`——停留帧在 o=0（纯无氧，酒精产量最高）。

**例题**：「储存粮食时要先晒干并保持低温、低氧，从细胞呼吸角度分析原因。」答案：晒干降低自由水含量，呼吸速率下降；低温降低酶活性；低氧抑制有氧呼吸且不至于缺氧进行无氧呼吸（产生酒精）。三点都是为了减少有机物消耗。
**六问**：① 有氧呼吸第一阶段的场所；② 无氧呼吸为什么产生乳酸或酒精；③ 为什么水淹后根会烂；④ 有氧呼吸生成的水中的氧从哪来；⑤ 无氧呼吸释放的能量去哪了；⑥ 为什么慢跑比剧烈冲刺「省 ATP」。
**易错**：✗ 有氧呼吸三个阶段都在线粒体 / ✗ 无氧呼吸第二阶段产生大量 ATP / ✗ 无氧呼吸不产生 CO₂（产乳酸时不产 CO₂）/ ✗ 有氧呼吸的水中氧来自葡萄糖 / ✗ 呼吸作用只在白天进行 / ✗ 低温让酶变性从而抑制呼吸。

## bx1-c5-s4 光合作用与能量转化

**课本原话**
1. 光合作用是指绿色植物通过叶绿体，利用光能，把二氧化碳和水转化成储存着能量的有机物，并且释放出氧气的过程。
2. 光反应在类囊体薄膜上进行，水的光解产生 O₂ 和 NADPH，同时生成 ATP；暗反应在叶绿体基质中进行，CO₂ 被固定形成 C₃，C₃ 被还原。
3. 光合作用释放的 O₂ 中的氧全部来自水。

**三个扣分点**：O₂ 来自水、不来自 CO₂；光反应给暗反应提供 ATP 和 NADPH；净光合 = 总光合 − 呼吸。

**四张图**：① 叶绿体结构与两阶段位置；② 光反应与暗反应的物质联系（ATP/NADPH/C₃）；③ 光照强度—净光合速率曲线（补偿点、饱和点）；④ CO₂ 浓度与温度的影响。

**互动模型**：滑块＝光照强度 I（0–200，相对值）
```js
gross = 20 * I / (I + 30);   // 总光合速率（示意）
net = gross - 4;             // 净光合 = 总光合 − 呼吸（呼吸按 4 计）
```
状态：I<7.5「净光合为负：消耗有机物」；I=7.5「光补偿点」；7.5<I<120「净光合随光强上升」；≥120「接近光饱和点」。
`cases`：`{v:0,eq:{gross:0,net:-4}}`、`{v:7.5,eq:{gross:4,net:0}}`、`{v:30,eq:{gross:10,net:6}}`、`{v:120,eq:{gross:16,net:12}}`、`{v:200,eq:{gross:17.39,net:13.39}}`。
Autopilot：`[{t:0,v:0},{t:3,v:0},{t:6,v:7.5},{t:9,v:7.5},{t:11.5,v:60},{t:14,v:200},{t:16,v:0}]`，keys `[0,7.5,30,120]`——停留帧在 7.5（补偿点：光合恰好抵消呼吸，净光合为 0）。

**例题**：「将某植物置于光照强度为光补偿点的条件下，一段时间后植物能否正常生长？为什么？」答案：不能长期正常生长。此时光合速率等于呼吸速率，净光合为 0，没有有机物积累；要正常生长必须大于光补偿点。
**六问**：① 释放的 O₂ 来自水还是 CO₂；② 光反应为暗反应提供什么；③ 光补偿点和光饱和点的含义；④ 突然停止光照 C₃ 和 C₅ 怎么变；⑤ 为什么净光合要用「总光合 − 呼吸」；⑥ 阴生植物与阳生植物的曲线差别。
**易错**：✗ O₂ 来自 CO₂ / ✗ 暗反应在类囊体薄膜上进行 / ✗ 净光合可直接用总光合比较 / ✗ 光补偿点就是不再光合 / ✗ 光反应不需要酶 / ✗ 停止光照后 C₃ 立刻减少（实际先增多）。

## bx1-c6-s1 细胞的增殖

**课本原话**
1. 细胞周期是指连续分裂的细胞，从一次分裂完成时开始，到下一次分裂完成时为止。
2. 一个细胞周期包括分裂间期和分裂期两个阶段；分裂间期占细胞周期的绝大部分时间。
3. 细胞体积越大，其相对表面积越小，物质运输的效率越低。

**三个扣分点**：细胞周期从「分裂完成」开始算，不是从分裂开始；间期时间最长（约 90%）；后期着丝点分裂 → 染色体数目加倍、染色单体消失，但 DNA 总数不变。

**四张图**：① 细胞周期（间期 vs 分裂期的时长比例）；② 有丝分裂四期形态（前期/中期/后期/末期）；③ 染色体数、DNA 数、染色单体数的变化曲线；④ 相对表面积与物质运输效率（琼脂块实验）。

**互动模型**：滑块＝细胞周期进度 t（0–100%，以 2N=4 的细胞为例）
```js
// 间期 0–90（G1 0–44、S 44–66、G2 66–90）；前期 90–93.5；中期 93.5–96.5；后期 96.5–98.5；末期 98.5–100
function calc(t) {
  if (t < 44) return { chr: 4, dna: 4, chd: 0 };
  if (t < 66) { var k = (t - 44) / 22; return { chr: 4, dna: 4 + 4 * k, chd: 8 * k }; }
  if (t < 96.5) return { chr: 4, dna: 8, chd: 8 };
  if (t < 98.5) return { chr: 8, dna: 8, chd: 0 };
  var q = (t - 98.5) / 1.5; return { chr: 8 - 4 * q, dna: 8 - 4 * q, chd: 0 };
}
```
状态：t<90「间期（G1/S/G2）」；90–93.5「前期」；93.5–96.5「中期」；96.5–98.5「后期」；≥98.5「末期」。
`cases`：`{v:20,eq:{chr:4,dna:4,chd:0}}`、`{v:55,eq:{chr:4,dna:6,chd:4}}`、`{v:75,eq:{chr:4,dna:8,chd:8}}`、`{v:95,eq:{chr:4,dna:8,chd:8}}`、`{v:97.5,eq:{chr:8,dna:8,chd:0}}`、`{v:100,eq:{chr:4,dna:4,chd:0}}`。
Autopilot：`[{t:0,v:20},{t:3,v:44},{t:5.5,v:90},{t:7.5,v:90},{t:9.5,v:97.5},{t:11.5,v:97.5},{t:13.5,v:100},{t:15,v:20}]`，keys `[20,44,75,97.5,100]`——停留帧在 97.5（后期：染色体数目突然加倍，曲线最直观的一格）。

**例题**：「某细胞（2N=4）完成一次有丝分裂，后期时染色体数、DNA 数、染色单体数分别是多少？为什么？」答案：8、8、0。着丝点分裂，姐妹染色单体分开成为两条染色体，染色体数暂时加倍；每条染色体只含 1 个 DNA；染色单体因着丝点分裂而消失。
**六问**：① 细胞周期从什么时候开始算；② 间期为什么时间长；③ 后期染色体数为什么加倍；④ 有丝分裂的意义；⑤ 细胞为什么不能无限长大；⑥ 染色单体在哪个时期出现和消失。
**易错**：✗ 细胞周期从分裂开始算 / ✗ 分裂期时间最长 / ✗ 后期 DNA 数目加倍（加倍的是染色体）/ ✗ 间期细胞不活动 / ✗ 有丝分裂使染色体数目减半 / ✗ 染色单体数一直等于 DNA 数。

## bx1-c6-s2 细胞的分化

**课本原话**
1. 细胞分化是指在个体发育中，由一个或一种细胞增殖产生的后代，在形态、结构和生理功能上发生稳定性差异的过程。
2. 细胞分化是基因选择性表达的结果；细胞分化具有普遍性、持久性和稳定性。
3. 细胞的全能性是指已经分化的细胞，仍然具有发育成完整个体的潜能。

**三个扣分点**：分化不改变遗传物质（同一个体不同细胞的基因相同）；全能性大小：受精卵 > 生殖细胞 > 体细胞，植物 > 动物；分化程度越高，全能性越低。

**四张图**：① 一个受精卵 → 多种细胞（分化树）；② 基因选择性表达（同一套基因、不同的「开关」）；③ 分化程度与全能性的反向关系；④ 植物组织培养（脱分化 → 再分化）。

**互动模型**：滑块＝分化程度 d（0–100）
```js
pot = 100 - 0.85 * d;    // 全能性（示意）
expr = 90 - 0.7 * d;     // 表达的基因比例（示意，%）
```
状态：d<20「受精卵级：全能性最高」；20–70「干细胞：多向分化」；>70「高度分化：如神经细胞、肌肉细胞」。
`cases`：`{v:0,eq:{pot:100,expr:90}}`、`{v:50,eq:{pot:57.5,expr:55}}`、`{v:100,eq:{pot:15,expr:20}}`。
Autopilot：`[{t:0,v:0},{t:3,v:0},{t:5.5,v:50},{t:8,v:100},{t:10.5,v:100},{t:13,v:0}]`，keys `[0,30,60,100]`。

**例题**：「同一个人的神经细胞和肌肉细胞，形态功能差别很大，它们的遗传物质相同吗？为什么？」答案：相同（除非发生突变）。因为它们由同一个受精卵经有丝分裂产生，遗传物质相同；差异来自基因的选择性表达。
**六问**：① 分化后遗传物质变了吗；② 全能性大小怎么排；③ 为什么植物细胞比动物细胞容易表现全能性；④ 干细胞是什么；⑤ 分化一定是不可逆的吗；⑥ 细胞分化与细胞分裂的关系。
**易错**：✗ 分化后基因发生了改变 / ✗ 全能性最高的是体细胞 / ✗ 动物细胞没有全能性 / ✗ 分化程度越高全能性越强 / ✗ 脱分化就是分化 / ✗ 所有细胞都能表现全能性。

## bx1-c6-s3 细胞的衰老和死亡

**课本原话**
1. 细胞衰老的特征：细胞内水分减少，细胞萎缩，体积变小；多种酶的活性降低；色素逐渐积累；呼吸速率减慢，细胞核体积增大，染色质收缩，染色加深；细胞膜通透性改变，使物质运输功能降低。
2. 细胞凋亡是由基因所决定的细胞自动结束生命的过程。
3. 细胞坏死是在种种不利因素影响下，由于细胞正常代谢活动受损或中断引起的细胞损伤和死亡。

**三个扣分点**：衰老细胞的细胞核体积「增大」（不是变小）；凋亡是程序性的、对个体有利，坏死是病理性的、有害；多细胞生物个体的衰老 ≠ 细胞的衰老，但二者有关。

**四张图**：① 衰老细胞的五个特征；② 凋亡 vs 坏死对照；③ 个体衰老与细胞衰老的关系；④ 细胞生命历程全景（增殖→分化→衰老→凋亡）。

**互动模型**：滑块＝衰老程度 a（0–100，示意）
```js
water   = 100 - 0.45 * a;   // 细胞内水分（相对）
enzyme  = 100 - 0.60 * a;   // 酶活性（相对）
pigment = 0.8 * a;          // 色素积累（相对）
nucleus = 100 + 0.50 * a;   // 细胞核体积（相对）
```
状态：a<20「年轻细胞」；20–60「衰老早期」；>60「明显衰老」；=100「濒临凋亡」。
`cases`：`{v:0,eq:{water:100,enzyme:100,pigment:0,nucleus:100}}`、`{v:50,eq:{water:77.5,enzyme:70,pigment:40,nucleus:125}}`、`{v:100,eq:{water:55,enzyme:40,pigment:80,nucleus:150}}`。
Autopilot：`[{t:0,v:0},{t:3,v:0},{t:5.5,v:50},{t:8,v:100},{t:10.5,v:100},{t:13,v:0}]`，keys `[0,20,60,100]`——停留帧在 100（核体积反而最大，和「细胞萎缩」形成反差）。

**例题**：「老年人皮肤上出现老年斑，从细胞衰老角度解释原因。」答案：衰老细胞内色素（脂褐素）逐渐积累，随年龄增长积累增多并沉积在皮肤细胞中，形成老年斑。
**六问**：① 衰老细胞核体积变大还是变小；② 凋亡和坏死怎么区分；③ 细胞凋亡对个体有害吗；④ 多细胞生物衰老与细胞衰老是一回事吗；⑤ 为什么老年人伤口愈合慢；⑥ 被病原体感染的细胞被清除属于凋亡还是坏死。
**易错**：✗ 衰老细胞核体积变小 / ✗ 凋亡就是细胞坏死 / ✗ 凋亡对机体有害 / ✗ 个体衰老等于所有细胞都衰老 / ✗ 细胞衰老后水分增多 / ✗ 细胞死亡都是病理性的。
