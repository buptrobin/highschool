## bx2-c4-s2 基因表达与性状的关系

**课本原话**
1. 基因通过控制酶的合成来控制代谢过程，进而控制生物体的性状。
2. 基因通过控制蛋白质的结构直接控制生物体的性状。
3. 基因与性状的关系并不都是简单的线性关系；环境也能影响性状。表观遗传：基因的碱基序列不变，但基因表达和表型发生可遗传变化。

**三个扣分点**：基因控性状有**两条途径**（控酶 vs 控结构蛋白）；一个基因可能影响多个性状、多个基因也可能影响同一性状；甲基化不改变碱基序列但改变表达。

**四张图**：① 基因→酶→代谢→性状（白化病）；② 基因→结构蛋白→性状（镰状细胞贫血）；③ 多基因与一因多效；④ 甲基化与表观遗传。

**互动模型**：滑块＝启动子甲基化程度 m（0–100%，step 5）
```js
expr = 100 - m;               // 基因表达量（相对值）
pheno = expr >= 50 ? 1 : 0;   // 性状是否正常表现（阈值示意）
```
`cases`：`{v:0,eq:{expr:100}}`、`{v:60,eq:{expr:40,pheno:0}}`、`{v:100,eq:{expr:0}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:60},{t:6.5,v:60},{t:9,v:100},{t:11,v:30},{t:13,v:0}]`，keys `[0,30,60,100]`。
**停留帧在 m=60**（表达量掉到 40%，性状开始异常）。
状态：m<50「表达基本正常」；m≥60「表达不足，性状改变」；m=100「完全沉默」。

**例题**：「同一卵双胞胎为什么性状可能有差异？」答案：基因相同，但环境因素与表观遗传修饰（如 DNA 甲基化）不同，导致基因表达不同。
**六问**：① 基因控制性状的两条途径；② 白化病属于哪条途径；③ 镰状细胞贫血属于哪条；④ 表观遗传改变碱基序列吗；⑤ 一个基因只控制一个性状吗；⑥ 环境能影响性状吗。
**易错**：✗ 基因都通过控制酶来控制性状 / ✗ 表观遗传是基因突变 / ✗ 一个基因只对应一个性状 / ✗ 同卵双胞胎性状完全相同 / ✗ 甲基化改变了碱基序列 / ✗ 环境不影响基因表达。
