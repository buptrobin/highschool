# 本节规格（只读这一节，不要读 SPEC.md 全文）

## bx2-c4-s1 基因指导蛋白质的合成

**课本原话**
1. 转录：以 DNA 的一条链为模板，合成 RNA 的过程。
2. 翻译：以 mRNA 为模板，在核糖体上合成蛋白质的过程。
3. 密码子：mRNA 上决定 1 个氨基酸的 3 个相邻碱基；tRNA 上的反密码子与之互补配对。

**三个扣分点**：转录的模板是 DNA 的**一条链**（不是两条）；**密码子在 mRNA 上**、反密码子在 tRNA 上（别写反）；密码子有 64 种，其中 3 种是终止密码子。

**四张图**：① 转录过程（DNA→mRNA）；② 翻译过程（核糖体沿 mRNA 移动）；③ 密码子表与反密码子的配对；④ 肽链合成中的脱水缩合。

**互动模型**：滑块＝肽链中的氨基酸数 aa（5–100，step 5）
```js
mrna  = aa * 3;         // 至少需要的 mRNA 碱基数（不含终止密码子）
trna  = aa;             // tRNA 搬运次数
water = aa - 1;         // 脱去的水分子数
```
`cases`：`{v:20,eq:{mrna:60,trna:20}}`、`{v:50,eq:{mrna:150,trna:50}}`、`{v:100,eq:{mrna:300,water:99}}`。
Autopilot：`[{t:0,v:5},{t:1.2,v:5},{t:4,v:50},{t:6.5,v:50},{t:9,v:100},{t:11,v:70},{t:13,v:5}]`，keys `[5,50,70,100]`。
**停留帧在 aa=50**（mRNA 150 个碱基、tRNA 搬 50 次、脱 49 分子水）。
状态：aa 越大「mRNA 越长、tRNA 搬运次数越多」。

**例题**：「某 mRNA 上有 300 个碱基，翻译成的肽链最多含多少个氨基酸？脱去多少分子水？」答案：300÷3=100 个（终止密码子不编码氨基酸，实际少于 100）；脱水 100−1=99 个。
**六问**：① 转录和翻译的模板分别是什么；② 密码子和反密码子在哪；③ 密码子有多少种；④ 终止密码子编码氨基酸吗；⑤ 一个 mRNA 能结合几个核糖体；⑥ 转录在哪进行、翻译在哪进行。
**易错**：✗ 转录以两条链为模板 / ✗ 密码子在 tRNA 上 / ✗ 64 种密码子都编码氨基酸 / ✗ 1 个氨基酸对应 1 个碱基 / ✗ 翻译在细胞核进行 / ✗ 多肽链脱水数算成 n。
