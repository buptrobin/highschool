# 本节规格（只读这一节，不要读 SPEC.md 全文）

## bx2-c5-s2 染色体变异

**课本原话**
1. 染色体变异包括染色体结构变异（缺失、重复、倒位、易位）和染色体数目变异。
2. 染色体数目变异包括个别染色体增减和以染色体组为单位成倍增减。
3. 体细胞中含有三个或三个以上染色体组的个体叫多倍体；体细胞中含有本物种配子染色体数目的个体叫单倍体。

**三个扣分点**：**单倍体**看的是「本物种配子染色体数」，不是「含一个染色体组」（六倍体小麦的单倍体有 3 个组）；三倍体**高度不育**（联会紊乱）；结构变异 4 类要分清。

**四张图**：① 四种结构变异（缺失、重复、倒位、易位）；② 染色体组与倍性（1、2、3、4 组）；③ 单倍体、二倍体、多倍体的判定；④ 三倍体不育与无子西瓜。

**互动模型**：滑块＝体细胞中染色体组数 n（1–6，step 1）
```js
sets = n;
kind = n === 1 ? 1 : n === 2 ? 2 : 3;      // 1 单倍体 2 二倍体 3 多倍体
fert = n > 1 && n % 2 === 0 ? 1 : 0;       // 偶数组可育，奇数组联会紊乱
```
`cases`：`{v:1,eq:{sets:1,fert:0}}`、`{v:2,eq:{sets:2,fert:1}}`、`{v:3,eq:{sets:3,fert:0}}`、`{v:4,eq:{sets:4,fert:1}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:2},{t:6.5,v:2},{t:9,v:3},{t:11,v:4},{t:13,v:1}]`，keys `[1,2,3,4]`。
**停留帧在 n=3**（三倍体：高度不育，无子西瓜的原理）。
状态：n=1「单倍体，高度不育」；n 为偶数「可育」；n 为奇数（≥3）「联会紊乱，不育」。

**例题**：「六倍体小麦的配子含几个染色体组？由配子直接发育成的植株叫什么？」答案：配子含 3 个染色体组；由配子直接发育成的个体叫单倍体（虽然含 3 个组）。
**六问**：① 结构变异有哪四类；② 单倍体一定只有一个染色体组吗；③ 三倍体为什么不育；④ 多倍体怎么形成；⑤ 染色体变异在显微镜下可见吗；⑥ 单倍体育种有什么优点。
**易错**：✗ 单倍体只含一个染色体组 / ✗ 三倍体可育 / ✗ 倒位与易位混 / ✗ 染色体变异是基因突变 / ✗ 多倍体都不能繁殖 / ✗ 无子西瓜是三倍体所以无子（其实是不育）。
