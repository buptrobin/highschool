## bx2-c3-s4 基因通常是有遗传效应的DNA片段

**课本原话**
1. 基因通常是有遗传效应的 DNA 片段。
2. 一个 DNA 分子上有许多个基因，基因在染色体上呈线性排列。
3. 基因中的遗传信息蕴藏在 4 种碱基的排列顺序之中。

**三个扣分点**：基因是**有遗传效应**的片段（不是任意一段 DNA）；「通常」是因为少数病毒基因由 RNA 构成；真核基因有内含子，编码序列不连续。

**四张图**：① 基因与 DNA 的关系（DNA 分子上多个基因 + 非基因片段）；② 4 种碱基的排列承载信息；③ 3 个碱基决定 1 个氨基酸（编码关系）；④ 真核基因的内含子与外显子。

**互动模型**：滑块＝基因的碱基对数 L（300–3000，step 100）
```js
aa    = L / 3;                 // 最多编码的氨基酸数（3 个碱基 1 个）
mrna  = L;                     // 对应的 mRNA 碱基数
water = aa - 1;                // 脱水数
```
`cases`：`{v:300,eq:{aa:100}}`、`{v:900,eq:{aa:300}}`、`{v:3000,eq:{aa:1000}}`。
Autopilot：`[{t:0,v:300},{t:1.2,v:300},{t:4,v:900},{t:6.5,v:900},{t:9,v:3000},{t:11,v:1500},{t:13,v:300}]`，keys `[300,900,1500,3000]`。
**停留帧在 L=900**（最多编码 300 个氨基酸，最标准的一格）。
状态：L 越大「编码的氨基酸越多」；真核基因含内含子时实际更少。

**例题**：「某基因含 900 个碱基对，最多能编码多少个氨基酸？」答案：900÷3=300 个（若含内含子则少于 300）。
**六问**：① 基因与 DNA 是什么关系；② 为什么说「通常」；③ 3 个碱基为什么对应 1 个氨基酸；④ 内含子算什么；⑤ 基因的遗传信息存在哪里；⑥ 一个 DNA 上有几个基因。
**易错**：✗ 基因就是 DNA 分子 / ✗ 任意一段 DNA 都是基因 / ✗ 1 个碱基对应 1 个氨基酸 / ✗ 基因都是 DNA 片段（RNA 病毒）/ ✗ 内含子也编码氨基酸 / ✗ 一个 DNA 只有一个基因。
