## bx2-c1-s1 孟德尔的豌豆杂交实验（一）

**课本原话**
1. 孟德尔以豌豆为材料，进行了一对相对性状的杂交实验，F₁ 全部表现为显性性状，F₂ 中显性∶隐性≈3∶1。
2. 生物体遗传因子成对存在；形成配子时，成对的遗传因子彼此分离，分别进入不同的配子中。
3. 受精时，雌雄配子随机结合。

**三个扣分点**：3∶1 是**统计**结果，样本少时可能偏差；F₁ 只表现显性但**同时含隐性遗传因子**；测交用隐性纯合子，后代 1∶1。

**四张图**：① 一对相对性状的杂交过程（P→F₁→F₂）；② 遗传因子分离的图解（配子只带一个）；③ 棋盘法写 F₂ 的 3 种基因型；④ 测交验证（隐性纯合子）。

**互动模型**：滑块＝连续自交代数 n（1–5，从 Aa 开始，每代自交）
```js
het  = Math.pow(0.5, n);              // 杂合子 Aa 的比例
dom  = 0.5 + het / 2;                 // 显性表现型比例 = AA + Aa
rec  = (1 - het) / 2;                 // 隐性 aa 比例
```
`cases`：`{v:1,eq:{het:0.5,dom:0.75}}`、`{v:2,eq:{het:0.25,dom:0.625}}`、`{v:4,eq:{het:0.0625,dom:0.53125}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:4},{t:6.5,v:4},{t:9,v:2},{t:11,v:5},{t:13,v:1}]`，keys `[1,2,4,5]`。
**停留帧在 n=4**（杂合子只剩 6.25%，显性∶隐性已从 3∶1 滑到约 1.06∶1）。
状态：n=1「F₂ 显隐 3∶1」；n≥2「连续自交：杂合子逐代减半，纯合子越来越多」。

**例题**：「豌豆高茎（D）对矮茎（d）显性，Dd 自交得 F₁。① F₁ 基因型与比例？② F₁ 中高茎：矮茎？」答案：① DD∶Dd∶dd=1∶2∶1；② 高茎（DD+Dd）∶矮茎=3∶1。
**六问**：① 3∶1 为什么是统计规律；② F₁ 表现高茎说明它不含 d 吗；③ 测交为什么用隐性纯合子；④ 自交与杂交结果为什么不同；⑤ 连续自交杂合子怎么变；⑥ 分离定律的实质发生在哪个时期。
**易错**：✗ 3∶1 每胎都严格成立 / ✗ F₁ 高茎就说基因型是 DD / ✗ 测交对方用显性纯合 / ✗ 分离定律说成配子自由组合 / ✗ 把表现型和基因型混为一谈 / ✗ 认为自交与自由交配结果一样。

## bx2-c1-s2 孟德尔的豌豆杂交实验（二）

**课本原话**
1. F₁ 自交，F₂ 出现 4 种表现型，数量比接近 9∶3∶3∶1。
2. 控制不同性状的遗传因子的分离和组合是互不干扰的——形成配子时，决定同一性状的成对遗传因子彼此分离，决定不同性状的遗传因子自由组合。
3. 自由组合定律的实质：非同源染色体上的非等位基因自由组合。

**三个扣分点**：9∶3∶3∶1 需要**两对基因独立**（位于非同源染色体上）；自由组合发生在**减数第一次分裂后期**；9∶3∶3∶1 的变形（9∶7、15∶1）仍是自由组合。

**四张图**：① 两对相对性状杂交到 F₂ 的 4 种表现型；② 棋盘法 16 格；③ 配子种类 2ⁿ 的来源；④ 9∶3∶3∶1 的常见变形。

**互动模型**：滑块＝独立遗传的基因对数 n（1–4）
```js
gam  = Math.pow(2, n);     // 配子种类
phe  = Math.pow(2, n);     // F₂ 表现型种类
geno = Math.pow(3, n);     // F₂ 基因型种类
comb = Math.pow(4, n);     // 棋盘格数
```
`cases`：`{v:1,eq:{gam:2,phe:2,geno:3}}`、`{v:2,eq:{gam:4,phe:4,geno:9}}`、`{v:3,eq:{gam:8,phe:8,geno:27}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:2},{t:6.5,v:2},{t:9,v:4},{t:11,v:3},{t:13,v:1}]`，keys `[1,2,3,4]`。
**停留帧在 n=2**（配子 4 种、F₂ 基因型 9 种、表现型 4 种、棋盘 16 格，即 9∶3∶3∶1 那一页）。
状态：n=2「两对基因独立，F₂ 表现型 4 种」；n=3「三对基因，8 种表现型」。

**例题**：「黄色圆粒（YyRr）自交，求 F₂ 中黄色圆粒的比例与纯合子比例。」答案：F₂ 表现型 9∶3∶3∶1，黄色圆粒占 9/16；纯合子（YYRR、YYrr、yyRR、yyrr）占 4/16=1/4。
**六问**：① 9∶3∶3∶1 一定出现吗；② 与分离定律什么关系；③ 棋盘格数怎么来的；④ 两对基因连锁还会是 9∶3∶3∶1 吗；⑤ F₂ 中重组型比例是多少；⑥ 怎么验证自由组合定律。
**易错**：✗ 所有两对性状都 9∶3∶3∶1 / ✗ 自由组合发生在减数第二次分裂 / ✗ 把 9∶7 当成不遵循自由组合 / ✗ 配子种类算成 n 种 / ✗ 纯合子比例算成 1/16 / ✗ 两对基因在同一对染色体上也套 9∶3∶3∶1。

## bx2-c2-s1 减数分裂和受精作用

**课本原话**
1. 减数分裂是进行有性生殖的生物，在产生成熟生殖细胞时进行的染色体数目减半的细胞分裂。
2. 减数分裂过程中，染色体复制一次，细胞连续分裂两次，结果成熟生殖细胞中的染色体数目比原始生殖细胞减少一半。
3. 受精作用使受精卵中的染色体数目又恢复到体细胞的数目，其中一半来自父方、一半来自母方。

**三个扣分点**：复制**一次**、分裂**两次**；减数第二次分裂后期**着丝粒分裂**使染色体数暂时加倍（DNA 数不变）；减Ⅰ后期同源染色体分离，减Ⅱ后期姐妹染色单体分离。

**四张图**：① 减数分裂全过程（染色体数与 DNA 数曲线）；② 减Ⅰ后期同源染色体分离；③ 减Ⅱ后期着丝粒分裂、染色体数暂时加倍；④ 受精作用恢复染色体数。

**互动模型**：滑块＝减数分裂进程 p（0–100%，step 5），体细胞 2n=4（4 条染色体）
```js
chrom: p<75 ? 4 : p<88 ? 2 : p<97 ? 4 : 2;    // 2n=4：减Ⅰ末减半为 2，减Ⅱ后期暂时回到 4
dna:   p<20 ? (4 + 4 * p / 20) : p<75 ? 8 : p<97 ? 4 : 2;
```
实现要点（**按每个细胞数，2n=4**）：DNA 在间期由 4 复制到 8（0–20%），减Ⅰ末（75%）降到 4，减Ⅱ末（100%）降到 2；染色体数在减Ⅰ全程 4，减Ⅰ末减半为 2（75%），减Ⅱ后期着丝粒分裂时暂时回到 4（88–97%），配子为 2。
`cases`：`{v:30,eq:{chrom:4,dna:8}}`、`{v:93,eq:{chrom:4,dna:4}}`、`{v:100,eq:{chrom:2,dna:2}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:93},{t:6.5,v:93},{t:9,v:100},{t:11,v:55},{t:13,v:0}]`，keys `[0,55,93,100]`。
**停留帧在 p=93**（减Ⅱ后期：染色体由 2 暂时加倍到 4，DNA 仍是 4——最容易被扣分的一格）。
状态：p<20「间期：DNA 正在复制」；55% 左右「减Ⅰ后期：同源染色体分离」；93%「减Ⅱ后期：着丝粒分裂」；100%「配子：染色体减半」。

**例题**：「某动物体细胞 2n=4，问减数第二次分裂后期细胞内染色体数与 DNA 数。」答案：染色体 4 条（减Ⅰ末减半为 2，着丝粒分裂后暂时加倍回到 4），DNA 4 个（复制后减半过一次）。
**六问**：① 减数分裂复制几次分裂几次；② 染色体数目减半发生在哪个时期；③ 减Ⅱ后期染色体为什么加倍；④ 同源染色体什么时候分离；⑤ 受精作用的意义；⑥ 姐妹染色单体何时分开。
**易错**：✗ 减数分裂复制两次 / ✗ 染色体减半发生在减Ⅱ / ✗ 减Ⅱ后期染色体数仍是 n / ✗ 减Ⅱ有同源染色体分离 / ✗ 姐妹染色单体在减Ⅰ分开 / ✗ 受精卵染色体全部来自父方。

## bx2-c2-s2 基因在染色体上

**课本原话**
1. 萨顿发现基因和染色体行为存在着明显的平行关系，提出基因位于染色体上的假说。
2. 摩尔根用果蝇杂交实验证明了基因在染色体上。
3. 一条染色体上有许多个基因，基因在染色体上呈线性排列。

**三个扣分点**：类比推理只是**假说**，摩尔根才是**证明**；一条染色体上有多个基因（不是一对一）；同源染色体上等位基因位置相同。

**四张图**：① 基因与染色体行为的平行关系表；② 摩尔根果蝇实验（红眼×白眼）；③ 基因在染色体上线性排列；④ 同源染色体与等位基因的位置。

**互动模型**：滑块＝两基因间的图距 d（0–50 cM，step 1）
```js
cross = d / 100;                            // 交换率（示意：1 cM ≈ 1% 交换）
parental = (1 - cross) / 2;                 // 每种亲本型比例
recomb   = cross / 2;                       // 每种重组型比例
linked = d < 50 ? 1 : 0;                    // 图距 50 cM 时表现为独立
```
`cases`：`{v:0,eq:{cross:0,linked:1}}`、`{v:20,eq:{cross:0.2,recomb:0.1}}`、`{v:50,eq:{cross:0.5,linked:0}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:20},{t:6.5,v:20},{t:9,v:50},{t:11,v:35},{t:13,v:0}]`，keys `[0,20,35,50]`。
**停留帧在 d=20**（交换率 20%，亲本型各 40%、重组型各 10%——连锁的典型数字）。
状态：d<50「两基因连锁，交换率 <50%」；d=50「表现如独立（自由组合）」。

**例题**：「果蝇灰身长翅（BbVv）测交，后代灰长 40%、黑残 40%、灰残 10%、黑长 10%，说明什么？」答案：亲本型远多于重组型，说明 B 与 V 在同一对染色体上（连锁）；交换率 =（10%+10%）=20%，图距约 20 cM。
**六问**：① 萨顿与摩尔根各做了什么；② 一条染色体有几个基因；③ 连锁遗传为什么不遵循自由组合；④ 交换率与图距的关系；⑤ 等位基因在什么位置；⑥ 性染色体上的基因也线性排列吗。
**易错**：✗ 萨顿实验证明了基因在染色体上 / ✗ 一条染色体只有一个基因 / ✗ 连锁基因仍写 9∶3∶3∶1 / ✗ 交换率可以等于 60% / ✗ 同源染色体上基因都相同 / ✗ 把图距单位当百分数直接相加。

## bx2-c2-s3 伴性遗传

**课本原话**
1. 位于性染色体上的基因，其遗传上总是和性别相关联，这种现象叫做伴性遗传。
2. 红绿色盲基因位于 X 染色体上，Y 染色体上没有相应的等位基因，属于伴 X 隐性遗传。
3. 男性患者多于女性患者；女性患者的父亲和儿子一定患病。

**三个扣分点**：X 隐性病**男性多于女性**（因为男性只有一条 X）；男性患者的致病基因**只传给女儿**；书写基因型必须带 X/Y（如 XbY），不能只写 Bb。

**四张图**：① X、Y 染色体的同源与非同源区段；② 伴 X 隐性的交叉遗传（外祖父→母亲→外孙）；③ 男女发病率对比；④ 伴 X 显性与伴 Y 遗传的区别。

**互动模型**：滑块＝人群中致病基因 b 的频率 q（0.01–0.5，step 0.01）
```js
male   = q;                    // 男性患病率（只有一条 X）
female = q * q;                // 女性患病率（两条 X 都带 b）
carrier = 2 * q * (1 - q);     // 女性携带者比例
ratio  = q > 0 ? q / (q * q) : 0;   // 男女患病率之比 = 1/q
```
`cases`：`{v:0.1,eq:{male:0.1,female:0.01}}`、`{v:0.2,eq:{male:0.2,female:0.04}}`、`{v:0.5,eq:{male:0.5,female:0.25}}`。
Autopilot：`[{t:0,v:0.01},{t:1.2,v:0.01},{t:4,v:0.1},{t:6.5,v:0.1},{t:9,v:0.5},{t:11,v:0.3},{t:13,v:0.01}]`，keys `[0.01,0.1,0.3,0.5]`。
**停留帧在 q=0.1**（男 10%、女 1%，男性是女性的 10 倍——伴 X 隐性最核心的结论）。
状态：q 越小「男女患病率差距越大」；q=0.5「男女差距消失」。

**例题**：「一对正常夫妇生了一个色盲儿子，再生一个孩子是色盲的概率？」答案：父亲 XBY、母亲 XBXb，再生男孩 50% 患病、女孩全部正常（女儿可能携带）；按性别算：男孩 1/2×1/2=1/4 患病。
**六问**：① 为什么男性患者多；② 男性患者的致病基因来自谁；③ 女性患者的父亲一定患病吗；④ 色盲基因在 Y 上还是 X 上；⑤ 携带者表现型正常吗；⑥ 伴 X 显性有什么特点。
**易错**：✗ 女性发病率高于男性 / ✗ 男性患者把致病基因传给儿子 / ✗ 基因型写成 Bb / ✗ 携带者女性是患者 / ✗ 伴 Y 遗传男女都有 / ✗ 母亲色盲儿子一定色盲（其实一定患病，但女儿不一定）。

## bx2-c3-s1 DNA是主要的遗传物质

**课本原话**
1. 格里菲思的肺炎链球菌体内转化实验说明存在「转化因子」。
2. 艾弗里等人的实验证明 DNA 才是使 R 型细菌产生稳定遗传变化的物质。
3. 赫尔希和蔡斯的噬菌体侵染细菌实验：DNA 在亲子代间具有连续性，蛋白质不是遗传物质。

**三个扣分点**：**DNA 是主要的遗传物质**（不是「唯一」，少数病毒以 RNA 为遗传物质）；噬菌体实验**不能**证明蛋白质不是遗传物质（只证明了 DNA 是）；保温时间过短或过长都会影响结果。

**四张图**：① 格里菲思四组实验（R、S、加热杀死的 S、混合）；② 艾弗里分离提纯（DNA、蛋白质、DNA 酶处理）；③ 噬菌体侵染与搅拌离心（32P、35S 两组）；④ 保温时间对结果的影响曲线。

**互动模型**：滑块＝保温时间 t（0–30 min，step 2）
```js
p32 = t <= 15 ? 20 + 4 * t : 80 - 2 * (t - 15);   // 32P 组：沉淀物放射性占比%
p35 = 20;                                          // 35S 组：沉淀物始终低
```
`cases`：`{v:0,eq:{p32:20}}`、`{v:15,eq:{p32:80}}`、`{v:30,eq:{p32:50}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:15},{t:6.5,v:15},{t:9,v:30},{t:11,v:24},{t:13,v:0}]`，keys `[0,15,24,30]`。
**停留帧在 t=15**（沉淀物放射性最高 80%——侵染刚完成、细菌还没裂解）。
状态：t<10「侵染不充分，上清液放射性偏高」；15 左右「最适」；t>22「细菌裂解，子代噬菌体释放，上清液又升高」。

## bx2-c3-s2 DNA的结构

**课本原话**
1. DNA 由两条脱氧核苷酸链组成，这两条链按反向平行方式盘旋成双螺旋结构。
2. 磷酸和脱氧核糖交替连接，排列在外侧，构成基本骨架；碱基排列在内侧。
3. 碱基通过氢键连接成碱基对：A 与 T 配对（2 个氢键）、G 与 C 配对（3 个氢键）。

**三个扣分点**：A=T、G=C 是**碱基数量**关系（A+G=T+C）；两条链**反向平行**（不是同向）；G-C 对越多，DNA 越稳定（氢键多）。

**四张图**：① 双螺旋的三部分（磷酸、脱氧核糖、碱基）；② 碱基互补配对（A-T 两个氢键、G-C 三个氢键）；③ A=T、G=C 的数量关系；④ GC 含量与稳定性的关系。

**互动模型**：滑块＝GC 含量 gc（0–100%，step 5），以 100 个碱基对计
```js
A  = (100 - gc) / 2;                  // A = T
G  = gc / 2;                          // G = C
hb = 2 * A + 3 * G;                   // 100 个碱基对的氢键总数
ratio = gc === 0 ? 0 : A / G;         // A 与 G 的比
```
`cases`：`{v:40,eq:{A:30,G:20}}`、`{v:60,eq:{A:20,G:30}}`、`{v:50,eq:{hb:125}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:50},{t:6.5,v:50},{t:9,v:100},{t:11,v:70},{t:13,v:0}]`，keys `[0,50,70,100]`。
**停留帧在 gc=50**（A=T=G=C=25，氢键 125 个，最「对称」的一格）。
状态：gc 越高「G-C 对越多，氢键越多，DNA 越稳定」。

**例题**：「某 DNA 分子中 A 占 28%，求 G 的比例与 (A+T)/(G+C)。」答案：A=T=28%，G=C=(100−56)/2=22%；(A+T)/(G+C)=56/44≈1.27。
**六问**：① A 与 T 为什么一定相等；② 两条链方向相同吗；③ 氢键数怎么算；④ GC 含量高说明什么；⑤ 双螺旋的骨架是什么；⑥ 一条链的 A 与另一条链的 T 相等吗。
**易错**：✗ A+G=A+T / ✗ 两条链同向平行 / ✗ G-C 两个氢键 / ✗ GC 高说明不稳定 / ✗ 骨架由碱基构成 / ✗ 把碱基对数量当碱基数量。

## bx2-c3-s3 DNA的复制

**课本原话**

3. 半保留复制：新合成的每个 DNA 分子中，都保留了原来 DNA 的一条链。

**三个扣分点**：**半保留**（每个子代 DNA 一条旧链一条新链），不是全保留；复制是**边解旋边复制**（不是先全解开再复制）；复制 n 次得到 2ⁿ 个 DNA 分子。

**四张图**：① 解旋与复制叉；② 半保留复制的两代结果；③ 复制 n 次的分子数 2ⁿ；④ 15N 标记实验（密度梯度离心）。

**互动模型**：滑块＝复制次数 n（1–5，初始 1 个双链都被 15N 标记，在 14N 中复制）
```js

pure   = total - 2;             // 纯 14N 分子
```
`cases`：`{v:1,eq:{total:2,hybrid:2,pure:0}}`、`{v:3,eq:{total:8,hybrid:2,pure:6}}`、`{v:5,eq:{total:32,pure:30}}`。

**停留帧在 n=3**（8 个分子里恰好 2 个带 15N——半保留复制的关键数字）。
状态：任何 n「含 15N 的分子恒为 2 个」。

**例题**：「将 15N 标记的 DNA 放在 14N 培养基中复制 3 次，含 15N 的 DNA 分子有几个？纯 14N 的呢？」答案：总数 2³=8 个；含 15N 的 2 个（各保留一条旧链）；纯 14N 的 6 个。
**六问**：① 半保留是什么意思；② 复制 3 次共需要多少原料；③ 含 15N 的分子为什么总是 2 个；④ 复制方向是单向还是双向；⑤ 复制出错会怎样；⑥ 边解旋边复制有什么好处。
**易错**：✗ 全保留复制 / ✗ 含 15N 的分子随复制次数增加 / ✗ 复制 3 次得到 3 个分子 / ✗ 先完全解旋再复制 / ✗ 子代 DNA 全是新链 / ✗ 复制不需要能量。

## bx2-c4-s2 基因表达与性状的关系

## bx2-c5-s1 基因突变和基因重组

**课本原话**
1. 基因突变是指 DNA 分子中发生碱基的替换、增添或缺失，而引起的基因碱基序列的改变。
2. 基因突变产生新基因，是生物变异的根本来源。
3. 基因重组是指在生物体进行有性生殖的过程中，控制不同性状的基因的重新组合。

**三个扣分点**：**替换**只改一个密码子；**增添/缺失**若不是 3 的倍数会造成**移码突变**（后面全部改变）；基因突变是**不定向**的、基因重组**不产生新基因**。

**四张图**：① 三种突变方式（替换、增添、缺失）；② 移码突变与整码突变对比；③ 基因重组的来源（自由组合、交叉互换）；④ 突变与重组的区别表。

**互动模型**：滑块＝插入的碱基数 k（0–6，step 1），基因共 900 bp，插入点在 300 bp 处
```js
shifted = k % 3 === 0 ? 0 : 1;                 // 是否移码
changed = k === 0 ? 0 : (shifted ? 200 : k / 3); // 受影响的氨基酸数
```
`cases`：`{v:0,eq:{changed:0}}`、`{v:3,eq:{changed:1}}`、`{v:1,eq:{changed:200}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:1},{t:6.5,v:1},{t:9,v:3},{t:11,v:2},{t:13,v:0}]`，keys `[0,1,2,3]`。
**停留帧在 k=1**（插 1 个碱基就移码，后面 200 个氨基酸全部改变）。
状态：k=0「没有突变」；k 是 3 的倍数「整码插入，影响局部」；否则「移码突变，影响巨大」。

**例题**：「某基因插入 1 个碱基对，会导致什么后果？插入 3 个呢？」答案：插入 1 个 → 移码突变，插入点之后的所有密码子改变，蛋白质结构可能完全改变；插入 3 个 → 多编码 1 个氨基酸，其余不变，影响较小。
**六问**：① 三种突变方式哪种影响最大；② 移码突变为什么严重；③ 基因重组产生新基因吗；④ 基因突变的方向；⑤ 突变一定导致性状改变吗；⑥ 基因重组发生在什么时候。
**易错**：✗ 缺失 1 个碱基只影响 1 个氨基酸 / ✗ 基因重组产生新基因 / ✗ 基因突变是定向的 / ✗ 突变一定改变性状（密码子简并）/ ✗ 交叉互换属于基因突变 / ✗ 突变只发生在分裂期。

## bx2-c5-s2 染色体变异

## bx2-c5-s3 人类遗传病

**课本原话**
1. 人类遗传病通常是指由遗传物质改变而引起的人类疾病，主要分为单基因遗传病、多基因遗传病和染色体异常遗传病。
2. 单基因遗传病受一对等位基因控制，如多指、白化病、红绿色盲。
3. 通过遗传咨询和产前诊断等手段，可在一定程度上预防遗传病的产生。

**三个扣分点**：21 三体综合征是**染色体异常**（不是单基因）；多基因遗传病**易受环境影响**、常表现家族聚集；近亲结婚提高**隐性**遗传病的发病风险。

**四张图**：① 三类遗传病的划分；② 单基因病的四种遗传方式；③ 21 三体与染色体异常；④ 近亲结婚的风险放大。

**互动模型**：滑块＝人群中致病基因频率 q（0.01–0.2，step 0.01），常染色体隐性病
```js
disease = q * q;                  // 患病率
carrier = 2 * q * (1 - q);        // 携带者比例
ratio   = disease > 0 ? carrier / disease : 0;  // 携带者/患者
```
`cases`：`{v:0.01,eq:{disease:0.0001,carrier:0.0198}}`、`{v:0.1,eq:{disease:0.01,carrier:0.18}}`、`{v:0.2,eq:{disease:0.04,carrier:0.32}}`。
Autopilot：`[{t:0,v:0.01},{t:1.2,v:0.01},{t:4,v:0.1},{t:6.5,v:0.1},{t:9,v:0.2},{t:11,v:0.15},{t:13,v:0.01}]`，keys `[0.01,0.1,0.15,0.2]`。
**停留帧在 q=0.1**（患病 1%，携带者 18%，携带者是患者的 18 倍——隐性病难被发现的根源）。
状态：q 越小「携带者相对越多，越难发现」。

**例题**：「某常染色体隐性病在人群中的发病率为 1/10000，求致病基因频率与携带者频率。」答案：q²=1/10000，q=1/100；携带者 2q(1−q)≈2/100。
**六问**：① 三类遗传病怎么分；② 21 三体属于哪类；③ 近亲结婚为什么危险；④ 多基因病为什么易受环境影响；⑤ 产前诊断包括哪些；⑥ 携带者有症状吗。
**易错**：✗ 21 三体是单基因病 / ✗ 近亲结婚增加显性病风险 / ✗ 多基因病不受环境影响 / ✗ 携带者就是患者 / ✗ 遗传病都由基因突变引起 / ✗ 产前诊断能治疗遗传病。

## bx2-c6-s1 生物有共同祖先的证据

**课本原话**
1. 化石是研究生物进化最直接、最重要的证据。
2. 比较解剖学、胚胎学、细胞和分子水平的证据都支持生物有共同祖先。
3. 亲缘关系越近的生物，在分子水平上的差异越小。

**三个扣分点**：化石是**最直接**证据但不是唯一证据；分子水平比较的是**同种蛋白质/基因的序列差异**；差异越小说明亲缘越近、分化越晚。

**四张图**：① 地层中的化石按年代排列；② 比较解剖学（同源器官）；③ 胚胎发育早期相似；④ 分子水平（细胞色素 c 序列差异）。

**互动模型**：滑块＝两种生物细胞色素 c 的氨基酸差异数 d（0–40，共 104 个氨基酸）
```js
same   = (104 - d) / 104;            // 序列相同比例
degree = d <= 5 ? 3 : d <= 20 ? 2 : 1; // 3 近 2 中 1 远
```
`cases`：`{v:0,eq:{same:1}}`、`{v:20,eq:{same:0.8077}}`、`{v:40,eq:{same:0.6154}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:20},{t:6.5,v:20},{t:9,v:40},{t:11,v:30},{t:13,v:0}]`，keys `[0,20,30,40]`。
**停留帧在 d=0**（人与黑猩猩的细胞色素 c 完全相同——最有力的分子证据）。
状态：d≤5「亲缘关系很近」；d>20「亲缘关系较远」。

**例题**：「人、黑猩猩、猕猴的细胞色素 c 与人的差异分别是 0、0、1，说明什么？」答案：差异越小，亲缘关系越近；人与黑猩猩差异为 0，说明二者亲缘关系最近。
**六问**：① 最直接的证据是什么；② 同源器官说明什么；③ 胚胎学证据是什么；④ 分子水平比较什么；⑤ 差异小说明什么；⑥ 化石为什么能证明共同祖先。
**易错**：✗ 化石是唯一证据 / ✗ 分子比较比的是蛋白质含量 / ✗ 差异越大亲缘越近 / ✗ 同源器官功能一定相同 / ✗ 胚胎学证明个体发育重演系统发育（夸大）/ ✗ 共同祖先只靠化石就能证明。

## bx2-c6-s2 自然选择与适应的形成

**课本原话**
1. 达尔文的自然选择学说：过度繁殖、生存斗争、遗传变异、适者生存。
2. 适应是自然选择的结果；适应的形成是种群中有利变异逐代积累的过程。
3. 自然选择直接作用于个体的表现型。

**三个扣分点**：**自然选择作用于表现型，淘汰的是表现型**（不是直接改变基因）；变异是**不定向**的，选择是**定向**的；适应是**相对**的（环境一变可能不再适应）。

**四张图**：① 自然选择学说的四个要点；② 有利变异逐代积累；③ 选择压力与基因频率变化；④ 适应的相对性（尺蛾工业黑化）。

**互动模型**：滑块＝选择系数 s（0–1，step 0.05），有利等位基因初始频率 0.1，繁殖 10 代
```js
p = 0.1;
for (let i = 0; i < 10; i++) p = p * (1 + s) / (1 + s * p);
// s=0 → 0.1；s=0.5 → 0.865；s=1 → 0.989
```
`cases`：`{v:0,eq:{p:0.1}}`、`{v:0.5,eq:{p:0.865}}`、`{v:1,eq:{p:0.9913}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:0.5},{t:6.5,v:0.5},{t:9,v:1},{t:11,v:0.75},{t:13,v:0}]`，keys `[0,0.5,0.75,1]`。
**停留帧在 s=0.5**（10 代后有利基因从 10% 涨到 86.5%）。
状态：s=0「没有选择压力，频率不变」；s 越大「上升越快」。

**例题**：「工业污染后深色尺蛾比例迅速上升，如何用自然选择解释？」答案：深色变异本来就存在（不定向）；污染后深色个体不易被鸟发现（有利），自然选择保留了它们；有利变异逐代积累，深色基因频率上升（定向）。
**六问**：① 自然选择作用于基因还是表现型；② 变异方向是定向的吗；③ 为什么说适应是相对的；④ 选择压力为 0 会怎样；⑤ 自然选择创造新基因吗；⑥ 达尔文与拉马克的区别。
**易错**：✗ 自然选择直接改变基因 / ✗ 变异是定向的 / ✗ 适应是绝对的 / ✗ 自然选择产生新基因 / ✗ 用进废退属于达尔文学说 / ✗ 环境变化导致生物「主动」变异。

## bx2-c6-s3 种群基因组成的变化与物种的形成

**课本原话**
1. 种群是生物进化的基本单位；种群中全部个体所含有的全部基因叫基因库。
2. 基因频率：某个基因占该位点全部等位基因数的比率。
3. 突变和基因重组产生进化的原材料；自然选择使基因频率定向改变；隔离是物种形成的必要条件。

**三个扣分点**：进化的**基本单位是种群**不是个体；生物进化的**实质是基因频率的改变**（不是性状改变）；生殖隔离才是物种形成的标志。

**四张图**：① 种群与基因库；② 哈代-温伯格平衡（p²+2pq+q²=1）；③ 基因频率定向改变；④ 地理隔离与生殖隔离。

**互动模型**：滑块＝等位基因 A 的频率 p（0–1，step 0.05）
```js
AA = p * p;              // p²
Aa = 2 * p * (1 - p);    // 2pq
aa = (1 - p) * (1 - p);  // q²
```
`cases`：`{v:0.2,eq:{AA:0.04,Aa:0.32}}`、`{v:0.5,eq:{AA:0.25,Aa:0.5}}`、`{v:0.8,eq:{AA:0.64,Aa:0.32}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:0.5},{t:6.5,v:0.5},{t:9,v:1},{t:11,v:0.75},{t:13,v:0}]`，keys `[0,0.25,0.5,0.75,1]`。
**停留帧在 p=0.5**（杂合子达到最大值 50%，基因频率 0.5 时遗传多样性最高）。
状态：p=0 或 1「只有一个等位基因，多样性为 0」；p=0.5「杂合子最多」。

**例题**：「某人群中白化病发病率为 1/10000，求致病基因频率与携带者频率。」答案：q²=1/10000→q=1/100，p=99/100；携带者 2pq≈2/100。
**六问**：① 进化的基本单位是什么；② 进化的实质是什么；③ 基因频率怎么算；④ 哈代-温伯格的条件；⑤ 物种形成的标志；⑥ 地理隔离一定导致生殖隔离吗。
**易错**：✗ 进化的单位是个体 / ✗ 进化就是性状改变 / ✗ 基因型频率等于基因频率 / ✗ 地理隔离等于生殖隔离 / ✗ 突变决定进化方向 / ✗ 哈代-温伯格在自然选择下仍成立。

## bx2-c6-s4 协同进化与生物多样性的形成

**课本原话**
1. 不同物种之间、生物与无机环境之间在相互影响中不断进化和发展，这就是协同进化。
2. 生物多样性包括基因多样性（遗传多样性）、物种多样性和生态系统多样性。
3. 生物多样性是协同进化的结果。

**三个扣分点**：协同进化包括**生物与生物**和**生物与环境**两个方向；生物多样性有**三个层次**（基因、物种、生态系统）；捕食者与被捕食者相互选择，不是单向的。

**四张图**：① 协同进化（传粉昆虫与花）；② 捕食者与猎物相互选择；③ 生物多样性的三个层次；④ 物种数与多样性指数的关系。

**互动模型**：滑块＝群落中的物种数 S（2–12，step 1），假设各物种个体数相等
```js
h    = Math.log(S);       // Shannon 指数（均匀时 = lnS）
sim  = 1 - 1 / S;         // Simpson 指数（均匀时）
```
`cases`：`{v:2,eq:{h:0.6931,sim:0.5}}`、`{v:6,eq:{h:1.7918,sim:0.8333}}`、`{v:12,eq:{h:2.4849,sim:0.9167}}`。
Autopilot：`[{t:0,v:2},{t:1.2,v:2},{t:4,v:6},{t:6.5,v:6},{t:9,v:12},{t:11,v:8},{t:13,v:2}]`，keys `[2,6,8,12]`。
**停留帧在 S=6**（Shannon 指数 1.79、Simpson 0.83，中等群落的典型值）。
状态：S 越大「多样性越高」；但个体数极不均匀时会明显下降。

**例题**：「为什么说生物多样性是协同进化的结果？」答案：物种之间相互选择（如传粉昆虫与花），生物与环境相互改造，长期相互影响形成基因、物种、生态系统三个层次的多样性。
**六问**：① 协同进化包括哪两个方向；② 生物多样性三个层次；③ 捕食者会导致猎物灭绝吗；④ 为什么物种越多多样性越高；⑤ 均匀度低会怎样；⑥ 保护生物多样性保护的是什么。
**易错**：✗ 协同进化只有生物与生物 / ✗ 生物多样性只有物种多样性 / ✗ 捕食者单向选择猎物 / ✗ 物种多就一定多样性高（还要看均匀度）/ ✗ 多样性是偶然形成的 / ✗ 保护多样性只保护珍稀物种。
