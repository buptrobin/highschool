## xx3-c3-s3 基因工程的应用

**课本原话**
1. 基因工程在农业、医药、工业、环境保护等方面得到广泛应用。
2. 转基因抗虫作物通过导入抗虫基因，使作物自身产生抗虫物质。
3. 基因工程药物（如胰岛素、干扰素）通过工程菌发酵生产。

**三个扣分点**：转基因抗虫作物是**自身产生**抗虫物质（不是喷洒农药）；工程菌生产药物利用的是**微生物繁殖快**的优势；基因工程产品**不改变**原有营养成分的基本性质（安全性评价的起点）。

**四张图**：① 基因工程应用的四大领域；② 抗虫棉的原理；③ 工程菌生产人胰岛素的流程；④ 基因工程与育种速度的对比。

**互动模型**：滑块＝抗虫基因的表达量 e（0–100，相对单位，step 1）
```js
death = 100 * e / (e + 20);      // 害虫死亡率（%）
```
`cases`：`{v:20,eq:{death:50}}`、`{v:80,eq:{death:80}}`、`{v:5,eq:{death:20}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:20},{t:6.5,v:20},{t:9,v:100},{t:11,v:60},{t:13,v:0}]`，keys `[0,20,60,100]`。
**停留帧在 e=20**（害虫死亡率 50%，半最大效应：表达量再高，死亡率涨得越来越慢）。
状态：e<10「防效不足」；20–60「防效明显」；>80「接近饱和，收益递减」。

**例题**：「转基因抗虫棉为什么能减少农药使用？」答案：抗虫基因在棉株内表达，使棉株自身产生对害虫有毒性的物质，害虫取食后死亡或生长受阻，从而减少农药喷洒。
**六问**：① 基因工程有哪些应用领域；② 抗虫棉的原理；③ 工程菌为什么适合生产药物；④ 基因工程育种与杂交育种比有何优势；⑤ 转基因产品要不要评估安全性；⑥ 抗虫基因会不会影响人体。
**易错**：✗ 抗虫棉靠喷洒农药 / ✗ 工程菌生产药物没有优势 / ✗ 基因工程育种比杂交育种慢 / ✗ 转基因作物不需要安全评估 / ✗ 抗虫基因只在害虫体内起作用 / ✗ 转基因一定改变营养成分。
