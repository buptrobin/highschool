## xx3-c4-s2 关注生殖性克隆人

**课本原话**
1. 生殖性克隆是指将体细胞核移植到去核卵母细胞中，获得重构胚胎并植入母体，最终获得与供核个体遗传信息相同的个体。
2. 我国明确禁止生殖性克隆人，但不反对治疗性克隆的研究。
3. 生殖性克隆人面临严重的技术、伦理和社会问题。

**三个扣分点**：**生殖性克隆**（产生个体）与**治疗性克隆**（获得干细胞、不产生个体）要分清；生殖性克隆人**技术上成功率低、代价高**；我国**禁止生殖性克隆人**，对治疗性克隆按规定管理。

**四张图**：① 体细胞核移植的流程；② 生殖性克隆与治疗性克隆的分岔；③ 核移植成功率与尝试次数的关系；④ 生殖性克隆人的伦理问题清单。

**互动模型**：滑块＝核移植的成功率 s（5–50%，示意值，step 5）
```js
tries = 100 / s;                  // 期望需要尝试的次数
cost  = tries * 1.0;              // 需要消耗的卵母细胞（按每次 1 个，示意）
```
`cases`：`{v:10,eq:{tries:10}}`、`{v:25,eq:{tries:4}}`、`{v:50,eq:{tries:2}}`。
Autopilot：`[{t:0,v:50},{t:1.2,v:50},{t:4,v:25},{t:6.5,v:25},{t:9,v:5},{t:11,v:10},{t:13,v:50}]`，keys `[5,10,25,50]`。
**停留帧在 s=10**（成功率只有 10%：要尝试 10 次才可能成功，代价与伦理问题都在这一格显现）。
状态：s≥40「成功率较高，但仍不是常规技术」；20–40「成功率低」；<15「极低，代价巨大」。

**例题**：「生殖性克隆人和治疗性克隆的根本区别是什么？」答案：生殖性克隆要把重构胚胎植入母体、最终产生新的个体；治疗性克隆只是在体外培养获得胚胎干细胞用于治疗，不产生个体。
**六问**：① 生殖性克隆的流程；② 与治疗性克隆的区别；③ 为什么成功率低；④ 我国的态度；⑤ 有哪些伦理问题；⑥ 治疗性克隆有什么价值。
**易错**：✗ 两种克隆是一回事 / ✗ 生殖性克隆成功率高 / ✗ 我国支持生殖性克隆人 / ✗ 治疗性克隆会产生个体 / ✗ 克隆个体与供核者完全一样（还受环境影响）/ ✗ 克隆只是技术问题没有伦理问题。
