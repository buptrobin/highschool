## xx3-c3-s4 蛋白质工程的原理和应用

**课本原话**
1. 蛋白质工程是以蛋白质分子的结构规律及其与生物功能的关系为基础，通过基因修饰或基因合成，对现有蛋白质进行改造，或制造一种新的蛋白质。
2. 蛋白质工程的目标是改造蛋白质的结构，从而改变其功能。
3. 蛋白质工程最终要通过改造基因来实现，因此被称为「第二代基因工程」。

**三个扣分点**：蛋白质工程**先设计结构、再改基因**（方向与基因工程相反：基因工程是拿到基因看功能，蛋白质工程是想功能找结构）；**必须通过改造基因**实现（直接改蛋白质不能遗传）；中心法则在这里是**逆向使用**的。

**四张图**：① 天然蛋白质的合成方向与蛋白质工程的设计方向（反向）；② 蛋白质工程的四个步骤；③ 定点突变改变酶活性；④ 蛋白质工程与基因工程的对照。

**互动模型**：滑块＝定点突变的位点数 n（0–6，step 1）
```js
act = 100 * (2 - Math.exp(-n / 2));     // 酶的相对活性（%），改造越多越接近上限
```
`cases`：`{v:0,eq:{act:100}}`、`{v:1,eq:{act:139.4}}`、`{v:3,eq:{act:177.7}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:3},{t:6.5,v:3},{t:9,v:6},{t:11,v:4},{t:13,v:0}]`，keys `[0,1,3,6]`。
**停留帧在 n=3**（活性提到 177.7%：再改收益递减，且可能破坏结构——反直觉的「改多了反而不好」）。
状态：n=0「原酶」；1–3「明显提升」；>4「接近上限，继续改造风险增大」。

**例题**：「为什么说蛋白质工程是「第二代基因工程」，它必须先改造基因？」答案：蛋白质的功能由结构决定、结构由基因决定；直接改变蛋白质不能遗传，只有改造基因（或基因合成），才能让细胞持续产生改造后的蛋白质。
**六问**：① 蛋白质工程与基因工程的方向差别；② 为什么要改基因；③ 蛋白质工程的基本步骤；④ 定点突变的作用；⑤ 中心法则在这里怎么用；⑥ 蛋白质工程能创造新蛋白吗。
**易错**：✗ 蛋白质工程直接改造蛋白质即可遗传 / ✗ 与基因工程方向相同 / ✗ 只改结构不设目标 / ✗ 蛋白质工程不需要基因 / ✗ 改造位点越多越好 / ✗ 中心法则不能逆向使用。
