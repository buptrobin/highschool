## xx3-c4-s3 禁止生物武器

**课本原话**
1. 生物武器包括致病菌、病毒、生化毒剂以及经过基因重组的致病菌等。
2. 生物武器具有致病性强、传染性强、作用时间长、难以防治等特点。
3. 《禁止生物武器公约》禁止发展、生产和储存生物武器（我国是缔约国）。

**三个扣分点**：生物武器的**传染性强**（可在人群中扩散，这是与常规武器最大的不同）；**基因重组可能增强致病性**（技术滥用风险）；国际公约**禁止**发展、生产和储存，我国**是缔约国并严格履约**。

**四张图**：① 生物武器的种类；② 传播链与防控的难点；③ 传染性（R₀）与所需防控覆盖率的关系；④ 国际公约与我国的立场。

**互动模型**：滑块＝病原体基本传染数 R₀（1–18，step 1）
```js
need = (1 - 1 / R0) * 100;        // 阻断传播所需的人群免疫覆盖率（%）
hard = R0 >= 10 ? 1 : 0;          // 防控难度是否进入高位区间
```
`cases`：`{v:3,eq:{need:66.7}}`、`{v:12,eq:{need:91.7}}`、`{v:18,eq:{need:94.4}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:12},{t:6.5,v:12},{t:9,v:18},{t:11,v:15},{t:13,v:1}]`，keys `[1,3,12,18]`。
**停留帧在 R₀=12**（需要 91.7% 的人有免疫力才能阻断——生物武器「难以防治」的量化解释）。
状态：R₀<3「常规传染病水平」；3–10「需要高覆盖率」；>10「防控极难，接近消灭不掉」。

**例题**：「为什么生物武器被认为特别危险？」答案：致病性和传染性强，可在人群中快速扩散、作用时间长、难以防治；若利用基因重组增强致病性或抗药性，风险更大，因此被国际公约严格禁止。
**六问**：① 生物武器包括哪些；② 与常规武器最大的不同；③ 为什么难以防治；④ 国际公约禁止什么；⑤ 我国的态度；⑥ 基因技术被滥用有什么风险。
**易错**：✗ 生物武器只传染不致病 / ✗ 生物武器作用时间短 / ✗ 公约只禁止使用 / ✗ 我国不是缔约国 / ✗ 基因技术只能用于造福 / ✗ R₀ 越大越容易防控。
