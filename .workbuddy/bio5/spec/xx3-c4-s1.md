# 本节规格（只读这一节，不要读 SPEC.md 全文）

## xx3-c4-s1 转基因产品的安全性

**课本原话**
1. 转基因产品的安全性包括食品安全和生态安全两个方面。
2. 对转基因产品要进行科学的评估，包括实质等同原则、个案分析原则等。
3. 我国对转基因生物实行安全评价、标识等管理制度。

**三个扣分点**：安全性的两个方面（**食品安全**与**生态安全**）都要考虑；**基因漂移**是生态安全的核心担忧（外源基因转入野生近缘种）；评价原则是**个案分析**（不能一概而论「转基因都安全/都不安全」）。

**四张图**：① 食品安全与生态安全两个维度；② 基因漂移的路径；③ 隔离距离与外源基因漂移率的关系；④ 转基因标识制度。

**互动模型**：滑块＝种植区与野生近缘种之间的距离 d（0–1000 m，step 20）
```js
drift = 100 * Math.exp(-d / 200);    // 外源基因漂移率（%，示意）
```
`cases`：`{v:0,eq:{drift:100}}`、`{v:200,eq:{drift:36.8}}`、`{v:600,eq:{drift:5}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:200},{t:6.5,v:200},{t:9,v:1000},{t:11,v:600},{t:13,v:0}]`，keys `[0,200,600,1000]`。
**停留帧在 d=200**（漂移率降到 36.8%：距离是最直接的隔离手段，但并不能归零）。
状态：d<100「漂移率高，风险大」；100–400「明显下降」；>600「风险很低，但仍不为 0」。

**例题**：「为什么说转基因作物的生态安全要「个案分析」？」答案：不同转基因作物的外源基因、受体物种、种植环境、近缘野生种分布都不同，风险大小差异很大，必须逐个评价，不能一概而论。
**六问**：① 安全性包括哪两面；② 什么是基因漂移；③ 为什么是个案分析；④ 隔离距离有什么用；⑤ 转基因食品标识的意义；⑥ 实质等同原则指什么。
**易错**：✗ 转基因只考虑食品安全 / ✗ 基因漂移不会发生 / ✗ 所有转基因安全性一样 / ✗ 距离足够远就绝对安全 / ✗ 转基因产品不需要标识 / ✗ 个案分析就是逐个审批走形式。
