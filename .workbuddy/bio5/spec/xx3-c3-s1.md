# 本节规格（只读这一节，不要读 SPEC.md 全文）

## xx3-c3-s1 重组DNA技术的基本工具

**课本原话**
1. 限制酶能识别双链 DNA 分子的特定核苷酸序列，并在特定的位点切割 DNA。
2. DNA 连接酶能将 DNA 片段连接起来，恢复被限制酶切开的磷酸二酯键。
3. 基因进入受体细胞的载体必须能在受体细胞中复制并稳定保存，常用的是质粒。

**三个扣分点**：限制酶切割的是**磷酸二酯键**（不是氢键）；**DNA 连接酶**连接的是磷酸二酯键（不是碱基对）；三种工具缺一不可（**限制酶、DNA 连接酶、载体**）。

**四张图**：① 三种工具的分工；② 限制酶识别序列与黏性末端；③ DNA 连接酶的工作方式；④ 质粒作为载体的三个条件。

**互动模型**：滑块＝限制酶识别序列长度 n（4–8 bp，step 1，基因组按随机序列计）
```js
gap = Math.pow(4, n);            // 平均每多少个碱基出现一个切点
cuts = 1000000 / gap;            // 1 Mb 基因组中的切点数
```
`cases`：`{v:4,eq:{gap:256}}`、`{v:6,eq:{gap:4096}}`、`{v:8,eq:{gap:65536}}`。
Autopilot：`[{t:0,v:4},{t:1.2,v:4},{t:4,v:6},{t:6.5,v:6},{t:9,v:8},{t:11,v:7},{t:13,v:4}]`，keys `[4,6,7,8]`。
**停留帧在 n=6**（识别 6 个碱基的酶平均每 4096 bp 切一刀——EcoRI 这类常用酶的量级）。
状态：n=4「切点太密，基因组被切碎」；n=6「常用酶的量级」；n≥8「切点太稀，难以操作」。

**例题**：「EcoRI 识别 GAATTC 6 个碱基，为什么它的切点不会太多也不会太少？」答案：6 个碱基的特定序列在随机 DNA 中平均每 4⁶=4096 bp 出现一次，既能把 DNA 切成可操作的片段，又不会过密。
**六问**：① 三种工具分别干什么；② 限制酶切的是哪种键；③ DNA 连接酶连接什么；④ 载体需要什么条件；⑤ 黏性末端为什么能互补；⑥ 为什么不用识别 4 个碱基的酶。
**易错**：✗ 限制酶切氢键 / ✗ DNA 连接酶连接碱基对 / ✗ 载体不需要复制原点 / ✗ 只有限制酶就够了 / ✗ 识别序列越短越好 / ✗ 黏性末端不需要互补。
