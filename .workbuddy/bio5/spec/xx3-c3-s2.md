# 本节规格（只读这一节，不要读 SPEC.md 全文）

## xx3-c3-s2 基因工程的基本操作程序

**课本原话**
1. 基因工程的基本操作程序包括目的基因的获取、基因表达载体的构建、将目的基因导入受体细胞、目的基因的检测与鉴定。
2. 基因表达载体包括目的基因、启动子、终止子和标记基因等。
3. PCR 技术能在体外大量扩增目的基因。

**三个扣分点**：四步顺序不能颠倒（**构建表达载体在导入之前**）；表达载体必须有**启动子**（决定转录起始）；PCR 需要**引物、模板、dNTP、Taq 酶**。

**四张图**：① 基因工程的四个步骤；② 表达载体的组成；③ PCR 的三个阶段（变性、复性、延伸）；④ PCR 循环次数与 DNA 量的关系。

**互动模型**：滑块＝PCR 循环次数 n（0–30，step 1）
```js
copies = Math.pow(2, n);        // 目的基因拷贝数
```
`cases`：`{v:10,eq:{copies:1024}}`、`{v:20,eq:{copies:1048576}}`、`{v:30,eq:{copies:1073741824}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:10},{t:6.5,v:10},{t:9,v:30},{t:11,v:20},{t:13,v:0}]`，keys `[0,10,20,30]`。
**停留帧在 n=30**（2³⁰≈10.7 亿倍：30 轮就能把一段 DNA 扩增到十亿倍，这正是教材里的经典数字）。
状态：n<15「扩增量还不够」；15–25「可用于检测」；>28「指数放大，足够测序或电泳」。

**例题**：「一个目的基因经过 30 次 PCR 循环，理论上扩增为原来的多少倍？」答案：2³⁰≈1.07×10⁹ 倍（约十亿倍）。
**六问**：① 基因工程的四个步骤；② 表达载体必须有哪几部分；③ PCR 为什么要引物；④ PCR 与体内复制的区别；⑤ 为什么先构建载体再导入；⑥ 检测目的基因有哪些方法。
**易错**：✗ 先导入再构建载体 / ✗ 表达载体不需要启动子 / ✗ PCR 不需要引物 / ✗ PCR 是体内复制 / ✗ 30 次循环是 30 倍 / ✗ 标记基因用来扩增。
