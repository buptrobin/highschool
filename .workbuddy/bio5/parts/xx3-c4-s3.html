01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 生物武器的种类人教版（2019）选择性必修3 · 第4章第3节

生物武器包括致病菌、病毒、生化毒剂以及经过基因重组的致病菌等。

→ 翻成人话：这句话是四个并列项——①致病菌 ②病毒 ③生化毒剂 ④经过基因重组的致病菌。前三项是「自然界已有的」，第四项是「人改造出来的」；答题时漏掉第④项，就等于漏掉了本节最想考的那一层：基因重组可能增强致病性。

课本原话 · 四个特点人教版（2019）选择性必修3 · 第4章第3节

生物武器具有致病性强、传染性强、作用时间长、难以防治等特点。

→ 翻成人话：四个特点要成串背，顺序就是因果链——致病性强所以一次投放就有人发病；传染性强所以病人本身成了新的「投放点」，能在人群中继续扩散；作用时间长所以污染区很久不能进入；难以防治所以疫苗、药物往往赶不上。四个词里只有「传染性强」是常规武器没有的，其余三项都是它的后果。

课本原话 · 国际公约与我国立场人教版（2019）选择性必修3 · 第4章第3节

《禁止生物武器公约》禁止发展、生产和储存生物武器（我国是缔约国）。

→ 翻成人话：公约禁的是三个动作——发展、生产、储存，不是只禁「使用」；我国是缔约国并严格履约。答题写「禁止使用」就丢分，写「禁止发展、生产和储存」才完整。

比什么常规武器（炸弹、炮弹）生物武器（致病菌、病毒等）
杀伤方式一次爆炸，能量释放完就结束靠病原体在人体内繁殖，持续致病
作用时间短，爆心外很快恢复长，污染区可长期不宜进入
能否人传人不能，受害者不会变成新的杀伤源能，病人就是新的传染源
真正的区别作用范围＝投放范围传染性极强：作用范围随人群流动不断扩大
防治清障、灭火、修房难以防治：潜伏期长、难以快速识别，疫苗药物常滞后
国际法地位战争法限制使用方式《禁止生物武器公约》禁止发展、生产和储存，我国是缔约国

背法：四个特点＝「两强两长」记不牢，就记因果链：致病性强 → 传染性强 → 作用时间长 → 难以防治。整张表只高亮一行，就是「真正的区别」那一行：常规武器的范围由投放决定，生物武器的范围由人群接触决定。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 简答「为什么特别危险」必考

生物武器被称为「穷人的原子弹」，也被认为比常规武器更危险。请回答：（1）生物武器包括哪几类？（2）为什么生物武器被认为特别危险？请从课本的四个特点出发，并结合基因技术的滥用说明。陷阱：很多同学只答「毒性大」，或把公约写成「只禁止使用」。

  1. 第 1 步 · 审题

    两个小问，第（1）问是「列举」，第（2）问是「说理」。说理题的采分点是课本四个特点，不是自己的形容词。

    用到：生物武器的种类（四个并列项）、四个特点。

  2. 第 2 步 · 先列种类

    致病菌、病毒、生化毒剂、经过基因重组的致病菌。第四项一定要写，它是本节的新内容，也是第（2）问「基因技术滥用」的落点。

    用到：生物武器包括致病菌、病毒、生化毒剂以及经过基因重组的致病菌等。

  3. 第 3 步 · 把四个特点写成因果链

    致病性强 → 一次投放就有人发病；传染性强 → 病人成为新的传染源，在人群中扩散（这是与常规武器最大的不同）；作用时间长 → 污染区长期不宜进入；难以防治 → 潜伏期长、难以快速识别，疫苗和药物常滞后。

    用到：致病性强、传染性强、作用时间长、难以防治。

  4. 第 4 步 · 加一层技术滥用

    用基因工程改造致病菌，基因重组可能增强致病性，也可能增强抗药性，使原有的疫苗和药物失效，风险进一步放大。所以《禁止生物武器公约》禁止发展、生产和储存生物武器，我国是缔约国并严格履约。

    用到：基因重组可能增强致病性；公约禁止发展、生产和储存；我国是缔约国。

  5. 第 5 步 · 回查两个坑

    ① 有没有把「禁止发展、生产和储存」写成「只禁止使用」？② 有没有写「我国不是缔约国」或干脆不提我国立场？这两处是本题最常见的丢分点。

    用到：公约义务的范围、我国的缔约国身份。

标准答案（可抄进答题卡）

（1）生物武器包括致病菌、病毒、生化毒剂以及经过基因重组的致病菌等。
（2）①致病性强：少量病原体进入人体即可大量繁殖、引起严重疾病。②传染性强：可在人与人之间传播，病人成为新的传染源，作用范围随人群流动不断扩大，这是生物武器与常规武器最大的不同。③作用时间长：病原体在环境中存活久，污染区长期不宜进入。④难以防治：潜伏期长、难以快速识别，疫苗和药物研制常滞后于疫情。⑤技术滥用风险：基因重组可能增强致病菌的致病性或抗药性，使原有防治手段失效。⑥因此《禁止生物武器公约》禁止发展、生产和储存生物武器，我国是缔约国并严格履约。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

生物武器到底包括哪几类？只写「细菌」够吗？

不够。课本是四个并列项：致病菌、病毒、生化毒剂、经过基因重组的致病菌。少写第四项，就丢掉了「基因重组可能增强致病性」这一层。

生物武器和常规武器最大的不同是什么？

传染性极强：病原体能在人与人之间传播，病人成为新的传染源，作用范围随人群流动不断扩大；常规武器炸完就停，受害者不会变成新的杀伤源。

为什么说生物武器难以防治？

因为潜伏期长、难以快速识别，等发现时已经传给别人；而且疫苗和药物研制常滞后于疫情，病原体还可能有抗药性。

《禁止生物武器公约》到底禁止什么？

禁止发展、生产和储存生物武器——三个动作，不是只禁止「使用」。答「只禁止使用」是本节能踩的最大的坑。

我国对生物武器的态度是什么？

我国是《禁止生物武器公约》的缔约国，严格履约，反对发展、生产和储存生物武器，也反对生物技术的军事化滥用。

基因技术只能造福人类吗？被滥用有什么风险？

不一定。技术本身中性，基因重组可能增强致病性（也可能增强抗药性），一旦被用于改造致病菌，后果比天然病原体更难控制，所以必须用公约和法律约束。

这六问其实是同一件事：生物武器的危险 = 致病性强 × 传染性强 × 作用时间长 × 难以防治，再乘上基因技术可能放大的那一项；正因为如此，国际社会才用公约把「发展、生产和储存」一起禁掉，而我国是缔约国。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 生物武器只是致病，不会在人与人之间传播。

✓ 生物武器致病性强，且传染性强，可在人群中扩散，这是它与常规武器最大的不同。

错在哪：只记住了「致病」，漏掉了「传染」。传染性极强才是本节的核心判断。

✗ 生物武器作用时间短，投放后很快就没事了。

✓ 生物武器作用时间长，病原体在环境中存活久，污染区长期不宜进入。

错在哪：把常规武器「炸完就结束」的印象套到生物武器上，方向正好相反。

✗ 《禁止生物武器公约》只禁止使用生物武器。

✓ 公约禁止发展、生产和储存生物武器，禁止的范围比「使用」更靠前。

错在哪：把三个动作记成一个。禁「发展、生产、储存」是把风险掐在源头。

✗ 我国没有加入《禁止生物武器公约》。

✓ 我国是缔约国，并严格履行公约义务。

错在哪：事实性错误，一到选择题就送分。

✗ 基因技术只会造福人类，不会带来任何风险。

✓ 基因重组可能增强致病菌的致病性或抗药性，技术滥用会带来严重风险。

错在哪：技术是中性的，风险来自滥用；这句话也是「基因重组可能增强致病性」的落点。

✗ R₀ 越大，说明越容易防控，需要免疫的人越少。

✓ R₀ 越大，阻断传播所需的人群免疫覆盖率越高（100(1−1/R₀)%），越难防控。

错在哪：把「传染力强」误当成「好对付」。R₀=12 时要 91.7% 的人免疫，几乎做不到。

✗ 生物武器就是「更毒的化学武器」，两者一样。

✓ 生化毒剂只是生物武器的一类，且不是活病原体；致病菌、病毒能在人体内繁殖并人传人。

错在哪：混淆了「毒剂」和「病原体」。会不会繁殖、能不能人传人，是两条不同的判据。
