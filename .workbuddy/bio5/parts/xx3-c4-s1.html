01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 安全性的两个方面人教版（2019）选择性必修3 · 第4章第1节

转基因产品的安全性包括食品安全和生态安全两个方面。

→ 翻成人话：这句话由两个并列的条件组成（①食品安全 ②生态安全），少答一个就只答了一半。①问的是「人吃了、接触了有没有害」；②问的是「外源基因跑出去会不会改变野生种群」。答题时先写「两方面」，再分述，阅卷老师一眼看到关键词就给你分。

课本原话 · 评价原则人教版（2019）选择性必修3 · 第4章第1节

对转基因产品要进行科学的评估，包括实质等同原则、个案分析原则等。

→ 翻成人话：这句话里藏着两个原则。实质等同＝把转基因产品与「原来那个传统品种」逐项比，比出来差不多就按传统品种管；个案分析＝一个品种一个结论，不能拿 A 的结论套到 B 上。少写「个案」两个字，就是本节最常丢的分。

课本原话 · 管理制度人教版（2019）选择性必修3 · 第4章第1节

我国对转基因生物实行安全评价、标识等管理制度。

→ 翻成人话：这句话是管理层面的两个动作：安全评价（进市场之前先评，评不过不放行）+ 标识（进市场之后告诉你这是转基因的，把选择权交回消费者）。两者一个是「准入」，一个是「知情」，别混成一句「国家管得很严」。

比什么食品安全生态安全
担心的是谁吃它的人、接触它的人田里的野生种群、整个生态系统
典型问题有无毒性、有无致敏性、营养成分是否被改变外源基因漂移、产生「超级杂草」、非目标生物受害
核心担忧毒性、致敏性等直接健康效应基因漂移：外源基因转入野生近缘种
怎么降风险实质等同原则逐项比较、安全评价设置隔离距离、隔离带、错开开花期
能不能归零可评估到「与传统品种同等安全」只能降到很低，不能归零

整张表只高亮 1 行。背法：先答「两方面」，再把「基因漂移」四个字挂到生态安全名下——这一句就是本节的分水岭。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 原因分析类简答必考

某地计划大面积种植抗除草剂转基因油菜，附近田间有同属的野生近缘种。有人主张「只要检验过转基因油菜的食用油里没有毒素，就可以放心推广」。请回答：（1）指出该主张在安全性评价上遗漏了哪一方面，并说明理由；（2）为什么说转基因作物的生态安全必须「个案分析」？

  1. 第 1 步 · 定性：先分两方面

    题干只说「食用油里没有毒素」，这是食品安全这一半。要立刻想起课本那句：转基因产品的安全性包括食品安全和生态安全两个方面。所以主张遗漏的是生态安全。

    用到：安全性的两个方面。

  2. 第 2 步 · 点出生态安全的核心担忧

    生态安全的核心担忧是基因漂移：转基因油菜的花粉可借风或昆虫传播，落到同属野生近缘种的柱头上并完成受精，外源基因就进入了野生种群，可能使其获得抗除草剂特性、变成难以防除的「超级杂草」。

    用到：基因漂移的路径（供体 → 传播 → 杂交 → 后果）。

  3. 第 3 步 · 把「距离」说成手段而不是结论

    设置隔离距离、隔离带、错开开花期都可以降低漂移率，但漂移率随距离只是指数下降、趋近于 0 而不等于 0，所以只能说「风险很低」，不能说「绝对安全」。

    用到：隔离距离与漂移率的关系（不为 0）。

  4. 第 4 步 · 回答「个案分析」

    不同转基因作物的外源基因不同、受体物种不同、种植环境不同、附近野生近缘种的分布也不同，风险大小差异很大，因此必须一个品种一个结论地逐个评价，不能拿一个品种的结论套到另一个品种上。

    用到：个案分析原则。

  5. 第 5 步 · 收口到管理制度

    正因为要逐个评价，我国才对转基因生物实行安全评价与标识等管理制度：先评价再准入，上市后按目录强制标识，把知情权与选择权交给消费者。

    用到：安全评价 + 标识的管理制度。

1 / 5

标准答案（可抄进答题卡）

（1）遗漏了生态安全。转基因产品的安全性包括食品安全和生态安全两个方面，只检验食用油有无毒素只评价了食品安全；还应评价外源基因漂移等生态风险。生态安全的核心担忧是基因漂移，即转基因作物通过花粉传播，把外源基因转入野生近缘种，可能产生「超级杂草」等后果。
（2）因为不同转基因作物的外源基因不同、受体物种不同、种植环境不同、附近野生近缘种的分布也不同，风险大小差异很大，必须逐个品种评价，不能一概而论；这就是个案分析原则。我国据此实行安全评价、标识等管理制度。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「转基因产品的安全性到底包括哪几方面？只答食品安全行不行？」

不行。安全性包括食品安全和生态安全两个方面，缺一即不完整；生态安全的核心担忧是基因漂移。

「基因漂移是什么意思？是转基因作物自己跑过去吗？」

不是「跑」。基因漂移指外源基因经花粉传播转入野生近缘种并随后代遗传；载体是花粉，不是植株移动。

「为什么转基因作物的生态安全要个案分析？给个统一结论不是更省事？」

因为外源基因、受体物种、种植环境、野生近缘种分布各不相同，风险差异很大，只能逐个品种评价，不能一概而论。

「设隔离距离有什么用？离得足够远是不是就绝对安全了？」

隔离距离能显著降低漂移率（d=200 m 时降到 36.8%），但漂移率趋近于 0 而不等于 0，只能说「风险很低」。

「转基因食品标了标识，是不是说明它不安全？」

不是。标识保障的是知情权与选择权，是「如实告知」；安全与否由安全评价决定，两者是不同环节。

「实质等同原则到底在比什么？」

把转基因产品与原来那个传统品种逐项比较（成分、营养、毒性、致敏性），比出来实质相同就按传统品种管理，不必再按新食品从零评估。

收尾点明：这六问其实是同一件事——先问「哪一方面」，再问「哪个环节」，最后问「有没有按个案来判断」。三句话串起来，本节所有简答都能落到分点上。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 转基因产品只要吃了没事就安全，只看食品安全就够了。

✓ 转基因产品的安全性包括食品安全和生态安全两个方面。

错在哪：把「两方面」砍成了一方面。生态安全的核心担忧是基因漂移，漏了它本题最多给一半分。

✗ 基因漂移不会发生，转基因作物又不会自己跑到野外去。

✓ 基因漂移是指外源基因通过花粉传播转入野生近缘种，可能使其成为「超级杂草」。

错在哪：把基因漂移理解成「植株移动」。载体是花粉（风媒、虫媒），不是植株。

✗ 所有转基因产品的安全性都一样，可以给一个统一结论。

✓ 不同转基因作物的外源基因、受体物种、种植环境、野生近缘种分布不同，必须个案分析、逐个评价。

错在哪：违反个案分析原则。「转基因都安全」和「转基因都不安全」是同一类错误。

✗ 只要隔离距离足够远，就绝对安全了，漂移率等于 0。

✓ 增大隔离距离能显著降低外源基因漂移率，但漂移率趋近于 0 而不等于 0，只能说风险很低。

错在哪：把指数下降读成了「可以压到 0」。d=1000 m 时仍有约 0.67%。

✗ 转基因产品不需要标识，反正都通过安全评价了。

✓ 我国对转基因生物实行安全评价、标识等管理制度，列入目录的产品必须标识才能销售。

错在哪：把「准入」和「知情」混成一件事。评价通过不等于可以不给消费者知情权。

✗ 标了转基因就是判定它不安全，所以我不能买。

✓ 标识保障消费者的知情权与选择权，是如实告知，不等于安全评价不合格。

错在哪：把标识当成安全判决。标识回答「是什么」，安全评价回答「安不安全」。

✗ 个案分析就是逐个审批走个形式，反正最后都能通过。

✓ 个案分析是评价原则：每个品种单独评价、单独结论，评价不通过的不得释放和上市。

错在哪：把「原则」说成「流程形式」。个案分析的落点是「结论可以不同」，不是「走过场」。

七条错句里，前三条是本节的主干（两方面 / 基因漂移 / 个案分析），后四条是它们的「变形题」。背主干，变形题自然就错不了。
