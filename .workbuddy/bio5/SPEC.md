## xx3-c1-s1 传统发酵技术的应用

**课本原话**
1. 发酵是指人们利用微生物，在适宜的条件下，将原料通过微生物的代谢转化为人类所需要的产物的过程。
2. 果酒的制作利用酵母菌的无氧呼吸，果醋的制作利用醋酸菌的有氧发酵。
3. 泡菜的制作利用乳酸菌的无氧发酵，产生乳酸。

**三个扣分点**：**酵母菌**是兼性厌氧（有氧产 CO₂ 和水、无氧产酒精），**醋酸菌**必须**有氧**（所以果醋要通气）；温度不能过高（会杀死菌种）；泡菜坛要**密封**（乳酸菌是严格厌氧）。

**四张图**：① 三种发酵的菌种与条件对照表；② 酵母菌的有氧/无氧两条去向；③ 温度对酵母菌与乳酸菌活性的影响（两条最适温度不同的曲线）；④ 果酒→果醋的流程与通气要求。

**互动模型**：滑块＝发酵温度 T（15–40 ℃，step 1）
```js
yeast = 100 * Math.exp(-Math.pow(T - 28, 2) / 50);   // 酵母菌相对活性（最适约 28 ℃）
lacto = 100 * Math.exp(-Math.pow(T - 37, 2) / 60);   // 乳酸菌相对活性（最适约 37 ℃）
```

Autopilot：`[{t:0,v:15},{t:1.2,v:15},{t:4,v:28},{t:6.5,v:28},{t:9,v:40},{t:11,v:35},{t:13,v:15}]`，keys `[15,25,28,37,40]`。
**停留帧在 T=28**（酵母菌恰好 100%，乳酸菌只有 26%——同温度下两种菌的状态完全不同）。
状态：T<20「两种菌都慢」；25–30「酵母菌最适，适合果酒」；35–38「乳酸菌最适，适合泡菜/酸奶」。

**例题**：「制作果酒时需要哪些条件？为什么果醋制作后期要通气？」答案：果酒要用酵母菌、无氧、18–30 ℃；果醋用醋酸菌，醋酸菌是好氧菌，必须持续通气才能把乙醇氧化成醋酸。
**六问**：① 酵母菌在有氧与无氧时产物有什么不同；② 醋酸菌需要氧气吗；③ 泡菜坛为什么要密封；④ 温度过高会怎样；⑤ 果酒变果醋的条件；⑥ 传统发酵为什么要用新鲜原料。
**易错**：✗ 醋酸菌是厌氧菌 / ✗ 酵母菌只进行无氧呼吸 / ✗ 泡菜坛要经常开盖 / ✗ 温度越高发酵越快 / ✗ 果醋不需要通气 / ✗ 发酵就是腐败。

## xx3-c1-s2 微生物的培养与应用

**课本原话**
1. 培养基一般都含有水、碳源、氮源和无机盐，此外还要满足微生物对 pH、特殊营养物质以及氧气的需求。
2. 获得纯净培养物的关键是防止杂菌污染，方法包括消毒和灭菌。
3. 稀释涂布平板法可以用于统计样品中的活菌数目。

**三个扣分点**：**消毒与灭菌不同**（灭菌要杀死包括芽孢在内的所有微生物）；统计活菌用**稀释涂布平板法**（不是平板划线法）；平板计数结果通常**偏小**（两个菌落长在一起时只算一个）。

**四张图**：① 培养基的成分与类型（选择培养基、鉴别培养基）；② 消毒与灭菌的方法对照；③ 稀释涂布平板法的操作步骤；④ 稀释倍数与平板菌落数的关系。

**互动模型**：滑块＝稀释指数 d（1–7，原始菌液 10⁷ 个/mL）
```js
col = 10000000 / Math.pow(10, d);      // 每个平板上的菌落数
ok  = col >= 30 && col <= 300 ? 1 : 0; // 30–300 才适合计数
```
`cases`：`{v:5,eq:{col:100}}`、`{v:6,eq:{col:10}}`、`{v:7,eq:{col:1}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:5},{t:6.5,v:5},{t:9,v:7},{t:11,v:6},{t:13,v:1}]`，keys `[1,5,6,7]`。
**停留帧在 d=5**（每板 100 个菌落，落在 30–300 的可数区间内——这一格才适合计数）。
状态：d<4「菌落太多，连成一片数不清」；d=5「可数区间」；d≥6「菌落太少，误差大」。

**例题**：「某样品稀释 10⁵ 倍后，取 0.1 mL 涂布，平板上长出 100 个菌落，估算样品中活菌数。」答案：100÷0.1×10⁵=1×10⁸ 个/mL。（注意：两个菌落连在一起时只算一个，结果可能偏小。）
**六问**：① 消毒与灭菌的区别；② 培养基必须含哪些成分；③ 为什么用稀释涂布平板法计数；④ 平板计数为什么偏小；⑤ 选择培养基的原理；⑥ 菌落数太多或太少都不行吗。
**易错**：✗ 消毒就是灭菌 / ✗ 用平板划线法统计活菌 / ✗ 平板计数结果偏大 / ✗ 培养基只需要碳源 / ✗ 菌落越多数得越准 / ✗ 灭菌只杀死细菌繁殖体。

## xx3-c1-s3 发酵工程及其应用

**课本原话**
1. 发酵工程一般包括菌种的选育、扩大培养、培养基的配制、灭菌、接种、发酵、产品的分离与提纯等步骤。
2. 发酵过程中要严格控制温度、pH、溶氧、罐压等条件。
3. 发酵工程的产品包括微生物细胞本身、代谢产物等，广泛应用于食品、医药、能源等领域。

**三个扣分点**：发酵工程是**工业化、规模化**的生产（与实验室培养不同）；**中心环节是发酵过程控制**（温度、pH、溶氧）；产品分离提纯在**发酵之后**（顺序别倒）。

**四张图**：① 发酵工程的完整流程（六步）；② 发酵罐的结构与检测装置；③ 发酵过程的三个阶段（延滞期、对数期、稳定期）；④ 产物量随时间变化的曲线。

**互动模型**：滑块＝发酵时间 t（0–40 h，step 1）
```js
prod = 100 / (1 + Math.exp(-(t - 20) / 4));   // 产物相对量（%），S 形
rate = prod * (1 - prod / 100) / 4;           // 增长速率（示意，峰值在 t=20）
```
`cases`：`{v:10,eq:{prod:7.6}}`、`{v:20,eq:{prod:50}}`、`{v:30,eq:{prod:92.4}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:20},{t:6.5,v:20},{t:9,v:40},{t:11,v:30},{t:13,v:0}]`，keys `[0,10,20,40]`。
**停留帧在 t=20**（产物 50%、增长速率最大：加料、控温的收益在这一段最高）。
状态：t<10「延滞期，产物很少」；10–30「对数期，快速积累」；>32「稳定期，趋于饱和」。

**例题**：「为什么发酵过程中要不断检测温度和 pH？」答案：微生物代谢会产生热量并改变 pH，偏离最适范围会降低代谢速率甚至导致菌体死亡，必须实时监测、调控，才能保证产物稳定高产。
**六问**：① 发酵工程的步骤顺序；② 中心环节是什么；③ 三个时期的特点；④ 为什么要扩大培养；⑤ 产品分离提纯在哪一步；⑥ 发酵工程与实验室培养的区别。
**易错**：✗ 先分离提纯再发酵 / ✗ 发酵过程不需要控温 / ✗ 发酵工程就是实验室小量培养 / ✗ 延滞期产物最多 / ✗ 溶氧对所有菌都一样 / ✗ 发酵结束不用灭菌。

## xx3-c2-s1 植物细胞工程

**课本原话**
1. 植物组织培养就是在无菌和人工控制条件下，将离体的植物器官、组织、细胞，培养在人工配制的培养基上，给予适宜的培养条件，诱导其产生愈伤组织、丛芽，最终形成完整的植株。
2. 植物组织培养的原理是细胞的全能性。
3. 在组织培养中，生长素与细胞分裂素的比值影响愈伤组织的分化方向。

**三个扣分点**：原理是**细胞的全能性**（不是细胞分裂）；**生长素/细胞分裂素比值高→诱导生根，低→诱导生芽**（方向别记反）；全程必须**无菌**。

**四张图**：① 组织培养的流程（外植体→愈伤组织→丛芽/根→植株）；② 生长素与细胞分裂素比例对分化的影响；③ 无菌操作的关键环节；④ 植物体细胞杂交与组织培养的关系。

**互动模型**：滑块＝生长素与细胞分裂素的浓度比值 r（0.25–8，对数感，step 0.25）
```js
shoot = 100 * r / (1 + r);         // 生芽倾向（%）
root  = 100 / (1 + r);             // 生根倾向（%）
```
`cases`：`{v:0.25,eq:{shoot:20,root:80}}`、`{v:1,eq:{shoot:50,root:50}}`、`{v:4,eq:{shoot:80,root:20}}`。
Autopilot：`[{t:0,v:0.25},{t:1.2,v:0.25},{t:4,v:1},{t:6.5,v:1},{t:9,v:8},{t:11,v:4},{t:13,v:0.25}]`，keys `[0.25,1,4,8]`。
**停留帧在 r=1**（生芽与生根各 50%，两种激素势均力敌——比值往哪边偏，分化就往哪边走）。
状态：r<0.5「细胞分裂素占优，偏向生芽」；r≈1「平衡」；r>2「生长素占优，偏向生根」。

**例题**：「在组织培养中，要诱导生根应如何调整激素比例？」答案：提高生长素与细胞分裂素的比值（生长素占优），促进生根；若要大量生芽则降低该比值。
**六问**：① 组织培养的原理；② 为什么必须在无菌条件下；③ 愈伤组织是什么；④ 激素比值怎样影响分化；⑤ 组织培养能保持亲本性状吗；⑥ 体细胞杂交与组织培养的关系。
**易错**：✗ 组织培养原理是细胞分裂 / ✗ 生长素高就生芽 / ✗ 不必无菌 / ✗ 愈伤组织已是完整植株 / ✗ 组织培养改变遗传物质 / ✗ 两种激素作用相同。

## xx3-c2-s2 动物细胞工程

**课本原话**
1. 动物细胞培养需要适宜的营养、温度、pH 和渗透压，以及无菌、无毒的环境。
2. 动物细胞融合技术最重要的用途是制备单克隆抗体。
3. 单克隆抗体的制备要经过细胞融合、筛选杂交瘤细胞、克隆化培养和抗体检测等步骤。

**三个扣分点**：单克隆抗体的优点是**特异性强、灵敏度高、可大量制备**；制备要经过**两次筛选**（先选杂交瘤，再选能产生特定抗体的）；动物细胞培养**贴壁生长**、需要**胰蛋白酶处理**传代。

**四张图**：① 动物细胞培养的条件；② 单克隆抗体制备的流程（融合→筛选→克隆→检测）；③ 两次筛选各筛掉什么；④ 杂交瘤细胞的特点（既能无限增殖又能产生抗体）。

**互动模型**：滑块＝克隆化培养的代数 p（0–20，step 1）
```js
ab = 100 / (1 + Math.exp(-(p - 8) / 2));    // 抗体相对产量（%）
```
`cases`：`{v:4,eq:{ab:11.9}}`、`{v:8,eq:{ab:50}}`、`{v:16,eq:{ab:98.2}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:8},{t:6.5,v:8},{t:9,v:20},{t:11,v:16},{t:13,v:0}]`，keys `[0,4,8,20]`。
**停留帧在 p=8**（产量到 50%，正是对数增长最快的一段）。
状态：p<5「刚扩增，产量低」；5–12「快速上升」；>14「接近饱和，可收集抗体」。

**例题**：「为什么用杂交瘤细胞生产单克隆抗体？」答案：杂交瘤细胞既具有 B 淋巴细胞产生特定抗体的能力，又具有骨髓瘤细胞在体外大量增殖的能力，因此能大量生产特异性强、纯度高的单克隆抗体。
**六问**：① 动物细胞培养需要什么条件；② 杂交瘤细胞的特点；③ 为什么需要两次筛选；④ 单克隆抗体的优点；⑤ 传代为什么要用胰蛋白酶；⑥ 细胞融合的原理。
**易错**：✗ 杂交瘤只需一次筛选 / ✗ 单克隆抗体特异性差 / ✗ 动物细胞培养不需无菌 / ✗ 杂交瘤只能增殖不能产抗体 / ✗ 骨髓瘤细胞能产生抗体 / ✗ 单克隆抗体是多克隆的混合物。

## xx3-c2-s3 胚胎工程

**课本原话**
1. 胚胎工程是指对动物早期胚胎或配子所进行的多种显微操作和处理技术，如体外受精、胚胎移植、胚胎分割等。
2. 受精卵经过卵裂形成多个细胞，此时胚胎总体积基本不变或略有缩小。
3. 胚胎移植的实质是早期胚胎在相同生理环境条件下的空间位置的转移。

**三个扣分点**：卵裂期**细胞数增加但总体积不变**（甚至略减）；**胚胎移植**不改变遗传物质（只是「搬家」）；胚胎分割要注意**均等分割**，否则影响发育。

**四张图**：① 胚胎发育的阶段（受精卵→卵裂→桑葚胚→囊胚→原肠胚）；② 卵裂期细胞数与体积的变化；③ 胚胎移植的流程；④ 胚胎分割的要点。

**互动模型**：滑块＝胚胎发育天数 d（0–7 天，step 1）
```js
cells = Math.pow(2, d);                   // 细胞数（示意：每天分裂一次）
stage = d === 0 ? 1 : d <= 3 ? 2 : d <= 4 ? 3 : 4;   // 1 受精卵 2 卵裂 3 桑葚胚 4 囊胚
```
`cases`：`{v:2,eq:{cells:4}}`、`{v:4,eq:{cells:16}}`、`{v:7,eq:{cells:128}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:4},{t:6.5,v:4},{t:9,v:7},{t:11,v:6},{t:13,v:0}]`，keys `[0,2,4,7]`。
**停留帧在 d=4**（16 个细胞，桑葚胚——总体积几乎没变，这是卵裂期的关键）。
状态：d=0「受精卵」；1–3「卵裂期，细胞多而体积不变」；d=4「桑葚胚」；≥5「囊胚及以后」。

**例题**：「卵裂期细胞数目不断增多，胚胎总体积却基本不变，为什么？」答案：卵裂是在透明带内进行的，细胞不断分裂但受透明带限制，胚胎总体积基本不变或略有缩小，细胞的体积越来越小。
**六问**：① 胚胎工程的常用技术；② 卵裂期体积怎么变；③ 桑葚胚与囊胚的区别；④ 胚胎移植的实质；⑤ 胚胎分割要注意什么；⑥ 为什么胚胎移植不改变遗传物质。
**易错**：✗ 卵裂期总体积随细胞数增加 / ✗ 胚胎移植改变了遗传物质 / ✗ 胚胎分割可以随意分割 / ✗ 桑葚胚是已经分化的胚胎 / ✗ 受精卵立即着床 / ✗ 胚胎工程就是克隆。

## xx3-c3-s1 重组DNA技术的基本工具

**课本原话**
1. 限制酶能识别双链 DNA 分子的特定核苷酸序列，并在特定的位点切割 DNA。
2. DNA 连接酶能将 DNA 片段连接起来，恢复被限制酶切开的磷酸二酯键。
3. 基因进入受体细胞的载体必须能在受体细胞中复制并稳定保存，常用的是质粒。

## xx3-c3-s4 蛋白质工程的原理和应用

**课本原话**
1. 蛋白质工程是以蛋白质分子的结构规律及其与生物功能的关系为基础，通过基因修饰或基因合成，对现有蛋白质进行改造，或制造一种新的蛋白质。
2. 蛋白质工程的目标是改造蛋白质的结构，从而改变其功能。
3. 蛋白质工程最终要通过改造基因来实现，因此被称为「第二代基因工程」。

**三个扣分点**：蛋白质工程**先设计结构、再改基因**（方向与基因工程相反：基因工程是拿到基因看功能，蛋白质工程是想功能找结构）；**必须通过改造基因**实现（直接改蛋白质不能遗传）；中心法则在这里是**逆向使用**的。

**四张图**：① 天然蛋白质的合成方向与蛋白质工程的设计方向（反向）；② 蛋白质工程的四个步骤；③ 定点突变改变酶活性；④ 蛋白质工程与基因工程的对照。
