## bx2-c1-s1 平面向量的概念

**课本原话**
1. 既有大小又有方向的量叫做向量。
2. 长度为 0 的向量叫做零向量，记作 0；长度等于 1 个单位长度的向量，叫做单位向量。
3. 方向相同或相反的非零向量叫做平行向量（也叫共线向量）；长度相等且方向相同的向量叫做相等向量。

**三个扣分点**：向量不能比较大小（只有模能比）；零向量的方向是任意的（不是「没有方向」）；平行向量可以不在同一条直线上。

**四张图**：① 有向线段与向量的三要素（起点、方向、长度）；② 相等向量＝平移后能重合（位置无关）；③ 共线向量的三种情形（同向、反向、零向量）；④ 向量的模与方向：单位向量是把长度缩成 1。

**互动模型**：滑块＝向量 a 的方向角 θ（0–360°，step 15°），与固定向量 b=(1,0) 比较；|a|=2
```js
re = 2 * Math.cos(θ); im = 2 * Math.sin(θ);      // 只用来画箭头
cos = Math.cos(θ);
kind: 0 同向（θ=0）、1 垂直（θ=90/270）、2 反向（θ=180）、3 其他
```
`cases`：`{v:0,eq:{cos:1,kind:0}}`、`{v:90,eq:{cos:0,kind:1}}`、`{v:180,eq:{cos:-1,kind:2}}`、`{v:270,eq:{cos:0,kind:1}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:90},{t:6.5,v:90},{t:9,v:180},{t:11.5,v:270},{t:13.5,v:0}]`，keys `[0,90,180,270]`——停留帧在 90°（垂直：既不平行也不反向，最容易和「不共线」混）。
状态：θ=0「同向」；90/270「垂直（a·b=0）」；180「反向」；其他「既不平行也不垂直」。

**例题**：「判断：① 若 |a|=|b|，则 a=b；② 若 a∥b，则 a 与 b 方向相同；③ 零向量与任意向量平行。正确的是？」答案：只有 ③。① 模相等方向可以不同；② 平行还包括反向；③ 规定零向量与任一向量平行。
**六问**：① 向量能不能比大小；② 零向量有没有方向；③ 平行向量是不是一定画在同一条线上；④ 单位向量有几个；⑤ 相等向量与共线向量的区别；⑥ 两个向量「不共线」意味着什么。
**易错**：✗ 向量可以比较大小 / ✗ 零向量没有方向 / ✗ 平行向量一定在同一条直线上 / ✗ 模相等的向量相等 / ✗ 单位向量都相等（方向不同）/ ✗ 共线向量就是方向相同的向量。

## bx2-c1-s2 平面向量的运算

**课本原话**
1. 求两个向量和的运算，叫做向量的加法；向量加法的三角形法则与平行四边形法则。
2. 一般地，我们规定实数 λ 与向量 a 的积是一个向量，这种运算叫做数乘。
3. 已知两个非零向量 a 与 b，我们把数量 |a||b|cosθ 叫做 a 与 b 的数量积（或内积），记作 a·b。

**三个扣分点**：数量积是**数量**不是向量（可以负）；θ 是两向量起点重合后的夹角，取 0°–180°；a·b=0 只能推出垂直或有一个是零向量。

**四张图**：① 三角形法则与平行四边形法则；② 减法 a−b＝终点连线的反向；③ 数乘 λa 的三种情形（λ>1、0<λ<1、λ<0）；④ 数量积的几何意义：b 在 a 上的投影。

**互动模型**：滑块＝夹角 θ（0–180°，step 5°），|a|=|b|=2
```js
dot = 4 * Math.cos(θ);      // a·b = |a||b|cosθ
proj = 2 * Math.cos(θ);     // b 在 a 上的投影
kind: 0 锐角（dot>0）、1 直角（dot=0）、2 钝角（dot<0）
```
`cases`：`{v:0,eq:{dot:4,proj:2}}`、`{v:60,eq:{dot:2,proj:1}}`、`{v:90,eq:{dot:0,proj:0}}`、`{v:120,eq:{dot:-2,proj:-1}}`、`{v:180,eq:{dot:-4,proj:-2}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:90},{t:6.5,v:90},{t:9,v:150},{t:11.5,v:150},{t:13.5,v:0}]`，keys `[0,60,90,150]`——停留帧在 90°（数量积第一次变成 0，也是正负分界）。
状态：θ<90「锐角，a·b>0」；=90「垂直，a·b=0」；>90「钝角，a·b<0（最容易漏的负值）」。

**例题**：「已知 |a|=2，|b|=3，a 与 b 的夹角为 120°，求 a·b、|a+b|。」答案：a·b=2×3×cos120°=−3；|a+b|²=4+9+2×(−3)=7，|a+b|=√7。
**六问**：① 数量积是向量还是数；② 夹角怎么取（为什么要起点重合）；③ a·b=0 能不能推出 a⊥b；④ (a·b)c 与 a(b·c) 相等吗；⑤ |a+b| 一定小于 |a|+|b| 吗；⑥ 数乘 λa 与 a 的方向关系。
**易错**：✗ 数量积是向量 / ✗ a·b=|a||b| （漏 cosθ）/ ✗ a·b=0 就一定有 a⊥b / ✗ |a+b|=|a|+|b| / ✗ 夹角可以取 200° / ✗ 数乘后方向不变。

## bx2-c1-s3 平面向量基本定理及坐标表示

**课本原话**
1. 如果 e₁，e₂ 是同一平面内的两个不共线向量，那么对于这一平面内的任一向量 a，有且只有一对实数 λ₁，λ₂，使 a=λ₁e₁+λ₂e₂。
2. 设 a=(x₁,y₁)，b=(x₂,y₂)，则 a∥b ⇔ x₁y₂−x₂y₁=0。
3. 设 a=(x₁,y₁)，b=(x₂,y₂)，则 a·b=x₁x₂+y₁y₂。

**三个扣分点**：基底必须**不共线**（共线就不能表示整个平面）；坐标是「唯一」的一对系数；共线条件是叉积为 0，别写成点积为 0（那是垂直）。

**四张图**：① 用基底 e₁,e₂ 表示 a 的唯一分解；② 平面直角坐标系中向量的坐标（终点减起点）；③ 共线判定：叉积 x₁y₂−x₂y₁ 的几何意义（平行四边形面积）；④ 垂直判定：点积为 0。

**互动模型**：滑块＝向量 b 的横坐标 t（0–9，step 0.5），a=(2,1)，b=(t,3)
```js
det = 2 * 3 - 1 * t;        // x1y2 − x2y1 = 6 − t
area = Math.abs(det);       // 平行四边形面积
kind: 0 共线（det=0）、1 逆时针（det>0）、2 顺时针（det<0）
```
`cases`：`{v:0,eq:{det:6}}`、`{v:3,eq:{det:3}}`、`{v:6,eq:{det:0}}`、`{v:9,eq:{det:-3}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:3},{t:6.5,v:6},{t:9,v:6},{t:11,v:9},{t:13,v:0}]`，keys `[0,3,6,9]`——停留帧在 t=6（叉积为 0，两向量恰好共线，面积塌成 0）。
状态：det>0「b 在 a 的逆时针侧」；det=0「共线（面积 0）」；det<0「b 在 a 的顺时针侧」。

**例题**：「已知 a=(2,1)，b=(t,3)。(1) 当 t 为何值时 a∥b？(2) 当 t 为何值时 a⊥b？」答案：(1) 2×3−1×t=0 → t=6；(2) 2t+3=0 → t=−3/2。
**六问**：① 基底为什么要求不共线；② 分解为什么是唯一的；③ 共线条件为什么是叉积为 0；④ 点积为 0 是什么关系；⑤ 坐标是终点坐标还是终点减起点；⑥ 零向量能不能当基底。
**易错**：✗ 任意两个向量都能当基底 / ✗ 共线条件写成 x₁x₂+y₁y₂=0 / ✗ 垂直条件写成叉积为 0 / ✗ 向量坐标就是终点坐标 / ✗ a∥b 就一定同向 / ✗ 分解系数可以不唯一。

## bx2-c1-s4 平面向量的应用

**课本原话**
1. 余弦定理：三角形中任何一边的平方，等于其他两边平方的和减去这两边与它们夹角的余弦的积的两倍，即 a²=b²+c²−2bccosA。
2. 正弦定理：在一个三角形中，各边和它所对角的正弦的比相等，即 a/sinA=b/sinB=c/sinC。
3. 用向量方法解决平面几何问题：把长度、角度转化为向量的模与数量积。

**三个扣分点**：余弦定理里是**减** 2bccosA（夹角为钝角时它自动变大）；正弦定理不能判定钝角（sin 相同角可能互补）；合力大小用余弦定理时角是两向量的夹角，不是补角。

**四张图**：① 余弦定理的向量证明（c²=(a−b)²）；② 正弦定理与「一解/两解」的判定；③ 力的合成：平行四边形法则求合力；④ 用向量证平行与垂直（共线/点积）。

**互动模型**：滑块＝两个力 F₁=3、F₂=4 的夹角 θ（0–180°，step 5°）
```js
R = Math.sqrt(9 + 16 + 24 * Math.cos(θ));   // |F1+F2|，余弦定理
Rmin = 1; Rmax = 7;
```
`cases`：`{v:0,eq:{R:7}}`、`{v:60,eq:{R:6.083}}`、`{v:90,eq:{R:5}}`、`{v:120,eq:{R:3.606}}`、`{v:180,eq:{R:1}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:90},{t:6.5,v:90},{t:9,v:180},{t:11.5,v:180},{t:13.5,v:0}]`，keys `[0,60,90,180]`——停留帧在 90°（直角时合力 5，正好是 3-4-5 直角三角形）。
状态：θ<90「合力大于 √25」；=90「合力恰为 5（勾股）」；>90「合力小于 5，最小到 1」。

**例题**：「两个力 F₁=3 N、F₂=4 N，夹角 60°，求合力大小；夹角多大时合力为 5 N？」答案：R=√(9+16+2×12×0.5)=√37≈6.08 N；R=5 → 9+16+24cosθ=25 → cosθ=0 → θ=90°。
**六问**：① 余弦定理里为什么是减号；② 正弦定理为什么可能有两解；③ 合力什么时候最大/最小；④ 用向量证平行用什么条件；⑤ 用向量求夹角用什么公式；⑥ 三角形中「大边对大角」怎么用正弦定理理解。
**易错**：✗ 余弦定理写成加号 / ✗ 已知两边及其中一边对角用正弦定理直接得唯一解 / ✗ 合力永远比每个分力大 / ✗ 三边不满足两边之和大于第三边也能解 / ✗ 用点积证共线 / ✗ 夹角取成补角。

## bx2-c2-s1 复数的概念

**课本原话**
1. 我们把形如 a+bi（a，b∈R）的数叫做复数，其中 i 叫做虚数单位；规定 i²=−1。
2. a 与 b 分别叫做复数 z=a+bi 的实部与虚部。
3. 两个复数相等的充要条件是它们的实部与虚部分别相等。

**三个扣分点**：虚部是**实数** b（不是 bi）；纯虚数要求 a=0 且 b≠0（b=0 时是实数 0，不是纯虚数）；复数不能比较大小（只有相等/不等）。

**四张图**：① 数系扩充：N→Z→Q→R→C；② 复数的分类树（实数 / 虚数 / 纯虚数）；③ 复平面：实轴、虚轴、点与向量一一对应；④ 共轭复数与模 |z|=√(a²+b²)。

**互动模型**：滑块＝点 z 在复平面上的辐角 θ（0–360°，step 15°），模固定 |z|=2
```js
re = 2 * Math.cos(θ); im = 2 * Math.sin(θ);
mod = 2;
type: 0 实数（im=0）、1 纯虚数（re=0 且 im≠0）、2 一般虚数
```
`cases`：`{v:0,eq:{re:2,im:0,type:0}}`、`{v:90,eq:{re:0,im:2,type:1}}`、`{v:180,eq:{re:-2,im:0,type:0}}`、`{v:45,eq:{re:1.414,im:1.414,type:2}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:90},{t:6.5,v:90},{t:9,v:180},{t:11.5,v:270},{t:13.5,v:0}]`，keys `[0,90,180,270]`——停留帧在 90°（纯虚数，最容易被判成「虚数但实部不为 0」的那一格）。
状态：θ=0/180「实数（落在实轴上）」；90/270「纯虚数（落在虚轴上）」；其他「虚数」。

**例题**：「已知 z=(m²−1)+(m+1)i，当 m 为何值时 z 是实数、纯虚数？」答案：实数 → m+1=0 → m=−1；纯虚数 → m²−1=0 且 m+1≠0 → m=1。
**六问**：① 虚部是 b 还是 bi；② 纯虚数与虚数的区别；③ 复数能不能比大小；④ i² 等于多少、i³ 呢；⑤ 两个复数相等的条件；⑥ 复平面上的点与复数什么关系。
**易错**：✗ 虚部是 bi / ✗ 纯虚数只要实部为 0 / ✗ 复数可以比较大小 / ✗ i²=1 / ✗ 0 是纯虚数 / ✗ 复数相等的条件是模相等。

## bx2-c2-s2 复数的四则运算

**课本原话**
1. 两个复数的和仍是一个复数，它的实部是原来两个复数实部的和，虚部是原来两个复数虚部的和。
2. 复数乘法：(a+bi)(c+di)=(ac−bd)+(ad+bc)i。
3. 复数除法：分子分母同乘分母的共轭复数，把分母化为实数。

**三个扣分点**：乘法里 i²=−1 会把 bd 变成 −bd；除法必须乘**共轭**（a−bi）而不是 a+bi；两个虚数不能比较大小，但可以相等。

**四张图**：① 加减法的几何意义（平行四边形、三角形）；② 乘法的几何意义：模相乘、辐角相加（乘 i 就是转 90°）；③ 共轭复数的对称性；④ 除法的分母实数化流程。

**互动模型**：滑块＝乘数 w=cosθ+isinθ 的辐角 θ（0–360°），被乘数 z=2
```js
re = 2 * Math.cos(θ); im = 2 * Math.sin(θ);   // z·w
mod = 2;                                       // 模不变（|w|=1）
```
`cases`：`{v:0,eq:{re:2,im:0}}`、`{v:90,eq:{re:0,im:2}}`、`{v:180,eq:{re:-2,im:0}}`、`{v:270,eq:{re:0,im:-2}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:90},{t:6.5,v:180},{t:9,v:180},{t:11.5,v:270},{t:13.5,v:0}]`，keys `[0,90,180,270]`——停留帧在 180°（乘 −1 就是把向量转半圈，i²=−1 的来源）。
状态：θ=90「乘 i：逆时针转 90°」；180「乘 −1：转 180°」；270「乘 −i：顺时针转 90°」。

**例题**：「计算 (1+2i)(3−i)。」答案：(1+2i)(3−i)=3−i+6i−2i²=3+5i+2=5+5i。
**六问**：① 复数乘法为什么要把 i² 换成 −1；② 乘 i 在复平面上是什么变换；③ 除法为什么乘共轭；④ 共轭复数的乘积是什么；⑤ 两个复数的和是实数还是复数；⑥ z·z̄ 等于什么。
**易错**：✗ (a+bi)(c+di)=ac+bdi / ✗ 除法乘的是本身而不是共轭 / ✗ i²=1 / ✗ 共轭就是取绝对值 / ✗ 复数加法要合并 i² 项 / ✗ z·z̄ 还是复数（其实是 |z|²，实数）。

## bx2-c2-s3 复数的三角表示

**课本原话**
1. 复数 z=a+bi 可以表示为 z=r(cosθ+isinθ)，其中 r=|z|，θ 是以 x 轴非负半轴为始边、向量 OZ 为终边的角，叫做辐角。
2. 两个复数相乘，积的模等于各复数的模的积，积的辐角等于各复数的辐角的和。
3. 两个复数相除，商的模等于模的商，商的辐角等于辐角的差。

```js

```

## bx2-c3-s1 基本立体图形

**课本原话**
1. 有两个面互相平行，其余各面都是四边形，并且每相邻两个四边形的公共边都互相平行，由这些面所围成的多面体叫做棱柱。
2. 有一个面是多边形，其余各面都是有一个公共顶点的三角形，由这些面所围成的多面体叫做棱锥。
3. 用平行于棱锥底面的平面去截棱锥，底面与截面之间的部分叫做棱台。

**三个扣分点**：棱柱的侧棱**互相平行**（不是「都相等」就够）；棱台必须由棱锥截得（侧棱延长后交于一点）；球不是多面体。

**互动模型**：滑块＝正 n 棱柱的底面边数 n（3–12，step 1）


## bx2-c3-s2 立体图形的直观图

**课本原话**
1. 在已知图形中取互相垂直的 x 轴和 y 轴，两轴交于点 O；画直观图时，把它们画成对应的 x′ 轴与 y′ 轴，两轴交于点 O′，且使 ∠x′O′y′=45°（或 135°）。
2. 已知图形中平行于 x 轴或 y 轴的线段，在直观图中分别画成平行于 x′ 轴或 y′ 轴的线段。
3. 已知图形中平行于 x 轴的线段，在直观图中长度不变；平行于 y 轴的线段，长度变为原来的一半。

**三个扣分点**：只有 y 方向减半，x 方向不变；角度是 45°（或 135°），不是 90°；直观图面积 = (√2/4)×原面积（不是 1/2）。

**四张图**：① 斜二测三步：建系、取角、减半；② 正方形→平行四边形的对照；③ 圆→椭圆的对照；④ 面积比 √2/4 的来源（底不变、高变成 (1/2)sin45°）。

**互动模型**：滑块＝直观图中 y′ 轴与 x′ 轴的夹角 θ（0–90°，step 5°）
```js
ratio = 0.5 * Math.sin(θ * Math.PI / 180);   // 面积比：底不变，高 = (1/2)sinθ
```
`cases`：`{v:30,eq:{ratio:0.25}}`、`{v:45,eq:{ratio:0.3536}}`、`{v:90,eq:{ratio:0.5}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:30},{t:4,v:45},{t:6.5,v:45},{t:9,v:90},{t:11.5,v:90},{t:13,v:0}]`，keys `[0,30,45,90]`——停留帧在 45°（教材规定的角，面积比 √2/4≈0.354）。
状态：θ=0「退化（面积为 0）」；45「斜二测标准角：面积比 √2/4」；90「正投影：面积比 1/2」。

**例题**：「边长为 2 的正方形，用斜二测画法画出的直观图面积是多少？」答案：原面积 4；直观图面积 = (√2/4)×4 = √2。

**易错**：✗ x 方向也减半 / ✗ 面积比是 1/2 / ✗ 角度画成 90° / ✗ 圆的直观图还是圆 / ✗ 直观图面积比随图形大小改变 / ✗ 斜二测只能画正方形。

## bx2-c3-s3 简单几何体的表面积与体积

**课本原话**
1. 柱体的体积 V=Sh；锥体的体积 V=(1/3)Sh；台体的体积 V=(1/3)h(S+√(SS′)+S′)。
2. 球的体积 V=(4/3)πR³，球的表面积 S=4πR²。
3. 圆柱的侧面积 S=2πrl，圆锥的侧面积 S=πrl（l 为母线长）。

**三个扣分点**：锥体体积有 1/3（漏了就错三倍）；球的表面积是 4πR² 不是 2πR²；表面积要算**全部**面（含底面），侧面积不含底面。

**四张图**：① 柱/锥/台的体积公式与「同底等高」关系；② 圆柱、圆锥的侧面展开图；③ 球的体积与表面积；④ 组合体：先拆再算、别重复计算接面。

**互动模型**：滑块＝球的半径 R（1–5，step 0.5）
```js
V = 4 / 3 * Math.PI * R ** 3;   S = 4 * Math.PI * R ** 2;
k = V / (2 * Math.PI * R ** 3);  // 与等底等高圆柱（半径 R、高 2R）的体积比，恒为 2/3
```
`cases`：`{v:1,eq:{V:4.189,S:12.566,k:0.6667}}`、`{v:3,eq:{V:113.097,S:113.097}}`、`{v:5,eq:{V:523.599,S:314.159}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:3},{t:6.5,v:3},{t:9,v:5},{t:11.5,v:5},{t:13,v:1}]`，keys `[1,2,3,5]`——停留帧在 R=3（体积与表面积数值恰好都是 113.1，最容易被误当成「相等」）。

## bx2-c3-s5 空间直线、平面的平行

**课本原话**
1. 平面外一条直线与此平面内的一条直线平行，则该直线与此平面平行。
2. 一个平面内的两条相交直线与另一个平面平行，则这两个平面平行。
3. 一条直线与一个平面平行，如果过该直线的平面与此平面相交，那么该直线与交线平行。

**三个扣分点**：线面平行判定必须强调「平面外」+「平面内一条直线」两个条件（缺一个结论就不成立）；面面平行判定要「两条**相交**直线」（平行直线不行）；线面平行不能直接推出线线平行，要借助第三个平面。

**四张图**：① 线面平行判定定理的三个条件；② 面面平行判定：两条相交直线；③ 线面平行性质：过直线的平面与已知平面相交；④ 面面平行性质：第三个平面截两组平行平面。

**互动模型**：滑块＝斜线 l 与平面 α 所成的角 θ（0–90°，step 5°）
```js

kind: 0 平行或在面内（θ=0）、1 斜交（0<θ<90）、2 垂直（θ=90）
```
`cases`：`{v:0,eq:{sinT:0,kind:0}}`、`{v:30,eq:{sinT:0.5,kind:1}}`、`{v:90,eq:{sinT:1,kind:2}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:30},{t:6.5,v:30},{t:9,v:90},{t:11.5,v:90},{t:13,v:0}]`，keys `[0,30,60,90]`——停留帧在 0°（平行/在面内，判定定理最想让你确认的那一格）。

**例题**：「在正方体 ABCD-A₁B₁C₁D₁ 中，求证：BD∥平面 B₁D₁C。」答案：连 B₁D₁，BD∥B₁D₁（正方体对面平行且相等）；BD⊄平面 B₁D₁C，B₁D₁⊂平面 B₁D₁C；由线面平行判定定理得 BD∥平面 B₁D₁C。

**易错**：✗ 平面内一条直线与平面外一条直线平行就推出线面平行（漏「平面外」）/ ✗ 两条平行直线都平行于另一平面就推出面面平行 / ✗ 线面平行直接推出线线平行 / ✗ 平行于同一平面的两直线平行 / ✗ 面面平行时两平面内所有直线都平行 / ✗ 判定定理条件可省。

## bx2-c3-s6 空间直线、平面的垂直

**课本原话**

## bx2-c4-s1 随机抽样

**课本原话**
1. 一般地，设一个总体含有 N 个个体，从中逐个不放回地抽取 n 个个体作为样本（n≤N），如果每次抽取时总体内的各个个体被抽到的机会都相等，就把这种抽样方法叫做简单随机抽样。
2. 一般地，按一个或多个变量把总体划分成若干个子总体，每个个体属于且仅属于一个子总体，在每个子总体中独立地进行简单随机抽样，再把所有子总体中抽取的样本合在一起作为总样本，这样的抽样方法称为分层随机抽样。
3. 在分层随机抽样中，如果每层样本量都与层的大小成比例，那么称这种样本量的分配方式为比例分配。

**三个扣分点**：简单随机抽样必须「逐个不放回」且「机会相等」；分层抽样是**层内**简单随机、**层间**独立；比例分配时样本量按层的大小比例分配，不是平均分。

**四张图**：① 抽签法与随机数法；② 分层抽样的分层与比例分配；③ 样本均值与总体均值的关系；④ 样本量越大，抽样误差越小（标准误 ∝ 1/√n）。

**互动模型**：滑块＝样本量 n（4–400），总体标准差 σ=10
```js
se = 10 / Math.sqrt(n);        // 抽样误差（标准误）
rel = se / 10;                 // 相对误差
```
`cases`：`{v:4,eq:{se:5}}`、`{v:25,eq:{se:2}}`、`{v:100,eq:{se:1}}`、`{v:400,eq:{se:0.5}}`。
Autopilot：`[{t:0,v:4},{t:1.2,v:4},{t:4,v:25},{t:6.5,v:25},{t:9,v:400},{t:11.5,v:400},{t:13,v:4}]`，keys `[4,25,100,400]`——停留帧在 n=25（误差 2，正好是 n=4 时的一半：样本量×6，误差才÷2.6）。
状态：n<10「误差大，样本太少」；25–100「够用」；>300「误差已很小，再增大收益递减」。

**例题**：「某校高一 600 人、高二 500 人、高三 400 人，用分层抽样抽取 150 人，三个年级各抽多少人？」答案：总 1500 人，比例 1/10；高一 60、高二 50、高三 40。
**六问**：① 简单随机抽样的两个条件；② 分层抽样每层内部怎么抽；③ 比例分配怎么算；④ 样本量越大误差越小，能无限增大吗；⑤ 系统抽样与简单随机抽样的区别；⑥ 样本均值能代表总体均值吗。
**易错**：✗ 有放回抽样也是简单随机抽样 / ✗ 分层抽样每层抽一样多 / ✗ 样本量越大误差成比例减小 / ✗ 分层抽样不需要层内随机 / ✗ 样本均值一定等于总体均值 / ✗ 总体容量越大误差越大。

## bx2-c4-s2 用样本估计总体

**课本原话**
1. 一般地，一组数据的第 p 百分位数是这样一个值，它使得这组数据中至少有 p% 的数据小于或等于这个值，且至少有 (100−p)% 的数据大于或等于这个值。
2. 一组数据的方差 s²=(1/n)Σ(xᵢ−x̄)²，标准差 s=√(s²)。
3. 在频率分布直方图中，每个小矩形的面积等于相应区间的频率。

**三个扣分点**：直方图的纵轴是「频率/组距」，面积才是频率；中位数是第 50 百分位数，不是平均数；方差越小越稳定（不是越大）。

**四张图**：① 频率分布直方图的画法与「面积=频率」；② 平均数、中位数、众数在直方图上的位置；③ 方差/标准差的意义（离散程度）；④ 极端值对平均数与中位数的影响。

**互动模型**：滑块＝把数据里最大的 12 换成 12+Δ 的偏移 Δ（0–18，step 1）；数据为 8,9,9,10,10,10,11,11,12+Δ
```js
mean = (90 + Δ) / 9;                     // 10 + Δ/9
median = 10;                             // 始终是第 5 个数
sd = sqrt(方差)                           // 随 Δ 迅速变大
```
`cases`：`{v:0,eq:{mean:10,median:10,sd:1.155}}`、`{v:9,eq:{mean:11,median:10,sd:3.651}}`、`{v:18,eq:{mean:12,median:10,sd:6.429}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:9},{t:6.5,v:9},{t:9,v:18},{t:11.5,v:18},{t:13,v:0}]`，keys `[0,9,18]`——停留帧在 Δ=18（均值被拉走 2，中位数一动不动，方差涨 31 倍）。
状态：Δ=0「对称数据：均值=中位数」；Δ≤9「轻微右偏」；Δ>9「严重右偏，均值被极端值拖走」。

**例题**：「某组数据 8,9,9,10,10,10,11,11,12，把 12 改成 21 后，平均数、中位数、方差怎么变？」答案：平均数 90/9=10 → 99/9=11；中位数仍为 10；方差由 4/3 增大到约 13.3（数据更分散）。
**六问**：① 直方图纵轴是什么；② 面积为什么等于频率；③ 中位数与平均数什么时候相等；④ 方差大说明什么；⑤ 极端值对哪个统计量影响最大；⑥ 标准差与方差的单位一样吗。
**易错**：✗ 直方图纵轴是频率 / ✗ 中位数等于平均数 / ✗ 方差越大越稳定 / ✗ 平均数一定比中位数大 / ✗ 标准差可以小于 0 / ✗ 去掉一个最大值平均数不变。

## bx2-c4-s3 统计案例 公司员工的肥胖情况调查分析

**课本原话**
1. 用样本的频率分布估计总体的频率分布，用样本的数字特征估计总体的数字特征。
2. 在比较两个群体的某项指标时，可以分别计算它们的平均数与标准差，也可以用频率分布直方图直观比较。

**三个扣分点**：样本只能**估计**总体，不能断言总体；比较两组数据要同时看平均数和离散程度；用频率估计概率时样本量要足够大。

**四张图**：① 调查流程：抽样 → 整理 → 描述 → 推断；② 两组员工 BMI 的直方图对比；③ 平均数相同但标准差不同时的两条分布；④ 样本比例 p̂ 的波动范围（±1.96√(p(1−p)/n)）。

**互动模型**：滑块＝样本量 n（100–1600），总体比例 p=0.5
```js
moe = 1.96 * Math.sqrt(0.25 / n);   // 95% 置信水平的误差范围
```
`cases`：`{v:100,eq:{moe:0.098}}`、`{v:400,eq:{moe:0.049}}`、`{v:900,eq:{moe:0.0327}}`、`{v:1600,eq:{moe:0.0245}}`。

**易错**：✗ 样本比例就是总体比例 / ✗ 平均数相同两组数据就相同 / ✗ 样本量越大结论一定更「正确」（只是误差更小）/ ✗ 误差范围随总体规模增大而增大 / ✗ 直方图能直接读出原始数据 / ✗ 忽略分层导致结论偏差。

## bx2-c5-s1 随机事件与概率

**课本原话**
1. 我们把对随机现象的实现和对它的观察称为随机试验；随机试验的每个可能的基本结果称为样本点，全体样本点的集合称为样本空间。
2. 样本空间 Ω 的子集称为随机事件；只包含一个样本点的事件称为基本事件。
3. 一般地，设试验 E 是古典概型，样本空间 Ω 包含 n 个样本点，事件 A 包含其中的 k 个样本点，则 P(A)=k/n。

**三个扣分点**：古典概型要同时满足「有限」与「等可能」；P(A) 范围是 [0,1]，不可能事件概率 0 但概率 0 的事件不一定不可能（连续型）；互斥与对立不同（对立一定互斥，互斥不一定对立）。

**四张图**：① 样本空间与事件（集合的语言）；② 古典概型的两个条件；③ 互斥与对立的区别（Venn 图）；④ 概率的基本性质（P(Ω)=1、P(∅)=0、P(A∪B)=P(A)+P(B)−P(AB)）。

**互动模型**：滑块＝同时掷两枚骰子的点数和 s（2–12，step 1）
```js
ways = 6 - Math.abs(s - 7);   // 有序数对个数：1,2,3,4,5,6,5,4,3,2,1
p = ways / 36;
```
`cases`：`{v:2,eq:{ways:1,p:0.02778}}`、`{v:5,eq:{ways:4,p:0.11111}}`、`{v:7,eq:{ways:6,p:0.16667}}`、`{v:12,eq:{ways:1,p:0.02778}}`。
Autopilot：`[{t:0,v:2},{t:1.2,v:2},{t:4,v:7},{t:6.5,v:7},{t:9,v:12},{t:11.5,v:12},{t:13,v:2}]`，keys `[2,7,12]`——停留帧在 s=7（概率最大 1/6，最反直觉：和越大越难，中间最容易）。
状态：s=2 或 12「只有 1 种，P=1/36」；s=7「6 种，P=1/6 最大」；其他「居中」。

**例题**：「同时掷两枚质地均匀的骰子，求点数和为 7 的概率；点数和为 2 的概率。」答案：样本点共 36 个（有序）；和为 7 有 (1,6)(2,5)(3,4)(4,3)(5,2)(6,1) 共 6 个，P=1/6；和为 2 只有 (1,1)，P=1/36。
**六问**：① 古典概型的两个条件；② 为什么样本点要按「有序」数；③ 互斥与对立的区别；④ 概率为 0 的事件一定不可能吗；⑤ P(A∪B) 怎么算；⑥ 掷两枚骰子和为 7 与和为 8 哪个概率大。
**易错**：✗ 样本点不按有序数（漏解）/ ✗ 互斥就是对立 / ✗ P(A)+P(B) 一定等于 P(A∪B) / ✗ 概率为 0 就是不可能事件 / ✗ 古典概型不需要等可能 / ✗ 两个事件概率相加超过 1 也正常。

## bx2-c5-s2 事件的相互独立性

**课本原话**
1. 对任意两个事件 A 与 B，如果 P(AB)=P(A)P(B) 成立，则称事件 A 与事件 B 相互独立。
2. 如果事件 A 与 B 相互独立，那么 A 与 B̄、Ā 与 B、Ā 与 B̄ 也都相互独立。
3. 如果 A 与 B 相互独立，则 P(A∪B)=P(A)+P(B)−P(A)P(B)。

**三个扣分点**：独立的判据是 P(AB)=P(A)P(B)（不是「互不影响」这种口语）；互斥与独立是两回事（互斥且概率都大于 0 时一定不独立）；「至少一个发生」用 1−P(都 不发生) 更快。

**四张图**：① 独立的定义与乘法公式；② 互斥 vs 独立（Venn 图与数值对照）；③ 至少一个发生：对立事件转化；④ 独立重复试验与二项分布雏形。

**互动模型**：滑块＝P(A)（0.05–1，step 0.05），P(B)=0.5，A 与 B 独立
```js
both = PA * 0.5;                    // P(AB)
union = PA + 0.5 - both;            // P(A∪B)
none = (1 - PA) * 0.5;              // 都不发生
```
`cases`：`{v:0.2,eq:{both:0.1,union:0.6}}`、`{v:0.5,eq:{both:0.25,union:0.75}}`、`{v:1,eq:{both:0.5,union:1}}`。
Autopilot：`[{t:0,v:0.2},{t:1.2,v:0.2},{t:4,v:0.5},{t:6.5,v:0.5},{t:9,v:1},{t:11.5,v:1},{t:13,v:0.2}]`，keys `[0.2,0.5,1]`——停留帧在 P(A)=0.5（两个 0.5 的事件，并集 0.75 而不是 1）。
状态：PA<0.4「并集被重叠吃掉一截」；0.5「典型：各 1/2，并 3/4」；1「A 必然发生，并集为 1」。

**例题**：「甲、乙两人独立破译一份密码，甲成功的概率 0.6，乙 0.5。求密码被破译的概率。」答案：P=1−(1−0.6)(1−0.5)=1−0.2=0.8。
**六问**：① 独立怎么判定；② 互斥与独立的区别；③ 为什么「至少一个」用对立事件算；④ 独立性能否由 P(AB)=P(A)P(B) 反推；⑤ 三个事件相互独立要满足几个等式；⑥ 独立重复试验的概率怎么算。
**易错**：✗ 互斥就是独立 / ✗ P(A∪B)=P(A)+P(B) 用于独立事件 / ✗ 「至少一个」直接相加 / ✗ 独立需要 P(A)=P(B) / ✗ 独立与概率大小有关 / ✗ 两次独立试验结果互不影响所以一定有 P(AB)=P(A)P(B)（这是定义，要用它算）。

## bx2-c5-s3 频率与概率

**课本原话**
1. 频率是随机的，在试验前不能确定；随着试验次数的增加，频率会逐渐稳定于概率。
2. 我们可以用频率估计概率，也可以用随机模拟的方法估计概率。
3. 概率是事件的本质属性，不随试验次数变化。

**三个扣分点**：频率是试验值、会波动，概率是客观值、不变；「频率稳定于概率」不等于「频率等于概率」；试验次数很大时频率才接近概率，次数少时可能差很多。

**四张图**：① 抛硬币频率随次数波动的折线；② 频率与概率的关系（稳定但不相等）；③ 用频率估计概率的流程；④ 随机模拟（用随机数代替真实试验）。

**互动模型**：滑块＝试验次数 n（10–10000，按 10 的倍数）
```js
bound = 1 / (2 * Math.sqrt(n));    // 频率偏离概率的典型量级（示意）
n 越大，bound 越小
```
`cases`：`{v:100,eq:{bound:0.05}}`、`{v:400,eq:{bound:0.025}}`、`{v:10000,eq:{bound:0.005}}`。
Autopilot：`[{t:0,v:10},{t:1.2,v:10},{t:4,v:100},{t:6.5,v:100},{t:9,v:10000},{t:11.5,v:10000},{t:13,v:10}]`，keys `[10,100,1000,10000]`——停留帧在 n=100（频率已经贴着 0.5，但还会晃）。
状态：n<50「频率乱跳，不能当概率」；100–1000「逐渐稳定」；>5000「基本稳定于 0.5」。

**例题**：「抛硬币 100 次出现 58 次正面，能否说正面概率是 0.58？为什么？」答案：不能。频率 0.58 是这次试验的结果，会波动；概率是客观值 0.5，试验次数增大时频率会稳定在 0.5 附近。
**六问**：① 频率与概率的区别；② 「稳定于」是什么意思；③ 次数少时频率能信吗；④ 随机模拟为什么能估计概率；⑤ 概率为 0.5 意味着 100 次一定 50 次正面吗；⑥ 频率能为 0 或 1 吗。
**易错**：✗ 频率就是概率 / ✗ 抛 100 次一定有 50 次正面 / ✗ 频率稳定于概率意味着相等 / ✗ 概率随试验次数变化 / ✗ 次数越多频率一定越接近 / ✗ 随机模拟不如真做实验所以没用。
