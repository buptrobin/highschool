## bx2-c3-s2 立体图形的直观图

**课本原话**
1. 在已知图形中取互相垂直的 x 轴和 y 轴，两轴交于点 O；画直观图时，把它们画成对应的 x′ 轴与 y′ 轴，两轴交于点 O′，且使 ∠x′O′y′=45°（或 135°）。
2. 已知图形中平行于 x 轴或 y 轴的线段，在直观图中分别画成平行于 x′ 轴或 y′ 轴的线段。
3. 已知图形中平行于 x 轴的线段，在直观图中长度不变；平行于 y 轴的线段，长度变为原来的一半。

**三个扣分点**：只有 y 方向减半，x 方向不变；角度是 45°（或 135°），不是 90°；直观图面积 = (√2/4)×原面积（不是 1/2）。

**四张图**：① 斜二测三步：建系、取角、减半；② 正方形→平行四边形的对照；③ 圆→椭圆的对照；④ 面积比 √2/4 的来源（底不变、高变成 (1/2)sin45°）。

**互动模型**：滑块＝直观图中 y′ 轴与 x′ 轴的夹角 θ（0–90°，step 5°）
```js
ratio = 0.5 * Math.sin(θ * Math.PI / 180);   // 面积比：底不变，高 = (1/2)sinθ
```
`cases`：`{v:30,eq:{ratio:0.25}}`、`{v:45,eq:{ratio:0.3536}}`、`{v:90,eq:{ratio:0.5}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:30},{t:4,v:45},{t:6.5,v:45},{t:9,v:90},{t:11.5,v:90},{t:13,v:0}]`，keys `[0,30,45,90]`——停留帧在 45°（教材规定的角，面积比 √2/4≈0.354）。
状态：θ=0「退化（面积为 0）」；45「斜二测标准角：面积比 √2/4」；90「正投影：面积比 1/2」。

**例题**：「边长为 2 的正方形，用斜二测画法画出的直观图面积是多少？」答案：原面积 4；直观图面积 = (√2/4)×4 = √2。
**六问**：① 哪个方向减半；② 为什么要取 45°；③ 直观图面积比是 1/2 吗；④ 圆的直观图是什么；⑤ 135° 和 45° 有什么区别；⑥ 直观图能还原出原图吗。
**易错**：✗ x 方向也减半 / ✗ 面积比是 1/2 / ✗ 角度画成 90° / ✗ 圆的直观图还是圆 / ✗ 直观图面积比随图形大小改变 / ✗ 斜二测只能画正方形。

## 通用约定（所有页一致）

- 出处一律写「人教A版必修第二册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
- 禁止写「请拖动滑块」——自动演示时滑块的圆点会自己动，这才是提示。
