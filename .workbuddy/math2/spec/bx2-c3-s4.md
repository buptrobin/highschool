## bx2-c3-s4 空间点、直线、平面之间的位置关系

**课本原话**
1. 基本事实 1：过不在一条直线上的三个点，有且只有一个平面。
2. 基本事实 2：如果一条直线上的两个点在一个平面内，那么这条直线在这个平面内。
3. 不同在任何一个平面内的两条直线叫做异面直线。

**三个扣分点**：异面直线是「不同在任何一个平面内」，不是「不相交」（不相交还可能平行）；直线在平面内也是位置关系的一种；两平面相交有且只有一条公共直线。

**四张图**：① 点、线、面的三种语言（图形语言/文字语言/符号语言）；② 正方体中棱与棱的三种关系（平行/相交/异面）；③ 直线与平面的三种位置关系；④ 两个平面的两种位置关系。

**互动模型**：滑块＝正方体中与棱 AB 比较的第 k 条棱（1–11，共 11 条非 AB 棱）
顺序：BC、CD、DA、A₁B₁、B₁C₁、C₁D₁、D₁A₁、AA₁、BB₁、CC₁、DD₁
```js
type: 0 平行（3 条）、1 相交（4 条）、2 异面（4 条）
count: {par: 3, cross: 4, skew: 4}
```
`cases`：`{v:1,eq:{type:1}}`、`{v:2,eq:{type:0}}`、`{v:5,eq:{type:2}}`、`{v:8,eq:{type:1}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:2},{t:3.5,v:2},{t:6,v:5},{t:8.5,v:5},{t:11,v:9},{t:13,v:1}]`，keys `[1,2,5,9]`——停留帧在 CD（平行）与 B₁C₁（异面）两格。
状态：type 0「平行：共面且无公共点」；1「相交：共面且有一个公共点」；2「异面：不共面（既不相交也不平行）」。

**例题**：「在正方体 ABCD-A₁B₁C₁D₁ 中，与棱 AB 异面的棱有几条？分别是哪几条？」答案：4 条：B₁C₁、C₁C、D₁D、A₁D₁。
**六问**：① 异面直线为什么不等于不相交；② 三点确定平面的条件是什么；③ 直线在平面内算不算「直线与平面相交」；④ 两个平面可能只有一个公共点吗；⑤ 平行直线一定共面吗；⑥ 正方体里与一条棱平行的棱有几条。
**易错**：✗ 异面直线就是不相交的直线 / ✗ 任意三点确定一个平面 / ✗ 直线与平面只有相交和平行两种关系 / ✗ 两平面相交有无数个公共点 / ✗ 异面直线可以画在一个平面里 / ✗ 共面直线一定相交。

- 出处一律写「人教A版必修第二册 · 第X章第Y节」，**不写页码**。
