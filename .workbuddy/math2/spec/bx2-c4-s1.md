## bx2-c4-s1 随机抽样

**课本原话**
1. 一般地，设一个总体含有 N 个个体，从中逐个不放回地抽取 n 个个体作为样本（n≤N），如果每次抽取时总体内的各个个体被抽到的机会都相等，就把这种抽样方法叫做简单随机抽样。
2. 一般地，按一个或多个变量把总体划分成若干个子总体，每个个体属于且仅属于一个子总体，在每个子总体中独立地进行简单随机抽样，再把所有子总体中抽取的样本合在一起作为总样本，这样的抽样方法称为分层随机抽样。
3. 在分层随机抽样中，如果每层样本量都与层的大小成比例，那么称这种样本量的分配方式为比例分配。

**三个扣分点**：简单随机抽样必须「逐个不放回」且「机会相等」；分层抽样是**层内**简单随机、**层间**独立；比例分配时样本量按层的大小比例分配，不是平均分。

**四张图**：① 抽签法与随机数法；② 分层抽样的分层与比例分配；③ 样本均值与总体均值的关系；④ 样本量越大，抽样误差越小（标准误 ∝ 1/√n）。

**互动模型**：滑块＝样本量 n（4–400），总体标准差 σ=10
```js
se = 10 / Math.sqrt(n);        // 抽样误差（标准误）
rel = se / 10;                 // 相对误差
```
`cases`：`{v:4,eq:{se:5}}`、`{v:25,eq:{se:2}}`、`{v:100,eq:{se:1}}`、`{v:400,eq:{se:0.5}}`。
Autopilot：`[{t:0,v:4},{t:1.2,v:4},{t:4,v:25},{t:6.5,v:25},{t:9,v:400},{t:11.5,v:400},{t:13,v:4}]`，keys `[4,25,100,400]`——停留帧在 n=25（误差 2，正好是 n=4 时的一半：样本量×6，误差才÷2.6）。
状态：n<10「误差大，样本太少」；25–100「够用」；>300「误差已很小，再增大收益递减」。

**例题**：「某校高一 600 人、高二 500 人、高三 400 人，用分层抽样抽取 150 人，三个年级各抽多少人？」答案：总 1500 人，比例 1/10；高一 60、高二 50、高三 40。
**六问**：① 简单随机抽样的两个条件；② 分层抽样每层内部怎么抽；③ 比例分配怎么算；④ 样本量越大误差越小，能无限增大吗；⑤ 系统抽样与简单随机抽样的区别；⑥ 样本均值能代表总体均值吗。
**易错**：✗ 有放回抽样也是简单随机抽样 / ✗ 分层抽样每层抽一样多 / ✗ 样本量越大误差成比例减小 / ✗ 分层抽样不需要层内随机 / ✗ 样本均值一定等于总体均值 / ✗ 总体容量越大误差越大。
