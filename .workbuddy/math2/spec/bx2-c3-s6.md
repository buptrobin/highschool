## bx2-c3-s6 空间直线、平面的垂直

**课本原话**
1. 如果一条直线与一个平面内的两条相交直线都垂直，则该直线与此平面垂直。
2. 如果一个平面经过另一个平面的垂线，则这两个平面垂直。
3. 平面的一条斜线和它在平面上的射影所成的角，叫做这条直线和这个平面所成的角。

**三个扣分点**：线面垂直判定要「两条**相交**直线」（两条平行直线不行）；线面角是斜线与**射影**的夹角，范围 0°–90°；二面角的平面角要「垂直于棱」的两条射线。

**四张图**：① 线面垂直判定：两条相交直线；② 面面垂直判定：一个面过另一个面的垂线；③ 线面角的作法（斜线、射影、角）；④ 二面角与平面角（垂直于棱）。

**互动模型**：滑块＝二面角 α-l-β 的大小 θ（0–180°，step 5°）
```js
angle = Math.min(θ, 180 - θ);   // 两平面的夹角取 ≤90° 的那个
kind: 0 锐二面角、1 直二面角（θ=90）、2 钝二面角（θ>90）
```
`cases`：`{v:60,eq:{angle:60,kind:0}}`、`{v:90,eq:{angle:90,kind:1}}`、`{v:120,eq:{angle:60,kind:2}}`、`{v:180,eq:{angle:0}}`。
Autopilot：`[{t:0,v:60},{t:1.2,v:60},{t:4,v:90},{t:6.5,v:90},{t:9,v:120},{t:11.5,v:120},{t:13,v:60}]`，keys `[60,90,120,180]`——停留帧在 90°（直二面角 = 两平面垂直，判定定理的结论）。
状态：θ<90「锐二面角」；=90「直二面角 → 两平面垂直」；>90「钝二面角，但两平面的夹角取 180°−θ」。

**例题**：「在正方体 ABCD-A₁B₁C₁D₁ 中，求证：AC⊥平面 BDD₁B₁。」答案：AC⊥BD（正方形对角线互相垂直），AC⊥DD₁（DD₁⊥底面），BD∩DD₁=D，由线面垂直判定得 AC⊥平面 BDD₁B₁。
**六问**：① 线面垂直判定为什么要求两条相交直线；② 线面角最大是多少；③ 二面角 120° 时两平面夹角是 120° 吗；④ 面面垂直能推出线面垂直吗；⑤ 一条直线垂直于平面内无数条直线就垂直吗；⑥ 线面角的射影怎么找。
**易错**：✗ 垂直于平面内两条直线就垂直（没说相交）/ ✗ 线面角可以是 120° / ✗ 二面角就是两平面夹角 / ✗ 面面垂直则一个面内任意直线垂直另一个面 / ✗ 垂直于平面内无数条平行直线就垂直 / ✗ 线面角是斜线与平面内任意直线的夹角。
