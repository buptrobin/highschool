## bx2-c2-s3 复数的三角表示

**课本原话**
1. 复数 z=a+bi 可以表示为 z=r(cosθ+isinθ)，其中 r=|z|，θ 是以 x 轴非负半轴为始边、向量 OZ 为终边的角，叫做辐角。
2. 两个复数相乘，积的模等于各复数的模的积，积的辐角等于各复数的辐角的和。
3. 两个复数相除，商的模等于模的商，商的辐角等于辐角的差。

**三个扣分点**：辐角不唯一（差 2kπ），通常取 [0,2π) 内的主值；乘法是「模相乘、角相加」（不是角相乘）；三角形式必须是 r(cosθ+isinθ)，中间是 **加号**。

**四张图**：① 复数的三角形式与 r、θ 的几何含义；② 乘法：模相乘、辐角相加（旋转+伸缩）；③ 除法：模相除、辐角相减；④ 棣莫弗定理与 n 次方。

**互动模型**：滑块＝第二个因数的辐角 θ（0–360°），z₁=2∠30°、z₂=3∠θ
```js
mod = 6;                                  // 2×3
arg = (30 + θ) % 360;                     // 辐角相加，超过 360 要减
```
`cases`：`{v:0,eq:{mod:6,arg:30}}`、`{v:90,eq:{mod:6,arg:120}}`、`{v:180,eq:{mod:6,arg:210}}`、`{v:330,eq:{mod:6,arg:0}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:90},{t:6.5,v:90},{t:9,v:180},{t:11.5,v:330},{t:13.5,v:0}]`，keys `[0,90,180,330]`——停留帧在 330°（辐角相加得 360°，绕回 0，最容易被写成 360°）。
状态：arg=30「与 z₁ 同向」；90–180「转到了第二象限」；330+30=360「绕回实轴正半轴」。

**例题**：「计算 2(cos30°+isin30°)·3(cos60°+isin60°)。」答案：模 6，辐角 90°，即 6(cos90°+isin90°)=6i。
**六问**：① 辐角为什么不唯一；② 三角形式里为什么是加号；③ 乘法的几何意义；④ 除法辐角为什么相减；⑤ 棣莫弗定理怎么用；⑥ 1 的立方根有几个、辐角各是多少。
**易错**：✗ 辐角唯一 / ✗ 三角形式写成 cosθ−isinθ / ✗ 乘法辐角相乘 / ✗ 乘法模相加 / ✗ 辐角超过 360° 不处理 / ✗ z 的模写成 a²+b²。
