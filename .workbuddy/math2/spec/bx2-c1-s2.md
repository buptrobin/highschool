# 本节规格（只读这一节，不要读 SPEC.md 全文）

## bx2-c1-s2 平面向量的运算

**课本原话**
1. 求两个向量和的运算，叫做向量的加法；向量加法的三角形法则与平行四边形法则。
2. 一般地，我们规定实数 λ 与向量 a 的积是一个向量，这种运算叫做数乘。
3. 已知两个非零向量 a 与 b，我们把数量 |a||b|cosθ 叫做 a 与 b 的数量积（或内积），记作 a·b。

**三个扣分点**：数量积是**数量**不是向量（可以负）；θ 是两向量起点重合后的夹角，取 0°–180°；a·b=0 只能推出垂直或有一个是零向量。

**四张图**：① 三角形法则与平行四边形法则；② 减法 a−b＝终点连线的反向；③ 数乘 λa 的三种情形（λ>1、0<λ<1、λ<0）；④ 数量积的几何意义：b 在 a 上的投影。

**互动模型**：滑块＝夹角 θ（0–180°，step 5°），|a|=|b|=2
```js
dot = 4 * Math.cos(θ);      // a·b = |a||b|cosθ
proj = 2 * Math.cos(θ);     // b 在 a 上的投影
kind: 0 锐角（dot>0）、1 直角（dot=0）、2 钝角（dot<0）
```
`cases`：`{v:0,eq:{dot:4,proj:2}}`、`{v:60,eq:{dot:2,proj:1}}`、`{v:90,eq:{dot:0,proj:0}}`、`{v:120,eq:{dot:-2,proj:-1}}`、`{v:180,eq:{dot:-4,proj:-2}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:90},{t:6.5,v:90},{t:9,v:150},{t:11.5,v:150},{t:13.5,v:0}]`，keys `[0,60,90,150]`——停留帧在 90°（数量积第一次变成 0，也是正负分界）。
状态：θ<90「锐角，a·b>0」；=90「垂直，a·b=0」；>90「钝角，a·b<0（最容易漏的负值）」。

**例题**：「已知 |a|=2，|b|=3，a 与 b 的夹角为 120°，求 a·b、|a+b|。」答案：a·b=2×3×cos120°=−3；|a+b|²=4+9+2×(−3)=7，|a+b|=√7。
**六问**：① 数量积是向量还是数；② 夹角怎么取（为什么要起点重合）；③ a·b=0 能不能推出 a⊥b；④ (a·b)c 与 a(b·c) 相等吗；⑤ |a+b| 一定小于 |a|+|b| 吗；⑥ 数乘 λa 与 a 的方向关系。
**易错**：✗ 数量积是向量 / ✗ a·b=|a||b| （漏 cosθ）/ ✗ a·b=0 就一定有 a⊥b / ✗ |a+b|=|a|+|b| / ✗ 夹角可以取 200° / ✗ 数乘后方向不变。
