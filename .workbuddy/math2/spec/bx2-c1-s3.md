## bx2-c1-s3 平面向量基本定理及坐标表示

**课本原话**
1. 如果 e₁，e₂ 是同一平面内的两个不共线向量，那么对于这一平面内的任一向量 a，有且只有一对实数 λ₁，λ₂，使 a=λ₁e₁+λ₂e₂。
2. 设 a=(x₁,y₁)，b=(x₂,y₂)，则 a∥b ⇔ x₁y₂−x₂y₁=0。
3. 设 a=(x₁,y₁)，b=(x₂,y₂)，则 a·b=x₁x₂+y₁y₂。

**三个扣分点**：基底必须**不共线**（共线就不能表示整个平面）；坐标是「唯一」的一对系数；共线条件是叉积为 0，别写成点积为 0（那是垂直）。

**四张图**：① 用基底 e₁,e₂ 表示 a 的唯一分解；② 平面直角坐标系中向量的坐标（终点减起点）；③ 共线判定：叉积 x₁y₂−x₂y₁ 的几何意义（平行四边形面积）；④ 垂直判定：点积为 0。

**互动模型**：滑块＝向量 b 的横坐标 t（0–9，step 0.5），a=(2,1)，b=(t,3)
```js
det = 2 * 3 - 1 * t;        // x1y2 − x2y1 = 6 − t
area = Math.abs(det);       // 平行四边形面积
kind: 0 共线（det=0）、1 逆时针（det>0）、2 顺时针（det<0）
```
`cases`：`{v:0,eq:{det:6}}`、`{v:3,eq:{det:3}}`、`{v:6,eq:{det:0}}`、`{v:9,eq:{det:-3}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:3},{t:6.5,v:6},{t:9,v:6},{t:11,v:9},{t:13,v:0}]`，keys `[0,3,6,9]`——停留帧在 t=6（叉积为 0，两向量恰好共线，面积塌成 0）。
状态：det>0「b 在 a 的逆时针侧」；det=0「共线（面积 0）」；det<0「b 在 a 的顺时针侧」。

**例题**：「已知 a=(2,1)，b=(t,3)。(1) 当 t 为何值时 a∥b？(2) 当 t 为何值时 a⊥b？」答案：(1) 2×3−1×t=0 → t=6；(2) 2t+3=0 → t=−3/2。
**六问**：① 基底为什么要求不共线；② 分解为什么是唯一的；③ 共线条件为什么是叉积为 0；④ 点积为 0 是什么关系；⑤ 坐标是终点坐标还是终点减起点；⑥ 零向量能不能当基底。
**易错**：✗ 任意两个向量都能当基底 / ✗ 共线条件写成 x₁x₂+y₁y₂=0 / ✗ 垂直条件写成叉积为 0 / ✗ 向量坐标就是终点坐标 / ✗ a∥b 就一定同向 / ✗ 分解系数可以不唯一。

## 通用约定（所有页一致）

- 出处一律写「人教A版必修第二册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
