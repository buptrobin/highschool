## bx2-c1-s4 平面向量的应用

**课本原话**
1. 余弦定理：三角形中任何一边的平方，等于其他两边平方的和减去这两边与它们夹角的余弦的积的两倍，即 a²=b²+c²−2bccosA。
2. 正弦定理：在一个三角形中，各边和它所对角的正弦的比相等，即 a/sinA=b/sinB=c/sinC。
3. 用向量方法解决平面几何问题：把长度、角度转化为向量的模与数量积。

**三个扣分点**：余弦定理里是**减** 2bccosA（夹角为钝角时它自动变大）；正弦定理不能判定钝角（sin 相同角可能互补）；合力大小用余弦定理时角是两向量的夹角，不是补角。

**四张图**：① 余弦定理的向量证明（c²=(a−b)²）；② 正弦定理与「一解/两解」的判定；③ 力的合成：平行四边形法则求合力；④ 用向量证平行与垂直（共线/点积）。

**互动模型**：滑块＝两个力 F₁=3、F₂=4 的夹角 θ（0–180°，step 5°）
```js
R = Math.sqrt(9 + 16 + 24 * Math.cos(θ));   // |F1+F2|，余弦定理
Rmin = 1; Rmax = 7;
```
`cases`：`{v:0,eq:{R:7}}`、`{v:60,eq:{R:6.083}}`、`{v:90,eq:{R:5}}`、`{v:120,eq:{R:3.606}}`、`{v:180,eq:{R:1}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:90},{t:6.5,v:90},{t:9,v:180},{t:11.5,v:180},{t:13.5,v:0}]`，keys `[0,60,90,180]`——停留帧在 90°（直角时合力 5，正好是 3-4-5 直角三角形）。
状态：θ<90「合力大于 √25」；=90「合力恰为 5（勾股）」；>90「合力小于 5，最小到 1」。

**例题**：「两个力 F₁=3 N、F₂=4 N，夹角 60°，求合力大小；夹角多大时合力为 5 N？」答案：R=√(9+16+2×12×0.5)=√37≈6.08 N；R=5 → 9+16+24cosθ=25 → cosθ=0 → θ=90°。
**六问**：① 余弦定理里为什么是减号；② 正弦定理为什么可能有两解；③ 合力什么时候最大/最小；④ 用向量证平行用什么条件；⑤ 用向量求夹角用什么公式；⑥ 三角形中「大边对大角」怎么用正弦定理理解。
**易错**：✗ 余弦定理写成加号 / ✗ 已知两边及其中一边对角用正弦定理直接得唯一解 / ✗ 合力永远比每个分力大 / ✗ 三边不满足两边之和大于第三边也能解 / ✗ 用点积证共线 / ✗ 夹角取成补角。

## 通用约定（所有页一致）

- 出处一律写「人教A版必修第二册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
