# 本节规格（只读这一节，不要读 SPEC.md 全文）

## bx2-c3-s1 基本立体图形

**课本原话**
1. 有两个面互相平行，其余各面都是四边形，并且每相邻两个四边形的公共边都互相平行，由这些面所围成的多面体叫做棱柱。
2. 有一个面是多边形，其余各面都是有一个公共顶点的三角形，由这些面所围成的多面体叫做棱锥。
3. 用平行于棱锥底面的平面去截棱锥，底面与截面之间的部分叫做棱台。

**三个扣分点**：棱柱的侧棱**互相平行**（不是「都相等」就够）；棱台必须由棱锥截得（侧棱延长后交于一点）；球不是多面体。

**四张图**：① 棱柱/棱锥/棱台的结构对比（底、侧棱、高）；② 旋转体：圆柱、圆锥、圆台、球；③ 正 n 棱柱的顶点、棱、面计数；④ 欧拉公式 V−E+F=2 的验证。

**互动模型**：滑块＝正 n 棱柱的底面边数 n（3–12，step 1）
```js
V = 2 * n;  E = 3 * n;  F = n + 2;  euler = V - E + F;   // 恒为 2
```
`cases`：`{v:3,eq:{V:6,E:9,F:5,euler:2}}`、`{v:6,eq:{V:12,E:18,F:8,euler:2}}`、`{v:12,eq:{V:24,E:36,F:14,euler:2}}`。
Autopilot：`[{t:0,v:3},{t:1.2,v:3},{t:4,v:6},{t:6.5,v:6},{t:9,v:12},{t:11.5,v:12},{t:13,v:3}]`，keys `[3,4,6,12]`——停留帧在 n=6（六棱柱，最常见的那一个）。
状态：n=3「三棱柱：5 个面」；n=6「六棱柱：8 个面」；n=12「十二棱柱：14 个面」——而 V−E+F 永远是 2。

**例题**：「一个棱柱有 12 个顶点，它是几棱柱？有多少条棱、多少个面？」答案：2n=12 → n=6，六棱柱；棱 3n=18 条，面 n+2=8 个（验证 12−18+8=2）。
**六问**：① 棱柱的侧棱有什么要求；② 棱台与棱柱的区别；③ 球是不是多面体；④ 欧拉公式对棱锥成立吗；⑤ 圆柱的侧面展开是什么；⑥ 「正棱柱」的「正」指什么。
**易错**：✗ 侧棱相等就是棱柱 / ✗ 棱台可以随便截 / ✗ 球是多面体 / ✗ 棱柱的面数等于顶点数 / ✗ 圆柱有无数条母线所以不是旋转体 / ✗ 正棱柱的底面可以是任意多边形。
