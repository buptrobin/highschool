## bx2-c1-s1 平面向量的概念

**课本原话**
1. 既有大小又有方向的量叫做向量。
2. 长度为 0 的向量叫做零向量，记作 0；长度等于 1 个单位长度的向量，叫做单位向量。
3. 方向相同或相反的非零向量叫做平行向量（也叫共线向量）；长度相等且方向相同的向量叫做相等向量。

**三个扣分点**：向量不能比较大小（只有模能比）；零向量的方向是任意的（不是「没有方向」）；平行向量可以不在同一条直线上。

**四张图**：① 有向线段与向量的三要素（起点、方向、长度）；② 相等向量＝平移后能重合（位置无关）；③ 共线向量的三种情形（同向、反向、零向量）；④ 向量的模与方向：单位向量是把长度缩成 1。

**互动模型**：滑块＝向量 a 的方向角 θ（0–360°，step 15°），与固定向量 b=(1,0) 比较；|a|=2
```js
re = 2 * Math.cos(θ); im = 2 * Math.sin(θ);      // 只用来画箭头
cos = Math.cos(θ);
kind: 0 同向（θ=0）、1 垂直（θ=90/270）、2 反向（θ=180）、3 其他
```
`cases`：`{v:0,eq:{cos:1,kind:0}}`、`{v:90,eq:{cos:0,kind:1}}`、`{v:180,eq:{cos:-1,kind:2}}`、`{v:270,eq:{cos:0,kind:1}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:90},{t:6.5,v:90},{t:9,v:180},{t:11.5,v:270},{t:13.5,v:0}]`，keys `[0,90,180,270]`——停留帧在 90°（垂直：既不平行也不反向，最容易和「不共线」混）。
状态：θ=0「同向」；90/270「垂直（a·b=0）」；180「反向」；其他「既不平行也不垂直」。

**例题**：「判断：① 若 |a|=|b|，则 a=b；② 若 a∥b，则 a 与 b 方向相同；③ 零向量与任意向量平行。正确的是？」答案：只有 ③。① 模相等方向可以不同；② 平行还包括反向；③ 规定零向量与任一向量平行。
**六问**：① 向量能不能比大小；② 零向量有没有方向；③ 平行向量是不是一定画在同一条线上；④ 单位向量有几个；⑤ 相等向量与共线向量的区别；⑥ 两个向量「不共线」意味着什么。
**易错**：✗ 向量可以比较大小 / ✗ 零向量没有方向 / ✗ 平行向量一定在同一条直线上 / ✗ 模相等的向量相等 / ✗ 单位向量都相等（方向不同）/ ✗ 共线向量就是方向相同的向量。
