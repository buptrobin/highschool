## bx2-c4-s3 统计案例 公司员工的肥胖情况调查分析

**课本原话**
1. 用样本的频率分布估计总体的频率分布，用样本的数字特征估计总体的数字特征。
2. 在比较两个群体的某项指标时，可以分别计算它们的平均数与标准差，也可以用频率分布直方图直观比较。
3. 样本量越大，用样本估计总体的误差一般越小。

**三个扣分点**：样本只能**估计**总体，不能断言总体；比较两组数据要同时看平均数和离散程度；用频率估计概率时样本量要足够大。

**四张图**：① 调查流程：抽样 → 整理 → 描述 → 推断；② 两组员工 BMI 的直方图对比；③ 平均数相同但标准差不同时的两条分布；④ 样本比例 p̂ 的波动范围（±1.96√(p(1−p)/n)）。

**互动模型**：滑块＝样本量 n（100–1600），总体比例 p=0.5
```js
moe = 1.96 * Math.sqrt(0.25 / n);   // 95% 置信水平的误差范围
```
`cases`：`{v:100,eq:{moe:0.098}}`、`{v:400,eq:{moe:0.049}}`、`{v:900,eq:{moe:0.0327}}`、`{v:1600,eq:{moe:0.0245}}`。
Autopilot：`[{t:0,v:100},{t:1.2,v:100},{t:4,v:400},{t:6.5,v:400},{t:9,v:1600},{t:11.5,v:1600},{t:13,v:100}]`，keys `[100,400,900,1600]`——停留帧在 n=400（误差 4.9%，最常见的样本量档位）。
状态：n=100「±9.8%，结论只能粗略」；400「±4.9%」；1600「±2.5%，可以下较肯定的结论」。

**例题**：「调查 400 名员工，超重比例 30%，能否说该公司超重比例就是 30%？误差范围多大？」答案：不能，只能估计；误差范围约 ±1.96√(0.3×0.7/400)≈±4.5%，即真实比例大约在 25.5%–34.5% 之间。
**六问**：① 样本能代表总体吗；② 平均数相同就一定一样吗；③ 误差范围怎么算；④ 样本量翻 4 倍误差减半吗；⑤ 分层抽样在这里有什么用；⑥ 「显著」在统计里是什么意思。
**易错**：✗ 样本比例就是总体比例 / ✗ 平均数相同两组数据就相同 / ✗ 样本量越大结论一定更「正确」（只是误差更小）/ ✗ 误差范围随总体规模增大而增大 / ✗ 直方图能直接读出原始数据 / ✗ 忽略分层导致结论偏差。

## 通用约定（所有页一致）

- 出处一律写「人教A版必修第二册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
- 禁止写「请拖动滑块」——自动演示时滑块的圆点会自己动，这才是提示。
