# 本节规格（只读这一节，不要读别的页的 spec）

## bx2-c2-s2 更好发挥政府作用

**一句话**：政府不是市场的“替补”，而是市场的“裁判 + 医生 + 安全网”：该管的事管好（宏观调控、市场监管、公共服务），不该管的事不插手。

**生活钩子**：从“经济冷了怎么办”开场：街上店铺关门、找工作变难，政府会做什么？发消费券、降利率、修高铁、给企业减税……这些动作背后就是“宏观调控”。再问：政府能不能直接规定奶茶卖几块钱？引出“有形的手”的边界。

**课本原话**
1. 社会主义市场经济体制是社会主义基本经济制度的重要组成部分。
2. 科学的宏观调控、有效的政府治理，是社会主义市场经济体制优势的内在要求。
3. 政府要履行好经济职能：保持宏观经济稳定，加强和优化公共服务，保障公平竞争，加强市场监管，维护市场秩序，推动可持续发展，促进共同富裕，弥补市场失灵。

**三个扣分点**
- **政府作用不是代替市场**：市场在资源配置中起决定性作用，政府更好发挥作用，二者是有机统一的。
- **宏观调控 ≠ 行政命令**：主要用财政政策、货币政策等经济手段，不是直接给企业下指标。
- **社会主义市场经济体制的基本特征**要记全：党的领导、公有制为主体多种所有制共同发展、共同富裕根本目标、科学宏观调控有效政府治理。

**四张图**
1. 社会主义市场经济体制“四大特征”：坚持党的领导、公有制为主体多种所有制共同发展、以共同富裕为根本目标、科学宏观调控有效政府治理。四根柱子撑起一个“体制”屋顶。
2. 政府五项经济职能：宏观调控、市场监管、公共服务、社会管理、环境保护（按教材表述：保持宏观经济稳定、加强和优化公共服务、保障公平竞争、加强市场监管、维护市场秩序、推动可持续发展、促进共同富裕、弥补市场失灵）。用“一只手的五根手指”图。
3. 财政政策 vs 货币政策工具箱：财政（税收、政府支出、国债、转移支付）vs 货币（存款准备金率、利率、公开市场操作）；各自“什么时候用、往哪个方向调”。
4. “有效市场 + 有为政府”配合图：市场负责“效率”，政府负责“公平与稳定”；中间是“边界”，标注“不越位、不缺位、不错位”。

**互动模型**：滑块＝政府财政刺激力度 s（-100–100；负=紧缩，0=中性，正=扩张）
```js
ad  = 100 + 0.5 * s;    // 总需求指数
gap = ad - 100;          // 产出缺口：正=过热，负=需求不足
inf = 0.3 * gap;         // 物价涨幅（%）
```
`cases`：`{v:-100,eq:{ad:50,gap:-50,inf:-15}}`、`{v:0,eq:{ad:100,gap:0,inf:0}}`、`{v:60,eq:{ad:130,gap:30,inf:9}}`。

Autopilot：`[{t:0,v:-80},{t:1.2,v:-80},{t:4,v:0},{t:6.5,v:0},{t:9,v:80},{t:11,v:80},{t:13,v:-80}]`，keys `[-80,0,80]`。
**停留帧在 s=0**（总需求与潜在产出匹配，物价稳定）。
状态：`gap < -5`「需求不足，应扩张」；`-5<=gap<=5`「供求基本平衡」；`gap > 5`「经济过热，应紧缩」。
`.gx-note` 说明：模型把“潜在产出”固定为 100，只演示“总需求—产出缺口—物价”的方向关系；真实宏观调控比这复杂。

**例题**（措施/评析类）
题干：当前部分行业需求不足、就业压力加大。有人认为“政府直接给企业下生产指标最快”。请评析。
5 步：① 审题，锁定“政府经济职能/宏观调控”；② 需求不足时，政府应实施扩张性财政政策和稳健/宽松货币政策；③ “直接下生产指标”是行政命令，容易扭曲市场，不是宏观调控的主要手段；④ 政府还应加强公共服务、社会保障、营商环境，稳定预期；⑤ 收口：有效市场 + 有为政府，既不能缺位，也不能越位。
答案分点。

**六问**
① 政府作用是不是代替市场？② 财政政策和货币政策有什么区别？③ 政府直接规定价格好不好？④ 宏观调控就是行政命令吗？⑤ 为什么政府要弥补市场失灵？⑥ 共同富裕是不是“杀富济贫”？

**易错**
- ✗ 发挥政府作用就是政府管得越多越好 → ✓ 政府要“有为”但“不越位”，市场起决定性作用。
- ✗ 宏观调控就是政府直接给企业下指标 → ✓ 主要用财政、货币等经济手段，间接调控。
- ✗ 财政政策和货币政策是一回事 → ✓ 财政靠税收/支出/国债，货币靠利率/准备金/公开市场操作。
- ✗ 社会主义市场经济就是“市场经济 + 政府补贴” → ✓ 有党的领导、公有制主体、共同富裕目标、有效政府治理等制度特征。
- ✗ 政府只要把经济增速搞上去就行 → ✓ 还要稳物价、保就业、促公平、可持续、防风险。
- ✗ 市场失灵了，政府就应直接替市场经营 → ✓ 政府弥补失灵，不是取代市场。
- ✗ 共同富裕就是同步富裕、平均分配 → ✓ 是全体人民共同富裕，不是少数人富裕，也不是平均主义。

**语气要求**：基础一般的学生。用“经济冷了怎么办”“政府能不能直接定价”这类问题开场；把“宏观调控”翻译成“给经济踩油门/踩刹车”。每段不超过 3 行。不要用禁用语。
