# 本节规格（只读这一节，不要读别的页的 spec）

## bx2-c2-s1 使市场在资源配置中起决定性作用

**一句话**：市场像一只“看不见的手”，用**价格、供求、竞争**三个信号指挥生产；但它不是万能的，会失灵、会抽风，所以还需要政府（下一框）。

**生活钩子**：从一杯奶茶开场：夏天排队，老板涨价；隔壁店跟着降价；第二年一条街开了五家奶茶店，又倒了两家。问：谁在指挥？没有一个人下命令，但大家都动了——这就是价格机制。

**课本原话**
1. 市场在资源配置中起决定性作用。市场决定资源配置是市场经济的一般规律。
2. 市场配置资源主要是通过价格、供求、竞争等机制来进行的。
3. 市场调节不是万能的，存在自发性、盲目性、滞后性等弊端。

**三个扣分点**
- **“决定性作用”不是“政府什么都不管”**：市场决定资源配置，政府更好发挥作用，两者不是对立。
- **市场调节的三个弊端要分得清**：自发性（为了赚钱不择手段）、盲目性（一哄而上）、滞后性（事后才知道）。
- **市场失灵不等于市场不好**：公共物品、外部性、垄断、信息不对称，这些是市场“管不了”的领域。

**四张图**
1. 价格—供求—竞争循环图：价格上涨 → 生产扩大、需求减少 → 供过于求 → 价格下跌 → 生产缩小、需求增加。用环形箭头。
2. 需求曲线与供给曲线：横轴数量、纵轴价格；需求向下、供给向上，交点是均衡点；标出“供不应求（短缺）”和“供过于求（过剩）”两个区域。
3. 市场调节三弊端：三格漫画式卡片——自发性（假冒伪劣、坑蒙拐骗）、盲目性（看别人种蒜赚钱都去种）、滞后性（今年价格高，明年才扩产，上市时已经跌了）。
4. 市场失灵的四种情形：公共物品（路灯、国防）、外部性（污染）、垄断（独家供水）、信息不对称（二手车、保健品）。每格一句“市场为什么管不了”。

**互动模型**：滑块＝市场价格 P（4–16，单位元/杯）
```js
demand = 120 - 6 * P;     // 需求量
supply = 6 * P;           // 供给量
gap    = supply - demand; // 正=过剩，负=短缺
```
`cases`：`{v:4,eq:{demand:96,supply:24,gap:-72}}`、`{v:10,eq:{demand:60,supply:60,gap:0}}`、`{v:14,eq:{demand:36,supply:84,gap:48}}`。

Autopilot：`[{t:0,v:14},{t:1.2,v:14},{t:4,v:10},{t:6.5,v:10},{t:9,v:6},{t:11,v:6},{t:13,v:14}]`，keys `[14,10,6]`。
**停留帧在 P=10**（供给量=需求量，均衡价格）。
状态：`P<9.5`「供不应求，价格有上涨压力」；`9.5<=P<=10.5`「供求均衡」；`P>10.5`「供过于求，价格有下跌压力」。
`.gx-note` 说明：把价格当外部拨动的量，是为了看“价格偏离均衡后，供求缺口会把它推回去”；现实中价格由供求共同决定。

**例题**（图表/传导类）
题干：某年大蒜价格大涨，农民一哄而上扩种，第二年大蒜集中上市，价格暴跌。请用市场调节的知识分析。
5 步：① 审题，锁定“市场调节的弊端”；② 价格大涨→信号→农民扩种，体现市场配置资源；③ 一哄而上体现**盲目性**；④ 上市时才知道供过于求，体现**滞后性**；⑤ 收口：市场调节有弊端，需要政府引导和信息服务，但不能因此否定市场决定性作用。
答案分点。

**六问**
① 市场决定价格，是不是政府就不能管价格？② 供不应求就应该涨价吗？③ 为什么有人囤药、造假？这是哪个弊端？④ 盲目性和滞后性到底怎么分？⑤ 路灯、国防为什么不能靠市场提供？⑥ 市场失灵了怎么办？

**易错**
- ✗ 市场在资源配置中起决定性作用，所以政府越少越好 → ✓ 市场决定性作用 + 政府更好发挥作用，两者结合。
- ✗ 市场调节的弊端是市场经济的根本缺陷，所以要限制市场 → ✓ 是市场调节固有的局限性，要通过宏观调控弥补，不是否定市场。
- ✗ 自发性就是盲目性，都是“一哄而上” → ✓ 自发性是逐利驱动的不当行为；盲目性是信息不全、决策跟风；滞后性是事后调整。
- ✗ 价格上涨就是坏事 → ✓ 价格上涨是市场信号，能引导生产、抑制需求；关键看是否被操纵。
- ✗ 公共物品也可以由市场充分提供 → ✓ 公共物品非竞争性、非排他性，市场供给不足，需要政府提供。
- ✗ 市场失灵是市场机制本身坏了 → ✓ 是市场在某些领域管不了，需要政府弥补。
- ✗ 市场竞争必然导致垄断 → ✓ 竞争可能产生垄断，所以要反垄断、维护公平竞争。

**语气要求**：基础一般的学生。用奶茶、蒜你狠、囤药这些生活例子开场；每张图先告诉学生“先看哪里”。术语要出现“价格机制、供求机制、竞争机制、自发性、盲目性、滞后性、市场失灵”。每段不超过 3 行。不要用禁用语。
