# 本节规格（只读这一节，不要读别的页的 spec）

## bx2-c1-s1 公有制为主体 多种所有制经济共同发展

**一句话**：公有制为主体，说的是两件事——**公有资产在社会总资产中占优势**，**国有经济控制国民经济命脉、起主导作用**；不是“所有行业都归国企干”。

**生活钩子**：从学生每天接触的东西开场：国家电网、复兴号、三大运营商、快递、奶茶店、直播间。问一句：哪些是国企，哪些是民企？为什么电网、铁路不能全交给市场？先让学生感到“这事跟我有关”，再进课本。

**课本原话**
1. 公有制为主体、多种所有制经济共同发展，是我国社会主义初级阶段的基本经济制度。
2. 公有制经济包括国有经济、集体经济以及混合所有制经济中的国有成分和集体成分。国有经济控制国民经济命脉，对经济发展起主导作用。
3. 公有资产在社会总资产中占优势。非公有制经济是社会主义市场经济的重要组成部分。

**三个扣分点**
- **公有制主体地位 ≠ 国有经济主导作用**：主体地位讲“公有资产占优势”，主导作用讲“国有经济控制命脉”。两个判断不能互换。
- **公有制经济 ≠ 国有经济**：还包括集体经济、混合所有制经济中的国有成分和集体成分。
- **非公有制经济是“社会主义市场经济的重要组成部分”**，不是“社会主义经济”的组成部分，不能漏掉“市场”两个字。

**四张图**
1. 所有制结构全景：左边公有制（国有经济、集体经济、混合所有制中的公有成分），右边非公有制（个体、私营、外资），中间一条“共同发展”的桥；每类举一个学生熟悉的例子。
2. 主体地位的两个判据：双支柱图。左柱“公有资产在社会总资产中占优势”，右柱“国有经济控制国民经济命脉”，两根柱子都立住才叫“主体地位稳固”。
3. 国有经济“控制力”地图：能源、交通、通信、军工、金融等关键行业标红；家电、餐饮、服装等竞争性行业标绿。说明“控制力”不是“什么都自己干”，而是“关键时候握得住”。
4. 公有制 vs 非公有制对照表：地位、作用、国家政策三列；只高亮“地位”这一行，因为这是最容易被偷换的。

**互动模型**：滑块＝公有资产占社会总资产比重 x（30–90，单位 %）
```js
pub = x;
non = 100 - x;
adv = x >= 50 ? 1 : 0;      // 是否“占优势”，50% 只是教学分界线
```
`cases`：`{v:70,eq:{pub:70,non:30,adv:1}}`、`{v:52,eq:{pub:52,non:48,adv:1}}`、`{v:40,eq:{pub:40,non:60,adv:0}}`。

Autopilot：`[{t:0,v:70},{t:1.2,v:70},{t:4,v:52},{t:6.5,v:52},{t:9,v:38},{t:11,v:38},{t:13,v:70}]`，keys `[70,52,38,60]`。
**停留帧在 x=52**（刚过半：优势还在，但不牢）——这是全篇最值钱的一帧。
状态：`x>=60`「公有资产占优势，主体地位稳固」；`50<=x<60`「刚过半，优势不牢」；`x<50`「公有资产不占优势，主体地位受挑战」。
画面右侧固定画一根“国有经济控制力：强（关键行业）”的柱子，并在 `.gx-note` 里说明：这张图只调第一个判据，第二个判据在现实里同样关键。

**例题**（辨析类）
题干：“公有制为主体，就意味着国有经济在所有行业都占优势。”判断并说明理由。
5 步：① 审题，锁定“公有制主体地位”与“国有经济主导作用”两个概念；② 主体地位的第一个判据是公有资产在社会总资产中占优势，不是“所有行业”；③ 国有经济的主导作用体现在控制国民经济命脉，不是包办一切；④ 非公有制经济在竞争性行业可以占优势，这不否定公有制主体地位；⑤ 收口：主体地位是就全国而言，两个判据一起看。
答案要分点，能直接抄。

**六问**
① 公有制经济就是国有企业吗？② 公有制主体地位看比重还是看控制力？③ 国有经济的主导作用表现在哪里？④ 非公有制经济为什么重要？⑤ “两个毫不动摇”是不是只对国企？⑥ 混合所有制经济里的国有成分算不算公有制经济？

**易错（左边必须是学生真会写的错句）**
- ✗ 公有制为主体就是国企在所有行业占优势 → ✓ 公有资产在社会总资产中占优势，国有经济控制国民经济命脉。
- ✗ 公有制经济只有国有经济 → ✓ 还包括集体经济和混合所有制中的国有、集体成分。
- ✗ 非公有制经济是社会主义经济的重要组成部分 → ✓ 是社会主义市场经济的重要组成部分（多“市场”两字）。
- ✗ 国有经济主导作用就是国有经济比重越大越好 → ✓ 主导看控制力，不看数量比重。
- ✗ 股份制企业都是公有制企业 → ✓ 只有其中的国有、集体成分属于公有制经济。
- ✗ 公有制和非公有制是对立的，只能二选一 → ✓ 两者都是社会主义市场经济的重要组成部分，共同发展。
- ✗ 公有制主体地位靠政府保护就能维持 → ✓ 归根到底靠公有制经济自身活力、控制力和竞争力。

**语气要求**：基础一般的学生。每段不超过 3 行；先给生活例子，再给课本原话，再翻译成人话。不要用“简单来说”“众所周知”“其实很简单”“只要记住”。可以多用“你可能会问”“注意这里有个坑”“答题时写这句”。
