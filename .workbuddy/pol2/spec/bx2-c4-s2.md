# 本节规格（只读这一节，不要读别的页的 spec）

## bx2-c4-s2 我国的社会保障

**一句话**：社会保障是一张“安全网”：**社会保险是核心，社会救助是最后一道防线，社会福利是更高层次，社会优抚是特殊保障**；网要够大，也不能大到把船压沉——保障水平要与经济发展水平相适应。

**生活钩子**：从“一场病”开场：家里人住院，医保报销一部分；失业了有失业保险；老了有养老金；遇到灾害有救助。问：这些钱从哪来？为什么不能“什么都国家包”？引出社保的构成和“适度原则”。

**课本原话**
1. 社会保障是保障和改善民生、维护社会公平、增进人民福祉的基本制度保障。
2. 社会保障主要由社会保险、社会救助、社会福利、社会优抚等组成，其中社会保险是社会保障体系的核心。
3. 完善社会保障体系，要坚持覆盖全民、统筹城乡、公平统一、安全规范、可持续。

**三个扣分点**
- **社会保险 ≠ 商业保险**：社会保险强制、保基本、政府主导；商业保险自愿、营利、补充。
- **社会救助是“最后一道防线”**，不是谁都能领；社会福利是更高层次，不是“发钱”。
- **保障水平要与经济发展水平相适应**：太低保障不足，太高会加重财政负担、养懒人。

**四张图**
1. 社保“四支柱”：社会保险（核心，五险）、社会救助（最后一道防线）、社会福利（最高层次）、社会优抚（特殊保障）；用一张桌子四条腿/四层金字塔。
2. 社保运行闭环：参保缴费 → 社保基金 → 待遇发放 → 再分配；用环形箭头，旁注“大数法则、互助共济”。
3. 商业保险 vs 社会保险：两栏对照（性质、是否强制、目的、资金来源、保障水平）；只高亮“是否强制”这一行。
4. 保障水平“适度”曲线：横轴保障水平，纵轴“覆盖效果”和“财政负担”；两条曲线，一条增长放缓，一条加速上升；标出“保障不足—适度—不可持续”三段。

**互动模型**：滑块＝社会保障水平 L（0–100）
```js
cover  = 100 * (1 - Math.exp(-L / 30));   // 覆盖效果：先快后慢
burden = 0.7 * L + 0.005 * L * L;          // 财政负担：越往后越陡
```
`cases`：`{v:0,eq:{cover:0,burden:0}}`、`{v:50,eq:{cover:81.1,burden:47.5}}`、`{v:100,eq:{cover:96.4,burden:120}}`。

Autopilot：`[{t:0,v:20},{t:1.2,v:20},{t:4,v:55},{t:6.5,v:55},{t:9,v:95},{t:11,v:95},{t:13,v:20}]`，keys `[20,55,95]`。
**停留帧在 L=55**（覆盖效果已经不错，财政负担还可承受——适度区间）。
状态：`L<40`「保障不足」；`40<=L<=70`「与经济发展水平基本适应」；`L>70`「财政压力过大，不可持续」。
`.gx-note` 说明：两条曲线是教学示意，不是精算模型；真实社保要精算人口结构、缴费率、替代率等因素。

**例题**（评析类）
题干：有人建议“把养老金标准一下子提高到发达国家的水平，才叫有保障”。请评析。
5 步：① 审题，锁定“社会保障水平与经济发展水平相适应”；② 提高保障水平能增进民生福祉，方向可取；③ 但脱离经济发展水平、财政承受能力，会导致基金不可持续；④ 社会保障要坚持公平原则、权责一致、与经济发展水平相适应；⑤ 收口：尽力而为、量力而行，覆盖全民、统筹城乡、公平统一、安全规范、可持续。
答案分点。

**六问**
① 社会保障就是商业保险吗？② 社会保险包括哪五险？③ 社会救助是不是养懒人？④ 为什么不能搞“高福利”？⑤ 城乡居民养老金为什么比职工低？⑥ 社保基金会不会“穿底”？

**易错**
- ✗ 社会保障就是国家发钱 → ✓ 包括社会保险、社会救助、社会福利、社会优抚等，以保险为核心。
- ✗ 社会保险和商业保险是一回事 → ✓ 社会保险强制、保基本、政府主导；商业保险自愿、营利、补充。
- ✗ 社会救助谁都可以领 → ✓ 针对因自然灾害或其他原因陷入生存困境的公民，是最后一道防线。
- ✗ 保障水平越高越好 → ✓ 要与经济发展水平相适应，否则不可持续。
- ✗ 社会保障只是政府的事 → ✓ 国家、单位、个人共同参与，权责一致。
- ✗ 有了社保就不用商业保险 → ✓ 商业保险是补充，可满足多层次需求。
- ✗ 社保基金是“自己存的钱”，不会统筹 → ✓ 社会保险有互助共济和再分配功能。

**语气要求**：基础一般的学生。用“一场病”“一张安全网”“四条腿的桌子”这些具体画面开场；把“社会保险/社会救助/社会福利/社会优抚”用一句话分别讲清。每段不超过 3 行。不要用禁用语。
