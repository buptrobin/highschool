# 本节规格（只读这一节，不要读别的页的 spec）

## bx2-c1-s2 坚持“两个毫不动摇”

**一句话**：“两个毫不动摇”不是二选一，而是**两条腿走路**：公有制经济要做强做优做大，非公有制经济要鼓励、支持、引导，两个轮子一起转，经济才走得稳。

**生活钩子**：从“找工作”开场：你想去国家电网、中国商飞，还是去比亚迪、蜜雪冰城、直播间？这些单位背后是不同所有制。再问：如果只扶持一边，会发生什么？用“两条腿走路”贯穿全页。

**课本原话**
1. 毫不动摇巩固和发展公有制经济，毫不动摇鼓励、支持、引导非公有制经济发展。
2. 国有企业是国有经济最主要的实现形式，是中国特色社会主义的重要物质基础和政治基础，是推进国家现代化、保障人民共同利益的重要力量。
3. 非公有制经济是社会主义市场经济的重要组成部分，是我国经济社会发展的重要基础。

**三个扣分点**
- **“两个毫不动摇”是“巩固和发展公有制经济”+“鼓励、支持、引导非公有制经济”**，不是“公有制为主、非公有制为辅”这么简单。
- **国有企业改革不是私有化**：是做强做优做大国有资本和国有企业，增强竞争力、创新力、控制力、影响力、抗风险能力。
- **支持民营经济不是“给特权”**：是优化营商环境、保护产权、公平竞争、破除市场准入壁垒。

**四张图**
1. “两条腿走路”结构图：左腿公有制经济（国企、集体），右腿非公有制经济（个体、私营、外资），中间是“共同发展”；缺一条腿，身体就歪。
2. 国企改革“五个力”：竞争力、创新力、控制力、影响力、抗风险能力；用五个齿轮或五根柱子，说明“做强做优做大”不是“做大数量”。
3. 民营经济的贡献“56789”：50% 以上税收、60% 以上 GDP、70% 以上技术创新成果、80% 以上城镇劳动就业、90% 以上企业数量。标注“常见概括，具体年份口径略有差异，不是精确统计”。
4. 营商环境的“加减法”：减（减税降费、破除壁垒、缩短负面清单）+ 加（产权保护、公平竞争、融资支持）；用一杆秤或一张清单表示。

**互动模型**：滑块＝政策资源与精力在两边的分配 x（0–100；0＝全给公有制，50＝两边均衡，100＝全给非公有制）
```js
pub   = 100 - 0.8 * Math.max(0, x - 50);   // 公有制经济活力
pri   = 100 - 0.8 * Math.max(0, 50 - x);   // 非公有制经济活力
total = (pub + pri) / 2;                    // 整体经济活力
```
`cases`：`{v:20,eq:{pub:100,pri:76,total:88}}`、`{v:50,eq:{pub:100,pri:100,total:100}}`、`{v:80,eq:{pub:76,pri:100,total:88}}`。

Autopilot：`[{t:0,v:20},{t:1.2,v:20},{t:4,v:50},{t:6.5,v:50},{t:9,v:80},{t:11,v:80},{t:13,v:20}]`，keys `[20,50,80]`。
**停留帧在 x=50**（两条腿一样长，整体活力最高）。
状态：`x<35`「偏科：民营经济被冷落」；`35<=x<=65`「两条腿走路」；`x>65`「偏科：公有制经济被削弱」。
`.gx-note` 说明：x 是“政策资源分配”的示意刻度，50 表示两边都用力，不是数学定理；模型只表达“此消彼长”与“共同发展”的差别。

**例题**（原因/措施类）
题干：某地为了“做大国有经济”，把土地、贷款、项目都给国企，对民企设置各种门槛。请运用“两个毫不动摇”的知识，评析这一做法。
5 步：① 审题，锁定“两个毫不动摇”；② 指出做法违背“鼓励、支持、引导非公有制经济”；③ 说明非公有制经济的地位和作用（重要组成部分、重要基础、就业/创新/税收）；④ 说明国企改革的方向是做强做优做大，不是挤占民企空间；⑤ 收口：坚持两个毫不动摇，优化营商环境，公平竞争。
答案分点，术语到位。

**六问**
① “两个毫不动摇”是不是自相矛盾？② 国企和民企谁更重要？③ “民营经济离场论”错在哪？④ 国企改革是不是私有化？⑤ 发展混合所有制经济是不是搞私有化？⑥ 为什么要给民营企业减税降费？

**易错**
- ✗ 两个毫不动摇就是公有制为主、非公有制为辅 → ✓ 两个都要“毫不动摇”，不是主辅关系。
- ✗ 支持民营经济就是让民营经济取代公有制经济 → ✓ 两者共同发展，公有制主体地位不动摇。
- ✗ 国企改革就是私有化、卖掉国企 → ✓ 是做强做优做大国有资本和国有企业。
- ✗ 民营经济只能干小生意，成不了大事 → ✓ 民营经济是重要组成部分、重要基础，贡献大量税收、GDP、创新和就业。
- ✗ 给民企减税降费是“偏心” → ✓ 是优化营商环境、公平竞争，不是给特权。
- ✗ 混合所有制改革就是私有化 → ✓ 混合所有制经济中的国有、集体成分仍属公有制经济。
- ✗ 国有企业效率一定低，民营经济效率一定高 → ✓ 要具体分析，国企改革正是为了提高活力与效率。

**语气要求**：基础一般的学生。用“两条腿”“两个轮子”这类生活比喻开场，但比喻之后必须落到课本术语“公有制经济、非公有制经济、两个毫不动摇”。每段不超过 3 行。不要用禁用语。
