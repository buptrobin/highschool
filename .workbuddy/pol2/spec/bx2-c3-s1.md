# 本节规格（只读这一节，不要读别的页的 spec）

## bx2-c3-s1 贯彻新发展理念

**一句话**：新发展理念是五块板拼成的一只木桶——**创新、协调、绿色、开放、共享**，只补一块，水还是会从最短的那块板漏出去。

**生活钩子**：从“手机芯片被卡脖子”“老家河水变清”“村里通了快递”“进博会买全球”“医保报销”五个生活画面开场，让学生先感到五个理念不是五个口号，而是五件正在发生的事。再用“木桶”把五块板串起来。

**课本原话**
1. 坚持以人民为中心的发展思想。
2. 贯彻创新、协调、绿色、开放、共享的新发展理念。
3. 创新是引领发展的第一动力；协调是持续健康发展的内在要求；绿色是永续发展的必要条件和人民对美好生活追求的重要体现；开放是国家繁荣发展的必由之路；共享是中国特色社会主义的本质要求。

**三个扣分点**
- **五个理念各解决什么问题，不能串**：创新→动力，协调→平衡，绿色→人与自然，开放→内外联动，共享→公平正义。
- **新发展理念是一个整体**：要一体坚持、一体贯彻，不能只抓一项。
- **以人民为中心 ≠ 只发钱**：发展为了人民、发展依靠人民、发展成果由人民共享。

**四张图**
1. 五大理念“一张图”：五个方块，每个写“解决什么问题 + 一句课本原话 + 一个生活例子”。例：创新—芯片/新能源；协调—城乡/区域；绿色—垃圾分类/长江禁渔；开放—进博会/一带一路；共享—医保/义务教育。
2. 以人民为中心的三问：发展为了谁（为了人民）、依靠谁（依靠人民）、成果归谁（由人民共享）。用三个同心圆或三问三答卡片。
3. “五块板”木桶图：五块板分别标创新/协调/绿色/开放/共享，水位由最短的板决定；旁边写“只补一块，水还是漏”。
4. 五个生活场景对照：一张表，左列生活场景，右列对应理念和具体做法；只高亮“创新”一行（因为最容易和“科技”画等号）。

**互动模型**：滑块＝创新投入/创新得分 x（20–100；其余四项固定在 60 分）
```js
innov  = x;
others = 60;
total  = Math.min(innov, others);   // 木桶水位=最短的板
```
`cases`：`{v:30,eq:{innov:30,others:60,total:30}}`、`{v:60,eq:{innov:60,others:60,total:60}}`、`{v:90,eq:{innov:90,others:60,total:60}}`。

Autopilot：`[{t:0,v:20},{t:1.2,v:20},{t:4,v:80},{t:6.5,v:80},{t:9,v:95},{t:11,v:95},{t:13,v:20}]`，keys `[20,60,80,95]`。
**停留帧在 x=80**（创新已经超过 60，但总水位仍被其他四项卡在 60——全篇最反直觉的一帧）。
状态：`x<60`「短板在创新，综合水平被拖住」；`x>=60`「创新上来了，但短板转到其他四项，总水平仍是 60」。
`.gx-note` 说明：其余四项固定在 60 分，只为演示“木桶效应”；现实中五项要一起补，不能理解为“创新不重要”。

**例题**（评析类）
题干：某地提出“只要把芯片产业搞上去，就是贯彻了新发展理念”，于是把资金全投芯片，忽视污染治理和城乡差距。请评析。
5 步：① 审题，锁定“新发展理念是一个整体”；② 创新是引领发展的第一动力，抓芯片有合理性；③ 但只抓创新，忽视绿色、协调、共享，违背“一体坚持、一体贯彻”；④ 污染和城乡差距会反过来制约发展，木桶短板会拖低整体水平；⑤ 收口：以人民为中心，五大理念统一贯彻。
答案分点。

**六问**
① 五个理念怎么记才不混？② 创新就是科技吗？③ 协调是不是平均发展？④ 绿色是不是不要发展？⑤ 开放是不是依赖外国？⑥ 共享是不是平均分配？

**易错**
- ✗ 新发展理念就是五个口号，背下来就行 → ✓ 五个理念各解决一个实际问题，要落到具体做法。
- ✗ 创新就是高科技、芯片、航天 → ✓ 创新包括理论、制度、科技、文化等各方面创新，科技创新是核心。
- ✗ 协调就是平均发展、一样富 → ✓ 是统筹城乡、区域、经济社会等协调发展，不是平均主义。
- ✗ 绿色就是少发展、不发展 → ✓ 是绿色发展、可持续发展，绿水青山就是金山银山。
- ✗ 开放就是依赖外国、市场换技术 → ✓ 是内外联动、互利共赢，独立自主与对外开放统一。
- ✗ 共享就是平均分配、养懒人 → ✓ 是人人参与、人人尽力、人人享有，不是平均主义。
- ✗ 只抓创新就能高质量发展 → ✓ 新发展理念是一个整体，要一体贯彻。

**语气要求**：基础一般的学生。用“木桶”“五块板”贯穿全页；每个理念必须配一个学生身边的具体例子（芯片、快递进村、垃圾分类、进博会、医保）。每段不超过 3 行。不要用禁用语。
