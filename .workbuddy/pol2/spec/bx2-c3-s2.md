# 本节规格（只读这一节，不要读别的页的 spec）

## bx2-c3-s2 推动高质量发展

**一句话**：高质量发展不是“不要速度”，而是**换发动机**：从“多出汗、多占地、多耗能”转到“靠技术、靠品牌、靠效率”，把饭碗端在自己手里。

**生活钩子**：从“一双运动鞋”开场：同样一双鞋，代工只赚几块钱，贴上品牌、加上研发，能卖几百上千。问：钱被谁赚走了？中国制造下一步往哪走？引出“微笑曲线”和“实体经济”。

**课本原话**
1. 高质量发展是全面建设社会主义现代化国家的首要任务。
2. 建设现代化产业体系，坚持把发展经济的着力点放在实体经济上。
3. 加快构建以国内大循环为主体、国内国际双循环相互促进的新发展格局。

**三个扣分点**
- **高质量发展 ≠ 不要速度**：是质量第一、效益优先，速度是合理区间内的速度。
- **实体经济是着力点**：不是“虚拟经济不重要”，而是不能脱实向虚。
- **新发展格局不是“闭关锁国”**：以国内大循环为主体，国内国际双循环相互促进。

**四张图**
1. 高质量发展“三个转变”：转方式（粗放→集约）、优结构（低端→中高端）、换动力（要素驱动→创新驱动）。用三根箭头或三档换挡图。
2. 现代化产业体系：以实体经济为根基，向上是制造强国、质量强国、航天强国、交通强国、网络强国、数字中国；用一棵树表示“根—干—冠”。
3. 三张“组合牌”：乡村振兴（农业农村优先）、区域协调（东中西部/城市群）、高水平开放（制度型开放、一带一路）。用三张卡片并列。
4. 微笑曲线：横轴“研发—制造—品牌—服务”，纵轴“附加值”；两端高、中间低；标出“代工组装”在谷底，“研发/品牌”在两端。

**互动模型**：滑块＝在产业链上的位置 p（0=研发端，50=组装制造，100=品牌服务端）
```js
value = 20 + 80 * Math.pow((p - 50) / 50, 2);   // 附加值指数：中间 20，两端 100
gap   = value - 20;                              // 比谷底高多少
```
`cases`：`{v:10,eq:{value:71.2,gap:51.2}}`、`{v:50,eq:{value:20,gap:0}}`、`{v:90,eq:{value:71.2,gap:51.2}}`。

Autopilot：`[{t:0,v:50},{t:1.2,v:50},{t:4,v:10},{t:6.5,v:10},{t:9,v:90},{t:11,v:90},{t:13,v:50}]`，keys `[50,10,90]`。
**停留帧在 p=10**（研发端：附加值高，但需要长期投入）。
状态：`p<20`「研发端：技术含量高」；`20<=p<=80`「组装制造：附加值低」；`p>80`「品牌服务端：附加值高」。
`.gx-note` 说明：曲线形状是“微笑曲线”的教学示意，数值不是某行业统计；现实中不同行业曲线形状不同。

**例题**（措施类）
题干：某地为国外品牌代工运动鞋，一双只赚 5 元，利润越来越薄。请运用“推动高质量发展”的知识，提出两条转型建议。
5 步：① 审题，锁定“高质量发展、现代化产业体系、实体经济”；② 指出代工处在微笑曲线谷底，附加值低；③ 建议向研发端延伸：加大研发投入、掌握核心技术、打造自主品牌；④ 建议向品牌服务端延伸：提升设计、营销、售后服务；⑤ 收口：把发展着力点放在实体经济上，推动产业转型升级。
答案分点，两条建议要具体。

**六问**
① 高质量发展是不是不要速度了？② 实体经济和虚拟经济是什么关系？③ 乡村振兴是不是只让农民种地？④ 区域协调是不是平均发展？⑤ 对外开放是不是会被“卡脖子”？⑥ 微笑曲线的两端到底是什么？

**易错**
- ✗ 高质量发展就是不要速度、越慢越好 → ✓ 是质量第一、效益优先，保持合理速度。
- ✗ 发展实体经济就是不要互联网、不要金融 → ✓ 实体经济是根基，虚拟经济要服务实体经济，不能脱实向虚。
- ✗ 乡村振兴就是让农民回去种地 → ✓ 是产业、人才、文化、生态、组织全面振兴。
- ✗ 区域协调就是东部补贴西部、搞平均 → ✓ 是发挥各地比较优势、协调发展。
- ✗ 新发展格局就是闭关锁国、只靠内需 → ✓ 以国内大循环为主体，国内国际双循环相互促进。
- ✗ 高质量发展只是企业的事，跟个人无关 → ✓ 涉及就业、收入、环境、公共服务，人人相关。
- ✗ 只要 GDP 增长就是高质量发展 → ✓ 还要看创新、协调、绿色、开放、共享。

**语气要求**：基础一般的学生。用“一双鞋”“代工厂”“换发动机”这些具体画面开场；每张图先告诉学生“先看哪里”。术语要出现“高质量发展、现代化产业体系、实体经济、新发展格局、乡村振兴、区域协调”。每段不超过 3 行。不要用禁用语。
