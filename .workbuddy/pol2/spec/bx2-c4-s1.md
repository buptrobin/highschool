## bx2-c4-s1 我国的个人收入分配

**一句话**：分配制度是“蛋糕怎么切”：**按劳分配为主体、多种分配方式并存**；先由市场切一次（初次分配），再由政府切一次（再分配），最后还有社会自愿的第三次分配。

**生活钩子**：从“小张一家的收入”开场：爸爸在国企上班拿工资，妈妈开网店赚经营收入，爷爷把房子出租收租金，奶奶领养老金，小张拿奖学金。问：这些钱分别叫什么收入？为什么同一家人收入来源不一样？引出分配制度。

**课本原话**
1. 按劳分配为主体、多种分配方式并存，是我国社会主义基本经济制度的重要内容。
2. 按劳分配是社会主义的分配原则。在生产资料公有制条件下，以劳动者提供的劳动为尺度分配个人消费品，多劳多得、少劳少得。
3. 生产要素由市场评价贡献、按贡献决定报酬。居民收入来源包括工资性收入、经营性收入、财产性收入、转移性收入。

**三个扣分点**
- **按劳分配 ≠ 平均分配**：多劳多得、少劳少得，承认差别。
- **按生产要素分配 ≠ 剥削**：劳动、资本、土地、知识、技术、管理、数据等按贡献参与分配，是社会主义基本经济制度的重要内容。
- **三次分配要分清**：初次分配靠市场（工资、利润），再分配靠政府（税收、社保、转移支付），第三次分配靠自愿（慈善捐赠）。

**四张图**
1. 分配制度全景：上层“按劳分配为主体、多种分配方式并存”；下层三条通道“初次分配（市场）—再分配（政府）—第三次分配（社会）”；用三层漏斗图。
2. 按劳分配 vs 按生产要素分配：两栏对照，判据是“在什么所有制经济中、按什么尺度分配”；只高亮“分配尺度”这一行。
3. 居民收入四来源：工资性收入（上班）、经营性收入（开店/直播）、财产性收入（房租/利息/股票分红）、转移性收入（养老金/低保/补贴）；用四个钱包图。
4. 橄榄型分配结构：低收入者少、中等收入者多、高收入者少；标出“提低、扩中、调高”，并注明“不是杀富济贫，是形成中间大、两头小的橄榄型”。

**互动模型**：滑块＝再分配力度 r（0–100；税收、社保、转移支付等调节力度）
```js
gini  = 0.47 - 0.0017 * r;    // 基尼系数：0.47 → 0.30
mid   = 30 + 0.25 * r;         // 中等收入群体占比（%）
low   = 15 + 0.20 * r;         // 低收入群体收入占比（%）
```
`cases`：`{v:0,eq:{gini:0.47,mid:30,low:15}}`、`{v:50,eq:{gini:0.385,mid:42.5,low:25}}`、`{v:100,eq:{gini:0.3,mid:55,low:35}}`。

Autopilot：`[{t:0,v:10},{t:1.2,v:10},{t:4,v:55},{t:6.5,v:55},{t:9,v:90},{t:11,v:90},{t:13,v:10}]`，keys `[10,55,90]`。
**停留帧在 r=55**（再分配明显见效，中等收入群体扩大）。
状态：`r<30`「差距较大，再分配不足」；`30<=r<=70`「差距缩小中」；`r>70`「分配格局较合理，但要注意效率」。
`.gx-note` 说明：基尼系数 0.47 取近年国家统计局公布值的近似，降幅是教学示意，不是政策效果预测；第三次分配不在模型内。

**例题**（原因/措施类）
题干：小张的爸爸在国企上班，妈妈开网店，爷爷出租房屋，奶奶领养老金。请指出四人的收入分别属于哪种分配方式/收入来源，并说明为什么要完善个人收入分配。
5 步：① 审题，先分“分配方式”和“收入来源”两套口径；② 爸爸：公有制经济中的按劳分配，工资性收入；③ 妈妈：按劳动/经营要素分配，经营性收入；④ 爷爷：按土地/财产要素分配，财产性收入；⑤ 奶奶：再分配/转移性收入；收口：完善分配制度，提低扩中调高，促进共同富裕。
答案分点，注意区分口径。

**六问**
① 按劳分配就是平均分配吗？② 按生产要素分配就是剥削吗？③ 初次分配、再分配、第三次分配怎么分？④ 财产性收入是不是“不劳而获”？⑤ 提高最低工资好不好？⑥ 共同富裕是不是同步富裕、平均富裕？

**易错**
- ✗ 按劳分配就是大家拿一样多 → ✓ 多劳多得、少劳少得，承认劳动差别。
- ✗ 按生产要素分配是资本主义的东西 → ✓ 生产要素由市场评价贡献、按贡献决定报酬，是社会主义基本经济制度的重要内容。
- ✗ 三次分配都是政府主导 → ✓ 初次分配靠市场，再分配靠政府，第三次分配靠自愿。
- ✗ 财产性收入就是不劳而获 → ✓ 是合法财产带来的收入，要保护合法收入。
- ✗ 提高劳动报酬比重就是不要资本回报 → ✓ 是提高劳动报酬在初次分配中的比重，不是否定其他要素。
- ✗ 共同富裕就是同步富裕、平均分配 → ✓ 是全体人民共同富裕，不是少数人富裕，也不是平均主义。
- ✗ 再分配力度越大越好 → ✓ 要与经济发展水平相适应，兼顾公平与效率。
