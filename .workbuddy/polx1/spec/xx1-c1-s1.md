# 本节规格

## xx1-c1-s1 国体与政体

**一句话**：国体是国家性质（谁掌握政权），政体是政权组织形式（怎么组织政权）；国体决定政体，政体具有相对独立性。

**三个扣分点**：国体不等于政体；政体不是国体的简单复制，具有相对独立性；君主立宪制是资本主义国家的政体，不能简单说成“封建残余”。

**四张图**：① 国家的构成要素（主权、人口、领土、政权），主权是国家的生命和灵魂；② 国体与政体的决定与反作用；③ 政体类型：议会制、总统制、半总统制、君主立宪制；④ 我国国体（人民民主专政）与政体（人民代表大会制度）。

**五个情境**：
1. 英国国王是国家元首，但实际权力在首相和议会｜对应：君主立宪制、议会制｜依据：国王“统而不治”，政府对议会负责。
2. 美国总统既是国家元首又是政府首脑，与国会相互制衡｜对应：总统制｜依据：总统不由议会产生，不对议会负责。
3. 法国总统由选民直接选举，总理对议会负责｜对应：半总统制｜依据：总统掌握大政方针，总理领导政府。
4. 日本天皇只做象征性国家元首｜对应：君主立宪制｜依据：天皇无实权，议会内阁掌权。
5. 中国由人民选举代表组成人民代表大会，统一行使国家权力｜对应：人民代表大会制度｜依据：我国国体是人民民主专政，政体是人民代表大会制度。

**例题**：说明国体与政体的关系。答案按“国体决定政体、政体体现国体并反作用于国体、政体具有相对独立性”展开。
