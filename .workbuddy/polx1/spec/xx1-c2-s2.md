# 本节规格

## xx1-c2-s2 和平与发展

**一句话**：和平与发展是当今时代的主题；和平是发展的前提，发展是和平的基础；霸权主义、强权政治是主要障碍；要构建人类命运共同体。

**三个扣分点**：时代主题不等于时代问题已经解决；和平与发展不是“二选一”，二者相互依存；人类命运共同体不是“中国优先”。

**四张图**：① 时代主题：和平与发展；② 和平与发展的关系；③ 主要障碍：霸权主义、强权政治、南北差距；④ 构建人类命运共同体。

**五个情境**：
1. 联合国维和行动帮助冲突地区恢复秩序｜对应：维护世界和平｜依据：和平是发展的前提。
2. “一带一路”帮助沿线国家修路、建港、发展产业｜对应：促进共同发展｜依据：发展是和平的基础。
3. 某些国家搞单边制裁、长臂管辖｜对应：霸权主义、强权政治｜依据：违反国际关系基本准则，是和平与发展的主要障碍。
4. 全球发展倡议聚焦减贫、粮食安全、发展融资｜对应：构建人类命运共同体、共同发展｜依据：不让任何一个国家掉队。
5. 疫情、气候变化等全球性问题需要各国合作｜对应：全球治理、命运与共｜依据：没有哪个国家能独善其身。

**例题**：为什么说和平与发展仍是时代主题？答案按“和平是前提、发展是基础、问题仍在但趋势未变”展开。
