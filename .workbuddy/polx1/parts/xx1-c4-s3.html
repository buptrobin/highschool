01课本怎么说

先背标准表述，再拆关键词。答题时写课本这句，不写你脑子里那句。

课本原话 · 中国与联合国的关系人教版（2019）选择性必修1 · 第四单元 第九课

中国是联合国创始会员国和安理会常任理事国，一贯支持联合国在国际事务中发挥核心作用，是联合国维和行动的重要参与者，也是联合国第二大会费国和维和摊款国。

→ 翻成人话：这一句里藏着三个身份，考试时千万分开用。①创始会员国——1945 年联合国成立，中国就在场，参与写下《联合国宪章》；②安理会常任理事国——五个常任理事国之一，对实质性决议有否决权，也承担特殊责任；③维和行动的重要参与者——出人、出钱、出装备。怎么用？材料说"派出工兵分队排雷"，你写维和；材料说"按时足额缴纳会费"，你写会费国；材料说"在安理会投了反对票"，你写常任理事国行使权利。先认身份，再写作用，句子才不会飘。

课本原话 · 真正的多边主义人教版（2019）选择性必修1 · 第四单元 第九课

中国坚定维护以联合国为核心的国际体系、以国际法为基础的国际秩序、以联合国宪章宗旨和原则为基础的国际关系基本准则，践行真正的多边主义，反对霸权主义和强权政治。

→ 翻成人话：这是一组"三个以……为……"的排比，最容易背漏中间那半句。①以联合国为核心的国际体系；②以国际法为基础的国际秩序；③以宪章宗旨和原则为基础的国际关系基本准则。三个"基础"各管一层：体系、秩序、准则，层层收窄。还有一个词要盯住——真正的多边主义。加了"真正的"三个字，是在划界：有的国家嘴上讲多边，实际拉小圈子、搞阵营对抗，那不叫多边。答题时"以联合国为核心"这七个字常常就是采分点，别省。

课本原话 · 建设性参与者与中国方案人教版（2019）选择性必修1 · 第四单元 第九课

中国是上海合作组织、金砖国家、二十国集团等重要国际组织的参与者、建设者、贡献者，推动构建人类命运共同体，提出全球发展倡议、全球安全倡议、全球文明倡议。

→ 翻成人话：先看那三个并列的"者"——参与者、建设者、贡献者。这三个词是定性，专治"中国要另起炉灶"这类错答：我们是在现有的台子上干活的人，不是拆台的人。再看三个倡议的分工：全球发展倡议管"日子怎么过好"，全球安全倡议管"仗怎么不打"，全球文明倡议管"不同文明怎么相处"。材料给减贫、粮食安全、基础设施，写发展倡议；给冲突、反恐、对话谈判，写安全倡议；给文化交流、文明对话，写文明倡议。三个倡议都指向同一个目标：人类命运共同体。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 作用类主观题必考

自 1990 年以来，中国累计派出维和人员 5 万余人次，参加了 20 多项联合国维和行动，是联合国第二大会费国和维和摊款国。2001 年加入世界贸易组织后，中国关税总水平大幅下降，不断缩减外资准入负面清单，履行开放市场承诺。中国推动上海合作组织扩员，成员国联合打击恐怖主义、分裂主义、极端主义三股势力；推动金砖国家扩员，新开发银行开业运营。在二十国集团框架内，中国倡导建设开放型世界经济，推动全球经济治理改革。结合材料，说明中国在国际组织中发挥的作用。

  1. 第 1 步 · 审题定性

    设问是"说明……发挥的作用"，属于作用类。作用类不问你"是什么"，问你"做了什么、带来什么"。答题框架固定：分平台 → 写动作 → 落到定性。先在草稿纸中间画四条竖线，分成四栏。

    用到：中国与国际组织的关系、建设性参与者。

  2. 第 2 步 · 找主体

    材料里做事的主体只有一个：中国。但"中国"出现的场合有四个：联合国、世界贸易组织、上合与金砖、二十国集团。场合不同，答案就不同，别把四段合成一段。

    用到：联合国、多边贸易体制、区域合作、全球经济治理。

  3. 第 3 步 · 找行为

    把动词圈出来：派出维和人员、缴纳会费、加入 WTO 并降关税、推动上合扩员并反恐、推动金砖扩员、在 G20 倡导开放型世界经济。六个动作，正好归到四栏里。

    用到：维和行动、履行承诺、安全合作、治理改革。

  4. 第 4 步 · 对应原理

    一行一行对：维和与会费 → 维护以联合国为核心的国际体系；入世降关税 → 融入多边贸易体制、以开放促改革；上合反恐 → 参与区域安全合作；金砖与 G20 → 推动全球治理体系改革、建设开放型世界经济。

    用到：真正的多边主义、人类命运共同体。

  5. 第 5 步 · 收口

    最后一句统一拔高：中国是国际组织的参与者、建设者、贡献者，推动构建人类命运共同体。注意别写"中国主导国际组织"——课本用的是"建设性参与者"，"主导"两个字一写，性质就变了。

    用到：参与者、建设者、贡献者；人类命运共同体。

1 / 5

标准答案（可抄进答题卡）

① 在联合国，中国是创始会员国和安理会常任理事国，支持联合国在国际事务中发挥核心作用。派出维和人员、承担会费与维和摊款，维护世界和平与安全，维护以联合国为核心的国际体系。
② 在世界贸易组织，中国融入多边贸易体制，履行降关税、开放市场的承诺，以开放促改革、促发展，推动建设开放型世界经济。
③ 在区域合作方面，中国参与上海合作组织等平台，联合打击三股势力，共同维护地区安全稳定，推动区域合作走深走实。
④ 在全球治理方面，中国推动金砖国家扩员和全球经济治理改革，增加发展中国家代表性，在二十国集团倡导建设开放型世界经济，践行真正的多边主义，推动构建人类命运共同体。
⑤ 总之，中国是国际组织的参与者、建设者、贡献者，不搞另起炉灶，不搞拉帮结派。

写法提醒：四点顺序就是采分顺序，一段一个平台，每段都是"动作 + 定性"两句。最容易丢分的是第④点只写"合作共赢"四个字——没有"增加发展中国家代表性"这句，全球治理这一栏等于没答。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

中国是不是要「另起炉灶」，另外建一套国际组织？

不是。课本的定性很清楚：中国是国际组织的参与者、建设者、贡献者，维护以联合国为核心的国际体系。改革和完善现有体系，和推倒重来是两件完全不同的事。凡材料出现"中国倡议""中国推动扩员"，你都要在后面补一句"在现有国际体系内"。

中国是安理会常任理事国，是不是国际事务中国说了算？

不是。否决权是宪章赋予的程序性权利，同时也意味着更大的责任，不等于一家拍板。安理会决议要按程序表决，还要靠会员国执行。卷子上写"中国主导联合国"，性质就错了；写"承担特殊责任、维护宪章宗旨"，才是课本口径。

中国加入世界贸易组织，是被迫让利吗？

不是，是自主作出的战略抉择。降关税、开放市场是承诺，换来的是进入国际市场的通道和参与规则制定的资格。二十多年的事实摆在那里：中国成为货物贸易第一大国，也倒逼国内产业升级。答题写以开放促改革、促发展，别写"被迫""吃亏"。

上合、金砖扩员，是不是在「拉帮结派」？

不是。上合是区域安全合作平台，金砖是新兴市场国家合作机制，两者都开放、不针对第三方，也没有军事同盟条款。扩员恰恰说明平台有吸引力。写"拉帮结派""搞阵营对抗"，等于把中国放到了多边主义的对立面，和"真正的多边主义"直接矛盾。

中国提出三大倡议，是要用中国方案取代联合国吗？

不是。三大倡议是合作路径，不是新机构；它们都在现有国际体系内推进，以联合国为核心。目标是构建人类命运共同体，联合国是落实的重要平台。材料里如果出现"中国倡议"，你要接着写它服务于多边主义，不是替代多边主义。

中国在 G20 里，算发达国家还是发展中国家？

仍是发展中国家，这个定位没变。人均水平、城乡差距、发展任务都摆在那里。但中国又确实承担着大国责任，为发展中国家说话、推动增加新兴市场国家的代表性。答题时两句一起写：发展中国家定位不变，同时承担与自身能力相适应的责任。

这六问其实是同一件事：中国在国际组织里的身份和定性。身份是参与者、建设者、贡献者；定性是维护以联合国为核心的国际体系。材料换成维和、关税、反恐、扩员、G20，答案都落回两个抽屉——做了什么，说明了什么。先写动作，再写定性，别把两句话混成一句。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 现有的国际组织都是西方主导的，中国应该另起炉灶，重新建一套。

✓ 中国是国际组织的参与者、建设者、贡献者，维护以联合国为核心的国际体系，推动全球治理体系改革和完善。

错在哪：把改革完善读成推倒重来。参与规则修订和退出体系重建，是两条完全不同的路。

✗ 中国是安理会常任理事国，国际上的事中国可以说了算。

✓ 中国是安理会常任理事国，对实质性决议有否决权，也承担维护国际和平与安全的特殊责任，按宪章程序办事。

错在哪：把程序性权利写成主导权。否决权是责任，不是"一票定天下"。

✗ 中国加入世界贸易组织是被迫让利，降关税吃了大亏。

✓ 加入世界贸易组织是中国自主作出的战略抉择，中国履行降关税、开放市场承诺，以开放促改革、促发展。

错在哪：把自主抉择写成被迫。承诺是对等交换，换来市场准入和规则参与资格。

✗ 上合、金砖不断扩员，说明中国在拉帮结派、搞自己的小圈子。

✓ 上合组织、金砖国家是开放包容的合作平台，扩员提升了代表性，中国是建设性参与者，不针对第三方。

错在哪：把合作平台当成军事同盟。这两个机制既没有同盟条款，也不搞阵营对抗。

✗ 中国提出全球发展倡议、全球安全倡议，是要用中国方案取代联合国。

✓ 三大倡议在现有国际体系内推进，以联合国为核心，服务于构建人类命运共同体，不取代任何国际组织。

错在哪：把路径当成替代品。倡议是合作方向，不是新设的机构。

✗ 中国在 G20 里已经是发达国家，应该按发达国家标准承担责任。

✓ 中国仍是发展中国家，发展中国家定位没有改变；同时承担与自身能力相适应的责任，为发展中国家争取权益。

错在哪：把经济体量大当成发达。看的是人均水平和发展任务，不是总量排名。

✗ 中国派维和部队到别国，是干涉他国内政。

✓ 中国参加的维和行动由联合国安理会授权，以维护国际和平与安全为目的，是联合国维和行动的重要参与者。

错在哪：漏掉安理会授权这一步。有授权是维和，没授权才可能变成干涉，这一句就是分水岭。

七条里最常考的是第 1、2、4 条：一条考定性，一条考权利与责任，一条考平台性质。把这三条的正确表述各抄一遍，再去翻课本第九课的原句对照，比刷十道选择题管用。
