# 本节规格

## bx4-c3-s3 唯物辩证法的实质与核心

**一句话**：矛盾即对立统一，是事物发展的源泉和动力；矛盾具有普遍性、特殊性，要坚持具体问题具体分析，坚持两点论与重点论统一。

**三个扣分点**：哲学矛盾不等于逻辑矛盾（不是“自相矛盾”）；矛盾普遍性寓于特殊性之中；主要矛盾不等于矛盾的主要方面。

**四张图**：① 矛盾的含义（对立统一）；② 矛盾的普遍性与特殊性；③ 主要矛盾与次要矛盾、矛盾主要方面与次要方面；④ 两点论与重点论。

**五个情境**：
1. “因地制宜、因材施教”｜对应：矛盾的特殊性、具体问题具体分析｜依据：不同事物有不同矛盾。
2. 抓“牛鼻子”、牵“牛鼻子”｜对应：主要矛盾｜依据：集中力量解决主要矛盾。
3. 看人看主流、看大局｜对应：矛盾的主要方面｜依据：分清主流和支流。
4. 既看到机遇又看到挑战｜对应：两点论｜依据：全面看问题，坚持一分为二。
5. 统筹兼顾又突出重点｜对应：两点论与重点论统一｜依据：反对形而上学的一点论。

**例题**：如何坚持两点论与重点论的统一？答案按“看到两面、抓住重点、统筹兼顾”展开。
