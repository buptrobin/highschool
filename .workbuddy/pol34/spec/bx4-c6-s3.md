# 本节规格

## bx4-c6-s3 价值的创造和实现

**一句话**：劳动和奉献是创造价值的根本途径；个人与社会统一；要砥砺自我、坚定理想信念。

**三个扣分点**：实现人生价值不是“靠机遇”；不是“只要努力就行”，要在个人与社会的统一中；不是“只顾自己”。

**四图**：① 劳动与奉献；② 个人与社会；③ 砥砺自我；④ 理想信念。

**五个情境**：
1. 大国工匠几十年打磨一门手艺｜对应：劳动创造价值｜依据：在平凡岗位上的劳动实现人生价值。
2. 大学生支教偏远山区｜对应：奉献社会、个人与社会统一｜依据：在服务人民中实现价值。
3. 科研人员坐冷板凳攻关“卡脖子”技术｜对应：砥砺自我、坚定理想信念｜依据：顽强奋斗、刻苦钻研。
4. 创业者失败多次仍坚持｜对应：发挥主观能动性、顽强拼搏｜依据：实现价值需要意志品质。
5. 只想着“躺平”、不愿付出｜对应：错误人生观｜依据：不劳动、不奉献，人生价值无从实现。

**例题**：青年应如何实现人生价值？答案按“劳动奉献、个人与社会统一、砥砺自我、坚定理想信念”展开。
