# 本节规格

## bx4-c3-s1 世界是普遍联系的

**一句话**：联系是普遍的、客观的、多样的；整体与部分相互联系，要树立全局观念，同时重视部分的作用。

**三个扣分点**：联系普遍不等于“任何两个事物都有联系”；联系客观不等于人不能建立新的具体联系（要尊重客观规律）；整体功能不等于部分功能之和。

**四张图**：① 联系的普遍性、客观性、多样性；② 整体与部分；③ 系统优化；④ 用联系的观点看问题。

**五个情境**：
1. 亚马逊一只蝴蝶扇动翅膀可能影响远处天气｜对应：联系的普遍性｜依据：世界是普遍联系的有机整体。
2. “城门失火，殃及池鱼”｜对应：联系的客观性、多样性｜依据：事物之间存在客观的、多样的联系。
3. 木桶装水看最短的板｜对应：整体与部分、系统优化｜依据：部分影响整体功能。
4. “一带一路”联通各国｜对应：人为事物的联系、联系多样性｜依据：人可以根据事物固有联系建立新的具体联系。
5. 生态治理山水林田湖草沙一体化｜对应：系统优化、整体观念｜依据：用综合的思维方式认识事物。

**例题**：用联系的观点分析某一问题。答案按“联系普遍性、客观性、多样性、整体与部分”展开。
