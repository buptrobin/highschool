# 本节规格

## bx3-c3-s1 坚持党的领导

**一句话**：党的领导是中国特色社会主义最本质的特征，是中国特色社会主义制度的最大优势；党是最高政治领导力量，总揽全局、协调各方。

**三个扣分点**：党的领导不是党直接包办一切，党的领导主要是政治领导、思想领导、组织领导；“最高政治领导力量”不是“最高国家权力机关”（那是全国人民代表大会）；党的领导与依法治国统一，不是“以党代法”。

**四张图**：① 党的领导地位（最本质特征、最大优势）；② 总揽全局、协调各方；③ 三种领导方式（政治、思想、组织）；④ 党的领导与国家治理的关系。

**五个情境**：
1. 党中央对重大工作作出部署，人大、政府、政协、司法机关各司其职｜对应：总揽全局、协调各方｜依据：党领导一切，但不代替国家机关行使职权。
2. 全国人大通过法律，把党的主张变成国家意志｜对应：党的政治领导、依法执政｜依据：通过法定程序使党的主张成为国家意志。
3. 基层党组织带领群众修路、发展产业｜对应：党的组织领导｜依据：基层党组织是战斗堡垒。
4. 国企党委把方向、管大局、保落实｜对应：党对国有企业的领导｜依据：党的领导融入公司治理。
5. 抗疫中党中央统一指挥、全国一盘棋｜对应：党的集中统一领导｜依据：集中力量办大事的制度优势。

**例题**：为什么必须坚持党的全面领导？答案从“最本质特征、最大优势、最高政治领导力量、总揽全局协调各方”展开，并落到“把党的领导落实到国家治理各领域各方面各环节”。
