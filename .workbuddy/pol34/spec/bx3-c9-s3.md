# 本节规格

## bx3-c9-s3 公正司法

**一句话**：司法是维护社会公平正义的最后一道防线；法院、检察院依法独立公正行使审判权、检察权。

**三个扣分点**：司法机关是法院和检察院，公安机关是行政机关；司法独立不是“不受监督”，要接受人大监督、社会监督；公正司法要实体公正与程序公正统一。

**四张图**：① 司法机关；② 依法独立公正行使职权；③ 司法责任制、司法公开；④ 最后一道防线。

**五个情境**：
1. 庭审直播、裁判文书上网｜对应：司法公开｜依据：以公开促公正。
2. 法官对案件质量终身负责｜对应：司法责任制｜依据：谁办案谁负责。
3. 检察院对错误判决提出抗诉｜对应：检察监督｜依据：检察机关依法履行法律监督职责。
4. 对困难当事人进行司法救助｜对应：司法为民、权利保障｜依据：让困难群众打得起官司。
5. 人民陪审员参与庭审｜对应：司法民主｜依据：保障人民群众有序参与司法。

**例题**：如何推进公正司法？答案按“独立公正行使职权、司法责任制、司法公开、司法为民”展开。
