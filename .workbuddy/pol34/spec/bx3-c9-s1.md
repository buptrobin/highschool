# 本节规格

## bx3-c9-s1 科学立法

**一句话**：科学立法、民主立法、依法立法，形成良法善治。

**三个扣分点**：立法机关不只是全国人大（还有全国人大常委会、地方人大及其常委会、国务院等）；科学立法不等于民主立法；立法不是“少数专家的事”，要开门立法。

**四张图**：① 立法体制；② 科学立法（尊重规律、体系科学）；③ 民主立法（开门立法、反映民意）；④ 依法立法（依照法定权限和程序）。

**五个情境**：
1. 立法听证会、公开征求意见｜对应：民主立法｜依据：广泛听取各方面意见。
2. 立法前进行必要性、可行性论证｜对应：科学立法｜依据：遵循客观规律，提高立法质量。
3. 基层立法联系点把群众意见“原汁原味”带上立法会｜对应：民主立法、全过程人民民主｜依据：让立法接地气。
4. 立法必须依照宪法和法律规定的权限和程序｜对应：依法立法｜依据：不能越权立法、违反程序。
5. 编纂民法典，系统整合民事法律规范｜对应：科学立法、体系化｜依据：增强法律体系的系统性、整体性、协同性。

**例题**：如何推进科学立法？答案按“科学立法、民主立法、依法立法”三条展开，各配一个做法。
