# 本节规格

## bx3-c5-s2 人民代表大会制度：我国的根本政治制度

**一句话**：人民代表大会制度是我国的根本政治制度，组织活动原则是民主集中制。

**三个扣分点**：根本政治制度不等于基本政治制度（基本政治制度是三项：政党制度、民族区域自治制度、基层群众自治制度）；民主集中制不是“民主加集中”简单相加；人大制度不是“人大自己”。

**四张图**：① 制度地位；② 民主集中制；③ 四大优势；④ 坚持和完善。

**五个情境**：
1. 人大对政府工作进行监督，政府向人大报告工作｜对应：人大与政府的关系、民主集中制｜依据：国家行政机关由人大产生、对人大负责、受人大监督。
2. 中央统一领导，地方发挥主动性｜对应：中央与地方关系、民主集中制｜依据：在中央统一领导下，充分发挥地方积极性。
3. 立法听证会、公开征求意见｜对应：民主立法、人大制度优势｜依据：保障人民当家作主。
4. 人大代表联络站常态化接待群众｜对应：人大代表与人民的关系｜依据：保持同人民群众密切联系。
5. 人大审查预算、开展执法检查｜对应：人大监督权、制度优势｜依据：保证国家机关协调高效运转。

**例题**：为什么必须坚持人民代表大会制度？答案按“保障人民当家作主、动员人民、保证国家机关协调运转、维护国家统一和民族团结”四点展开。
