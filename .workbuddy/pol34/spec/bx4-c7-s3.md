# 本节规格

## bx4-c7-s3 弘扬中华优秀传统文化与民族精神

**一句话**：中华民族精神以爱国主义为核心，包含团结统一、爱好和平、勤劳勇敢、自强不息；要弘扬民族精神，发挥时代精神。

**三个扣分点**：民族精神的核心是爱国主义；民族精神不是“排外”；民族精神与时代精神是统一的。

**四图**：① 中华民族精神的内涵；② 爱国主义；③ 民族精神与时代精神；④ 弘扬民族精神的路径。

**五个情境**：
1. 抗战精神、抗美援朝精神｜对应：爱国主义、团结统一｜依据：在民族危难中凝聚民族精神。
2. 抗疫精神、脱贫攻坚精神｜对应：民族精神在新时代的体现｜依据：时代精神丰富民族精神。
3. 航天精神、“两弹一星”精神｜对应：自强不息、艰苦奋斗｜依据：自力更生、勇攀高峰。
4. 爱国不是盲目排外，而是开放包容｜对应：爱国主义与对外开放统一｜依据：爱国要理性，学习借鉴世界优秀文明成果。
5. 青年学生参加志愿服务、国防教育｜对应：弘扬民族精神的实践｜依据：从身边做起，从小事做起。

**例题**：如何弘扬和培育中华民族精神？答案按“传承中华优秀传统文化、结合时代精神、立足实践、青年担当”展开。
