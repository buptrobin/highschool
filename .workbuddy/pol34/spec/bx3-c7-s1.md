# 本节规格

## bx3-c7-s1 我国法治建设的历程

**一句话**：从中华法系到新中国法治建设，再到全面依法治国；2010 年中国特色社会主义法律体系形成，2020 年民法典颁布。

**三个扣分点**：中华法系不是“中国古代没有法”；法治不是“有法律就是法治”；依法治国要与以德治国相结合，不是“只靠法律”。

**四张图**：① 中华法系；② 新中国法治建设时间轴（1954 宪法→2010 法律体系→2020 民法典→全面依法治国）；③ 中国特色社会主义法律体系；④ 法治与德治。

**五个情境**：
1. 《唐律疏议》对周边国家影响深远｜对应：中华法系｜依据：中国古代法律传统，礼法结合。
2. 1954 年第一部宪法诞生｜对应：新中国法治建设的起点｜依据：确立人民代表大会制度等根本制度。
3. 2010 年中国特色社会主义法律体系形成｜对应：法治建设里程碑｜依据：国家经济、政治、文化、社会生活各方面有法可依。
4. 2020 年民法典颁布｜对应：公民权利保障的里程碑｜依据：社会生活的百科全书。
5. 依法抗疫与弘扬社会主义核心价值观结合｜对应：依法治国与以德治国相结合｜依据：法律与道德共同发挥作用。

**例题**：说明我国法治建设的历程。答案按“古代中华法系→新中国法治建设→全面依法治国”三个阶段，各举一个标志性事件。
