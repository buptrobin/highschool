# 本节规格

## bx3-c4-s2 坚持人民民主专政

**一句话**：对人民民主、对敌人专政，两者统一；人民民主专政是社会主义现代化建设的政治保证。

**三个扣分点**：专政不等于专制；坚持人民民主专政不是“只讲民主”或“只讲专政”；国家职能包括对内职能和对外职能。

**四张图**：① 民主与专政的统一；② 国家职能（对内：维护秩序、管理经济文化、公共服务；对外：保卫主权、安全、发展利益）；③ 政治保证；④ 国防、治安、外交。

**五个情境**：
1. 扫黑除恶专项斗争｜对应：对敌人专政、维护社会秩序｜依据：依法打击危害人民利益的势力。
2. 基层人大代表选举｜对应：对人民民主｜依据：保障人民当家作主。
3. 国防和军队现代化建设｜对应：对外职能、保卫国家安全｜依据：维护国家主权、安全、发展利益。
4. 疫情防控中依法采取必要措施｜对应：国家社会管理职能｜依据：保障人民生命安全和身体健康。
5. 网络空间治理、打击网络诈骗｜对应：维护社会秩序、保护人民财产｜依据：依法治理网络空间。

**例题**：为什么要坚持人民民主专政？答案从“民主与专政统一、国家职能、政治保证”三点展开。
