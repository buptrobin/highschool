# 本节规格

## bx3-c3-s2 巩固党的执政地位

**一句话**：科学执政、民主执政、依法执政，依法执政是基本方式；全面从严治党、自我革命，才能巩固党的执政地位。

**三个扣分点**：三种执政方式不能混；依法执政不等于依法行政（依法行政的主体是政府）；全面从严治党核心是加强党的领导，不是“约束党的领导”。

**四张图**：① 三种执政方式；② 依法执政是基本方式；③ 全面从严治党；④ 自我革命。

**五个情境**：
1. 重大决策前组织专家论证、风险评估｜对应：科学执政｜依据：遵循共产党执政规律、社会主义建设规律、人类社会发展规律。
2. 立法前公开征求意见、召开听证会｜对应：民主执政｜依据：为了人民、依靠人民，支持和保证人民当家作主。
3. 党领导立法、保证执法、支持司法、带头守法｜对应：依法执政｜依据：依据宪法法律治国理政。
4. 查处腐败分子、完善党内法规｜对应：全面从严治党｜依据：治国必先治党，治党务必从严。
5. 党内开展主题教育、批评与自我批评｜对应：自我革命｜依据：刀刃向内，保持党的先进性和纯洁性。

**例题**：新时代如何巩固党的执政地位？答案按“科学执政、民主执政、依法执政、全面从严治党”四点展开。
