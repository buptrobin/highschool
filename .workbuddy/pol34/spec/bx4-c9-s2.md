# 本节规格

## bx4-c9-s2 文化发展的基本路径

**一句话**：坚定理想信念、坚持以人民为中心、立足时代实践、融通古今中外。

**三个扣分点**：文化发展不是“闭门造车”；不是“只满足市场”；不是“丢掉传统”。

**四图**：① 坚定理想信念；② 以人民为中心；③ 立足时代实践；④ 融通古今中外。

**五个情境**：
1. 主旋律电影讲好中国故事｜对应：坚定理想信念、弘扬主流价值｜依据：用优秀作品凝聚人心。
2. 网络文学、短视频创作贴近普通人｜对应：以人民为中心的创作导向｜依据：人民是文化创作的主体。
3. 乡村振兴中的村史馆、村晚｜对应：立足时代实践｜依据：文化发展扎根实践。
4. 国潮设计融合传统元素与现代审美｜对应：融通古今中外｜依据：推动优秀传统文化创造性转化。
5. 只追求流量、低俗媚俗｜对应：错误的文化创作倾向｜依据：要把社会效益放在首位。

**例题**：如何发展中国特色社会主义文化？答案按“理想信念、人民中心、时代实践、融通古今中外”展开。
