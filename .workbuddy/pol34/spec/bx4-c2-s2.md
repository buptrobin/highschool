# 本节规格

## bx4-c2-s2 运动的规律性

**一句话**：规律是事物运动过程中固有的本质的必然的稳定的联系；规律是客观的、普遍的，要尊重规律与发挥主观能动性相统一。

**三个扣分点**：规律不等于现象；规律不能被创造、消灭，但可以被认识和利用；发挥主观能动性不等于任意妄为。

**四张图**：① 规律的含义；② 规律的客观性、普遍性；③ 尊重规律与发挥主观能动性；④ 一切从实际出发、实事求是。

**五个情境**：
1. “揠苗助长”违背植物生长规律｜对应：规律客观性，违背规律要受惩罚｜依据：不能凭主观愿望办事。
2. “庖丁解牛”按牛的筋骨规律下刀｜对应：认识和利用规律｜依据：尊重规律，按规律办事。
3. 因地制宜发展特色产业｜对应：一切从实际出发、具体问题具体分析｜依据：从本地条件出发。
4. 长江十年禁渔、生态修复｜对应：尊重自然规律、人与自然和谐共生｜依据：按生态规律办事。
5. 国家按经济规律进行宏观调控｜对应：尊重经济规律与发挥主观能动性统一｜依据：既遵循规律，又主动作为。

**例题**：如何做到一切从实际出发、实事求是？答案按“尊重客观规律、发挥主观能动性、反对主观主义”展开。
