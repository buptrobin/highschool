# 本节规格

## bx4-c5-s3 社会历史的主体

**一句话**：人民群众是历史的创造者，是社会物质财富、精神财富的创造者和社会变革的决定力量；要坚持群众观点和群众路线。

**三个扣分点**：人民群众不等于“所有人”；英雄人物的作用不能否定，但英雄不能代替人民群众创造历史；群众路线不是“群众说了算、不要领导”。

**四张图**：① 人民群众的历史地位；② 三个“创造者”；③ 群众观点与群众路线；④ 以人民为中心。

**五个情境**：
1. 小岗村农民率先搞“大包干”｜对应：人民群众是社会变革的决定力量｜依据：改革来自群众实践。
2. 抗疫中广大人民群众参与｜对应：人民群众是历史创造者｜依据：人民战争靠人民。
3. 脱贫攻坚依靠群众苦干实干｜对应：人民群众是物质财富创造者｜依据：幸福是奋斗出来的。
4. 民间文艺、非遗传承｜对应：人民群众是精神财富创造者｜依据：文化源于人民实践。
5. 领导干部蹲点调研、问计于民｜对应：群众观点、群众路线｜依据：从群众中来，到群众中去。

**例题**：为什么说人民群众是历史的创造者？答案按“物质财富、精神财富、社会变革”三个创造者展开。
