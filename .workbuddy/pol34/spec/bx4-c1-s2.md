# 本节规格

## bx4-c1-s2 哲学的基本问题

**一句话**：思维和存在的关系问题是哲学的基本问题，包括“谁是本原”（唯物/唯心）和“有无同一性”（可知/不可知）两个方面。

**三个扣分点**：基本问题不是“物质和意识谁更重要”；唯物主义不等于机械唯物主义；唯心主义不等于全是胡说，要具体分析。

**四张图**：① 哲学基本问题的两个方面；② 唯物主义三种形态（古代朴素、近代形而上学、辩证唯物主义历史唯物主义）；③ 唯心主义两种形态（主观唯心、客观唯心）；④ 可知论与不可知论。

**五个情境**：
1. “气者，理之依也”“天地合而万物生”｜对应：古代朴素唯物主义｜依据：把物质归结为具体形态（气、水、火）。
2. “原子是世界的本原”｜对应：近代形而上学唯物主义｜依据：把物质归结为原子，具有机械性、形而上学性。
3. “心外无物”“存在就是被感知”｜对应：主观唯心主义｜依据：把人的主观精神当作本原。
4. “理生万物”“绝对精神决定世界”｜对应：客观唯心主义｜依据：把客观精神（理、绝对精神）当作本原。
5. “人类永远无法认识世界”｜对应：不可知论｜依据：否认思维和存在有同一性。

**例题**：如何划分唯物主义和唯心主义？答案看“谁是本原”：物质第一性、意识第二性是唯物主义；意识第一性、物质第二性是唯心主义。
