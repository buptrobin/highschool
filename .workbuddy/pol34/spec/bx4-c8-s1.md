# 本节规格

## bx4-c8-s1 文化的民族性与多样性

**一句话**：民族文化是民族生存和发展的精神根基；文化多样性是人类文明进步的重要动力；要尊重差异、理解个性、和睦相处。

**三个扣分点**：文化多样性不等于文化有优劣；民族性不等于封闭性；尊重差异不等于放弃本民族文化。

**四图**：① 民族文化的地位；② 文化多样性；③ 尊重差异、理解个性；④ 中华文化与世界文化。

**五个情境**：
1. 世界文化遗产、非遗名录｜对应：文化多样性｜依据：各民族文化共同构成世界文化。
2. 不同民族服饰、节日、饮食｜对应：文化的民族性｜依据：民族文化各具特色。
3. 把本民族文化强加给别的民族｜对应：违背文化多样性、文化霸权｜依据：要尊重差异、平等相待。
4. 孔子学院、汉语热｜对应：中华文化走出去、文化交流｜依据：在交流中展示中华文化魅力。
5. 只追捧外来文化、贬低本民族文化｜对应：民族虚无主义｜依据：要树立文化自信。

**例题**：如何正确对待文化多样性？答案按“认同本民族文化、尊重其他民族文化、交流互鉴”展开。
