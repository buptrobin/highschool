# 本节规格

## bx3-c6-s3 基层群众自治制度

**一句话**：村委会、居委会是基层群众性自治组织，实行自我管理、自我教育、自我服务、自我监督。

**三个扣分点**：村委会、居委会不是国家机关，不是基层政府；基层群众自治不是“基层政权”；村民自治不是“村长说了算”，要经村民会议、村民代表会议。

**四张图**：① 组织性质；② 四个自我；③ 民主选举、民主协商、民主决策、民主管理、民主监督；④ 基层治理案例。

**五个情境**：
1. 村委会换届选举｜对应：民主选举｜依据：村民直接选举村委会成员。
2. 村民会议讨论村规民约｜对应：民主决策、民主管理｜依据：涉及全村利益的事由村民会议决定。
3. 社区议事会商量停车位改造｜对应：民主协商｜依据：众人的事情由众人商量。
4. 居务公开栏公开财务收支｜对应：民主监督｜依据：村（居）务公开，接受群众监督。
5. 乡镇政府指导村委会工作，但不能包办｜对应：基层群众自治与基层政府的关系｜依据：指导、支持、帮助，不是领导、包办。

**例题**：如何理解基层群众自治制度？答案按“组织性质、四个自我、五个民主、基层治理效能”展开。
