# 本节规格

## bx3-c1-s1 中华人民共和国成立前各种政治力量

**一句话**：近代中国三种政治力量、三条道路都试过，只有中国共产党领导的新民主主义革命走得通——这就是“历史和人民的选择”。

**三个扣分点**：资本主义道路走不通，不是“没试过”；中国共产党诞生是 1921 年，不是 1919 年五四运动；1949 年新中国成立标志新民主主义革命胜利，不是社会主义制度确立（1956 年）。

**四张图**：① 近代中国半殖民地半封建社会与两对主要矛盾；② 三种政治力量、三条道路（地主阶级洋务派、资产阶级维新派/革命派、无产阶级）的成败对照；③ 时间轴 1840→1919→1921→1949；④ “没有共产党就没有新中国”的逻辑链。

**五个情境**：
1. 洋务运动“师夷长技以自强”，只学技术、不改制度｜对应：地主阶级洋务派，维护封建统治｜依据：只学器物不改制度，甲午战败证明走不通。
2. 戊戌变法、辛亥革命想走资本主义道路｜对应：资产阶级改良/革命道路，资本主义道路走不通｜依据：资产阶级软弱性、妥协性，没有发动最广大人民。
3. 五四运动中工人阶级登上政治舞台｜对应：新民主主义革命的开端｜依据：领导阶级从资产阶级变成无产阶级，革命性质没变、领导力量变了。
4. 1921 年中国共产党成立｜对应：中国革命的面貌焕然一新｜依据：有科学理论、有组织、有纲领，有了主心骨。
5. 1949 年新中国成立｜对应：新民主主义革命取得基本胜利｜依据：推翻三座大山，建立人民民主专政。

**例题**：为什么资本主义道路在中国走不通？答案要从“半殖民地半封建社会国情、资产阶级软弱性妥协性、帝国主义不允许、无产阶级和人民大众不接受”四个角度分点。
