# 本节规格

## bx4-c9-s1 文化发展的必然选择

**一句话**：中华文化复兴历经艰辛，马克思主义传入中国，中国共产党领导人民发展中国特色社会主义文化。

**三个扣分点**：文化复兴不是“复古”；马克思主义不是“外来文化简单移植”；中国特色社会主义文化有三个来源（中华优秀传统文化、革命文化、社会主义先进文化）。

**四图**：① 近代文化探索；② 马克思主义传入；③ 革命文化与社会主义先进文化；④ 中国特色社会主义文化。

**五个情境**：
1. 新文化运动提倡民主与科学｜对应：近代文化探索｜依据：向西方学习，但未能根本解决中国问题。
2. 马克思主义传入中国｜对应：文化发展的新方向｜依据：为中国文化发展提供科学理论。
3. 延安文艺座谈会｜对应：革命文化｜依据：文艺为人民服务、为革命服务。
4. 改革开放以来的文化建设｜对应：社会主义先进文化｜依据：面向现代化、面向世界、面向未来。
5. “文化复古论”“全盘西化论”｜对应：错误的文化发展道路｜依据：脱离中国实际，行不通。

**例题**：为什么必须发展中国特色社会主义文化？答案按“历史选择、马克思主义指导、三种文化资源、实践需要”展开。
