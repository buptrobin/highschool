# 本节规格

## bx4-c1-s3 科学的世界观和方法论

**一句话**：马克思主义哲学是辩证唯物主义和历史唯物主义，具有科学性、革命性、实践性；它是不断中国化时代化的。

**三个扣分点**：马克思主义哲学不是“黑格尔辩证法 + 费尔巴哈唯物主义的简单相加”；实践性是马克思主义哲学的首要基本观点；中国化时代化不是“另起炉灶”，是一脉相承又与时俱进。

**四张图**：① 马克思主义哲学的构成（辩证唯物主义、历史唯物主义）；② 三个特征（科学性、革命性、实践性）；③ 中国化时代化时间轴；④ 习近平新时代中国特色社会主义思想。

**五个情境**：
1. 马克思主义哲学强调“实践是认识的基础”｜对应：实践性｜依据：不仅解释世界，更要改变世界。
2. 辩证法与唯物主义的有机结合｜对应：辩证唯物主义｜依据：克服了旧唯物主义的机械性、形而上学性。
3. 唯物史观揭示社会发展规律｜对应：历史唯物主义｜依据：社会存在决定社会意识，人民群众是历史创造者。
4. 毛泽东思想、中国特色社会主义理论体系｜对应：马克思主义中国化｜依据：与中国实际相结合。
5. 习近平新时代中国特色社会主义思想｜对应：马克思主义中国化时代化新境界｜依据：回答新时代重大课题。

**例题**：为什么说马克思主义哲学是科学的世界观和方法论？答案按“研究对象、内容构成、三个特征、实践检验”展开。
