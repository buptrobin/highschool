# 本节规格

## bx3-c9-s4 全民守法

**一句话**：全民守法是法治社会的基础；尊法学法守法用法，权利义务相统一。

**三个扣分点**：全民守法不只是“老百姓守法”，也包括国家机关和领导干部；守法不是“不违法就行”，还要依法行使权利、履行义务；权利与义务相统一，不能只讲权利不讲义务。

**四张图**：① 全民守法的主体；② 尊法学法守法用法；③ 权利与义务统一；④ 法治信仰。

**五个情境**：
1. 国家工作人员宪法宣誓、带头学法｜对应：领导干部带头守法｜依据：抓住“关键少数”。
2. 青少年法治教育进课堂｜对应：全民守法从青少年抓起｜依据：扣好人生第一粒扣子。
3. 企业合规经营、依法纳税｜对应：企业守法经营｜依据：市场经济是法治经济。
4. 网民依法上网、不信谣不传谣｜对应：公民依法行使权利、履行义务｜依据：网络不是法外之地。
5. 群众遇到纠纷找法律、不闹访｜对应：法治信仰、依法维权｜依据：办事依法、遇事找法、解决问题用法、化解矛盾靠法。

**例题**：如何推进全民守法？答案按“领导干部带头、青少年教育、企业合规、公民依法维权”展开。
