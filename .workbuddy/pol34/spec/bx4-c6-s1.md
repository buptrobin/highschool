# 本节规格

## bx4-c6-s1 价值与价值观

**一句话**：哲学上的价值是事物满足主体需要的属性和功能；人的价值在于创造价值、对社会作贡献；价值观对人生道路有重要导向作用。

**三个扣分点**：哲学价值不是“价格”；人的价值不等于“自我价值”，社会价值是根本；价值观不是“个人偏好”，有正确与错误之分。

**四张图**：① 哲学价值的含义；② 人的价值（社会价值与自我价值）；③ 价值观的导向作用；④ 评价人的价值的标准。

**五个情境**：
1. 袁隆平一生研究杂交水稻，让亿万人吃饱饭｜对应：人的社会价值、劳动奉献｜依据：对社会的贡献是评价人生价值的根本尺度。
2. 志愿者参与社区服务，自己也有获得感｜对应：社会价值与自我价值的统一｜依据：在奉献社会中实现自我价值。
3. “金钱至上”“流量至上”｜对应：错误价值观的导向｜依据：把金钱、流量当作唯一标准，会把人引向歧途。
4. 选择职业时只看出钱多不多｜对应：价值判断与价值选择｜依据：还要看是否对社会有贡献、是否适合自己。
5. 企业既追求利润又承担社会责任｜对应：价值观对企业行为的导向｜依据：正确价值观促进企业和社会共同发展。

**例题**：如何评价一个人的价值？答案按“社会价值是根本尺度、贡献与索取统一、劳动奉献”展开。
