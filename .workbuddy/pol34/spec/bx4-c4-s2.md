# 本节规格

## bx4-c4-s2 在实践中追求和发展真理

**一句话**：真理是标志主观与客观相符合的哲学范畴，是客观的、具体的、有条件的；认识具有反复性、无限性、上升性。

**三个扣分点**：真理不等于多数人认同；真理与谬误有严格界限，但一定条件下可以相互转化；真理面前人人平等。

**四张图**：① 真理的含义与客观性；② 真理的具体性、条件性；③ 认识的反复性、无限性、上升性；④ 在实践中追求和发展真理。

**五个情境**：
1. 日心说战胜地心说｜对应：真理是客观的，实践检验真理｜依据：真理不因多数人反对而改变。
2. 牛顿力学在宏观低速条件下成立｜对应：真理是具体的、有条件的｜依据：超出适用范围就变成谬误。
3. 反复实验、不断修正认识｜对应：认识具有反复性｜依据：受主客观条件限制。
4. 人类对宇宙的认识不断深化｜对应：认识具有无限性、上升性｜依据：追求真理是一个永无止境的过程。
5. 把真理向前多迈一步变成谬误｜对应：真理与谬误的界限｜依据：真理有适用条件。

**例题**：如何理解真理是具体的、有条件的？答案按“适用范围、条件变化、真理与谬误转化”展开。
