# 本节规格

## bx4-c6-s2 价值判断与价值选择

**一句话**：价值判断是价值选择的基础；价值判断和价值选择具有社会历史性、主体差异性，要遵循社会发展规律、站在最广大人民立场上。

**三个扣分点**：价值判断不等于事实判断；主体差异不等于“怎么选都对”；社会历史性不等于“过去对的现在一定对”。

**四图**：① 价值判断与价值选择；② 社会历史性；③ 主体差异性；④ 正确价值判断与价值选择的标准。

**五个情境**：
1. 垃圾分类，有人嫌麻烦，有人主动做｜对应：价值判断的主体差异性｜依据：立场、需要不同，判断不同。
2. 不同年代对“铁饭碗”的看法不同｜对应：价值判断的社会历史性｜依据：社会条件变化，判断标准变化。
3. 改革中取舍眼前利益与长远利益｜对应：遵循社会发展规律｜依据：站在社会发展规律一边。
4. 城市建设为多数人还是为少数人｜对应：站在最广大人民立场｜依据：把人民利益作为最高标准。
5. 看到“网红”赚钱就想辍学｜对应：错误价值判断的导向｜依据：只看到表面，没看到长远发展。

**例题**：如何作出正确的价值判断和价值选择？答案按“遵循社会发展规律、站在最广大人民立场、正确处理个人与社会关系”展开。
