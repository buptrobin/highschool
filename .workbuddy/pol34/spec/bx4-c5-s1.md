# 本节规格

## bx4-c5-s1 社会历史的本质

**一句话**：社会存在决定社会意识，社会意识具有相对独立性；社会生活在本质上是实践的。

**三个扣分点**：社会存在不等于地理环境、人口因素的简单相加，核心是物质生产方式；社会意识相对独立不等于脱离社会存在；社会意识有先进和落后之分。

**四张图**：① 社会存在与社会意识；② 社会意识的相对独立性；③ 社会生活在本质上是实践的；④ 先进社会意识的作用。

**五个情境**：
1. 经济体制改革带来思想观念变化｜对应：社会存在决定社会意识｜依据：社会存在的变化决定社会意识的变化。
2. 传统观念阻碍改革｜对应：社会意识具有相对独立性｜依据：社会意识可能落后于社会存在。
3. 先进思想推动社会变革｜对应：先进社会意识促进社会发展｜依据：先进社会意识对社会存在有积极反作用。
4. 网络文化、流行语的变化｜对应：社会存在决定社会意识｜依据：社会生活在本质上是实践的。
5. 社会主义核心价值观凝聚共识｜对应：先进社会意识的能动作用｜依据：正确价值观推动社会进步。

**例题**：说明社会存在与社会意识的辩证关系。答案按“社会存在决定社会意识、社会意识相对独立、先进社会意识有促进作用”展开。
