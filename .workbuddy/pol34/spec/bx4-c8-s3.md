# 本节规格

## bx4-c8-s3 正确对待外来文化

**一句话**：面向世界、博采众长，以我为主、为我所用；反对封闭主义和民族虚无主义。

**三个扣分点**：外来文化不等于全盘吸收；以我为主不等于盲目排外；学习借鉴不等于照搬。

**四图**：① 面向世界、博采众长；② 以我为主、为我所用；③ 反对封闭主义和民族虚无主义；④ 中华文化主体性。

**五个情境**：
1. 引进消化吸收再创新高铁技术｜对应：博采众长、以我为主｜依据：学习借鉴，形成自主能力。
2. 好莱坞电影、日本动漫在中国传播｜对应：外来文化的影响｜依据：要辨别良莠，不能全盘吸收。
3. “洋节”热、传统节日冷｜对应：文化自信、正确对待外来文化｜依据：不能数典忘祖。
4. 马克思主义与中国实际结合｜对应：以我为主、为我所用｜依据：外来理论要中国化。
5. 封闭排外、拒绝交流｜对应：封闭主义｜依据：闭关锁国不利于文化发展。

**例题**：如何正确对待外来文化？答案按“面向世界、博采众长、以我为主、反对两种错误”展开。
