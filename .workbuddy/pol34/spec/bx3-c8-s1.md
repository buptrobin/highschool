# 本节规格

## bx3-c8-s1 法治国家

**一句话**：法治国家是法治建设的目标；坚持依法治国、依法执政、依法行政共同推进，法治国家、法治政府、法治社会一体建设。

**三个扣分点**：法治国家不等于法治政府（后者是前者的重点任务之一）；法治国家核心是宪法法律至上；法治国家不是“政府用法律管老百姓”，而是权力受约束、权利有保障。

**四张图**：① 法治国家的内涵；② 宪法法律至上；③ 良法之治；④ 权利保障与权力制约。

**五个情境**：
1. 国家工作人员就职时进行宪法宣誓｜对应：宪法法律至上｜依据：宪法是国家的根本法，具有最高法律效力。
2. 对法规、规范性文件进行合宪性审查｜对应：维护宪法权威、良法之治｜依据：一切法律法规不得同宪法相抵触。
3. 立法公开征求意见，提高立法质量｜对应：良法之治｜依据：良法是善治的前提。
4. 政府公布权力清单、责任清单｜对应：权力制约、权利保障｜依据：把权力关进制度的笼子。
5. 司法机关依法纠正冤错案件｜对应：权利保障、司法公正｜依据：让人民群众在每一个司法案件中感受到公平正义。

**例题**：如何建设法治国家？答案按“宪法法律至上、良法之治、权力制约、权利保障”展开。
