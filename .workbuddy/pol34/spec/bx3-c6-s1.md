# 本节规格

## bx3-c6-s1 中国共产党领导的多党合作和政治协商制度

**一句话**：共产党领导、多党派合作，共产党执政、多党派参政，是我国的新型政党制度；人民政协是社会主义协商民主的重要渠道和专门协商机构。

**三个扣分点**：各民主党派不是在野党、反对党，是参政党；人民政协不是国家机关，不履行国家职能；多党合作不是“多党轮流执政”。

**四张图**：① 新型政党制度的定位；② 十六字基本方针（长期共存、互相监督、肝胆相照、荣辱与共）；③ 人民政协的性质与三大职能（政治协商、民主监督、参政议政）；④ 协商民主的渠道。

**五个情境**：
1. 民主党派中央向中共中央提出意见建议｜对应：参政党的参政议政、政党协商｜依据：民主党派是参政党，不是反对党。
2. 政协委员提交提案，政府部门办理答复｜对应：人民政协的民主监督、参政议政｜依据：政协不是国家机关，提案是协商监督形式。
3. 中共中央召开党外人士座谈会，商量经济工作｜对应：政党协商｜依据：重大决策前充分协商。
4. 政协委员视察调研、反映社情民意｜对应：参政议政、民主监督｜依据：政协围绕团结和民主两大主题履职。
5. 西方多党制下政党恶斗、政府停摆｜对应：我国新型政党制度的优势｜依据：共产党领导、多党派合作，避免轮流坐庄、相互倾轧。

**例题**：为什么说我国政党制度是“新型政党制度”？答案从“党的领导、多党派合作、参政党定位、协商民主”四点展开，并对比西方多党制。
