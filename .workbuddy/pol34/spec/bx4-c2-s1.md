# 本节规格

## bx4-c2-s1 世界的物质性

**一句话**：世界是物质的世界，物质的唯一特性是客观实在性；运动是物质固有的根本属性和存在方式。

**三个扣分点**：物质不等于物质的具体形态；客观实在不等于客观存在；运动不等于机械运动。

**四张图**：① 物质定义；② 自然界、人类社会、意识的物质性；③ 运动与静止；④ 世界的物质统一性。

**五个情境**：
1. 山川湖海不依赖人的意识而存在｜对应：自然界的物质性｜依据：自然界的事物是客观的。
2. 生产关系、生产方式不以人的意志为转移｜对应：人类社会的物质性｜依据：社会存在是客观的。
3. 意识是人脑的机能，是对客观存在的反映｜对应：意识的物质性（意识依赖于物质）｜依据：没有人脑和客观对象，就没有意识。
4. “刻舟求剑”只承认静止、否认运动｜对应：运动是绝对的，静止是相对的｜依据：物质世界处于运动变化中。
5. 动中有静、静中有动｜对应：绝对运动与相对静止的统一｜依据：静止是运动的一种特殊状态。

**例题**：为什么说世界的真正统一性在于它的物质性？答案从自然界、人类社会、意识三个领域举例说明。
