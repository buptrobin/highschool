# 本节规格

## bx3-c7-s2 全面依法治国的总目标与原则

**一句话**：总目标是建设中国特色社会主义法治体系、建设社会主义法治国家；五项原则是坚持党的领导、人民主体地位、法律面前人人平等、依法治国和以德治国相结合、从中国实际出发。

**三个扣分点**：总目标两个层次不能漏（法治体系 + 法治国家）；党的领导是根本保证，不能丢；法律面前人人平等不是“平均主义”。

**四张图**：① 总目标；② 五项原则；③ 法治体系五个子体系（法律规范、法治实施、法治监督、法治保障、党内法规）；④ 法治与德治。

**五个情境**：
1. 党中央领导立法、保证执法、支持司法、带头守法｜对应：坚持党的领导｜依据：党的领导是社会主义法治最根本的保证。
2. 立法公开征求意见、人民参与｜对应：坚持人民主体地位｜依据：法治为了人民、依靠人民、造福人民、保护人民。
3. 高官违法同样受追究｜对应：法律面前人人平等｜依据：任何组织和个人都没有超越宪法法律的特权。
4. 把社会主义核心价值观融入法治建设｜对应：依法治国和以德治国相结合｜依据：法安天下，德润人心。
5. 不照搬西方法治模式｜对应：从中国实际出发｜依据：立足中国国情，走中国特色社会主义法治道路。

**例题**：如何理解全面依法治国的总目标？答案按“法治体系、法治国家”两个层次，结合五个子体系展开。
