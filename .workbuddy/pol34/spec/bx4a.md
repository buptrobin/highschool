## bx4-c1-s1 追求智慧的学问

**一句话**：哲学是系统化理论化的世界观，是世界观和方法论的统一；哲学与具体科学是一般与个别的关系。

**三个扣分点**：哲学不是“所有具体科学的总和”；哲学不是“玄学”，它研究世界最一般的本质和规律；世界观不等于哲学，哲学是系统化理论化的世界观。

**四张图**：① 哲学与世界观、方法论的关系；② 哲学与具体科学（共性与个性）；③ 哲学是时代精神的精华；④ 哲学的作用（认识世界、改造世界）。

**五个情境**：
1. 物理学家研究量子、生物学家研究基因，哲学家追问“世界的本原是什么”｜对应：哲学与具体科学的研究对象不同｜依据：具体科学研究某一领域，哲学研究整个世界的一般规律。
2. 相对论、量子力学的新成果推动哲学发展｜对应：具体科学是哲学的基础｜依据：具体科学的进步推动哲学发展。
3. 哲学为具体科学提供世界观和方法论指导｜对应：哲学对具体科学有指导作用｜依据：科学家总是在一定世界观指导下研究。
4. “老百姓过日子都有自己的世界观”｜对应：自发世界观不等于哲学｜依据：哲学是系统化理论化的世界观。
5. 哲学不是“万能钥匙”，不能代替具体科学｜对应：哲学与具体科学不能互相替代｜依据：一般不能代替个别。

**例题**：说明哲学与具体科学的关系。答案按“具体科学是哲学的基础、哲学为具体科学提供世界观方法论指导、二者是一般与个别的关系”展开。

## bx4-c1-s2 哲学的基本问题

**一句话**：思维和存在的关系问题是哲学的基本问题，包括“谁是本原”（唯物/唯心）和“有无同一性”（可知/不可知）两个方面。

**三个扣分点**：基本问题不是“物质和意识谁更重要”；唯物主义不等于机械唯物主义；唯心主义不等于全是胡说，要具体分析。

**四张图**：① 哲学基本问题的两个方面；② 唯物主义三种形态（古代朴素、近代形而上学、辩证唯物主义历史唯物主义）；③ 唯心主义两种形态（主观唯心、客观唯心）；④ 可知论与不可知论。

**五个情境**：
1. “气者，理之依也”“天地合而万物生”｜对应：古代朴素唯物主义｜依据：把物质归结为具体形态（气、水、火）。
2. “原子是世界的本原”｜对应：近代形而上学唯物主义｜依据：把物质归结为原子，具有机械性、形而上学性。
3. “心外无物”“存在就是被感知”｜对应：主观唯心主义｜依据：把人的主观精神当作本原。
4. “理生万物”“绝对精神决定世界”｜对应：客观唯心主义｜依据：把客观精神（理、绝对精神）当作本原。
5. “人类永远无法认识世界”｜对应：不可知论｜依据：否认思维和存在有同一性。

**例题**：如何划分唯物主义和唯心主义？答案看“谁是本原”：物质第一性、意识第二性是唯物主义；意识第一性、物质第二性是唯心主义。

## bx4-c1-s3 科学的世界观和方法论

**一句话**：马克思主义哲学是辩证唯物主义和历史唯物主义，具有科学性、革命性、实践性；它是不断中国化时代化的。

**三个扣分点**：马克思主义哲学不是“黑格尔辩证法 + 费尔巴哈唯物主义的简单相加”；实践性是马克思主义哲学的首要基本观点；中国化时代化不是“另起炉灶”，是一脉相承又与时俱进。

**四张图**：① 马克思主义哲学的构成（辩证唯物主义、历史唯物主义）；② 三个特征（科学性、革命性、实践性）；③ 中国化时代化时间轴；④ 习近平新时代中国特色社会主义思想。

**五个情境**：
1. 马克思主义哲学强调“实践是认识的基础”｜对应：实践性｜依据：不仅解释世界，更要改变世界。
2. 辩证法与唯物主义的有机结合｜对应：辩证唯物主义｜依据：克服了旧唯物主义的机械性、形而上学性。
3. 唯物史观揭示社会发展规律｜对应：历史唯物主义｜依据：社会存在决定社会意识，人民群众是历史创造者。
4. 毛泽东思想、中国特色社会主义理论体系｜对应：马克思主义中国化｜依据：与中国实际相结合。
5. 习近平新时代中国特色社会主义思想｜对应：马克思主义中国化时代化新境界｜依据：回答新时代重大课题。

**例题**：为什么说马克思主义哲学是科学的世界观和方法论？答案按“研究对象、内容构成、三个特征、实践检验”展开。

## bx4-c2-s1 世界的物质性

**一句话**：世界是物质的世界，物质的唯一特性是客观实在性；运动是物质固有的根本属性和存在方式。

**三个扣分点**：物质不等于物质的具体形态；客观实在不等于客观存在；运动不等于机械运动。

**四张图**：① 物质定义；② 自然界、人类社会、意识的物质性；③ 运动与静止；④ 世界的物质统一性。

**五个情境**：
1. 山川湖海不依赖人的意识而存在｜对应：自然界的物质性｜依据：自然界的事物是客观的。
2. 生产关系、生产方式不以人的意志为转移｜对应：人类社会的物质性｜依据：社会存在是客观的。
3. 意识是人脑的机能，是对客观存在的反映｜对应：意识的物质性（意识依赖于物质）｜依据：没有人脑和客观对象，就没有意识。
4. “刻舟求剑”只承认静止、否认运动｜对应：运动是绝对的，静止是相对的｜依据：物质世界处于运动变化中。
5. 动中有静、静中有动｜对应：绝对运动与相对静止的统一｜依据：静止是运动的一种特殊状态。

**例题**：为什么说世界的真正统一性在于它的物质性？答案从自然界、人类社会、意识三个领域举例说明。

## bx4-c2-s2 运动的规律性

**一句话**：规律是事物运动过程中固有的本质的必然的稳定的联系；规律是客观的、普遍的，要尊重规律与发挥主观能动性相统一。

**三个扣分点**：规律不等于现象；规律不能被创造、消灭，但可以被认识和利用；发挥主观能动性不等于任意妄为。

**四张图**：① 规律的含义；② 规律的客观性、普遍性；③ 尊重规律与发挥主观能动性；④ 一切从实际出发、实事求是。

**五个情境**：
1. “揠苗助长”违背植物生长规律｜对应：规律客观性，违背规律要受惩罚｜依据：不能凭主观愿望办事。
2. “庖丁解牛”按牛的筋骨规律下刀｜对应：认识和利用规律｜依据：尊重规律，按规律办事。
3. 因地制宜发展特色产业｜对应：一切从实际出发、具体问题具体分析｜依据：从本地条件出发。
4. 长江十年禁渔、生态修复｜对应：尊重自然规律、人与自然和谐共生｜依据：按生态规律办事。
5. 国家按经济规律进行宏观调控｜对应：尊重经济规律与发挥主观能动性统一｜依据：既遵循规律，又主动作为。

**例题**：如何做到一切从实际出发、实事求是？答案按“尊重客观规律、发挥主观能动性、反对主观主义”展开。

## bx4-c3-s1 世界是普遍联系的

**一句话**：联系是普遍的、客观的、多样的；整体与部分相互联系，要树立全局观念，同时重视部分的作用。

**三个扣分点**：联系普遍不等于“任何两个事物都有联系”；联系客观不等于人不能建立新的具体联系（要尊重客观规律）；整体功能不等于部分功能之和。

**四张图**：① 联系的普遍性、客观性、多样性；② 整体与部分；③ 系统优化；④ 用联系的观点看问题。

## bx4-c3-s2 世界是永恒发展的

**一句话**：发展的实质是新事物的产生和旧事物的灭亡；量变与质变、前进性与曲折性相统一。

**三个扣分点**：发展不等于运动、变化（发展是前进、上升的运动变化）；新事物不等于新出现的事物；量变必然引起质变，但需要达到一定程度和条件。

**四张图**：① 发展的实质；② 量变与质变；③ 前进性与曲折性；④ 用发展的观点看问题。

**五个情境**：

2. 反复失败后终于成功｜对应：前进性与曲折性统一｜依据：道路曲折，前途光明。
3. “拔苗助长”急于求成｜对应：量变是质变的必要准备｜依据：要重视量的积累。
4. “沉舟侧畔千帆过，病树前头万木春”｜对应：发展的前进性｜依据：新事物必然战胜旧事物。
5. 科技创新从跟跑到领跑｜对应：量变到质变、发展｜依据：持续积累实现跨越。

**例题**：用发展的观点看问题。答案按“发展实质、量变质变、前进性曲折性”展开。

## bx4-c5-s2 社会历史的发展

**一句话**：生产力与生产关系、经济基础与上层建筑的矛盾运动推动社会历史发展；改革是社会主义制度的自我完善和发展。

**四张图**：① 生产力与生产关系；② 经济基础与上层建筑；③ 社会基本矛盾运动；④ 改革。

4. 上层建筑改革（简政放权）促进经济发展｜对应：上层建筑反作用于经济基础｜依据：适合经济基础的上层建筑促进发展。
5. 阶级社会里阶级斗争推动社会变革｜对应：社会基本矛盾在阶级社会的表现｜依据：阶级斗争是阶级社会发展的直接动力。

**例题**：用社会基本矛盾运动说明为什么要全面深化改革。答案按“生产力与生产关系、经济基础与上层建筑、改革”展开。

## bx4-c5-s3 社会历史的主体

**一句话**：人民群众是历史的创造者，是社会物质财富、精神财富的创造者和社会变革的决定力量；要坚持群众观点和群众路线。

**三个扣分点**：人民群众不等于“所有人”；英雄人物的作用不能否定，但英雄不能代替人民群众创造历史；群众路线不是“群众说了算、不要领导”。

**四张图**：① 人民群众的历史地位；② 三个“创造者”；③ 群众观点与群众路线；④ 以人民为中心。

**五个情境**：
1. 小岗村农民率先搞“大包干”｜对应：人民群众是社会变革的决定力量｜依据：改革来自群众实践。
2. 抗疫中广大人民群众参与｜对应：人民群众是历史创造者｜依据：人民战争靠人民。
3. 脱贫攻坚依靠群众苦干实干｜对应：人民群众是物质财富创造者｜依据：幸福是奋斗出来的。
4. 民间文艺、非遗传承｜对应：人民群众是精神财富创造者｜依据：文化源于人民实践。
5. 领导干部蹲点调研、问计于民｜对应：群众观点、群众路线｜依据：从群众中来，到群众中去。

**例题**：为什么说人民群众是历史的创造者？答案按“物质财富、精神财富、社会变革”三个创造者展开。
