# 本节规格

## bx4-c4-s1 人的认识从何而来

**一句话**：实践是认识的基础，是认识的来源、动力、检验标准和目的；认识对实践有反作用。

**三个扣分点**：实践不等于认识；实践是检验真理的唯一标准，不是“多数人意见”；认识的来源是实践，不是人脑。

**四张图**：① 实践的含义与三个特征（直接现实性、自觉能动性、社会历史性）；② 实践是认识的基础；③ 认识对实践的反作用；④ 知行合一。

**五个情境**：
1. 科学实验发现新规律｜对应：实践是认识的来源、动力｜依据：认识在实践中产生和发展。
2. 反复实验检验理论｜对应：实践是检验认识真理性的唯一标准｜依据：只有实践才能把主观和客观联系起来。
3. 理论指导科技攻关｜对应：认识对实践有反作用｜依据：正确认识推动实践发展。
4. 读万卷书、行万里路｜对应：间接经验与直接经验｜依据：学习书本知识也要结合实践。
5. “纸上谈兵”脱离实际｜对应：认识脱离实践会失败｜依据：实践是认识的目的。

**例题**：为什么说实践是认识的基础？答案按“来源、动力、检验标准、目的”四点展开。
