# 本节规格

## bx3-c2-s1 始终坚持以人民为中心

**一句话**：党的性质、宗旨、初心使命、执政理念，四句话都落在“人民”二字上。

**三个扣分点**：党的性质是“两个先锋队”（中国工人阶级的先锋队，中国人民和中华民族的先锋队）；宗旨是“全心全意为人民服务”，不能少“全心全意”；执政理念是“立党为公、执政为民”，初心使命是“为中国人民谋幸福、为中华民族谋复兴”。

**四张图**：① 党的人民立场四句话（性质、宗旨、初心、执政理念）；② 四句话的关系：性质决定宗旨，宗旨体现初心，初心落到执政理念；③ 人民中心在政策中的体现（医保集采、脱贫攻坚、老旧小区改造）；④ 党员先锋模范作用。

**五个情境**：
1. 脱贫攻坚战，近一亿农村贫困人口脱贫｜对应：全心全意为人民服务、以人民为中心｜依据：把人民对美好生活的向往作为奋斗目标。
2. 医保药品集采，把“天价药”谈下来｜对应：立党为公、执政为民｜依据：为最广大人民谋利益，不是为少数人。
3. 老旧小区加装电梯、改造管网｜对应：保障和改善民生、共享发展成果｜依据：从群众身边事入手。
4. 党员突击队冲在抗洪一线｜对应：党员的先锋模范作用｜依据：平常时候看得出来、关键时刻站得出来。
5. 西方选举“选民至上”、上台后只照顾支持者｜对应：中国共产党的人民立场不是“选民立场”｜依据：党没有自己的特殊利益，代表最广大人民根本利益。

**例题**：为什么说“江山就是人民，人民就是江山”？答案从党的性质、宗旨、初心使命、执政理念四个角度，结合一个民生事实。
