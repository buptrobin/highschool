# 本节规格

## bx3-c9-s2 严格执法

**一句话**：执法机关要规范、公正、文明执法，落实执法责任制。

**三个扣分点**：执法主体不只是公安（还有市场监管、税务、生态环境、城管等）；严格执法不等于粗暴执法；执法要公开透明、接受监督。

**四张图**：① 执法主体；② 规范、公正、文明执法；③ 行政执法三项制度；④ 执法监督与责任追究。

**五个情境**：
1. 交警佩戴执法记录仪、全程记录｜对应：规范执法、全过程记录｜依据：执法全过程留痕，可回溯管理。
2. 市场监管部门“双随机、一公开”抽查｜对应：公正执法、公开透明｜依据：避免选择性执法。
3. 行政处罚前告知当事人权利、举行听证｜对应：文明执法、程序正当｜依据：保障当事人陈述申辩权。
4. 执法信息公示、执法结果公开｜对应：公开公正｜依据：让执法在阳光下运行。
5. 对执法过错进行追责｜对应：执法责任制｜依据：有权必有责、用权受监督、违法必追究。

**例题**：如何推进严格执法？答案按“规范执法、公正执法、文明执法、执法监督”展开。
