# 本节规格

## bx3-c8-s2 法治政府

**一句话**：法治政府是职能科学、权责法定、执法严明、公开公正、智能高效、廉洁诚信、人民满意的政府。

**三个扣分点**：法治政府不是“政府说了算”；依法行政不是“依政策行政”，要依宪法法律；政府职能不是越多越好，要“法定职责必须为、法无授权不可为”。

**四张图**：① 法治政府七个特征；② 权力清单、责任清单；③ 行政执法三项制度（公示、全过程记录、重大执法决定法制审核）；④ 政务服务、数字政府。

**五个情境**：
1. 行政审批“最多跑一次”、一网通办｜对应：智能高效、人民满意｜依据：转变政府职能，优化服务。
2. 行政执法公示执法信息、全过程记录｜对应：公开公正、执法严明｜依据：行政执法三项制度。
3. 政府信息公开，接受群众监督｜对应：公开公正｜依据：让权力在阳光下运行。
4. 行政复议纠正违法行政行为｜对应：权责法定、权力监督｜依据：行政行为要接受监督、承担法律责任。
5. 政府工作人员廉洁自律、失信追责｜对应：廉洁诚信｜依据：政务诚信是社会信用体系的基石。

**例题**：如何建设法治政府？答案按“职能科学、权责法定、执法严明、公开公正、智能高效、廉洁诚信、人民满意”展开。
