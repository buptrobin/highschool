# 本节规格

## bx4-c7-s1 文化的内涵与功能

**一句话**：文化是社会实践的产物，是精神现象；文化与经济、政治相互影响；文化具有引领风尚、教育人民、服务社会、推动发展的功能。

**三个扣分点**：文化不是“纯精神、与经济无关”；文化有先进与落后之分；文化功能不是“万能”。

**四图**：① 文化的内涵；② 文化与经济、政治的关系；③ 文化的功能；④ 文化自信。

**五个情境**：
1. 村 BA、村超带火乡村旅游｜对应：文化与经济相互交融｜依据：文化搭台、经济唱戏。
2. 博物馆热、非遗热｜对应：文化传承与文化功能｜依据：文化服务社会、教育人民。
3. 网络低俗内容影响青少年｜对应：落后文化的不良影响｜依据：文化有先进落后，要加强引导。
4. 企业文化凝聚员工｜对应：文化对经济、社会的反作用｜依据：先进文化促进发展。
5. 文化下乡、惠民演出｜对应：文化服务人民、推动发展｜依据：保障人民基本文化权益。

**例题**：文化有什么作用？答案按“引领风尚、教育人民、服务社会、推动发展”展开，并说明文化有先进落后。
