# 本节规格

## bx4-c8-s2 文化交流与文化交融

**一句话**：文化交流构成文化发展的重要动力；文化交融推动文化创新；要尊重、借鉴、融合。

**三个扣分点**：交流不等于输出价值观；交融不等于取代、同化；文化创新不是“无中生有”。

**四图**：① 文化交流；② 文化交融；③ 文化创新；④ 中华文化走出去。

**五个情境**：
1. 丝绸之路上的商旅、宗教、艺术交流｜对应：文化交流｜依据：交流促进文化传播。
2. 留学生互派、国际学术合作｜对应：文化交流｜依据：人员在来中传播文化。
3. 中餐在海外本土化｜对应：文化交融｜依据：不同文化相互借鉴、融合。
4. 中外合拍电影、联合办展｜对应：文化交融、文化创新｜依据：融合产生新的文化成果。
5. 进博会文化展区｜对应：文化交流互鉴｜依据：以开放姿态吸收借鉴。

**例题**：文化交流互鉴有什么意义？答案按“促进文化发展、推动文化创新、增进文明理解”展开。
