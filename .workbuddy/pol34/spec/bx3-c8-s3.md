# 本节规格

## bx3-c8-s3 法治社会

**一句话**：法治社会是法治国家、法治政府的基础；核心是全社会尊法学法守法用法。

**三个扣分点**：法治社会不是“社会自己管自己”，要在党的领导和法治国家框架下建设；法治社会不是“没有纠纷”，而是纠纷依法解决；法治社会与法治国家、法治政府一体建设。

**四张图**：① 法治社会的地位；② 法律信仰；③ 公共法律服务体系；④ 社会治理法治化。

**五个情境**：
1. 国家宪法日、宪法宣传周｜对应：树立宪法法律信仰｜依据：让法治成为全民信仰。
2. 法律援助为困难群众免费打官司｜对应：公共法律服务体系｜依据：保障困难群众平等获得法律帮助。
3. 人民调解化解邻里纠纷｜对应：矛盾纠纷多元化解、社会治理法治化｜依据：把矛盾化解在基层。
4. 对村规民约进行合法性审查｜对应：基层治理法治化｜依据：村规民约不得违反法律法规。
5. 企业诚信经营、个人守信激励｜对应：法治与德治相结合、社会信用体系｜依据：诚信建设是法治社会的重要基础。

**例题**：如何建设法治社会？答案按“树立法律信仰、完善公共法律服务、推进社会治理法治化”展开。
