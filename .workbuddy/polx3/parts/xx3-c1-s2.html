先说一个你肯定见过的场面：小组讨论“要不要给班里减负”，讲了十分钟，话题变成了“作业到底该不该留”，最后谁也没说服谁。这不是谁口才差，是讨论中途把论题换掉了。第二课就在讲这类事：逻辑学研究思维的形式结构及其规律，逻辑思维要守三条底线。它在整册书的最前面，是后面概念、判断、推理的地基，也最容易背成三句口号。

01课本怎么说

先背标准表述，再拆关键词。答题时写课本这句，不写你脑子里那句。

课本原话 · 逻辑学到底研究什么选择性必修3 · 第二课第一框

逻辑学是研究思维形式结构及其规律的科学。

→ 翻成人话：它不挑你“想什么”，只挑你“怎么想”。思维的内容归数学、归政治、归你的日常生活；思维的形式结构只有概念、判断、推理三类。逻辑学 = 形式结构 + 逻辑规律，这两个词都要落进答案里。考卷上问“逻辑学的研究对象是什么”，答这一句就够，但必须补上“不是思维内容”。

课本原话 · 同一律（思维的确定性）选择性必修3 · 第二课第二框

在同一思维过程中，每一思想必须保持自身同一性，不能混淆概念，也不能转移论题。公式：A 是 A。

→ 翻成人话：同一段话里，“减负”就必须一直是“减负”。换词义叫偷换概念，换话题叫转移论题，两条都踩同一律。注意“同一思维过程”这个前提，它把适用范围限得很死。材料里出现“说着说着就变成”，九成是这条。

课本原话 · 矛盾律与排中律选择性必修3 · 第二课第二框

矛盾律：在同一思维过程中，两个互相否定的思想不能同时为真，必有一假（A 不是非 A）。排中律：在同一思维过程中，两个互相矛盾的思想不能同时为假，必有一真（A 或者非 A）。

→ 翻成人话：矛盾律管“不能两个都✓”，排中律管“不能两个都✗”。一条管同真，一条管同假，千万别记反。违反矛盾律叫自相矛盾，违反排中律叫“两不可”。两条规律的前提一样，方向相反：一个不许同真，一个不许同假。

比什么同一律矛盾律排中律
管什么确定性一致性明确性
公式A 是 AA 不是非 AA 或者非 A
违反的样子偷换概念、转移论题自相矛盾两不可
一句话记住一个词，全程一个意思两个判断，不能都真两个判断，不能都假
材料里长这样“人民”被换成了“所有人”“总体很好，但每步都有问题”“有罪不对，无罪也不对”

做材料题先问三句：换词了吗（同一律）？两个都肯定了吗（矛盾律）？两个都否定了吗（排中律）？三句问完，规律就定了一半。这张表只给“一句话记住”这一行画了底色，因为考场上你需要的是一句能立刻调出来的话。口诀：违反矛盾律叫自相矛盾，违反排中律叫两不可，名字不能互换。

04一道题走一遍

先自己读题干想 30 秒，再点“下一步”。

例题 · 辨析类主观题必考

班会讨论“要不要减负”。有同学说：“减负就是让大家都不学习。”说着说着，话题变成了“作业到底该不该留”。请分析“偷换概念”与“转移论题”的区别。

  1. 第 1 步 · 审题定性

    题目问的是“区别”，不是“是什么”。落点只有一个：同一律。先把“同一律管确定性”写在心里，再去分层面。

    用到：同一律、思维的确定性

  2. 第 2 步 · 找出材料里的两次“换”

    材料给了两处：把“减负”换成“不学习”，是词的含义变了；把“要不要减负”换成“作业该不该留”，是讨论的话题变了。先把这两处圈出来。圈的时候顺手标上“词”还是“题”，后面就不用再想。

    用到：概念、论题

  3. 第 3 步 · 分层判据

    概念是思维的细胞，判断由概念构成，推理又由判断构成；论题是你要证明的那个判断。所以换词伤的是“细胞”，换题伤的是“方向”。

    用到：概念与判断的关系

  4. 第 4 步 · 说清后果

    概念一换，后面的判断和推理全跟着失真；论题一换，论证再严密也是答非所问。这一步是答案里的“为什么”，不能省。这一层写不出来，答案就只剩骨架没有肉。

    用到：同一律的作用

  5. 第 5 步 · 收口成三点

    按“同 → 异 → 回扣材料”写：都违反同一律；一个在概念层面、一个在论题层面；材料里哪句对哪条。分点写，术语照课本。每点一行，别挤成一大段。

    用到：答题结构

1 / 5

标准答案（可抄进答题卡）

①相同：二者都违反同一律。同一律要求在同一思维过程中每一思想保持自身同一性，偷换概念和转移论题都让“同一个意思”中途变了，思维失去确定性。
②不同之一：层面不同。概念是思维的细胞，偷换概念换的是语词的含义（“减负”被换成“不学习”）；论题是论证要证明的判断，转移论题换的是讨论的话题（“要不要减负”变成“作业该不该留”）。
③不同之二：后果不同。概念被换，由它构成的判断、推理全部失真；论题被换，论证再严密也是答非所问。
④回扣材料：材料中“减负就是不学习”属偷换概念，“减负”变成“作业该不该留”属转移论题。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

同一律、矛盾律、排中律，一句话怎么分？

三条规律各管一个“有没有”：同一律管“变没变”，概念和论题有没有中途被换；矛盾律管“能不能同真”，两个互相否定的判断不能都肯定；排中律管“能不能同假”，两个互相矛盾的判断不能都否定。

“偷换概念”和“转移论题”到底差在哪？

差在层面。概念是思维的细胞，偷换概念换的是词的含义，同一个词前后所指不同；论题是论证要证明的判断，转移论题换的是讨论的话题，答的不是问的。两者都违反同一律、都破坏确定性，但一个动“词”，一个动“题”。

“自相矛盾”和“两不可”怎么区分？

看方向。自相矛盾是“同时肯定”两个互相否定的判断，违反矛盾律；“两不可”是“同时否定”两个互相矛盾的判断，违反排中律。一个错在都✓，一个错在都✗。

矛盾律是不是否认事物有矛盾？

不是。矛盾律排除的是逻辑矛盾，即同一时间、同一方面对同一对象既肯定又否定；它不否认事物自身包含的矛盾。事物自身的矛盾是辩证矛盾，是事物发展的动力，由辩证法研究。把两者混成一件事，是这一课最典型的失分点。

同一律是不是要求概念永远不变？

不是。同一律的前提是“同一思维过程”：同一时间、同一对象、同一方面。换一个思维过程，概念可以变，只要你说清楚、不混用。“减负”在这场讨论里指作业量，在另一场里指评价方式，两次都交代清楚，就不违反同一律；一场讨论里偷偷换，才叫偷换概念。

后面的定义规则、三段论，跟这里是什么关系？

是同一律往下走。概念要同一，落到定义上就是四条规则：不能循环、不能否定、不能比喻、外延要相等；推理要可靠，三段论就要求中项至少周延一次。充分条件“肯前肯后、否后否前”，必要条件“否前否后、肯后肯前”，也是把前提与结论的对应关系固定住。

六问其实是同一件事：都在问你的思维在哪一步丢了确定性、一致性或明确性。判断顺序固定：先看有没有“换”，再看有没有“两个判断”，最后看两个判断是被同时肯定还是同时否定。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 同一律就是要求一个词的意思永远不能变。

✓ 同一律要求在同一思维过程中，概念和论题保持自身同一性。

“同一”限定在同一思维过程：同一时间、同一对象、同一方面。换了过程、换了语境，词义本来可以变；读成“永远不变”，就把逻辑规律读成了语言禁令。辨析时先写“在同一思维过程中”这个限定，再谈变不变。

✗ 他前后说的不一样，就是违反排中律。

✓ 前后不一致，违反的是矛盾律；排中律管的是两个互相矛盾的判断不能同假。

矛盾律管“不能同真”，排中律管“不能同假”，一个管✓，一个管✗。看到前后打架想矛盾律，看到“都不对”才想排中律。两条规律都要求同一时间、同一方面、同一对象，方向却正好相反。

✗ 矛盾律说明事物不能有矛盾。

✓ 矛盾律只排除思维中的逻辑矛盾，不否认事物自身包含的矛盾。

事物自身的矛盾是辩证矛盾，是发展的动力；矛盾律管的是你对同一对象不能同时既肯定又否定。两句混在一起，辨析题必扣分。

✗ “说他有罪不对，说他无罪也不对”是自相矛盾。

✓ 同时否定两个互相矛盾的判断，是“两不可”，违反排中律。

自相矛盾是“同时肯定”，“两不可”是“同时否定”，方向正好相反。有罪与无罪之间没有第三种情况，两个都否定才叫两不可。

✗ 偷换概念和转移论题是一回事，都是换了个说法。

✓ 偷换概念换的是概念的含义，转移论题换的是讨论的论题，都违反同一律，但层面不同。

概念是思维的细胞，论题是论证的方向。答题要先指出换的是哪一个层面，再说后果：换词让判断推理失真，换题让论证答非所问。材料里出现“换句话说”，先警惕。

✗ “逻辑”就是逻辑学，逻辑学就是研究怎么说话。

✓ “逻辑”有规律、逻辑规律与规则、思维方法、逻辑学等多重含义；逻辑学研究思维形式结构及其规律。

材料里说“强盗逻辑”“历史的逻辑”，指的是规律或方法，不是这门学问。先分清词义，再谈对象，这是第一框的送分点。

✗ 排中律要求对任何两个判断都必须选一个。

✓ 排中律只适用于同一时间、同一方面、对同一对象形成的两个互相矛盾的判断。

黑与白之间还有红，属于反对关系，可以都假，这时不适用排中律。把适用范围放大成“任何两个判断”，就会把正确的否定判成“两不可”。所以先看两个判断是不是矛盾关系，再决定用不用这条规律。
