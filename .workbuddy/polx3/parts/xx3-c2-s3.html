ELI5-HIGH · 讲给要考试的人

这一节真正要你会的，只有两句话：演绎推理从一般到个别，前提真实＋结构正确，结论才必然真实；三段论看中项，假言推理看肯/否的是哪一头。不是背「推理分几种」，而是拿到一段话就能验一遍。

数学课上老师说「所有三角形的内角和都是 180 度」，你在本子上画了一个三角形，于是断定「我这个三角形的内角和是 180 度」。你刚才做的事，就是演绎推理：拿一条管一整类对象的道理，落到眼前这一个对象上。这一节在整册里的位置很关键——前面学概念、学判断，都是攒零件；这一节开始把零件装成机器。最容易错的两处是：把「前提是真的」当成「推理一定有效」，把「地湿了」当成「一定下过雨」。考试里它就是那道「判断推理是否有效、错在哪一步」的题，材料换层皮，判据不变。

01课本怎么说

先背标准表述，再拆关键词。答题时写课本这句，不写你脑子里那句。

课本原话 · 演绎推理的含义与两个条件人教版（2019）选择性必修3 逻辑与思维 · 第二单元第六课

「演绎推理是从一般性前提推出个别性结论的推理。演绎推理是必然推理，前提真实、推理结构正确，结论就必然真实。」

→ 翻成人话：这里有两个条件，缺一个都不行。①前提得是真的，你拿来说事的那句话本身要符合事实；②结构得是对的，从前提走到结论的那一步要合规矩。两条都满足，结论才必然真；只满足一条，结论只能算碰巧对。数学证明敢下结论，就是因为这两条都站得住。

课本原话 · 三段论的构成人教版（2019）选择性必修3 逻辑与思维 · 第二单元第六课

「三段论是演绎推理的重要形式。它是以两个已知的性质判断为前提，借助一个共同的项，推出一个新的性质判断的推理。三段论由大项、小项和中项构成。」

→ 翻成人话：三段论就是「两个前提共用一个项，推出第三个判断」。结论的主项叫小项（S），结论的谓项叫大项（P），两个前提里都出现、结论里不出现的那个项叫中项（M）。中项是桥，桥没搭稳，两头就接不上。所以第一条规则是「中项至少周延一次」——周延，指这个项在判断里被断定了全部范围。

课本原话 · 复合判断的演绎推理人教版（2019）选择性必修3 逻辑与思维 · 第二单元第六课

「充分条件假言判断的前件真，后件一定真；后件假，前件一定假。必要条件假言判断的前件假，后件一定假；后件真，前件一定真。」

→ 翻成人话：假言推理只有四种走法，两种有效、两种无效。充分条件「如果 p 那么 q」：肯定前件就能肯定后件，否定后件就能否定前件；否定前件、肯定后件都不行。必要条件「只有 p 才 q」：否定前件就能否定后件，肯定后件就能肯定前件；肯定前件、否定后件都不行。答题先写条件类型，再写用了哪一种式。

比什么三段论假言推理
前提长什么样两个性质判断，共用一个项一个假言判断，加一个性质判断
靠什么连起来中项 M，两个前提都有、结论没有前件或后件，看肯定还是否定
有效式口诀中项至少周延一次充分：肯前肯后、否后否前；必要：否前否后、肯后肯前
最常见的错中项一次也没周延，还硬推结论充分条件肯定后件，必要条件肯定前件
判有效性先看哪一步先查中项周延没有，再查前提真假先定条件类型，再看肯/否的是前件还是后件

背法一句话：方向「一般到个别」，条件「真实＋正确」，三段论查「中项周延」，假言查「肯前肯后 / 否前否后」。这里有个坑：题目说「推理有效」，问的是形式；说「结论正确」，问的是内容和形式两头，两个词不能互换。还有一层：演绎推理的结论不会超出前提的范围，前提里没有的东西，结论里不能凭空长出来。答题顺序也固定：先写「这是三段论」或「这是充分条件假言推理」，再写「有效／无效」，最后写理由。顺序一反，判据就藏起来了。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 判断一个三段论是否有效必考

「所有鸟都会飞，企鹅是鸟，所以企鹅会飞。」请判断这个三段论是否有效，并说明理由。注意：题目问的是「是否有效」，不是「结论对不对」，这两件事要分开答。

  1. 第 1 步 · 审题定性

    先数句子：两个性质判断作前提，一个性质判断作结论，正好三个，这就是三段论。再圈出题目的问法：「是否有效」问形式，「结论对不对」问内容，先答形式。材料三句话都不长，先按「前提、前提、结论」标上序号，再动笔。

    用到：三段论、推理的有效性。

  2. 第 2 步 · 找三个项

    结论「企鹅会飞」里，主项「企鹅」是小项 S，谓项「会飞的」是大项 P。两个前提都出现的「鸟」是中项 M。写成标准形式：所有 M 是 P，所有 S 是 M，所以所有 S 是 P。标准形式读作「所有 M 是 P」：M 是中项，P 是大项；小前提读作「所有 S 是 M」，S 是小项。

    用到：大项、小项、中项。

  3. 第 3 步 · 查中项周延

    中项「鸟」在大前提里作全称判断的主项，周延；在小前提「企鹅是鸟」里作肯定判断的谓项，不周延。至少周延一次，这一条过关。再看结论有没有扩大范围：结论是单称判断，S 在小前提里也是单称主项，周延，没有超出前提。

    用到：周延、中项至少周延一次。

  4. 第 4 步 · 查前提真假

    形式过关，接着查内容。大前提「所有鸟都会飞」不符合事实，企鹅、鸵鸟、鸡都不会飞。前提假，结论就不能保证真。这一步是本节的扣分点：形式有效，不等于结论真实。

    用到：前提真实、结论的真实性。

  5. 第 5 步 · 分两层收口

    答案写两层：第一层说形式，中项周延、结论未扩大范围，推理形式有效；第二层说前提，大前提虚假，所以结论不能必然推出，事实上这个结论也是假的。最后补一句：这说明演绎推理要结论真实，前提真实和形式正确缺一不可。

    用到：两个条件、演绎推理的保真性。

1 / 5

标准答案（可抄进答题卡）

① 这是三段论。结论的主项「企鹅」是小项 S，结论的谓项「会飞的」是大项 P，两个前提共有的「鸟」是中项 M，形式为「所有 M 是 P，所有 S 是 M，所以所有 S 是 P」。
② 从形式看，这个推理有效：中项「鸟」在大前提中作全称判断的主项，是周延的，满足「中项至少周延一次」；结论中的小项 S 在小前提中作单称判断的主项，也周延，结论没有扩大范围。
③ 从前提看，大前提「所有鸟都会飞」不符合客观实际，是虚假前提。演绎推理要得到真实结论，必须前提真实且推理结构正确，这里只满足后者。
④ 所以，该三段论推理形式有效，但结论不能必然推出，事实上「企鹅会飞」为假。可见前提真实与推理有效是两件事，不能互相顶替。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「演绎推理的结论一定可靠吗？」

不一定。演绎推理的结论要必然真实，必须前提真实和推理结构正确同时成立。只满足一条，结论只能算可能真。答题时先写这两个条件，再落到材料上分别检查。同一道题里，「前提是否真实」常常单独一问，别混进形式里答。

「三段论的中项，为什么要至少周延一次？」

中项是连接两个前提的桥。它一次都不周延，说明两个前提只各说了一部分，没有真正接上，结论就推不出来。答这类题先指认中项，再说明它在两个前提里都不周延，最后落到「桥断了」。周延的意思就是「断定了全部范围」，全称的主项、否定的谓项都算。

「『所有 S 是 P』能换成『所有 P 是 S』吗？」

不能。全称肯定判断的谓项不周延，换到主项位置就变成周延，范围被放大。只能限量换位：「所有 S 是 P」换成「有些 P 是 S」。这一条在换位题里几乎每次都考。记住一句：换位只换位置，不换范围。

「换质法到底要改几个地方？」

改两处：联项由「是」改成「不是」或反过来；谓项换成它的矛盾概念。主项和量项都不动。改完两句话意思一样，只是说法变了，这就是换质能保真的原因。

「地湿了，能推出刚才下雨了吗？」

不能。「如果下雨，地就湿」是充分条件，只保证有前件必有后件。反过来肯定后件，推不出前件——地湿也可能是洒水车。充分条件只能肯前肯后、否后否前。

「年满 18 周岁，就一定有选举权吗？」

不一定。「只有年满 18 周岁，才有选举权」是必要条件，只说明没它不行，没说有它就够——还要未被剥夺政治权利。必要条件只能否前否后、肯后肯前，肯定前件推不出后件。答完「不一定」，还要把缺的那个条件补出来，答案才完整。

六问其实是同一件事：先看形式合不合规矩，再看前提真不真。形式管「推得出推不出」，前提管「结论对不对」；两条都过了，结论才敢写进答题卡。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 前提都是真的，这个推理就一定有效，结论一定对。

✓ 演绎推理要得到真实结论，必须前提真实、推理结构正确，两个条件缺一不可。

错在哪：把「有效」和「真实」合成一个词。有效说的是形式，真实说的是前提和结论的内容，考试喜欢在这里设一个选项。答题时把「有效」交给形式，把「真实」交给前提，两句话分开写。

✗ 中项在两个前提里都不周延，也一样能推出结论。

✓ 中项至少要在一个前提中周延，否则两个前提没有真正连接起来，推不出结论。

错在哪：忘了中项是桥。两次都不周延，桥就架空了，两个前提各说各的一部分，接不上。周延的意思是断定了全部范围，判它要一个前提一个前提地看。

✗ 「有些学生是团员，有些学生是党员，所以有些团员是党员」，前提都是真的，推理没错。

✓ 两个特称前提不能推出结论；这里中项「学生」在两个前提中都不周延，该三段论无效。

错在哪：拿前提真顶替形式有效。这个结论就算碰巧为真，也不是从这两个前提推出来的。两个特称前提推不出结论，这条规则本身就能判它无效。

✗ 结论里可以出现前提没提过的新词，只要意思说得通。

✓ 结论中的项必须来自前提；前提中不周延的项，在结论中也不得周延。

错在哪：一加新项，结论就超出前提范围，形式立刻无效。这是「结论扩大范围」的典型写法。

✗ 「所有金属都导电」可以换成「所有导电的都是金属」，换位就是主谓对调。

✓ 全称肯定判断只能限量换位：「所有金属都导电」换位为「有些导电的是金属」。

错在哪：全称肯定的谓项不周延，换到主项位置就周延了，范围被放大。换位不是随便对调。全称肯定换位只能换出特称，这是硬规则，不是语感问题。

✗ 如果下雨，地就湿；现在地湿了，所以刚才下雨了。

✓ 充分条件假言推理只能「肯前肯后」或「否后否前」；肯定后件推不出肯定前件。

错在哪：把后件当成了前件的唯一原因。洒水车、洗地都能让地湿，后件成立不代表前件成立。改成「否定后件」才有效：地没湿，才能推出没下雨。

✗ 只有年满 18 周岁，才有选举权；小王年满 18 周岁，所以小王有选举权。

✓ 必要条件假言推理只能「否前否后」或「肯后肯前」；肯定前件推不出肯定后件。

错在哪：把「没它不行」当成「有它就够」。必要条件只是一块敲门砖，凑齐它不等于条件全齐。改成「否定前件」才有效：没满 18 周岁，一定没有选举权。
