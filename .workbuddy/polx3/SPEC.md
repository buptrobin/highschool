## xx3-c1-s1 走进思维世界

**一句话**：思维是人脑对客观事物的间接的、概括的反映；思维具有间接性、概括性、能动性，分为形象思维和抽象思维。

**三个扣分点**：思维不是“大脑自带的凭空想法”，它来源于实践；间接性不等于主观臆测；形象思维和抽象思维不是“对错之分”，是两种形态。

**四张图**：① 思维的含义与三个特征（间接性、概括性、能动性）；② 形象思维与抽象思维；③ 思维与实践的关系；④ 思维形态在生活中的例子。

**五个情境**：
1. 早上看到地面湿、树叶滴水，判断夜里下过雨｜对应：思维的间接性｜依据：通过现象推断没有直接感知的事情。
2. 把苹果、梨、桃归为“水果”｜对应：思维的概括性｜依据：从个别事物中概括出共同本质。
3. 设计师先在脑中构思，再画出图纸｜对应：思维的能动性｜依据：思维能指导实践、改造世界。
4. 诗人用“月亮”表达思乡｜对应：形象思维｜依据：以具体形象为基本单元。
5. 科学家用公式、概念推导结论｜对应：抽象思维（逻辑思维）｜依据：以概念、判断、推理为基本形式。

**例题**：说明思维的特征。答案按“间接性、概括性、能动性”三点，各配一个生活例子。

## xx3-c1-s2 把握逻辑要义

**一句话**：逻辑学研究思维形式结构及其规律；逻辑思维要遵守同一律、矛盾律、排中律，做到确定性、一致性、明确性。

**三个扣分点**：同一律管“概念/论题不能偷换”；矛盾律管“不能同时肯定两个互相否定的判断”；排中律管“不能同时否定两个互相矛盾的判断”。

**四张图**：① 逻辑学的研究对象；② 同一律；③ 矛盾律；④ 排中律。

**五个情境**：
1. 讨论“要不要减负”，说着说着变成“作业该不该留”｜对应：转移论题（违反同一律）｜依据：论题中途被换掉。
2. 把“人民”偷换成“所有人”，再推出结论｜对应：偷换概念（违反同一律）｜依据：同一个词在不同语境含义不同。
3. “我这句话是假话”｜对应：自相矛盾（违反矛盾律）｜依据：同时肯定又否定同一判断。
4. “说他有罪不对，说他无罪也不对”｜对应：两不可（违反排中律）｜依据：两个互相矛盾的判断不能同时否定。
5. “这个方案总体很好，但每个环节都有问题”｜对应：自相矛盾/前后不一致｜依据：总体肯定与全面否定不能同真。

**例题**：分析“偷换概念”与“转移论题”的区别。答案按“同一律、概念/论题两个层面”展开。

## xx3-c1-s3 领会科学思维

**一句话**：科学思维追求认识的客观性、结果的可检验性、结论的可预见性，能指导人们正确认识和改造世界。

**三个扣分点**：科学思维不等于“科学家的思维”，人人可以学；可检验不等于“立刻能验证”；可预见不等于“算命”。

**四张图**：① 科学思维的含义；② 三个特征（客观性、可检验性、可预见性）；③ 科学思维与逻辑思维、辩证思维、创新思维的关系；④ 学习科学思维的意义。

**五个情境**：
1. 科学家做实验、公开数据，让别人重复｜对应：结果的可检验性｜依据：结论要能经受实践检验。
2. 气象台根据模型预测台风路径｜对应：结论的可预见性｜依据：把握规律，预见发展趋势。
3. 研究从事实出发，不凭主观好恶｜对应：认识的客观性｜依据：尊重客观实际。
4. “水变油”“永动机”拿不出可重复证据｜对应：违背科学思维｜依据：不可检验、违背科学规律。
5. 用科学思维分析社会问题，提出可行方案｜对应：科学思维的实践价值｜依据：指导实践、解决问题。

**例题**：为什么说科学思维能指导实践？答案按“客观性、可检验性、可预见性”展开。

## xx3-c2-s1 准确把握概念

**一句话**：概念是反映事物本质属性的思维形式，包括内涵和外延；定义要合规则，划分要相称。

**三个扣分点**：内涵是“是什么”，外延是“包括哪些”；定义不能用否定、比喻、循环；划分子项不能交叉、不能多出或漏掉。

**四张图**：① 概念的内涵与外延；② 定义的方法与规则；③ 划分的规则；④ 概念间的关系（全同、属种、交叉、矛盾等）。

**五个情境**：
1. “商品是用来交换的劳动产品”｜对应：属加种差定义｜依据：先找属概念，再找种差。
2. “生命是有生命的物体的生理现象”｜对应：循环定义｜依据：定义项直接或间接包含被定义项。
3. “正义就是非不正义”｜对应：否定定义｜依据：定义一般不能用否定形式。
4. “儿童是祖国的花朵”｜对应：比喻定义｜依据：比喻不能揭示本质属性。
5. 把“学生”分为“大学生、中学生、小学生、三好学生”｜对应：划分标准不一/子项交叉｜依据：同一次划分只能用一个标准，子项不能交叉。

**例题**：指出一个定义错在哪里并改正。答案按“属加种差、定义规则”展开。

## xx3-c2-s2 正确运用判断

**一句话**：判断是对认识对象有所断定的思维形式；简单判断分性质判断和关系判断，复合判断分联言、选言、假言判断。

**三个扣分点**：判断必须有所断定（不能模棱两可）；联言判断“都真才真”；选言判断分相容/不相容，假言判断分充分/必要/充要。

**四张图**：① 判断的含义；② 简单判断（性质判断、关系判断）；③ 复合判断（联言、选言、假言）；④ 判断的真值。

**五个情境**：
1. “小明既聪明又努力”｜对应：联言判断｜依据：两个支判断都真，联言才真。
2. “周末或者去图书馆，或者去打球”｜对应：相容选言判断｜依据：可以都去，至少一个真。
3. “要么选A，要么选B”｜对应：不相容选言判断｜依据：只能选一个。
4. “如果明天不下雨，我们就去春游”｜对应：充分条件假言判断｜依据：前件是后件的充分条件。
5. “只有努力学习，才能取得好成绩”｜对应：必要条件假言判断｜依据：前件是后件的必要条件。

**例题**：分析“如果下雨，地就湿”的逻辑形式。答案按“充分条件假言判断、前件后件、真值”展开。

## xx3-c2-s3 掌握演绎推理方法

**一句话**：演绎推理从一般到个别；三段论要“中项至少周延一次、前提真实”，复合判断推理要遵守充分/必要条件规则。

**三个扣分点**：前提真实不等于推理有效；中项不周延是常见错误；充分条件“肯定后件”不能推出“肯定前件”。

**四张图**：① 演绎推理的含义；② 三段论的结构与规则；③ 换质位推理；④ 复合判断推理规则。

**五个情境**：
1. “所有金属都导电，铜是金属，所以铜导电”｜对应：有效三段论｜依据：中项“金属”周延，前提真实。
2. “所有鸟都会飞，企鹅是鸟，所以企鹅会飞”｜对应：前提虚假（不是推理形式错）｜依据：大前提“所有鸟都会飞”不符合事实。
3. “有些学生是团员，有些学生是党员，所以有些团员是党员”｜对应：中项不周延，推理无效｜依据：两个特称前提不能推出结论。
4. “如果下雨，地就湿；地湿了，所以下雨了”｜对应：充分条件肯定后件，无效｜依据：地湿也可能因为洒水。
5. “只有年满18周岁，才有选举权；小王有选举权，所以小王年满18周岁”｜对应：必要条件肯定后件，有效｜依据：必要条件“肯后肯前”。

**例题**：判断一个三段论是否有效。答案按“中项周延、前提真假、结论范围”展开。

## xx3-c2-s4 学会归纳与类比推理

**一句话**：归纳推理从个别到一般，分完全归纳和不完全归纳；类比推理根据相同/相似属性推出，结论是或然的。

**三个扣分点**：完全归纳结论必然，不完全归纳结论或然；简单枚举不可靠；类比推理不是“相似就一定相同”。

**四张图**：① 归纳推理；② 完全归纳与不完全归纳；③ 求同法、求异法、共变法、剩余法；④ 类比推理。

**五个情境**：
1. 调查全班每个同学，得出“全班都参加了”｜对应：完全归纳推理｜依据：考察了全部对象。
2. 看到几只天鹅是白的，得出“所有天鹅都是白的”｜对应：简单枚举归纳｜依据：只考察部分对象，结论或然。
3. 不同场合都有A、B，只有C不同，结果不同｜对应：求异法｜依据：寻找差异因素。
4. 几个场合都有A，结果都出现a｜对应：求同法｜依据：寻找共同因素。
5. 根据鸟的翅膀发明飞机机翼｜对应：类比推理｜依据：根据相似属性进行类推。

**例题**：说明如何提高类比推理的可靠性。答案按“相似属性多、本质属性、反例”展开。

## xx3-c3-s1 把握辩证分合

**一句话**：辩证思维具有整体性和动态性；分析与综合是辩证思维的基本方法，分析是综合的基础，综合是分析的完成。

**三个扣分点**：分析不是“把事物拆开就完了”；综合不是“把部分简单相加”；整体性不等于“只看整体不看部分”。

**四张图**：① 辩证思维的整体性；② 辩证思维的动态性；③ 分析与综合；④ 分析与综合的辩证关系。

**五个情境**：
1. 只看一个零件，不看整台机器如何运转｜对应：形而上学、孤立看问题｜依据：只见部分不见整体。
2. 把问题拆成几个方面逐一研究｜对应：分析｜依据：把认识对象分解为部分、要素。
3. 把各部分研究结果整合成整体方案｜对应：综合｜依据：在分析基础上形成整体认识。
4. 研究经济问题既看国内也看国际、既看当前也看长远｜对应：辩证思维的整体性、动态性｜依据：多角度、发展地看。
5. 先分领域调研，再形成总体规划｜对应：分析基础上的综合｜依据：分析是综合的基础。

**例题**：说明分析与综合的辩证关系。答案按“分析是基础、综合是完成、二者相互依存”展开。

## xx3-c3-s2 理解质量互变

**一句话**：量变是质变的必要准备，质变是量变的必然结果；要把握适度原则，重视量的积累，抓住时机促成质变。

**三个扣分点**：量变不一定立刻引起质变，但达到一定程度必然引起；质变不是“全盘否定”；适度原则不是“不要变化”。

**四张图**：① 量变与质变；② 量变质变规律；③ 适度原则；④ 连续性与间断性。

**五个情境**：
1. 每天背十个单词，一年后词汇量明显提高｜对应：量的积累引起质变｜依据：量变是质变的必要准备。
2. 水温升到100℃沸腾｜对应：质变、度的临界点｜依据：达到一定程度发生质变。
3. “过犹不及”，批评过度反而伤感情｜对应：适度原则｜依据：保持事物的度。
4. 水滴石穿｜对应：量变到质变｜依据：持续积累。
5. 拔苗助长｜对应：违背质量互变规律｜依据：急于求成，跳过必要积累。

**例题**：用质量互变规律分析“循序渐进”。答案按“量变准备、质变飞跃、适度原则”展开。

## xx3-c3-s3 推动认识发展

**一句话**：辩证否定是事物自身的否定，是发展的环节、联系的环节，实质是“扬弃”；认识从感性具体到思维抽象，再到思维具体。

**三个扣分点**：辩证否定不是“全盘否定”或“全盘肯定”；扬弃是既克服又保留；思维具体不是“回到感性具体”。

**四张图**：① 辩证否定的含义；② 辩证否定的实质（扬弃）；③ 认识的两次飞跃；④ 认识发展的反复性、无限性。

**五个情境**：
1. 对传统文化“取其精华、去其糟粕”｜对应：辩证否定、扬弃｜依据：既克服又保留。
2. 把旧理论全部推翻，什么都不留｜对应：形而上学否定观｜依据：否定一切，割断联系。
3. 从观察现象到形成概念、规律｜对应：从感性具体到思维抽象｜依据：透过现象把握本质。
4. 把抽象概念综合成对事物整体的具体认识｜对应：从思维抽象到思维具体｜依据：在思维中再现具体。
5. 科学认识经过反复实验、不断修正｜对应：认识发展的反复性、无限性｜依据：认识是一个过程。

**例题**：说明辩证否定观与形而上学否定观的区别。答案按“自身否定/外力否定、扬弃/全盘否定”展开。

## xx3-c4-s1 创新思维要善于联想

**一句话**：创新思维思路新、方法新、结果新；联想思维通过迁移和想象，把已有认识与新材料连接起来。

**三个扣分点**：创新不是“凭空乱想”；迁移不是“照搬”；想象分有意想象和无意想象，创新主要靠有意想象。

**四张图**：① 创新思维的特征；② 联想思维；③ 迁移；④ 想象。

**五个情境**：
1. 鲁班被草叶划伤，想到做锯子｜对应：联想、迁移｜依据：从相似结构得到启发。
2. 根据蝙蝠回声定位发明雷达｜对应：迁移/类比联想｜依据：把一种原理迁移到另一领域。
3. 科幻作家构造未来世界｜对应：有意想象｜依据：有目的、有意识地创造新形象。
4. 看到云朵像小狗｜对应：无意想象｜依据：没有预定目的。
5. 把数学方法用到经济分析中｜对应：迁移｜依据：把一种知识方法用到新情境。

**例题**：说明联想思维在创新中的作用。答案按“迁移、想象、连接已有与未知”展开。

## xx3-c4-s2 创新思维要多路探索

**一句话**：创新思维要多路探索：发散思维与聚合思维结合，逆向思维另辟蹊径，头脑风暴、检核表、信息交合等方法各有用处。

**三个扣分点**：发散不是“胡思乱想”，要围绕目标；聚合不是“简单相加”，要筛选优化；逆向不是“抬杠”，要合理反向。

**四张图**：① 发散思维；② 聚合思维；③ 逆向思维；④ 常用创新方法。

**五个情境**：
1. 一道题想出多种解法｜对应：发散思维｜依据：从不同方向、不同角度思考。
2. 把多种方案比较、筛选出最优方案｜对应：聚合思维｜依据：在发散基础上集中、优化。
3. 别人想“如何让伞更防水”，你想“如何让水不沾伞”｜对应：逆向思维｜依据：对事物结构、功能反向思考。
4. 用检核表逐项提问：能否替代、组合、颠倒｜对应：检核表法｜依据：按清单逐项激发新想法。
5. 一群人自由提想法，先不批评，再汇总｜对应：头脑风暴法｜依据：延迟评判，激发大量设想。

**例题**：说明发散思维与聚合思维的关系。答案按“发散是基础、聚合是提升、二者结合”展开。

## xx3-c4-s3 创新思维要力求超前

**一句话**：超前思维具有预测性、不确定性；要通过矛盾分析、推理和想象、调查研究，把握事物发展趋势。

**三个扣分点**：超前思维不是“算命”，不是“瞎猜”；预测具有不确定性；超前思维要立足现实、尊重规律。

**四张图**：① 超前思维的含义；② 超前思维的特征（预测性、不确定性）；③ 超前思维的方法（矛盾分析、推理想象、调查研究）；④ 超前思维的意义。

**五个情境**：
1. 气象台根据数据预测台风路径｜对应：超前思维的预测性｜依据：把握规律、推断趋势。
2. 企业调研市场需求，提前布局新产品｜对应：调查研究｜依据：从实际出发，掌握信息。
3. 分析社会主要矛盾变化，判断发展方向｜对应：矛盾分析法｜依据：抓住矛盾及其变化。
4. 面对多种可能，准备多套预案｜对应：超前思维的不确定性｜依据：预测不是确定无疑，要留有余地。
