# 本节规格

## xx3-c2-s2 正确运用判断

**一句话**：判断是对认识对象有所断定的思维形式；简单判断分性质判断和关系判断，复合判断分联言、选言、假言判断。

**三个扣分点**：判断必须有所断定（不能模棱两可）；联言判断“都真才真”；选言判断分相容/不相容，假言判断分充分/必要/充要。

**四张图**：① 判断的含义；② 简单判断（性质判断、关系判断）；③ 复合判断（联言、选言、假言）；④ 判断的真值。

**五个情境**：
1. “小明既聪明又努力”｜对应：联言判断｜依据：两个支判断都真，联言才真。
2. “周末或者去图书馆，或者去打球”｜对应：相容选言判断｜依据：可以都去，至少一个真。
3. “要么选A，要么选B”｜对应：不相容选言判断｜依据：只能选一个。
4. “如果明天不下雨，我们就去春游”｜对应：充分条件假言判断｜依据：前件是后件的充分条件。
5. “只有努力学习，才能取得好成绩”｜对应：必要条件假言判断｜依据：前件是后件的必要条件。

**例题**：分析“如果下雨，地就湿”的逻辑形式。答案按“充分条件假言判断、前件后件、真值”展开。
