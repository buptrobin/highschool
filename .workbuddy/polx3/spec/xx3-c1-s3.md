# 本节规格

## xx3-c1-s3 领会科学思维

**一句话**：科学思维追求认识的客观性、结果的可检验性、结论的可预见性，能指导人们正确认识和改造世界。

**三个扣分点**：科学思维不等于“科学家的思维”，人人可以学；可检验不等于“立刻能验证”；可预见不等于“算命”。

**四张图**：① 科学思维的含义；② 三个特征（客观性、可检验性、可预见性）；③ 科学思维与逻辑思维、辩证思维、创新思维的关系；④ 学习科学思维的意义。

**五个情境**：
1. 科学家做实验、公开数据，让别人重复｜对应：结果的可检验性｜依据：结论要能经受实践检验。
2. 气象台根据模型预测台风路径｜对应：结论的可预见性｜依据：把握规律，预见发展趋势。
3. 研究从事实出发，不凭主观好恶｜对应：认识的客观性｜依据：尊重客观实际。
4. “水变油”“永动机”拿不出可重复证据｜对应：违背科学思维｜依据：不可检验、违背科学规律。
5. 用科学思维分析社会问题，提出可行方案｜对应：科学思维的实践价值｜依据：指导实践、解决问题。

**例题**：为什么说科学思维能指导实践？答案按“客观性、可检验性、可预见性”展开。
