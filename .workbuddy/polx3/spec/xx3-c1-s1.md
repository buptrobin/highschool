# 本节规格

## xx3-c1-s1 走进思维世界

**一句话**：思维是人脑对客观事物的间接的、概括的反映；思维具有间接性、概括性、能动性，分为形象思维和抽象思维。

**三个扣分点**：思维不是“大脑自带的凭空想法”，它来源于实践；间接性不等于主观臆测；形象思维和抽象思维不是“对错之分”，是两种形态。

**四张图**：① 思维的含义与三个特征（间接性、概括性、能动性）；② 形象思维与抽象思维；③ 思维与实践的关系；④ 思维形态在生活中的例子。

**五个情境**：
1. 早上看到地面湿、树叶滴水，判断夜里下过雨｜对应：思维的间接性｜依据：通过现象推断没有直接感知的事情。
2. 把苹果、梨、桃归为“水果”｜对应：思维的概括性｜依据：从个别事物中概括出共同本质。
3. 设计师先在脑中构思，再画出图纸｜对应：思维的能动性｜依据：思维能指导实践、改造世界。
4. 诗人用“月亮”表达思乡｜对应：形象思维｜依据：以具体形象为基本单元。
5. 科学家用公式、概念推导结论｜对应：抽象思维（逻辑思维）｜依据：以概念、判断、推理为基本形式。

**例题**：说明思维的特征。答案按“间接性、概括性、能动性”三点，各配一个生活例子。
