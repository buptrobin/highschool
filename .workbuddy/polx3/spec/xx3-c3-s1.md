# 本节规格

## xx3-c3-s1 把握辩证分合

**一句话**：辩证思维具有整体性和动态性；分析与综合是辩证思维的基本方法，分析是综合的基础，综合是分析的完成。

**三个扣分点**：分析不是“把事物拆开就完了”；综合不是“把部分简单相加”；整体性不等于“只看整体不看部分”。

**四张图**：① 辩证思维的整体性；② 辩证思维的动态性；③ 分析与综合；④ 分析与综合的辩证关系。

**五个情境**：
1. 只看一个零件，不看整台机器如何运转｜对应：形而上学、孤立看问题｜依据：只见部分不见整体。
2. 把问题拆成几个方面逐一研究｜对应：分析｜依据：把认识对象分解为部分、要素。
3. 把各部分研究结果整合成整体方案｜对应：综合｜依据：在分析基础上形成整体认识。
4. 研究经济问题既看国内也看国际、既看当前也看长远｜对应：辩证思维的整体性、动态性｜依据：多角度、发展地看。
5. 先分领域调研，再形成总体规划｜对应：分析基础上的综合｜依据：分析是综合的基础。

**例题**：说明分析与综合的辩证关系。答案按“分析是基础、综合是完成、二者相互依存”展开。
