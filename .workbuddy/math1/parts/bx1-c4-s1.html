一句话说清本节最该记住的判断：分数指数幂的底数必须为正 + ⁿ√(aⁿ) 偶次等于 |a|。

人教A版必修第一册 第四章第 1 节 高一 · 必修第一册 阅读 12 分钟 含 1 个互动模型

指数是整章的入口：后面指数函数、对数、幂函数全挂在「a^x 的运算」上。这一节真正要过的关只有三道——把根式写成 a^(m/n) 时底数必须为正、负指数是倒数（0 的负指数没有意义）、ⁿ√(aⁿ) 在 n 为偶数时等于 |a| 而不是 a。三条里错一条，后面所有化简题都会连锁失分。

01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · n 次方根人教A版必修第一册 · 第四章第 1 节

若 xⁿ=a（n>1，n∈N*），则 x 叫做 a 的 n 次方根；正数的偶次方根有两个，负数没有偶次方根。

→ 翻成人话：这句话由三个条件组成——① n 是大于 1 的正整数；② 偶次方根要给出正负两个；③ 负数没有偶次方根。少第 ③ 条，就会写 √(−4) = −2 这种根本不存在的数。

课本原话 · 分数指数幂人教A版必修第一册 · 第四章第 1 节

a^(m/n) = ⁿ√(a^m)（a>0，m，n∈N*，n>1）。

→ 翻成人话：三个条件一个都不能丢——底数 a 必须大于 0、指数分子 m 与根指数 n 都是正整数、n 还要大于 1。底数为负时这条互化不成立；0 的负指数幂同样没有意义。

课本原话 · 指数运算法则人教A版必修第一册 · 第四章第 1 节

同底数幂相乘：a^m·a^n = a^(m+n)；幂的乘方：(a^m)^n = a^(mn)。

→ 翻成人话：两条法则底数都不变，区别只在指数「做加法」还是「做乘法」。把 a^m·a^n 写成 a^(mn) 是最常见的一处错，也是本节唯一需要靠对比记忆的地方。

条件不满足时会发生什么
a>0（分数指数幂）a=−4 时 a^(1/2)=√(−4) 不是实数，互化公式失效
n>1 且 n∈N*n=1 时 ⁿ√ 退化成 a 本身，这一层规定没有内容
偶次方根取正负两个只写一个就丢解：16 的四次方根是 ±2，而 √16 只表示算术根 2
a≠0（零指数与负指数）0^(−1)=1/0 没有意义；0^(−2)、0⁰ 同样无意义——负指数是倒数，分母不能为 0
同底数（乘法与除法法则）底数不同不能合并指数：2³·3² 不能写成 6⁵

整张表只高亮 1 行：负指数是倒数，所以底数一旦为 0 就整条失效。答题卡上写「因为 a≠0，所以 a^(−n)=1/aⁿ」，比只写结果稳。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 分数指数幂与负指数幂的化简必考

计算 8^(2/3) + (1/2)^(−2)。（两个陷阱：8^(2/3) 不是 8²÷3；(1/2)^(−2) 不是 −(1/2)²。）

  1. 第 1 步 · 审题：先统一底数

    8=2³，(1/2)=2⁻¹，两项都能化成以 2 为底的幂，再各自用运算法则。

    用到：底数相同才能合并指数；负指数是倒数。

  2. 第 2 步 · 化 8^(2/3)

    8^(2/3)=(2³)^(2/3)=2^(3×2/3)=2²=4。括号外的指数相乘，这是幂的乘方。

    用到：(a^m)^n=a^(mn)，此时 a=2>0，条件满足。

  3. 第 3 步 · 化 (1/2)^(−2)

    (1/2)^(−2)=1/(1/2)²=1/(1/4)=4。负指数先把幂翻到分母，再平方。

    用到：a^(−n)=1/aⁿ（a≠0）；(1/2)≠0，式子有意义。

  4. 第 4 步 · 相加

    两项都是 4，4+4=8。两个幂底数相同但指数不同，不能合并成一个幂，只能先各算各的再相加。

    用到：只有同底数幂相乘才能加指数，加法没有合并法则。

  5. 第 5 步 · 换条路验算

    (1/2)^(−2)=(2⁻¹)^(−2)=2^(−1×−2)=2²=4，与第 3 步一致；8^(2/3)=³√(8²)=³√64=4，与第 2 步一致。

    用到：a^(m/n)=ⁿ√(a^m)；两条路径同结果才算做对。

1 / 5

标准答案（可抄进答题卡）

解：8^(2/3)=(2³)^(2/3)=2²=4；　　　(1/2)^(−2)=1/(1/2)²=4；　　　所以 8^(2/3)+(1/2)^(−2)=4+4=8。
说明：负指数是倒数，底数 (1/2)≠0 时 (1/2)^(−2)=1/(1/2)²；若底数为 0，如 0^(−1)，则无意义，不能计算。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「ⁿ√(aⁿ) 一定等于 a 吧？」

不一定。n 为偶数时 ⁿ√(aⁿ)=|a|，n 为奇数时才等于 a。因为偶次方根的结果不能为负，而 a 可以是负数。

「负指数是不是把负号提到前面？」

不是。负指数是倒数：a^(−n)=1/aⁿ（a≠0）。负号进的是分母，不是整个式子的正负号，所以 a^(−n)≠−aⁿ。

「0 的负指数幂等于 0 吗？」

0 的负指数幂没有意义。负指数是倒数，0^(−1)=1/0 分母为 0，式子不存在；0 只有正指数幂等于 0。

「分数指数幂的底数为什么非要正数？」

因为 a^(m/n)=ⁿ√(a^m) 要求对任意 m、n 都有唯一确定的实数。a<0 时偶次根开不出来，法则就会自相矛盾，所以课本统一规定 a>0。

「a^m·a^n 和 (a^m)^n 差在哪？」

指数相加还是相乘。两个幂并排相乘是 a^(m+n)；(a^m)^n 是幂再乘方，指数相乘得 a^(mn)。

「2^(1/2) 不就是 1 吗？」

不是。2^(1/2)=√2≈1.414，是无理数，比 1 大、比 2 小。分数指数幂只是根式的另一种写法，不改变数值。

六问其实是同一件事：先把底数与根指数的条件摆出来，再动指数。条件不满足就没有式子，谈不上算错还是算对。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ ⁿ√(aⁿ)=a，对任何 n 都成立

✓ n 为偶数时 ⁿ√(aⁿ)=|a|；n 为奇数时才等于 a

错在哪：偶次方根的结果不能为负，⁴√((−3)⁴)=3，直接写 −3 就把符号弄丢了。

✗ a^(−n)=−aⁿ，负号提到前面

✓ a^(−n)=1/aⁿ（a≠0），负指数是倒数

错在哪：负号进的是分母。2⁻³=1/8，不是 −8；一个小于 1 的正数，不可能变成负数。

✗ 0^(−1)=0，因为底数是 0

✓ 0 的负指数幂没有意义（负指数是倒数，分母不能为 0）

错在哪：0^(−1)=1/0 根本不存在，写成 0 等于给一个不存在的式子硬塞了值。

✗ a^m·a^n=a^(mn)

✓ a^m·a^n=a^(m+n)；(a^m)^n=a^(mn)

错在哪：并排相乘用加法，括号外还有指数才用乘法，两条法则的适用对象不同。

✗ 分数指数幂的底数取负数也能算，比如 (−8)^(2/3)=4

✓ a^(m/n)=ⁿ√(a^m) 的前提是 a>0、n>1

错在哪：负底数配偶次根在实数范围内没有定义，换个 m、n 就会自相矛盾，所以课本统一要求 a>0。

✗ 2^(1/2)=1，指数是分数就约掉了

✓ 2^(1/2)=√2≈1.414，是无理数

错在哪：分数指数幂只是根式的另一种写法，2^(1/2) 表示「平方得 2 的正数」，不是 2 除以 2。

✗ 8^(2/3)=8²÷3=64/3

✓ 8^(2/3)=(2³)^(2/3)=2²=4

错在哪：分母 3 是根指数不是除数。正确读法是「先 3 次方根、再平方」，顺序换过来 ³√(8²)=³√64=4 也一样。
