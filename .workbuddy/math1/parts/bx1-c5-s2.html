前面刚把角从锐角扩到任意角、把弧度制讲完，这一节马上给「任意角」配一个数——用单位圆。它在整章的位置是地基：后面同角关系、诱导公式、图象性质，全部从这里长出来。最容易错的一件事：把 sinα 记成「对边比斜边」，于是第二象限的 sin、cos 符号一错到底。

01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 三角函数的定义人教A版必修第一册 · 第五章第二节

设 α 是一个任意角，α 的终边与单位圆交于点 P(x, y)，则 sinα = y，cosα = x，tanα = y/x（x ≠ 0）。

→ 翻成人话：这句话由三个条件锁死——① 圆必须是单位圆（半径 1，圆心在原点）；② 点 P 必须取在终边与圆的交点上，不是随便一点；③ tanα 额外要求 x ≠ 0。少第 ① 条，坐标就变成 r·cosα、r·sinα，不再是函数值本身；少第 ③ 条，tan 90° 就会被你写成一个数。

课本原话 · 为什么叫「函数」人教A版必修第一册 · 第五章第二节

正弦、余弦、正切都是以角为自变量、以比值为函数值的函数。

→ 翻成人话：自变量是角（可以取任意实数，单位是弧度），函数值是比值（一个纯数，没有单位）。所以 sin 后面跟的必须是角，sin30° 的 30° 不能扔；而 sinα 的结果 −0.5 是一个数，不是长度。

课本原话 · 符号规律人教A版必修第一册 · 第五章第二节

三角函数值的符号：一全正、二正弦、三正切、四余弦。

→ 翻成人话：这十二个字是结论不是定义，它来自「P 的坐标在哪个象限」。第一象限 x>0、y>0，三个全正；第二象限 x<0、y>0，只有 sin 正；第三象限 x<0、y<0，只有 tan 正（负÷负）；第四象限 x>0、y<0，只有 cos 正。记不住就画圆看坐标符号，两秒钟的事。

定义里的条件缺了它会怎样
圆是单位圆，半径 r = 1坐标变成 (r·cosα, r·sinα)，sinα 就不等于纵坐标了，要再除一个 r
P 在终边与圆的交点上取终边上别的点，坐标随点的远近变化，同一个角算出不同的值
tanα = y/x 要求 x ≠ 0α = 90°、270° 时 x = 0，tan 无意义，不能写成 0，也不能写成 ∞
自变量是角，函数值是比值把 sinα 当成一条边长，符号、范围、后面的公式全部对不上

整张表只高亮 1 行：x ≠ 0 那行是每年都有人踩的坑。口径提醒：课本说的是「比值」，不是「边长比」——比值可正可负，边长只能为正，这就是符号规律的来源。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 由终边上一点求三个函数值必考

已知角 α 的终边经过点 P(−3, 4)，求 sinα、cosα、tanα 的值。陷阱：点的坐标带负号，先判断象限再动笔。

  1. 第 1 步 · 先定象限与符号

    x = −3 < 0，y = 4 > 0，P 在第二象限。所以 sinα > 0、cosα < 0、tanα < 0。先把这三个符号写在草稿上，最后对答案用。

    用到：符号规律「二正弦」——第二象限只有正弦为正。

  2. 第 2 步 · 求 r

    r = √(x² + y²) = √((−3)² + 4²) = √(9 + 16) = √25 = 5。r 是到原点的距离，一定取正值。

    用到：单位圆定义推广到「半径 r」的情形，r 恒正。

  3. 第 3 步 · 求 sinα

    sinα = y/r = 4/5。分子直接写纵坐标 4，正数，与第 1 步的判断一致。

    用到：sinα = y/r，即「纵坐标 ÷ 距离」。

  4. 第 4 步 · 求 cosα

    cosα = x/r = −3/5。负号必须保留在分子上，不能写成 3/5，也不能写成 −3/−5。

    用到：cosα = x/r；这里最容易丢负号。

  5. 第 5 步 · 求 tanα 并回验

    tanα = y/x = 4/(−3) = −4/3。注意 tan 不经过 r，直接用原坐标相除；x ≠ 0，所以有意义。回验：sin 正、cos 负、tan 负，与第 1 步完全吻合。

    用到：tanα = y/x（x ≠ 0），且「符号先判、数值后算」是稳的顺序。

1 / 5

标准答案（可抄进答题卡）

由 P(−3, 4) 得 x = −3，y = 4，
r = √(x² + y²) = √(9 + 16) = 5。
所以 sinα = y/r = 4/5；cosα = x/r = −3/5；tanα = y/x = 4/(−3) = −4/3。
因为点 P 在第二象限，故 sinα > 0、cosα < 0、tanα < 0，结果符号与此一致。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「三个函数分别在哪几个象限为正？我总记混。」

一全正、二正弦、三正切、四余弦：sin 在一、二象限为正，cos 在一、四象限为正，tan 在一、三象限为正。第二象限只有正弦为正。

「tan 什么时候无意义？写成 0 行不行？」

α = 90° + k·180°（终边落在 y 轴上）时 x = 0，tanα 无意义，既不是 0 也不是无穷大，答题卡上写「无意义」或「不存在」。

「题目不给单位圆，只给终边上一点，还能求吗？」

能。取任意一点 P(x, y)，先算 r = √(x² + y²)，再 sinα = y/r、cosα = x/r、tanα = y/x（x ≠ 0）。单位圆只是 r = 1 的特殊情形。

「sin²α + cos²α 等于多少？为什么？」

等于 1。因为 P(cosα, sinα) 在单位圆上，坐标为 (x, y) 且 x² + y² = 1，代入即得。这是同角关系的第一条，后面全靠它。

「第二象限 cos 为什么是负的？」

因为 cosα 就是 P 的横坐标 x，而第二象限的点在 y 轴左侧，x < 0。同理第二象限 sinα = y > 0。符号问题一律回到坐标。

「既然能用直角三角形，为什么还要单位圆？」

直角三角形只能处理锐角，而且边长恒正、写不出负号；单位圆用坐标定函数值，任意角都成立，符号随象限自然出现。定义用单位圆，不是直角三角形。

这六问其实是同一件事：一切回到 P(x, y) 的坐标。符号、无意义、求值、平方和，全是坐标的推论——所以定义要背成「单位圆上交点的坐标」，不能背成「对边比斜边」。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 第二象限 sinα 和 cosα 都是正的，都在 y 轴左边嘛。

✓ 第二象限只有 sinα 为正，cosα < 0，tanα < 0。

错在哪：cosα 是横坐标 x，第二象限 x < 0，必为负；「二正弦」只说正弦一个为正。

✗ tan90° = 0，因为 90° 时正弦余弦都差不多。

✓ 90° 时 cos90° = 0，tan90° 无意义（x = 0，分母为零）。

错在哪：tanα = y/x，x = 0 时除法没有定义；90° 时 sin 是最大值 1，不是 0。

✗ sinα = 邻边/斜边，cosα = 对边/斜边。

✓ sinα = y/r（纵坐标比距离），cosα = x/r（横坐标比距离）。

错在哪：定义用单位圆上的坐标，不是直角三角形的边；一旦记反，30° 与 60° 的值全颠倒。

✗ sin60° = 1/2，cos30° = √3/2。

✓ sin30° = 1/2，sin60° = √3/2；cos30° = √3/2，cos60° = 1/2。

错在哪：把 30° 与 60° 的正弦记反了。记法：角越大，sin 越大（0°→90° 递增），cos 越小。

✗ 终边过 P(−3, 4)，所以 cosα = 3/5。

✓ cosα = x/r = −3/5，负号必须保留。

错在哪：算完数值忘了符号。正确顺序是先判象限定符号、再算数值。

✗ 三角函数只能用在锐角三角形里，钝角没有三角函数值。

✓ 三角函数以任意角为自变量，钝角、负角、大于 360° 的角都有函数值。

错在哪：把初中「解直角三角形」的适用范围当成了定义；单位圆定义对任意角成立。

✗ sinα = 4/5，所以这条边长度是 4/5。

✓ sinα 是一个比值（纯数），不是长度，也没有单位。

错在哪：函数值是比值，可正可负；长度恒正，两者不能混。这也是为什么 sin 能取负值。
