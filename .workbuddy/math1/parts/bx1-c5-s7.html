01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 简谐运动人教A版必修第一册 · 第5章第7节

简谐运动的位移 y 与时间 t 的关系可以用 y = A sin(ωt + φ) 描述，其中 A 叫振幅，T = 2π/ω 叫周期，φ 叫初相。

→ 翻成人话：这句话由三个条件组成——① A 管「峰有多高」，② ω 管「多久重复一次」，③ φ 管「t = 0 时曲线在哪儿」。少一个，图就画不出来；错一个，曲线要么被拉高、要么被压扁、要么整体左右错位。

课本原话 · 周期现象人教A版必修第一册 · 第5章第7节

实际问题中的周期现象（潮汐、温度、交变电流）常用三角函数建模。

→ 翻成人话：只要是「按固定节奏来回变」的量，就先假设它形如 y = A sin(ωt + φ) + b，再用四件事把 A、b、ω、φ 一个个定下来。注意多出来的那个 b：潮水不会围着 0 米上下摆，它围着平均水深上下摆。

课本原话 · 建模步骤人教A版必修第一册 · 第5章第7节

建模步骤：设模型 → 由最值定 A、由周期定 ω、由特殊点定 φ → 还原。

→ 翻成人话：四个量各有各的出处，不许互相顶替——A 和 b 只能从最值来，ω 只能从周期来，φ 只能从特殊点来。混着用就是本题最大的失分点。

h(t) = A sin(ωt + φ) + b，其中 A = (最大值−最小值)/2，b = (最大值+最小值)/2，ω = 2π/T

要定的量必须由什么定搞错了会怎样
振幅 AA 由 (最大值−最小值)/2 定直接取最大值，振幅翻倍，曲线整体被拉高
中位线 b中位线 b 由 (最大值+最小值)/2 定漏掉 b，曲线贴着 t 轴走，所有水深值全错
角频率 ω由周期 T 定：ω = 2π/T把半个周期当成 T，ω 大一倍，图象挤成两倍密
初相 φφ 要用特殊点代入且注意范围随手取 0，图象能画但整体左右平移，最值时刻全错
定义域与单位t ≥ 0，且时间统一为小时小时与分钟混用，ω 差 60 倍，周期算成 0.2 小时

背法：一图三读——先读最值（得 A、b）→ 再读周期（得 ω）→ 最后读一个特殊点（得 φ）。表里只高亮最容易漏的那一行：中位线 b。它是「水面平均高度」，不是坐标原点。

04一道题走一遍

例题 · 潮汐模型求最值与时段必考

某港口的水深 h（米）与时间 t（时）近似满足 h(t) = 3sin(πt/6) + 5，t ∈ [0,24)。
(1) 求一天中水深的最大值、最小值与周期；
(2) 一天内水深不低于 6.5 米的时间共有多少小时？
陷阱：第 (2) 问只解出一个区间就交卷，漏掉周期带来的第二段。

h(t) = 3sin(πt/6) + 5，t ∈ [0,24)

  1. 第 1 步 · 审题：把式子对上模型

    把 h(t) = 3sin(πt/6) + 5 与 y = A sin(ωt + φ) + b 逐项对照：A = 3，ω = π/6，φ = 0，b = 5；t 的单位是小时，h 的单位是米，两者都不换算。

    用到：形如 y = A sin(ωt+φ) + b 的对照，先认参数再算数。

  2. 第 2 步 · 求最值

    sin 的最大值是 1、最小值是 −1，所以 h 最大 = b + A = 5 + 3 = 8（此时 πt/6 = π/2，即 t = 3），h 最小 = b − A = 5 − 3 = 2（此时 πt/6 = 3π/2，即 t = 9）。反向记：A 由 (最大值−最小值)/2 定，b 由 (最大值+最小值)/2 定。

    用到：振幅 A 与中位线 b 的定义，最值点由相位等于 π/2、3π/2 给出。

  3. 第 3 步 · 求周期与涨落次数

    T = 2π/ω = 2π ÷ (π/6) = 12（小时）。一天 24 小时 = 2 个周期，所以一天内涨落两次：0～12 时一次，12～24 时一次。

    用到：周期只由 ω 决定，与 A、b 无关——A 改高度，ω 改疏密。

  4. 第 4 步 · 解第二问的三角不等式

    由 3sin(πt/6) + 5 ≥ 6.5 得 sin(πt/6) ≥ 1/2，故一个周期内 π/6 ≤ πt/6 ≤ 5π/6，即 1 ≤ t ≤ 5。再加上周期 12，得 13 ≤ t ≤ 17。两段各 4 小时，合计 8 小时。

    用到：sin θ ≥ 1/2 的解集 [π/6 + 2kπ, 5π/6 + 2kπ]，以及用定义域 t ∈ [0,24) 截取。

  5. 第 5 步 · 代回检验并作答

    代 t = 3 得 h = 8，代 t = 9 得 h = 2，与第 2 步一致；代边界 t = 1 得 h = 6.5，正好卡在临界值上。检验通过，可以作答。

    用到：检验 = 把特殊点、端点代回原式，看是否与已得结论吻合。

1 / 5

标准答案（可抄进答题卡）

(1) 由 h(t) = 3sin(πt/6) + 5 知 A = 3，b = 5，ω = π/6。故 h 最大 = 5 + 3 = 8（米），此时 πt/6 = π/2，t = 3；h 最小 = 5 − 3 = 2（米），此时 πt/6 = 3π/2，t = 9。周期 T = 2π/ω = 2π ÷ (π/6) = 12（小时）。
(2) 由 24 ÷ 12 = 2 知一天内涨落两次。令 3sin(πt/6) + 5 ≥ 6.5，即 sin(πt/6) ≥ 1/2，得 π/6 ≤ πt/6 ≤ 5π/6 + 2kπ 型的解集，一个周期内为 1 ≤ t ≤ 5，再加周期得 13 ≤ t ≤ 17。故共有 4 + 4 = 8（小时）。
答：水深最大 8 米（t = 3 时），最小 2 米（t = 9 时），周期 12 小时，一天涨落两次，水深不低于 6.5 米的时间共 8 小时。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「最大值是 8，那振幅 A 就等于 8 吧？」

不是。振幅是曲线到中位线的距离：A 由 (最大值−最小值)/2 定，所以 A = (8 − 2)/2 = 3；剩下的 5 才是中位线 b。直接取最大值，等于把「水面高度」当成了「振幅」。

「图上相邻两个最低点隔 6 小时，所以 T = 6？」

那是半个周期。周期要读相邻两个最高点（或相邻两个最低点）横坐标之差：T = 12 小时，ω = 2π/T = π/6。T 读错一倍，ω 就错一倍，整条曲线挤成两倍密。

「φ 取 0 行不行？」

只有当 t = 0 时曲线恰在中位线且开始上升，才有 φ = 0。一般地 φ 要用特殊点代入且注意范围：把最高点 t = 3、h = 8 代入得 sin(π/2 + φ) = 1，取 |φ| < π/2 得 φ = 0；起点换到高潮，φ 就跟着变。

「为什么一天正好涨落两次？」

因为 T = 12 小时，24 ÷ 12 = 2，一天正好两个完整周期。涨落次数只由 ω 决定：把 A 从 3 改成 4，潮水涨得更高，但一天还是两次。

「有了 h = 3sin(πt/6) + 5，明年的今天也能算？」

不能。这个模型只用了一个港口、一天的数据，只在天气相近、日期相邻时可信；t 超出 [0,24) 或遇上台风、大潮，都必须重新取数建模。模型有适用范围，不是一条万能公式。

「实测最低 1.6 米，模型给 2 米，模型是不是错了？」

先看偏差是随机的还是系统的：每次都整体低 0.4 米，就平移修正中位线 b；只有个别时刻偏低，说明叠加了别的因素（大潮、径流）。此时应缩小适用范围或分段建模，而不是硬套一条曲线。

这六问其实是同一件事：每个参数只认一个出处——A、b 认最值，ω 认周期，φ 认特殊点；剩下的问题都归到「这个模型在什么范围内可信」。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ h 的最大值是 8，所以振幅 A = 8。

✓ A 由 (最大值−最小值)/2 定，A = (8 − 2)/2 = 3，中位线 b = 5。

错在哪：最大值里混着中位线，A 是「峰到中位线」的距离，不是峰的高度。

✗ 图象上相邻两个最低点隔 6 小时，所以周期 T = 6。

✓ 相邻两个最高点（或最低点）横坐标之差才是周期，T = 12 小时。

错在哪：读成了半个周期，ω = 2π/T 会算大一倍，图象疏密全错。

✗ φ 取 0 最省事，反正曲线的形状一样。

✓ φ 要用特殊点代入且注意范围，例如代 t = 3、h = 8 得 φ = 0。

错在哪：φ 改的是左右位置，形状确实一样，但最高潮出现的时刻全错。

✗ h = 3sin(πt/6) + 5，所以曲线围着 t 轴上下摆。

✓ 中位线 b 由 (最大值+最小值)/2 定，b = 5，曲线围 h = 5 上下摆动。

错在哪：漏掉水平线 b，所有水深值凭空少了 5 米，最值也跟着错。

✗ t 用分钟代进去也一样，反正都是时间。

✓ 先统一单位：t 以小时计，ω = π/6 才成立；若 t 用分钟，ω 必须同步换算。

错在哪：ω 与时间单位绑定，单位不统一，周期会差 60 倍。

✗ 3sin(πt/6) + 5 可以写成 3sin(πt/6 + 5)。

✓ 加 5 是上下平移，写在括号外：3sin(πt/6) + 5。

错在哪：+5 进了括号就变成相位，振幅、周期、最值全被改掉。

✗ 参数算完直接写答案，检验是多余的一步。

✓ 把特殊点代回原式检验：t = 3 得 h = 8、t = 9 得 h = 2，与最值一致。

错在哪：不检验就发现不了单位错、相位错，答案看着完整却是错的。
