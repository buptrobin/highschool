这一节是第五章的开头：先把「角」从 0°–360° 的框里放出来，允许任意大小、允许负；再换一把更省事的尺子——弧度制。后面所有三角函数（诱导公式、图象、周期性）都建在这两个约定上：象限决定符号，弧度决定公式长什么样。最容易错的一件事：以为转了一整圈角就不一样了，其实 390° 和 30° 的终边完全重合，它们只差 360° 的整数倍。

01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 任意角与象限角人教A版必修第一册 · 第五章第一节

一条射线绕它的端点旋转，按逆时针方向旋转形成的角叫做正角，按顺时针方向旋转形成的角叫做负角；如果一条射线没有作任何旋转，就称它形成了一个零角。使角的顶点与原点重合，角的始边与 x 轴的非负半轴重合，那么角的终边在第几象限，就说这个角是第几象限角。

→ 翻成人话：判象限角要同时满足三个条件：① 顶点在原点；② 始边与 x 轴非负半轴重合；③ 终边落在某个象限的内部。第 ③ 条的重点是「内部」——终边压在坐标轴上时，这个角哪个象限都不属于，它叫轴线角，轴线角不算象限角。

课本原话 · 终边相同的角人教A版必修第一册 · 第五章第一节

所有与角 α 终边相同的角，连同角 α 在内，可构成一个集合 S = {β | β = α + k·360°，k∈Z}，即任一与角 α 终边相同的角，都可以表示成角 α 与整数个周角的和。

→ 这句话只有两个零件：k∈Z 和 360°。漏了 k∈Z，你只写出了「加一圈」的那一个角；把 360° 写成 180°，你写出的就不是终边相同的角，而是终边关于原点对称的角。判据只有一句：终边相同的角差 360° 的整数倍。

课本原话 · 弧度制人教A版必修第一册 · 第五章第一节

长度等于半径长的圆弧所对的圆心角叫做 1 弧度的角，记作 1 rad；用弧度作单位来度量角的制度叫做弧度制。半径为 r 的圆的圆心角 α 所对弧的长为 l，则 |α| = l / r。由此得到弧长公式 l = |α|·r，扇形面积公式 S = ½ l r。

→ 三个信息：① 1 rad 是「弧长 = 半径」对出来的角，与圆画多大无关；② 它等于比值 l/r，所以弧度数是一个没有单位的实数；③ π rad = 180°，度化弧度乘 π/180。正因为 α 是纯数，弧长公式里的角必须用弧度，代 60° 进去就全错。

条件（缺一不可）缺了会怎样
顶点在原点，始边与 x 轴非负半轴重合同一根终边会被读成不同的角，象限判断失去统一口径
终边落在象限的内部0°、90°、180°、270° 这些压轴的角没有象限，轴线角不算象限角
β = α + k·360°，k∈Z少写 k∈Z 只得到「加一圈」一个角；写成 180° 则差 180°，终边根本不同
弧长公式 l = |α|·r 中 α 用弧度把 60 当度数代进去，弧长会放大到 57 倍多，整题作废
度化弧度乘 π/180，弧度化度乘 180/π方向乘反或漏乘 π，答案差一个 π 的因子

背法：看终边 → 先减整圈 → 再看落在哪。减整圈就是把角写成 α + k·360°，减到 0°–360° 之间再看；落在象限里才有象限号，压在坐标轴上就写「轴线角」。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 负角化弧度并写终边相同的角必考

（1）把 −120° 化为弧度；（2）判断 −120° 是第几象限角；（3）写出与 −120° 终边相同的角的集合。陷阱：负角的「顺时针」方向和集合里 k∈Z 的写法。

  1. 第 1 步 · 审题定性

    负号只说明旋转方向是顺时针，不改变它可以化成弧度、也可以有象限这一事实；先老老实实做度化弧度，再判终边，最后写集合。

    用到：正角、负角、零角的规定；度化弧度 × π/180。

  2. 第 2 步 · 度化弧度

    −120° = −120 × π/180 = −2π/3。分子分母同除 60，别急着写 −120π/180 当答案。

    用到：1° = π/180 rad，结果保留 π。

  3. 第 3 步 · 判象限（先减整圈）

    −120° 终边与 −120° + 360° = 240° 相同；240° 落在 180° 与 270° 之间，在第三象限内部，且 240° 不是 90° 的整数倍，不是轴线角，所以 −120° 是第三象限角。

    用到：判象限先把它写成 α + k·360°（0° ≤ α < 360°）的形式。

  4. 第 4 步 · 写终边相同的角的集合

    在弧度制下，「一圈」是 2π，所以集合写成 {β | β = −2π/3 + 2kπ，k∈Z}。如果要写角度制版本，就是 {β | β = −120° + k·360°，k∈Z}；两种写法不能混用单位。

    用到：S = {β | β = α + k·360°，k∈Z}，弧度制下把 360° 换成 2π。

  5. 第 5 步 · 回代验算

    取 k = 1：−2π/3 + 2π = 4π/3（即 240°），与 −120° 终边相同，正确。再取 k = 0 得 −2π/3 本身，说明 α 也在集合里。

    用到：终边相同的角差 2π 的整数倍（角度制下差 360° 的整数倍）。

1 / 5

标准答案（可抄进答题卡）

（1）−120° = −120 × π/180 = −2π/3。
（2）因为 −120° + 360° = 240°，240° 在 180° 与 270° 之间，所以 −120° 是第三象限角（不是轴线角）。
（3）与它终边相同的角的集合为 {β | β = −2π/3 + 2kπ，k∈Z}；写成角度制为 {β | β = −120° + k·360°，k∈Z}。
得分点：π/180 的换算方向、k∈Z 必须写、2π 与 360° 不能混用。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「两个角终边相同，它们的差到底是多少？」

差是 360° 的整数倍（弧度制下是 2π 的整数倍），不是 180°，也不是「差不多一整圈」。差 180° 的两根终边是反向延长线，永远不重合。

「90°、180° 的终边那么特殊，算第几象限角？」

都不算。轴线角不算象限角——终边落在 x 轴或 y 轴上时，这个角不属于任何象限。所有轴线角可以统一写成 β = k·90°（k∈Z），答题时就写「轴线角（不在任何象限）」。

「1 rad 到底是多少度？能直接说 1 rad = 1° 吗？」

不能。π rad = 180°，所以 1 rad = 180/π ≈ 57.30°。rad 是个提醒你「这是弧度数」的记号，弧度数本身没有单位。

「弧长公式 l = |α|r，α 可以填 60° 吗？」

不行，弧长公式里的角必须用弧度。60° 要先化成 π/3 再代。填 60 进去，等于把角放大成 60 rad，结果错 57 倍多。

「−120° 是负角，那它还有象限吗？」

有。负角只是顺时针转出来的角，照样能判终边：−120° + 360° = 240°，终边落在第三象限内部，所以是第三象限角；它也不是轴线角（240 不是 90 的整数倍）。

「S = ½lr 和 S = ½|α|r²，考试写哪个？」

两个都对，是同一个式子：把 l = |α|r 代进 S = ½lr 就得到 S = ½|α|r²。已知弧长用第一个，已知圆心角用第二个；两者都要求 α 用弧度。

六问其实是同一件事的三个零件：判终边先减整圈（差 360° 的整数倍）、压轴的角没有象限号（轴线角不算象限角）、公式里只认弧度（弧长公式里的角必须用弧度）。把这三句钉住，本节 90% 的坑都填平了。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 与 30° 终边相同的角是 210°，它们差 180°。

✓ 与 30° 终边相同的角是 30° + k·360°（k∈Z）；差 180° 的 210° 终边与它反向，不重合。

错在哪：把「差 180°」当成了终边相同。终边相同的角差 360° 的整数倍，180° 不是 360° 的整数倍。

✗ 90° 的终边在 y 轴正半轴上，所以它是第一（或第二）象限角。

✓ 90° 的终边落在 y 轴上，是轴线角，不属于任何象限。

错在哪：轴线角不算象限角。终边必须落在象限的内部才有象限号，压在轴上就没有。

✗ 半径 r = 2、圆心角 60°，所以弧长 l = |60| × 2 = 120。

✓ 先把 60° 化为 π/3，再算 l = |α|·r = (π/3) × 2 = 2π/3。

错在哪：弧长公式里的角必须用弧度，代进去的是弧度的数值，不是度数。

✗ 120° = 120π rad。

✓ 120° = 120 × π/180 = 2π/3。

错在哪：度化弧度要乘 π/180，不是乘 π。乘 π 等于把 1° 当成 1 rad。

✗ 与 α 终边相同的角的集合是 {β | β = α + k·360°}。

✓ {β | β = α + k·360°，k∈Z}，弧度制下写作 {β | β = α + 2kπ，k∈Z}。

错在哪：漏写 k∈Z，集合里只剩「加一圈」的那一个角，也说不清 k 是什么数。

✗ 负角是「倒着转」的，不能算角，也不能化成弧度。

✓ 按顺时针方向旋转形成的角叫负角，它同样是角，同样能化弧度、判象限。

错在哪：任意角包括正角、负角和零角；负号只表示旋转方向，不影响后续所有运算。

✗ 1 rad = 1°，π rad = 3.14 rad。

✓ 1 rad ≈ 57.30°，π rad = 180°；π 是 3.14159…，不是 3.14 rad。

错在哪：把弧度的记号 rad 当成了度。rad 只提示「这是弧度数」，弧度数本身是纯数。
