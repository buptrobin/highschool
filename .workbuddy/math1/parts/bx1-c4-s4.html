01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 对数函数的概念人教A版必修第一册 · 第四章 4.4

一般地，函数 y=log_a x（a>0，且 a≠1）叫做对数函数，它的定义域是 (0,+∞)。

→ 翻成人话：这句话由三个条件组成：① 底数 a>0；② 底数 a≠1；③ 真数 x 只能是正数。①②是对底数的限制，缺了 log 这个记号本身就没意义；③是定义域——写成 R 就整题扣光，因为负数与 0 没有对数。

课本原话 · 图象的公共点人教A版必修第一册 · 第四章 4.4

对数函数的图象都经过点 (1,0)。

→ 因为 log_a 1 = 0 对任何合法底数都成立。看到对数函数的图象题，先找 (1,0) 这个锚点：曲线与 x 轴有且只有这一个交点，所以「图象与 x 轴交于 (0,1)」一定是错的。

课本原话 · 单调性人教A版必修第一册 · 第四章 4.4

当 a>1 时，y=log_a x 在 (0,+∞) 上单调递增；当 0<a<1 时，在 (0,+∞) 上单调递减。

→ 单调性只由底数 a 决定，与真数长什么样无关：a 比 1 大就朝上走，a 比 1 小就朝下走。比较两个对数值大小时，先看底数，再决定不等号要不要翻。

条件数学写法缺了会怎样
底数为正a>0负数的幂不能取遍正数，log 无定义
底数不为 1a≠1a=1 时 1 的任何次幂都是 1，真数≠1 时无解
真数为正x>0负数和 0 没有对数，曲线在那一侧根本不存在
定义域x∈(0,+∞)写成 R、[0,+∞) 都是错的；复合函数里最容易丢

三句话背下本节：底大过一、真数为正、图象过 (1,0)。选择题里 80% 的判断都落在这三句上。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 求对数型复合函数的定义域必考

求函数 y = log₂(3 − x) 的定义域。
（陷阱：真数是 3−x 整个式子，不是 x。写 x>0 的同学，把「外层看整体」这一步丢了。）

  1. 第 1 步 · 审题，定结构

    函数是 y=log₂ u 与 u=3−x 复合而成：外层是对数函数，内层是一次函数。

    用到：对数函数 y=log_a x 的定义域是 (0,+∞)，所以只要求真数 u>0。

  2. 第 2 步 · 列不等式

    外层要求真数为正，把 u=3−x 整个代进去：3 − x > 0。

    用到：真数位置上的整体为正，不是 x 为正。

  3. 第 3 步 · 解不等式

    3 − x > 0 ⇔ −x > −3 ⇔ x < 3。两边同乘 −1，不等号方向要翻。

    用到：一元一次不等式的解法；符号翻转。

  4. 第 4 步 · 写成定义域

    定义域是使式子有意义的 x 的全体，写成区间 (−∞, 3)。x=3 时真数为 0，对数无意义，所以 3 不取，用开区间。

    用到：定义域是集合，最终必须用区间或集合表示。

  5. 第 5 步 · 代值验算

    取 x=2：log₂(3−2)=log₂1=0，有意义；取 x=4：log₂(−1) 无意义，确实不在定义域内。若误写成 x>0，x=4 这个反例就通不过。

    用到：取端点两侧的特殊值检验，是检查定义域最快的办法。

1 / 5

标准答案（可抄进答题卡）

解：由对数函数的真数必须大于 0，得
3 − x > 0，
解得 x < 3。
所以函数 y = log₂(3 − x) 的定义域是 (−∞, 3)。
（注意：真数是 3−x 整体，不是 x；端点 x=3 使真数为 0，故不取。）

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「对数函数的定义域凭什么不是 R？」

因为真数必须大于 0：a 的任意次幂都是正数，所以 log_a x 里的 x 只能取正数，定义域 (0,+∞)，与底数 a 取什么无关。

「图象一定过哪个点？」

必过 (1,0)：因为 log_a 1 = 0 对任何 a>0、a≠1 都成立。曲线与 x 轴只有这一个交点，(0,1) 是指数函数的点。

「对数和指数到底是什么关系？」

互为反函数：y=aˣ 与 y=log_a x 的图象关于直线 y=x 对称。点 (0,1) 与 (1,0) 就是一对对称点，不是同一条曲线。

「y=log₂(3−x) 这种怎么求定义域？」

三步：真数整体>0 → 内层自身限制 → 取交集。这里 3−x>0 得 x<3，内层无额外限制，定义域 (−∞,3)。

「两个对数值怎么比大小？」

先看底数：a>1 时真数越大值越大；0<a<1 时真数越大值越小。底数不同则先化成同底，或插 0、1 当中间量。

「log_a x 能等于 0 吗？」

能，当且仅当 x=1 时 log_a x=0。所以 0 在对数函数的值域里，图象必与 x 轴交于 (1,0)；但真数 x 永远取不到 0。

六问其实是同一件事：真数为正、过 (1,0)、单调性看底数。定义域、比大小、复合函数，全是这三条的组合。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ y=log_a x 的定义域是 R。

✓ 对数函数的定义域是 (0,+∞)，因为真数必须大于 0。

错在哪：把对数函数当成了整式函数。负数与 0 没有对数，x≤0 的部分在图上根本不存在。

✗ 对数函数的图象过点 (0,1)。

✓ 对数函数的图象都过点 (1,0)。

错在哪：把指数函数的 (0,1) 记串了。log_a 1=0，是横坐标为 1、纵坐标为 0。

✗ 对数函数与指数函数的图象重合。

✓ 二者互为反函数，图象关于直线 y=x 对称。

错在哪：把「互逆」当成「相同」。对称是翻折，不是重叠。

✗ 求 y=log₂(3−x) 的定义域，只要求 x>0。

✓ 要求真数整体大于 0，即 3−x>0，得 x<3，定义域 (−∞,3)。

错在哪：只盯住了 x，没盯住真数 3−x 这个整体。这是复合函数定义域的第一大坑。

✗ 0<a<1 时，y=log_a x 在 (0,+∞) 上递增。

✓ 0<a<1 时在 (0,+∞) 上单调递减；a>1 时单调递增。

错在哪：单调性只看底数与 1 的大小，a 小于 1 就是递减。

✗ 定义域写成 [0,+∞) 或 [3,+∞) 这类闭区间。

✓ 端点使真数为 0 时必须开：定义域用 (−∞,3)、(0,+∞) 这样的开区间。

错在哪：端点代回去真数等于 0，对数无意义，所以端点一律不取。

✗ y=log_a x 里 a=1 也行，反正 1 是正数。

✓ 底数必须 a>0 且 a≠1；a=1 时对数值不唯一。

错在哪：漏了 a≠1。1 的任何次幂都是 1，真数不等于 1 时根本无解。
