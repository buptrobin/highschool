「集合」是整个高中数学的第一块地基：后面函数的定义域、值域、不等式的解集，全部要用集合的语言来写。这一节概念少，但判分极狠——一道 5 分的填空，错在「互异性」上就是 0 分，而且每年都有人错在同一处：把 {1,1,2} 当成 3 个元素。下面按「课本原话 → 拆四张图 → 自己拖一眼 → 完整走一道题 → 六问 → 易错句」的顺序走一遍。

01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 元素与集合人教A版必修第一册 · 第一章第一节

一般地，我们把研究对象统称为元素，把一些元素组成的总体叫做集合。

→ 翻成人话：这句话由三个条件组成。① 元素是「研究对象」，可以是数、点、式子，不限于数；② 集合是「总体」，是一个整体，不是散着摆的几样东西；③ 只有确定的对象才能凑成总体，说不清在不在的，一律不成集合。后面讲的三性，就是从这个定义里长出来的。

课本原话 · 元素与集合的关系人教A版必修第一册 · 第一章第一节

如果 a 是集合 A 的元素，就说 a 属于 A，记作 a∈A；否则记作 a∉A。

→ 翻成人话：两个条件。① 只有 ∈ 与 ∉ 两种关系，非此即彼，没有第三种写法；② 符号的左边必须是一个元素，右边必须是一个集合，位置写反或两边都写集合（如 A∈B）都是错的。

课本原话 · 三性人教A版必修第一册 · 第一章第一节

集合中的元素具有确定性、互异性、无序性。

→ 翻成人话：三个条件缺一不可。不确定 → 根本不是集合；重复 → 同一个元素只算一次，写两遍等于写一遍；顺序换 → 还是同一个集合。考试真正扣分的是第二条。

条件课本要求缺了它，你会怎么错
确定性任给一个对象，能判断它在不在这个集合里「高个子同学」「接近 1 的数」都被当成集合，其实不成立
互异性同一个元素在集合里只算一次把 {1,1,2} 数成 3 个元素；求参数时算出两个 a 却都不检验
无序性元素写的前后顺序不影响集合把 {1,2} 与 {2,1} 当成两个不同集合，个数、判断全错
元素类型不限数、点、式子、字母都能当元素看到 {(1,2)} 以为是两个数，其实是一个点
空集也算集合∅ 是不含任何元素的集合把 ∅ 与 {0} 混为一谈，认为它们元素个数都是 1

整张表只高亮一行：互异性。这一节所有「求参数 a」的题，最后一步几乎都是回代检验互异性——写出 a 的值只是拿一半分。另一处高频混淆是 ∅ ≠ {0}：∅ 里一个元素都没有，{0} 里有一个元素 0，两者元素个数分别是 0 和 1。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 由元素与集合的关系求参数必考

已知集合 A = {a+2, (a+1)², a²+3a+3}，若 1∈A，求 a 的值。
陷阱：三个元素分别等于 1 会算出好几个 a，其中有两个会让集合出现重复元素，必须回代检验、舍去。

  1. 第 1 步 · 把「1∈A」翻译成方程

    1∈A 表示 1 是 A 的元素，而 A 里只有 a+2、(a+1)²、a²+3a+3 这三个「位置」，所以 1 必须等于其中之一，至少有一种情况成立。于是分三种情况列方程，逐个解。

    用到：元素与集合的关系 a∈A，以及集合由它的元素唯一确定。

  2. 第 2 步 · 情况一：a+2=1

    解得 a=−1。回代：a+2=1，(a+1)²=0，a²+3a+3=1−3+3=1，此时 A={1,0,1} 中 1 出现两次，与互异性矛盾，故 a=−1 舍去。

    用到：互异性——同一元素只能出现一次。

  3. 第 3 步 · 情况二：(a+1)²=1

    解得 a=0 或 a=−2。分别回代：a=0 时 A={2,1,3}，三个元素互不相同，成立；a=−2 时 A={0,1,1}，1 重复，舍去。

    用到：解得多个值时，必须逐个回代检验互异性。

  4. 第 4 步 · 情况三：a²+3a+3=1

    即 a²+3a+2=0，解得 a=−1 或 a=−2。这两个值在第 2、3 步已被淘汰，不产生新的答案。

    用到：分类要「不重不漏」，重复的答案并到一起。

  5. 第 5 步 · 收口：写出答案并点明检验

    三种情况合起来只有 a=0 通过检验，且此时 A={2,1,3}，确实含 1。答案唯一：a=0。答题卡上要写出「回代检验互异性」这一步，缺了它通常只给一半分。

    用到：检验是结论的一部分，不是草稿。

1 / 5

标准答案（可抄进答题卡）

因为 1∈A，所以 1 等于 A 中三个元素之一。
① 若 a+2=1，则 a=−1，此时 A={1,0,1}，元素 1 重复，不满足互异性，舍去；
② 若 (a+1)²=1，则 a=0 或 a=−2。a=0 时 A={2,1,3}，满足互异性；a=−2 时 A={0,1,1}，元素 1 重复，舍去；
③ 若 a²+3a+3=1，则 a=−1 或 a=−2，均已舍去。
综上，a=0。
检验：a=0 时 A={2,1,3}，三个元素互不相同且 1∈A

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

集合里的元素能不能重复？写两遍算两个吗？

不能，写两遍也只算一个。集合中的元素具有互异性，所以 {1,1,2} 与 {1,2} 是同一个集合，元素个数都是 2。凡是题目让你数元素个数，先合并相同的再数。

∅ 与 {0} 不是都能写成空集吗？它们一样吧？

不一样。∅ 与 {0} 不是一回事：∅ 不含任何元素，元素个数是 0；{0} 含一个元素 0，元素个数是 1。所以 0∈{0}，而 0∉∅。

{1,2} 和 {2,1} 是两个不同的集合吧？顺序都变了。

是同一个集合。集合无序，元素写的前后顺序只影响外观，不影响是哪一个集合，所以 {1,2}={2,1}。同理 (1,2) 与 (2,1) 是两个不同的点，但那是点，不是集合无序的问题。

0∈N 到底对不对？N 里含不含 0？

对，0∈N。N 是自然数集 {0,1,2,3,…}，含 0；N* 是正整数集 {1,2,3,…}，不含 0，所以 0∉N*。记法就一条：看到 N 与 N*，只想一件事——含不含 0。

描述法那个竖线前面到底写什么？写成逗号行不行？

竖线前写代表元素（如 x 或 (x,y)），竖线后写它满足的条件，两部分缺一不可。竖线是结构，不能换成逗号：{x | x>1 且 x∈R} 是「大于 1 的实数」，而 {x, x>1} 是「x 与式子 x>1 两个元素」，意思完全不同。

「我们班的高个子同学」能构成一个集合吗？

不能。缺确定性：多高算高没有标准，任给一个同学，无法判断他在不在里面，所以它不构成集合。改成「身高超过 180 cm 的同学」就确定，能构成集合。

六问其实是同一件事：先问这个对象确定不确定，再问同一个元素算几次，最后问顺序有没有影响。三性过完，符号只是把答案写出来而已。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 集合中的元素可以重复，{1,1,2} 有 3 个元素

✓ 集合中的元素具有互异性，同一元素只算一次；{1,1,2}={1,2}，元素个数是 2

错在哪：把「写了几个数」当成了「有几个元素」。求参数 a 的题里，凡是算出的 a 让两个元素相等，一律舍去。

✗ ∅={0}，都表示「没有」

✓ ∅ 是不含任何元素的集合，{0} 是含元素 0 的集合，∅≠{0}

错在哪：∅ 的元素个数是 0，{0} 的元素个数是 1；0∉∅，但 0∈{0}。空集是集合，不是「什么都没有」。

✗ {1,2} 与 {2,1} 是两个不同的集合

✓ 集合无序，{1,2}={2,1}

错在哪：把书写顺序当成了集合本身。写答案时按从小到大排只是为了好看，不是规定。

✗ 0∉N，N 是正整数集

✓ 0∈N；N 是自然数集，N*（或 N₊）才是正整数集，0∉N*

错在哪：记混了 N 与 N*。判断时只问一句「这个符号含不含 0」。

✗ 用描述法写成 {x, x>1}，用逗号隔开

✓ {x | x>1 且 x∈R}，竖线前写代表元素，竖线后写条件

错在哪：逗号在集合里表示「这些都是元素」，写成逗号就成了「元素 x 与元素 x>1」，集合的意思完全变了。

✗ 「高个子同学」能构成集合，因为人是一个整体

✓ 不满足确定性，不能构成集合；改为「身高超过 180 cm 的同学」才可以

错在哪：集合的边界必须清楚到「任给一个对象都能判断在不在」，靠感觉划分的不算集合。

✗ 1⊆{1,2}，1 在集合里

✓ 1∈{1,2}；⊆ 只连两个集合，如 {1}⊆{1,2}

错在哪：∈ 连「元素与集合」，⊆ 连「集合与集合」。左边是数就用 ∈，左边带大括号才能用 ⊆。
