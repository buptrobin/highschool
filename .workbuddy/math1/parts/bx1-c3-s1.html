3.1 是整册函数的地基：初中把函数当成「一个式子」，这一节把它升级成「两个实数集之间的对应关系」，后面 3.2 单调性、3.3 奇偶性、3.4 幂函数全建在这句话上。最容易错的一件事：拿到题目先算 f(某数)，而忘了先问「这个 x 在不在定义域里」——定义域优先不是口号，是第一步。

01课本怎么说

先背标准表述，再拆关键词。答题卡上写左边这句，不写右边的人话。

课本原话 · 函数的定义人教A版必修第一册 · 第3章第1节

设 A、B 是非空的实数集，如果对于集合 A 中的任意一个数 x，按照某种确定的对应关系 f，在集合 B 中都有唯一确定的数 y 和它对应，那么就称 f：A→B 为从集合 A 到集合 B 的一个函数。

→ 翻成人话：这句话由三个条件组成——① A、B 都是非空实数集；② A 中任意一个 x 都有对应；③ 对应的 y 唯一。少第 ② 条，定义域就缩水；少第 ③ 条，一个 x 对出两个 y，直接不是函数。

课本原话 · 函数的三要素人教A版必修第一册 · 第3章第1节

函数的三要素：定义域、对应关系、值域。其中定义域与对应关系一旦确定，值域也就随之确定。

→ 翻成人话：三要素里只有两个是自由的（定义域、对应关系），值域是算出来的结果。所以「定义域优先」有硬理由：它是自变量那一边唯一能被人为规定的东西，先定它，后面的单调区间、值域才有地方可写。

课本原话 · 分段函数人教A版必修第一册 · 第3章第1节

在定义域的不同部分有不同的对应关系，但它是一个函数。

→ 翻成人话：只讲了一件事——分段函数是一个函数，不是两个、三个。几段只是同一个 f 在不同区间上的不同写法，定义域是各段区间的并集，拿一个 x 代进去，只走其中一段。

定义里的条件课本怎么写缺了它会怎样
条件 ①A、B 是非空实数集A 是空集就没有 x 可对应，写不出函数；B 里有非实数就超出「数集」
条件 ②对 A 中任意一个数 x只对一部分 x 有对应，那部分才叫定义域，剩下的要从 A 里挖掉
条件 ③都有唯一确定的数 y一个 x 配出两个 y，例如 x² + y² = 1 里的 y，就不是函数
真正的区别按确定的对应关系 ff 是「对应关系」，不是「公式」：一张表格、一条曲线都可以是 f

背法：非空实数集 → 任意 → 唯一，三个词按顺序背。考场口决：先看 x 能不能取（定义域优先），再看一个 x 是不是只出一个 y（唯一），这两步就能挡掉 90% 的概念判断题。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 分段函数求复合函数值必考

已知 f(x) = x² (x < 0)；2x (0 ≤ x < 2)；4 − x (x ≥ 2)，求 f(f(−1))。陷阱：−1 和算出来的那个数，各自落在哪一段并不相同。

  1. 第 1 步 · 审题：由内向外

    f(f(−1)) 里有两次求值，先算括号最里面那个 f(−1)，把它算成一个具体的数，再把这个数代回 f。不要试图先化简整个 f。

    用到：复合求值的顺序——内层先算。

  2. 第 2 步 · 定位内层 −1 属于哪一段

    比较 −1 与两个分界点 0、2：因为 −1 < 0，所以 −1 落在第一段，用 x² 这个对应关系，f(−1) = (−1)² = 1。

    用到：分段函数的「先看 x 落在哪一段」——分界点归哪段以等号为准。

  3. 第 3 步 · 再定位外层 1 属于哪一段

    现在要算 f(1)。1 满足 0 ≤ 1 < 2，落在第二段，用 2x，所以 f(1) = 2 × 1 = 2。注意 1 不属于第一段，代 x² 会得到 1，恰好也是 1，但过程是错的——换个数就露馅。

    用到：同一道题里两次定位，每次都要重新比区间。

  4. 第 4 步 · 写结论并回头验一遍

    所以 f(f(−1)) = f(1) = 2。检查一遍：内层结果是 1，1 不在 x ≥ 2 那一支，也不在 x < 0 那一支，用的段没串。

    用到：结论写成一个数，不写「f(f(−1)) = 2x」这种半成品。

  5. 第 5 步 · 补一句定义域

    整题的合法性依赖 f 的定义域是 R：−1 和 1 都在 R 里，两次求值都允许。若题目改成 f(x) = x² (x < 0)；2x (0 ≤ x < 2)，没有第三段，则 f(2) 无意义，答案要写成「不存在」。

    用到：定义域优先——先确认要代的数在定义域内，再动手算。

1 / 5

标准答案（可抄进答题卡）

解：因为 −1 < 0，所以 f(−1) = (−1)² = 1；
又因为 0 ≤ 1 < 2，所以 f(1) = 2 × 1 = 2；
故 f(f(−1)) = f(1) = 2。
答：f(f(−1)) = 2。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「唯一确定」到底什么意思，一个 x 配两个 y 为什么不行？

指 A 中每一个 x 只有一个 y 与它对应，不是「y 只有一个来源」。所以 y = x² 合规（y = 4 时 x = ±2 没关系），而 x² + y² = 1 中 y 不是 x 的函数。判据：过图象上任意一点作平行于 y 轴的直线，与图象最多一个交点。

拿到一个式子，定义域怎么「先」求？

定义域优先：动笔第一件事，扫三类限制——分母 ≠ 0、偶次根号下 ≥ 0、零次幂底数 ≠ 0，各自解出来再取交集。交集为空就说明这个式子写不成函数。写完定义域才允许开始化简、求值域。

分段函数是几个函数？答案能写两个吗？

分段函数是一个函数，只能算一个。定义域是各段区间的并集，对应关系还是同一个 f，只是写法按区间分开。写答案时写「f(x) = …」，别写成「f₁(x)、f₂(x)」。

两个式子长得一样，就是同一函数吗？

不是。判断同一函数要看定义域与对应关系两点，与字母无关。y = x 与 y = x²/x 化简后同为 y = x，但后者定义域是 {x | x ≠ 0}，不是同一函数；而 y = x² 与 s = t² 是同一函数。

分界点 x = 2 到底归哪一段？两个值都写行不行？

只归一段，写两个值就是「一个 x 对两个 y」，直接违背定义。看不等式里的等号：0 ≤ x < 2 没有接住 2，x ≥ 2 接住了，所以 f(2) = 4 − 2 = 2。图象上 (2, 4) 是空心点，(2, 2) 是实心点。

值域怎么求？直接把 B 抄上去行不行？

不行，值域是实际取到的 y 的集合，只是 B 的子集。分段函数要逐段求值域再取并集：x < 0 得 (0, +∞)，0 ≤ x < 2 得 [0, 4)，x ≥ 2 得 (−∞, 2]，并起来是 R。

六问其实是同一件事的两面：定义域优先（先问 x 能不能取、落在哪一段），以及「一个 x 只许一个 y」。把这两条守住，分段函数求和、同一函数判断、值域求解都不会跑偏。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 这个函数分两段，所以是两个函数。

✓ 分段函数是一个函数，它在定义域的不同部分有不同的对应关系。

错在哪：把「写法分几段」当成了「函数有几个」。定义域取各段并集，整体只对应一个 f。

✗ 已知 f(x) 分段，f(f(−1)) 就先算外面的 f。

✓ 由内向外：先算 f(−1) = 1，再算 f(1) = 2。

错在哪：外层要代的数是内层算出来的结果，内层没算完，外层无从下手。

✗ y = x 与 y = x²/x 化简后一样，是同一函数。

✓ 判断同一函数要看定义域与对应关系都相同，后者定义域是 {x | x ≠ 0}。

错在哪：化简会约掉 x，把 x = 0 这个「坑」一起抹掉了，定义域已经变了。

✗ 求定义域太麻烦，先算出结果再说。

✓ 定义域优先：先列分母 ≠ 0、偶次根号下 ≥ 0、零次幂底数 ≠ 0 的限制，取交集。

错在哪：定义域是答案的一部分，也是判据——不写定义域，同一函数判断、单调区间、值域全部失去依据。

✗ f(2) 用第二段算是 4，用第三段算是 2，填 4 或 2 都对。

✓ 分界点只归一段：0 ≤ x < 2 不含 2，x ≥ 2 含 2，故 f(2) = 4 − 2 = 2。

错在哪：写成两个值等于承认一个 x 有两个 y，那就不是函数了。等号在哪一段，点就归哪一段。

✗ 对应关系就是那个公式，公式不同函数就不同。

✓ 对应关系 f 可以是式子、表格或图象；判同一函数比的是定义域与对应关系是否都相同。

错在哪：把 f 窄化成「解析式」。y = |x| 与 y = √(x²) 式子不同，却是同一函数。

✗ 值域就是 B，把 B 抄上就行。

✓ 值域是 {f(x) | x∈A}，是 B 的子集，要逐段算完再取并集。

错在哪：B 只要求「y 落在里面」，没要求「每个 y 都被取到」，两者不是一回事。
