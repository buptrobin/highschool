01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 指数函数的定义人教A版必修第一册 · 第4章第2节

一般地，函数 y=a^x（a>0，且 a≠1）叫做指数函数，其中 x 是自变量，定义域是 R。

→ 翻成人话：这句话由三个条件组成——① 底数 a>0；② 底数 a≠1；③ 自变量 x 在指数上。三条缺一条就不是指数函数：a=1 时 y=1^x=1 是一条水平线，画得出来，但不叫指数函数；a=−2 时 x=1/2 就成了负数开偶次方，定义域直接断掉。

课本原话 · 图象过的定点人教A版必修第一册 · 第4章第2节

指数函数的图象都过点 (0,1)。

→ 翻成人话：「都」是指不管 a 取 3 还是取 0.4，把 x=0 代进去，a^0=1 恒成立，所以定点坐标是 (0,1)。写成 (1,0) 是把横纵读数对调了：x=1 时 y=a，那条曲线上是 (1,a)，不是 (1,0)。

课本原话 · 单调性人教A版必修第一册 · 第4章第2节

当 a>1 时，指数函数 y=a^x 在 R 上是增函数；当 0

→ 翻成人话：增减由底数 a 与 1 的大小关系决定，与 x 取什么值无关。a>1 时底数越大图象越陡；0

定义里的条件满足时得到什么缺了会怎样（考卷上的样子）
底数 a>0对任意实数 x，a^x 都有意义a<0 时 x=1/2 无意义，定义域断成两截，谈不上「在 R 上」
底数 a≠1单调性才分成 a>1 递增、0a=1 时 y=1 是常函数，没有单调性，定义直接把它排除在外
自变量 x 在指数上这才是「指数」函数x 跑到指数位置上以外的地方（如 y=x^2）就是幂函数，名字和性质全换
定义域是 R比较大小、解不等式才有共同范围答题只写「递增」不写范围，过程分被扣一半

背法一句话：先看底数，再看位置。底数决定图象的形状（增还是减、陡还是缓），指数位置决定它姓「指数」还是姓「幂」。整张表只高亮了 a≠1 这一行——它是三条条件里最容易被跳过的那一条。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 用单调性比较大小必考

（1）比较 1.7^(2.5) 与 1.7^3 的大小。
（2）已知 0.8^m>0.8^n，比较 m 与 n 的大小。
陷阱：两个小问的底数一个大于 1、一个小于 1，不等号的方向正好相反。

  1. 第 1 步 · 审题：底数相同，比指数

    两边的底数都是 1.7，只有指数不同（2.5 与 3）。这类题不算近似值，直接把它看成同一个函数 y=1.7^x 在两点处的函数值。

    用到：同底数幂比较 → 转化为函数值比较。

  2. 第 2 步 · 定底数与 1 的关系

    1.7>1。由课本结论，a>1 时 y=a^x 在 R 上是增函数。所以函数值的大小顺序与自变量的大小顺序一致。

    用到：a>1 与 0

  3. 第 3 步 · 比指数，写结论

    因为 2.5<3，且 y=1.7^x 递增，所以 1.7^(2.5)<1.7^3。写答案时要把「递增」这三个字写出来，否则只有结果没有过程分。

    用到：增函数 f(x₁)

  4. 第 4 步 · 第（2）问：换成 0

    底数 0.8 满足 0<0.8<1，所以 y=0.8^x 在 R 上递减。减函数里函数值大的反而自变量小：由 0.8^m>0.8^n 得 m

    用到：减函数 f(x₁)>f(x₂) ⇔ x₁

  5. 第 5 步 · 回扣：为什么不能直接「看指数」

    第（1）问指数大的函数值大，第（2）问指数大的函数值小，差别全在底数。所以做这类题的固定顺序是：先读底数、判定与 1 的大小、再决定不等号方向。底数 a=1 的情况根本不用讨论，因为它不在指数函数的定义里。

    用到：底数 a>0 且 a≠1 是前提，a=1 不是指数函数。

1 / 5

标准答案（可抄进答题卡）

（1）∵ 1.7>1，∴ y=1.7^x 在 R 上是增函数。又 2.5<3，∴ 1.7^(2.5)<1.7^3。
（2）∵ 0<0.8<1，∴ y=0.8^x 在 R 上是减函数。又 0.8^m>0.8^n，∴ m<n。
【注意】两问结论方向相反，原因是底数与 1 的大小关系相反；写「递增 / 递减」时必须带上「在 R 上」。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「指数函数的底数到底有什么限制？」

两个：a>0 且 a≠1。a≤0 时 x 取某些值会让 a^x 无意义（如 a=−2、x=1/2）；a=1 时 y=1 是常函数，没有单调性。定义域是 R，这一条也要一起写。

「图象一定过哪个点？是 (1,0) 吗？」

是 (0,1)，不是 (1,0)。因为 x=0 时 a^0=1 与 a 无关；而 x=1 时 y=a，得到的是 (1,a)。写成 (1,0) 是把横纵读数对调了。

「a=1 为什么不算指数函数？」

a=1 时 y=1^x=1，图象是一条水平线，值域只有一个数 {1}，没有单调性，也就失去了指数函数「a>1 递增 / 0<a<1 递减」的全部性质。所以定义用 a>0 且 a≠1 把它排除。

「底数互为倒数时，两条曲线什么关系？」

关于 y 轴对称。因为 a^(−x)=(1/a)^x，点 (x,y) 在 y=a^x 上，点 (−x,y) 就在 y=(1/a)^x 上。两条曲线同样都过 (0,1)，但一个增、一个减。

「指数函数和幂函数怎么区分？」

看自变量 x 站在哪：x 在指数上是指数函数 y=a^x（底数 a>0 且 a≠1）；x 在底数上是幂函数 y=x^a（指数是常数）。y=x^2 是幂函数，y=2^x 才是指数函数。

「比较大小有几种方法？」

常用三条：同底数用单调性（先看底数与 1 比）；同指数看成幂函数或用图象高低；底数指数都不同时插入中间量 1 或 0 搭桥。任何一条都先读底数，别急着算。

这六问其实是同一件事：先确认它是不是指数函数，再看底数落在 1 的哪一边。定义里的 a>0 且 a≠1 决定「有没有资格」，定点 (0,1) 决定「图象钉在哪」，底数与 1 的大小决定「增还是减」。三步走完，比较大小、判单调、辨函数名都不会再错。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ a=1 也是指数函数，只是图象平一点。

✓ 指数函数 y=a^x 中 a>0 且 a≠1；a=1 时 y=1 是常函数，不是指数函数。

错在哪：把「能画出图象」当成「符合定义」。定义里 a≠1 就是专门排除这一格的。

✗ 指数函数的图象都过点 (1,0)。

✓ 指数函数的图象都过点 (0,1)。

错在哪：a^0=1 说的是 x=0、y=1；(1,0) 把两个读数写反了，那是 x 轴上的点，曲线碰不到。

✗ 底数小于 1 的时候，函数还是递增的。

✓ 当 0<a<1 时，y=a^x 在 R 上是减函数。

错在哪：漏了「底数与 1 比大小」这一步。a>1 递增与 0<a<1 递减方向相反，不能套同一个结论。

✗ y=x^2 也是指数函数，因为指数是 2。

✓ y=x^2 是幂函数；指数函数要求自变量 x 在指数上，形如 y=a^x。

错在哪：只看「有没有指数」，没看自变量站在哪。位置决定名字，名字决定性质。

✗ 比较 1.7^(2.5) 与 1.7^3，直接看指数，指数大的就大。

✓ 先看底数：1.7>1，函数递增，再由 2.5<3 得 1.7^(2.5)<1.7^3。

错在哪：结论碰巧对了，过程全错。底数换成 0.7 时同一句话就得出相反答案。

✗ 0.5^3 比 0.5^2 大，因为 3 比 2 大。

✓ 0<0.5<1，y=0.5^x 递减，由 2<3 得 0.5^2>0.5^3。

错在哪：把增函数的直觉搬到减函数上。底数在 (0,1) 内时，指数越大函数值越小。

✗ y=2×3^x 是指数函数，底数是 3。

✓ 指数函数必须是 y=a^x 的形式，系数为 1；y=2×3^x 只是形如它的函数。

错在哪：忽略了「形如」两个字。多一个系数就不再符合 y=a^x 的定义，单调性可以借，名字不能借。
