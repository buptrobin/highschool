## bx1-c1-s1 集合的概念

**课本原话**
1. 一般地，我们把研究对象统称为元素，把一些元素组成的总体叫做集合。
2. 集合中的元素具有确定性、互异性、无序性。
3. 如果 a 是集合 A 的元素，就说 a 属于 A，记作 a∈A；否则记作 a∉A。

**三个扣分点**：互异性（同一个元素只算一次，"1,1,2"与"1,2"是同一个集合）；空集 ∅ 与 {0} 不是一回事；集合中的元素类型可以完全不同（数、点、式子）。

**四张图**：① 三性各一句（确定性/互异性/无序性）；② 元素与集合的符号表（∈ ∉，N N* Z Q R 各指什么）；③ 列举法与描述法对照；④ 互异性：{a,1,2} 里 a 取 1 或 2 时集合只剩 2 个元素。

**互动模型**：滑块＝集合 S={a,1,2} 里的参数 a（0–4，step 1）
```js
size = (a === 1 || a === 2) ? 2 : 3;      // 互异性：重复的元素只算一次
dup  = (a === 1 || a === 2) ? 1 : 0;
```
`cases`：`{v:0,eq:{size:3}}`、`{v:1,eq:{size:2}}`、`{v:2,eq:{size:2}}`、`{v:4,eq:{size:3}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:1},{t:6.5,v:1},{t:9,v:2},{t:11.5,v:4},{t:13.5,v:0}]`，keys `[0,1,2,4]`——停留帧在 a=1（元素从 3 个掉成 2 个，"同一个数只算一次"）。
状态：a=1 或 2「有重复元素，集合只有 2 个元素」；其他「3 个元素」。

**例题**：「已知集合 A={a+2, (a+1)², a²+3a+3}，若 1∈A，求 a 的值。」答案：分三种情况（三个元素分别等于 1）解出 a，再**回代检验互异性**，重复的舍去；重点在第 3 步的检验。
**六问**：① 集合的元素能不能重复；② ∅ 与 {0} 一样吗；③ {1,2} 与 {2,1} 是同一个集合吗；④ 0∈N 吗；⑤ 描述法的竖线前面写什么；⑥ 「高个子同学」能构成集合吗。
**易错**：✗ 元素可以重复 / ✗ ∅={0} / ✗ 集合中的顺序不同就是不同集合 / ✗ 0∉N / ✗ 描述法写 {x | x>1, x∈R} 的逗号写成竖线 / ✗ 高个子能构成集合（缺确定性）。

## bx1-c1-s2 集合间的基本关系

**课本原话**
1. 如果集合 A 的任何一个元素都是集合 B 的元素，就说 A 是 B 的子集，记作 A⊆B。
2. 如果 A⊆B，且存在元素 x∈B 而 x∉A，就说 A 是 B 的真子集，记作 A⫋B。
3. 不含任何元素的集合叫做空集，记作 ∅，规定 ∅ 是任何集合的子集。

**三个扣分点**：空集是任何集合的子集（漏掉"空集这一支"是最常见失分）；n 元集合的子集有 2ⁿ 个；A⊆B 与 A⫋B 的区别（相等时只是子集不是真子集）。

**四张图**：① 子集与真子集的 Venn 对照；② 空集的三条规定；③ n 元集合子集个数 2ⁿ 的来历（每个元素"取或不取"）；④ 数轴上区间的包含关系。

**互动模型**：滑块＝集合元素个数 n（0–8，step 1）
```js
sub  = 2 ** n;          // 子集个数
proper = sub - 1;       // 真子集（去掉自身）
nonEmptyProper = sub - 2;  // 非空真子集（再去掉 ∅）
```
`cases`：`{v:0,eq:{sub:1,proper:0}}`、`{v:3,eq:{sub:8,proper:7}}`、`{v:8,eq:{sub:256,proper:255}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:3},{t:6.5,v:3},{t:9,v:5},{t:11.5,v:8},{t:13.5,v:0}]`，keys `[0,3,5,8]`——停留帧在 n=3（8 个子集，正好能一个个列出来）。
状态：n=0「只有 ∅ 一个子集，没有真子集」；n≥1「子集 2ⁿ 个，真子集少 1 个」。

**例题**：「已知 A={1,2}，B={x | x⊆A}，求 B 的元素个数。」答案：B 的元素是 A 的所有子集：∅、{1}、{2}、{1,2}，共 4 个；**注意 B 的元素本身是集合**。
**六问**：① ∅ 是任何集合的子集吗；② ∅ 是任何集合的真子集吗；③ {1,2} 的子集有几个；④ A⊆B 且 B⊆A 说明什么；⑤ 0 与 ∅ 的关系；⑥ B={x|x⊆A} 这种"集合的集合"怎么数。
**易错**：✗ 空集不是任何集合的真子集（错在"真"）/ ✗ 子集个数是 n / ✗ A⊆B 就意味着 A 比 B 小 / ✗ {∅} 就是 ∅ / ✗ 2 元集合有 3 个子集 / ✗ 忘记"集合本身"也是子集。

## bx1-c1-s3 集合的基本运算

**课本原话**
1. 由属于 A 且属于 B 的所有元素组成的集合，叫做 A 与 B 的交集，记作 A∩B。
2. 由属于 A 或属于 B 的所有元素组成的集合，叫做 A 与 B 的并集，记作 A∪B。
3. 若 A⊆U，由 U 中不属于 A 的所有元素组成的集合，叫做 A 在 U 中的补集，记作 ∁ᵤA。

**三个扣分点**：并集里重复元素只写一次（互异性）；"或"包含"且"（A∩B 的元素也在 A∪B 里）；补集必须先有全集 U。

**四张图**：① 交集/并集/补集的 Venn 三连；② 数轴上的区间运算（交、并、补各一例）；③ 容斥公式 |A∪B|=|A|+|B|−|A∩B| 的来历；④ 含参数的集合运算（端点取舍）。

**互动模型**：滑块＝A∩B 的元素个数 k（0–6），|A|=|B|=6，全集 U 有 10 个元素
```js
union = 12 - k;      // 容斥：|A|+|B|−k
onlyA = 6 - k;
comp  = 10 - 6;      // ∁ᵤA 的个数，恒为 4
```
`cases`：`{v:0,eq:{union:12}}`、`{v:3,eq:{union:9,onlyA:3}}`、`{v:6,eq:{union:6,onlyA:0}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:3},{t:6.5,v:3},{t:9,v:6},{t:11.5,v:6},{t:13.5,v:0}]`，keys `[0,3,6]`——停留帧在 k=3（两个 6 元集合并起来只有 9，重叠被减掉）。
状态：k=0「不相交，并集 12」；0<k<6「部分重叠」；k=6「B⊆A，并集就是 6」。

**例题**：「A={x|−1<x≤3}，B={x|x≥2}，求 A∩B、A∪B、∁ᵣA。」答案：A∩B={x|2≤x≤3}；A∪B={x|x>−1}；∁ᵣA={x|x≤−1 或 x>3}；重点在端点的开闭与"或"。
**六问**：① 并集里的重复元素写几次；② A∩B 是 A∪B 的子集吗；③ 补集能离开全集吗；④ {x|−1<x≤3} 在数轴上怎么画；⑤ 交集为空说明什么；⑥ A∩B=A 意味着什么。
**易错**：✗ 并集重复写元素 / ✗ 补集不写全集 / ✗ 区间端点随便写开闭 / ✗ "或"理解成"二选一" / ✗ A∩B=A 与 A⊆B 混 / ✗ 数轴画图时空心实心不分。

## bx1-c1-s4 充分条件与必要条件

**课本原话**
1. 若 p⇒q，则称 p 是 q 的充分条件，q 是 p 的必要条件。
2. 若 p⇒q 且 q⇏p，则 p 是 q 的充分不必要条件。
3. 若 p⇔q，则 p 是 q 的充要条件。

**三个扣分点**：方向（"p 是 q 的充分"与"p 的充分条件是 q"完全相反）；小范围推大范围（A⊆B 时 A 充分、B 必要）；判断时要两个方向都算。

**四张图**：① p、q 的推出箭头与四个条件名称；② 小范围套大范围的图（A⊆B ⇒ A 充分、B 必要）；③ 数轴上两个区间谁包含谁；④ 四种条件的判定流程（两个方向各试一次）。

**互动模型**：滑块＝命题 p 的端点 a（−3 到 3，step 1）；p: x≥a，q: x≥0
```js
// a<0：q⇒p 成立、p⇏q  ⇒ p 是 q 的必要不充分条件
// a=0：双向都成立        ⇒ 充要条件
// a>0：p⇒q 成立、q⇏p  ⇒ p 是 q 的充分不必要条件
kind = a < 0 ? 2 : a === 0 ? 3 : 1;      // 1 充分不必要、2 必要不充分、3 充要
```
`cases`：`{v:-2,eq:{kind:2}}`、`{v:0,eq:{kind:3}}`、`{v:2,eq:{kind:1}}`。
Autopilot：`[{t:0,v:-3},{t:1.2,v:-3},{t:4,v:0},{t:6.5,v:0},{t:9,v:3},{t:11.5,v:0},{t:13.5,v:-3}]`，keys `[-3,0,3]`——停留帧在 a=0（两个方向都成立，充要条件）。
状态：a<0「p 是 q 的必要不充分」；a=0「充要」；a>0「p 是 q 的充分不必要」。

**例题**：「判断：p: x>1，q: x>0。p 是 q 的什么条件？」答案：p⇒q 成立（x>1 时必有 x>0），q⇏p（x=0.5 时 q 真 p 假），故 p 是 q 的充分不必要条件；**反过来 q 是 p 的必要不充分条件**。
**六问**：① 充分条件的方向怎么记；② 小范围与大范围谁充分；③ 充要条件是两向都成立吗；④ p 是 q 的充分条件，q 是 p 的什么条件；⑤ 能不能只看一个方向就下结论；⑥ "x>1 的充分条件是 x>2"对吗。
**易错**：✗ "p 是 q 的充分条件"说成"q 是 p 的充分条件" / ✗ 大范围推小范围 / ✗ 只验一个方向 / ✗ 充要条件等同于"相等"（其实可以互相推出）/ ✗ 把必要条件当成"必要但没用" / ✗ 空集（无解）当作充分。

## bx1-c1-s5 全称量词与存在量词

**课本原话**
1. "所有的""任意一个"在逻辑中通常叫做全称量词，用符号 ∀ 表示。
2. "存在一个""至少有一个"叫做存在量词，用符号 ∃ 表示。
3. 全称量词命题的否定是存在量词命题：¬(∀x∈M, p(x)) ⇔ ∃x∈M, ¬p(x)。

**三个扣分点**：否命题要**同时**换量词和否定结论（只换一个是最常见的错）；"∀x, p(x)"为假只需一个反例；否定后量词要变。

**四张图**：① ∀ 与 ∃ 的读法与例子；② 否定的两条规则（换量词 + 否结论）；③ 恒成立问题的判别式法；④ 一个反例就够了。

**互动模型**：滑块＝命题"∀x∈R，x²+ax+1>0"里的参数 a（−3 到 3，step 0.5）
```js
disc = a * a - 4;          // 判别式
truth = disc < 0 ? 1 : 0;  // 恒成立 ⇔ 判别式小于 0
```
`cases`：`{v:0,eq:{disc:-4,truth:1}}`、`{v:2,eq:{disc:0,truth:0}}`、`{v:3,eq:{disc:5,truth:0}}`。
Autopilot：`[{t:0,v:-3},{t:1.2,v:-3},{t:4,v:0},{t:6.5,v:0},{t:9,v:2},{t:11.5,v:3},{t:13.5,v:-3}]`，keys `[-3,0,2,3]`——停留帧在 a=0（判别式 −4，恒成立，抛物线整个在水面上方）。
状态：|a|<2「恒成立（Δ<0）」；|a|=2「含重根处等于 0，不满足 >0」；|a|>2「有实根，命题假」。

**例题**：「已知 ∀x∈R，x²+ax+1>0 恒成立，求 a 的取值范围。」答案：需要 Δ=a²−4<0，即 −2<a<2；**若改为 ≥0 恒成立则 Δ≤0**，边界差一点就是错。
**六问**：① 否定要改几个地方；② ∀ 为假需要几个反例；③ "所有"的否定是"所有都不"吗；④ 恒成立与判别式什么关系；⑤ ∃ 命题怎么证真、怎么证假；⑥ x²+ax+1≥0 与 >0 的答案差在哪。
**易错**：✗ 否定只换量词不改结论 / ✗ 否命题与命题的否定混 / ✗ ∀ 命题为假要全部反例 / ✗ "至少有一个"的否定是"至少有一个不" / ✗ 恒成立只用 Δ>0 / ✗ ≥0 与 >0 用同一个判别式条件。

## bx1-c2-s1 等式性质与不等式性质

**课本原话**
1. 如果 a>b，那么 a+c>b+c。
2. 如果 a>b，c>0，那么 ac>bc；如果 a>b，c<0，那么 ac<bc。
3. 作差比较法：a−b>0 ⇔ a>b。

**三个扣分点**：乘负数要变号（所有不等式性质里最常忘）；同向不等式只能相加、不能相减；取倒数要讨论正负。

**四张图**：① 不等式的八条性质（加、乘、同向相加）；② 乘负数变号的数轴演示；③ 作差法的三步（作差→变形→判号）；④ 同向相加与相减的区别（一正一反）。

**互动模型**：滑块＝正数 c（−5 到 5，step 1），已知 a=3>b=1
```js
ac = 3 * c; bc = 1 * c; diff = 2 * c;
kind = c > 0 ? 1 : c === 0 ? 0 : -1;    // 1 不变号、0 相等、−1 变号
```
`cases`：`{v:2,eq:{ac:6,bc:2,diff:4}}`、`{v:0,eq:{ac:0,bc:0,diff:0}}`、`{v:-2,eq:{ac:-6,bc:-2,diff:-4}}`。
Autopilot：`[{t:0,v:2},{t:1.2,v:2},{t:4,v:0},{t:6.5,v:0},{t:9,v:-2},{t:11.5,v:-2},{t:13.5,v:3}]`，keys `[2,0,-2,3]`——停留帧在 c=−2（乘负数，不等号方向翻过来）。
状态：c>0「方向不变」；c=0「两边都变 0，不等式失效」；c<0「方向反转」。

**例题**：「已知 a>b，c<0，判断 ac 与 bc 的大小。」答案：由 a>b 且 c<0，得 ac<bc（乘负数变号）；若 c 是正数则方向不变。
**六问**：① 乘负数为什么要变号；② 同向不等式能不能相减；③ 取倒数要不要讨论符号；④ 作差法的第三步做什么；⑤ a>b 能否推出 a²>b²；⑥ 两边同除一个负数怎么做。
**易错**：✗ 乘负数不变号 / ✗ 同向不等式相减 / ✗ 两边平方不讨论符号 / ✗ a>b 就 a²>b² / ✗ 取倒数不分类 / ✗ 不等式两边同加一个式子当作乘。

## bx1-c2-s2 基本不等式

**课本原话**
1. 如果 a>0，b>0，那么 √(ab) ≤ (a+b)/2，当且仅当 a=b 时等号成立。
2. 变形：a+b ≥ 2√(ab)（a，b>0）。
3. 用基本不等式求最值的三个条件：一正、二定、三相等。

**三个扣分点**：必须"一正二定三相等"（缺一个就不能用）；等号能否取到决定最值能否取到；积定和最小、和定积最大是两个方向。

**四张图**：① 基本不等式的几何意义（半圆中的弦与半径）；② 和定求积最大值（a=b 时最大）；③ 积定求和最小值；④ 三条件缺一不可的反例。

**互动模型**：滑块＝a（0.5–9.5，step 0.5），固定 a+b=10
```js
b = 10 - a; prod = a * b;            // 最大值 25，在 a=b=5
gap  = 25 - prod;                     // 与最大值的差，a=5 时为 0
```
`cases`：`{v:1,eq:{b:9,prod:9}}`、`{v:5,eq:{b:5,prod:25}}`、`{v:9,eq:{b:1,prod:9}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:5},{t:6.5,v:5},{t:9,v:9},{t:11.5,v:1},{t:13.5,v:1}]`，keys `[1,3,5,9]`——停留帧在 a=5（a=b，等号成立，积取到最大值 25）。
状态：a=5「等号成立，积最大」；a≠5「都没取到最大值」。

**例题**：「x>0，求 x+4/x 的最小值。」答案：x>0 且 x·(4/x)=4 为定值，由基本不等式 x+4/x≥2√4=4，当且仅当 x=2 时取到最小值 4。

## bx1-c3-s1 函数的概念及其表示

**课本原话**
1. 设 A、B 是非空的实数集，如果对于集合 A 中的任意一个数 x，按照某种确定的对应关系 f，在集合 B 中都有唯一确定的数 y 和它对应，那么就称 f：A→B 为从集合 A 到集合 B 的一个函数。

**三个扣分点**：定义域优先（做题第一步）；判断"同一函数"要看定义域和对应关系都相同；分段函数在分界点要看清归哪一段。

**四张图**：① 函数定义的三个关键词（任意、唯一、实数集）；② 三要素与常见定义域限制（分母、偶次根、对数）；③ 分段函数的图象与分界点；④ 判断同一函数的三步。

```js
seg = x < 0 ? 0 : x < 2 ? 1 : 2;      // 用哪一段
```
`cases`：`{v:-2,eq:{y:4,seg:0}}`、`{v:1,eq:{y:2,seg:1}}`、`{v:3,eq:{y:1,seg:2}}`、`{v:2,eq:{y:2,seg:2}}`。
Autopilot：`[{t:0,v:-3},{t:1.2,v:-3},{t:4,v:0},{t:6.5,v:1},{t:9,v:2},{t:11.5,v:3},{t:13.5,v:-3}]`，keys `[-3,0,1,3]`——停留帧在 x=2（分界点，归第三段，值从 2x 的 4 掉到 4−x 的 2）。

## bx1-c3-s2 函数的基本性质

**课本原话**

**易错**：✗ 说"在定义域上递增" / ✗ 奇偶性不看定义域 / ✗ 最值直接代端点 / ✗ 单调区间用 ∪ 连接 / ✗ 奇函数 f(0) 必为 0（定义域要含 0）/ ✗ 对称轴公式写成 b/(2a)。

## bx1-c3-s3 幂函数

## bx1-c4-s1 指数

## bx1-c4-s3 对数

**课本原话**
1. 若 a^b=N（a>0，a≠1），则 b 叫做以 a 为底 N 的对数，记作 b=log_a N。
2. 对数恒等式：a^(log_a N)=N；log_a 1=0；log_a a=1。
3. 运算法则：log_a(MN)=log_a M+log_a N；log_a(M/N)=log_a M−log_a N；log_a M^n=n·log_a M。

**三个扣分点**：真数必须大于 0（求定义域必考）；log_a(M+N) ≠ log_a M+log_a N（法则只对乘除）；换底公式记反（log_a b=1/log_b a）。

**四张图**：① 指数式与对数式的互化；② 三个特殊值（1、0、自身）；③ 运算法则三条；④ 换底公式与常用对数（lg、ln）。

**互动模型**：滑块＝指数 k（0–10，step 1），N=2^k
```js
n = 2 ** k;        // 真数
lg = k;            // log₂N = k
```

## bx1-c4-s5 函数的应用（二）


状态：ω>1「周期变短，图象被压扁」；ω=1「T=2π」；0<ω<1「周期变长，被拉宽」。

**例题**：「已知 y=Asin(ωx+φ) 的最大值是 3、最小正周期是 π、图象过点 (0,1)，且 |φ|<π/2，求解析式。」答案：A=3；ω=2π/π=2；过 (0,1) 得 3sinφ=1，sinφ=1/3，φ=arcsin(1/3)；所以 y=3sin(2x+arcsin(1/3))。
**六问**：① T 与 ω 的关系；② 先伸缩后平移平移多少；③ 振幅与最大值的关系；④ 五点法取哪五个点；⑤ 初相 φ 怎么读；⑥ A<0 怎么处理。
**易错**：✗ T=2πω / ✗ 平移量不除以 ω / ✗ 振幅等于最大值的一半 / ✗ 五点法取错点 / ✗ φ 读成与 x 轴交点 / ✗ A 为负不先化正。

## bx1-c5-s7 三角函数的应用

**课本原话**
1. 简谐运动：位移 y 与时间 t 的关系可用 y=Asin(ωt+φ) 描述。
2. 实际问题中的周期现象（潮汐、温度、交变电流）常用三角函数建模。
3. 建模步骤：设模型→由最值定 A、由周期定 ω、由特殊点定 φ→还原。

**三个扣分点**：A 由 (最大值−最小值)/2 定；b 由 (最大值+最小值)/2 定；φ 要用特殊点代入且注意范围。

**四张图**：① 简谐运动的三个参数；② 潮汐模型的图象与最值；③ 由最值、周期、特殊点反解参数；④ 建模流程与检验。

**互动模型**：滑块＝时间 t（0–24 时，step 0.5），潮高 h=3sin(πt/6)+5
```js
h = 3 * Math.sin(Math.PI * t / 6) + 5;
// 最大 8（t=3），最小 2（t=9），周期 12 小时
```
`cases`：`{v:0,eq:{h:5}}`、`{v:3,eq:{h:8}}`、`{v:6,eq:{h:5}}`、`{v:9,eq:{h:2}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:3},{t:6.5,v:3},{t:9,v:9},{t:11.5,v:12},{t:13.5,v:0}]`，keys `[0,3,9,12]`——停留帧在 t=3（涨到最高 8 米，之后开始落潮）。
状态：h 升「涨潮」；h=8「高潮」；h 降「落潮」；h=2「低潮」。

**例题**：「某港口水深 h(t)=3sin(πt/6)+5（t 为小时），求一天中水深的最大值、最小值与周期。」答案：最大 8、最小 2、周期 12 小时；一天 24 小时里涨落两次。
**六问**：① A 怎么由最值求；② 周期怎么由图象读；③ φ 怎么定；④ 为什么一天涨落两次；⑤ 模型能预测任意时刻吗；⑥ 实际数据与模型有偏差怎么办。
**易错**：✗ A 直接取最大值 / ✗ 周期读成半个周期 / ✗ φ 随便取 / ✗ 水平线 b 漏掉 / ✗ 单位（小时/分钟）不统一 / ✗ 忘了检验模型合理性。
