## bx1-c4-s4 对数函数

**课本原话**
1. 一般地，函数 y=log_a x（a>0，a≠1）叫做对数函数，定义域是 (0,+∞)。
2. 对数函数的图象都过点 (1,0)。
3. 当 a>1 时在 (0,+∞) 上递增；当 0<a<1 时递减。

**三个扣分点**：定义域是 (0,+∞)（求复合函数定义域是必考）；过 (1,0)；对数函数与指数函数互为反函数（关于 y=x 对称）。

**四张图**：① 底数对图象的影响；② 都过 (1,0)；③ 与指数函数的对称关系；④ 复合函数定义域三步。

**互动模型**：滑块＝底数 a（0.2–5，step 0.1）
```js
l2 = Math.log(2) / Math.log(a);    // log_a 2
l4 = 2 * l2;                        // log_a 4 = 2log_a 2
mono = a > 1 ? 1 : -1;
```
`cases`：`{v:2,eq:{l2:1,l4:2}}`、`{v:0.5,eq:{l2:-1,l4:-2}}`、`{v:4,eq:{l2:0.5,l4:1}}`。
Autopilot：`[{t:0,v:0.5},{t:1.2,v:0.5},{t:4,v:2},{t:6.5,v:2},{t:9,v:4},{t:11.5,v:0.5},{t:13.5,v:0.5}]`，keys `[0.5,2,4]`——停留帧在 a=2（log₂2=1，log₂4=2，正好是"翻倍变加一"）。
状态：a>1「递增」；0<a<1「递减」；任何 a「都过 (1,0)」。

**例题**：「求 y=log₂(3−x) 的定义域。」答案：真数 3−x>0，得 x<3，定义域 (−∞,3)。
**六问**：① 对数函数的定义域；② 图象过哪个点；③ 与指数函数的关系；④ 复合函数定义域怎么求；⑤ 底数大小怎么比较；⑥ log_a x 能取到 0 吗。
**易错**：✗ 定义域是 R / ✗ 过 (0,1) / ✗ 与指数函数图象重合 / ✗ 复合函数只求真数不管整体 / ✗ 0<a<1 时还递增 / ✗ 定义域写成闭区间。
