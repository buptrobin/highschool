## bx1-c2-s2 基本不等式

**课本原话**
1. 如果 a>0，b>0，那么 √(ab) ≤ (a+b)/2，当且仅当 a=b 时等号成立。
2. 变形：a+b ≥ 2√(ab)（a，b>0）。
3. 用基本不等式求最值的三个条件：一正、二定、三相等。

**三个扣分点**：必须"一正二定三相等"（缺一个就不能用）；等号能否取到决定最值能否取到；积定和最小、和定积最大是两个方向。

**四张图**：① 基本不等式的几何意义（半圆中的弦与半径）；② 和定求积最大值（a=b 时最大）；③ 积定求和最小值；④ 三条件缺一不可的反例。

**互动模型**：滑块＝a（0.5–9.5，step 0.5），固定 a+b=10
```js
b = 10 - a; prod = a * b;            // 最大值 25，在 a=b=5
gap  = 25 - prod;                     // 与最大值的差，a=5 时为 0
```
`cases`：`{v:1,eq:{b:9,prod:9}}`、`{v:5,eq:{b:5,prod:25}}`、`{v:9,eq:{b:1,prod:9}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:5},{t:6.5,v:5},{t:9,v:9},{t:11.5,v:1},{t:13.5,v:1}]`，keys `[1,3,5,9]`——停留帧在 a=5（a=b，等号成立，积取到最大值 25）。
状态：a=5「等号成立，积最大」；a≠5「都没取到最大值」。

**例题**：「x>0，求 x+4/x 的最小值。」答案：x>0 且 x·(4/x)=4 为定值，由基本不等式 x+4/x≥2√4=4，当且仅当 x=2 时取到最小值 4。
**六问**：① 三个条件分别是；② 等号取不到会怎样；③ 和定求什么最值；④ 积定求什么最值；⑤ 为什么要求 a,b>0；⑥ x+4/x 在 x<0 时最小是多少。
**易错**：✗ 直接用不等式不看正负 / ✗ 忽略等号条件 / ✗ 和定求积最小（方向反）/ ✗ 把 2√(ab) 写成 √(2ab) / ✗ a+b≥2√(ab) 对任意实数成立 / ✗ 拆项后不再验等号。

## 通用约定（所有页一致）

- 出处一律写「人教A版必修第一册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
