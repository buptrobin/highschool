## bx1-c4-s2 指数函数

**课本原话**
1. 一般地，函数 y=a^x（a>0，且 a≠1）叫做指数函数，定义域是 R。
2. 指数函数的图象都过点 (0,1)。
3. 当 a>1 时在 R 上递增；当 0<a<1 时在 R 上递减。

**三个扣分点**：底数必须 a>0 且 a≠1（a=1 不是指数函数）；都过 (0,1) 而不是 (1,0)；a>1 与 0<a<1 的单调性相反。

**四张图**：① 底数 a 的取值对图象的影响（一组曲线）；② 都过 (0,1)；③ 单调性与 a 的关系；④ 与 y=x²（幂函数）的区别。

**互动模型**：滑块＝底数 a（0.1–3，step 0.1）
```js
y1 = a;            // a^1
y0 = 1;            // a^0，恒为 1
yn = 1 / a;        // a^(−1)
mono = a > 1 ? 1 : a === 1 ? 0 : -1;
```
`cases`：`{v:0.5,eq:{y1:0.5,yn:2}}`、`{v:1,eq:{y1:1,yn:1}}`、`{v:2,eq:{y1:2,yn:0.5}}`、`{v:3,eq:{y1:3,yn:0.333}}`。
Autopilot：`[{t:0,v:0.5},{t:1.2,v:0.5},{t:4,v:2},{t:6.5,v:2},{t:9,v:1},{t:11.5,v:3},{t:13.5,v:0.5}]`，keys `[0.5,1,2,3]`——停留帧在 a=1（图象变成一条水平线，此时它不是指数函数，最容易被漏掉的一格）。
状态：a>1「递增，图象上升」；a=1「常函数 y=1，不是指数函数」；0<a<1「递减」。

**例题**：「比较 1.7^2.5 与 1.7^3 的大小。」答案：底数 1.7>1，函数递增，2.5<3，所以 1.7^2.5<1.7^3。
**六问**：① 指数函数的底数有什么限制；② 图象一定过哪个点；③ a=1 为什么不算指数函数；④ 底数互为倒数时两条曲线什么关系；⑤ 指数函数与幂函数怎么区分；⑥ 比较大小有几种方法。
**易错**：✗ a=1 也是指数函数 / ✗ 过 (1,0) / ✗ 底数小于 1 时还是递增 / ✗ 与幂函数混 / ✗ 比较大小不看底数 / ✗ 0.5^3 比 0.5^2 大。
