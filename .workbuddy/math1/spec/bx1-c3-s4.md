## bx1-c3-s4 函数的应用（一）

**课本原话**
1. 用函数模型解决实际问题的一般步骤：审题→设变量→建立函数关系→求最值→还原。
2. 常见模型：一次函数、二次函数、分段函数、分式函数。
3. 实际问题中自变量的取值范围由实际意义决定。

**三个扣分点**：定义域要被"实际意义"卡住（价格、数量不能为负、销量不能为负）；最值要在**定义域内**取；单位与单位换算。

**四张图**：① 建模五步流程；② 利润=单件利润×销量的二次模型；③ 销量随价格下降的直线模型；④ 最值可能取在端点或顶点（对比两图）。

**互动模型**：滑块＝售价 p（15–25 元，step 0.5），成本 10 元，销量 q=100−4p
```js
q = 100 - 4 * p;
L = (p - 10) * q;      // 利润
// 顶点在 p = 17.5 处，最大利润 225
```
`cases`：`{v:15,eq:{q:40,L:200}}`、`{v:17.5,eq:{q:30,L:225}}`、`{v:20,eq:{q:20,L:200}}`。
Autopilot：`[{t:0,v:15},{t:1.2,v:15},{t:4,v:17.5},{t:6.5,v:17.5},{t:9,v:20},{t:11.5,v:25},{t:13.5,v:15}]`，keys `[15,17.5,20,25]`——停留帧在 p=17.5（涨价到这儿利润最高，再涨就掉）。
状态：p<17.5「涨价还能多赚」；p=17.5「利润最大 225」；p>17.5「涨价反而少赚」。

**例题**：「某商品成本 10 元，售价 p 元时销量 q=100−4p，求利润最大时的售价与最大利润。」答案：L=(p−10)(100−4p)=−4p²+140p−1000，顶点 p=17.5 时 L=225；需检验销量 q=30>0 符合实际。
**六问**：① 建模的第一步是什么；② 定义域为什么要看实际意义；③ 最值一定在顶点吗；④ 销量为负说明什么；⑤ 分段模型怎么处理；⑥ 结果要不要检验。
**易错**：✗ 不管定义域直接求顶点 / ✗ 利润写成售价×销量（漏成本）/ ✗ 销量为负也照算 / ✗ 最值只看顶点不看端点 / ✗ 忽略单位 / ✗ 结果不回代检验。

## 通用约定（所有页一致）

- 出处一律写「人教A版必修第一册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
- 禁止写「请拖动滑块」——自动演示时滑块的圆点会自己动，这才是提示。
