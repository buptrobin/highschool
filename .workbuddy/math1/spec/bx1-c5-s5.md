## bx1-c5-s5 三角恒等变换

**课本原话**
1. 两角差的余弦公式：cos(α−β)=cosαcosβ+sinαsinβ。
2. 二倍角公式：sin2α=2sinαcosα，cos2α=cos²α−sin²α=2cos²α−1=1−2sin²α。
3. 平方关系：sin²α+cos²α=1。

**三个扣分点**：二倍角公式有三个形式（按需选，选错就多算）；符号由 α 所在象限决定（开方要带 ±）；辅助角公式的 φ 要写对。

**四张图**：① 和差角公式表；② 二倍角的三种形式与选用；③ 平方关系与符号判定；④ 辅助角公式 asinx+bcosx=√(a²+b²)sin(x+φ)。

**互动模型**：滑块＝α（0–90°，step 5°）
```js
s2 = Math.sin(2 * α * Math.PI / 180);
c2 = Math.cos(2 * α * Math.PI / 180);
one = Math.pow(Math.sin(a), 2) + Math.pow(Math.cos(a), 2);   // 恒为 1
```
`cases`：`{v:30,eq:{s2:0.866,c2:0.5}}`、`{v:45,eq:{s2:1,c2:0}}`、`{v:60,eq:{s2:0.866,c2:-0.5}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:45},{t:6.5,v:45},{t:9,v:60},{t:11.5,v:90},{t:13.5,v:0}]`，keys `[0,30,45,60]`——停留帧在 α=45°（2α=90°，sin2α 取到最大值 1、cos2α 恰好为 0）。
状态：α<45「cos2α>0」；α=45「cos2α=0」；α>45「cos2α<0」。

**例题**：「已知 sinα=3/5，α∈(π/2,π)，求 sin2α、cos2α。」答案：cosα=−4/5（第二象限），sin2α=2×(3/5)×(−4/5)=−24/25；cos2α=1−2sin²α=1−18/25=7/25。
**六问**：① 二倍角公式有几种写法；② 开方为什么带 ±；③ 辅助角公式怎么用；④ cos2α 选哪个形式最快；⑤ sin²α+cos²α 恒等于几；⑥ 半角公式与二倍角的关系。
**易错**：✗ 开方不带符号 / ✗ 只用一种 cos2α 形式 / ✗ sin2α=2sinα / ✗ 辅助角 φ 写反 / ✗ 平方关系记成 2 / ✗ 忽略 α 的象限。
