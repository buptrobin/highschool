## bx1-c1-s3 集合的基本运算

**课本原话**
1. 由属于 A 且属于 B 的所有元素组成的集合，叫做 A 与 B 的交集，记作 A∩B。
2. 由属于 A 或属于 B 的所有元素组成的集合，叫做 A 与 B 的并集，记作 A∪B。
3. 若 A⊆U，由 U 中不属于 A 的所有元素组成的集合，叫做 A 在 U 中的补集，记作 ∁ᵤA。

**三个扣分点**：并集里重复元素只写一次（互异性）；"或"包含"且"（A∩B 的元素也在 A∪B 里）；补集必须先有全集 U。

**四张图**：① 交集/并集/补集的 Venn 三连；② 数轴上的区间运算（交、并、补各一例）；③ 容斥公式 |A∪B|=|A|+|B|−|A∩B| 的来历；④ 含参数的集合运算（端点取舍）。

**互动模型**：滑块＝A∩B 的元素个数 k（0–6），|A|=|B|=6，全集 U 有 10 个元素
```js
union = 12 - k;      // 容斥：|A|+|B|−k
onlyA = 6 - k;
comp  = 10 - 6;      // ∁ᵤA 的个数，恒为 4
```
`cases`：`{v:0,eq:{union:12}}`、`{v:3,eq:{union:9,onlyA:3}}`、`{v:6,eq:{union:6,onlyA:0}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:3},{t:6.5,v:3},{t:9,v:6},{t:11.5,v:6},{t:13.5,v:0}]`，keys `[0,3,6]`——停留帧在 k=3（两个 6 元集合并起来只有 9，重叠被减掉）。
状态：k=0「不相交，并集 12」；0<k<6「部分重叠」；k=6「B⊆A，并集就是 6」。

**例题**：「A={x|−1<x≤3}，B={x|x≥2}，求 A∩B、A∪B、∁ᵣA。」答案：A∩B={x|2≤x≤3}；A∪B={x|x>−1}；∁ᵣA={x|x≤−1 或 x>3}；重点在端点的开闭与"或"。
**六问**：① 并集里的重复元素写几次；② A∩B 是 A∪B 的子集吗；③ 补集能离开全集吗；④ {x|−1<x≤3} 在数轴上怎么画；⑤ 交集为空说明什么；⑥ A∩B=A 意味着什么。
**易错**：✗ 并集重复写元素 / ✗ 补集不写全集 / ✗ 区间端点随便写开闭 / ✗ "或"理解成"二选一" / ✗ A∩B=A 与 A⊆B 混 / ✗ 数轴画图时空心实心不分。

## 通用约定（所有页一致）

- 出处一律写「人教A版必修第一册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
- 禁止写「请拖动滑块」——自动演示时滑块的圆点会自己动，这才是提示。
