## bx1-c5-s2 三角函数的概念

**课本原话**
1. 设 α 是一个任意角，α 的终边与单位圆交于点 P(x,y)，则 sinα=y，cosα=x，tanα=y/x（x≠0）。
2. 正弦、余弦、正切都是以角为自变量、以比值为函数值的函数。
3. 三角函数值的符号：一全正、二正弦、三正切、四余弦。

**三个扣分点**：符号规律（第二象限只有正弦正）；tan 在 x=0 时无意义；定义用单位圆，不是直角三角形。

**四张图**：① 单位圆定义与坐标；② 四个象限的符号图（ASTC）；③ 特殊角的值表；④ 由终边上一点求三角函数值。

**互动模型**：滑块＝角 α（0–360°，step 15°）
```js
sin = Math.sin(α * Math.PI / 180);
cos = Math.cos(α * Math.PI / 180);
```

`cases`：`{v:30,eq:{sin:0.5,cos:0.866}}`、`{v:120,eq:{sin:0.866,cos:-0.5}}`、`{v:210,eq:{sin:-0.5,cos:-0.866}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:90},{t:6.5,v:90},{t:9,v:180},{t:11.5,v:270},{t:13.5,v:0}]`，keys `[0,90,180,270]`——停留帧在 90°（sin 到最大值 1、cos 掉到 0，符号开始翻转）。
状态：第一象限「全正」；第二「正弦正」；第三「正切正」；第四「余弦正」。

**例题**：「已知角 α 的终边过点 P(−3,4)，求 sinα、cosα、tanα。」答案：r=5，sinα=4/5，cosα=−3/5，tanα=−4/3。
**六问**：① 三类函数分别在哪几个象限为正；② tan 什么时候无意义；③ 用终边上任意一点能求吗；④ sin²α+cos²α 等于多少；⑤ 第二象限 cos 为什么是负的；⑥ 单位圆定义的优点。
**易错**：✗ 第二象限余弦为正 / ✗ tan 处处有意义 / ✗ 用斜边比错（对边/斜边记反）/ ✗ 特殊角值记混 / ✗ 由点求值时忘了符号 / ✗ 认为三角函数只能用于锐角。

## 通用约定（所有页一致）

- 出处一律写「人教A版必修第一册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
