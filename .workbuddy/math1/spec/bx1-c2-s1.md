## bx1-c2-s1 等式性质与不等式性质

**课本原话**
1. 如果 a>b，那么 a+c>b+c。
2. 如果 a>b，c>0，那么 ac>bc；如果 a>b，c<0，那么 ac<bc。
3. 作差比较法：a−b>0 ⇔ a>b。

**三个扣分点**：乘负数要变号（所有不等式性质里最常忘）；同向不等式只能相加、不能相减；取倒数要讨论正负。

**四张图**：① 不等式的八条性质（加、乘、同向相加）；② 乘负数变号的数轴演示；③ 作差法的三步（作差→变形→判号）；④ 同向相加与相减的区别（一正一反）。

**互动模型**：滑块＝正数 c（−5 到 5，step 1），已知 a=3>b=1
```js
ac = 3 * c; bc = 1 * c; diff = 2 * c;
kind = c > 0 ? 1 : c === 0 ? 0 : -1;    // 1 不变号、0 相等、−1 变号
```
`cases`：`{v:2,eq:{ac:6,bc:2,diff:4}}`、`{v:0,eq:{ac:0,bc:0,diff:0}}`、`{v:-2,eq:{ac:-6,bc:-2,diff:-4}}`。
Autopilot：`[{t:0,v:2},{t:1.2,v:2},{t:4,v:0},{t:6.5,v:0},{t:9,v:-2},{t:11.5,v:-2},{t:13.5,v:3}]`，keys `[2,0,-2,3]`——停留帧在 c=−2（乘负数，不等号方向翻过来）。
状态：c>0「方向不变」；c=0「两边都变 0，不等式失效」；c<0「方向反转」。

**例题**：「已知 a>b，c<0，判断 ac 与 bc 的大小。」答案：由 a>b 且 c<0，得 ac<bc（乘负数变号）；若 c 是正数则方向不变。
**六问**：① 乘负数为什么要变号；② 同向不等式能不能相减；③ 取倒数要不要讨论符号；④ 作差法的第三步做什么；⑤ a>b 能否推出 a²>b²；⑥ 两边同除一个负数怎么做。
**易错**：✗ 乘负数不变号 / ✗ 同向不等式相减 / ✗ 两边平方不讨论符号 / ✗ a>b 就 a²>b² / ✗ 取倒数不分类 / ✗ 不等式两边同加一个式子当作乘。

## 通用约定（所有页一致）

- 出处一律写「人教A版必修第一册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
