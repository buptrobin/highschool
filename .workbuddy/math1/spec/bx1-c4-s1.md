## bx1-c4-s1 指数

**课本原话**
1. 若 xⁿ=a（n>1，n∈N*），则 x 叫做 a 的 n 次方根；正数的偶次方根有两个，负数没有偶次方根。
2. a^(m/n)=ⁿ√(a^m)（a>0，m，n∈N*，n>1）。
3. 同底数幂相乘：a^m·a^n=a^(m+n)；幂的乘方：(a^m)^n=a^(mn)。

**三个扣分点**：ⁿ√(aⁿ) 当 n 为偶数时等于 |a|（不是 a）；负指数与分数指数互化；0 的负指数幂没有意义。

**四张图**：① 根式与分数指数幂的互化表；② 运算法则三条（乘、除、幂的乘方）；③ 负指数与倒数的关系；④ ⁿ√(aⁿ) 的分类（n 奇偶）。

**互动模型**：滑块＝指数 x（−3 到 3，step 0.5），底数 2
```js
pw = Math.pow(2, x);          // 2^x
inv = Math.pow(2, -x);        // 2^(−x)
prod = pw * inv;              // 恒为 1（同底数幂相乘的法则）
```
`cases`：`{v:-1,eq:{pw:0.5,inv:2}}`、`{v:0,eq:{pw:1,inv:1}}`、`{v:3,eq:{pw:8,inv:0.125}}`。
Autopilot：`[{t:0,v:-3},{t:1.2,v:-3},{t:4,v:0},{t:6.5,v:0},{t:9,v:1.5},{t:11.5,v:3},{t:13.5,v:-3}]`，keys `[-3,0,1.5,3]`——停留帧在 x=0（2⁰=1，正负指数的分界，两侧互为倒数）。
状态：x>0「2^x>1」；x=0「等于 1」；x<0「0<2^x<1」。

**例题**：「计算 8^(2/3) + (1/2)^(−2)。」答案：8^(2/3)=(2³)^(2/3)=2²=4；(1/2)^(−2)=2²=4；结果为 8。
**六问**：① ⁿ√(aⁿ) 一定等于 a 吗；② 负指数怎么化成倒数；③ 0 的负指数有意义吗；④ 分数指数幂的底数为什么要正；⑤ a^m·a^n 与 (a^m)^n 的区别；⑥ 2^(1/2) 是有理数吗。
**易错**：✗ ⁿ√(aⁿ)=a 恒成立 / ✗ a^(−n)=−aⁿ / ✗ 0^(−1)=0 / ✗ a^m·a^n=a^(mn) / ✗ 分数指数幂底数可以为负 / ✗ 把 2^(1/2) 写成 1。
