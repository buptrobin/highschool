## bx1-c5-s6 函数 y=Asin(ωx+φ)

**课本原话**
1. 形如 y=Asin(ωx+φ)（A>0，ω>0）的函数，A 叫振幅，ωx+φ 叫相位，φ 叫初相。
2. 最小正周期 T=2π/ω，频率 f=1/T。
3. 图象变换：先平移后伸缩，或先伸缩后平移，平移量不同。

**三个扣分点**：周期公式 T=2π/ω（不是 2π·ω）；先伸缩后平移时平移量是 |φ|/ω；振幅 A 决定最大值 A 与最小值 −A。

**四张图**：① A、ω、φ 各自动什么；② 由 y=sinx 到 y=Asin(ωx+φ) 的两条变换路线；③ 五点法作图；④ 由图象读 A、ω、φ。

**互动模型**：滑块＝ω（0.5–4，step 0.1），A=2
```js
T = 2 * Math.PI / w;      // 最小正周期
f = 1 / T;                // 频率 = ω/(2π)
max = 2;                  // 振幅 A
```
`cases`：`{v:1,eq:{T:6.2832,f:0.1592}}`、`{v:2,eq:{T:3.1416,f:0.3183}}`、`{v:0.5,eq:{T:12.566,f:0.0796}}`。
Autopilot：`[{t:0,v:0.5},{t:1.2,v:0.5},{t:4,v:1},{t:6.5,v:1},{t:9,v:2},{t:11.5,v:4},{t:13.5,v:0.5}]`，keys `[0.5,1,2,4]`——停留帧在 ω=1（T=2π，最朴素的那一条）。
状态：ω>1「周期变短，图象被压扁」；ω=1「T=2π」；0<ω<1「周期变长，被拉宽」。

**例题**：「已知 y=Asin(ωx+φ) 的最大值是 3、最小正周期是 π、图象过点 (0,1)，且 |φ|<π/2，求解析式。」答案：A=3；ω=2π/π=2；过 (0,1) 得 3sinφ=1，sinφ=1/3，φ=arcsin(1/3)；所以 y=3sin(2x+arcsin(1/3))。
**六问**：① T 与 ω 的关系；② 先伸缩后平移平移多少；③ 振幅与最大值的关系；④ 五点法取哪五个点；⑤ 初相 φ 怎么读；⑥ A<0 怎么处理。
**易错**：✗ T=2πω / ✗ 平移量不除以 ω / ✗ 振幅等于最大值的一半 / ✗ 五点法取错点 / ✗ φ 读成与 x 轴交点 / ✗ A 为负不先化正。
