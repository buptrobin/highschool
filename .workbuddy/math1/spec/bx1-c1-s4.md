## bx1-c1-s4 充分条件与必要条件

**课本原话**
1. 若 p⇒q，则称 p 是 q 的充分条件，q 是 p 的必要条件。
2. 若 p⇒q 且 q⇏p，则 p 是 q 的充分不必要条件。
3. 若 p⇔q，则 p 是 q 的充要条件。

**三个扣分点**：方向（"p 是 q 的充分"与"p 的充分条件是 q"完全相反）；小范围推大范围（A⊆B 时 A 充分、B 必要）；判断时要两个方向都算。

**四张图**：① p、q 的推出箭头与四个条件名称；② 小范围套大范围的图（A⊆B ⇒ A 充分、B 必要）；③ 数轴上两个区间谁包含谁；④ 四种条件的判定流程（两个方向各试一次）。

**互动模型**：滑块＝命题 p 的端点 a（−3 到 3，step 1）；p: x≥a，q: x≥0
```js
// a<0：q⇒p 成立、p⇏q  ⇒ p 是 q 的必要不充分条件
// a=0：双向都成立        ⇒ 充要条件
// a>0：p⇒q 成立、q⇏p  ⇒ p 是 q 的充分不必要条件
kind = a < 0 ? 2 : a === 0 ? 3 : 1;      // 1 充分不必要、2 必要不充分、3 充要
```
`cases`：`{v:-2,eq:{kind:2}}`、`{v:0,eq:{kind:3}}`、`{v:2,eq:{kind:1}}`。
Autopilot：`[{t:0,v:-3},{t:1.2,v:-3},{t:4,v:0},{t:6.5,v:0},{t:9,v:3},{t:11.5,v:0},{t:13.5,v:-3}]`，keys `[-3,0,3]`——停留帧在 a=0（两个方向都成立，充要条件）。
状态：a<0「p 是 q 的必要不充分」；a=0「充要」；a>0「p 是 q 的充分不必要」。

**例题**：「判断：p: x>1，q: x>0。p 是 q 的什么条件？」答案：p⇒q 成立（x>1 时必有 x>0），q⇏p（x=0.5 时 q 真 p 假），故 p 是 q 的充分不必要条件；**反过来 q 是 p 的必要不充分条件**。
**六问**：① 充分条件的方向怎么记；② 小范围与大范围谁充分；③ 充要条件是两向都成立吗；④ p 是 q 的充分条件，q 是 p 的什么条件；⑤ 能不能只看一个方向就下结论；⑥ "x>1 的充分条件是 x>2"对吗。
**易错**：✗ "p 是 q 的充分条件"说成"q 是 p 的充分条件" / ✗ 大范围推小范围 / ✗ 只验一个方向 / ✗ 充要条件等同于"相等"（其实可以互相推出）/ ✗ 把必要条件当成"必要但没用" / ✗ 空集（无解）当作充分。
