## bx1-c3-s2 函数的基本性质

**课本原话**
1. 设函数 f(x) 的定义域为 I，如果对任意 x₁，x₂∈I，当 x₁<x₂ 时都有 f(x₁)<f(x₂)，那么 f(x) 在 I 上单调递增。
2. 如果对定义域内任意 x，都有 f(−x)=f(x)，那么 f(x) 是偶函数；若 f(−x)=−f(x)，则是奇函数。
3. 二次函数 f(x)=ax²+bx+c 的对称轴是 x=−b/(2a)。

**三个扣分点**：单调性要在**区间**上讨论（不能笼统说"在定义域上递增"）；奇偶性先看定义域是否关于原点对称；二次函数的最值与对称轴位置有关。

**四张图**：① 增函数与减函数的定义（任取两点）；② 奇偶性的图象对称（关于 y 轴 / 关于原点）；③ 二次函数的对称轴、顶点、单调区间；④ 含参二次函数在给定区间上的最值（分类）。

**互动模型**：滑块＝参数 a（−2 到 2，step 0.5），f(x)=x²−2ax
```js
axis = a;  min = -(a * a);   // 对称轴 x=a，最小值 −a²
```
`cases`：`{v:0,eq:{axis:0,min:0}}`、`{v:1,eq:{axis:1,min:-1}}`、`{v:2,eq:{axis:2,min:-4}}`。
Autopilot：`[{t:0,v:-2},{t:1.2,v:-2},{t:4,v:0},{t:6.5,v:0},{t:9,v:2},{t:11.5,v:2},{t:13.5,v:-2}]`，keys `[-2,0,2]`——停留帧在 a=0（对称轴是 y 轴，最小值在原点，此时还是偶函数）。
状态：a=0「偶函数，对称轴 x=0」；a>0「对称轴右移，减区间 (−∞,a)」；a<0「对称轴左移」。

**例题**：「求 f(x)=x²−2ax 在 [0,3] 上的最小值。」答案：讨论对称轴 a 与区间的关系：a<0 时最小 f(0)=0；0≤a≤3 时最小 f(a)=−a²；a>3 时最小 f(3)=9−6a。
**六问**：① 单调性为什么要在区间上说；② 奇偶性第一步看什么；③ 二次函数最值为什么要分类；④ 偶函数图象有什么对称性；⑤ 奇函数在 x=0 处一定为 0 吗；⑥ 单调区间能用并集写吗。
**易错**：✗ 说"在定义域上递增" / ✗ 奇偶性不看定义域 / ✗ 最值直接代端点 / ✗ 单调区间用 ∪ 连接 / ✗ 奇函数 f(0) 必为 0（定义域要含 0）/ ✗ 对称轴公式写成 b/(2a)。

- 出处一律写「人教A版必修第一册 · 第X章第Y节」，**不写页码**。
