## bx1-c5-s7 三角函数的应用

**课本原话**
1. 简谐运动：位移 y 与时间 t 的关系可用 y=Asin(ωt+φ) 描述。
2. 实际问题中的周期现象（潮汐、温度、交变电流）常用三角函数建模。
3. 建模步骤：设模型→由最值定 A、由周期定 ω、由特殊点定 φ→还原。

**三个扣分点**：A 由 (最大值−最小值)/2 定；b 由 (最大值+最小值)/2 定；φ 要用特殊点代入且注意范围。

**四张图**：① 简谐运动的三个参数；② 潮汐模型的图象与最值；③ 由最值、周期、特殊点反解参数；④ 建模流程与检验。

**互动模型**：滑块＝时间 t（0–24 时，step 0.5），潮高 h=3sin(πt/6)+5
```js
h = 3 * Math.sin(Math.PI * t / 6) + 5;
// 最大 8（t=3），最小 2（t=9），周期 12 小时
```
`cases`：`{v:0,eq:{h:5}}`、`{v:3,eq:{h:8}}`、`{v:6,eq:{h:5}}`、`{v:9,eq:{h:2}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:3},{t:6.5,v:3},{t:9,v:9},{t:11.5,v:12},{t:13.5,v:0}]`，keys `[0,3,9,12]`——停留帧在 t=3（涨到最高 8 米，之后开始落潮）。
状态：h 升「涨潮」；h=8「高潮」；h 降「落潮」；h=2「低潮」。

**例题**：「某港口水深 h(t)=3sin(πt/6)+5（t 为小时），求一天中水深的最大值、最小值与周期。」答案：最大 8、最小 2、周期 12 小时；一天 24 小时里涨落两次。
**六问**：① A 怎么由最值求；② 周期怎么由图象读；③ φ 怎么定；④ 为什么一天涨落两次；⑤ 模型能预测任意时刻吗；⑥ 实际数据与模型有偏差怎么办。
**易错**：✗ A 直接取最大值 / ✗ 周期读成半个周期 / ✗ φ 随便取 / ✗ 水平线 b 漏掉 / ✗ 单位（小时/分钟）不统一 / ✗ 忘了检验模型合理性。

## 通用约定（所有页一致）

- 出处一律写「人教A版必修第一册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
