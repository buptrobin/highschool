## bx1-c1-s1 集合的概念

**课本原话**
1. 一般地，我们把研究对象统称为元素，把一些元素组成的总体叫做集合。
2. 集合中的元素具有确定性、互异性、无序性。
3. 如果 a 是集合 A 的元素，就说 a 属于 A，记作 a∈A；否则记作 a∉A。

**三个扣分点**：互异性（同一个元素只算一次，"1,1,2"与"1,2"是同一个集合）；空集 ∅ 与 {0} 不是一回事；集合中的元素类型可以完全不同（数、点、式子）。

**四张图**：① 三性各一句（确定性/互异性/无序性）；② 元素与集合的符号表（∈ ∉，N N* Z Q R 各指什么）；③ 列举法与描述法对照；④ 互异性：{a,1,2} 里 a 取 1 或 2 时集合只剩 2 个元素。

**互动模型**：滑块＝集合 S={a,1,2} 里的参数 a（0–4，step 1）
```js
size = (a === 1 || a === 2) ? 2 : 3;      // 互异性：重复的元素只算一次
dup  = (a === 1 || a === 2) ? 1 : 0;
```
`cases`：`{v:0,eq:{size:3}}`、`{v:1,eq:{size:2}}`、`{v:2,eq:{size:2}}`、`{v:4,eq:{size:3}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:1},{t:6.5,v:1},{t:9,v:2},{t:11.5,v:4},{t:13.5,v:0}]`，keys `[0,1,2,4]`——停留帧在 a=1（元素从 3 个掉成 2 个，"同一个数只算一次"）。
状态：a=1 或 2「有重复元素，集合只有 2 个元素」；其他「3 个元素」。

**例题**：「已知集合 A={a+2, (a+1)², a²+3a+3}，若 1∈A，求 a 的值。」答案：分三种情况（三个元素分别等于 1）解出 a，再**回代检验互异性**，重复的舍去；重点在第 3 步的检验。
**六问**：① 集合的元素能不能重复；② ∅ 与 {0} 一样吗；③ {1,2} 与 {2,1} 是同一个集合吗；④ 0∈N 吗；⑤ 描述法的竖线前面写什么；⑥ 「高个子同学」能构成集合吗。
**易错**：✗ 元素可以重复 / ✗ ∅={0} / ✗ 集合中的顺序不同就是不同集合 / ✗ 0∉N / ✗ 描述法写 {x | x>1, x∈R} 的逗号写成竖线 / ✗ 高个子能构成集合（缺确定性）。

## 通用约定（所有页一致）

- 出处一律写「人教A版必修第一册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
- 禁止写「请拖动滑块」——自动演示时滑块的圆点会自己动，这才是提示。
