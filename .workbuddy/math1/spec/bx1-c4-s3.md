## bx1-c4-s3 对数

**课本原话**
1. 若 a^b=N（a>0，a≠1），则 b 叫做以 a 为底 N 的对数，记作 b=log_a N。
2. 对数恒等式：a^(log_a N)=N；log_a 1=0；log_a a=1。
3. 运算法则：log_a(MN)=log_a M+log_a N；log_a(M/N)=log_a M−log_a N；log_a M^n=n·log_a M。

**三个扣分点**：真数必须大于 0（求定义域必考）；log_a(M+N) ≠ log_a M+log_a N（法则只对乘除）；换底公式记反（log_a b=1/log_b a）。

**四张图**：① 指数式与对数式的互化；② 三个特殊值（1、0、自身）；③ 运算法则三条；④ 换底公式与常用对数（lg、ln）。

**互动模型**：滑块＝指数 k（0–10，step 1），N=2^k
```js
n = 2 ** k;        // 真数
lg = k;            // log₂N = k
lg2n = k + 1;      // log₂(2N) = k+1，乘变加
lg2sq = 2 * k;     // log₂(N²) = 2k，乘方变乘
```
`cases`：`{v:0,eq:{n:1,lg:0}}`、`{v:3,eq:{n:8,lg:3}}`、`{v:10,eq:{n:1024,lg:10}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:3},{t:6.5,v:3},{t:9,v:6},{t:11.5,v:10},{t:13.5,v:0}]`，keys `[0,3,6,10]`——停留帧在 k=3（N=8，log₂8=3，再加一倍就加 1）。
状态：N=1「对数为 0」；N 每翻倍「对数加 1」；N=2^k「对数正好是 k」。

**例题**：「计算 log₂8 + log₂(1/4)。」答案：log₂8=3，log₂(1/4)=log₂(2^(−2))=−2，和为 1。
**六问**：① 真数为什么必须大于 0；② log_a(M+N) 能拆吗；③ 换底公式怎么写；④ lg 与 ln 分别以什么为底；⑤ log_a 1 等于多少；⑥ 负数和 0 有对数吗。
**易错**：✗ log(M+N)=logM+logN / ✗ 真数可以 ≤0 / ✗ 换底公式写反 / ✗ lg 是以 e 为底 / ✗ log_a a=0 / ✗ 对数运算法则可以用于加减。
