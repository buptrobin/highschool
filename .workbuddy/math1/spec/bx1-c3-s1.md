## bx1-c3-s1 函数的概念及其表示

**课本原话**
1. 设 A、B 是非空的实数集，如果对于集合 A 中的任意一个数 x，按照某种确定的对应关系 f，在集合 B 中都有唯一确定的数 y 和它对应，那么就称 f：A→B 为从集合 A 到集合 B 的一个函数。
2. 函数的三要素：定义域、对应关系、值域。
3. 分段函数：在定义域的不同部分有不同的对应关系，但它是一个函数。

**三个扣分点**：定义域优先（做题第一步）；判断"同一函数"要看定义域和对应关系都相同；分段函数在分界点要看清归哪一段。

**四张图**：① 函数定义的三个关键词（任意、唯一、实数集）；② 三要素与常见定义域限制（分母、偶次根、对数）；③ 分段函数的图象与分界点；④ 判断同一函数的三步。

**互动模型**：滑块＝x（−3 到 5，step 0.5），分段函数 f(x) 在 x<0 时取 x²，0≤x<2 时取 2x，x≥2 时取 4−x
```js
y = x < 0 ? x * x : x < 2 ? 2 * x : 4 - x;
seg = x < 0 ? 0 : x < 2 ? 1 : 2;      // 用哪一段
```
`cases`：`{v:-2,eq:{y:4,seg:0}}`、`{v:1,eq:{y:2,seg:1}}`、`{v:3,eq:{y:1,seg:2}}`、`{v:2,eq:{y:2,seg:2}}`。
Autopilot：`[{t:0,v:-3},{t:1.2,v:-3},{t:4,v:0},{t:6.5,v:1},{t:9,v:2},{t:11.5,v:3},{t:13.5,v:-3}]`，keys `[-3,0,1,3]`——停留帧在 x=2（分界点，归第三段，值从 2x 的 4 掉到 4−x 的 2）。
状态：x<0「第一段 x²」；0≤x<2「第二段 2x」；x≥2「第三段 4−x」。

**例题**：「已知 f(x)=…（上述分段），求 f(f(−1))。」答案：先算 f(−1)=(−1)²=1；再算 f(1)=2×1=2，所以 f(f(−1))=2。
**六问**：① 函数定义里"唯一确定"是什么意思；② 定义域怎么先求；③ 分段函数是几个函数；④ 判断同一函数看哪两点；⑤ 分界点归哪一段；⑥ 值域怎么求。
**易错**：✗ 分段函数是两个函数 / ✗ 求 f(f(a)) 不先算内层 / ✗ 只看解析式判同一函数 / ✗ 定义域写成空集或忽略 / ✗ 分界点两边都算进去 / ✗ 把"对应关系"当成"公式"。

## 通用约定（所有页一致）

- 出处一律写「人教A版必修第一册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
- 禁止写「请拖动滑块」——自动演示时滑块的圆点会自己动，这才是提示。
