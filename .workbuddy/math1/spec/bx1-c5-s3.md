## bx1-c5-s3 诱导公式

**课本原话**
1. 公式一：sin(α+2kπ)=sinα，cos(α+2kπ)=cosα，tan(α+2kπ)=tanα（k∈Z）。
2. 公式二：sin(π+α)=−sinα，cos(π+α)=−cosα。
3. 诱导公式的记忆口诀：奇变偶不变，符号看象限。

**三个扣分点**："奇变偶不变"的奇偶看的是 **k·π/2 里的 k**；"符号看象限"是把 α 当锐角时原函数的符号；化简要一步一步来，别跳。

**四张图**：① 公式一到四的对照表；② 奇变偶不变的判定（k 的奇偶）；③ 符号看象限的判定；④ 化简流程（负化正、大化小、小化锐）。

**互动模型**：滑块＝k（0–7，step 1），α=30°，求 sin(α+k·π/2)
```js
// k 偶：函数名不变；k 奇：函数名变（sin↔cos）
// 符号：把 α 看作锐角，判断 α+k·π/2 所在象限中原函数的符号
val = [0.5, 0.866, -0.5, -0.866][k % 4];
name = k % 2 === 0 ? "sin" : "cos";
```
`cases`：`{v:0,eq:{val:0.5}}`、`{v:1,eq:{val:0.866}}`、`{v:2,eq:{val:-0.5}}`、`{v:3,eq:{val:-0.866}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:1},{t:6.5,v:2},{t:9,v:2},{t:11.5,v:3},{t:13.5,v:0}]`，keys `[0,1,2,3]`——停留帧在 k=2（sin(π+α)=−sinα，名字不变、符号变）。
状态：k 偶「函数名不变（sin 还是 sin）」；k 奇「函数名变成 cos」。

**例题**：「化简 sin(π+α)·cos(−α)/tan(π−α)。」答案：sin(π+α)=−sinα；cos(−α)=cosα；tan(π−α)=−tanα；原式 =(−sinα·cosα)/(−tanα)=cos²α。
**六问**：① 奇变偶不变里的奇偶指什么；② 符号看象限是怎么看的；③ sin(−α) 与 sinα 的关系；④ tan(π+α) 等于多少；⑤ 化简的顺序是什么；⑥ 诱导公式一共有几组。
**易错**：✗ 把 α 的象限当结果符号 / ✗ 奇偶看 α 的大小 / ✗ sin(−α)=sinα / ✗ tan(π−α)=tanα / ✗ 只变号不变名 / ✗ 化简跳步导致符号丢。
