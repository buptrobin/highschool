## bx1-c5-s4 三角函数的图象与性质

**课本原话**
1. 正弦函数 y=sinx 的定义域是 R，值域是 [−1,1]，最小正周期是 2π。
2. 正弦函数在 [−π/2+2kπ, π/2+2kπ] 上递增，在 [π/2+2kπ, 3π/2+2kπ] 上递减。
3. 正切函数 y=tanx 的定义域是 {x | x≠π/2+kπ}，最小正周期是 π。

**三个扣分点**：周期：sin/cos 是 2π、tan 是 π；单调区间要写 +2kπ（漏 k 就是错）；对称轴与对称中心不要混。

**四张图**：① 正弦曲线与五个关键点；② 余弦曲线；③ 正切曲线与渐近线；④ 周期、奇偶、单调、对称的四栏表。

**互动模型**：滑块＝角 x（0–360°，step 15°）
```js
sin = Math.sin(x * Math.PI / 180);
cos = Math.cos(x * Math.PI / 180);
```
`cases`：`{v:30,eq:{sin:0.5,cos:0.866}}`、`{v:90,eq:{sin:1,cos:0}}`、`{v:180,eq:{sin:0,cos:-1}}`、`{v:270,eq:{sin:-1,cos:0}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:90},{t:6.5,v:180},{t:9,v:180},{t:11.5,v:270},{t:13.5,v:0}]`，keys `[0,90,180,270]`——停留帧在 180°（sin 从 1 掉到 0、cos 到 −1，两者的波峰差半个周期）。
状态：sin 增/减由 x 所在区间决定；cos 与 sin 差 π/2。

**例题**：「求 y=2sin(2x−π/3) 的最小正周期与最大值。」答案：T=2π/2=π；最大值为 2（振幅），在 2x−π/3=π/2+2kπ 时取到。
**六问**：① sin 与 tan 的周期分别是多少；② 单调区间为什么要加 2kπ；③ 对称轴与对称中心怎么求；④ 余弦与正弦图象差多少；⑤ tan 的定义域；⑥ 最大值由振幅决定吗。
**易错**：✗ tan 周期写成 2π / ✗ 单调区间漏 2kπ / ✗ 对称中心写成对称轴 / ✗ 定义域漏 π/2+kπ / ✗ 把振幅当最大值以外的量 / ✗ 周期公式写成 2π·ω。

- 出处一律写「人教A版必修第一册 · 第X章第Y节」，**不写页码**。
