## bx1-c5-s1 任意角和弧度制

**课本原话**
1. 角的顶点与原点重合，角的始边与 x 轴的非负半轴重合，终边落在第几象限，就说这个角是第几象限角。
2. 与角 α 终边相同的角的集合：{β | β=α+k·360°，k∈Z}。
3. 1 rad 的角：长度等于半径长的圆弧所对的圆心角；l=|α|r，S=½lr。

**三个扣分点**：终边相同的角差 360° 的整数倍（不是 180°）；象限角不含轴线角；弧度与角度互化要用 π。

**四张图**：① 象限角与轴线角；② 终边相同的角（多圈）；③ 弧度制的定义（弧长=半径）；④ 弧长、扇形面积公式。

**互动模型**：滑块＝角 θ（0–720°，step 15°）
```js
rad = θ * Math.PI / 180;
cot = θ % 360;                                  // 终边相同的最小正角
quad = cot % 90 === 0 ? 0 : Math.floor(cot / 90) + 1;   // 0 表示轴线角
```
`cases`：`{v:30,eq:{rad:0.5236,cot:30,quad:1}}`、`{v:390,eq:{rad:6.8068,cot:30,quad:1}}`、`{v:180,eq:{rad:3.1416,cot:180,quad:0}}`。
Autopilot：`[{t:0,v:30},{t:1.2,v:30},{t:4,v:180},{t:6.5,v:180},{t:9,v:390},{t:11.5,v:390},{t:13.5,v:30}]`，keys `[30,180,390]`——停留帧在 390°（转了一整圈还多 30°，终边与 30° 完全重合）。
状态：cot=0/90/180/270「轴线角（不在任何象限）」；其他「第 n 象限角」。

**例题**：「把 −120° 化为弧度，并写出与它终边相同的角的集合。」答案：−120°=−120×π/180=−2π/3；集合 {β | β=−2π/3+2kπ，k∈Z}。
**六问**：① 终边相同的角差多少；② 轴线角算象限角吗；③ 1 rad 是多少度；④ 弧长公式里的角要用什么单位；⑤ −120° 在第几象限；⑥ 扇形面积公式与弧长什么关系。
**易错**：✗ 终边相同差 180° / ✗ 轴线角也归入象限 / ✗ 弧长公式用角度 / ✗ 度化弧度不乘 π/180 / ✗ 集合漏写 k∈Z / ✗ 负角不算角。

## 通用约定（所有页一致）

- 出处一律写「人教A版必修第一册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
- 禁止写「请拖动滑块」——自动演示时滑块的圆点会自己动，这才是提示。
