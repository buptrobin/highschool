## bx1-c2-s3 二次函数与一元二次方程、不等式

**课本原话**
1. 二次函数 y=ax²+bx+c 的图象与 x 轴交点的横坐标，就是方程 ax²+bx+c=0 的根。
2. 判别式 Δ=b²−4ac：Δ>0 有两个不等实根；Δ=0 有两个相等实根；Δ<0 没有实根。
3. 解一元二次不等式要"看开口、算判别式、求根、写解集"。

**三个扣分点**：二次项系数为负要先乘 −1 **并变号**；Δ=0 时解集是"x≠根"而不是空集；解集的"或"与"且"不能混（>0 取两边、<0 取中间）。

**四张图**：① 抛物线开口、判别式与 x 轴交点的三类图；② 三个二次关系的对照表；③ 解集在数轴上的取法；④ 含参二次不等式（按 a 分类）。

**互动模型**：滑块＝常数项 c（−3 到 3，step 0.5），函数 y=x²−2x+c
```js
disc  = 4 - 4 * c;
roots = disc > 0 ? 2 : disc === 0 ? 1 : 0;
```
`cases`：`{v:0,eq:{disc:4,roots:2}}`、`{v:1,eq:{disc:0,roots:1}}`、`{v:2,eq:{disc:-4,roots:0}}`。
Autopilot：`[{t:0,v:-3},{t:1.2,v:-3},{t:4,v:1},{t:6.5,v:1},{t:9,v:2},{t:11.5,v:2},{t:13.5,v:-3}]`，keys `[-3,0,1,2]`——停留帧在 c=1（判别式为 0，抛物线与 x 轴相切，解集是 x≠1）。
状态：c<1「两个交点，解集取两边」；c=1「相切，解集 x≠1」；c>1「无交点，解集是 R」。

**例题**：「解不等式 x²−2x−3>0。」答案：因式分解 (x−3)(x+1)>0，两根 −1、3，开口向上、取两边，解集 {x|x<−1 或 x>3}。
**六问**：① 判别式三种情况各对应几个交点；② Δ=0 时解集怎么写；③ 二次项系数为负怎么办；④ "取两边"还是"取中间"由什么决定；⑤ 含参不等式为什么要分类；⑥ 不等式的解集能用区间写吗。
**易错**：✗ Δ=0 时解集是空集 / ✗ 二次项系数为负不变号 / ✗ 取两边与取中间搞反 / ✗ 因式分解符号错 / ✗ 含参不分类 / ✗ 把方程的根直接当解集端点却不判开闭。

## 通用约定（所有页一致）

- 出处一律写「人教A版必修第一册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
- 禁止写「请拖动滑块」——自动演示时滑块的圆点会自己动，这才是提示。
