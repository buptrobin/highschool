## bx1-c4-s5 函数的应用（二）

**课本原话**
1. 对于函数 y=f(x)，使 f(x)=0 的实数 x 叫做函数的零点。
2. 如果函数 y=f(x) 在区间 [a,b] 上的图象是一条连续不断的曲线，且有 f(a)·f(b)<0，那么函数在区间 (a,b) 内至少有一个零点。
3. 二分法：不断把零点所在的区间一分为二，使区间的两个端点逐步逼近零点。

**三个扣分点**：零点存在定理只保证"至少一个"，不保证唯一；f(a)f(b)<0 是充分不必要条件；零点不是点，是**数**。

**四张图**：① 零点与方程根、图象交点的三重身份；② 零点存在定理的图示；③ 二分法流程；④ 唯一零点的条件（再加单调）。

**互动模型**：滑块＝x（1 到 2，step 0.05），f(x)=x³−x−1
```js
f = x*x*x - x - 1;
// f(1)=−1<0，f(2)=5>0 ⇒ 零点在 (1,2)，二分 8 次后误差 < 1/256
```
`cases`：`{v:1,eq:{f:-1}}`、`{v:1.25,eq:{f:-0.2969}}`、`{v:1.5,eq:{f:0.875}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:1.25},{t:6.5,v:1.5},{t:9,v:1.5},{t:11.5,v:2},{t:13.5,v:1}]`，keys `[1,1.25,1.5,2]`——停留帧在 x=1.5（f 由负变正，零点就在这附近，约 1.3247）。
状态：f<0「零点在右边」；f=0「找到了」；f>0「零点在左边」。

**例题**：「证明 f(x)=x³−x−1 在 (1,2) 内存在零点，并估计它。」答案：f(1)=−1<0，f(2)=5>0，图象连续，由零点存在定理得至少一个零点；继续算 f(1.5)=0.875>0，零点在 (1,1.5)；二分若干次后约为 1.32。
**六问**：① 零点是什么；② 零点存在定理的条件；③ 定理能保证唯一吗；④ 二分法什么时候停；⑤ f(a)f(b)>0 说明什么；⑥ 零点与方程根的关系。
**易错**：✗ 零点是一个点 / ✗ 定理保证唯一 / ✗ f(a)f(b)>0 就无零点 / ✗ 二分法不需要连续 / ✗ 零点存在就等于能求出精确值 / ✗ 区间端点可以取。
