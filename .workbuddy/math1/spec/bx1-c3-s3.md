## bx1-c3-s3 幂函数

**课本原话**
1. 一般地，形如 y=x^α 的函数叫做幂函数，其中 α 为常数。
2. 幂函数 y=x^α 的图象都过点 (1,1)。
3. 当 α>0 时，幂函数在 (0,+∞) 上单调递增；当 α<0 时，在 (0,+∞) 上单调递减。

**三个扣分点**：幂函数要"系数为 1、指数是常数"（y=2x² 不是幂函数）；α<0 时在 (0,+∞) 递减且不过原点；α 为偶数/奇数决定奇偶性。

**四张图**：① 五个常见幂函数图象（α=1,2,3,1/2,−1）；② 都过 (1,1) 的共同点；③ α 的正负与单调性；④ α 决定奇偶性与定义域。

**互动模型**：滑块＝指数 α（−2 到 3，step 0.5）
```js
y1 = 1;                     // 都过 (1,1)
y2 = Math.pow(2, α);        // x=2 处的函数值
mono = α > 0 ? 1 : α === 0 ? 0 : -1;   // 1 增、0 常、−1 减
```
`cases`：`{v:-1,eq:{y2:0.5,mono:-1}}`、`{v:0.5,eq:{y2:1.414,mono:1}}`、`{v:2,eq:{y2:4,mono:1}}`。
Autopilot：`[{t:0,v:-2},{t:1.2,v:-2},{t:4,v:-1},{t:6.5,v:0.5},{t:9,v:2},{t:11.5,v:3},{t:13.5,v:-2}]`，keys `[-2,-1,0.5,2]`——停留帧在 α=−1（递减、不过原点、x=2 时只有 0.5）。
状态：α>0「(0,+∞) 递增」；α=0「y=1（x≠0），常函数」；α<0「(0,+∞) 递减」。

**例题**：「已知幂函数 f(x)=x^(m²−2m−3)（m∈Z）在 (0,+∞) 上单调递减，求 m。」答案：递减要求指数 <0，即 m²−2m−3<0，得 −1<m<3，m∈Z 取 m=0,1,2。
**六问**：① y=2x² 是幂函数吗；② 幂函数的图象都过哪个点；③ α<0 时图象在哪几个象限；④ α 为偶数时是奇函数还是偶函数；⑤ y=x⁰ 与 y=1 一样吗；⑥ 幂函数与指数函数的区别。
**易错**：✗ 系数不为 1 也叫幂函数 / ✗ 认为都过 (0,0) / ✗ α<0 时还过原点 / ✗ 幂函数与指数函数混 / ✗ 偶函数判断只看指数正负 / ✗ y=x⁰ 与 y=1 完全相同。

- 出处一律写「人教A版必修第一册 · 第X章第Y节」，**不写页码**。
