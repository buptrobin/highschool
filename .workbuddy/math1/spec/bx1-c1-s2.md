## bx1-c1-s2 集合间的基本关系

**课本原话**
1. 如果集合 A 的任何一个元素都是集合 B 的元素，就说 A 是 B 的子集，记作 A⊆B。
2. 如果 A⊆B，且存在元素 x∈B 而 x∉A，就说 A 是 B 的真子集，记作 A⫋B。
3. 不含任何元素的集合叫做空集，记作 ∅，规定 ∅ 是任何集合的子集。

**三个扣分点**：空集是任何集合的子集（漏掉"空集这一支"是最常见失分）；n 元集合的子集有 2ⁿ 个；A⊆B 与 A⫋B 的区别（相等时只是子集不是真子集）。

**四张图**：① 子集与真子集的 Venn 对照；② 空集的三条规定；③ n 元集合子集个数 2ⁿ 的来历（每个元素"取或不取"）；④ 数轴上区间的包含关系。

**互动模型**：滑块＝集合元素个数 n（0–8，step 1）
```js
sub  = 2 ** n;          // 子集个数
proper = sub - 1;       // 真子集（去掉自身）
nonEmptyProper = sub - 2;  // 非空真子集（再去掉 ∅）
```
`cases`：`{v:0,eq:{sub:1,proper:0}}`、`{v:3,eq:{sub:8,proper:7}}`、`{v:8,eq:{sub:256,proper:255}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:3},{t:6.5,v:3},{t:9,v:5},{t:11.5,v:8},{t:13.5,v:0}]`，keys `[0,3,5,8]`——停留帧在 n=3（8 个子集，正好能一个个列出来）。
状态：n=0「只有 ∅ 一个子集，没有真子集」；n≥1「子集 2ⁿ 个，真子集少 1 个」。

**例题**：「已知 A={1,2}，B={x | x⊆A}，求 B 的元素个数。」答案：B 的元素是 A 的所有子集：∅、{1}、{2}、{1,2}，共 4 个；**注意 B 的元素本身是集合**。
**六问**：① ∅ 是任何集合的子集吗；② ∅ 是任何集合的真子集吗；③ {1,2} 的子集有几个；④ A⊆B 且 B⊆A 说明什么；⑤ 0 与 ∅ 的关系；⑥ B={x|x⊆A} 这种"集合的集合"怎么数。
**易错**：✗ 空集不是任何集合的真子集（错在"真"）/ ✗ 子集个数是 n / ✗ A⊆B 就意味着 A 比 B 小 / ✗ {∅} 就是 ∅ / ✗ 2 元集合有 3 个子集 / ✗ 忘记"集合本身"也是子集。
