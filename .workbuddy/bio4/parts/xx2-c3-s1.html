01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 生态系统的概念人教版（2019）选择性必修2 · 第3章第1节

生态系统是由生物群落与它的无机环境相互作用而形成的统一整体。

→ 翻成人话：这句话由两个条件组成：①生物群落（不是「所有生物」这种散装说法，是群落）；②它的无机环境（光、水、气、土、无机盐）。两个条件之间还要相互作用——只把生物摆在那里、不与无机环境交换物质和能量，就不叫生态系统。

课本原话 · 组成成分人教版（2019）选择性必修2 · 第3章第1节

生态系统的组成成分包括非生物的物质和能量、生产者、消费者、分解者。

→ 翻成人话：这是四个并列成分，不是「三大类」也不是「生物部分＋非生物部分」就完事。答题要四个都点到名字，顺序照课本写；漏掉「非生物的物质和能量」、把光能单独拎出来当一个成分，都是原话没背住。

课本原话 · 营养结构人教版（2019）选择性必修2 · 第3章第1节

食物链和食物网是生态系统的营养结构，是物质循环和能量流动的渠道。

→ 翻成人话：这句话给营养结构定了三个条件：①由生产者与消费者构成（分解者不进来）；②箭头方向＝物质和能量的去向，指向捕食者；③它的身份是「渠道」，所以第2节讲能量流动、第3节讲物质循环，都要回到这张网。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 能量逐级递减的解释题必考

某草原生态系统中，生产者固定的能量为 1.0×10⁶ kJ。若能量传递效率按 10% 计算，回答：(1) 第三营养级最多可获得多少能量？占生产者固定能量的百分之几？(2) 为什么食物链一般不超过 4–5 个营养级？

  1. 第 1 步 · 定起点、数级数

    第三营养级＝从生产者数起的第 3 格：生产者是第 1 营养级，初级消费者第 2，次级消费者第 3。所以能量只传递了 2 次（3−1），不是 3 次。

    用到：营养级从生产者起数；传递次数＝n−1。

  2. 第 2 步 · 写公式

    设生产者固定的能量为 E，则第 n 营养级获得的能量为 Eₙ = E × (10%)^(n−1)；本题 E = 1.0×10⁶ kJ，n = 3。

    用到：逐级递减，数学形式是等比数列。

  3. 第 3 步 · 代数字

    E₃ = 1.0×10⁶ × (0.1)² = 1.0×10⁶ × 0.01 = 1.0×10⁴ kJ；占生产者固定的比例就是 0.1² = 1%。

    用到：10% 的平方是 1%，不是 10% 的一半。

  4. 第 4 步 · 推到第 5 营养级

    n = 5 时 E₅ = 1.0×10⁶ × (0.1)⁴ = 100 kJ，只有生产者固定量的 0.01%。这点能量在传递途中还要被呼吸消耗、被未利用部分截留，能真正变成个体有机物的更少。

    用到：递减是乘法，不是减法。

  5. 第 5 步 · 落到结论句

    所以答案不是「因为营养级越高动物越大」，而是：能量沿食物链逐级递减、传递效率只有 10%–20%，到第 4、第 5 营养级时剩下的能量已不足以维持一个种群的生存。

    用到：结论必须落到「能量不足以维持种群」。

1 / 5

标准答案（可抄进答题卡）

(1) 第三营养级获得的能量 = 1.0×10⁶ kJ × (10%)² = 1.0×10⁴ kJ，占生产者固定能量的 1%。
(2) 能量沿食物链逐级递减，相邻营养级间的传递效率只有 10%–20%；营养级越多，到达高营养级的能量越少，到第 4、第 5 营养级时能量已不足以维持种群的生存，因此食物链一般不超过 4–5 个营养级。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「生态系统到底由哪些成分组成？」

四个并列成分：非生物的物质和能量、生产者、消费者、分解者。答题时四个都要点名，不能只写「生物部分＋非生物部分」；光能归入「非生物的物质和能量」，不单独算一个成分。

「生产者为什么被称为基石？」

因为它自养：靠光合作用或化能合成把无机物合成有机物，把能量固定下来送进生物群落。没有它，消费者和分解者都没有有机物来源——生产者是基石。

「分解者能去掉吗？反正它不吃活的。」

不能。分解者不可缺：它把动植物遗体和排遗物中的有机物分解成 CO₂、H₂O、无机盐，还给无机环境被生产者重新利用。去掉它，有机物只进不出，物质循环中断，生态系统无法自我维持。

「食物链能不能写成『阳光 → 草 → 兔』？」

不能。食物链起点必须是生产者：箭头表示物质和能量从被吃者流向吃它的生物，阳光不是生物、也不会被草「吃」，所以不能当第一环。同理，分解者也不写进食物链。

「营养级越高，能量越多还是越少？」

越少。能量沿食物链逐级递减，传递效率只有 10%–20%：第 n 营养级只拿到前一级的十分之一左右，所以营养级越高，可用能量越少、个体数量通常也越少。

「食物网比食物链多了什么？」

多了交错：多条食物链彼此交叉，同一种生物可以同时占几个营养级，某种食物少了还有替代来源。所以食物网比单条食物链更稳定，抵抗外界干扰的能力更强。

六问其实是同一件事：成分定角色，链定位置。成分里生产者和分解者不能缺；链上第一个必须是生产者，越往后能量越少。把这两句写稳，本节的选择题和简答题都不会跑偏。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 食物链：阳光 → 草 → 兔 → 狐

✓ 食物链：草 → 兔 → 狐

错在哪：食物链起点必须是生产者。阳光不是生物，也不是被草捕食的对象，它只是非生物的物质和能量。

✗ 草 → 兔 → 狐 → 分解者

✓ 草 → 兔 → 狐（分解者另列组成成分）

错在哪：分解者不参与捕食关系，不占食物链上的位置；它处理的是所有营养级的遗体，写进链里就破坏了「箭头＝捕食」的规则。

✗ 消费者是生态系统必不可少的成分

✓ 生产者是基石，分解者不可缺；消费者一般不是必需的

错在哪：把「加快物质循环」当成「必需」。人工生态缸里可以没有消费者，但不能没有生产者和分解者。

✗ 分解者可有可无，只是清理垃圾的

✓ 分解者不可缺：把有机物分解为无机物，保证物质循环进行

错在哪：少了它，碳氮等元素锁在遗体里回不到无机环境，物质循环中断，生产者也会因原料耗尽而垮掉。生产者是基石、分解者守回路，两者缺一不可。

✗ 营养级越高，积累的能量越多

✓ 能量沿食物链逐级递减，营养级越高能量越少

错在哪：把「生物个体更大」误当成「能量更多」。第 n 营养级只有前一级的约 10%，n=3 时只剩 1%。

✗ 能量传递效率是 100%，能量守恒所以不损失

✓ 相邻营养级间传递效率为 10%–20%

错在哪：能量确实守恒，但大量能量以呼吸作用的热能散失、还有未被利用的部分，能流到下一级的只有一小部分。

✗ 食物网就是几条食物链加起来

✓ 食物网是食物链彼此交错形成的复杂营养关系

错在哪：「相加」是并列，食物网的要点是交叉——同一生物占多个营养级，一种食物消失还有替代，这才带来稳定性。
