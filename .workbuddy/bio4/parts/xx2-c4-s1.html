生态足迹是面积，不是排放量；足迹超过承载力就是生态赤字；可持续发展是不超过承载力地继续发展。

这一节是第4章「人与环境」的开头：先把人对生态的影响换算成一把统一的尺子——面积，再用「几个地球」把全球超载说清楚，最后落到可持续发展的定义上。最容易错的一件事：把生态足迹当成「排放量」或「污染量」。它是把资源消耗和废物吸纳都折算成的土地与水域面积，单位是全球公顷。

01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 生态足迹的概念人教版（2019）选择性必修2 · 第4章第1节

生态足迹（生态占用）是指维持某一人口单位生存所需的生产资源和吸纳废物的土地及水域面积。

→ 翻成人话：这句话由四个条件组成：①一个「人口单位」（一个人、一座城、一个国家、全球）；②要维持它生存；③既算消耗的生产资源，也算吸纳废物；④最后统一折算成土地及水域面积。少掉第④个条件，就写成了「排放量」——这是本页第一号扣分点。

课本原话 · 足迹大小的意义人教版（2019）选择性必修2 · 第4章第1节

生态足迹越大，对生态环境的影响越大。

→ 翻成人话：足迹是影响大小的度量，不是「好坏的评价」。所以题目问「影响大小」答足迹；问「是否超载」要拿足迹和生态承载力比，两个量比出来才叫赤字。

课本原话 · 全球现状与出路人教版（2019）选择性必修2 · 第4章第1节

全球生态足迹已超过地球的生态承载力，需要走可持续发展道路。

→ 翻成人话：这句话有三个条件：①比较的对象是全球；②比较的结果是足迹 > 承载力；③结论是「走可持续发展道路」。注意结论不是「停止发展」——可持续发展是发展不越过承载力，不是不发展。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 生态足迹计算与结论必考

某国人均生态足迹为 4.0 全球公顷，全球人均生物承载力为 1.7 全球公顷。请回答：（1）说明该国的人均资源消耗与全球平均水平相比处于什么状况；（2）从生态足迹角度说明该国应选择怎样的发展道路。陷阱：题干问的是「面积」还是「排放量」。

  1. 第 1 步 · 审题：先对单位

    4.0 与 1.7 都是「全球公顷 / 人」，是同一个面积口径，可以直接比较；这一步不做单位换算，只确认能比。

    用到：生态足迹的单位是面积（全球公顷），不是排放量。

  2. 第 2 步 · 定性：和谁比、比出什么

    4.0 > 1.7，需求大于供给，说明该国人均占用的生物生产性面积超过了全球人均可提供的水平，已经出现生态赤字。

    用到：足迹 > 承载力 → 生态赤字（不是「足迹小叫赤字」）。

  3. 第 3 步 · 定量：折算成几个地球

    earth = 4.0 ÷ 1.7 ≈ 2.35，约需 2.4 个地球才能维持该国人均消费水平；超出的 1.4 个地球就是靠透支生态资本换来的。

    用到：需要几个地球 = 足迹 ÷ 承载力，比值无单位。

  4. 第 4 步 · 下结论：落到「道路」上

    该国必须走可持续发展道路：在满足当代人需求的同时，把生态足迹控制在承载力以内，不危及后代人满足其需求的能力。注意结论是「改变发展方式」，不是「停止发展」。

    用到：可持续发展的两个条件必须同时成立。

  5. 第 5 步 · 防陷阱：换个问法还答得出吗

    若题目改问「该国的污染物排放量是多少」，不能拿 4.0 直接当答案——4.0 是面积。若问「怎样减小足迹」，答提高资源利用率、优化能源结构、改变消费方式、控制人口增长，四条中写两条即可。

    用到：足迹是面积；减小足迹靠「效率 + 结构 + 人口」。

1 / 5

标准答案（可抄进答题卡）

（1）该国人均生态足迹 4.0 全球公顷，大于全球人均生物承载力 1.7 全球公顷，人均资源消耗与废物吸纳所需面积约为全球平均可供给水平的 2.4 倍（4.0 ÷ 1.7 ≈ 2.4），处于生态赤字状态，对生态环境的影响较大。
（2）应走可持续发展道路：在发展经济、满足当代人需求的同时，把生态足迹控制在生态承载力范围之内，不危及后代人满足其需求的能力；可通过提高资源利用率、改善能源结构、改变消费方式、控制人口增长来减小生态足迹。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「生态足迹的单位是吨碳还是公顷？」

是面积：全球公顷（gha），且通常是「全球公顷 / 人」。碳足迹虽然名字带「碳」，也要按吸纳这些 CO₂ 所需的面积折算后再相加，所以它的单位仍是面积，不是排放量。

「足迹比承载力小，是不是就叫生态赤字？」

反了。足迹超过承载力即生态赤字（需求 > 供给）；足迹小于承载力叫生态盈余。判据只有一个方向：f > 1.7。

「生态足迹只算耕地和工厂占地吧？」

不止。包括耕地、牧地、林地、建设用地、碳足迹五类生物生产性面积。前四类是「提供资源」，碳足迹是「吸纳废物」，废物也要占地，所以一起计入。

「可持续发展就是停止发展、回到原始生活？」

不是。可持续发展要同时满足两个条件：满足当代人的需求 + 不危及后代人满足其需求的能力。它约束的是发展方式——发展继续，只是足迹不越过承载力。

「怎样减小生态足迹？写三条就行？」

四条抓手：提高资源利用率、优化能源结构（多用可再生）、改变消费方式（少肉食、少私家车）、控制人口增长。前三条降的是人均 f，第四条降的是总需求。

「生态承载力是个固定常数，永远 1.7？」

不是。它是一定区域内持续提供的生物生产性面积，会随土地退化、技术提高、投入增加而变，也会随气候变化而变。1.7 只是本节的全球人均参照值，换区域、换年份都要换数。

六问其实是同一件事：先问单位（面积），再问比较（f 与 1.7），最后问结论（赤字 → 可持续发展）。顺序不乱，答题就不会把「排放量」写成足迹。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 生态足迹是指人类活动排放的污染物总量。

✓ 生态足迹是维持某一人口单位生存所需的生产资源和吸纳废物的土地及水域面积。

错在哪：把「面积」写成「排放量」。足迹的单位是面积（全球公顷），排放量只是被折算的原料之一。

✗ 生态足迹小于生态承载力，说明出现了生态赤字。

✓ 生态足迹超过生态承载力才出现生态赤字；小于承载力属于生态盈余。

错在哪：判据方向反了。赤字永远对应「需求 > 供给」。

✗ 可持续发展就是为了保护环境而停止发展。

✓ 可持续发展是既满足当代人的需求，又不危及后代人满足其需求的能力的发展。

错在哪：可持续发展不是停止发展，约束的是「不越过承载力」，不是「不发展」。

✗ 生态承载力是固定不变的常数，全球就是 1.7。

✓ 生态承载力会随土地状况、技术水平、投入和气候变化；1.7 只是本节用于比较的全球人均参照值。

错在哪：把口径当常数。换区域、换年份，参照值要换。

✗ 只有工业排放的 CO₂ 才计入生态足迹。

✓ 生态足迹包括耕地、牧地、林地、建设用地和碳足迹五类，碳足迹只是其中一项。

错在哪：漏掉四类资源型面积，也把「碳足迹」当成全部。

✗ 一个国家生态超载只影响自己，和其他国家无关。

✓ 生态赤字可通过贸易与资源输入转嫁，全球尺度上超载是共同的；全球足迹已超过承载力。

错在哪：忽略贸易转移与全球性。全球比较的结论才落到「走可持续发展道路」。

✗ 生态足迹越大说明经济越发达，所以越大越好。

✓ 生态足迹越大，对生态环境的影响越大；超过承载力即生态赤字。

错在哪：把「影响大小」当成「发展好坏」。足迹是度量，不是评价。
