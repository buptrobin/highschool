## xx2-c1-s1 种群的数量特征

**课本原话**
1. 种群在单位面积或单位体积中的个体数就是种群密度，它是种群最基本的数量特征。
2. 估算种群密度常用的方法有样方法和标记重捕法。
3. 标记重捕法：N（种群总数）= M（标记数）× n（重捕总数）÷ m（重捕中带标记的个体数）。

**三个扣分点**：种群密度是**最基本的数量特征**（其他特征都影响它）；标记重捕法的公式是 **M×n÷m**（分母是**重捕中有标记**的数，不是重捕总数）；标记物不能脱落、不能影响活动能力，否则估算**偏大**。

**四张图**：① 样方法（随机取样、多个样方取平均）；② 标记重捕法的操作流程；③ 公式里三个字母各指什么；④ 重捕数 m 太小时，估算值为什么会飘。

**互动模型**：滑块＝重捕个体中带标记的个数 m（2–40，标记数 M=50、重捕总数 n=100）
```js
N = 50 * 100 / m;          // 标记重捕法估算值
err = (N - 500) / 500 * 100;   // 与真实值 500 的相对误差（%）
```
`cases`：`{v:5,eq:{N:1000}}`、`{v:10,eq:{N:500}}`、`{v:25,eq:{N:200}}`。
Autopilot：`[{t:0,v:40},{t:1.2,v:40},{t:4,v:10},{t:6.5,v:10},{t:9,v:2},{t:11,v:25},{t:13,v:40}]`，keys `[2,10,25,40]`。
**停留帧在 m=10**（估算值正好 500＝真实值；m 再小，估算就越大越不准）。
状态：m≥10「估算稳定，接近真值」；5≤m<10「误差偏大」；m<5「m 太小，估算值严重偏大」。

**例题**：「某草地捕获 50 只鼠并标记后放回，一段时间后重捕 100 只，其中有标记的 10 只，估算鼠的种群数量。」答案：N=50×100÷10=500（只）。注意：若标记物脱落，重捕中 m 偏小，估算值会**偏大**。
**六问**：① 种群密度为什么是最基本的特征；② 标记重捕法的分母是什么；③ 标记物脱落会怎样；④ 样方法为什么要随机取样；⑤ 什么情况下不能用标记重捕法；⑥ 样方大小怎么定。
**易错**：✗ 公式写成 M×m÷n / ✗ 分母用重捕总数 / ✗ 标记物脱落只影响标记数 / ✗ 样方挑长得好的地方 / ✗ 种群密度是唯一特征 / ✗ 两次捕获间隔越短越好。

## xx2-c1-s2 种群数量的变化

**课本原话**
1. 种群在理想条件下呈「J」形增长：Nₜ=N₀λᵗ。
2. 在资源和空间有限的环境中，种群经过一定时间的增长后，数量趋于稳定，呈「S」形增长。
3. 「S」形增长曲线中，种群数量达到环境容纳量（K 值）后不再增加；在 K/2 时增长速率最大。

**三个扣分点**：J 形是**理想条件**（无环境阻力），S 形有**环境容纳量 K**；**K/2 时增长速率最快**（不是 K 时）；λ 是**相邻两代的倍数**（不是增长率）。

**四张图**：① 两种增长曲线放在同一坐标里（J 与 S 分岔）；② S 形曲线的 K 与 K/2；③ 增长速率曲线的峰值在 K/2；④ λ 与增长率的关系。

**互动模型**：滑块＝时间 t（0–15 代，N₀=10，J 形 λ=1.5，S 形 K=1000、r=0.5）
```js
J = 10 * Math.pow(1.5, t);
S = 1000 / (1 + 99 * Math.exp(-0.5 * t));
```
`cases`：`{v:5,eq:{J:75.9,S:109.5}}`、`{v:10,eq:{J:576.7,S:600}}`、`{v:15,eq:{J:4378.9,S:999.9}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:10},{t:6.5,v:10},{t:9,v:15},{t:11,v:7},{t:13,v:0}]`，keys `[0,7,10,15]`。
**停留帧在 t=10**（J 形已经 577，S 形才 600 且开始变平——两条线从这里分开）。
状态：t≤5「两条线还挨着」；t≥8「J 形继续翻倍，S 形趋向 K」。

**例题**：「某种群在理想条件下每代数量是上一代的 1.5 倍，N₀=10，第 5 代数量是多少？若改为有限环境（K=1000、r=0.5），第 5 代约多少？」答案：J 形 N=10×1.5⁵≈75.9；S 形约 109.5（公式 N=K/(1+((K−N₀)/N₀)e^(−rt))）。
**六问**：① J 形与 S 形的区别；② K 值是什么；③ 增长速率最大在哪；④ λ 与增长率一样吗；⑤ 为什么 S 形会趋于稳定；⑥ K/2 有什么应用。
**易错**：✗ K 值处增长最快 / ✗ J 形是自然状态下的常态 / ✗ λ 就是增长率 / ✗ S 形没有上限 / ✗ K 值固定不变（环境改变会变）/ ✗ S 形曲线是直线。

## xx2-c1-s3 影响种群数量变化的因素

**课本原话**
1. 影响种群数量变化的因素分为非密度制约因素和密度制约因素。
2. 非密度制约因素（如气温、干旱、火灾）对种群的作用强度与该种群的密度无关。
3. 密度制约因素（如食物、传染病）对种群的作用强度随种群密度增大而增强，是调节种群数量的重要因素。

**三个扣分点**：**密度制约 vs 非密度制约**要分清（食物、疾病属密度制约；气温、火灾属非密度制约）；K 值会随环境改变；**持续产量要用「剩余量」捕捞**（捕到 K/2 附近，保持最大增长速率）。

**四张图**：① 两类因素的对照；② 密度制约因素随密度增强；③ 不同捕捞强度下的种群走势；④ K/2 与最大持续产量。

**互动模型**：滑块＝每年捕捞比例 h（0–80%，内禀增长率 r=50%）
```js
g = (50 - h) / 100;        // 年净增长率（>0 增长、=0 稳定、<0 下降）
```
`cases`：`{v:20,eq:{g:0.3}}`、`{v:50,eq:{g:0}}`、`{v:70,eq:{g:-0.2}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:20},{t:6.5,v:20},{t:9,v:80},{t:11,v:50},{t:13,v:0}]`，keys `[0,20,50,80]`。
**停留帧在 h=50**（净增长恰好为 0：捕捞速度等于增长速度，种群数量稳定——最大持续产量的临界）。
状态：h<50「还能增长」；h=50「收支相抵」；h>50「长期会衰退甚至灭绝」。

**例题**：「某鱼群年增长率为 50%，每年捕捞多少比例能长期保持产量？」答案：捕捞比例应低于内禀增长率（50%）；把种群维持在 K/2 附近时增长速率最大，可获得最大持续产量。
**六问**：① 两类因素怎么区分；② 温度属于哪类；③ 为什么不能捕到 K/2 以下；④ K 值会变吗；⑤ 密度制约因素为什么能调节数量；⑥ 最大持续产量的原理。
**易错**：✗ 气温属于密度制约因素 / ✗ 种群越小增长越快（低于 K/2 反而更慢）/ ✗ K 值永远不变 / ✗ 捕捞越多产量越高 / ✗ 疾病属于非密度制约 / ✗ 数量下降与密度无关。

## xx2-c2-s1 群落的结构

**课本原话**
1. 群落是指同一时间内聚集在一定区域中各种生物种群的集合。
2. 群落中各个生物种群分别占据了不同的空间，使群落形成一定的空间结构，包括垂直结构和水平结构。
3. 生态位是指一个物种在群落中的地位或作用，包括所处的空间位置、占用资源的情况以及与其它物种的关系等。

**三个扣分点**：**垂直结构是分层**（光照、食物决定）、**水平结构是镶嵌分布**（地形、湿度决定），两者别混；生态位重叠越多，**竞争越激烈**；群落是**所有生物**（不只植物）。

**四张图**：① 群落的垂直分层（乔木—灌木—草本）；② 水平结构的镶嵌分布；③ 生态位的三维示意（空间、资源、关系）；④ 生态位重叠与竞争强度。

**互动模型**：滑块＝两个物种的生态位重叠度 o（0–100%）
```js
comp = o / 100;                     // 竞争强度（0–1）
coexist = comp < 0.8 ? 1 : 0;       // 重叠超过 80% 后难以长期共存
```
`cases`：`{v:0,eq:{comp:0}}`、`{v:50,eq:{comp:0.5}}`、`{v:90,eq:{comp:0.9}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:50},{t:6.5,v:50},{t:9,v:100},{t:11,v:70},{t:13,v:0}]`，keys `[0,50,70,100]`。
**停留帧在 o=50**（重叠一半：还能共存，但已出现明显的资源竞争——生态位分化的起点）。
状态：o<30「几乎不竞争，容易共存」；30–80「部分重叠，出现竞争」；>80「严重重叠，通常一方被排除或分化」。

**例题**：「同一片森林里，几种鸟都在树上取食昆虫，为什么能共存？」答案：它们的取食高度、时间或食物大小不同（生态位分化），生态位重叠小、竞争弱，因此能共存。
**六问**：① 垂直结构与水平结构的区别；② 生态位包括什么；③ 重叠越多会怎样；④ 群落是否只指植物；⑤ 竞争的结果有哪些；⑥ 分层对光照利用有什么意义。
**易错**：✗ 垂直结构就是高低不同 / ✗ 群落=所有植物 / ✗ 生态位就是一个物种的食物 / ✗ 重叠越多越容易共存 / ✗ 水平结构是分层 / ✗ 竞争一定导致一方灭绝。

## xx2-c2-s2 群落的主要类型

**课本原话**
1. 根据群落的外貌和物种组成等方面的差异，可以将群落划分为不同类型的生物群落。
2. 荒漠生物群落、草原生物群落、森林生物群落的主要区别在于水分条件。
3. 群落的类型与气候（尤其降水量和温度）密切相关。

**三个扣分点**：**水分是划分荒漠/草原/森林的关键**（不是温度单独决定）；同一类型群落的**物种组成**不同但外貌相似；群落类型不是固定不变的（可演替）。

**四张图**：① 三类群落的外貌对照；② 年降水量与群落类型的关系；③ 荒漠植物的适应性（根系、叶片）；④ 森林的分层与草原的草本层。

**互动模型**：滑块＝年降水量 P（100–1000 mm，step 10）
```js
cover = Math.min(100, P / 10);      // 植被盖度（%，示意）
kind  = P < 300 ? 1 : P < 600 ? 2 : 3;   // 1 荒漠 2 草原 3 森林
```
`cases`：`{v:200,eq:{cover:20,kind:1}}`、`{v:500,eq:{cover:50,kind:2}}`、`{v:900,eq:{cover:90,kind:3}}`。
Autopilot：`[{t:0,v:100},{t:1.2,v:100},{t:4,v:500},{t:6.5,v:500},{t:9,v:1000},{t:11,v:700},{t:13,v:100}]`，keys `[100,500,700,1000]`。
**停留帧在 P=500**（草原：盖度 50%，正好卡在荒漠与森林之间）。
状态：P<300「荒漠」；300–600「草原」；>600「森林」。

**例题**：「为什么我国从东到西，群落类型依次是森林、草原、荒漠？」答案：从东到西降水量逐渐减少，水分条件决定了群落类型：降水多的地区形成森林，居中形成草原，最少处形成荒漠。
**六问**：① 划分群落类型的主要依据；② 决定荒漠/草原/森林的关键因素；③ 荒漠植物有哪些适应；④ 草原为什么没有高大乔木；⑤ 群落类型会变吗；⑥ 同一类型群落物种组成一样吗。
**易错**：✗ 温度决定三类群落 / ✗ 草原只是草多的地方 / ✗ 荒漠没有生物 / ✗ 群落类型固定不变 / ✗ 森林一定比草原物种多 / ✗ 同类型群落物种完全相同。

## xx2-c2-s3 群落的演替

**课本原话**
1. 随着时间的推移，一个群落被另一个群落代替的过程，叫做群落演替。
2. 演替分为初生演替和次生演替；初生演替从从来没有被植物覆盖的地面开始。
3. 次生演替从原有植被虽已不存在、但原有土壤条件基本保留的地方开始，速度通常更快。

**三个扣分点**：**初生演替**起点无土壤、无繁殖体（如裸岩、沙丘），**次生演替**保留土壤和种子（如弃耕农田、火灾后）；演替是**优势种更替**，不是「物种完全替换」；人类活动会**改变演替的速度和方向**。

**四张图**：① 演替的一般过程（裸岩→地衣→苔藓→草本→灌木→森林）；② 初生演替与次生演替的起点对照；③ 物种丰富度随时间上升的曲线；④ 人类活动对演替方向的影响。

**互动模型**：滑块＝演替年限 t（0–200 年，step 5）
```js
S = 5 + 60 * (1 - Math.exp(-t / 80));    // 物种丰富度（种）
```
`cases`：`{v:50,eq:{S:32.9}}`、`{v:100,eq:{S:47.8}}`、`{v:200,eq:{S:60.1}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:50},{t:6.5,v:50},{t:9,v:200},{t:11,v:120},{t:13,v:0}]`，keys `[0,50,120,200]`。
**停留帧在 t=50**（丰富度 32.9，上升最快的一段刚过，曲线开始变缓）。
状态：t<20「演替早期，物种少」；20–80「快速上升期」；>120「接近顶极，上升变慢」。

**例题**：「弃耕农田上的演替属于哪种？为什么它比裸岩上的演替快？」答案：次生演替；因为原有土壤条件基本保留，还可能有植物的种子和其他繁殖体，所以速度更快。
**六问**：① 初生与次生演替的区别；② 演替是物种被完全替换吗；③ 人类活动影响演替吗；④ 弃耕农田属于哪种；⑤ 演替到最后一定是森林吗；⑥ 演替过程中丰富度如何变化。
**易错**：✗ 演替是旧物种全部消失 / ✗ 弃耕农田属于初生演替 / ✗ 演替一定到森林 / ✗ 人类活动不影响演替 / ✗ 初生演替速度更快 / ✗ 演替过程中物种数一直线性增加。

## xx2-c3-s1 生态系统的结构

**课本原话**
1. 生态系统是由生物群落与它的无机环境相互作用而形成的统一整体。
2. 生态系统的组成成分包括非生物的物质和能量、生产者、消费者、分解者。
3. 食物链和食物网是生态系统的营养结构，是物质循环和能量流动的渠道。

**三个扣分点**：**生产者是基石**（自养、固定能量）；**分解者不可缺**（把有机物变无机物，否则物质循环中断）；食物链的起点必须是**生产者**（不是阳光，也不是消费者）。

**四张图**：① 四种组成成分及其关系；② 一条食物链的书写规范；③ 食物网与营养级；④ 分解者缺失会怎样（物质循环中断）。

**互动模型**：滑块＝营养级数 n（2–5，能量传递效率固定 10%，生产者固定 100%）
```js
gain = Math.pow(0.1, n - 1) * 100;   // 第 n 营养级可获得的能量（相对生产者%）
```

## xx2-c3-s2 生态系统的能量流动

**课本原话**
1. 能量流动是指生态系统中能量的输入、传递、转化和散失的过程。
2. 能量流动的特点是单向流动、逐级递减。
3. 某一营养级同化的能量，一部分用于呼吸作用散失，一部分用于生长、发育和繁殖，还有一部分被下一营养级摄入。

**三个扣分点**：**单向流动**（不能循环，热能无法再被利用）；**逐级递减**（传递效率 10%–20%）；同化量 ≠ 摄入量（摄入 − 粪便 = 同化）。

**四张图**：① 能量流动的四个环节；② 同化量的几条去向（呼吸、生长繁殖、下一级、分解者）；③ 能量金字塔；④ 摄入量与同化量的区别。

**互动模型**：滑块＝呼吸消耗占同化量的比例 rr（0–90%，step 5，同化量固定 1000）
```js
net   = 1000 * (1 - rr / 100);      // 用于生长、发育、繁殖的能量
toNxt = net * 0.1;                  // 传给下一营养级（效率 10%，示意）
```
`cases`：`{v:50,eq:{net:500,toNxt:50}}`、`{v:80,eq:{net:200,toNxt:20}}`、`{v:0,eq:{net:1000,toNxt:100}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:50},{t:6.5,v:50},{t:9,v:90},{t:11,v:70},{t:13,v:0}]`，keys `[0,50,70,90]`。
**停留帧在 rr=50**（一半被呼吸掉、剩 500 用于生长繁殖、其中 50 传给下一级）。
状态：rr<40「剩余多，传递给下一级的也多」；40–70「典型情况」；>70「大部分被呼吸消耗，向上传递很少」。

**例题**：「某营养级同化量为 1000 kJ，呼吸消耗 600 kJ，传递效率按 10% 计算，下一营养级能获得多少？」答案：用于生长、发育和繁殖的能量 = 1000−600 = 400 kJ；传给下一营养级 = 400×10% = 40 kJ。
**六问**：① 能量流动的特点；② 为什么不能循环；③ 同化量与摄入量的区别；④ 呼吸消耗算不算能量流动；⑤ 传递效率怎么算；⑥ 能量金字塔为什么上窄下宽。
**易错**：✗ 能量可以循环利用 / ✗ 同化量=摄入量 / ✗ 传递效率 100% / ✗ 呼吸消耗的能量能再被利用 / ✗ 能量金字塔是倒的（一般不是）/ ✗ 下一级获得的是同化量的全部。

## xx2-c3-s3 生态系统的物质循环

**课本原话**
1. 组成生物体的 C、H、O、N、P、S 等元素，都不断进行着从无机环境到生物群落、又从生物群落回到无机环境的循环过程，这就是生态系统的物质循环。
2. 物质循环具有全球性，因此又叫生物地球化学循环。
3. 碳在生物群落与无机环境之间主要以 CO₂ 的形式循环，在生物群落内部以含碳有机物的形式流动。

**三个扣分点**：物质循环是**全球性**的（不是局限在某一片区域）；碳在生物群落内部以**有机物**形式流动、与无机环境之间以 **CO₂** 形式；物质**可以循环**，能量**不能循环**（两者常一起考）。

**四张图**：① 碳循环的全过程（光合、呼吸、分解、燃烧）；② 物质循环与能量流动的对照表；③ 化石燃料燃烧对大气 CO₂ 的影响；④ 氮循环的固氮与反硝化。

**互动模型**：滑块＝人类每年排放的碳 E（0–40 Gt，step 1）
```js
delta = E * 0.5;                    // 大气 CO₂ 年增量（ppm，示意吸收率 50%）
alarm = E > 20 ? 1 : 0;             // 是否超过自然吸收能力
```
`cases`：`{v:10,eq:{delta:5}}`、`{v:20,eq:{delta:10}}`、`{v:40,eq:{delta:20}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:20},{t:6.5,v:20},{t:9,v:40},{t:11,v:30},{t:13,v:0}]`，keys `[0,20,30,40]`。
**停留帧在 E=20**（大气 CO₂ 年增 10 ppm：自然吸收已经跟不上，开始净累积）。
状态：E≤20「自然吸收还能消化大部分」；E>20「净累积，大气 CO₂ 持续上升」。

**例题**：「为什么说物质循环具有全球性，而能量流动是单向的？」答案：C、N 等元素可以随大气和水在 global 范围移动，最终回到无机环境再被利用，所以是全球性的；能量以热能形式散失后不能被再固定，故单向流动、逐级递减。
**六问**：① 物质循环为什么是全球性；② 碳在群落内部以什么形式流动；③ 能量能循环吗；④ 化石燃料燃烧影响碳循环吗；⑤ 氮循环的关键环节；⑥ 分解者在物质循环中的作用。
**易错**：✗ 物质循环只在一个生态系统内 / ✗ 碳在群落内以 CO₂ 形式流动 / ✗ 能量可以循环 / ✗ 物质循环和能量流动一样是单向的 / ✗ 分解者不参与碳循环 / ✗ 碳循环只在生物之间进行。

## xx2-c3-s4 生态系统的信息传递

**课本原话**
1. 生态系统中的光、声、温度、湿度、磁力等，通过物理过程传递的信息，称为物理信息。
2. 生物在生命活动过程中产生的、可以传递信息的化学物质，称为化学信息；动物的特殊行为称为行为信息。
3. 信息传递在生态系统中能维持生命活动的正常进行，影响种群的繁衍，调节种间关系。

**三个扣分点**：三类信息要分清（光照、声音属**物理信息**；信息素属**化学信息**；求偶舞蹈属**行为信息**）；信息传递是**双向**的（不像能量单向）；信息传递能**调节种间关系**、维持生态系统稳定。

**四张图**：① 三类信息举例对照；② 昆虫信息素吸引同种个体；③ 信息传递与能量流动、物质循环的对照；④ 信息传递调节种间关系（捕食者与猎物）。

**互动模型**：滑块＝信息素浓度 c（0–100，相对单位，step 1）
```js
attract = 50 * (1 - Math.exp(-c / 30));    // 吸引到的同种个体数（只）
```
`cases`：`{v:30,eq:{attract:31.6}}`、`{v:60,eq:{attract:43.2}}`、`{v:100,eq:{attract:48.2}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:30},{t:6.5,v:30},{t:9,v:100},{t:11,v:60},{t:13,v:0}]`，keys `[0,30,60,100]`。
**停留帧在 c=30**（吸引 31.6 只，接近饱和的一半：再加浓度收益递减）。
状态：c<20「浓度低，几乎吸引不到」；20–50「明显吸引」；>60「接近饱和，加浓度收益很小」。

**例题**：「用性外激素诱杀农业害虫，依据的是什么信息？有什么优点？」答案：化学信息（性外激素）；优点是专一性强、不污染环境、不杀伤天敌，能干扰害虫的正常交配从而降低种群密度。
**六问**：① 三类信息怎么分；② 光属于哪类；③ 信息传递是单向还是双向；④ 信息传递有什么作用；⑤ 用信息素防治害虫的优点；⑥ 信息传递与能量流动的区别。
**易错**：✗ 光属于化学信息 / ✗ 信息传递是单向的 / ✗ 信息传递不调节种间关系 / ✗ 行为信息就是化学信息 / ✗ 信息传递只影响繁殖 / ✗ 信息素越多效果越好（会饱和）。

## xx2-c3-s5 生态系统的稳定性

**课本原话**
1. 生态系统所具有的保持或恢复自身结构和功能相对稳定的能力，叫做生态系统的稳定性。
2. 生态系统之所以能维持相对稳定，是由于生态系统具有自我调节能力。
3. 生态系统的自我调节能力有限，抵抗力稳定性与恢复力稳定性往往呈负相关。

**三个扣分点**：**抵抗力**（抵抗干扰保持原状）与**恢复力**（破坏后恢复）**常呈负相关**（反直觉）；自我调节能力**有上限**（超过阈值生态系统会崩溃）；物种组成越复杂，抵抗力稳定性越强。

**四张图**：① 抵抗力与恢复力的定义对照；② 两种稳定性的负相关（森林 vs 荒漠）；③ 自我调节能力的上限（超过阈值崩溃）；④ 物种丰富度与稳定性的关系。

**互动模型**：滑块＝物种丰富度 S（5–50，step 1）
```js
resist = 1 - Math.exp(-S / 15);     // 抵抗力稳定性（0–1）
recov  = Math.exp(-S / 25);         // 恢复力稳定性（0–1）
```
`cases`：`{v:5,eq:{resist:0.283,recov:0.819}}`、`{v:20,eq:{resist:0.736,recov:0.449}}`、`{v:50,eq:{resist:0.964,recov:0.135}}`。
Autopilot：`[{t:0,v:5},{t:1.2,v:5},{t:4,v:20},{t:6.5,v:20},{t:9,v:50},{t:11,v:35},{t:13,v:5}]`，keys `[5,13,20,35,50]`。
**停留帧在 S=13**（两曲线交叉：抵抗力与恢复力大致相等——最容易被扣分的那一格）。
状态：S<10「恢复力强、抵抗力弱（如荒漠）」；S≈13「两者相当」；S>25「抵抗力强、恢复力弱（如森林）」。

**例题**：「热带雨林和荒漠草原，哪个抵抗力稳定性高？哪个恢复力稳定性高？」答案：热带雨林物种丰富、营养结构复杂，抵抗力稳定性高；荒漠草原物种少、结构简单，恢复力稳定性高。二者呈负相关。
**六问**：① 两种稳定性怎么区分；② 为什么呈负相关；③ 自我调节能力有上限吗；④ 物种越多越稳定吗；⑤ 哪些生态系统抵抗力高；⑥ 恢复力高的系统抵抗力一定低吗。
**易错**：✗ 两种稳定性都高才是好 / ✗ 物种越多两种稳定性都越强 / ✗ 自我调节能力无限 / ✗ 森林恢复力最强 / ✗ 抵抗力就是恢复力 / ✗ 生态系统不会崩溃。

## xx2-c4-s1 人类活动对生态环境的影响

**课本原话**
1. 生态足迹（生态占用）是指维持某一人口单位生存所需的生产资源和吸纳废物的土地及水域面积。

**三个扣分点**：生态足迹是**面积**（不是排放量）；足迹超过承载力即**生态赤字**；**可持续发展**不等于不发展，而是不超过承载力。

**四张图**：① 生态足迹的组成（耕地、牧地、林地、建筑、碳足迹）；② 足迹与承载力的比较（几个地球）；③ 生活方式与足迹的关系；④ 可持续发展的含义。

**互动模型**：滑块＝人均生态足迹 f（1.0–6.0 全球公顷/人，step 0.1；生物承载力取 1.7）

```js
deficit = f > 1.7 ? 1 : 0;       // 是否出现生态赤字
```
`cases`：`{v:1.7,eq:{earth:1}}`、`{v:3.4,eq:{earth:2}}`、`{v:5.1,eq:{earth:3}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:3.4},{t:6.5,v:3.4},{t:9,v:6},{t:11,v:5.1},{t:13,v:1}]`，keys `[1,1.7,3.4,6]`。

## xx2-c4-s2 生物多样性及其保护

## xx2-c4-c3 生态工程
