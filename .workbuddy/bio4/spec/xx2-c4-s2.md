## xx2-c4-s2 生物多样性及其保护

**课本原话**
1. 生物多样性包括基因多样性（遗传多样性）、物种多样性和生态系统多样性。
2. 保护生物多样性最有效的措施是就地保护，主要形式是建立自然保护区。
3. 生物多样性的价值包括直接价值、间接价值和潜在价值。

**三个扣分点**：**就地保护**是最有效的措施（迁地保护是补充）；**间接价值**指生态功能（调节气候、涵养水源，常被忽略但最大）；三个层次别漏（基因、物种、生态系统）。

**四张图**：① 生物多样性三个层次；② 就地保护与迁地保护的区别；③ 三类价值的举例；④ 栖息地面积与物种数的关系。

**互动模型**：滑块＝栖息地面积损失比例 loss（0–90%，step 5；`S=S₀×A^0.25`，S₀=100、z=0.25）
```js
S = 100 * Math.pow((100 - loss) / 100, 0.25);   // 剩余物种数（种）
```
`cases`：`{v:0,eq:{S:100}}`、`{v:50,eq:{S:84.1}}`、`{v:90,eq:{S:56.2}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:50},{t:6.5,v:50},{t:9,v:90},{t:11,v:75},{t:13,v:0}]`，keys `[0,50,75,90]`。
**停留帧在 loss=90**（栖息地损失九成，物种数掉到 56——「少一半物种」的经典结论）。
状态：loss<30「物种数下降不多」；30–70「明显下降」；>85「损失过半」。

**例题**：「为什么保护生物多样性最有效的措施是就地保护？」答案：就地保护（建立自然保护区）保存了物种原有的栖息环境和生态过程，保护了基因、物种、生态系统三个层次，比迁地保护更全面、更经济。
**六问**：① 生物多样性有三个层次吗；② 就地保护与迁地保护的区别；③ 间接价值指什么；④ 为什么说间接价值最大；⑤ 栖息地面积与物种数什么关系；⑥ 保护多样性就是保护珍稀物种吗。
**易错**：✗ 生物多样性只有物种多样性 / ✗ 迁地保护是最有效措施 / ✗ 间接价值最小 / ✗ 保护多样性只保护动物 / ✗ 栖息地减少物种等比例减少 / ✗ 保护就是禁止利用。
