# 本节规格（只读这一节，不要读 SPEC.md 全文）

## xx2-c1-s2 种群数量的变化

**课本原话**
1. 种群在理想条件下呈「J」形增长：Nₜ=N₀λᵗ。
2. 在资源和空间有限的环境中，种群经过一定时间的增长后，数量趋于稳定，呈「S」形增长。
3. 「S」形增长曲线中，种群数量达到环境容纳量（K 值）后不再增加；在 K/2 时增长速率最大。

**三个扣分点**：J 形是**理想条件**（无环境阻力），S 形有**环境容纳量 K**；**K/2 时增长速率最快**（不是 K 时）；λ 是**相邻两代的倍数**（不是增长率）。

**四张图**：① 两种增长曲线放在同一坐标里（J 与 S 分岔）；② S 形曲线的 K 与 K/2；③ 增长速率曲线的峰值在 K/2；④ λ 与增长率的关系。

**互动模型**：滑块＝时间 t（0–15 代，N₀=10，J 形 λ=1.5，S 形 K=1000、r=0.5）
```js
J = 10 * Math.pow(1.5, t);
S = 1000 / (1 + 99 * Math.exp(-0.5 * t));
```
`cases`：`{v:5,eq:{J:75.9,S:109.5}}`、`{v:10,eq:{J:576.7,S:600}}`、`{v:15,eq:{J:4378.9,S:999.9}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:10},{t:6.5,v:10},{t:9,v:15},{t:11,v:7},{t:13,v:0}]`，keys `[0,7,10,15]`。
**停留帧在 t=10**（J 形已经 577，S 形才 600 且开始变平——两条线从这里分开）。
状态：t≤5「两条线还挨着」；t≥8「J 形继续翻倍，S 形趋向 K」。

**例题**：「某种群在理想条件下每代数量是上一代的 1.5 倍，N₀=10，第 5 代数量是多少？若改为有限环境（K=1000、r=0.5），第 5 代约多少？」答案：J 形 N=10×1.5⁵≈75.9；S 形约 109.5（公式 N=K/(1+((K−N₀)/N₀)e^(−rt))）。
**六问**：① J 形与 S 形的区别；② K 值是什么；③ 增长速率最大在哪；④ λ 与增长率一样吗；⑤ 为什么 S 形会趋于稳定；⑥ K/2 有什么应用。
**易错**：✗ K 值处增长最快 / ✗ J 形是自然状态下的常态 / ✗ λ 就是增长率 / ✗ S 形没有上限 / ✗ K 值固定不变（环境改变会变）/ ✗ S 形曲线是直线。
