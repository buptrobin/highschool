## xx2-c1-s1 种群的数量特征

**课本原话**
1. 种群在单位面积或单位体积中的个体数就是种群密度，它是种群最基本的数量特征。
2. 估算种群密度常用的方法有样方法和标记重捕法。
3. 标记重捕法：N（种群总数）= M（标记数）× n（重捕总数）÷ m（重捕中带标记的个体数）。

**三个扣分点**：种群密度是**最基本的数量特征**（其他特征都影响它）；标记重捕法的公式是 **M×n÷m**（分母是**重捕中有标记**的数，不是重捕总数）；标记物不能脱落、不能影响活动能力，否则估算**偏大**。

**四张图**：① 样方法（随机取样、多个样方取平均）；② 标记重捕法的操作流程；③ 公式里三个字母各指什么；④ 重捕数 m 太小时，估算值为什么会飘。

**互动模型**：滑块＝重捕个体中带标记的个数 m（2–40，标记数 M=50、重捕总数 n=100）
```js
N = 50 * 100 / m;          // 标记重捕法估算值
err = (N - 500) / 500 * 100;   // 与真实值 500 的相对误差（%）
```
`cases`：`{v:5,eq:{N:1000}}`、`{v:10,eq:{N:500}}`、`{v:25,eq:{N:200}}`。
Autopilot：`[{t:0,v:40},{t:1.2,v:40},{t:4,v:10},{t:6.5,v:10},{t:9,v:2},{t:11,v:25},{t:13,v:40}]`，keys `[2,10,25,40]`。
**停留帧在 m=10**（估算值正好 500＝真实值；m 再小，估算就越大越不准）。
状态：m≥10「估算稳定，接近真值」；5≤m<10「误差偏大」；m<5「m 太小，估算值严重偏大」。

**例题**：「某草地捕获 50 只鼠并标记后放回，一段时间后重捕 100 只，其中有标记的 10 只，估算鼠的种群数量。」答案：N=50×100÷10=500（只）。注意：若标记物脱落，重捕中 m 偏小，估算值会**偏大**。
**六问**：① 种群密度为什么是最基本的特征；② 标记重捕法的分母是什么；③ 标记物脱落会怎样；④ 样方法为什么要随机取样；⑤ 什么情况下不能用标记重捕法；⑥ 样方大小怎么定。
**易错**：✗ 公式写成 M×m÷n / ✗ 分母用重捕总数 / ✗ 标记物脱落只影响标记数 / ✗ 样方挑长得好的地方 / ✗ 种群密度是唯一特征 / ✗ 两次捕获间隔越短越好。
