## xx2-c4-c3 生态工程

（slug 为 xx2-c4-s3）

**课本原话**
1. 生态工程是指人类应用生态学和系统学等学科的原理和方法，对人工生态系统进行分析、设计和调控，以提高其生产力的工程。
2. 生态工程遵循自生、循环、协调、整体等生态学基本原理。
3. 生态工程的目标是实现经济效益和生态效益的同步发展，达到可持续发展。

**三个扣分点**：**循环**原理（物质循环再生，如沼气池）；**整体**原理（自然—经济—社会整体，不能只看生态）；生态工程不是「不用化肥农药」这么简单，而是**系统设计**。

**四张图**：① 生态工程的四个基本原理；② 桑基鱼塘的物质循环（循环原理）；③ 整体原理（自然、经济、社会三者统筹）；④ 废弃物再利用率与外部投入的关系。

**互动模型**：滑块＝废弃物再利用率 r（0–90%，step 5）
```js
input  = 100 - r;              // 需要外部输入的资源（相对值）
output = 100 - r;              // 排放的废物（相对值）
```
`cases`：`{v:0,eq:{input:100,output:100}}`、`{v:50,eq:{input:50,output:50}}`、`{v:90,eq:{input:10,output:10}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:50},{t:6.5,v:50},{t:9,v:90},{t:11,v:70},{t:13,v:0}]`，keys `[0,50,70,90]`。
**停留帧在 r=50**（一半废弃物回到生产环节：外部投入与排放同时减半，循环原理的效果最直观）。
状态：r<30「线性经济，投入高排放高」；30–70「部分循环」；>70「接近循环经济」。

**例题**：「桑基鱼塘为什么能提高经济效益又减少污染？」答案：桑叶养蚕、蚕沙喂鱼、塘泥肥桑，物质在系统内循环利用（循环原理），减少了外部投入和废物排放，同时获得多重产品，实现经济效益与生态效益同步。
**六问**：① 生态工程的原理有哪些；② 循环原理的实例；③ 整体原理强调什么；④ 生态工程是不是禁止用化肥；⑤ 沼气的生态学意义；⑥ 生态工程的目标。
**易错**：✗ 生态工程只讲生态不讲经济 / ✗ 生态工程就是不用化肥 / ✗ 循环原理就是垃圾分类 / ✗ 整体原理只看自然 / ✗ 生态工程会降低产量 / ✗ 物质循环与生态工程无关。
