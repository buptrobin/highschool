## xx2-c2-s2 群落的主要类型

**课本原话**
1. 根据群落的外貌和物种组成等方面的差异，可以将群落划分为不同类型的生物群落。
2. 荒漠生物群落、草原生物群落、森林生物群落的主要区别在于水分条件。
3. 群落的类型与气候（尤其降水量和温度）密切相关。

**三个扣分点**：**水分是划分荒漠/草原/森林的关键**（不是温度单独决定）；同一类型群落的**物种组成**不同但外貌相似；群落类型不是固定不变的（可演替）。

**四张图**：① 三类群落的外貌对照；② 年降水量与群落类型的关系；③ 荒漠植物的适应性（根系、叶片）；④ 森林的分层与草原的草本层。

**互动模型**：滑块＝年降水量 P（100–1000 mm，step 10）
```js
cover = Math.min(100, P / 10);      // 植被盖度（%，示意）
kind  = P < 300 ? 1 : P < 600 ? 2 : 3;   // 1 荒漠 2 草原 3 森林
```
`cases`：`{v:200,eq:{cover:20,kind:1}}`、`{v:500,eq:{cover:50,kind:2}}`、`{v:900,eq:{cover:90,kind:3}}`。
Autopilot：`[{t:0,v:100},{t:1.2,v:100},{t:4,v:500},{t:6.5,v:500},{t:9,v:1000},{t:11,v:700},{t:13,v:100}]`，keys `[100,500,700,1000]`。
**停留帧在 P=500**（草原：盖度 50%，正好卡在荒漠与森林之间）。
状态：P<300「荒漠」；300–600「草原」；>600「森林」。

**例题**：「为什么我国从东到西，群落类型依次是森林、草原、荒漠？」答案：从东到西降水量逐渐减少，水分条件决定了群落类型：降水多的地区形成森林，居中形成草原，最少处形成荒漠。
**六问**：① 划分群落类型的主要依据；② 决定荒漠/草原/森林的关键因素；③ 荒漠植物有哪些适应；④ 草原为什么没有高大乔木；⑤ 群落类型会变吗；⑥ 同一类型群落物种组成一样吗。
**易错**：✗ 温度决定三类群落 / ✗ 草原只是草多的地方 / ✗ 荒漠没有生物 / ✗ 群落类型固定不变 / ✗ 森林一定比草原物种多 / ✗ 同类型群落物种完全相同。
