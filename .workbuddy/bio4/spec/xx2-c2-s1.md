## xx2-c2-s1 群落的结构

**课本原话**
1. 群落是指同一时间内聚集在一定区域中各种生物种群的集合。
2. 群落中各个生物种群分别占据了不同的空间，使群落形成一定的空间结构，包括垂直结构和水平结构。
3. 生态位是指一个物种在群落中的地位或作用，包括所处的空间位置、占用资源的情况以及与其它物种的关系等。

**三个扣分点**：**垂直结构是分层**（光照、食物决定）、**水平结构是镶嵌分布**（地形、湿度决定），两者别混；生态位重叠越多，**竞争越激烈**；群落是**所有生物**（不只植物）。

**四张图**：① 群落的垂直分层（乔木—灌木—草本）；② 水平结构的镶嵌分布；③ 生态位的三维示意（空间、资源、关系）；④ 生态位重叠与竞争强度。

**互动模型**：滑块＝两个物种的生态位重叠度 o（0–100%）
```js
comp = o / 100;                     // 竞争强度（0–1）
coexist = comp < 0.8 ? 1 : 0;       // 重叠超过 80% 后难以长期共存
```
`cases`：`{v:0,eq:{comp:0}}`、`{v:50,eq:{comp:0.5}}`、`{v:90,eq:{comp:0.9}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:50},{t:6.5,v:50},{t:9,v:100},{t:11,v:70},{t:13,v:0}]`，keys `[0,50,70,100]`。
**停留帧在 o=50**（重叠一半：还能共存，但已出现明显的资源竞争——生态位分化的起点）。
状态：o<30「几乎不竞争，容易共存」；30–80「部分重叠，出现竞争」；>80「严重重叠，通常一方被排除或分化」。

**例题**：「同一片森林里，几种鸟都在树上取食昆虫，为什么能共存？」答案：它们的取食高度、时间或食物大小不同（生态位分化），生态位重叠小、竞争弱，因此能共存。
**六问**：① 垂直结构与水平结构的区别；② 生态位包括什么；③ 重叠越多会怎样；④ 群落是否只指植物；⑤ 竞争的结果有哪些；⑥ 分层对光照利用有什么意义。
**易错**：✗ 垂直结构就是高低不同 / ✗ 群落=所有植物 / ✗ 生态位就是一个物种的食物 / ✗ 重叠越多越容易共存 / ✗ 水平结构是分层 / ✗ 竞争一定导致一方灭绝。
