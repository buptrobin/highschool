## xx2-c3-s3 生态系统的物质循环

**课本原话**
1. 组成生物体的 C、H、O、N、P、S 等元素，都不断进行着从无机环境到生物群落、又从生物群落回到无机环境的循环过程，这就是生态系统的物质循环。
2. 物质循环具有全球性，因此又叫生物地球化学循环。
3. 碳在生物群落与无机环境之间主要以 CO₂ 的形式循环，在生物群落内部以含碳有机物的形式流动。

**三个扣分点**：物质循环是**全球性**的（不是局限在某一片区域）；碳在生物群落内部以**有机物**形式流动、与无机环境之间以 **CO₂** 形式；物质**可以循环**，能量**不能循环**（两者常一起考）。

**四张图**：① 碳循环的全过程（光合、呼吸、分解、燃烧）；② 物质循环与能量流动的对照表；③ 化石燃料燃烧对大气 CO₂ 的影响；④ 氮循环的固氮与反硝化。

**互动模型**：滑块＝人类每年排放的碳 E（0–40 Gt，step 1）
```js
delta = E * 0.5;                    // 大气 CO₂ 年增量（ppm，示意吸收率 50%）
alarm = E > 20 ? 1 : 0;             // 是否超过自然吸收能力
```
`cases`：`{v:10,eq:{delta:5}}`、`{v:20,eq:{delta:10}}`、`{v:40,eq:{delta:20}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:20},{t:6.5,v:20},{t:9,v:40},{t:11,v:30},{t:13,v:0}]`，keys `[0,20,30,40]`。
**停留帧在 E=20**（大气 CO₂ 年增 10 ppm：自然吸收已经跟不上，开始净累积）。
状态：E≤20「自然吸收还能消化大部分」；E>20「净累积，大气 CO₂ 持续上升」。

**例题**：「为什么说物质循环具有全球性，而能量流动是单向的？」答案：C、N 等元素可以随大气和水在 global 范围移动，最终回到无机环境再被利用，所以是全球性的；能量以热能形式散失后不能被再固定，故单向流动、逐级递减。
**六问**：① 物质循环为什么是全球性；② 碳在群落内部以什么形式流动；③ 能量能循环吗；④ 化石燃料燃烧影响碳循环吗；⑤ 氮循环的关键环节；⑥ 分解者在物质循环中的作用。
**易错**：✗ 物质循环只在一个生态系统内 / ✗ 碳在群落内以 CO₂ 形式流动 / ✗ 能量可以循环 / ✗ 物质循环和能量流动一样是单向的 / ✗ 分解者不参与碳循环 / ✗ 碳循环只在生物之间进行。
