## xx2-c3-s1 生态系统的结构

**课本原话**
1. 生态系统是由生物群落与它的无机环境相互作用而形成的统一整体。
2. 生态系统的组成成分包括非生物的物质和能量、生产者、消费者、分解者。
3. 食物链和食物网是生态系统的营养结构，是物质循环和能量流动的渠道。

**三个扣分点**：**生产者是基石**（自养、固定能量）；**分解者不可缺**（把有机物变无机物，否则物质循环中断）；食物链的起点必须是**生产者**（不是阳光，也不是消费者）。

**四张图**：① 四种组成成分及其关系；② 一条食物链的书写规范；③ 食物网与营养级；④ 分解者缺失会怎样（物质循环中断）。

**互动模型**：滑块＝营养级数 n（2–5，能量传递效率固定 10%，生产者固定 100%）
```js
gain = Math.pow(0.1, n - 1) * 100;   // 第 n 营养级可获得的能量（相对生产者%）
```
`cases`：`{v:2,eq:{gain:10}}`、`{v:3,eq:{gain:1}}`、`{v:4,eq:{gain:0.1}}`。
Autopilot：`[{t:0,v:2},{t:1.2,v:2},{t:4,v:3},{t:6.5,v:3},{t:9,v:5},{t:11,v:4},{t:13,v:2}]`，keys `[2,3,4,5]`。
**停留帧在 n=3**（第三营养级只剩 1%：这就是食物链一般不超过 4–5 级的原因）。
状态：n=2「一级消费者」；n=3「二级消费者」；n≥4「能量已不足千分之一」。

**例题**：「为什么食物链一般不超过 4–5 个营养级？」答案：能量沿食物链逐级递减，传递效率只有 10%–20%；到第 4、第 5 营养级时能量已不足以维持种群生存。
**六问**：① 生态系统由哪些成分组成；② 生产者为什么是基石；③ 分解者能去掉吗；④ 食物链的起点；⑤ 营养级越高能量越多还是越少；⑥ 食物网比食物链多了什么。
**易错**：✗ 食物链从阳光开始 / ✗ 分解者可有可无 / ✗ 消费者是必需的 / ✗ 营养级越高能量越多 / ✗ 传递效率是 100% / ✗ 食物网就是多条食物链相加。
