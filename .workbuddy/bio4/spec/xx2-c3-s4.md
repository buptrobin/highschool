## xx2-c3-s4 生态系统的信息传递

**课本原话**
1. 生态系统中的光、声、温度、湿度、磁力等，通过物理过程传递的信息，称为物理信息。
2. 生物在生命活动过程中产生的、可以传递信息的化学物质，称为化学信息；动物的特殊行为称为行为信息。
3. 信息传递在生态系统中能维持生命活动的正常进行，影响种群的繁衍，调节种间关系。

**三个扣分点**：三类信息要分清（光照、声音属**物理信息**；信息素属**化学信息**；求偶舞蹈属**行为信息**）；信息传递是**双向**的（不像能量单向）；信息传递能**调节种间关系**、维持生态系统稳定。

**四张图**：① 三类信息举例对照；② 昆虫信息素吸引同种个体；③ 信息传递与能量流动、物质循环的对照；④ 信息传递调节种间关系（捕食者与猎物）。

**互动模型**：滑块＝信息素浓度 c（0–100，相对单位，step 1）
```js
attract = 50 * (1 - Math.exp(-c / 30));    // 吸引到的同种个体数（只）
```
`cases`：`{v:30,eq:{attract:31.6}}`、`{v:60,eq:{attract:43.2}}`、`{v:100,eq:{attract:48.2}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:30},{t:6.5,v:30},{t:9,v:100},{t:11,v:60},{t:13,v:0}]`，keys `[0,30,60,100]`。
**停留帧在 c=30**（吸引 31.6 只，接近饱和的一半：再加浓度收益递减）。
状态：c<20「浓度低，几乎吸引不到」；20–50「明显吸引」；>60「接近饱和，加浓度收益很小」。

**例题**：「用性外激素诱杀农业害虫，依据的是什么信息？有什么优点？」答案：化学信息（性外激素）；优点是专一性强、不污染环境、不杀伤天敌，能干扰害虫的正常交配从而降低种群密度。
**六问**：① 三类信息怎么分；② 光属于哪类；③ 信息传递是单向还是双向；④ 信息传递有什么作用；⑤ 用信息素防治害虫的优点；⑥ 信息传递与能量流动的区别。
**易错**：✗ 光属于化学信息 / ✗ 信息传递是单向的 / ✗ 信息传递不调节种间关系 / ✗ 行为信息就是化学信息 / ✗ 信息传递只影响繁殖 / ✗ 信息素越多效果越好（会饱和）。
