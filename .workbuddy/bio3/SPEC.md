## xx1-c1-s1 细胞生活的环境

**课本原话**
1. 体液包括细胞内液和细胞外液，细胞外液主要由血浆、组织液和淋巴液组成，构成了内环境。
2. 内环境的理化性质包括渗透压、酸碱度和温度，其中血浆渗透压的大小主要与无机盐、蛋白质的含量有关。
3. 组织液中的物质可以进入血浆和淋巴液，血浆中的物质也能进入组织液。

**三个扣分点**：内环境 = **细胞外液**（不是细胞内液，也不是「体内所有液体」）；血浆蛋白属于内环境成分、血红蛋白属于细胞内成分（同一「蛋白」两个位置）；组织液→淋巴液是**单向**的。

**四张图**：① 血浆、组织液、淋巴液三者的物质交换关系（含单向箭头）；② 毛细血管壁两侧的胶体渗透压与水分移动；③ 血浆蛋白浓度下降 → 组织液增多 → 水肿；④ 内环境成分清单（哪些在里、哪些不在）。

**互动模型**：滑块＝血浆蛋白浓度 c（30–90 g/L，step 5）
```js
op    = 25 * c / 70;                       // 血浆胶体渗透压（mmHg，70 g/L 时 25）
edema = Math.max(0, (70 - c) / 70);        // 水肿指数：0 正常、越接近 1 越肿
```
`cases`：`{v:70,eq:{op:25,edema:0}}`、`{v:50,eq:{op:17.857,edema:0.2857}}`、`{v:30,eq:{op:10.714,edema:0.5714}}`。
Autopilot：`[{t:0,v:90},{t:1.2,v:90},{t:4,v:50},{t:6.5,v:50},{t:9,v:30},{t:11,v:40},{t:13,v:90}]`，keys `[30,50,70,90]`。
**停留帧在 c=50**（胶体渗透压掉到 17.9，回流变少，组织液开始堆积——营养不良性水肿的起点）。
状态：c≥65「回流正常」；45–65「回流偏少，轻度水肿」；<45「明显水肿」。

**例题**：「长期营养不良的人为什么会出现组织水肿？」答案：血浆蛋白合成不足 → 血浆胶体渗透压下降 → 血浆吸水能力减弱、组织液回流减少 → 组织液增多，形成水肿。（注意：不是「水变多了」，是水的分配变了。）
**六问**：① 内环境就是体液吗；② 血红蛋白在内环境里吗；③ 淋巴液为什么只能单向流；④ 血浆渗透压主要由什么决定；⑤ 组织水肿有哪些原因；⑥ 细胞外液占体液的比例。
**易错**：✗ 内环境=体液 / ✗ 血红蛋白、呼吸酶属于内环境成分 / ✗ 组织液可以流回淋巴管再进组织液（双向）/ ✗ 水肿就是喝水多 / ✗ 血浆蛋白和血红蛋白是同一回事 / ✗ 内环境包括细胞内液。

## xx1-c1-s2 内环境的稳态

**课本原话**
1. 内环境的稳态是指正常机体通过调节作用，使各个器官、系统协调活动，共同维持内环境的相对稳定状态。
2. 稳态的调节机制是神经—体液—免疫调节网络。
3. 血浆 pH 能维持在 7.35–7.45，与血浆中的缓冲物质（如 H₂CO₃/NaHCO₃）有关。

**三个扣分点**：稳态是**相对稳定**、**动态变化**（不是「不变」）；调节机制是**网络**（三个都要写）；缓冲对的作用是**减弱** pH 变化，不是「不让变」。

**四张图**：① 稳态的概念（调节 → 各器官系统协调 → 相对稳定）；② 血浆 pH 的缓冲对工作过程；③ 有缓冲与无缓冲的 pH 变化曲线对比；④ 稳态失调的几种情形（发烧、酸中毒、血糖过高）。

**互动模型**：滑块＝进入血液的乳酸量 L（0–20 mmol/L，step 1）
```js
buf   = 7.40 - 0.005 * L;      // 有缓冲对：变化很小
nobuf = 7.40 - 0.040 * L;      // 无缓冲：掉得快
```
`cases`：`{v:0,eq:{buf:7.4,nobuf:7.4}}`、`{v:10,eq:{buf:7.35,nobuf:7.0}}`、`{v:20,eq:{buf:7.3,nobuf:6.6}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:10},{t:6.5,v:10},{t:9,v:20},{t:11,v:15},{t:13,v:0}]`，keys `[0,10,15,20]`。
**停留帧在 L=10**（有缓冲 7.35 还在正常范围内，无缓冲已经掉到 7.00——两条线分开最明显的一格）。
状态：buf 7.35–7.45「在正常范围内」；<7.35「酸中毒方向」；>7.45「碱中毒方向」。

**例题**：「剧烈运动后血液中乳酸增多，为什么血浆 pH 仍能维持在 7.35–7.45？」答案：乳酸进入血液后与 NaHCO₃ 反应生成乳酸钠和 H₂CO₃，H₂CO₃ 分解为 CO₂ 由肺排出；缓冲物质减弱了 pH 的变化，加上神经—体液—免疫调节网络共同作用，pH 维持在正常范围。
**六问**：① 稳态是不是「不变」；② 缓冲对能完全阻止 pH 变化吗；③ 稳态的调节机制是什么；④ 发烧属于稳态失调吗；⑤ 缓冲对由什么组成；⑥ 稳态只针对 pH 吗。
**易错**：✗ 稳态就是恒定不变 / ✗ 缓冲对能让 pH 一点不变 / ✗ 调节机制只写神经调节 / ✗ 稳态只指 pH / ✗ 乳酸直接被排出体外所以 pH 不变 / ✗ 稳态失调只发生在生病时。

## xx1-c2-s1 神经调节的结构基础

**课本原话**
1. 神经系统包括中枢神经系统和外周神经系统，中枢神经系统包括脑和脊髓。
2. 神经元是神经系统结构和功能的基本单位，由细胞体、树突和轴突构成。
3. 反射的结构基础是反射弧，包括感受器、传入神经、神经中枢、传出神经和效应器。

**三个扣分点**：反射弧**五个环节缺一不可**；效应器是**传出神经末梢及其支配的肌肉或腺体**（不是「肌肉」两个字）；「有反应」不等于「有反射」（必须经过完整反射弧）。

**四张图**：① 神经系统的组成（中枢/外周）；② 神经元结构（细胞体、树突、轴突、髓鞘）；③ 反射弧五环节；④ 同一刺激下「损伤不同环节」的结果对照。

**互动模型**：滑块＝被损伤的环节序号 seg（1–5，依次为感受器、传入神经、神经中枢、传出神经、效应器）
```js
segName = ['感受器','传入神经','神经中枢','传出神经','效应器'][seg-1];
ok      = seg <= 0 ? 1 : 0;        // 任一环节损伤，反射都不能完成
sense   = seg === 1 ? 0 : 1;       // 能否产生感觉（感官→大脑通路未断）
eff     = (seg === 5) ? 0 : 1;     // 效应器是否还能被直接刺激引起反应
```
`cases`：`{v:1,eq:{ok:0,sense:0}}`、`{v:3,eq:{ok:0,sense:1}}`、`{v:5,eq:{ok:0,eff:0}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:3},{t:6.5,v:3},{t:9,v:5},{t:11,v:4},{t:13,v:1}]`，keys `[1,3,5]`。
**停留帧在 seg=3**（神经中枢受伤：有感觉、但不能完成反射——最能区分「感觉」和「反射」的一格）。
状态：seg=1「无感觉、无反射」；seg=2「无感觉、无反射（传入断了感觉也传不上去）」；seg=3「有感觉、无反射」；seg=4「有感觉、无反射」；seg=5「有感觉、无反射，但肌肉本身还能被直接刺激收缩」。

**例题**：「某人脊髓胸段受损，针刺足部有感觉但不能缩腿，说明什么？」答案：传入神经和脊髓上行传导束完好（有感觉），反射弧的传出部分或神经中枢通路被阻断，故不能完成缩腿反射。
**六问**：① 反射弧五个环节是什么；② 效应器到底指什么；③ 有反应就等于有反射吗；④ 中枢神经包括什么；⑤ 神经元由哪几部分构成；⑥ 神经胶质细胞有什么用。
**易错**：✗ 效应器就是肌肉 / ✗ 反射弧缺一个环节也能完成 / ✗ 有感觉就是有反射 / ✗ 中枢神经系统包括脑神经和脊神经 / ✗ 神经元只有轴突 / ✗ 神经胶质细胞只是填充物。

## xx1-c2-s2 神经调节的基本方式

**课本原话**
1. 反射是神经调节的基本方式，分为非条件反射和条件反射。
2. 非条件反射是出生后无需训练就有的，条件反射是在非条件反射的基础上通过学习和训练建立的。
3. 条件反射需要大脑皮层的参与，建立后若长期不强化会逐渐消退。

**三个扣分点**：条件反射**以非条件反射为基础**（不是凭空建立）；**需要大脑皮层**参与；**不强化会消退**（不是永久保存）。

**四张图**：① 非条件反射与条件反射的对照；② 条件反射建立的过程（无关刺激 + 非条件刺激）；③ 强化与消退曲线；④ 反射是神经调节基本方式的含义。

**互动模型**：滑块＝强化训练次数 n（0–20，step 1）
```js
strength = Math.round(100 * (1 - Math.exp(-n / 5)) * 10) / 10;   // 条件反射强度（%）
```
`cases`：`{v:0,eq:{strength:0}}`、`{v:5,eq:{strength:63.2}}`、`{v:20,eq:{strength:98.2}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:5},{t:6.5,v:5},{t:9,v:20},{t:11,v:12},{t:13,v:0}]`，keys `[0,5,12,20]`。
**停留帧在 n=5**（63.2%，建立最快的一段刚过，曲线开始变平——「练到后面收益递减」）。
状态：n=0「没有反应，还没建立」；n≤10「正在建立，逐次加强」；n>10「趋于稳定，再练提升很小」。

**例题**：「狗听到铃声就分泌唾液，这个反射的建立需要什么条件？如果长期只响铃不给食物会怎样？」答案：需要把无关刺激（铃声）与非条件刺激（食物）多次结合，需要大脑皮层参与；长期只响铃不给食物，条件反射会逐渐消退。
**六问**：① 条件反射和非条件反射的区别；② 条件反射的基础是什么；③ 条件反射需要哪个中枢；④ 为什么会消退；⑤ 望梅止渴属于哪种；⑥ 缩手反射属于哪种。
**易错**：✗ 条件反射生来就有 / ✗ 条件反射不需要大脑皮层 / ✗ 建立后会永久保存 / ✗ 消退就是忘记了刺激 / ✗ 缩手反射是条件反射 / ✗ 非条件反射不需要反射弧。

## xx1-c2-s3 神经冲动的产生和传导

**课本原话**
1. 静息时神经纤维膜电位表现为外正内负，称为静息电位，主要由 K⁺ 外流形成。
2. 受刺激后 Na⁺ 内流，膜电位变为外负内正，形成动作电位。
3. 动作电位具有「全或无」的特点：刺激达到阈值就产生，且幅度不随刺激强度增大而增大。

**三个扣分点**：静息电位靠 **K⁺ 外流**、动作电位靠 **Na⁺ 内流**（写反必错）；**全或无**（超过阈值后幅度不变）；兴奋在神经纤维上**双向**传导、在突触处**单向**传递。

**四张图**：① 静息电位与 K⁺ 外流；② 动作电位的产生（Na⁺ 内流 → 去极化 → 复极化）；③ 全或无：不同刺激强度下的动作电位幅度；④ 突触处的单向传递（神经递质）。

**互动模型**：滑块＝刺激强度 I（0–150%，step 5，阈值在 100）
```js
ap  = I >= 100 ? 1 : 0;          // 是否产生动作电位（全或无）
amp = I >= 100 ? 100 : 0;        // 动作电位幅度（达阈值就满格）
```
`cases`：`{v:50,eq:{ap:0,amp:0}}`、`{v:100,eq:{ap:1,amp:100}}`、`{v:150,eq:{ap:1,amp:100}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:50},{t:6.5,v:50},{t:9,v:150},{t:11,v:100},{t:13,v:0}]`，keys `[0,50,100,150]`。
**停留帧在 I=100**（刚好到阈值：再小一点什么都没有，到这一点立刻满幅——「全或无」的临界帧）。
状态：I<100「阈下刺激，只有局部电位」；I=100「刚好达阈值，产生动作电位」；I>100「幅度与阈值时完全相同」。

**例题**：「刺激强度增大，动作电位的幅度会增大吗？」答案：不会。动作电位具有全或无的特点：刺激未达阈值不产生，达到阈值即产生且幅度恒定；强度增大只是频率可能增加。
**六问**：① 静息电位由哪种离子形成；② 动作电位由哪种离子内流形成；③ 全或无是什么意思；④ 神经纤维上传导是单向还是双向；⑤ 突触处为什么单向；⑥ 兴奋在突触处如何传递。
**易错**：✗ 静息电位靠 Na⁺ 内流 / ✗ 动作电位靠 K⁺ 外流 / ✗ 刺激越强幅度越大 / ✗ 神经纤维上单向传导 / ✗ 突触处双向传递 / ✗ 静息电位是零。

## xx1-c2-s4 神经系统的分级调节

**课本原话**
1. 神经系统对躯体运动和内脏活动的调节存在分级调节，一般说来，低级中枢受高级中枢的调控。
2. 大脑皮层是调节机体活动的最高级中枢。
3. 位于大脑皮层的排尿反射中枢可以控制脊髓的低级排尿中枢。

**三个扣分点**：**低级受高级调控**（不是各管各的）；排尿反射的**低级中枢在脊髓**、高级中枢在大脑皮层；分级调节的意义是让反应**更精准、更适应环境**。

**四张图**：① 中枢神经系统的分级层次（大脑皮层 → 脑干/脊髓）；② 排尿反射的两级控制；③ 高级中枢受损与低级中枢受损的不同表现；④ 分级调节让反应更适应环境。

**互动模型**：滑块＝大脑皮层对脊髓的抑制强度 k（0–100%，step 5）
```js
control = k;                       // 高级中枢的控制力（%）
vol     = k >= 60 ? 1 : 0;         // 能否自主控制排尿（阈值示意）
```
`cases`：`{v:0,eq:{control:0,vol:0}}`、`{v:60,eq:{control:60,vol:1}}`、`{v:100,eq:{control:100,vol:1}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:60},{t:6.5,v:60},{t:9,v:100},{t:11,v:80},{t:13,v:0}]`，keys `[0,60,80,100]`。
**停留帧在 k=60**（刚能自主控制的那一格：控制力不足时就会「憋不住」）。
状态：k<60「低级中枢自行其是，无法自主控制」；k≥60「高级中枢能抑制脊髓的排尿中枢」。

## xx1-c3-s2 激素调节的过程

**课本原话**
1. 血糖平衡的调节主要依靠胰岛素和胰高血糖素，二者作用相反。

## xx1-c3-s3 体液调节与神经调节的关系

## xx1-c4-s2 特异性免疫

**课本原话**
1. 特异性免疫包括体液免疫和细胞免疫，主要由淋巴细胞完成。
2. 体液免疫中，B 细胞受抗原刺激后增殖分化为浆细胞和记忆细胞，浆细胞分泌抗体。
3. 二次免疫反应比初次更快、更强，因为记忆细胞能迅速增殖分化。


**例题**：「为什么患过麻疹的人一般不会再患麻疹？为什么有的疫苗要打加强针？」答案：患过麻疹后体内留有记忆细胞，再次接触同种抗原时记忆细胞迅速增殖分化，产生大量抗体（二次免疫更快更强）；疫苗打加强针是为了产生更多记忆细胞，提高抗体水平。

## xx1-c4-s3 免疫失调

**课本原话**
1. 免疫功能过强或过弱都会引起免疫失调，包括过敏反应、自身免疫病和免疫缺陷病。
2. 过敏反应是已免疫的机体再次接触相同抗原时发生的组织损伤或功能紊乱。
3. 艾滋病（AIDS）是由 HIV 引起的免疫缺陷病，HIV 主要攻击辅助性 T 细胞。

**三个扣分点**：过敏是**再次接触**同种过敏原才发生（第一次不发病）；HIV 攻击的是**辅助性 T 细胞**（不是 B 细胞、不是红细胞）；免疫缺陷病是免疫功能**过弱**。

**四张图**：① 三类免疫失调的划分；② 过敏反应的两次接触过程；③ 自身免疫病的机制（抗体攻击自身）；④ HIV 感染后辅助性 T 细胞数量与免疫功能的变化。

**互动模型**：滑块＝过敏原剂量 dose（1–20，相对单位，step 1）
```js
symptom = 100 * dose / (dose + 3);      // 症状强度（%）
```
`cases`：`{v:1,eq:{symptom:25}}`、`{v:3,eq:{symptom:50}}`、`{v:10,eq:{symptom:76.9}}`。
Autopilot：`[{t:0,v:20},{t:1.2,v:20},{t:4,v:3},{t:6.5,v:3},{t:9,v:1},{t:11,v:6},{t:13,v:20}]`，keys `[1,3,6,20]`。
**停留帧在 dose=3**（症状强度刚好 50%：剂量再大，症状也涨得越来越慢——但不会消失）。
状态：dose≤2「轻度」；3–8「中度」；>8「重度，可能出现全身反应」。

**例题**：「有人第一次吃海鲜没事，第二次却出现皮疹，为什么？」答案：第一次接触时体内产生了针对该过敏原的抗体并吸附在细胞表面（处于致敏状态），但未发病；再次接触同种过敏原时，过敏原与抗体结合引起组织细胞释放组胺等物质，出现过敏反应。
**六问**：① 过敏为什么第一次不发病；② HIV 攻击什么细胞；③ 免疫缺陷病属于过强还是过弱；④ 自身免疫病是怎么回事；⑤ 过敏反应用什么药缓解；⑥ 三类失调怎么快速区分。
**易错**：✗ 第一次接触就过敏 / ✗ HIV 攻击 B 细胞 / ✗ 免疫缺陷是免疫过强 / ✗ 自身免疫病是免疫力低 / ✗ 过敏是免疫缺陷 / ✗ 过敏反应与抗体无关。

## xx1-c4-s4 免疫学的应用

**课本原话**
1. 疫苗是用微生物或其代谢产物制成的生物制品，接种后可刺激机体产生特异性免疫。
2. 器官移植成功的主要障碍是免疫排斥反应，需使用免疫抑制剂。
3. 当人群中有足够比例的人具有免疫力时，传染病就不容易在人群中传播，这称为群体免疫。

**三个扣分点**：疫苗的原理是**刺激机体自身产生抗体和记忆细胞**（不是直接注射抗体）；器官移植的排斥反应属于**细胞免疫**；群体免疫需要**足够比例**（不是「一部分人打了就行」）。

**四张图**：① 疫苗的作用机制（抗原→记忆细胞）；② 器官移植与免疫排斥；③ 群体免疫的阈值示意；④ 抗体检测与抗原检测的区别。

**互动模型**：滑块＝人群免疫比例 p（0–100%，step 1），基本传染数 R₀=3
```js
R    = 3 * (1 - p / 100);          // 有效传染数
herd = p >= 66.7 ? 1 : 0;          // 是否达到群体免疫阈值（1−1/R₀≈66.7%）
```
`cases`：`{v:0,eq:{R:3,herd:0}}`、`{v:50,eq:{R:1.5,herd:0}}`、`{v:80,eq:{R:0.6,herd:1}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:50},{t:6.5,v:50},{t:9,v:100},{t:11,v:67},{t:13,v:0}]`，keys `[0,50,67,100]`。
**停留帧在 p=67**（R 刚好降到 1 以下，传播开始萎缩——阈值那一格）。
状态：R>1「还能传播，疫情扩大」；R=1「临界」；R<1「传播萎缩，达到群体免疫」。

**例题**：「为什么麻疹疫苗需要覆盖约 95% 的人群，而有些传染病 70% 就够？」答案：群体免疫阈值约为 1−1/R₀；麻疹 R₀ 很高（约 12–18），阈值≈95%；R₀ 较低的疾病阈值也低，所以需要的覆盖率不同。
**六问**：① 疫苗是抗体吗；② 器官移植排斥属于哪种免疫；③ 群体免疫阈值怎么算；④ 为什么不同疫苗覆盖率要求不同；⑤ 免疫抑制剂为什么能提高移植成活率；⑥ 抗原检测和抗体检测差在哪。
**易错**：✗ 疫苗就是注射抗体 / ✗ 群体免疫只要有人打疫苗就行 / ✗ 移植排斥属于体液免疫 / ✗ 所有疫苗覆盖率要求一样 / ✗ 免疫抑制剂是增强免疫 / ✗ 接种疫苗后就再也不需要免疫系统。

## xx1-c5-s1 植物生长素

**课本原话**
1. 生长素主要的合成部位是幼嫩的芽、叶和发育中的种子。
2. 生长素的作用具有两重性：低浓度促进生长，高浓度抑制生长。
3. 不同器官对生长素的敏感程度不同：根 > 芽 > 茎。

**三个扣分点**：**两重性**（低促高抑，同一浓度对不同器官效果可能相反）；**根最敏感、茎最不敏感**（顺序写反必错）；生长素只能**从形态学上端向下端**极性运输（不是自由扩散）。

**四张图**：① 生长素的合成与运输（极性运输）；② 两重性曲线（低促高抑）；③ 根、芽、茎三条曲线的最适浓度不同；④ 顶端优势的解释。

**互动模型**：滑块＝生长素相对浓度 r（0.1–8，相对最适浓度的倍数，step 0.1）
```js
promo = 100 * (2 * r / (1 + r * r)) - 15 * Math.max(0, r - 4);   // 促进率（%），>4 后转抑制
```
`cases`：`{v:0.1,eq:{promo:19.8}}`、`{v:1,eq:{promo:100}}`、`{v:8,eq:{promo:-35.4}}`。
Autopilot：`[{t:0,v:0.1},{t:1.2,v:0.1},{t:4,v:1},{t:6.5,v:1},{t:9,v:8},{t:11,v:5},{t:13,v:0.1}]`，keys `[0.1,1,5,8]`。
**停留帧在 r=1**（促进率 100%，最适浓度——峰顶那一格）。
状态：r<1「浓度偏低，促进作用不足」；r≈1「最适浓度」；r>4「浓度过高，转为抑制」。

**例题**：「为什么植物表现出顶端优势？去掉顶芽后会怎样？」答案：顶芽产生的生长素向下运输，积累在侧芽处，侧芽对生长素敏感，浓度过高反而抑制其生长；去掉顶芽后侧芽处生长素浓度下降，侧芽生长加快。
**六问**：① 两重性是什么意思；② 根、芽、茎谁最敏感；③ 极性运输是哪个方向；④ 顶端优势怎么解释；⑤ 生长素能防止落花落果吗；⑥ 高浓度为什么抑制。
**易错**：✗ 生长素浓度越高长得越快 / ✗ 茎比根敏感 / ✗ 生长素自由扩散运输 / ✗ 顶端优势是因为顶芽抢营养 / ✗ 不同器官最适浓度相同 / ✗ 生长素是抑制生长的激素。

## xx1-c5-s2 其他植物激素

**课本原话**
1. 赤霉素能促进细胞伸长，引起植株增高，促进种子萌发和果实发育。
2. 脱落酸能抑制细胞分裂，促进叶和果实的衰老和脱落，维持种子休眠。
3. 乙烯能促进果实成熟；细胞分裂素能促进细胞分裂。

**三个扣分点**：**赤霉素促萌发、脱落酸促休眠**（一对拮抗，方向写反必错）；乙烯促进的是**成熟**（不是生长）；植物的生长发育是**多种激素共同调节**的结果。

**四张图**：① 五种激素的主要作用对照表；② 赤霉素与脱落酸在种子萌发上的拮抗；③ 乙烯与果实成熟；④ 激素间的协同与拮抗关系。

**互动模型**：滑块＝脱落酸浓度 a（0–10，相对单位，step 0.5）
```js
germ = 100 / (1 + Math.exp((a - 5) / 1.2));    // 种子萌发率（%）
```
`cases`：`{v:0,eq:{germ:98.5}}`、`{v:5,eq:{germ:50}}`、`{v:10,eq:{germ:1.5}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:5},{t:6.5,v:5},{t:9,v:10},{t:11,v:7},{t:13,v:0}]`，keys `[0,5,7,10]`。
**停留帧在 a=5**（萌发率 50%，赤霉素与脱落酸势均力敌的临界点）。
状态：a<3「萌发率高，脱落酸少」；a≈5「临界」；a>7「基本不萌发，维持休眠」。

**例题**：「为什么收获后的种子要保持干燥低温保存？」答案：低温干燥条件下脱落酸含量相对较高、赤霉素作用弱，种子维持休眠状态，呼吸作用弱，不易霉变和消耗营养，有利于保存。
**六问**：① 赤霉素和脱落酸的作用方向；② 乙烯促进什么；③ 细胞分裂素的作用；④ 激素之间是什么关系；⑤ 种子萌发受哪些激素影响；⑥ 果实成熟由哪种激素主导。
**易错**：✗ 赤霉素促进休眠 / ✗ 脱落酸促进萌发 / ✗ 乙烯促进细胞伸长 / ✗ 一种生理过程只由一种激素调节 / ✗ 细胞分裂素促进成熟 / ✗ 激素间只有协同没有拮抗。

## xx1-c5-s3 植物生长调节剂的应用

**课本原话**
1. 植物生长调节剂是人工合成的对植物生长发育有调节作用的化学物质。
2. 植物生长调节剂具有容易合成、原料广泛、效果稳定等优点。
3. 使用植物生长调节剂要综合考虑浓度、时期、植物种类等因素，否则可能产生副作用。

**三个扣分点**：调节剂是**人工合成**的（不是植物自己产生的激素）；效果稳定是因为**植物体内没有分解它的酶**；使用要**控制浓度和时期**，过量会残留或产生药害。

**四张图**：① 植物激素与植物生长调节剂的区别；② 乙烯利催熟的作用与过量后果；③ 2,4-D 作为除草剂的选择性原理；④ 使用调节剂的三要素（浓度、时期、种类）。

**互动模型**：滑块＝乙烯利浓度 c（0–100 mg/L，step 5）
```js
ripe = 100 * (1 - Math.exp(-c / 25));     // 成熟度（%）
```
`cases`：`{v:25,eq:{ripe:63.2}}`、`{v:50,eq:{ripe:86.5}}`、`{v:100,eq:{ripe:98.2}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:25},{t:6.5,v:25},{t:9,v:100},{t:11,v:50},{t:13,v:0}]`，keys `[0,25,50,100]`。
**停留帧在 c=25**（成熟度 63.2%，性价比最高的一段，再加浓度收益递减还增加残留）。
状态：c<15「催熟不足」；15–40「催熟合适」；>60「过量，可能影响品质和残留」。

**例题**：「用乙烯利催熟香蕉时，为什么不能随意加大浓度？」答案：超过适宜浓度后成熟度提升有限（趋于饱和），反而可能造成果实软化过度、品质下降和残留超标，还会影响储存运输。
**六问**：① 调节剂和激素的区别；② 调节剂为什么效果稳定；③ 使用时要考虑什么；④ 2,4-D 为什么能除双子叶杂草；⑤ 过量使用有什么后果；⑥ 调节剂属于农药吗。
**易错**：✗ 植物生长调节剂就是植物激素 / ✗ 浓度越高效果越好 / ✗ 任何时期使用效果一样 / ✗ 调节剂没有副作用 / ✗ 2,4-D 对所有植物都有害 / ✗ 调节剂可以随意加大用量。

## xx1-c5-s4 环境因素参与调节植物的生命活动

**课本原话**
1. 光、温度、重力等环境因素参与调节植物的生命活动。
2. 光不仅为植物提供能量，还作为一种信号影响种子的萌发、植株的生长与开花。
3. 植物的开花与日照长度有关：长日照植物需要较长日照才开花，短日照植物需要较短日照才开花。

**三个扣分点**：光既是**能量**也是**信号**（两层作用都要写）；长日照植物其实是「日照**长于**临界值才开花」；温度通过**春化作用**影响开花、重力影响根的向地性。

**四张图**：① 光作为信号影响开花；② 长日照与短日照植物的临界日长；③ 温度与春化作用；④ 重力与根的向地性、茎的背地性。

**互动模型**：滑块＝每日日照时数 h（8–16 小时，step 0.5）
```js
ld = Math.max(0, Math.min(100, (h - 11) / 6 * 100));   // 长日照植物开花指数
sd = 100 - ld;                                          // 短日照植物开花指数
```
`cases`：`{v:10,eq:{ld:0,sd:100}}`、`{v:14,eq:{ld:50,sd:50}}`、`{v:16,eq:{ld:83.3,sd:16.7}}`。
Autopilot：`[{t:0,v:8},{t:1.2,v:8},{t:4,v:14},{t:6.5,v:14},{t:9,v:16},{t:11,v:12},{t:13,v:8}]`，keys `[8,12,14,16]`。
**停留帧在 h=14**（两条曲线交叉：日照 14 小时，两类植物各有 50% 开花指数——临界日长附近）。
状态：h<12「短日照植物占优」；h≈14「临界附近，两类都可能开花」；h>15「长日照植物占优」。

**例题**：「把短日照植物放在长日照条件下，为什么不开花？这说明光起什么作用？」答案：日照长度是植物开花的信号，短日照植物的开花需要短于临界日长的日照；长日照条件不满足这个信号条件，所以不开花。说明光不只是能量来源，还作为信息调节植物的生命活动。
**六问**：① 光对植物有哪两层作用；② 长日照植物的含义；③ 春化作用是什么；④ 重力影响什么；⑤ 临界日长的意义；⑥ 光信号通过什么物质传递（光敏色素）。
**易错**：✗ 长日照植物是「需要光照时间越长越好」/ ✗ 光只提供能量 / ✗ 短日照植物在长日照下也能开花 / ✗ 温度只影响酶的活性 / ✗ 重力对植物没有影响 / ✗ 开花只由激素决定。
