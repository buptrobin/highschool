## xx1-c3-s2 激素调节的过程

**课本原话**
1. 血糖平衡的调节主要依靠胰岛素和胰高血糖素，二者作用相反。
2. 胰岛素由胰岛 B 细胞分泌，能促进组织细胞摄取、利用和储存葡萄糖，从而降低血糖。
3. 甲状腺激素分泌存在下丘脑—垂体—甲状腺的分级调节和负反馈调节。

**三个扣分点**：胰岛素**降血糖**、胰高血糖素**升血糖**（写反必错）；存在**负反馈**（激素过多会抑制上游）；分级调节是**下丘脑→垂体→靶腺**三级。

**四张图**：① 血糖的两条对抗通路；② 胰岛素与胰高血糖素随血糖变化的分泌曲线；③ 下丘脑—垂体—甲状腺的分级与负反馈；④ 反馈调节的意义（把偏离拉回来）。

**互动模型**：滑块＝血糖浓度 G（3–10 mmol/L，step 0.1）
```js
ins = 100 / (1 + Math.exp(-(G - 5.5) / 0.6));   // 胰岛素分泌（相对%）
glu = 100 - ins;                                 // 胰高血糖素分泌（相对%，示意对冲）
```
`cases`：`{v:4,eq:{ins:7.8}}`、`{v:5.5,eq:{ins:50}}`、`{v:8,eq:{ins:98.5}}`。
Autopilot：`[{t:0,v:3},{t:1.2,v:3},{t:4,v:5.5},{t:6.5,v:5.5},{t:9,v:10},{t:11,v:8},{t:13,v:3}]`，keys `[3,5.5,8,10]`。
**停留帧在 G=5.5**（两条曲线交叉：胰岛素与胰高血糖素各占一半，血糖正处在调定点上）。
状态：G<3.9「低血糖，胰高血糖素占优」；3.9–6.1「正常范围，二者平衡」；>6.1「胰岛素占优，血糖偏高」。

**例题**：「血糖升高时，胰岛素分泌增多，胰高血糖素分泌减少，这属于什么调节？有什么意义？」答案：属于（负）反馈调节；通过两种激素的拮抗作用把血糖拉回正常范围，维持血糖稳态。
**六问**：① 胰岛素和胰高血糖素的作用方向；② 胰岛素由什么细胞分泌；③ 血糖调节属于什么调节方式；④ 负反馈的意义；⑤ 甲状腺激素的分级调节三级是什么；⑥ 甲状腺激素过多会怎样抑制上游。
**易错**：✗ 胰岛素升血糖 / ✗ 血糖调节只有激素没有神经 / ✗ 反馈是正反馈 / ✗ 下丘脑直接分泌甲状腺激素 / ✗ 胰高血糖素由胰岛 B 细胞分泌 / ✗ 血糖正常时激素不分泌。
