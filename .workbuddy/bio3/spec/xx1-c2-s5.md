# 本节规格（只读这一节，不要读 SPEC.md 全文）

## xx1-c2-s5 人脑的高级功能

**课本原话**
1. 大脑皮层具有语言、学习、记忆和情绪等高级功能。
2. 语言功能是人脑特有的高级功能，与大脑皮层的言语区（W 区、S 区、H 区、V 区）有关。
3. 记忆的形成与多个脑区有关，其中海马区与短期记忆转化为长期记忆有关。

**三个扣分点**：四个言语区**位置与症状要一一对应**（S 区在中央前回下部、W 区在颞中回后部附近、V 区在枕叶、H 区在颞上回后部——按课本表述写，别编位置细节）；语言功能是**人脑特有**；记忆不是存在一个地方。

**四张图**：① 大脑皮层言语区分布示意；② 四个言语区受损后的表现对照；③ 感觉性失语与运动性失语的区分；④ 记忆的分级与海马区的作用。

**互动模型**：滑块＝受损的言语区序号 loc（1–4，依次为 S 区、W 区、V 区、H 区）
```js
locName = ['S 区（运动性言语区）','W 区（书写言语区）','V 区（视觉性言语区）','H 区（听觉性言语区）'][loc-1];
sym     = ['不能讲话','不能写字','看不懂文字','听不懂话'][loc-1];
```
`cases`：`{v:1,eq:{loc:1}}`、`{v:3,eq:{loc:3}}`、`{v:4,eq:{loc:4}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:2},{t:6.5,v:2},{t:9,v:4},{t:11,v:3},{t:13,v:1}]`，keys `[1,2,3,4]`。
**停留帧在 loc=2**（W 区：能听懂、能说话，但写不出字——四个症状里最容易被张冠李戴的一个）。
状态：按 loc 输出对应症状，并给一句「其他功能多半完好」。

**例题**：「某人能听懂别人说话、也能写字，但说话含糊不成句，最可能是哪个区受损？」答案：S 区（运动性言语区）受损，表现为运动性失语症。
**六问**：① 四个言语区分别管什么；② 哪个区受损会「听不懂」；③ 语言功能是人和动物共有的吗；④ 记忆存在大脑的哪个部位；⑤ 海马区的作用；⑥ 情绪属于高级功能吗。
**易错**：✗ V 区受损是不能说话 / ✗ H 区受损是看不懂文字 / ✗ 语言功能动物也有 / ✗ 记忆只存在海马区 / ✗ 四个言语区可以互相替代 / ✗ 大脑皮层只有语言功能。
