# 本节规格（只读这一节，不要读 SPEC.md 全文）

## xx1-c4-s2 特异性免疫

**课本原话**
1. 特异性免疫包括体液免疫和细胞免疫，主要由淋巴细胞完成。
2. 体液免疫中，B 细胞受抗原刺激后增殖分化为浆细胞和记忆细胞，浆细胞分泌抗体。
3. 二次免疫反应比初次更快、更强，因为记忆细胞能迅速增殖分化。

**三个扣分点**：**浆细胞不能识别抗原**（它只分泌抗体，这一步最容易被扣分）；抗体只存在于**体液**中；二次免疫**更快更强**是因为**记忆细胞**，不是抗体变多了。

**四张图**：① 体液免疫的完整流程（抗原→辅助性 T 细胞→B 细胞→浆细胞→抗体）；② 细胞免疫的完整流程（靶细胞→细胞毒性 T 细胞）；③ 初次免疫与二次免疫的抗体量曲线；④ 记忆细胞的作用。

**互动模型**：滑块＝距首次接触的天数 d（0–40 天，step 1），第 14 天再次接触同种抗原
```js
// 初次峰在第 10 天（100），二次峰在第 17 天（600）
v = d <= 10 ? 100 * Math.pow(d / 10, 2) : Math.max(0, 100 - (d - 10) * 6);
if (d >= 14) v = Math.max(v, 600 * Math.exp(-Math.pow(d - 17, 2) / 8));
```
`cases`：`{v:5,eq:{v:25}}`、`{v:10,eq:{v:100}}`、`{v:17,eq:{v:600}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:10},{t:6.5,v:10},{t:9,v:17},{t:11,v:14},{t:13,v:0}]`，keys `[0,10,14,17]`。
**停留帧在 d=17**（二次峰 600，是初次峰 100 的 6 倍——「为什么疫苗要打加强针」）。
状态：d<7「初次应答上升中」；d=10「初次峰」；d≥14「二次应答：更快更高」。

**例题**：「为什么患过麻疹的人一般不会再患麻疹？为什么有的疫苗要打加强针？」答案：患过麻疹后体内留有记忆细胞，再次接触同种抗原时记忆细胞迅速增殖分化，产生大量抗体（二次免疫更快更强）；疫苗打加强针是为了产生更多记忆细胞，提高抗体水平。
**六问**：① 浆细胞能识别抗原吗；② 抗体在哪儿起作用；③ 二次免疫为什么快；④ 细胞免疫针对什么；⑤ 记忆细胞从哪来；⑥ 体液免疫和细胞免疫怎么配合。
**易错**：✗ 浆细胞能识别抗原 / ✗ 抗体在细胞内起作用 / ✗ 二次免疫是因为抗体一直存在 / ✗ 细胞免疫由 B 细胞完成 / ✗ 记忆细胞就是浆细胞 / ✗ 二次免疫不需要抗原刺激。
