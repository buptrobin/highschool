# 本节规格（只读这一节，不要读 SPEC.md 全文）

## xx1-c3-s1 激素与内分泌系统

**课本原话**
1. 内分泌腺没有导管，分泌的激素直接进入腺体内的毛细血管，随血液运输到全身。
2. 激素调节具有微量高效、通过体液运输、作用于靶器官靶细胞的特点。
3. 激素一经靶细胞接受并起作用后就被灭活。

**三个扣分点**：激素**微量高效**（不是「量多才有效」）；**作用于靶器官、靶细胞**（不是作用于全身所有细胞）；激素**不起催化作用**、只起调节作用，作用后被灭活。

**四张图**：① 内分泌腺与外分泌腺的区别（有无导管）；② 激素的运输路径（分泌→血液→靶细胞）；③ 剂量—效应曲线（低剂量上升、高剂量饱和）；④ 激素与酶、神经递质的比较表。

**互动模型**：滑块＝激素剂量 d（1–100 单位，step 1）
```js
resp = 100 * d / (d + 10);      // 反应强度（%），d=10 时半最大
```
`cases`：`{v:1,eq:{resp:9.09}}`、`{v:10,eq:{resp:50}}`、`{v:100,eq:{resp:90.9}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:10},{t:6.5,v:10},{t:9,v:100},{t:11,v:60},{t:13,v:1}]`，keys `[1,10,60,100]`。
**停留帧在 d=10**（半最大效应：再往上加剂量，反应涨得越来越慢——「加量不等于加效」）。
状态：d<5「低剂量，反应随剂量快速上升」；d≈10「半最大效应」；d>50「接近饱和，加量收益很小」。

**例题**：「为什么激素在血液中含量极低却能引起明显反应，而持续大量注射反而效果不再增加？」答案：激素微量高效、与靶细胞受体结合起调节作用；受体数量有限，剂量过高时受体饱和，反应不再增加。
**六问**：① 内分泌腺和外分泌腺的区别；② 激素通过什么运输；③ 为什么说微量高效；④ 激素作用于哪些细胞；⑤ 激素作用后怎样；⑥ 激素能起催化作用吗。
**易错**：✗ 激素量越多效果越好 / ✗ 激素作用于全身所有细胞 / ✗ 激素是酶 / ✗ 激素作用后可以反复使用 / ✗ 内分泌腺有导管 / ✗ 激素直接参与代谢反应。
