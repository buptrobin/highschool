## xx1-c4-s1 免疫系统的组成和功能

**课本原话**
1. 免疫系统包括免疫器官、免疫细胞和免疫活性物质。
2. 免疫系统具有免疫防御、免疫自稳和免疫监视三大功能。
3. 人体的三道防线：皮肤和黏膜及其分泌物、体液中的杀菌物质和吞噬细胞、特异性免疫。

**三个扣分点**：**三道防线的对应关系**（第一、二道是非特异性，第三道才是特异性）；免疫活性物质包括抗体、细胞因子、溶菌酶（不只有抗体）；免疫自稳是清除衰老损伤细胞，免疫监视是识别清除突变细胞。

**四张图**：① 免疫系统的三个组成部分；② 三道防线的层级与特异性；③ 三大功能与对应疾病；④ 第一道防线破损后各道防线的负担。

**互动模型**：滑块＝皮肤黏膜屏障完整度 b（0–100%，step 5）
```js
enter  = 100 - b;                    // 进入体内的病原体比例（%）
remain = enter * 0.1;                // 第二道防线后残余（%，示意 90% 清除率）
```
`cases`：`{v:100,eq:{enter:0,remain:0}}`、`{v:50,eq:{enter:50,remain:5}}`、`{v:0,eq:{enter:100,remain:10}}`。
Autopilot：`[{t:0,v:100},{t:1.2,v:100},{t:4,v:50},{t:6.5,v:50},{t:9,v:0},{t:11,v:25},{t:13,v:100}]`，keys `[0,25,50,100]`。
**停留帧在 b=50**（屏障破一半，进入 50%，第二道顶掉九成后还有 5% 需要第三道——「为什么小伤口通常不生病」）。
状态：b≥80「第一道基本完好」；50–80「有破损，第二道负担加重」；<50「大量病原体进入，必须依赖特异性免疫」。

**例题**：「皮肤大面积烧伤的病人为什么容易发生感染？」答案：皮肤和黏膜构成第一道防线（非特异性免疫），大面积损伤后屏障功能丧失，病原体容易侵入，机体主要依靠第二、三道防线，感染风险显著增加。
**六问**：① 免疫系统由哪三部分组成；② 三道防线哪几道是非特异性的；③ 免疫活性物质只有抗体吗；④ 免疫自稳和免疫监视的区别；⑤ 吞噬细胞属于第几道防线；⑥ 溶菌酶属于哪道防线。
**易错**：✗ 三道防线都是特异性免疫 / ✗ 免疫活性物质只有抗体 / ✗ 自稳是清除突变细胞 / ✗ 吞噬细胞只参与特异性免疫 / ✗ 免疫器官只有骨髓和胸腺 / ✗ 第一道防线破损后不影响其他防线。
