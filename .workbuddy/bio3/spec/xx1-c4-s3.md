## xx1-c4-s3 免疫失调

**课本原话**
1. 免疫功能过强或过弱都会引起免疫失调，包括过敏反应、自身免疫病和免疫缺陷病。
2. 过敏反应是已免疫的机体再次接触相同抗原时发生的组织损伤或功能紊乱。
3. 艾滋病（AIDS）是由 HIV 引起的免疫缺陷病，HIV 主要攻击辅助性 T 细胞。

**三个扣分点**：过敏是**再次接触**同种过敏原才发生（第一次不发病）；HIV 攻击的是**辅助性 T 细胞**（不是 B 细胞、不是红细胞）；免疫缺陷病是免疫功能**过弱**。

**四张图**：① 三类免疫失调的划分；② 过敏反应的两次接触过程；③ 自身免疫病的机制（抗体攻击自身）；④ HIV 感染后辅助性 T 细胞数量与免疫功能的变化。

**互动模型**：滑块＝过敏原剂量 dose（1–20，相对单位，step 1）
```js
symptom = 100 * dose / (dose + 3);      // 症状强度（%）
```
`cases`：`{v:1,eq:{symptom:25}}`、`{v:3,eq:{symptom:50}}`、`{v:10,eq:{symptom:76.9}}`。
Autopilot：`[{t:0,v:20},{t:1.2,v:20},{t:4,v:3},{t:6.5,v:3},{t:9,v:1},{t:11,v:6},{t:13,v:20}]`，keys `[1,3,6,20]`。
**停留帧在 dose=3**（症状强度刚好 50%：剂量再大，症状也涨得越来越慢——但不会消失）。
状态：dose≤2「轻度」；3–8「中度」；>8「重度，可能出现全身反应」。

**例题**：「有人第一次吃海鲜没事，第二次却出现皮疹，为什么？」答案：第一次接触时体内产生了针对该过敏原的抗体并吸附在细胞表面（处于致敏状态），但未发病；再次接触同种过敏原时，过敏原与抗体结合引起组织细胞释放组胺等物质，出现过敏反应。
**六问**：① 过敏为什么第一次不发病；② HIV 攻击什么细胞；③ 免疫缺陷病属于过强还是过弱；④ 自身免疫病是怎么回事；⑤ 过敏反应用什么药缓解；⑥ 三类失调怎么快速区分。
**易错**：✗ 第一次接触就过敏 / ✗ HIV 攻击 B 细胞 / ✗ 免疫缺陷是免疫过强 / ✗ 自身免疫病是免疫力低 / ✗ 过敏是免疫缺陷 / ✗ 过敏反应与抗体无关。
