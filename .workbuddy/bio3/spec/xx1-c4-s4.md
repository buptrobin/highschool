## xx1-c4-s4 免疫学的应用

**课本原话**
1. 疫苗是用微生物或其代谢产物制成的生物制品，接种后可刺激机体产生特异性免疫。
2. 器官移植成功的主要障碍是免疫排斥反应，需使用免疫抑制剂。
3. 当人群中有足够比例的人具有免疫力时，传染病就不容易在人群中传播，这称为群体免疫。

**三个扣分点**：疫苗的原理是**刺激机体自身产生抗体和记忆细胞**（不是直接注射抗体）；器官移植的排斥反应属于**细胞免疫**；群体免疫需要**足够比例**（不是「一部分人打了就行」）。

**四张图**：① 疫苗的作用机制（抗原→记忆细胞）；② 器官移植与免疫排斥；③ 群体免疫的阈值示意；④ 抗体检测与抗原检测的区别。

**互动模型**：滑块＝人群免疫比例 p（0–100%，step 1），基本传染数 R₀=3
```js
R    = 3 * (1 - p / 100);          // 有效传染数
herd = p >= 66.7 ? 1 : 0;          // 是否达到群体免疫阈值（1−1/R₀≈66.7%）
```
`cases`：`{v:0,eq:{R:3,herd:0}}`、`{v:50,eq:{R:1.5,herd:0}}`、`{v:80,eq:{R:0.6,herd:1}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:50},{t:6.5,v:50},{t:9,v:100},{t:11,v:67},{t:13,v:0}]`，keys `[0,50,67,100]`。
**停留帧在 p=67**（R 刚好降到 1 以下，传播开始萎缩——阈值那一格）。
状态：R>1「还能传播，疫情扩大」；R=1「临界」；R<1「传播萎缩，达到群体免疫」。

**例题**：「为什么麻疹疫苗需要覆盖约 95% 的人群，而有些传染病 70% 就够？」答案：群体免疫阈值约为 1−1/R₀；麻疹 R₀ 很高（约 12–18），阈值≈95%；R₀ 较低的疾病阈值也低，所以需要的覆盖率不同。
**六问**：① 疫苗是抗体吗；② 器官移植排斥属于哪种免疫；③ 群体免疫阈值怎么算；④ 为什么不同疫苗覆盖率要求不同；⑤ 免疫抑制剂为什么能提高移植成活率；⑥ 抗原检测和抗体检测差在哪。
**易错**：✗ 疫苗就是注射抗体 / ✗ 群体免疫只要有人打疫苗就行 / ✗ 移植排斥属于体液免疫 / ✗ 所有疫苗覆盖率要求一样 / ✗ 免疫抑制剂是增强免疫 / ✗ 接种疫苗后就再也不需要免疫系统。
