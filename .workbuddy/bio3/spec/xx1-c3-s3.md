## xx1-c3-s3 体液调节与神经调节的关系

**课本原话**
1. 体温调节和水盐平衡调节都是神经调节和体液调节共同作用的结果。
2. 寒冷时，皮肤冷觉感受器兴奋，通过神经—体液调节使产热增加、散热减少。
3. 炎热时，主要通过增加散热来维持体温相对稳定。

**三个扣分点**：体温调节**既有神经也有体液**（写「只有神经」必扣分）；寒冷时**产热增加且散热减少**（两个方向都写）；炎热时以**增加散热**为主（不是减少产热为主）。

**四张图**：① 寒冷环境下的调节路径（冷觉感受器→下丘脑→甲状腺激素/肾上腺素 + 皮肤血管收缩）；② 炎热环境下的调节路径（汗腺分泌增加、皮肤血管舒张）；③ 产热量与散热量随环境温度的两条曲线；④ 体温调节失调（中暑、失温）。

**互动模型**：滑块＝环境温度 T（−10 到 40 ℃，step 1）
```js
heat = 100 + Math.max(0, 20 - T) * 2.5;    // 产热（相对%），低温靠寒战和激素
loss = 100 + Math.max(0, T - 28) * 4;      // 散热（相对%），高温靠出汗
```
`cases`：`{v:-10,eq:{heat:175,loss:100}}`、`{v:25,eq:{heat:100,loss:100}}`、`{v:40,eq:{heat:100,loss:148}}`。
Autopilot：`[{t:0,v:40},{t:1.2,v:40},{t:4,v:25},{t:6.5,v:25},{t:9,v:-10},{t:11,v:5},{t:13,v:40}]`，keys `[-10,5,25,40]`。
**停留帧在 T=25**（产热与散热都回到 100，两条线重合——「体温稳定时产热=散热」）。
状态：T<20「靠增加产热（寒战、甲状腺激素）并减少散热」；20–28「产热散热基本平衡」；>28「靠增加散热（出汗、血管舒张）」。

**例题**：「寒冷环境中，人体通过哪些途径维持体温？属于什么调节方式？」答案：冷觉感受器兴奋→下丘脑体温调节中枢→皮肤血管收缩、汗腺分泌减少（减少散热），骨骼肌战栗、甲状腺激素和肾上腺素分泌增多（增加产热）；属于神经—体液调节。
**六问**：① 寒冷时散热减少吗；② 炎热时主要靠什么；③ 体温调节中枢在哪；④ 甲状腺激素在体温调节中的作用；⑤ 为什么说产热=散热时体温稳定；⑥ 中暑是哪个环节出了问题。
**易错**：✗ 寒冷时只增加产热 / ✗ 体温调节只有神经调节 / ✗ 炎热时主要减少产热 / ✗ 体温调节中枢在大脑皮层 / ✗ 出汗是被动散热不需要调节 / ✗ 产热和散热可以不相等而体温不变。
