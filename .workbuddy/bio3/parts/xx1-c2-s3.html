上一节讲清了反射弧的五个环节，这一节把镜头推进到一条神经纤维的膜上：同一张膜，静息时是「外正内负」，兴奋时翻转成「外负内正」，靠的是两种离子走两个方向。整节最容易错的只有三件事——把 K⁺ 和 Na⁺ 记反、以为刺激越强动作电位越高、以为兴奋在神经纤维上也单向跑。这三件事在这一页里各出现两次以上，读完请自己复述一遍。

01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 静息电位人教版（2019）选择性必修1 · 第2章第3节

静息时，神经纤维膜电位表现为外正内负，称为静息电位，主要由 K⁺ 外流形成。

→ 翻成人话：这句话由三个条件组成：① 状态是「静息」（没有刺激）；② 表现是「外正内负」；③ 原因是「K⁺ 外流」——不是 Na⁺ 内流，也不是「膜内外没有离子」。少写第③条，「主要由」就变成了「仅仅由」，遇到「还与其他离子有关」的选项会判错。

课本原话 · 动作电位人教版（2019）选择性必修1 · 第2章第3节

受刺激后，Na⁺ 内流，膜电位变为外负内正，形成动作电位。

→ 翻成人话：同样是三个条件：① 前提是「受刺激且达到阈值」；② 原因是「Na⁺ 内流」；③ 结果是「外负内正」，即膜内电位由负变正、膜外由正变负。注意「内流」两个字是判分点——写「Na⁺ 外流」或「K⁺ 内流」一律零分。

课本原话 · 全或无人教版（2019）选择性必修1 · 第2章第3节

动作电位具有「全或无」的特点：刺激达到阈值就产生，且幅度不随刺激强度增大而增大。

→ 翻成人话：两个条件缺一不可：① 「达到阈值就产生」说的是有无——阈值以下一点都没有，一到阈值立刻满幅；② 「幅度不随强度增大」说的是大小——阈值以上的刺激只改变放电频率，不改变单个动作电位的高度。很多人只记住前半句，于是答成「刺激越强幅度越大」。

03自己拖一下核心

拖「刺激强度 I」，看左边那条纤维有没有产生动作电位、右边两个数怎么跟着变。盯住 I = 100% 这个临界点。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 全或无与传导方向必考

给一条离体的神经纤维施加刺激：
（1）刺激强度刚好达到阈值后，再增大到 3 倍，动作电位的幅度会增大吗？说明理由。
（2）若刺激强度低于阈值，会出现什么现象？
（3）在纤维中段刺激，兴奋向哪个方向传导？若在突触处，又能向哪个方向传递？

  1. 第 1 步 · 审题定性

    题目问的是「幅度」，不是「有没有」。凡是问幅度、峰高、大小的，直接锁定课本那句话：动作电位具有全或无的特点。

    用到：动作电位的全或无。

  2. 第 2 步 · 分两种情况作答

    阈值以下：没有动作电位，只有局部电位，幅度为 0；阈值及以上：立即产生动作电位，且幅度恒定。所以「刚好阈值」和「阈值的 3 倍」产生的是同一个高度的动作电位。

    用到：I ≥ 阈值 → 幅度恒定。

  3. 第 3 步 · 说清「那变的是什么」

    刺激增强真正改变的是单位时间内动作电位的次数，也就是放电频率；幅度不变。答题时补上这一句，才不会被追问扣分。

    用到：幅度与频率是两个量。

  4. 第 4 步 · 分开写传导方向

    神经纤维上：兴奋由刺激点向两侧传导，是双向的。突触处：递质只能由突触前膜释放作用于后膜受体，是单向的。两个空各占一分，不要合并成一句「单向传导」。

    用到：纤维双向、突触单向。

1 / 4

标准答案（可抄进答题卡）

（1）不会增大。动作电位具有全或无的特点：刺激未达到阈值时不产生动作电位；一旦达到阈值即产生动作电位，且其幅度不随刺激强度的增大而增大。刺激增强只会使单位时间内产生的动作电位次数（频率）增多。
（2）不产生动作电位，仅在刺激部位出现局部电位（电位变化幅度小、不能远距离传导）。
（3）在神经纤维中段刺激，兴奋沿纤维向两侧传导，即双向传导；在突触处，神经递质只能由突触前膜释放并作用于突触后膜上的受体，因此只能单向传递。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「静息电位到底是哪种离子弄出来的？」

静息时膜主要对 K⁺ 通透，K⁺ 顺浓度梯度外流，把正电荷带到膜外，于是膜外正、膜内负，这个电位差就是静息电位。写「Na⁺ 内流」是把静息和兴奋记反了。

「动作电位是哪一种离子内流形成的？」

受刺激后 Na⁺ 通道开放、Na⁺ 内流，膜内正电荷增多，膜电位由外正内负变成外负内正，这就是去极化，也就是动作电位的上升段。下降段才是 K⁺ 外流。

「全或无到底是什么意思？刺激强一点峰会不会高一点？」

不会。刺激未达阈值不产生动作电位；一旦达到阈值就立即产生且幅度恒定，再加大刺激幅度也不变，只可能让放电频率变高。所以「全或无」同时管有无和大小。

「神经纤维上的传导是单向还是双向？」

在纤维中段给一个足够强的刺激，兴奋同时向两侧传导，是双向的。只有经过突触时才是单向。题目问「离体纤维中段刺激」就答双向。

「突触处为什么只能单向传递？」

因为神经递质只存在于突触前膜内的小泡中，只能由前膜释放到间隙，再作用于后膜上的受体；后膜没有小泡、也不能把递质送回去。结构决定了方向。

「兴奋在突触处是怎么传过去的？过程要怎么写？」

按四步写：① 兴奋传到突触小体；② 突触小泡与突触前膜融合，释放神经递质到突触间隙；③ 递质与突触后膜上的受体结合；④ 后膜产生电位变化，兴奋传到下一个神经元。注意：这里实现了「电信号 → 化学信号 → 电信号」的转换。

这六问其实是同一件事的两面：先问「哪种离子、往哪个方向」（K⁺ 外流 / Na⁺ 内流），再问「能不能往回走」（纤维双向、突触单向）。把这两组答案背成条件反射，本节的选择题基本不会失分。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 静息电位是由 Na⁺ 内流形成的。

✓ 静息时膜电位表现为外正内负，主要由 K⁺ 外流形成。

错在哪：把静息和兴奋的离子记反了。静息往外（K⁺ 出），兴奋往里（Na⁺ 进）——「静出兴进」四个字先记牢。

✗ 动作电位是由 K⁺ 外流形成的。

✓ 受刺激后 Na⁺ 内流，膜电位变为外负内正，形成动作电位。

错在哪：K⁺ 外流负责的是复极化（下降段）和静息电位，不是动作电位的上升段。一个动作电位里两种离子都要出场，别只认一个。

✗ 刺激越强，动作电位的幅度越大。

✓ 动作电位具有全或无的特点，达到阈值后幅度不随刺激强度增大而增大，刺激增强只使放电频率升高。

错在哪：把「频率」当成了「幅度」。作图题里画出「刺激越强峰越高」，这一整问的分就没了。

✗ 兴奋在神经纤维上是单向传导的。

✓ 兴奋在神经纤维上双向传导，在突触处才单向传递。

错在哪：把突触的性质套到了纤维上。题干只要出现「离体神经纤维中段刺激」，答案一定是双向。

✗ 兴奋在突触处可以双向传递。

✓ 神经递质只能由突触前膜释放，作用于突触后膜上的受体，故突触处单向传递。

错在哪：只看「间隙很窄、递质能扩散」，没看递质装在谁家里。方向由结构决定，不由距离决定。

✗ 静息电位就是零，膜内外电位相等。

✓ 静息电位是外正内负的电位差，约 −70 mV，不是零。

错在哪：把「电荷总量大致相等」当成「电位相等」。有电位差才有「外正内负」这个说法，写成零就自相矛盾。

✗ 静息电位的形成需要消耗 ATP，所以静息时也在耗能。

✓ 静息电位主要由 K⁺ 外流（协助扩散）形成，不直接耗能；恢复和维持膜内外离子浓度差靠 Na⁺-K⁺ 泵主动运输，才消耗 ATP。

错在哪：把「维持浓度差」和「形成电位差」混成一件事。前者耗能，后者不耗能。

最后一遍自检：合上讲义，能不能用一句话说清「静息 K⁺ 出、兴奋 Na⁺ 进、过了阈值就满幅、纤维双向突触单向」？能，这一节就过关了。
