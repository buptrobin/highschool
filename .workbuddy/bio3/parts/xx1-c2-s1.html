01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 神经系统的组成人教版（2019）选择性必修1 · 第2章第1节

神经系统包括中枢神经系统和外周神经系统，中枢神经系统包括脑和脊髓。

→ 翻成人话：这句话是两级分类（①中枢＝脑＋脊髓；②外周＝脑神经＋脊神经），不是并列三样东西。注意「外周神经系统」里不含脑和脊髓本身，只含从它们发出的神经。

课本原话 · 神经元人教版（2019）选择性必修1 · 第2章第1节

神经元是神经系统结构和功能的基本单位，由细胞体、树突和轴突构成。

→ 翻成人话：这句有三个条件：①「结构和功能」两个「基本单位」都要写全；②三部分＝细胞体＋树突＋轴突；③髓鞘是包在轴突外面的结构，不算神经元的第四个组成部分。

课本原话 · 反射弧人教版（2019）选择性必修1 · 第2章第1节

反射的结构基础是反射弧，包括感受器、传入神经、神经中枢、传出神经和效应器。

→ 翻成人话：五个环节按箭头顺序固定：感受器 → 传入神经 → 神经中枢 → 传出神经 → 效应器。五个环节缺一不可，砍掉任何一段，反射都不能完成。

比什么有反应有反射
经过的路径刺激 → 肌肉（可绕过神经中枢）感受器 → 传入神经 → 神经中枢 → 传出神经 → 效应器
要不要神经中枢不一定必须有，且必须完整
常见例子离体肌肉直接受刺激而收缩缩手反射、膝跳反射、眨眼反射
能不能叫反射不能，只能叫「反应」能，判据是完整反射弧

背法：中枢＝脑＋脊髓，外周＝脑神经＋脊神经；反射弧按「感—传—中—传—效」五个字背，答题必须五个词全写，写「神经」两个字不给分。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 损伤定位与结论表述必考

某人脊髓胸段受损，针刺足部能感觉到痛，但不能完成缩腿动作。请回答：（1）有感觉说明反射弧的哪些部分完好？（2）不能缩腿是否说明效应器一定受损？为什么？

  1. 第 1 步 · 审题／定性

    题干只给两个现象：「有感觉」和「不能缩腿」。把这两个现象各自换成一条通路去查，不要一上来就猜「神经断了」。

    用到：反射与感觉走的是两条路——感觉要上行到大脑皮层，反射只走到效应器。

  2. 第 2 步 · 拆「有感觉」

    痛觉在大脑皮层形成。针刺足部能感觉到痛，说明感受器→传入神经→脊髓→上行传导束→大脑皮层这一路是通的。

    用到：感觉的形成部位是大脑皮层，不是脊髓；有感觉只证明「传入＋上行」完好。

  3. 第 3 步 · 拆「不能缩腿」

    缩腿是反射，必须走完五段。现在传入和上行都通，问题只能出在脊髓内的中间通路或传出神经、效应器这一段。

    用到：反射弧五个环节缺一不可，断在中枢之后同样完不成反射。

  4. 第 4 步 · 排陷阱

    「不能缩腿」推不出「效应器坏了」：效应器（传出神经末梢及其支配的肌肉）如果本身正常，直接用电流刺激仍会收缩。「有感觉」也推不出「有反射」。

    用到：有反应不等于有反射；有感觉也不等于有反射。

  5. 第 5 步 · 写出答案

    按「现象 → 结构 → 结论」三句写，每句一个术语，不写「神经坏了」这种笼统话。

    用到：分点作答，术语到位。

1 / 5

标准答案（可抄进答题卡）

（1）针刺足部能在大脑皮层形成痛觉，说明感受器、传入神经以及脊髓的上行传导束完好。
（2）不能。缩腿反射的反射弧包括感受器、传入神经、神经中枢、传出神经和效应器，五个环节缺一不可；本例最可能是脊髓内的神经中枢通路或传出神经被阻断，效应器本身可能仍正常，用直接刺激可使其收缩。有感觉不等于有反射，有反应也不等于有反射。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

反射弧的五个环节到底是哪五个？顺序能换吗？

按信号走的方向背：感受器 → 传入神经 → 神经中枢 → 传出神经 → 效应器，顺序固定不能换。答题时五个词写全，只写「神经」不给分。

效应器就是肌肉吗？答「肌肉」为什么扣分？

不完整。效应器是传出神经末梢及其支配的肌肉或腺体，少了「传出神经末梢」这四个字，就等于把神经和肌肉切开，判据丢了。

肌肉被直接刺激收缩了，有反应就算有反射吗？

不算。反射必须经过完整反射弧，并且由刺激引起的反应；绕过神经中枢的收缩只是肌肉的反应，不是反射。

中枢神经系统包括什么？和「神经中枢」是一回事吗？

中枢神经系统＝脑＋脊髓（结构概念）；神经中枢是反射弧里的一段环节，指脑或脊髓中负责某一反射的神经元群。两者层级不同，不能混用。

神经元由哪几部分组成？髓鞘算一部分吗？

三部分：细胞体、树突、轴突。髓鞘包在轴突外面，起绝缘和加快传导的作用，答题时不要把它当第四个组成部分。

神经胶质细胞只是「填充物」吗？

不是。神经胶质细胞数量远多于神经元，起支持、保护、营养和修复等作用，还参与构成髓鞘。把功能说成「填充」是常见失分点。

这六问其实是同一件事：先分清「结构层次」（中枢／外周、神经元三部分），再守住「反射弧五环节缺一不可」这条判据，最后把「有反应」「有感觉」「有反射」三个词分开写。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 效应器就是肌肉。

✓ 效应器是传出神经末梢及其支配的肌肉或腺体。

错在哪：漏掉「传出神经末梢」，就把效应器缩成了肌肉，判据不完整——只答肌肉一律扣分。

✗ 反射弧缺一个环节也能完成反射，只要刺激够强。

✓ 反射弧五个环节缺一不可，任一环节损伤反射都不能完成。

错在哪：把「刺激强度」当变量。缺环节是结构断裂，刺激再强信号也传不过去。

✗ 有感觉就说明反射正常。

✓ 有感觉只说明传入神经和上行传导束完好；反射还要求传出部分完好。

错在哪：把「感觉通路」和「反射通路」当成一条。神经中枢或传出神经损伤时，有感觉但无反射。

✗ 中枢神经系统包括脑神经和脊神经。

✓ 中枢神经系统包括脑和脊髓；脑神经和脊神经属于外周神经系统。

错在哪：「中枢」和「外周」按位置分，脑神经、脊神经在颅腔和椎管外，是外周。

✗ 神经元只有轴突，树突可有可无。

✓ 神经元由细胞体、树突和轴突构成，三部分缺一不可。

错在哪：把「树突多而短」误当成「不重要」。树突负责接收并传向细胞体，是结构组成之一。

✗ 神经胶质细胞只是填充物，没有功能。

✓ 神经胶质细胞对神经元起支持、保护、营养和修复作用，并参与构成髓鞘。

错在哪：把「数量多、不直接传导冲动」误读成「没功能」。

✗ 刺激肌肉引起收缩，属于反射。

✓ 只有经过完整反射弧、由刺激引起的反应才叫反射；直接刺激肌肉引起的收缩不是反射。

错在哪：有反应不等于有反射——绕过了感受器和神经中枢，就只剩肌肉的反应。

收尾记一句：本节所有失分都出在「词写不全」和「路没走完」——五个环节写全、效应器写全、反射与感觉分开说。
