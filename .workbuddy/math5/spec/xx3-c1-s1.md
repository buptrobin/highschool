## xx3-c1-s1 分类加法计数原理与分步乘法计数原理

**课本原话**
1. 完成一件事有两类不同方案，在第 1 类方案中有 m 种不同的方法，在第 2 类方案中有 n 种不同的方法，那么完成这件事共有 N=m+n 种不同的方法。
2. 完成一件事需要两个步骤，做第 1 步有 m 种不同的方法，做第 2 步有 n 种不同的方法，那么完成这件事共有 N=m×n 种不同的方法。
3. 分类要「不重不漏」，分步要「步步相依」。

**三个扣分点**：「分类」用加法、「分步」用乘法，判据是**这件事做完了没有**（做完→加，没做完→乘）；分类必须不重不漏；分步中间任何一步缺失都不算完成。

**四张图**：① 分类加法（两条并列的路，终点相同）；② 分步乘法（两段必须都走完）；③ 判据：做完没做完；④ 一个既有分类又有分步的复合例子（先分类、类内分步）。

**互动模型**：滑块＝上衣件数 m（1 到 6，step 1），下装固定 3 件
```js
ways = m * 3;                    // 分步乘法：先选上衣再选裤子
mix  = m + 3;                    // 对照：分类加法（只有上衣或只有裤子时才用）
```
`cases`：`{v:1,eq:{ways:3}}`、`{v:3,eq:{ways:9}}`、`{v:6,eq:{ways:18}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:3},{t:6.5,v:3},{t:9,v:6},{t:11.5,v:4},{t:13.5,v:1}]`，keys `[1,3,6]`。
**停留帧在 m=3**（3×3=9 种配法，每一件上衣都有 3 条裤子可配）。
状态：m 件上衣「先上衣后裤子，是分步，要相乘」。

**例题**：「书架上有 5 本数学书、3 本物理书、4 本化学书。① 任取 1 本有多少种取法？② 每科各取 1 本有多少种取法？」答案：① 只取 1 本，三类方案任选其一，5+3+4=12 种；② 三科都要取，分三步，5×3×4=60 种。
**六问**：① 加法与乘法怎么区分；② 分类为什么要不重不漏；③ 「至少」「至多」算分类还是分步；④ 分步中间一步有 0 种方法会怎样；⑤ 同一件事能否既分类又分步（分层的题怎么做）；⑥ 数字能不能相加后再乘。
**易错**：✗ 分步用加法 / ✗ 分类用乘法 / ✗ 分类有重复 / ✗ 分类有遗漏 / ✗ 把「每类取一个」当分类 / ✗ 复合题不画层次直接乘。
