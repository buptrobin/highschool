## xx3-c3-s3 列联表与独立性检验

**课本原话**
1. 2×2 列联表把两个分类变量交叉计数。
2. χ²=n(ad−bc)²/[(a+b)(c+d)(a+c)(b+d)]。
3. 判断规则：若 χ²≥3.841，则有 95% 的把握认为两个变量有关联；χ²≥6.635 时有 99% 的把握；否则不能作出这样的判断（不是「没有关系」）。

**三个扣分点**：结论是「有 95% 把握认为有关联」而**不是**「两个变量一定有关」；χ² 小只能说「没有充分证据」，不能反过来说「无关」；公式里 n 是**总人数**。

**四张图**：① 2×2 列联表的结构（a b / c d）；② χ² 公式与各字母含义；③ 临界值表（3.841 / 6.635）；④ 三类结论的标准写法。

**互动模型**：滑块＝甲组有效人数 a（0 到 100，step 5），总计 200：甲组 100 人（a 有效、100−a 无效），乙组 100 人（60 有效、40 无效）
```js
b = 100 - a; c = 60; d = 40; n = 200;
chi = n * Math.pow(a * d - b * c, 2) / ((a + b) * (c + d) * (a + c) * (b + d));
sig = chi >= 3.841 ? 1 : 0;
```
`cases`：`{v:60,eq:{chi:0,sig:0}}`、`{v:75,eq:{chi:5.1282,sig:1}}`、`{v:90,eq:{chi:24,sig:1}}`。
Autopilot：`[{t:0,v:60},{t:1.2,v:60},{t:4,v:75},{t:6.5,v:75},{t:9,v:90},{t:11.5,v:70},{t:13.5,v:60}]`，keys `[60,70,75,90]`。
**停留帧在 a=75**（χ²=5.13 刚越过 3.841，判定「有 95% 把握认为有关联」——临界帧）。
状态：χ²<3.841「没有充分证据」；≥3.841「有 95% 把握有关联」；≥6.635「有 99% 把握」。

**例题**：「某调查：甲组 100 人中 75 人有效、25 人无效；乙组 100 人中 60 人有效、40 人无效。判断有效率与分组是否有关联。」答案：a=75、b=25、c=60、d=40、n=200，ad−bc=3000−1500=1500，χ²=200×1500²/(100×100×135×65)=450000000/87750000≈5.128>3.841，故有 95% 的把握认为有关联。
**六问**：① 结论能不能说「一定有关」；② χ² 小是什么意思；③ 公式里 n 是谁；④ 3.841 与 6.635 分别对应多少把握；⑤ 列联表与条形图的关系；⑥ 样本量变大 χ² 会怎样。
**易错**：✗ 结论写「两个变量有关」 / ✗ 说「没有关系」 / ✗ n 用错成一组人数 / ✗ 忘记平方 / ✗ 临界值记反 / ✗ 样本太小时勉强下结论。
