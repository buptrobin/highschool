## xx3-c1-s2 排列与组合

**课本原话**
1. 从 n 个不同元素中取出 m（m≤n）个元素，按照一定的顺序排成一列，叫做从 n 个不同元素中取出 m 个元素的一个排列。
2. 排列数 A(n,m)=n(n−1)…(n−m+1)=n!/(n−m)!。
3. 组合数 C(n,m)=A(n,m)/m!=n!/[m!(n−m)!]，且 C(n,m)=C(n,n−m)。

**三个扣分点**：**有序用排列、无序用组合**（「选出 3 人当代表」与「选出 3 人分别任正副组长」不同）；排列数比组合数多除的正是 m!；C(n,m)=C(n,n−m) 可以简化计算。

**四张图**：① 排列的「位置与顺序」；② 组合的「只成团不排序」；③ 同一组元素两种算法对照（A 与 C 的关系）；④ C(n,m)=C(n,n−m) 的对称性。

**互动模型**：滑块＝取出个数 m（1 到 5，step 1），n=5
```js
A = 1; for (let i = 0; i < m; i++) A *= 5 - i;   // A(5,m)
C = A; for (let i = 2; i <= m; i++) C /= i;       // C(5,m) = A/m!
```
`cases`：`{v:2,eq:{A:20,C:10}}`、`{v:3,eq:{A:60,C:10}}`、`{v:5,eq:{A:120,C:1}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:3},{t:6.5,v:3},{t:9,v:5},{t:11.5,v:4},{t:13.5,v:1}]`，keys `[1,3,5]`。
**停留帧在 m=3**（A(5,3)=60、C(5,3)=10，且 C(5,3)=C(5,2)=10，对称性一眼可见）。
状态：m=3「选了 3 个还排了序 ⇒ A；只成团 ⇒ C」。

**例题**：「从 5 人中选 3 人。① 选 3 人参加同一个活动，多少种？② 选 3 人分别担任正、副、组长，多少种？」答案：① 无序，C(5,3)=10 种；② 有序，A(5,3)=60 种（也就是 10×3!）。
**六问**：① 怎么判断该用 A 还是 C；② C(n,m) 为什么要除以 m!；③ A(n,n)=n! 对吗；④ C(n,0) 等于多少；⑤ C(5,3) 与 C(5,2) 为什么相等；⑥ 「相邻」「不相邻」问题怎么处理。
**易错**：✗ 该用 C 时用了 A / ✗ 组合数忘记除 m! / ✗ C(n,0)=0 / ✗ 把 C(n,n−m) 当成另一个数 / ✗ 排列数写成 nᵐ（可重复） / ✗ 「至少有 1 个」直接算不分类。
