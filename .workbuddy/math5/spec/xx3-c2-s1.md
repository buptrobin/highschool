## xx3-c2-s1 条件概率与全概率公式

**课本原话**
1. 条件概率：P(B|A)=P(AB)/P(A)（P(A)>0）。
2. 乘法公式：P(AB)=P(A)P(B|A)。
3. 全概率公式：若 A₁,A₂ 互斥且和为全集，则 P(B)=P(A₁)P(B|A₁)+P(A₂)P(B|A₂)。

**三个扣分点**：**P(B|A) 与 P(A|B) 不是一回事**（分母不同）；条件概率的分母是 P(A) 不是 1；全概率要**把所有互斥情形都算上**，漏一类就错。

**四张图**：① 条件概率的「缩小样本空间」；② P(B|A) 与 P(A|B) 的对照（两个方向不同）；③ 全概率的树形分解；④ 树形图上概率的乘法与加法。

**互动模型**：滑块＝P(A)（0.2 到 0.9，step 0.05），已知 P(B|A)=0.8、P(B|Ā)=0.3
```js
pA = p; pnA = 1 - p;
pb = pA * 0.8 + pnA * 0.3;      // 全概率公式
```
`cases`：`{v:0.2,eq:{pb:0.4}}`、`{v:0.5,eq:{pb:0.55}}`、`{v:0.9,eq:{pb:0.75}}`。
Autopilot：`[{t:0,v:0.2},{t:1.2,v:0.2},{t:4,v:0.5},{t:6.5,v:0.5},{t:9,v:0.9},{t:11.5,v:0.7},{t:13.5,v:0.2}]`，keys `[0.2,0.5,0.9]`。
**停留帧在 P(A)=0.5**（P(B)=0.55，正好是 0.8 与 0.3 的加权平均，落在两者之间）。
状态：P(A) 越大「P(B) 越靠向 0.8」；P(A) 越小「越靠向 0.3」。

**例题**：「某厂两条生产线，甲线产量占 60%，次品率 2%；乙线占 40%，次品率 5%。求任取一件是次品的概率。」答案：P(B)=0.6×0.02+0.4×0.05=0.012+0.02=0.032。
**六问**：① P(B|A) 与 P(A|B) 一样吗；② 条件概率分母是什么；③ 全概率为什么要把各类加起来；④ 各类必须互斥吗；⑤ 树形图上哪一步用乘、哪一步用加；⑥ 已知结果求原因用哪个公式（贝叶斯）。
**易错**：✗ 把 P(B|A) 当 P(B) / ✗ 分母用 P(B) / ✗ 全概率漏一类 / ✗ 各类有重叠 / ✗ 树上把「加」和「乘」用反 / ✗ 条件概率写出大于 1 的值。
