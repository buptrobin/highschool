# 本节规格（只读这一节，不要读 SPEC.md 全文）

## xx3-c2-s5 正态分布

**课本原话**
1. 若随机变量 X 的概率密度函数为 f(x)=1/(σ√(2π))·e^(−(x−μ)²/(2σ²))，则称 X 服从正态分布 N(μ,σ²)。
2. 正态曲线关于 x=μ 对称；σ 越大曲线越「矮胖」，σ 越小越「瘦高」。
3. 3σ 原则：P(μ−σ<X≤μ+σ)≈0.6827，P(μ−2σ<X≤μ+2σ)≈0.9545，P(μ−3σ<X≤μ+3σ)≈0.9973。

**三个扣分点**：正态曲线的**面积**是概率，高度不是概率；σ 变大曲线变矮但**面积仍是 1**；3σ 原则的三个数是固定值（0.6827 / 0.9545 / 0.9973），不能自己编。

**四张图**：① 正态曲线的钟形与 μ、σ；② μ 变 → 左右平移；③ σ 变 → 胖瘦变化但面积不变；④ 3σ 原则的三段面积。

**互动模型**：滑块＝标准差 σ（0.5 到 3，step 0.25），μ=0
```js
peak = 1 / (Math.sqrt(2 * Math.PI) * s);      // 峰值高度
p1   = 0.6827;                                 // P(|X|<σ) 恒定（不受 σ 影响）
pband = 0.9545;                                // P(|X|<2σ)
```
`cases`：`{v:1,eq:{peak:0.3989}}`、`{v:2,eq:{peak:0.1995}}`、`{v:0.5,eq:{peak:0.7979}}`。
Autopilot：`[{t:0,v:0.5},{t:1.2,v:0.5},{t:4,v:1},{t:6.5,v:1},{t:9,v:3},{t:11.5,v:2},{t:13.5,v:0.5}]`，keys `[0.5,1,2,3]`。
**停留帧在 σ=1**（标准正态，峰值 0.3989，σ 段面积 0.6827——数字最标准的一格）。
状态：σ 越小「越高越瘦」；σ 越大「越矮越胖」；两者面积都还是 1。

**例题**：「某次考试 X~N(90,100)，求 P(80<X≤100) 与 P(X>110)。」答案：μ=90、σ=10；80 与 100 正好是 μ±σ，故 P≈0.6827；110=μ+2σ，P(X>110)=(1−0.9545)/2≈0.0228。
**六问**：① 曲线高度是概率吗；② σ 变大曲线面积变吗；③ 3σ 原则的三个数是什么；④ 为什么 P(X=某个具体值)=0；⑤ μ 变曲线怎么动；⑥ 对称性能怎么用。
**易错**：✗ 把高度当概率 / ✗ σ 变大认为面积变大 / ✗ 3σ 数字记成 0.68/0.95/0.99 就够 / ✗ 求单侧概率忘记除以 2 / ✗ μ 与 σ 位置写反 / ✗ 认为正态分布一定能算精确值（要用查表/近似）。
