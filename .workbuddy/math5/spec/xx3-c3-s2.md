## xx3-c3-s2 一元线性回归模型及其应用

**课本原话**
1. 经验回归方程 ŷ=b̂x+â，其中 b̂=Σ(xᵢ−x̄)(yᵢ−ȳ)/Σ(xᵢ−x̄)²，â=ȳ−b̂x̄。
2. 残差 eᵢ=yᵢ−ŷᵢ，残差平方和 Q=Σ(yᵢ−ŷᵢ)² 越小，拟合效果越好。
3. 经验回归直线一定过样本中心点 (x̄,ȳ)。

**三个扣分点**：**回归直线必过样本中心**；b̂ 的分子是「叉积和」不是「x 的和乘 y 的和」；残差是 y−ŷ（观测减预测）。

**四张图**：① 散点与拟合直线；② 残差是竖直的小竖线；③ Q 随 b 变化的抛物线（最低点就是 b̂）；④ 预测与「内插可信、外推危险」。

**互动模型**：滑块＝斜率 b（0.5 到 2.5，step 0.1），数据 (1,2)(2,3)(3,5)(4,6)(5,8)，截距固定 â=0.3
```js
// Q(b) = Σ(yᵢ − (0.3 + b·xᵢ))²
q = Σ (y - 0.3 - b*x)²;      // 残差平方和
// 最小值在 b=1.5 处，Q=0.3
```
`cases`：`{v:0.5,eq:{q:55.3}}`、`{v:1.5,eq:{q:0.3}}`、`{v:2.5,eq:{q:55.3}}`。
Autopilot：`[{t:0,v:0.5},{t:1.2,v:0.5},{t:4,v:1.5},{t:6.5,v:1.5},{t:9,v:2.5},{t:11.5,v:1},{t:13.5,v:0.5}]`，keys `[0.5,1,1.5,2.5]`。
**停留帧在 b=1.5**（Q 降到 0.3 的最小值，此时直线穿得最正中）。
状态：b 偏离 1.5「残差平方和变大」；b=1.5「Q 最小，这就是最小二乘」。

**例题**：「由数据 (1,2)(2,3)(3,5)(4,6)(5,8) 求经验回归方程。」答案：x̄=3、ȳ=4.8，Σ(xᵢ−x̄)(yᵢ−ȳ)=15，Σ(xᵢ−x̄)²=10，b̂=1.5，â=4.8−1.5×3=0.3，故 ŷ=1.5x+0.3。
**六问**：① 回归直线为什么过 (x̄,ȳ)；② 残差是观测减预测还是反过来；③ Q 最小意味着什么；④ 外推为什么危险；⑤ b̂ 的分子是什么；⑥ 相关系数与回归斜率的关系。
**易错**：✗ 回归直线不过样本中心 / ✗ 残差写成 ŷ−y / ✗ 把 b̂ 的分子算成 ΣxΣy / ✗ 外推太远还当准确值 / ✗ â 也算错方向 / ✗ 认为 Q=0 一定拟合好（可能是过拟合）。
