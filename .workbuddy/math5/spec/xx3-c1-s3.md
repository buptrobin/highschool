## xx3-c1-s3 二项式定理

**课本原话**
1. (a+b)ⁿ=C(n,0)aⁿ+C(n,1)aⁿ⁻¹b+…+C(n,n)bⁿ。
2. 通项公式：T(k+1)=C(n,k)aⁿ⁻ᵏbᵏ（k=0,1,…,n）。
3. 二项式系数的性质：C(n,0)+C(n,1)+…+C(n,n)=2ⁿ；中间项系数最大。

**三个扣分点**：通项里 a 的指数是 **n−k**、b 的指数是 k（写反就全错）；系数之和 2ⁿ 是把 a=b=1 代进去得到的，**不是** 2n；中间项看 n 是奇偶：n 为偶数时第 n/2+1 项系数最大。

**四张图**：① 杨辉三角与二项式系数；② 通项的 indices（a 降 b 升）；③ 赋值法求系数和（a=b=1）；④ 二项式系数与项的系数的区别。

**互动模型**：滑块＝n（0 到 6，step 1）
```js
sum = Math.pow(2, n);                          // 各二项式系数之和
mid = n === 0 ? 1 : C(n, Math.floor(n / 2));   // 最大二项式系数
row = [C(n,0), …, C(n,n)];                     // 展开式各项系数
```
其中 C(n,k) 用连乘实现。`cases`：`{v:2,eq:{sum:4,mid:2}}`、`{v:4,eq:{sum:16,mid:6}}`、`{v:6,eq:{sum:64,mid:20}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:4},{t:6.5,v:4},{t:9,v:6},{t:11.5,v:3},{t:13.5,v:0}]`，keys `[0,4,6]`。
**停留帧在 n=4**（1,4,6,4,1，对称、中间系数 6 最大，系数和 16）。
状态：n=4「系数成对对称，中间的 6 最大」。

**例题**：「求 (2x+1)⁶ 的展开式中 x³ 的系数。」答案：通项 T(k+1)=C(6,k)(2x)⁶⁻ᵏ，要 x³ 需 6−k=3，即 k=3，系数为 C(6,3)×2³=20×8=160。
**六问**：① 通项里 a、b 的指数怎么分配；② 系数和为什么是 2ⁿ；③ 二项式系数和与项的系数和一样吗；④ n 为偶数时哪一项系数最大；⑤ 常数项怎么求；⑥ 杨辉三角相邻两行有什么关系。
**易错**：✗ 通项指数写反 / ✗ 系数和写成 2n / ✗ 把二项式系数当项的系数 / ✗ 中间项位置算错（n 为偶数时是第 n/2+1 项） / ✗ 求常数项时忘记 x 的指数 / ✗ 忘记 C(n,k) 前的数字系数。
