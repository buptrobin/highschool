## xx3-c2-s3 离散型随机变量的数字特征

**课本原话**
1. 均值（数学期望）E(X)=x₁p₁+x₂p₂+…+xₙpₙ。
2. 方差 D(X)=(x₁−E(X))²p₁+…+(xₙ−E(X))²pₙ，标准差 σ(X)=√D(X)。
3. 线性性质：E(aX+b)=aE(X)+b，D(aX+b)=a²D(X)。

**三个扣分点**：**D(aX+b)=a²D(X)**（不是 aD，也不是 a²D+b——常数 b 不改变方差）；E(X) 是加权平均不是算术平均；方差的单位是原数据单位的平方。

**四张图**：① 均值的加权平均意义（天平支点）；② 方差是「离均值的平均平方距离」；③ 数据整体平移 b 时方差不变；④ 数据放大 a 倍时方差放大 a² 倍。

**互动模型**：滑块＝倍数 a（1 到 4，step 0.5），X 取 1、2、3 等可能 → E(X)=2、D(X)=2/3，Y=aX
```js
ex = 2; dx = 2 / 3;
ey = a * ex;             // E(aX) = a·E(X)
dy = a * a * dx;         // D(aX) = a²·D(X)
```
`cases`：`{v:1,eq:{ey:2,dy:0.6667}}`、`{v:2,eq:{ey:4,dy:2.6667}}`、`{v:3.5,eq:{ey:7,dy:8.1667}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:2},{t:6.5,v:2},{t:9,v:4},{t:11.5,v:3},{t:13.5,v:1}]`，keys `[1,2,3,4]`。
**停留帧在 a=2**（均值翻 2 倍变 4，方差翻 4 倍变 2.667——方差不是翻 2 倍，最反直觉的一格）。
状态：a 变化「均值线性放大，方差按平方放大」。

**例题**：「X 的分布列：P(X=1)=0.2、P(X=2)=0.5、P(X=3)=0.3。求 E(X)、D(X) 与 E(2X+1)、D(2X+1)。」答案：E(X)=1×0.2+2×0.5+3×0.3=2.1；D(X)=(−1.1)²×0.2+(−0.1)²×0.5+(0.9)²×0.3=0.242+0.005+0.243=0.49；E(2X+1)=2×2.1+1=5.2；D(2X+1)=4×0.49=1.96。
**六问**：① 方差公式里为什么要平方；② D(aX+b) 与 a、b 的关系；③ 均值一定是分布列里的某个取值吗；④ 方差能为负吗；⑤ 标准差与方差的关系；⑥ 两个随机变量的和期望怎么算。
**易错**：✗ D(aX+b)=aD(X) / ✗ 常数 b 影响方差 / ✗ 方差忘了乘概率 / ✗ 均值当算术平均 / ✗ 标准差忘记开方 / ✗ 方差单位写错。
