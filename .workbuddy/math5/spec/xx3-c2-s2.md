## xx3-c2-s2 离散型随机变量及其分布列

**课本原话**
1. 随机变量：随着试验结果变化而变化的变量，常用 X、Y、ξ 表示。
2. 离散型随机变量的分布列：列出 X 的所有取值 x₁,x₂,… 及对应概率 p₁,p₂,…。
3. 分布列的两个性质：pᵢ≥0；p₁+p₂+…=1。

**三个扣分点**：分布列必须**列全所有取值**且概率和**恰好为 1**；概率不能为负；写成表格不是写成一句话。

**四张图**：① 随机变量与试验结果的对应；② 分布列的表格形式（两行）；③ 两条性质的自检（非负、和为 1）；④ 由分布列求 P(X≤a) 的累加。

**互动模型**：滑块＝成功概率 p（0.1 到 0.9，step 0.05），X 取 0、1（两点分布）
```js
p0 = 1 - p;              // P(X=0)
p1 = p;                  // P(X=1)
sum = p0 + p1;           // 恒为 1
cdf0 = p0;               // P(X≤0)
```
`cases`：`{v:0.3,eq:{p0:0.7,p1:0.3,sum:1}}`、`{v:0.5,eq:{p0:0.5,p1:0.5,sum:1}}`、`{v:0.9,eq:{p0:0.1,p1:0.9,sum:1}}`。
Autopilot：`[{t:0,v:0.1},{t:1.2,v:0.1},{t:4,v:0.5},{t:6.5,v:0.5},{t:9,v:0.9},{t:11.5,v:0.7},{t:13.5,v:0.1}]`，keys `[0.1,0.5,0.9]`。
**停留帧在 p=0.5**（p₀=p₁=0.5，和恰好 1，分布列最对称的一格）。
状态：任何 p「p₀+p₁=1」恒成立——这就是分布列的自检。

**例题**：「袋中有 3 个红球、2 个白球，任取 2 个，求取到红球个数 X 的分布列。」答案：X 可取 0、1、2；P(X=0)=C(2,2)/C(5,2)=1/10，P(X=1)=C(3,1)C(2,1)/C(5,2)=6/10，P(X=2)=C(3,2)/C(5,2)=3/10；和为 1。
**六问**：① 分布列必须满足什么；② 概率和不为 1 说明什么；③ 随机变量一定是数吗；④ 离散与连续的区别；⑤ P(X≤2) 怎么算；⑥ 分布列能写成公式吗。
**易错**：✗ 漏写某个取值 / ✗ 概率和不为 1 还往下做 / ✗ 概率出现负数 / ✗ 把 X 的取值写成事件 / ✗ P(X≤2) 用连乘 / ✗ 分布列写成文字叙述。
