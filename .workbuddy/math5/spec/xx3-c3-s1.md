# 本节规格（只读这一节，不要读 SPEC.md 全文）

## xx3-c3-s1 成对数据的统计相关性

**课本原话**
1. 散点图中点的分布如果从左下角到右上角，说明两个变量正相关；从左上角到右下角为负相关。
2. 样本相关系数 r=Σ(xᵢ−x̄)(yᵢ−ȳ)/√[Σ(xᵢ−x̄)²·Σ(yᵢ−ȳ)²]，且 −1≤r≤1。
3. |r| 越接近 1，线性相关程度越强；r>0 正相关，r<0 负相关。

**三个扣分点**：**相关不等于因果**；r 只衡量**线性**相关（曲线关系 r 可能接近 0）；r 无单位、范围 [−1,1]。

**四张图**：① 散点图与正/负相关；② r 从 −1 到 1 的点云变化（一条线 → 一团雾）；③ 曲线关系但 r≈0（相关≠线性相关）；④ r² 的意义（决定系数）。

**互动模型**：滑块＝相关系数 r（−1 到 1，step 0.1），用固定伪随机序列生成 24 个点
```js
// y = r·x + √(1−r²)·noise，noise 由固定种子生成，保证同一 r 每次一样
r2 = r * r;                      // 决定系数
dir = r > 0.05 ? 1 : r < -0.05 ? -1 : 0;
```
`cases`：`{v:0.8,eq:{r2:0.64,dir:1}}`、`{v:0,eq:{r2:0,dir:0}}`、`{v:-0.9,eq:{r2:0.81,dir:-1}}`。
Autopilot：`[{t:0,v:-1},{t:1.2,v:-1},{t:4,v:0.8},{t:6.5,v:0.8},{t:9,v:0},{t:11.5,v:0.5},{t:13.5,v:-1}]`，keys `[-1,0,0.8,1]`。
**停留帧在 r=0.8**（点云收得很紧，r²=0.64 说明 64% 的波动能被线性解释）。
状态：r>0「正相关」；r=0「看不出线性关系」；r<0「负相关」。

**例题**：「已知 5 组数据算得 r=0.98，说明什么？」答案：|r|=0.98 很接近 1，说明两变量有很强的**正线性相关**；但相关不等于因果，也不能据此断定 x 变化导致 y 变化。
**六问**：① r=0.9 说明因果吗；② r 能大于 1 吗；③ 曲线关系 r 会怎样；④ r 与 r² 的关系；⑤ r 正负说明什么；⑥ 样本太小 r 可靠吗。
**易错**：✗ 相关当因果 / ✗ 认为 r 越大越「准」 / ✗ 曲线关系用 r 判断 / ✗ r 有单位 / ✗ r² 与 r 混淆 / ✗ 离群点不影响 r。
