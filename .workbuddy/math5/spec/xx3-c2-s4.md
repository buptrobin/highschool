## xx3-c2-s4 二项分布与超几何分布

**课本原话**
1. n 次独立重复试验中，每次成功概率为 p，成功次数 X 服从二项分布，记作 X~B(n,p)。
2. P(X=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ，E(X)=np，D(X)=np(1−p)。
3. 超几何分布：从含 M 件次品的 N 件产品中不放回取 n 件，次品数 X 的分布 P(X=k)=C(M,k)C(N−M,n−k)/C(N,n)，E(X)=nM/N。

**三个扣分点**：二项分布是**有放回/独立重复**，超几何是**不放回**；D(X)=np(1−p) 别写成 np；超几何的期望也是 np 但方差不同（不必记公式，理解即可）。

**四张图**：① 二项分布的直方图（n 变大时的钟形）；② 有放回 vs 不放回的差别；③ 二项分布的 E、D 随 n、p 变化；④ 超几何抽样示意。

**互动模型**：滑块＝试验次数 n（5 到 20，step 1），p=0.4
```js
e = n * 0.4;                    // E(X) = np
d = n * 0.4 * 0.6;              // D(X) = np(1−p)
sd = Math.sqrt(d);              // 标准差
```
`cases`：`{v:5,eq:{e:2,d:1.2}}`、`{v:10,eq:{e:4,d:2.4}}`、`{v:20,eq:{e:8,d:4.8}}`。
Autopilot：`[{t:0,v:5},{t:1.2,v:5},{t:4,v:10},{t:6.5,v:10},{t:9,v:20},{t:11.5,v:15},{t:13.5,v:5}]`，keys `[5,10,15,20]`。
**停留帧在 n=10**（E=4、D=2.4，直方图最像钟形）。
状态：n 增大「期望与方差都按比例增长」。

**例题**：「某射手命中率 0.8，独立射击 5 次，求命中次数 X 的期望与方差。」答案：X~B(5,0.8)，E(X)=5×0.8=4，D(X)=5×0.8×0.2=0.8。
**六问**：① 二项与超几何怎么区分；② D(X)=np(1−p) 里 p 是谁；③ 命中率 0.8 时 D 为什么比 E 小；④ 超几何的期望也是 np 吗；⑤ n=1 时二项分布是什么；⑥ 不放回为什么不能直接用二项。
**易错**：✗ 不放回还用二项 / ✗ D(X)=np / ✗ p 与 1−p 弄反（不影响 E、D 但影响分布列） / ✗ 超几何方差套 np(1−p) 当精确值 / ✗ n 当样本容量用错 / ✗ 认为二项分布一定对称（p≠0.5 时不对称）。
