01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 散点图与相关方向人教A版选择性必修第三册 · 第8章第1节

散点图中点的分布如果从左下角到右上角，说明两个变量正相关；从左上角到右下角为负相关。

→ 翻成人话：只看点的整体走向，不看单个点。左下→右上＝x 大时 y 也大（正相关）；左上→右下＝x 大时 y 反而小（负相关）。这句只判方向，还没说强弱。

课本原话 · 样本相关系数人教A版选择性必修第三册 · 第8章第1节

样本相关系数 r = Σ(xᵢ−x̄)(yᵢ−ȳ) / √[Σ(xᵢ−x̄)² · Σ(yᵢ−ȳ)²]，且 −1 ≤ r ≤ 1。

→ 翻成人话：分子量的是「x 与 y 同时偏离各自平均值的配合程度」，分母把两把不同刻度的尺子除掉。所以 r 是纯数：没有单位，且必落在 [−1,1] —— 算出 1.2 一定是代错了数。

课本原话 · 相关程度人教A版选择性必修第三册 · 第8章第1节

|r| 越接近 1，线性相关程度越强；r>0 正相关，r<0 负相关。

→ 翻成人话：这句话要拆成三个条件一起读：① 看符号定方向；② 看 |r| 定强弱；③「线性」两个字不能丢 —— r 只衡量线性相关，一条完美的抛物线也能算出 r≈0，那叫「非线性相关」，不是「无关」。

用 r 之前必须满足的条件缺了这一条会怎样
数据是成对的 (xᵢ, yᵢ)，一一对应配对错位，r 算出来是个没有含义的数
先看散点图确认有线性趋势，再算 r曲线关系（如 y=x²）也会算出 r≈0，被误判成「两个变量无关」
说明 −1 ≤ r ≤ 1，且 r 无单位写成 r=1.2、或写「r=0.8 米」，直接判错
解释时不越界：相关 ≠ 因果把 r 大当成「x 导致 y」，结论超出数据能支持的范围

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 由 r 下结论必考

某班测得 10 名学生每天数学刷题时长 x（单位：小时）与月考数学成绩 y（单位：分），由 10 组成对数据算得样本相关系数 r = 0.98。请回答：
（1）能否说明刷题时长与成绩正相关？相关程度如何？
（2）能否由此断定「刷题时间越长，成绩一定越高」？请说明理由。

  1. 第 1 步 · 审题：先抓符号与绝对值

    题目只给了一个数 r=0.98。相关系数要拆成两半读：符号管方向，绝对值管强弱。先把这两件事分开，再谈结论。

    用到：r 的双重含义（方向 + 强弱）。

  2. 第 2 步 · 定方向：看符号

    r = 0.98 > 0，按课本表述：r>0 表示两个变量正相关，即 x 增大时 y 有增大的趋势。

    用到：r>0 ⇔ 正相关；r<0 ⇔ 负相关。

  3. 第 3 步 · 定强弱：看绝对值

    |r| = 0.98，非常接近 1（且不超过 1），说明线性相关程度很强。答题时要写出「正」和「强」两个字，缺一个都算没答全。

    用到：|r| 越接近 1，线性相关程度越强；−1 ≤ r ≤ 1。

  4. 第 4 步 · 越界检查：相关推不出因果

    r 大只说明两组数据同步变化，相关不等于因果。可能是刷题多导致成绩好，也可能是「学习习惯好」这个第三因素同时抬高了 x 和 y，甚至是成绩好的学生更愿意刷题（反向）。所以不能说「一定越高」。

    用到：相关 ≠ 因果；样本相关系数由样本算出，换一批人不保证同样强。

1 / 4

标准答案（可抄进答题卡）

（1）能。因为 r = 0.98 > 0，所以 x 与 y 正相关；又 |r| = 0.98 很接近 1，说明两个变量的线性相关程度很强。
（2）不能。样本相关系数 r 只刻画两个变量线性相关的强弱与方向，相关不等于因果；成绩还受基础、效率、考试状态等影响，且样本只有 10 人，不能由「r 大」推出「x 增大必然导致 y 增大」。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「算出 r = 0.9，是不是就说明 x 是 y 的原因？」

不是。相关不等于因果。r 只说明两组数据同步变化，可能由第三个变量同时影响 x 和 y，也可能因果方向相反。

「r 会不会算出 1.2？数值越大是不是越准？」

不会。必有 −1 ≤ r ≤ 1，r 无单位；算出 1.2 一定是代错了数。而且 r 不代表「准」，它只表示线性关系紧不紧。

「散点图明明是条漂亮的抛物线，r ≈ 0，能不能说两变量无关？」

不能。r 只衡量线性相关。抛物线是确定的非线性相关，r≈0 只说明没有线性相关，需改用其他方式描述。

「r = 0.8 和 r² = 0.64，到底哪个该写进答案？」

看问什么。问相关强弱与方向用 r（带符号）；问「能解释百分之几的波动」用 r²=64%。r² 只丢符号，0 ≤ r² ≤ 1，仍是纯数。

「r 的正负到底在告诉我什么？」

只告诉你方向：r>0 正相关，r<0 负相关，r=0 看不出线性关系。强弱要看 |r| 是否接近 1。

「只有 5 组数据，算出 r = 0.9 能当真吗？」

要谨慎。r 是样本相关系数，样本太小或含离群点时很不稳定，换一批数据可能差很多。它也只说明这批数据，不能外推到总体。

收尾点明：这六问其实是同一件事 —— r 是一个被限定在 [−1,1]、没有单位、只描述线性相关的数，它既不说明因果，也不说明样本之外的情况。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ r = 0.98，所以刷题时间越长成绩一定越高。

✓ |r| = 0.98 很接近 1，说明两变量线性相关程度很强、且为正相关；但相关不等于因果，不能推出「一定导致」。

错在哪：把相关直接升级成因果，还加了「一定」。

✗ r 越大越好，说明结果越准确。

✓ r 的大小只表示线性相关的强弱，与「准不准」无关；而且 r∈[−1,1] 且无单位，不存在「越大越准」。

错在哪：把「相关强度」偷换成「结果可信度」。

✗ 散点图是抛物线，r ≈ 0，所以 x 和 y 没关系。

✓ r 只衡量线性相关；r≈0 只说明没有线性相关，y = x² 属于非线性相关。

错在哪：漏掉「线性」这个前提，把 r=0 读成「无关」。

✗ 身高与体重的相关系数 r = 0.8 kg。

✓ r 无单位，且 −1 ≤ r ≤ 1，只能写 r = 0.8。

错在哪：给一个「纯数」安上了单位。

✗ 决定系数是 r，所以 r = 0.64。

✓ 相关系数是 r，决定系数是 r²；r = 0.8 时 r² = 0.64，两者不能互换。

错在哪：把 r 与 r² 的名字和数值都弄混。

✗ 有一个离群点没关系，r 不会变。

✓ 离群点对 r 影响很大，可能把 r 从 0.2 抬到 0.9；应先看散点图识别离群点。

错在哪：不知道 r 对极端值敏感。

✗ r = 0，所以 y 一定等于 ȳ。

✓ r = 0 只说明没有线性相关，y 仍可能随 x 呈曲线变化；相关不等于函数关系。

错在哪：把「线性无关」读成「y 是常数」。
