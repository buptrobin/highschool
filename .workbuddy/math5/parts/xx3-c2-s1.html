7.1 是整章概率的转折点：前面算的是「事件有多大」，从这里开始算「在某个已知条件下事件有多大」。一句话概括——把样本空间砍掉一块，再把概率按剩下那块重新分配。最容易错的地方不在公式本身，而在两处：写 P(B|A) 时把分母写成 P(B)（两个方向根本不是一回事），用全概率时只算了自己想到的那一类（漏掉的情形永远不会自己冒出来）。这一节把这两个坑各拆两遍。

01课本怎么说

先背标准表述，再拆条件。答题写左边这句，不写右边的人话。

课本原话 · 条件概率的定义人教A版选择性必修第三册 · 第7章第1节

一般地，设 A，B 为两个随机事件，且 P(A)>0，称 P(B|A)=P(AB)/P(A) 为在事件 A 发生的条件下，事件 B 发生的条件概率，简称条件概率。

→ 翻成人话，它由三个条件组成：① A、B 是同一个样本空间里的两个事件；② P(A)>0，否则分母为 0，定义直接失效；③ 分母是 P(A)，不是 P(B)，也不是 1。第 ③ 条就是第一个扣分点——P(B|A) 与 P(A|B) 不是一回事，它们的分子一样、分母不同。

课本原话 · 乘法公式人教A版选择性必修第三册 · 第7章第1节

由条件概率的定义，对任意两个事件 A 与 B，若 P(A)>0，则 P(AB)=P(A)P(B|A)，称此公式为乘法公式。

→ 它只是把定义式两边乘上 P(A)，但作用很大：把「A、B 同时发生」拆成「先 A，再在 A 的地盘里发生 B」两步。条件概率的分母是 P(A)，所以第一步的分母、第二步的条件，必须锁死在同一个事件上，随手换个字母就全错。

课本原话 · 全概率公式人教A版选择性必修第三册 · 第7章第1节

一般地，设 A₁，A₂，…，Aₙ 是一组两两互斥的事件，且 A₁∪A₂∪…∪Aₙ=Ω，P(Aᵢ)>0，则对任意事件 B，有 P(B)=P(A₁)P(B|A₁)+P(A₂)P(B|A₂)+…+P(Aₙ)P(B|Aₙ)。

→ 三个条件：① 两两互斥，保证同一情形不被算两遍；② 并起来是整个 Ω，保证一种情形都不漏；③ 每个 P(Aᵢ)>0。少 ① 结果偏大，少 ② 结果偏小。全概率要把所有互斥情形都算上，这句话在解题时的意思就是：先把分类列全，再动笔算。

公式必须满足的条件缺了这一条会怎样
条件概率 P(B|A)=P(AB)/P(A)P(A)>0分母为 0，式子没有意义，这道题要改用别的已知条件
乘法公式 P(AB)=P(A)P(B|A)P(A)>0，且以 A 为「先发生」的那一步顺序换错，条件概率的分母就跟着换错，两个方向被混成一个
全概率公式（互斥）A₁，A₂，…，Aₙ 两两互斥交集被重复计算，P(B) 偏大，且错得没有提示
全概率公式（不漏）A₁∪A₂∪…∪Aₙ=Ω漏掉的那一类不会自己冒出来，P(B) 偏小；这是最隐蔽的错，因为算式完全成立

背法：先问「已知谁」，分母就是谁；再问「分几类」，分几类就加几项。两个问题问完，公式自己就出来了，不用背三行。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。第 (2) 问是陷阱，方向反了就算错。

例题 · 全概率公式必考

某厂有甲、乙两条生产线生产同一种零件。甲线产量占全厂的 60%，次品率为 2%；乙线产量占 40%，次品率为 5%。任取一件产品。(1) 求它是次品的概率；(2) 已知取到的是次品，求它来自甲线的概率。

  1. 第 1 步 · 设事件，先分清「已知谁」

    设 A₁=「取到甲线产品」，A₂=「取到乙线产品」，B=「取到次品」。第 (1) 问直接从产量和次品率出发，没有额外条件；第 (2) 问是「已知 B 发生」，方向正好反过来。

    用到：条件概率的记法。竖线右边是已知，左边是所求——这两问的竖线方向不同，先看清再动笔。

  2. 第 2 步 · 列分类，检查「互斥」和「不漏」

    A₁ 与 A₂ 不能同时发生（一件产品只可能来自一条线），所以两两互斥；又因为产品只有这两条线，A₁∪A₂=Ω。两个条件都对上，才能用全概率公式。

    用到：全概率公式的两个前提。全概率要把所有互斥情形都算上，这里只有两类，两条都要进公式。

  3. 第 3 步 · 把四个概率抄成树上的四条枝

    P(A₁)=0.6，P(A₂)=0.4；P(B|A₁)=0.02，P(B|A₂)=0.05。注意 P(B|A₁)=0.02 是「甲线里面的次品率」，分母是甲线产量，不是全厂产量。

    用到：条件概率的分母是 P(A₁)。2% 与 5% 都是条件概率，不能和 0.6、0.4 混着直接加减。

  4. 第 4 步 · 先乘后加，代入全概率公式

    P(B)=P(A₁)P(B|A₁)+P(A₂)P(B|A₂)=0.6×0.02+0.4×0.05=0.012+0.02=0.032。

    用到：全概率公式。0.012 与 0.02 都是「某条线上又是次品」的概率，两项互斥，直接相加。

  5. 第 5 步 · 第 (2) 问反方向：已知结果求原因

    要求 P(A₁|B)，分母换成 P(B)=0.032：P(A₁|B)=P(A₁B)/P(B)=0.012/0.032=0.375。若误写成 0.012/0.6=0.02，就是把 P(B|A₁) 当成了 P(A₁|B)。

    用到：条件概率的定义 + 全概率公式。P(A₁|B) 与 P(B|A₁) 不是一回事，分子相同、分母分别是 P(B) 与 P(A₁)。

1 / 5

标准答案（可抄进答题卡）

(1) 设 A₁=「甲线产品」，A₂=「乙线产品」，B=「次品」。A₁ 与 A₂ 互斥，且 A₁∪A₂=Ω，P(A₁)=0.6，P(A₂)=0.4，P(B|A₁)=0.02，P(B|A₂)=0.05。由全概率公式，P(B)=P(A₁)P(B|A₁)+P(A₂)P(B|A₂)=0.6×0.02+0.4×0.05=0.012+0.02=0.032。所以任取一件是次品的概率为 0.032。
(2) 由条件概率的定义与乘法公式，P(A₁B)=P(A₁)P(B|A₁)=0.6×0.02=0.012，故 P(A₁|B)=P(A₁B)/P(B)=0.012/0.032=0.375。所以已知是次品时，它来自甲线的概率为 0.375。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「P(B|A) 和 P(A|B) 算出来差不多吧？」

不。分子同为 P(AB)，分母分别是 P(A) 与 P(B)，两个方向可以差很远。P(B|A) 与 P(A|B) 不是一回事，除非 P(A)=P(B)。

「P(B|A) 的分母到底是几？」

条件概率分母是 P(A)——条件里写的那个事件，就是分母。不是 P(B)，也不是 1：写成 1 等于把条件抹掉了，算出来的其实是 P(B)。

「全概率为什么非要把每一类都加起来？」

因为 B 只会从某一类里发生，各类互斥，所以 P(B) 就是各条路径概率之和。全概率要把所有互斥情形都算上：少加一类，等于把那一类里的 B 直接扔了。

「分类随便分几类都行吗？」

不行，必须两两互斥且并起来是全集。有重叠就重复计算（结果偏大），没覆盖就漏算（结果偏小）。检查方法：把各类的概率加起来，必须等于 1。

「树形图上什么时候乘、什么时候加？」

沿一条路径往下走用乘（一类里又发生 B），把多条路径汇总用加（到底是哪一类里发生 B）。乘法算一项，加法把项连起来。

「已知是次品，求它来自哪条线，用哪个公式？」

还是条件概率的定义，只是分母换成 P(B)：P(A₁|B)=P(A₁B)/P(B)，而 P(B) 刚用全概率算过。这就是贝叶斯公式的用法——已知结果求原因，分母必是结果的概率。

六问其实是同一件事：先问「已知谁」定分母，再问「分几类」定项数。这两步做对，条件概率、乘法公式、全概率公式、贝叶斯就是同一个动作的不同说法。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 已知是次品，所以次品率就是 2%。

✓ 设 B=「次品」，A₁=「甲线」，则 P(A₁|B)=P(A₁)P(B|A₁)/P(B)=0.012/0.032=0.375。

错在哪：把 P(B|A₁)=0.02 直接当成了 P(A₁|B)。同一个分子，分母一个是 P(A₁) 一个是 P(B)，P(B|A) 与 P(A|B) 不是一回事。

✗ P(B|A)=P(AB)/P(B)。

✓ P(B|A)=P(AB)/P(A)，要求 P(A)>0。

错在哪：条件概率分母是 P(A)，不是 P(B)。分母写成 P(B)，算出来的是 P(A|B)，方向反了；写成 1，算出来的是 P(B)。

✗ P(B)=0.6×0.02=0.012，就这条线有次品。

✓ P(B)=0.6×0.02+0.4×0.05=0.032，两类都要加。

错在哪：只算了甲线一类。全概率要把所有互斥情形都算上，漏掉乙线，P(B) 偏小一半多，而算式本身看不出任何毛病。

✗ 把「甲线次品」和「乙线次品」都算进 P(B)，反正都算上了。

✓ A₁∩A₂=∅ 且 A₁∪A₂=Ω，两类互斥，才能直接相加。

错在哪：分类必须两两互斥，否则两个集合的交集被算两次，P(B) 偏大。写完分类先验一句「各类概率之和=1」。

✗ 树上同一路径的 0.5 和 0.8 相加得 0.5+0.8=1.3。

✓ 同一路径上两个概率相乘得 0.4，不同路径之间才相加。

错在哪：把「乘」和「加」用反了。纵向（路径内）用乘，横向（路径间）用加；加反了还会算出大于 1 的概率，这本身就是报警信号。

✗ P(B|A)=1.6，因为 0.8 加上 0.8。

✓ 任何条件概率都满足 0≤P(B|A)≤1。

错在哪：算出的条件概率大于 1，说明分子分母搞混或把两个概率加了。条件概率是在缩小后的样本空间里取比例，不可能超过 1，超过 1 一定是公式错了。

✗ P(B|A)+P(B|Ā)=1，两个方向加起来就是全部。

✓ 正确的是 P(B|A)+P(B̄|A)=1，同一个条件下才互补。

错在哪：互补关系必须条件相同、事件互补。P(B|A) 与 P(B|Ā) 分母不同，一般加起来不等于 1，本节模型里就是 0.8+0.3=1.1。

这一页反复出现的三句话，就是阅卷时最容易被扣分的三处：P(B|A) 与 P(A|B) 不是一回事、条件概率分母是 P(A)、全概率要把所有互斥情形都算上。写完题用这三句各扫一遍，比再算一遍快。
