二项分布与超几何分布的区别不在公式长得像，而在抽样方式：有放回／独立重复用二项，不放回用超几何；两者的期望都是「总数 × 比例」，但方差只有二项是 np(1−p)。

7.2 讲离散型随机变量的分布列，7.3 讲期望与方差，这一节把它们落到两个天天考的模型上：二项分布和超几何分布。判定只用一句话——「抽完放不放回去」。放回去，每次成功的概率都不变，次数服从 B(n,p)；不放回去，每抽一件样本池就少一件，成功概率逐次变，次数服从超几何分布。最容易错的是两处：把不放回硬套二项分布，以及把 D(X) 写成 np。

01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

二项分布 · 定义人教A版选择性必修第三册 · 第七章第四节

一般地，在 n 次独立重复试验中，设每次试验成功的概率为 p，用 X 表示 n 次试验中成功的次数，则 X 的分布列满足 P(X=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ，k=0,1,2,…,n，称 X 服从二项分布，记作 X~B(n,p)。

→ 翻成人话：这句话由三个条件组成——① 试验次数 n 是事先定死的；② 每次只有「成功／失败」两种结果；③ 各次独立且每次成功的概率都是同一个 p。三个条件里 ③ 是命门：只要「放回」或「独立重复」，p 才不变；一旦不放回，第 2 次的成功概率就已经不是 p 了，公式立刻失效。

二项分布 · 期望与方差人教A版选择性必修第三册 · 第七章第四节

若 X~B(n,p)，则 E(X)=np，D(X)=np(1−p)。

→ 翻成人话：期望就是「做 n 次、每次 p 的成功率，平均成功 np 次」，直觉好接受；方差是 np(1−p)，不是 np。多乘的那个 (1−p) 是失败概率，它保证 p=0 或 p=1 时方差为 0——每次都必成或必败，当然没有波动。

超几何分布 · 定义与期望人教A版选择性必修第三册 · 第七章第四节

从含有 M 件次品的 N 件产品中不放回地抽取 n 件，用 X 表示抽到的次品数，则 P(X=k)=C(M,k)C(N−M,n−k)/C(N,n)，称 X 服从超几何分布，且 E(X)=nM/N。

→ 翻成人话：分子是「从 M 件次品里挑 k 件」乘「从 N−M 件正品里挑 n−k 件」，分母是「从 N 件里随便挑 n 件」，这是不放回的计数方式。注意两点：一是超几何的期望也是 nM/N，就是「样本容量 × 次品率」，和二项的 np 长得一模一样；二是方差不同，超几何的方差比 np(1−p) 小，因为不放回相当于多知道了信息。

条件二项分布 B(n,p)超几何分布
抽样方式（谁决定用哪个）有放回，或各次独立重复，每次 p 不变不放回，一次取 n 件，样本池逐次变小
n 的含义试验总次数，先定 n 再数成功次数样本容量，从 N 件里取 n 件（n ≤ N）
k 的取值范围0,1,2,…,n，全部取得到受两端夹住：max(0,n−(N−M)) ≤ k ≤ min(n,M)
分布列C(n,k)pᵏ(1−p)ⁿ⁻ᵏC(M,k)C(N−M,n−k)/C(N,n)
期望E(X)=npE(X)=nM/N，也是「样本量 × 比例」
方差D(X)=np(1−p)比 np(1−p) 小，高中不必套公式，理解即可
典型场景有放回摸球、独立射击、独立投掷产品抽检、抽签、从一批里一次抽若干

背法：先问一句「放不放回去」。放回去 → 二项，套 C(n,k)pᵏ(1−p)ⁿ⁻ᵏ、np、np(1−p)；不放回去 → 超几何，套组合数之比、nM/N，方差别硬套 np(1−p)。另外，当 N 很大而 n 相对很小时，不放回抽到次品的概率几乎不变，超几何分布可以用二项分布近似，这也是「不放回为什么有时也能当二项算」的真正理由。

例题 · 二项分布的期望与方差必考

某射手每次射击命中目标的概率为 0.8，各次射击相互独立。现连续射击 5 次，用 X 表示命中的次数。（1）写出 X 的分布列形式，并求 E(X)；（2）求 D(X) 与标准差 √D(X)（标准差精确到 0.01）。陷阱注意第 2 问，D(X) 不是 np。

  1. 第 1 步 · 审题定性

    5 次射击「相互独立」，且每次命中率都是同一个 0.8：这就是 n=5、p=0.8 的 n 次独立重复试验，X 是其中的成功次数。

    用到：二项分布三个条件（次数定、两种结果、独立且 p 不变）。只要出现「不放回」，这一步就走不通。

  2. 第 2 步 · 写模型与分布列

    X~B(5,0.8)，即 P(X=k)=C(5,k)0.8ᵏ0.2⁵⁻ᵏ，k=0,1,2,3,4,5。二项是有放回／独立重复，超几何是不放回，本题属于前者。

    用到：分布列公式。别漏写 k 的取值范围。

  3. 第 3 步 · 求期望

    E(X)=np=5×0.8=4。含义是平均命中 4 次，而 4 也正好是分布列的峰值位置（np 一定落在峰值附近）。

    用到：E(X)=np。

  4. 第 4 步 · 求方差

    D(X)=np(1−p)=5×0.8×0.2=0.8。这里最容易只写 5×0.8=4，那是期望，不是方差。

    用到：D(X)=np(1−p) 不是 np；1−p 就是失败概率 0.2。

  5. 第 5 步 · 收尾算标准差

    √D(X)=√0.8=√(4/5)=2√5/5≈0.89。标准差与 X 同单位，带单位作答才完整。

    用到：标准差是方差的算术平方根，开方后要保留两位小数。

1 / 5

标准答案（可抄进答题卡）

（1）因为 5 次射击相互独立，且每次命中概率均为 0.8，所以命中次数 X 服从二项分布，即 X~B(5,0.8)，P(X=k)=C(5,k)0.8ᵏ0.2⁵⁻ᵏ（k=0,1,…,5）。于是 E(X)=np=5×0.8=4。
（2）D(X)=np(1−p)=5×0.8×(1−0.8)=0.8，所以 √D(X)=√0.8=2√5/5≈0.89。
答：E(X)=4，D(X)=0.8，标准差约为 0.89。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「拿到题，我怎么知道该用二项还是超几何？」

只看一件事：抽完放不放回去。放回（或题目说「独立重复」「各次相互独立且概率相同」）→ 二项分布 B(n,p)；不放回（「一次抽取 n 件」「从中任取 n 件」）→ 超几何分布。二项是有放回／独立重复，超几何是不放回，与题目里的产品、球、射击这些外壳无关。

「D(X)=np(1−p) 里的 p 到底是谁？」

p 是单次试验成功的概率，不是总成功次数、不是命中总数。所以 n=5、p=0.8 时 D=5×0.8×0.2=0.8；把 p 当成 E(X)=4 代进去会算出 5×4×(−3) 这种荒唐值。1−p 是单次失败的概率，两者相加必须是 1。

「命中率 0.8，期望 4 次，方差怎么才 0.8？是不是算错了？」

没算错。D=np(1−p)=5×0.8×0.2=0.8，比 E=4 小很多，因为 p=0.8 偏高、结果很集中：多数情况就是命中 4 次。D(X)=np(1−p) 不是 np；p 越接近 0 或 1，方差越小，p=0.5 时方差最大。

「超几何分布的期望也要用组合数硬算吗？」

不用。课本给了结论：超几何的期望也是 nM/N，即「样本容量 × 次品率」，和二项的 np 形式完全一致。只有方差不同：超几何的方差比 np(1−p) 小，高中阶段不必记公式，理解「不放回信息更多、波动更小」即可。

「n=1 的时候，二项分布 B(1,p) 是什么东西？」

就是两点分布（也叫 0–1 分布）：X 只取 0 和 1，P(X=1)=p，P(X=0)=1−p。此时 E=np=p，D=np(1−p)=p(1−p)，与 7.3 的两点分布完全一致。所以二项分布是两点分布的 n 次独立重复版本。

「不就是少放回一次吗，凭什么不能直接用二项？」

因为二项分布的命门是各次独立、p 恒定。不放回时，第一件抽走后面池子只剩 19 件：抽到次品则次品率降为 4/19，抽到正品则升为 5/19，p 已经变了，独立性直接破裂，C(n,k)pᵏ(1−p)ⁿ⁻ᵏ 里的 p 失去意义。只有当 N 远大于 n（如 N=10000 取 n=10）时，p 变化极小，才可用二项分布近似超几何分布。

这六问其实是同一件事：先定「放不放回」，再定「用哪个公式」，最后才动笔算数。顺序反了，后面全错。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 从 20 件产品（含 5 件次品）中一次任取 4 件，设 X 为次品数，则 X~B(4,0.25)。

✓ 一次任取 4 件是不放回抽取，X 服从超几何分布，P(X=k)=C(5,k)C(15,4−k)/C(20,4)。

错在哪：二项是有放回／独立重复，超几何是不放回。看到「一次取 n 件」「不放回」就不能写 B(n,p)，0.25 这个概率在第 2 次就已经变了。

✗ X~B(5,0.8)，所以 D(X)=np=5×0.8=4。

✓ D(X)=np(1−p)=5×0.8×0.2=0.8，而 E(X)=np=4。

错在哪：D(X)=np(1−p) 不是 np。4 是期望不是方差；方差必须再乘失败概率 1−p。

✗ P(X=k)=C(n,k)(1−p)ᵏpⁿ⁻ᵏ，反正 p 和 1−p 换一下也一样。

✓ P(X=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ，p 是「成功」的概率，指数 k 对应成功次数。

错在哪：E 和 D 确实不变（对 p、1−p 对称），但分布列整体错位：P(X=0) 与 P(X=n) 会被互换，求具体某个 k 的概率时全错。

✗ 超几何分布的方差就是 np(1−p)，直接代进去算。

✓ 超几何的方差比 np(1−p) 小；高中只要求理解，不要求记公式，答题时不必写。

错在哪：np(1−p) 只是二项分布的精确方差；用在超几何上是近似值而且偏大，题目要精确值就扣分。

✗ 二项分布 B(n,p) 的图形一定左右对称，峰值在正中间。

✓ 只有 p=0.5 时才关于 np 对称；p≠0.5 时峰值偏在一侧，n 较小时尤其明显。

错在哪：把 p=0.5 的特例当成通例。峰值位置由 np 决定，未必是 n/2。

✗ 二项分布和超几何分布的期望都等于 np，所以它们是一回事。

✓ 超几何的期望也是 nM/N，与二项的 np 同形，但两者的分布列与方差不同，是两个不同模型。

错在哪：期望撞车不等于分布相同。判据永远是抽样方式，不是期望公式。

✗ 题目说「抽取 5 件」，我就把 n 当作产品总数 N 算超几何。

✓ N 是产品总数（分母 C(N,n)），n 是抽出的样本容量，M 是其中的次品数，三者不能混。

错在哪：n 与 N 搞反会让 C(N,n) 直接算不出来（n>N）或概率全错；写分布列前先把 N、M、n 三个字母标在题干上。

✗ 只要是不放回，就一定要用超几何，n 多大都一样。

✓ 不放回时超几何是精确模型；但当 N 远大于 n 时，p 变化极小，可用二项分布近似。

错在哪：忽略了「N 很大、n 很小」这个近似条件，反过来把该用超几何的题也近似成二项，属于另一头错。
