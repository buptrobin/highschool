01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 2×2 列联表人教A版选择性必修第三册 · 第八章第三节

设 A、B 为两个分类变量，从样本中得到分类数据，按两个变量的取值交叉排列所成的表格，叫做 2×2 列联表；表中 a、b、c、d 是四个交叉计数，n = a+b+c+d 是样本容量。

→ 翻成人话：把 100 个人先按「哪一组」分行、再按「有效 / 无效」分列，四个格子里填人数，最后补上行合计、列合计。这张表有三个条件：① 行是分组、列是结果；② 四格互不重叠；③ 右下角必须是总人数 n。

课本原话 · χ² 统计量人教A版选择性必修第三册 · 第八章第三节

χ² = n(ad − bc)² / [(a+b)(c+d)(a+c)(b+d)]，其中 n = a + b + c + d 为样本容量。

→ 翻成人话：先对角相乘再相减（ad − bc），把差平方，乘上总人数 n，再除以四个合计的乘积。三个条件缺一不可：① n 是总人数；② 分子整体平方；③ 分母四个合计一个都不能少。

课本原话 · 判断规则人教A版选择性必修第三册 · 第八章第三节

若 χ² ≥ 3.841，则有 95% 的把握认为变量 A 与 B 有关联；若 χ² ≥ 6.635，则有 99% 的把握认为变量 A 与 B 有关联；否则不能作出这样的判断。

→ 翻成人话：两条线、三种写法。「否则」那一句是不能作出「有关联」的判断，不是「两个变量没有关系」——差一个字的措辞，整道题的结论分就没了。

条件正确做法写错会怎样
四个格子的含义a=甲有效、b=甲无效、c=乙有效、d=乙无效含义说反，解释全反；但 ad−bc 只变号，平方后 χ² 不变
分子要平方先算 ad−bc，再把差平方忘记平方，χ² 被压小，该判显著时判不出来
分母四个合计(a+b)(c+d)(a+c)(b+d) 一个都不能少少乘一个，χ² 被放大几倍，凭空「显著」
n 是谁n = a+b+c+d，是总人数用成一组人数（如 100），χ² 只剩正确值的一半
与临界值比较和 3.841 比得 95%，和 6.635 比得 99%两个临界值记反，把握程度说错

背法：对角相减 → 平方 → 乘总人数 → 除四个合计。整张表最该盯住的是高亮那一行：公式里的 n 是总人数，不是甲组或乙组的人数，这一处代错，后面全错。

03自己拖一下核心

拖「甲组有效人数 a」，看右边 χ² 怎么跟着动。盯住两个点：a=70 时 χ²≈2.20 还不到线，a=75 时 χ²≈5.13 刚越过 3.841——结论就在这一步翻转。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 独立性检验的完整书写必考

某机构调查一种训练方法是否有效：甲组 100 人中有 75 人有效、25 人无效；乙组 100 人中有 60 人有效、40 人无效。问：能否据此认为「有效率」与「分组」有关联？请写出完整过程与结论。

  1. 第 1 步 · 审题：确认是两个分类变量

    变量一是分组（甲 / 乙），变量二是结果（有效 / 无效），都是分类变量，用 2×2 列联表与独立性检验，χ² 的临界值查 3.841 与 6.635。

    用到：独立性检验的适用对象——两个分类变量是否有关联。

  2. 第 2 步 · 列表：把四个数放对格子

    甲组有效 a=75、甲组无效 b=25、乙组有效 c=60、乙组无效 d=40。行合计 100、100，列合计 a+c=135、b+d=65，总人数 n=200。

    用到：2×2 列联表的行列约定，n=a+b+c+d 是总人数。

  3. 第 3 步 · 代入：先算 ad−bc 再平方

    ad−bc = 75×40 − 25×60 = 3000 − 1500 = 1500，平方得 2250000。分母 = 100×100×135×65 = 87750000，分子 = 200×2250000 = 450000000。

    用到：χ² = n(ad−bc)²/[(a+b)(c+d)(a+c)(b+d)]，n 取 200。

  4. 第 4 步 · 算值：χ²≈5.128

    χ² = 450000000 ÷ 87750000 ≈ 5.128。注意这里是 5.128，不是 51.28，也不是 2.56——分母四个合计少乘一个，结果就会差好几倍。

    用到：分步约分，最后保留三到四位小数即可。

  5. 第 5 步 · 比较临界值并写结论

    5.128 > 3.841 但 5.128 < 6.635，落在 95% 这一档。结论写「有 95% 的把握认为有效率与分组有关联」，不能写「有效率与分组一定有关」。

    用到：3.841 ↔ 95%、6.635 ↔ 99%；不到 3.841 只能写「没有充分证据」。

1 / 5

标准答案（可抄进答题卡）

① 列出 2×2 列联表：a=75，b=25，c=60，d=40，n=a+b+c+d=200。
② 计算 ad−bc = 75×40 − 25×60 = 1500，(ad−bc)² = 2250000。
③ 代入公式：χ² = 200×2250000 / (100×100×135×65) = 450000000 / 87750000 ≈ 5.128。
④ 因为 5.128 > 3.841，所以有 95% 的把握认为「有效率」与「分组」有关联。
⑤ 说明：这里的 95% 是判断的把握程度，不等于两个变量一定有关；若要说得更强，必须 χ² ≥ 6.635。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

算出 χ²=5.128，结论能不能写「两个变量一定有关」？

不能。χ² ≥ 3.841 只说明在「两个变量无关联」的前提下，出现当前数据的概率不超过 5%，所以写「有 95% 的把握认为有关联」。结论是概率式的判断，不是确定关系。

χ² 算出来只有 1.2，能说「两个变量无关」吗？

不能。χ² 小只说明没有充分证据说明有关联，可能是真的无关，也可能只是样本量不够。标准写法是「不能据此认为两个变量有关联」，反过来说「无关」就越界了。

公式 χ² = n(ad−bc)²/[(a+b)(c+d)(a+c)(b+d)] 里的 n 是甲组人数吗？

不是。n 是总人数 a+b+c+d。例题里甲组 100、乙组 100，n 要取 200；误用 100 会让 χ² 只剩一半（2.56），刚好从显著掉回不显著。

3.841 和 6.635 分别对应多少把握？

3.841 对应 95%，6.635 对应 99%：数值越大，把握越大。别把两个数记反，也别把 3.841 说成 99%。

列联表和条形图是什么关系？

同一组数据的两种摆法：列联表给数，条形图给形。条形图能一眼看出甲组有效率 75% 高于乙组 60%，但「差距够不够大」必须靠 χ² 判断，看图下结论不算数。

样本量从 200 加到 2000，χ² 会怎么变？

结构不变时 χ² 大致与 n 成正比，会明显变大。这提醒两件事：小样本容易「查不出」关联；也不能靠堆样本把毫无意义的微小差异吹成显著，结论要结合实际差异说。

六问其实是同一件事：χ² 只负责回答「证据够不够」，不负责回答「一定有没有」。证据够就说「有 95% 的把握认为有关联」，证据不够就说「没有充分证据」，两头都不能多说一句。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 因为 χ²=5.128>3.841，所以两个变量有关。

✓ 因为 χ²=5.128>3.841，所以有 95% 的把握认为两个变量有关联。

错在哪：漏掉「95% 的把握」，把概率判断写成了确定关系。

✗ χ²=1.2<3.841，所以两个变量没有关系。

✓ χ²=1.2<3.841，所以没有充分证据说明两个变量有关联。

错在哪：χ² 小只能说证据不足，不能说无关——这两句话方向相反。

✗ χ² = 100×(ad−bc)²/[(a+b)(c+d)(a+c)(b+d)]，n 用甲组的 100。

✓ χ² = 200×(ad−bc)²/[(a+b)(c+d)(a+c)(b+d)]，n=a+b+c+d 是总人数。

错在哪：公式里的 n 是总人数 200，用成一组人数会让 χ² 直接减半。

✗ χ² = n(ad−bc)/[(a+b)(c+d)(a+c)(b+d)]，差算完就除。

✓ χ² = n(ad−bc)²/[(a+b)(c+d)(a+c)(b+d)]，差要先平方。

错在哪：忘记平方，负差还会算出负的 χ²，与「χ² 非负」直接矛盾。

✗ χ²=7.2>6.635，所以有 95% 的把握认为有关联。

✓ χ²=7.2>6.635，所以有 99% 的把握认为有关联。

错在哪：临界值记反了。3.841 对应 95%，6.635 对应 99%，数值大的把握大。

✗ 甲组 10 人里 8 人有效、乙组 10 人里 5 人有效，χ² 够大，可以说有关联。

✓ 样本量太小，即使 χ² 偏大也不宜下结论，应扩大样本后再检验。

错在哪：独立性检验的结论依赖样本量，几十人的数据波动极大，勉强下结论不可靠。

✗ 由列联表算出甲组有效率 75%>60%，所以分组影响有效。

✓ 由列联表算出 χ²≈5.128>3.841，所以有 95% 的把握认为有效率与分组有关联。

错在哪：比大小只看描述性差异，没有做检验，判断「影响」缺少统计依据。
