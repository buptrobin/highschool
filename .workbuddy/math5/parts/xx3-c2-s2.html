一句话说清本节最该记住的判断：随机变量把试验结果换算成一个数 + 分布列把「取值—概率」配成两行表格，且概率和恰好为 1。

这一节把「随机事件」升级成「可以算的数」：先给每个试验结果配一个实数，得到随机变量 X；再把 X 的全部取值与对应概率列成两行表格，得到分布列。它是后面二项分布、超几何分布、均值与方差的统一入口——后面所有公式，本质都在读这张表。
最容易错的一件事：算完不检查「概率和是不是恰好 1」就往下做，等于带着漏掉的取值进考场。

01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句课本话，不是右边的人话。

课本原话 · 随机变量人教A版选择性必修第三册 · 第七章第2节

一般地，对于随机试验的每一个可能的结果，都有一个确定的实数与之对应，这样的变量称为随机变量，常用字母 X、Y、ξ 表示。随机变量随着试验结果的变化而变化。

→ 翻成人话：这句话由三个条件组成——① 试验结果是随机的、不确定的；② 每个结果都唯一对应一个实数；③ 这个数随结果变化。少掉②，写出来的只是一个随手起的代号，谈不上 P(X=xᵢ)。

课本原话 · 分布列人教A版选择性必修第三册 · 第七章第2节

设离散型随机变量 X 的所有可能取值为 x₁, x₂, …, xₙ，X 取每一个值 xᵢ 的概率为 pᵢ（i=1,2,…,n），则称这张表为 X 的概率分布列，简称分布列。

→ 关键词是两个：「所有可能取值」和「每一个」。漏一个取值，概率和永远凑不出 1；只写几个取值，那叫部分概率，不叫分布列。表格必须写成表，不能写成一句话。

课本原话 · 两条性质人教A版选择性必修第三册 · 第七章第2节

离散型随机变量的分布列具有性质：① pᵢ ≥ 0（i=1,2,…,n）；② p₁ + p₂ + … + pₙ = 1。

→ 这两条是自检器，不是装饰：算完先扫一眼有没有负数（概率不能为负），再把所有概率加起来。和不是 1，就说明取值漏了、重了，或某个概率算错——此时必须停下重查，不能硬着头皮写答案。

分布列要满足的条件具体写法缺了会怎样
取值列全X 的所有可能取值 x₁, x₂, …, xₙ 一个不漏漏一个 ⇒ 概率和 < 1，整题作废
概率非负每个 pᵢ ≥ 0，概率不能为负出现负数 ⇒ 该取值或该概率算错
概率和恰为 1p₁ + p₂ + … + pₙ = 1（恰好，不是约等于）和 ≠ 1 ⇒ 必有漏算或重算，先停下查题
写成表格上行放取值、下行放概率，逐列对齐写成文字叙述 ⇒ 对应关系看不见，不得分

整张表只高亮 1 行：真正要盯死的是「和为 1」——它既是检验，也是最后一步。写分布列的固定顺序：先列全取值 → 再逐个算概率 → 最后加一遍验证。顺序颠倒，就容易一边算一边漏。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 求分布列必考

袋中装有 3 个红球、2 个白球，从中任取 2 个球。设 X 为取到的红球个数，求 X 的分布列，并求 P(X≤1)。

  1. 第 1 步 · 定 X，列全取值

    「任取 2 个」→ 红球个数最少 0 个（两个都是白球），最多 2 个（两个都是红球），中间还能取 1 个。所以 X 的全部取值为 0、1、2，共 3 个，一个都不能少。

    用到：离散型随机变量的取值要列全，这直接决定表格有几列。

  2. 第 2 步 · 算样本点总数

    从 5 个球中任取 2 个，与顺序无关，是组合问题：总数 n = C(5,2) = 10。这 10 个样本点等可能，可以用古典概型算概率。

    用到：古典概型——样本点有限且等可能，P(A)=事件 A 含的样本点数 ÷ 总数。

  3. 第 3 步 · 逐个取值算概率

    取 0 个红球＝取 2 个白球：P(X=0) = C(3,0)C(2,2)/C(5,2) = 1/10。
    取 1 个红球＝1 红 1 白：P(X=1) = C(3,1)C(2,1)/C(5,2) = 6/10。
    取 2 个红球＝2 个都是红球：P(X=2) = C(3,2)C(2,0)/C(5,2) = 3/10。

    用到：「先分类再分步」计数：红球取法数 × 白球取法数。

  4. 第 4 步 · 自检：非负 + 和为 1

    三个概率 1/10、6/10、3/10 都 ≥ 0；相加得 (1+6+3)/10 = 10/10 = 1。两条性质都通过，说明取值没有漏、概率没有算错。和不是 1 就说明还有取值没找到，必须回去查。

    用到：pᵢ ≥ 0 与 p₁+p₂+…+pₙ = 1 是分布列的两条性质，也是唯一的自检手段。

  5. 第 5 步 · 写成两行表格，再累加

    分布列写成上行取值 0、1、2，下行概率 1/10、6/10、3/10。求 P(X≤1) 时把 a=1 左边（含 1）的列相加：P(X≤1) = P(X=0) + P(X=1) = 1/10 + 6/10 = 7/10。

    用到：P(X≤a) 用分布列累加，不是连乘，也不是 1 减去某一项。

1 / 5

标准答案（可抄进答题卡）

X 的所有可能取值为 0，1，2。
样本点总数 C(5,2) = 10。
P(X=0) = C(3,0)C(2,2)/C(5,2) = 1/10；
P(X=1) = C(3,1)C(2,1)/C(5,2) = 6/10；
P(X=2) = C(3,2)C(2,0)/C(5,2) = 3/10。
验证：1/10 + 6/10 + 3/10 = 1，且各概率均非负，故 X 的分布列为
P(X=0)=1/10，P(X=1)=6/10，P(X=2)=3/10
（答题卡上写成两行表格：上行 X 取 0、1、2，下行 P 取 1/10、6/10、3/10。）
所以 P(X≤1) = P(X=0) + P(X=1) = 1/10 + 6/10 = 7/10。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「分布列必须满足什么？」

两条性质缺一不可：① 每个 pᵢ ≥ 0（概率不能为负）；② p₁+p₂+…+pₙ = 1（概率和恰为 1）。此外所有取值必须列全，且写成两行表格。这四条里任何一条不满足，这张表就不是分布列。

「概率加起来不是 1，说明什么？」

说明这张表还不是分布列，必有一处错：要么有取值没列全（最常见，漏了最大或最小的那个取值），要么某个概率算错、要么各列重复计算。此时不能写「约为 1」蒙过去，必须回去把取值重新数一遍，再逐个重算。

「随机变量一定是数吗？」

是。随机变量是定义在样本空间上的实值变量，取的值是实数，不是文字、不是事件。「掷出正面」是事件不是随机变量；令 X=1 表示正面、X=0 表示反面，X 才是随机变量。所以写分布列时上行一定写数。

「离散型和连续型差在哪？」

看取值能不能一个一个列出来。离散型：取值是有限个或可列无限个（0、1、2…），可以写成两行分布列。连续型：取值填满一个区间，列不出来，单个点的概率为 0，要用密度曲线下的面积算区间概率，不能写分布列。

「P(X≤2) 怎么算？」

用分布列累加：把满足 X≤2 的所有列的概率相加，即 P(X≤2)=P(X=0)+P(X=1)+P(X=2)。若 2 已是最大取值，结果就是 1。不能连乘（连乘是求「同时发生」），也不能把 2 当成概率去乘。

「分布列能写成公式吗？」

可以，但公式必须与表格完全一致：公式给出的是 P(X=k) 的通项，表格给出的是每一个具体取值。考试里如果题目问「求分布列」，必须列出全部取值和概率（写成两行表格），只写一个通项公式通常不给满分；问「求概率」时用公式更快。

这六问其实是同一件事：分布列是一张必须完整、必须自洽的表——取值列全、概率非负、和恰为 1、写成两行。所有扣分都从这四条里漏掉一条开始。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ X 可能取 0、1，所以 P(X=0)=0.4，P(X=1)=0.5。

✓ X 的所有可能取值为 0，1，2，且 P(X=0)=0.1，P(X=1)=0.6，P(X=2)=0.3，和为 1。

错在哪：漏写了取值 2。分布列必须列全所有取值；漏一个，概率和只有 0.9，一眼就能看出表不成立。

✗ 概率和等于 0.9，约等于 1，就按这个写下去。

✓ 概率和必须恰好为 1；0.9 ≠ 1，先回去补全取值、重算概率，再写分布列。

错在哪：没有「约等于 1」。和不为 1 说明表本身是错的，继续往下算只会全错。

✗ 由 1 − 0.6 − 0.5 = −0.1 得 P(X=2) = −0.1。

✓ 概率不能为负；算出负数说明前面某个概率或取值错了，必须重算。

错在哪：把负数当答案交上去。pᵢ ≥ 0 是不可越过的红线，出现负数等于自己宣布这张表作废。

✗ X 的取值是「取到红球」「取到白球」。

✓ X 表示取到的红球个数，取值为 0，1，2；「取到红球」是事件，不是 X 的取值。

错在哪：把事件当成了取值。随机变量取的是实数，表格上行只能写数，写文字就没法算概率和。

✗ P(X≤2) = P(X=0)×P(X=1)×P(X=2)。

✓ P(X≤2) = P(X=0) + P(X=1) + P(X=2)，由分布列累加得到。

错在哪：把「或」用成了「且」。X≤2 是几个互斥情形的并，概率相加；连乘是求同时发生，这里根本不适用。

✗ 分布列：X 取 0 的概率是十分之一，取 1 的概率是十分之六，取 2 的概率是十分之三。

✓ 写成两行表格：上行 X 为 0、1、2，下行 P 为 1/10、6/10、3/10。

错在哪：写成文字叙述。分布列的「列」就是表格，取值与概率必须逐列对齐，写成句子阅卷时看不到对应关系。

✗ 表格上行写 0、1、2，下行写 0.1、0.3、0.6，顺序照抄题目。

✓ 下行概率必须与上行取值逐列对应：0↔0.1，1↔0.6，2↔0.3，和恰为 1。

错在哪：上下两行错位。概率和仍是 1，但每个取值的概率都配错了，属于「看起来对、其实全错」。
