## xx3-c1-s1 分类加法计数原理与分步乘法计数原理

**课本原话**
1. 完成一件事有两类不同方案，在第 1 类方案中有 m 种不同的方法，在第 2 类方案中有 n 种不同的方法，那么完成这件事共有 N=m+n 种不同的方法。
2. 完成一件事需要两个步骤，做第 1 步有 m 种不同的方法，做第 2 步有 n 种不同的方法，那么完成这件事共有 N=m×n 种不同的方法。
3. 分类要「不重不漏」，分步要「步步相依」。

**三个扣分点**：「分类」用加法、「分步」用乘法，判据是**这件事做完了没有**（做完→加，没做完→乘）；分类必须不重不漏；分步中间任何一步缺失都不算完成。

**四张图**：① 分类加法（两条并列的路，终点相同）；② 分步乘法（两段必须都走完）；③ 判据：做完没做完；④ 一个既有分类又有分步的复合例子（先分类、类内分步）。

**互动模型**：滑块＝上衣件数 m（1 到 6，step 1），下装固定 3 件
```js
ways = m * 3;                    // 分步乘法：先选上衣再选裤子
mix  = m + 3;                    // 对照：分类加法（只有上衣或只有裤子时才用）
```
`cases`：`{v:1,eq:{ways:3}}`、`{v:3,eq:{ways:9}}`、`{v:6,eq:{ways:18}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:3},{t:6.5,v:3},{t:9,v:6},{t:11.5,v:4},{t:13.5,v:1}]`，keys `[1,3,6]`。
**停留帧在 m=3**（3×3=9 种配法，每一件上衣都有 3 条裤子可配）。
状态：m 件上衣「先上衣后裤子，是分步，要相乘」。

**例题**：「书架上有 5 本数学书、3 本物理书、4 本化学书。① 任取 1 本有多少种取法？② 每科各取 1 本有多少种取法？」答案：① 只取 1 本，三类方案任选其一，5+3+4=12 种；② 三科都要取，分三步，5×3×4=60 种。
**六问**：① 加法与乘法怎么区分；② 分类为什么要不重不漏；③ 「至少」「至多」算分类还是分步；④ 分步中间一步有 0 种方法会怎样；⑤ 同一件事能否既分类又分步（分层的题怎么做）；⑥ 数字能不能相加后再乘。
**易错**：✗ 分步用加法 / ✗ 分类用乘法 / ✗ 分类有重复 / ✗ 分类有遗漏 / ✗ 把「每类取一个」当分类 / ✗ 复合题不画层次直接乘。

## xx3-c1-s2 排列与组合

**课本原话**
1. 从 n 个不同元素中取出 m（m≤n）个元素，按照一定的顺序排成一列，叫做从 n 个不同元素中取出 m 个元素的一个排列。
2. 排列数 A(n,m)=n(n−1)…(n−m+1)=n!/(n−m)!。
3. 组合数 C(n,m)=A(n,m)/m!=n!/[m!(n−m)!]，且 C(n,m)=C(n,n−m)。

**三个扣分点**：**有序用排列、无序用组合**（「选出 3 人当代表」与「选出 3 人分别任正副组长」不同）；排列数比组合数多除的正是 m!；C(n,m)=C(n,n−m) 可以简化计算。

**四张图**：① 排列的「位置与顺序」；② 组合的「只成团不排序」；③ 同一组元素两种算法对照（A 与 C 的关系）；④ C(n,m)=C(n,n−m) 的对称性。

**互动模型**：滑块＝取出个数 m（1 到 5，step 1），n=5
```js
A = 1; for (let i = 0; i < m; i++) A *= 5 - i;   // A(5,m)
C = A; for (let i = 2; i <= m; i++) C /= i;       // C(5,m) = A/m!
```
`cases`：`{v:2,eq:{A:20,C:10}}`、`{v:3,eq:{A:60,C:10}}`、`{v:5,eq:{A:120,C:1}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:3},{t:6.5,v:3},{t:9,v:5},{t:11.5,v:4},{t:13.5,v:1}]`，keys `[1,3,5]`。
**停留帧在 m=3**（A(5,3)=60、C(5,3)=10，且 C(5,3)=C(5,2)=10，对称性一眼可见）。
状态：m=3「选了 3 个还排了序 ⇒ A；只成团 ⇒ C」。

**例题**：「从 5 人中选 3 人。① 选 3 人参加同一个活动，多少种？② 选 3 人分别担任正、副、组长，多少种？」答案：① 无序，C(5,3)=10 种；② 有序，A(5,3)=60 种（也就是 10×3!）。
**六问**：① 怎么判断该用 A 还是 C；② C(n,m) 为什么要除以 m!；③ A(n,n)=n! 对吗；④ C(n,0) 等于多少；⑤ C(5,3) 与 C(5,2) 为什么相等；⑥ 「相邻」「不相邻」问题怎么处理。
**易错**：✗ 该用 C 时用了 A / ✗ 组合数忘记除 m! / ✗ C(n,0)=0 / ✗ 把 C(n,n−m) 当成另一个数 / ✗ 排列数写成 nᵐ（可重复） / ✗ 「至少有 1 个」直接算不分类。

## xx3-c1-s3 二项式定理

**课本原话**
1. (a+b)ⁿ=C(n,0)aⁿ+C(n,1)aⁿ⁻¹b+…+C(n,n)bⁿ。
2. 通项公式：T(k+1)=C(n,k)aⁿ⁻ᵏbᵏ（k=0,1,…,n）。
3. 二项式系数的性质：C(n,0)+C(n,1)+…+C(n,n)=2ⁿ；中间项系数最大。

**三个扣分点**：通项里 a 的指数是 **n−k**、b 的指数是 k（写反就全错）；系数之和 2ⁿ 是把 a=b=1 代进去得到的，**不是** 2n；中间项看 n 是奇偶：n 为偶数时第 n/2+1 项系数最大。

**四张图**：① 杨辉三角与二项式系数；② 通项的 indices（a 降 b 升）；③ 赋值法求系数和（a=b=1）；④ 二项式系数与项的系数的区别。

**互动模型**：滑块＝n（0 到 6，step 1）
```js
sum = Math.pow(2, n);                          // 各二项式系数之和
mid = n === 0 ? 1 : C(n, Math.floor(n / 2));   // 最大二项式系数
row = [C(n,0), …, C(n,n)];                     // 展开式各项系数
```
其中 C(n,k) 用连乘实现。`cases`：`{v:2,eq:{sum:4,mid:2}}`、`{v:4,eq:{sum:16,mid:6}}`、`{v:6,eq:{sum:64,mid:20}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:4},{t:6.5,v:4},{t:9,v:6},{t:11.5,v:3},{t:13.5,v:0}]`，keys `[0,4,6]`。
**停留帧在 n=4**（1,4,6,4,1，对称、中间系数 6 最大，系数和 16）。
状态：n=4「系数成对对称，中间的 6 最大」。

**例题**：「求 (2x+1)⁶ 的展开式中 x³ 的系数。」答案：通项 T(k+1)=C(6,k)(2x)⁶⁻ᵏ，要 x³ 需 6−k=3，即 k=3，系数为 C(6,3)×2³=20×8=160。
**六问**：① 通项里 a、b 的指数怎么分配；② 系数和为什么是 2ⁿ；③ 二项式系数和与项的系数和一样吗；④ n 为偶数时哪一项系数最大；⑤ 常数项怎么求；⑥ 杨辉三角相邻两行有什么关系。
**易错**：✗ 通项指数写反 / ✗ 系数和写成 2n / ✗ 把二项式系数当项的系数 / ✗ 中间项位置算错（n 为偶数时是第 n/2+1 项） / ✗ 求常数项时忘记 x 的指数 / ✗ 忘记 C(n,k) 前的数字系数。

## xx3-c2-s1 条件概率与全概率公式

**课本原话**
1. 条件概率：P(B|A)=P(AB)/P(A)（P(A)>0）。
2. 乘法公式：P(AB)=P(A)P(B|A)。
3. 全概率公式：若 A₁,A₂ 互斥且和为全集，则 P(B)=P(A₁)P(B|A₁)+P(A₂)P(B|A₂)。

**三个扣分点**：**P(B|A) 与 P(A|B) 不是一回事**（分母不同）；条件概率的分母是 P(A) 不是 1；全概率要**把所有互斥情形都算上**，漏一类就错。

**四张图**：① 条件概率的「缩小样本空间」；② P(B|A) 与 P(A|B) 的对照（两个方向不同）；③ 全概率的树形分解；④ 树形图上概率的乘法与加法。

**互动模型**：滑块＝P(A)（0.2 到 0.9，step 0.05），已知 P(B|A)=0.8、P(B|Ā)=0.3
```js
pA = p; pnA = 1 - p;
pb = pA * 0.8 + pnA * 0.3;      // 全概率公式
```
`cases`：`{v:0.2,eq:{pb:0.4}}`、`{v:0.5,eq:{pb:0.55}}`、`{v:0.9,eq:{pb:0.75}}`。
Autopilot：`[{t:0,v:0.2},{t:1.2,v:0.2},{t:4,v:0.5},{t:6.5,v:0.5},{t:9,v:0.9},{t:11.5,v:0.7},{t:13.5,v:0.2}]`，keys `[0.2,0.5,0.9]`。
**停留帧在 P(A)=0.5**（P(B)=0.55，正好是 0.8 与 0.3 的加权平均，落在两者之间）。
状态：P(A) 越大「P(B) 越靠向 0.8」；P(A) 越小「越靠向 0.3」。

**例题**：「某厂两条生产线，甲线产量占 60%，次品率 2%；乙线占 40%，次品率 5%。求任取一件是次品的概率。」答案：P(B)=0.6×0.02+0.4×0.05=0.012+0.02=0.032。
**六问**：① P(B|A) 与 P(A|B) 一样吗；② 条件概率分母是什么；③ 全概率为什么要把各类加起来；④ 各类必须互斥吗；⑤ 树形图上哪一步用乘、哪一步用加；⑥ 已知结果求原因用哪个公式（贝叶斯）。
**易错**：✗ 把 P(B|A) 当 P(B) / ✗ 分母用 P(B) / ✗ 全概率漏一类 / ✗ 各类有重叠 / ✗ 树上把「加」和「乘」用反 / ✗ 条件概率写出大于 1 的值。

## xx3-c2-s2 离散型随机变量及其分布列

**课本原话**
1. 随机变量：随着试验结果变化而变化的变量，常用 X、Y、ξ 表示。
2. 离散型随机变量的分布列：列出 X 的所有取值 x₁,x₂,… 及对应概率 p₁,p₂,…。
3. 分布列的两个性质：pᵢ≥0；p₁+p₂+…=1。

**三个扣分点**：分布列必须**列全所有取值**且概率和**恰好为 1**；概率不能为负；写成表格不是写成一句话。

**四张图**：① 随机变量与试验结果的对应；② 分布列的表格形式（两行）；③ 两条性质的自检（非负、和为 1）；④ 由分布列求 P(X≤a) 的累加。

**互动模型**：滑块＝成功概率 p（0.1 到 0.9，step 0.05），X 取 0、1（两点分布）
```js
p0 = 1 - p;              // P(X=0)
p1 = p;                  // P(X=1)
sum = p0 + p1;           // 恒为 1
cdf0 = p0;               // P(X≤0)
```
`cases`：`{v:0.3,eq:{p0:0.7,p1:0.3,sum:1}}`、`{v:0.5,eq:{p0:0.5,p1:0.5,sum:1}}`、`{v:0.9,eq:{p0:0.1,p1:0.9,sum:1}}`。
Autopilot：`[{t:0,v:0.1},{t:1.2,v:0.1},{t:4,v:0.5},{t:6.5,v:0.5},{t:9,v:0.9},{t:11.5,v:0.7},{t:13.5,v:0.1}]`，keys `[0.1,0.5,0.9]`。
**停留帧在 p=0.5**（p₀=p₁=0.5，和恰好 1，分布列最对称的一格）。
状态：任何 p「p₀+p₁=1」恒成立——这就是分布列的自检。

**例题**：「袋中有 3 个红球、2 个白球，任取 2 个，求取到红球个数 X 的分布列。」答案：X 可取 0、1、2；P(X=0)=C(2,2)/C(5,2)=1/10，P(X=1)=C(3,1)C(2,1)/C(5,2)=6/10，P(X=2)=C(3,2)/C(5,2)=3/10；和为 1。
**六问**：① 分布列必须满足什么；② 概率和不为 1 说明什么；③ 随机变量一定是数吗；④ 离散与连续的区别；⑤ P(X≤2) 怎么算；⑥ 分布列能写成公式吗。
**易错**：✗ 漏写某个取值 / ✗ 概率和不为 1 还往下做 / ✗ 概率出现负数 / ✗ 把 X 的取值写成事件 / ✗ P(X≤2) 用连乘 / ✗ 分布列写成文字叙述。

## xx3-c2-s3 离散型随机变量的数字特征

**课本原话**
1. 均值（数学期望）E(X)=x₁p₁+x₂p₂+…+xₙpₙ。
2. 方差 D(X)=(x₁−E(X))²p₁+…+(xₙ−E(X))²pₙ，标准差 σ(X)=√D(X)。
3. 线性性质：E(aX+b)=aE(X)+b，D(aX+b)=a²D(X)。

**三个扣分点**：**D(aX+b)=a²D(X)**（不是 aD，也不是 a²D+b——常数 b 不改变方差）；E(X) 是加权平均不是算术平均；方差的单位是原数据单位的平方。

**四张图**：① 均值的加权平均意义（天平支点）；② 方差是「离均值的平均平方距离」；③ 数据整体平移 b 时方差不变；④ 数据放大 a 倍时方差放大 a² 倍。

**互动模型**：滑块＝倍数 a（1 到 4，step 0.5），X 取 1、2、3 等可能 → E(X)=2、D(X)=2/3，Y=aX
```js
ex = 2; dx = 2 / 3;
ey = a * ex;             // E(aX) = a·E(X)
dy = a * a * dx;         // D(aX) = a²·D(X)
```
`cases`：`{v:1,eq:{ey:2,dy:0.6667}}`、`{v:2,eq:{ey:4,dy:2.6667}}`、`{v:3.5,eq:{ey:7,dy:8.1667}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:2},{t:6.5,v:2},{t:9,v:4},{t:11.5,v:3},{t:13.5,v:1}]`，keys `[1,2,3,4]`。
**停留帧在 a=2**（均值翻 2 倍变 4，方差翻 4 倍变 2.667——方差不是翻 2 倍，最反直觉的一格）。
状态：a 变化「均值线性放大，方差按平方放大」。

**例题**：「X 的分布列：P(X=1)=0.2、P(X=2)=0.5、P(X=3)=0.3。求 E(X)、D(X) 与 E(2X+1)、D(2X+1)。」答案：E(X)=1×0.2+2×0.5+3×0.3=2.1；D(X)=(−1.1)²×0.2+(−0.1)²×0.5+(0.9)²×0.3=0.242+0.005+0.243=0.49；E(2X+1)=2×2.1+1=5.2；D(2X+1)=4×0.49=1.96。
**六问**：① 方差公式里为什么要平方；② D(aX+b) 与 a、b 的关系；③ 均值一定是分布列里的某个取值吗；④ 方差能为负吗；⑤ 标准差与方差的关系；⑥ 两个随机变量的和期望怎么算。
**易错**：✗ D(aX+b)=aD(X) / ✗ 常数 b 影响方差 / ✗ 方差忘了乘概率 / ✗ 均值当算术平均 / ✗ 标准差忘记开方 / ✗ 方差单位写错。

## xx3-c2-s4 二项分布与超几何分布

**课本原话**
1. n 次独立重复试验中，每次成功概率为 p，成功次数 X 服从二项分布，记作 X~B(n,p)。
2. P(X=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ，E(X)=np，D(X)=np(1−p)。
3. 超几何分布：从含 M 件次品的 N 件产品中不放回取 n 件，次品数 X 的分布 P(X=k)=C(M,k)C(N−M,n−k)/C(N,n)，E(X)=nM/N。

**三个扣分点**：二项分布是**有放回/独立重复**，超几何是**不放回**；D(X)=np(1−p) 别写成 np；超几何的期望也是 np 但方差不同（不必记公式，理解即可）。

**四张图**：① 二项分布的直方图（n 变大时的钟形）；② 有放回 vs 不放回的差别；③ 二项分布的 E、D 随 n、p 变化；④ 超几何抽样示意。

**互动模型**：滑块＝试验次数 n（5 到 20，step 1），p=0.4
```js
e = n * 0.4;                    // E(X) = np
d = n * 0.4 * 0.6;              // D(X) = np(1−p)
sd = Math.sqrt(d);              // 标准差
```
`cases`：`{v:5,eq:{e:2,d:1.2}}`、`{v:10,eq:{e:4,d:2.4}}`、`{v:20,eq:{e:8,d:4.8}}`。
Autopilot：`[{t:0,v:5},{t:1.2,v:5},{t:4,v:10},{t:6.5,v:10},{t:9,v:20},{t:11.5,v:15},{t:13.5,v:5}]`，keys `[5,10,15,20]`。
**停留帧在 n=10**（E=4、D=2.4，直方图最像钟形）。
状态：n 增大「期望与方差都按比例增长」。

**例题**：「某射手命中率 0.8，独立射击 5 次，求命中次数 X 的期望与方差。」答案：X~B(5,0.8)，E(X)=5×0.8=4，D(X)=5×0.8×0.2=0.8。
**六问**：① 二项与超几何怎么区分；② D(X)=np(1−p) 里 p 是谁；③ 命中率 0.8 时 D 为什么比 E 小；④ 超几何的期望也是 np 吗；⑤ n=1 时二项分布是什么；⑥ 不放回为什么不能直接用二项。
**易错**：✗ 不放回还用二项 / ✗ D(X)=np / ✗ p 与 1−p 弄反（不影响 E、D 但影响分布列） / ✗ 超几何方差套 np(1−p) 当精确值 / ✗ n 当样本容量用错 / ✗ 认为二项分布一定对称（p≠0.5 时不对称）。

## xx3-c2-s5 正态分布

**课本原话**
1. 若随机变量 X 的概率密度函数为 f(x)=1/(σ√(2π))·e^(−(x−μ)²/(2σ²))，则称 X 服从正态分布 N(μ,σ²)。
2. 正态曲线关于 x=μ 对称；σ 越大曲线越「矮胖」，σ 越小越「瘦高」。
3. 3σ 原则：P(μ−σ<X≤μ+σ)≈0.6827，P(μ−2σ<X≤μ+2σ)≈0.9545，P(μ−3σ<X≤μ+3σ)≈0.9973。

**三个扣分点**：正态曲线的**面积**是概率，高度不是概率；σ 变大曲线变矮但**面积仍是 1**；3σ 原则的三个数是固定值（0.6827 / 0.9545 / 0.9973），不能自己编。

**四张图**：① 正态曲线的钟形与 μ、σ；② μ 变 → 左右平移；③ σ 变 → 胖瘦变化但面积不变；④ 3σ 原则的三段面积。

**互动模型**：滑块＝标准差 σ（0.5 到 3，step 0.25），μ=0
```js
peak = 1 / (Math.sqrt(2 * Math.PI) * s);      // 峰值高度
p1   = 0.6827;                                 // P(|X|<σ) 恒定（不受 σ 影响）
pband = 0.9545;                                // P(|X|<2σ)
```
`cases`：`{v:1,eq:{peak:0.3989}}`、`{v:2,eq:{peak:0.1995}}`、`{v:0.5,eq:{peak:0.7979}}`。
Autopilot：`[{t:0,v:0.5},{t:1.2,v:0.5},{t:4,v:1},{t:6.5,v:1},{t:9,v:3},{t:11.5,v:2},{t:13.5,v:0.5}]`，keys `[0.5,1,2,3]`。
**停留帧在 σ=1**（标准正态，峰值 0.3989，σ 段面积 0.6827——数字最标准的一格）。
状态：σ 越小「越高越瘦」；σ 越大「越矮越胖」；两者面积都还是 1。

**例题**：「某次考试 X~N(90,100)，求 P(80<X≤100) 与 P(X>110)。」答案：μ=90、σ=10；80 与 100 正好是 μ±σ，故 P≈0.6827；110=μ+2σ，P(X>110)=(1−0.9545)/2≈0.0228。
**六问**：① 曲线高度是概率吗；② σ 变大曲线面积变吗；③ 3σ 原则的三个数是什么；④ 为什么 P(X=某个具体值)=0；⑤ μ 变曲线怎么动；⑥ 对称性能怎么用。
**易错**：✗ 把高度当概率 / ✗ σ 变大认为面积变大 / ✗ 3σ 数字记成 0.68/0.95/0.99 就够 / ✗ 求单侧概率忘记除以 2 / ✗ μ 与 σ 位置写反 / ✗ 认为正态分布一定能算精确值（要用查表/近似）。

## xx3-c3-s1 成对数据的统计相关性

**课本原话**
1. 散点图中点的分布如果从左下角到右上角，说明两个变量正相关；从左上角到右下角为负相关。
2. 样本相关系数 r=Σ(xᵢ−x̄)(yᵢ−ȳ)/√[Σ(xᵢ−x̄)²·Σ(yᵢ−ȳ)²]，且 −1≤r≤1。
3. |r| 越接近 1，线性相关程度越强；r>0 正相关，r<0 负相关。

**三个扣分点**：**相关不等于因果**；r 只衡量**线性**相关（曲线关系 r 可能接近 0）；r 无单位、范围 [−1,1]。

**四张图**：① 散点图与正/负相关；② r 从 −1 到 1 的点云变化（一条线 → 一团雾）；③ 曲线关系但 r≈0（相关≠线性相关）；④ r² 的意义（决定系数）。

**互动模型**：滑块＝相关系数 r（−1 到 1，step 0.1），用固定伪随机序列生成 24 个点
```js
// y = r·x + √(1−r²)·noise，noise 由固定种子生成，保证同一 r 每次一样
r2 = r * r;                      // 决定系数
dir = r > 0.05 ? 1 : r < -0.05 ? -1 : 0;
```
`cases`：`{v:0.8,eq:{r2:0.64,dir:1}}`、`{v:0,eq:{r2:0,dir:0}}`、`{v:-0.9,eq:{r2:0.81,dir:-1}}`。
Autopilot：`[{t:0,v:-1},{t:1.2,v:-1},{t:4,v:0.8},{t:6.5,v:0.8},{t:9,v:0},{t:11.5,v:0.5},{t:13.5,v:-1}]`，keys `[-1,0,0.8,1]`。
**停留帧在 r=0.8**（点云收得很紧，r²=0.64 说明 64% 的波动能被线性解释）。
状态：r>0「正相关」；r=0「看不出线性关系」；r<0「负相关」。

**例题**：「已知 5 组数据算得 r=0.98，说明什么？」答案：|r|=0.98 很接近 1，说明两变量有很强的**正线性相关**；但相关不等于因果，也不能据此断定 x 变化导致 y 变化。
**六问**：① r=0.9 说明因果吗；② r 能大于 1 吗；③ 曲线关系 r 会怎样；④ r 与 r² 的关系；⑤ r 正负说明什么；⑥ 样本太小 r 可靠吗。
**易错**：✗ 相关当因果 / ✗ 认为 r 越大越「准」 / ✗ 曲线关系用 r 判断 / ✗ r 有单位 / ✗ r² 与 r 混淆 / ✗ 离群点不影响 r。

## xx3-c3-s2 一元线性回归模型及其应用

**课本原话**
1. 经验回归方程 ŷ=b̂x+â，其中 b̂=Σ(xᵢ−x̄)(yᵢ−ȳ)/Σ(xᵢ−x̄)²，â=ȳ−b̂x̄。
2. 残差 eᵢ=yᵢ−ŷᵢ，残差平方和 Q=Σ(yᵢ−ŷᵢ)² 越小，拟合效果越好。
3. 经验回归直线一定过样本中心点 (x̄,ȳ)。

**三个扣分点**：**回归直线必过样本中心**；b̂ 的分子是「叉积和」不是「x 的和乘 y 的和」；残差是 y−ŷ（观测减预测）。

**四张图**：① 散点与拟合直线；② 残差是竖直的小竖线；③ Q 随 b 变化的抛物线（最低点就是 b̂）；④ 预测与「内插可信、外推危险」。

**互动模型**：滑块＝斜率 b（0.5 到 2.5，step 0.1），数据 (1,2)(2,3)(3,5)(4,6)(5,8)，截距固定 â=0.3
```js
// Q(b) = Σ(yᵢ − (0.3 + b·xᵢ))²
q = Σ (y - 0.3 - b*x)²;      // 残差平方和
// 最小值在 b=1.5 处，Q=0.3
```
`cases`：`{v:0.5,eq:{q:55.3}}`、`{v:1.5,eq:{q:0.3}}`、`{v:2.5,eq:{q:55.3}}`。
Autopilot：`[{t:0,v:0.5},{t:1.2,v:0.5},{t:4,v:1.5},{t:6.5,v:1.5},{t:9,v:2.5},{t:11.5,v:1},{t:13.5,v:0.5}]`，keys `[0.5,1,1.5,2.5]`。
**停留帧在 b=1.5**（Q 降到 0.3 的最小值，此时直线穿得最正中）。
状态：b 偏离 1.5「残差平方和变大」；b=1.5「Q 最小，这就是最小二乘」。

**例题**：「由数据 (1,2)(2,3)(3,5)(4,6)(5,8) 求经验回归方程。」答案：x̄=3、ȳ=4.8，Σ(xᵢ−x̄)(yᵢ−ȳ)=15，Σ(xᵢ−x̄)²=10，b̂=1.5，â=4.8−1.5×3=0.3，故 ŷ=1.5x+0.3。
**六问**：① 回归直线为什么过 (x̄,ȳ)；② 残差是观测减预测还是反过来；③ Q 最小意味着什么；④ 外推为什么危险；⑤ b̂ 的分子是什么；⑥ 相关系数与回归斜率的关系。
**易错**：✗ 回归直线不过样本中心 / ✗ 残差写成 ŷ−y / ✗ 把 b̂ 的分子算成 ΣxΣy / ✗ 外推太远还当准确值 / ✗ â 也算错方向 / ✗ 认为 Q=0 一定拟合好（可能是过拟合）。

## xx3-c3-s3 列联表与独立性检验

**课本原话**
1. 2×2 列联表把两个分类变量交叉计数。
2. χ²=n(ad−bc)²/[(a+b)(c+d)(a+c)(b+d)]。
3. 判断规则：若 χ²≥3.841，则有 95% 的把握认为两个变量有关联；χ²≥6.635 时有 99% 的把握；否则不能作出这样的判断（不是「没有关系」）。

**三个扣分点**：结论是「有 95% 把握认为有关联」而**不是**「两个变量一定有关」；χ² 小只能说「没有充分证据」，不能反过来说「无关」；公式里 n 是**总人数**。

**四张图**：① 2×2 列联表的结构（a b / c d）；② χ² 公式与各字母含义；③ 临界值表（3.841 / 6.635）；④ 三类结论的标准写法。

**互动模型**：滑块＝甲组有效人数 a（0 到 100，step 5），总计 200：甲组 100 人（a 有效、100−a 无效），乙组 100 人（60 有效、40 无效）
```js
b = 100 - a; c = 60; d = 40; n = 200;
chi = n * Math.pow(a * d - b * c, 2) / ((a + b) * (c + d) * (a + c) * (b + d));
sig = chi >= 3.841 ? 1 : 0;
```
`cases`：`{v:60,eq:{chi:0,sig:0}}`、`{v:75,eq:{chi:5.1282,sig:1}}`、`{v:90,eq:{chi:24,sig:1}}`。
Autopilot：`[{t:0,v:60},{t:1.2,v:60},{t:4,v:75},{t:6.5,v:75},{t:9,v:90},{t:11.5,v:70},{t:13.5,v:60}]`，keys `[60,70,75,90]`。
**停留帧在 a=75**（χ²=5.13 刚越过 3.841，判定「有 95% 把握认为有关联」——临界帧）。
状态：χ²<3.841「没有充分证据」；≥3.841「有 95% 把握有关联」；≥6.635「有 99% 把握」。

**例题**：「某调查：甲组 100 人中 75 人有效、25 人无效；乙组 100 人中 60 人有效、40 人无效。判断有效率与分组是否有关联。」答案：a=75、b=25、c=60、d=40、n=200，ad−bc=3000−1500=1500，χ²=200×1500²/(100×100×135×65)=450000000/87750000≈5.128>3.841，故有 95% 的把握认为有关联。
**六问**：① 结论能不能说「一定有关」；② χ² 小是什么意思；③ 公式里 n 是谁；④ 3.841 与 6.635 分别对应多少把握；⑤ 列联表与条形图的关系；⑥ 样本量变大 χ² 会怎样。
**易错**：✗ 结论写「两个变量有关」 / ✗ 说「没有关系」 / ✗ n 用错成一组人数 / ✗ 忘记平方 / ✗ 临界值记反 / ✗ 样本太小时勉强下结论。
