## xx1-c1-s1 空间向量及其运算

**课本原话**
1. 与平面向量一样，空间向量也是既有大小又有方向的量，记作 a 或 AB。
2. 空间向量的加法、减法、数乘与平面向量完全相同（三角形法则、平行四边形法则）。
3. 数量积：a·b=|a||b|cos⟨a,b⟩。

**三个扣分点**：a·b 是**数**不是向量（写成 6 而不是 6e）；|a+b| 要用平方展开（不能直接 |a|+|b|）；夹角范围是 [0,π]。

**四张图**：① 三角形法则与平行四边形法则（空间中三个向量）；② 数乘：方向共线、长度缩放；③ 数量积的几何意义（投影）；④ |a±b|² 的展开与三个量（|a|、|b|、cosθ）的关系。

**互动模型**：滑块＝夹角 θ（0–180°，step 15°），|a|=2，|b|=3
```js
dot  = 6 * Math.cos(θ * Math.PI / 180);          // a·b
sum2 = 13 + 2 * dot;                             // |a+b|²  = 4+9+2·a·b
dif2 = 13 - 2 * dot;                             // |a−b|²
```
`cases`：`{v:0,eq:{dot:6,sum2:25}}`、`{v:90,eq:{dot:0,sum2:13}}`、`{v:180,eq:{dot:-6,sum2:1}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:90},{t:6.5,v:90},{t:9,v:180},{t:11.5,v:120},{t:13.5,v:0}]`，keys `[0,90,180]`。
**停留帧在 90°**（a·b=0，两向量垂直，此时 |a+b| 最小）。
状态：θ<90「a·b>0」；θ=90「a·b=0，垂直」；θ>90「a·b<0」。

**例题**：「已知 |a|=2，|b|=3，⟨a,b⟩=60°，求 |a+b| 与 |a−b|。」答案：|a+b|²=4+9+2×2×3×0.5=25，|a+b|=5；|a−b|²=4+9−6=7，|a−b|=√7。
**六问**：① a·b 是向量还是数；② |a+b| 能直接相加吗；③ 夹角范围；④ a·b=0 说明什么；⑤ (a+b)·c 能拆开吗；⑥ 空间向量与平面向量的运算有区别吗。
**易错**：✗ 把 a·b 写成向量 / ✗ |a+b|=|a|+|b| / ✗ 夹角取到 360° / ✗ a·b=0 就说 a、b 中有一个是零向量 / ✗ 数乘写成点乘 / ✗ 忘记夹角要共起点。

## xx1-c1-s2 空间向量基本定理

**课本原话**
1. 如果三个向量 a、b、c 不共面，那么对任意一个空间向量 p，存在唯一的有序实数组 (x,y,z)，使 p=xa+yb+zc。
2. a、b、c 叫做空间的一个基底，它们都是基向量。
3. 任意三个不共面的向量都可以构成空间的一个基底。

**三个扣分点**：基底必须**不共面**（共面的三个向量不能作基底）；分解是**唯一**的；p 落在 a、b 张成的平面内时 z=0（此时只需两个基向量）。

**四张图**：① 三个不共面的基向量；② p 的分解（平行四边形叠加）；③ 共面的三个向量为什么不能作基底；④ z=0 时 p 落在平面内。

**互动模型**：滑块＝分解系数 z（−2 到 2，step 0.5），p=xa+yb+zc，取 x=1、y=2
```js
inPlane = z === 0 ? 1 : 0;     // z=0 时 p 落在 a、b 张成的平面内
coef    = [1, 2, z];           // 唯一的有序实数组
```
`cases`：`{v:0,eq:{inPlane:1}}`、`{v:1,eq:{inPlane:0}}`、`{v:-2,eq:{inPlane:0}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:1},{t:6.5,v:1},{t:9,v:-2},{t:11.5,v:2},{t:13.5,v:0}]`，keys `[0,1,-2,2]`。
**停留帧在 z=0**（p 恰好落在平面内，两个基向量就够，第三个系数是 0）。
状态：z=0「p 与 a、b 共面，基底退化成两个」；z≠0「必须用满三个基向量」。

**例题**：「已知 {a,b,c} 是基底，p=a+2b+zc，若 p 与 a、b 共面，求 z。」答案：共面意味着 c 的系数为 0，故 z=0；反过来若 z≠0，p 就不在 a、b 张成的平面内。
**六问**：① 基底需要几个向量；② 共面的三个向量能作基底吗；③ 分解为什么唯一；④ z=0 意味着什么；⑤ 零向量能作基向量吗；⑥ 基底换了，坐标会变吗。
**易错**：✗ 任意三个向量都能作基底 / ✗ 分解不唯一 / ✗ z=0 时还写「三个基向量」 / ✗ 零向量当基向量 / ✗ 基向量必须是单位向量 / ✗ 换了基底坐标不变。

## xx1-c1-s3 空间向量及其运算的坐标表示

**课本原话**
1. 若 a=(x₁,y₁,z₁)，b=(x₂,y₂,z₂)，则 a+b=(x₁+x₂, y₁+y₂, z₁+z₂)。
2. 数量积的坐标表示：a·b=x₁x₂+y₁y₂+z₁z₂。
3. a⊥b ⇔ x₁x₂+y₁y₂+z₁z₂=0；a∥b ⇔ x₁=x₂λ，y₁=y₂λ，z₁=z₂λ。

**三个扣分点**：垂直用**数量积为 0**、平行用**成比例**，两者不能混；模是 √(x²+y²+z²) 三项不是两项；平行要检验三个分量（含 z）。

**四张图**：① 空间直角坐标系的三个轴与点的坐标；② 坐标运算表（加、减、数乘、数量积）；③ 垂直与平行的判定对照；④ 模与夹角的坐标公式。

**互动模型**：滑块＝b 的横坐标 t（−2 到 2，step 0.5），a=(1,1,0)，b=(t,0,1)
```js
dot  = t;                                  // a·b = x₁x₂+y₁y₂+z₁z₂
perp = t === 0 ? 1 : 0;                    // 垂直 ⇔ 数量积为 0
absB = Math.sqrt(t * t + 1);
cos  = t / (Math.SQRT2 * absB);            // 夹角余弦
```
`cases`：`{v:0,eq:{dot:0,perp:1}}`、`{v:1,eq:{dot:1,perp:0}}`、`{v:-2,eq:{dot:-2,perp:0}}`。
Autopilot：`[{t:0,v:-2},{t:1.2,v:-2},{t:4,v:0},{t:6.5,v:0},{t:9,v:2},{t:11.5,v:1},{t:13.5,v:-2}]`，keys `[-2,0,1,2]`。
**停留帧在 t=0**（数量积为 0，两向量垂直，最容易被漏掉的判别）。
状态：t=0「垂直（数量积为 0）」；t≠0「不垂直，数量积不为 0」。

**例题**：「a=(1,1,0)，b=(t,0,1)，若 a⊥b 求 t；若 a∥b 求 t。」答案：垂直要求 t=0；平行要求 (1,1,0)=λ(t,0,1)，由 z 分量 0=λ 得 λ=0，与 x 分量 1=λt 矛盾，故**不存在**这样的 t。
**六问**：① 垂直与平行分别用什么判据；② 模是几项的平方和；③ 两个向量平行能不能只看 x、y；④ 数量积为 0 一定垂直吗（零向量）；⑤ 夹角公式的分母是什么；⑥ 空间坐标与平面坐标的差别。
**易错**：✗ 平行用数量积为 0 / ✗ 垂直只比前两个分量 / ✗ 模写成两项 / ✗ 平行不看 z 分量 / ✗ 零向量与任何向量都「垂直」（定义上不算）/ ✗ 夹角公式漏绝对值。

## xx1-c1-s4 空间向量的应用

**课本原话**
1. 直线 l 的方向向量为 u，平面 α 的法向量为 n，则 l⊥α ⇔ u∥n，l∥α ⇔ u·n=0。
2. 点 P 到平面 α 的距离 d=|AP·n|/|n|（A 为平面内任一点）。
3. 用向量求角：线线角、线面角、二面角都归结为两个向量的夹角或其补角。

**三个扣分点**：**线面角 = 90° − 方向向量与法向量的夹角**（最容易直接写错）；点到平面距离要**取绝对值再除以 |n|**；二面角要看是锐角还是钝角。

**四张图**：① 方向向量与法向量；② 线面角的转化（夹角与 90°−夹角）；③ 点到平面距离的投影公式；④ 二面角与两法向量夹角的关系。

**互动模型**：滑块＝点 P 的纵坐标 t（−3 到 3，step 0.5），平面 x+y+z=0，P(1,t,2)
```js
d = Math.abs(3 + t) / Math.sqrt(3);        // 距离 = |AP·n|/|n|，n=(1,1,1)
onPlane = Math.abs(3 + t) < 1e-9 ? 1 : 0;  // t=−3 时点在平面上
```
`cases`：`{v:0,eq:{d:1.7321}}`、`{v:3,eq:{d:3.4641}}`、`{v:-3,eq:{d:0,onPlane:1}}`。
Autopilot：`[{t:0,v:3},{t:1.2,v:3},{t:4,v:0},{t:6.5,v:0},{t:9,v:-3},{t:11.5,v:-3},{t:13.5,v:3}]`，keys `[3,0,-3]`。
**停留帧在 t=−3**（P 恰好落在平面上，距离为 0，公式给出 0 说明代入正确）。
状态：d>0「点在平面外」；d=0「点在平面内」。

**例题**：「求点 P(1,0,2) 到平面 x+y+z=0 的距离。」答案：取平面内点 A(0,0,0)，AP=(1,0,2)，n=(1,1,1)，AP·n=3，|n|=√3，d=3/√3=√3。
**六问**：① 线面角与两向量夹角是什么关系；② 距离公式为什么要加绝对值；③ 法向量怎么求；④ 二面角什么时候取补角；⑤ n 可以取任意倍数吗；⑥ 线面平行怎么用向量判。
**易错**：✗ 直接把方向向量与法向量夹角当线面角 / ✗ 距离不取绝对值 / ✗ 法向量不验证是否垂直平面内两条相交直线 / ✗ 二面角一律取锐角 / ✗ 分母写成 |n|² / ✗ 平面内取的点不同结果不同（其实相同）。

## xx1-c2-s1 直线的倾斜角与斜率

**课本原话**
1. 直线向上的方向与 x 轴正方向所成的最小正角 α 叫做倾斜角，范围是 0°≤α<180°。
2. 倾斜角 α≠90° 时，k=tanα 叫做直线的斜率。
3. 经过两点 P₁(x₁,y₁)、P₂(x₂,y₂)（x₁≠x₂）的斜率 k=(y₂−y₁)/(x₂−x₁)。

**三个扣分点**：倾斜角范围是 [0°,180°)（**不含 180°**）；α=90° 时斜率**不存在**（不是 0）；由 tanα 求 α 要按象限取舍。

**四张图**：① 倾斜角的定义与范围；② 斜率随倾斜角变化的图象（tan 曲线的一段）；③ α=90° 时斜率不存在；④ 两点式斜率与 Δy/Δx。

**互动模型**：滑块＝倾斜角 α（0–180°，step 5°）
```js
k    = α === 90 ? null : Math.tan(α * Math.PI / 180);
ok   = α === 90 ? 0 : 1;            // 斜率是否存在
```
`cases`：`{v:45,eq:{k:1,ok:1}}`、`{v:135,eq:{k:-1,ok:1}}`、`{v:90,eq:{ok:0}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:45},{t:6.5,v:45},{t:9,v:90},{t:11.5,v:135},{t:13.5,v:0}]`，keys `[0,45,90,135]`。
**停留帧在 90°**（竖直线，斜率不存在——最容易被学生写成 0 的一格）。
状态：0<α<90「k>0，上升」；α=90「斜率不存在」；90<α<180「k<0，下降」；α=0「k=0，水平」。

**例题**：「经过 A(1,2)、B(3,6) 的直线，求倾斜角。」答案：k=(6−2)/(3−1)=2，由 tanα=2 且 α∈[0°,180°) 得 α=arctan2≈63.4°。
**六问**：① 倾斜角能等于 180° 吗；② 竖直线的斜率是多少；③ 斜率相同两直线什么关系；④ 由 k 求 α 要注意什么；⑤ 水平线倾斜角是多少；⑥ 两点式斜率的分母能为 0 吗。
**易错**：✗ 倾斜角取到 180° / ✗ 竖直线斜率写成 0 / ✗ tanα 求 α 不判象限 / ✗ 斜率不存在与斜率为 0 混 / ✗ 两点式分子分母反了 / ✗ 认为所有直线都有斜率。

## xx1-c2-s2 直线的方程

**课本原话**
1. 点斜式：y−y₀=k(x−x₀)。
2. 斜截式：y=kx+b（b 为纵截距）。
3. 一般式：Ax+By+C=0（A、B 不同时为 0）。

**三个扣分点**：点斜式不能表示竖直线（x=x₀）；斜截式的 b 是**纵截距**不是距离（可为负）；截距式要求两个截距都不为 0。

**四张图**：① 点斜式的几何含义；② 斜截式的 b 与直线的位置（b 正负）；③ 几种形式的适用范围对照表；④ 一般式与斜截式的互化。

**互动模型**：滑块＝纵截距 b（−4 到 4，step 1），直线 y=2x+b
```js
x0 = -b / 2;                 // 与 x 轴交点
y0 = b;                      // 与 y 轴交点
quad = b > 0 ? 123 : b === 0 ? 13 : 134;   // 经过的象限（数字串）
```
`cases`：`{v:-2,eq:{x0:1,y0:-2}}`、`{v:0,eq:{x0:0,y0:0}}`、`{v:4,eq:{x0:-2,y0:4}}`。
Autopilot：`[{t:0,v:-4},{t:1.2,v:-4},{t:4,v:0},{t:6.5,v:0},{t:9,v:4},{t:11.5,v:2},{t:13.5,v:-4}]`，keys `[-4,0,2,4]`。
**停留帧在 b=0**（直线过原点，最特殊的位置，也是截距式失效的那一格）。
状态：b>0「过第一、二、三象限」；b=0「过原点」；b<0「过第一、三、四象限」。

**例题**：「求过点 (1,2) 且斜率为 −3 的直线方程，并化成一般式。」答案：y−2=−3(x−1)，即 3x+y−5=0。
**六问**：① 点斜式能表示竖直线吗；② 纵截距 b 能为负吗；③ 截距式的适用条件；④ 一般式有什么好处；⑤ 斜截式的 b 与「截距」是距离吗；⑥ 两点式与点斜式的关系。
**易错**：✗ 点斜式写竖直线 / ✗ 截距当成距离取绝对值 / ✗ 截距式不管是否为 0 / ✗ 一般式 A、B 同时为 0 / ✗ 化一般式不整理 / ✗ 斜截式与点斜式混用。

## xx1-c2-s3 直线的交点坐标与距离公式

**课本原话**
1. 两点间距离：|P₁P₂|=√((x₂−x₁)²+(y₂−y₁)²)。
2. 点 P(x₀,y₀) 到直线 Ax+By+C=0 的距离 d=|Ax₀+By₀+C|/√(A²+B²)。
3. 两条平行线 Ax+By+C₁=0 与 Ax+By+C₂=0 的距离 d=|C₁−C₂|/√(A²+B²)。

**三个扣分点**：点到直线距离的**分子要加绝对值**；用公式前直线必须是**一般式**（y=kx+b 要先移项）；两平行线的 A、B 必须**化成相同**。

**四张图**：① 两点间距离；② 点到直线的垂线段；③ 两平行线间的距离（要求 A、B 相同）；④ 三条距离公式的对照。

**互动模型**：滑块＝点 P 的横坐标 t（−4 到 6，step 0.5），P(t,0)，直线 3x+4y−10=0
```js
d = Math.abs(3 * t - 10) / 5;      // |3t+4·0−10| / √(9+16)
onLine = Math.abs(3 * t - 10) < 1e-9 ? 1 : 0;
```
`cases`：`{v:0,eq:{d:2}}`、`{v:2,eq:{d:0.8}}`、`{v:5,eq:{d:1}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:2},{t:6.5,v:2},{t:9,v:5},{t:11.5,v:3.333},{t:13.5,v:0}]`，keys `[0,2,5]`（另含 t=10/3 处距离为 0）。
**停留帧在 t=10/3≈3.33**（点正好落在直线上，距离降到 0）。
状态：d>0「点在直线外」；d=0「点在直线上」。

**例题**：「求点 P(2,0) 到直线 3x+4y−10=0 的距离。」答案：d=|3×2+4×0−10|/√(9+16)=4/5=0.8。
**六问**：① 公式对直线形式有要求吗；② 绝对值可以省吗；③ 两平行线距离为什么要求 A、B 相同；④ 分母为什么是 √(A²+B²)；⑤ 点代入后为 0 说明什么；⑥ 两条相交直线的距离是多少。
**易错**：✗ 用斜截式直接代公式 / ✗ 忘记绝对值 / ✗ 平行线不统一 A、B / ✗ 分母写成 A²+B² / ✗ 把交点距离公式与点到直线混 / ✗ 直线过原点时 C=0 就不写。

## xx1-c2-s4 圆的方程

**课本原话**
1. 圆的标准方程：(x−a)²+(y−b)²=r²，圆心 (a,b)，半径 r。
2. 圆的一般方程：x²+y²+Dx+Ey+F=0，当 D²+E²−4F>0 时表示圆。
3. 一般方程配方后圆心 (−D/2,−E/2)，半径 r=½√(D²+E²−4F)。

**三个扣分点**：一般方程要**先判 D²+E²−4F>0** 才是圆；标准方程里是 (x−a) 不是 (x+a)；半径要开方后除以 2。

**四张图**：① 标准方程的圆心与半径；② 一般方程配方过程；③ 判别式三种情况（圆、点、无轨迹）；④ 求圆方程的两种方法（待定系数、几何法）。

**互动模型**：滑块＝半径 r（0.5 到 5，step 0.5），圆心固定 (1,2)
```js
n = r < 2 ? 0 : r === 2 ? 1 : 2;    // 与 x 轴的交点个数（圆心纵坐标 2）
disc = r * r - 4;                   // 与 x 轴相交的判别量
```
`cases`：`{v:1,eq:{n:0,disc:-3}}`、`{v:2,eq:{n:1,disc:0}}`、`{v:3,eq:{n:2,disc:5}}`。
Autopilot：`[{t:0,v:3},{t:1.2,v:3},{t:4,v:2},{t:6.5,v:2},{t:9,v:1},{t:11.5,v:4},{t:13.5,v:3}]`，keys `[1,2,3,4]`。
**停留帧在 r=2**（圆与 x 轴相切，交点从 2 个变成 0 个的分界）。
状态：r<2「与 x 轴相离」；r=2「相切」；r>2「相交于两点」。

**例题**：「求过三点 O(0,0)、A(1,1)、B(4,2) 的圆的方程。」答案：设 x²+y²+Dx+Ey+F=0，代入三点得 F=0、D+E=−2、4D+2E=−20，解得 D=−8、E=6，圆的方程为 x²+y²−8x+6y=0，圆心 (4,−3)，半径 5。
**六问**：① 一般方程一定是圆吗；② 标准方程里圆心符号怎么读；③ 判别式等于 0 是什么图形；④ 半径公式里的 ½ 从哪来；⑤ 求圆方程有几种方法；⑥ 圆心在原点时方程长什么样。
**易错**：✗ 一般方程直接当圆 / ✗ 圆心写成 (D,E) / ✗ 半径忘记开方 / ✗ 标准方程符号读反 / ✗ 判别式算成 D²+E²−F / ✗ 三个点求不出圆（其实一定能，除非共线）。

## xx1-c2-s5 直线与圆、圆与圆的位置关系

**课本原话**
1. 直线与圆：圆心到直线的距离 d 与半径 r 比较，d<r 相交、d=r 相切、d>r 相离。
2. 圆与圆：圆心距 d 与 r₁+r₂、|r₁−r₂| 比较，判断外离、外切、相交、内切、内含。
3. 弦长公式：l=2√(r²−d²)。

**三个扣分点**：直线与圆用**圆心距**比较，不是把直线方程代进去乱算；圆与圆要考虑**|r₁−r₂|**这一侧；弦长公式里 d 是**圆心到直线**的距离。

**四张图**：① 直线与圆的三种位置（d 与 r）；② 圆与圆的五种位置（d 与 r₁±r₂）；③ 弦长、半弦、半径的直角三角形；④ 判定流程（先算 d，再比较）。

**互动模型**：滑块＝圆心到直线的距离 d（0 到 8，step 0.5），圆半径 r=5
```js
chord = d <= 5 ? 2 * Math.sqrt(25 - d * d) : 0;    // 弦长
state = d < 5 ? 0 : d === 5 ? 1 : 2;               // 0 相交 1 相切 2 相离
```
`cases`：`{v:0,eq:{chord:10,state:0}}`、`{v:3,eq:{chord:8,state:0}}`、`{v:5,eq:{chord:0,state:1}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:3},{t:6.5,v:3},{t:9,v:5},{t:11.5,v:7},{t:13.5,v:0}]`，keys `[0,3,5,7]`。
**停留帧在 d=3**（弦长 8，3-4-5 直角三角形，最好算也最容易记错公式的一格）。
状态：d<5「相交，弦长 2√(25−d²)」；d=5「相切，弦长 0」；d>5「相离，没有公共点」。

**例题**：「圆 x²+y²=25，直线 3x+4y−15=0，求弦长。」答案：圆心到直线距离 d=|−15|/5=3，弦长 2√(25−9)=8。
**六问**：① 直线与圆用什么量判断；② 圆与圆要比较几个量；③ 弦长公式里的 d 是什么；④ 相切时弦长是多少；⑤ 内含与内切的区别；⑥ 用代数法（判别式）判断可以吗。
**易错**：✗ 圆与圆只比 r₁+r₂ / ✗ 弦长直接用 r²−d² 不开方 / ✗ d 算成圆心到弦端点的距离 / ✗ 内含与内切混 / ✗ 相切时仍写两个交点 / ✗ 判别式法漏算二次项系数。

## xx1-c3-s1 椭圆

**课本原话**
1. 平面内与两个定点 F₁、F₂ 的距离之和等于常数（大于 |F₁F₂|）的点的轨迹叫做椭圆。
2. 标准方程 x²/a²+y²/b²=1（a>b>0），且 c²=a²−b²。
3. 离心率 e=c/a，0<e<1；e 越接近 1 越扁，越接近 0 越圆。

**三个扣分点**：2a 必须**大于** |F₁F₂|（否则不是椭圆）；a²=b²+c² 里 a 最大（别记成 c²=a²+b²）；离心率 e 的范围是 (0,1)。

**四张图**：① 椭圆的定义（绳子和两个焦点）；② 三个参数 a、b、c 的直角三角形；③ 离心率对形状的影响（一组椭圆）；④ 焦点在 x 轴与 y 轴的两种标准方程。

**互动模型**：滑块＝短半轴 b（1 到 4.5，step 0.5），长半轴 a=5 固定
```js
c = Math.sqrt(25 - b * b);      // c² = a² − b²
e = c / 5;                      // 离心率
```
`cases`：`{v:3,eq:{c:4,e:0.8}}`、`{v:4,eq:{c:3,e:0.6}}`、`{v:4.5,eq:{c:2.1794,e:0.4359}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:4},{t:6.5,v:4},{t:9,v:4.5},{t:11.5,v:2.5},{t:13.5,v:1}]`，keys `[1,2.5,4,4.5]`。
**停留帧在 b=4.5**（b 逼近 a，椭圆越来越圆，离心率趋近 0）。
状态：b 越小「e 越大，越扁」；b→a「e→0，越接近圆」。

**例题**：「椭圆 x²/25+y²/9=1，求焦点坐标、离心率。」答案：a=5，b=3，c=√(25−9)=4，焦点 (±4,0)，e=4/5。
**六问**：① 2a 为什么要大于焦距；② a、b、c 谁最大；③ 离心率范围；④ 焦点在 y 轴时方程怎么写；⑤ e 越大越扁还是越圆；⑥ 椭圆上点到两焦点距离之和是多少。
**易错**：✗ c²=a²+b² / ✗ 2a 可以小于焦距 / ✗ e 取到 1 / ✗ 焦点坐标写反 / ✗ a 与 b 大小不分 / ✗ 把 e 写成 b/a。

## xx1-c3-s2 双曲线

**课本原话**
1. 平面内与两个定点 F₁、F₂ 的距离之差的绝对值等于常数（小于 |F₁F₂| 且大于 0）的点的轨迹叫做双曲线。
2. 标准方程 x²/a²−y²/b²=1，且 c²=a²+b²。
3. 渐近线 y=±(b/a)x；离心率 e=c/a>1。

**三个扣分点**：这里是 c²=a²+**b²**（与椭圆相反，最容易记混）；必须加**绝对值**（否则只是一支）；渐近线是 y=±(b/a)x，注意 b 在分子。

**四张图**：① 双曲线的两支与定义（差的绝对值）；② a、b、c 的关系（c 最大）；③ 渐近线与开口；④ 椭圆与双曲线的 a、b、c 对照表。

**互动模型**：滑块＝虚半轴 b（1 到 4，step 0.5），实半轴 a=3 固定
```js
c = Math.sqrt(9 + b * b);      // c² = a² + b²
e = c / 3;                     // 离心率 >1
k = b / 3;                     // 渐近线斜率
```
`cases`：`{v:1,eq:{c:3.1623,e:1.0541}}`、`{v:3,eq:{c:4.2426,e:1.4142}}`、`{v:4,eq:{c:5,e:1.6667}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:3},{t:6.5,v:3},{t:9,v:4},{t:11.5,v:2},{t:13.5,v:1}]`，keys `[1,2,3,4]`。
**停留帧在 b=3**（渐近线斜率恰好为 1，等轴双曲线附近，最容易被问的一格）。
状态：b 越大「渐近线越陡，开口越开」；e 恒 >1。

**例题**：「双曲线 x²/9−y²/16=1，求 c、离心率与渐近线。」答案：a=3，b=4，c=√(9+16)=5，e=5/3，渐近线 y=±(4/3)x。
**六问**：① c² 与 a²、b² 的关系；② 为什么要加绝对值；③ 渐近线斜率是多少；④ e 的范围；⑤ 双曲线与椭圆的 a、b、c 有什么不同；⑥ 焦点在 y 轴时方程怎么写。
**易错**：✗ c²=a²−b²（记成椭圆）/ ✗ 不加绝对值只取一支 / ✗ 渐近线写成 y=±(a/b)x / ✗ e 小于 1 / ✗ 焦点坐标算错 / ✗ a、b 谁大不确定时乱设。

## xx1-c3-s3 抛物线

**课本原话**
1. 平面内与一个定点 F 和一条定直线 l（F∉l）距离相等的点的轨迹叫做抛物线。
2. 标准方程 y²=2px（p>0），焦点 (p/2,0)，准线 x=−p/2。
3. 焦半径：抛物线 y²=2px 上一点 P(x₀,y₀)，则 |PF|=x₀+p/2。

**三个扣分点**：焦点是 (p/2,0) 不是 (p,0)；准线是 x=−p/2 要带负号；2p 是系数（y²=2px 里的 2p 不要读成 p）。

**四张图**：① 定义（到焦点与到准线等距）；② 焦点、准线、顶点；③ p 对开口的影响；④ 焦半径公式的几何来源。

**互动模型**：滑块＝参数 p（1 到 8，step 0.5），抛物线 y²=2px
```js
fx = p / 2;                    // 焦点横坐标
dir = -p / 2;                  // 准线
r1  = 1 + p / 2;               // 点 (1,y₀) 的焦半径 = x₀ + p/2
```
`cases`：`{v:2,eq:{fx:1,r1:2}}`、`{v:4,eq:{fx:2,r1:3}}`、`{v:8,eq:{fx:4,r1:5}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:4},{t:6.5,v:4},{t:9,v:8},{t:11.5,v:2},{t:13.5,v:1}]`，keys `[1,2,4,8]`。
**停留帧在 p=4**（焦点 (2,0)、准线 x=−2，焦半径 3，数字最干净的一格）。
状态：p 越大「开口越宽」；焦点与准线始终关于顶点对称。

**例题**：「抛物线 y²=8x 上一点 P 到焦点的距离为 5，求 P 的横坐标。」答案：2p=8，p=4，焦点 (2,0)，焦半径 |PF|=x₀+2=5，得 x₀=3。
**六问**：① 焦点坐标是什么；② 准线方程；③ 2p 与 p 的关系；④ 焦半径公式怎么来；⑤ p 越大开口越宽还是越窄；⑥ 抛物线有离心率吗。
**易错**：✗ 焦点写成 (p,0) / ✗ 准线漏负号 / ✗ 把 2p 当 p / ✗ 焦半径写成 x₀+p / ✗ 开口方向看错 / ✗ 认为抛物线没有离心率（e=1）。
