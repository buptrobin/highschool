这一节把空间向量从「画在图上」搬成「写成三数组」：建好空间直角坐标系，向量 a 就对应唯一的三元有序实数组 (x, y, z)，加法、减法、数乘、数量积全部变成对 x、y、z 的算术。它是本章后面用向量法证平行垂直、求空间角的全部工具。最容易错的一件事：把「垂直」和「平行」的判据混着用 —— 垂直看数量积是否为 0，平行看三个分量是否成比例，而模是三项平方和。

01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 空间向量的坐标运算人教A版选择性必修第一册 · 第一章 1.3

设 a=(x₁,y₁,z₁)，b=(x₂,y₂,z₂)，则 a+b=(x₁+x₂, y₁+y₂, z₁+z₂)，a−b=(x₁−x₂, y₁−y₂, z₁−z₂)，λa=(λx₁, λy₁, λz₁)。

→ 翻成人话：这句话由三个条件组成 —— ①先有一个空间直角坐标系 Oxyz，i、j、k 是两两垂直的单位向量；②向量 a 写成 x i + y j + z k，才记作 (x, y, z)；③加减数乘都是「同名分量对着算」。少掉 ①，坐标就没有意义；少掉 ③，就会出现 (x₁+y₂, …) 这种错位。

课本原话 · 数量积的坐标表示人教A版选择性必修第一册 · 第一章 1.3

已知 a=(x₁,y₁,z₁)，b=(x₂,y₂,z₂)，则 a·b=x₁x₂+y₁y₂+z₁z₂；|a|=√(x₁²+y₁²+z₁²)。

→ 翻成人话：数量积是「先对应相乘，再把三个积相加」，结果是一个实数，不是向量。三个积一个都不能少，z₁z₂ 这一项是空间区别于平面的地方；模是三项平方和再开方，同样少一项就错。

课本原话 · 平行与垂直的判定人教A版选择性必修第一册 · 第一章 1.3

设 a、b 为非零向量，则 a⊥b ⇔ x₁x₂+y₁y₂+z₁z₂=0；a∥b ⇔ x₁=λx₂，y₁=λy₂，z₁=λz₂（λ∈R）。

→ 翻成人话：两个判据各管一件事，垂直 ⇔ 数量积为 0，平行要三个分量成比例。垂直是「乘完加起来等于 0」，平行是「三个分量被同一个 λ 串起来」，不能互相替代；平行漏掉 z 分量，就等于默认所有向量都在同一个平面里。

要判断的正确判据漏一个分量会怎样
垂直 a⊥bx₁x₂+y₁y₂+z₁z₂=0（非零向量）只算 x₁x₂+y₁y₂，会把 z 方向上的「斜着垂直」判成不垂直
平行 a∥b三个分量成同一比例：x₁=λx₂，y₁=λy₂，z₁=λz₂只看 x、y，会漏掉 z 分量给出的 λ，把「方向根本不同」当成平行
模 |a|三项平方和再开方：√(x₁²+y₁²+z₁²)写成两项，相当于把空间向量压回平面，答案整体偏小
夹角 cos θa·b / (|a||b|)，分母是两个模的乘积分母只写 |a|，余弦值被放大，角度自然算错

背法：垂直 ⇔ 数量积为 0；平行要三个分量成比例；模是三项平方和。三句话各管一件事，考场上先问自己「这题判的是哪一件事」，再动笔。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。第（2）问藏着一个容易漏掉的分量。

例题 · 垂直与平行的坐标判定必考

已知空间向量 a=(1,1,0)，b=(t,0,1)，t∈R。（1）若 a⊥b，求 t；（2）若 a∥b，求 t。两问用的是同一条判据吗？

  1. 第 1 步 · 审题：两问判据不同

    （1）问垂直，用「数量积为 0」；（2）问平行，用「三个分量成比例」。先把 a、b 的三个分量对齐写出来：a=(1,1,0)，b=(t,0,1)，z 分量分别是 0 和 1，不能默认它不存在。

    用到：空间向量的坐标表示，三元有序实数组。

  2. 第 2 步 · 第（1）问：算数量积

    a·b=1·t+1·0+0·1=t。垂直要求 a·b=0，所以 t=0。

    用到：a·b=x₁x₂+y₁y₂+z₁z₂。

  3. 第 3 步 · 第（1）问：回代检验

    t=0 时 b=(0,0,1)，a·b=1·0+1·0+0·1=0，且 a、b 都是非零向量，所以 a⊥b 成立。答案：t=0。

    用到：垂直 ⇔ 数量积为 0（前提是非零向量）。

  4. 第 4 步 · 第（2）问：三个分量成比例

    若 a∥b，存在 λ 使 a=λb，即 1=λt，1=λ·0，0=λ·1。由 z 分量得 λ=0；把 λ=0 代回 x 分量，得 1=0，矛盾。

    用到：平行要三个分量成比例，λ 必须同时满足三式。

  5. 第 5 步 · 收尾：陷阱在 z 分量

    只比 x、y 的人会想：取 t=1、λ=1 好像让 x 分量成立，但 y 分量 1=λ·0 已经矛盾，z 分量 0=λ·1 又要求 λ=0。三个分量一起看，结论是：不存在这样的 t。

    用到：平行必须三个分量一起检验，z 分量不能省。

1 / 5

标准答案（可抄进答题卡）

（1）a⊥b ⇔ a·b=0。a·b=1·t+1·0+0·1=t，所以 t=0；此时 a、b 均为非零向量，垂直成立。
（2）若 a∥b，则存在实数 λ 使 a=λb，即 1=λt，1=λ·0，0=λ·1。由 z 分量得 λ=0，代入 x 分量得 1=0，矛盾，所以不存在实数 t 使 a∥b。
易错：第（2）问必须三个分量一起列式，只比 x、y 会漏掉 z 分量给出的 λ=0。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「垂直和平行到底分别用什么判据？」

垂直 ⇔ 数量积为 0：x₁x₂+y₁y₂+z₁z₂=0；平行要三个分量成比例：x₁=λx₂，y₁=λy₂，z₁=λz₂。一个算「乘完再相加」，一个看「三个比是否相等」，不能互换。

「模是几项的平方和？」

三项。模是三项平方和：|a|=√(x₁²+y₁²+z₁²)。空间向量有三个分量，平方和就有三项，根号里少写一项，等于把空间压回平面，数值一定偏小。

「两个向量平行，能不能只看 x、y 分量？」

不能。平行要三个分量成比例，z 分量同样给出同一个 λ。只看 x、y，会把「z 方向对不上」的两个向量误判成平行；正确做法是三式一起列，出现矛盾就说明不存在这样的 λ。

「数量积为 0，就一定垂直吗？」

要加前提：a、b 都是非零向量时，a·b=0 ⇔ a⊥b。零向量与任何向量的数量积都是 0，但零向量方向不确定，课本的垂直判定限定在非零向量上，答题时写出这一句才严密。

「夹角公式的分母到底是什么？」

是 |a|·|b|，两个模的乘积。分母漏一个模是高频错，会让余弦值整体偏大；另外 cos θ 的符号直接对应锐角、直角、钝角，算出负数不要急着取绝对值。

「空间坐标与平面坐标的差别在哪？」

只多一个 z 分量，但每一处都要补：点写成 (x,y,z)、模是三项平方和、平行要三个分量成比例、数量积多一项 z₁z₂。判据本身没变，变的是「项数」。

六问其实是同一件事：空间比平面多一个 z 分量 —— 数量积多一项、模多一项平方、平行多一个比例。判据一条都没变，变的是「别把第三项弄丢」。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 因为 a∥b，所以 a·b=0。

✓ 平行要三个分量成比例；垂直 ⇔ 数量积为 0。

错在哪：把两条判据对调了，平行与数量积没有直接关系。

✗ 判 a⊥b，只算 x₁x₂+y₁y₂=0 就够了。

✓ a⊥b ⇔ x₁x₂+y₁y₂+z₁z₂=0，三项相加。

错在哪：漏掉 z₁z₂，等于只在平面里判垂直。

✗ |a|=√(x₁²+y₁²)。

✓ 模是三项平方和：|a|=√(x₁²+y₁²+z₁²)。

错在哪：空间向量有三个分量，少一项结果偏小。

✗ 只要 x₁/x₂=y₁/y₂，两个向量就平行。

✓ 平行要三个分量成比例，还要 z₁=λz₂，且 λ 必须同时满足三式。

错在哪：z 分量可能给出矛盾的 λ，必须一起检验。

✗ 零向量与任何向量都垂直。

✓ 垂直判定要求 a、b 为非零向量。

错在哪：0·b=0 恒成立，但零向量方向任意，课本约定不讨论。

✗ cos θ = a·b / |a|。

✓ cos θ = a·b / (|a|·|b|)，分母是两个模的乘积。

错在哪：分母漏一个模，余弦值偏大，锐角钝角都会判错。

✗ 数量积 a·b 的结果是一个向量。

✓ 数量积的结果是实数，所以才能拿它和 0 比大小、判垂直。

错在哪：混淆向量与实数，垂直判据的「=0」就失去了依据。
