空间向量基本定理只讲一件事：三个不共面的向量能把任一空间向量 p 写成 唯一 的 x a + y b + z c；门槛是「不共面」，不是「有三个」。

上一节把平面向量基本定理搬进空间：平面上两个不共线向量就够用，空间里必须三个不共面向量。这一节的位置很关键——后面用坐标算空间向量、求法向量、建系，全靠「分解唯一」这四个字撑着，坐标才配叫坐标。最容易错的是把「三个向量」当成基底的充分条件：三个共面向量凑够数也不行。

01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 空间向量基本定理人教A版选择性必修第一册 · 第1章第2节

如果三个向量 a、b、c 不共面，那么对任意一个空间向量 p，存在唯一的有序实数组 (x,y,z)，使 p = x a + y b + z c。

→ 翻成人话：这句话由三个条件组成——① a、b、c 不共面；② p 是任意空间向量，不是某个特殊向量；③ 有序实数组 (x,y,z) 存在且唯一。缺①：三个向量压在同一张平面内，平面外的 p 根本分解不出来；缺③：同一个 p 能写出两组系数，坐标就没法定义了。

课本原话 · 基底与基向量人教A版选择性必修第一册 · 第1章第2节

a、b、c 叫做空间的一个基底，它们都是基向量。

→ 「一个基底」不是「唯一的基底」：任意三个不共面的向量都能当基底，所以空间有无穷多组基底；但一旦选定，分解就是唯一的。还要注意「基向量」不是「单位向量」，也不要求两两垂直、不要求长度相等。

课本原话 · 任意三个不共面的向量人教A版选择性必修第一册 · 第1章第2节

任意三个不共面的向量都可以构成空间的一个基底。

→ 判据只有一条：不共面。长短、夹角、方向全都随便。反过来说，只要三个向量共面（包括其中两个共线、或有一个是零向量），它们就张不出整个空间，不能作基底。

定理里的条件课本怎么写缺了会怎样
① 三个向量不共面「三个向量 a、b、c 不共面」只张成一张平面，平面外的 p 分解不出来，{a,b,c} 也不能叫基底
② p 是任意空间向量「对任意一个空间向量 p」若 p 本来就落在 a、b 张成的平面内，第三个系数 z 必为 0，c 白选
③ 存在且唯一「存在唯一的有序实数组 (x,y,z)」不唯一，就没法把 (x,y,z) 叫作 p 的坐标，建系、求法向量全部失效
隐含：基向量都非零「它们都是基向量」零向量与任何向量共面，夹了零向量的三个向量一定共面，作不了基底

给分句式背这两句：「因为 a、b、c 不共面，所以 {a,b,c} 是空间的一个基底」→「由空间向量基本定理，存在唯一的有序实数组 (x,y,z)，使 p=xa+yb+zc」。阅卷看的就是「不共面」和「唯一」两个词，只写结果不给分。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 共面条件反求系数必考

已知 {a,b,c} 是空间的一个基底，p = a + 2b + zc。
（1）若 p 与 a、b 共面，求 z 的值；
（2）反过来，若 z ≠ 0，p 与 a、b 还共面吗？说明理由。
陷阱：条件是「{a,b,c} 是基底」，不是「a、b、c 是三个向量」。

  1. 第 1 步 · 审题：先把「基底」翻译成条件

    {a,b,c} 是空间的一个基底 ⇒ a、b、c 不共面 ⇒ 由空间向量基本定理，任一空间向量关于这组基底的分解存在且唯一。

    用到：基底必须不共面；分解唯一。

  2. 第 2 步 · 把「共面」翻译成系数

    p 与 a、b 共面 ⇔ 存在实数 m、n，使 p = m a + n b（平面向量基本定理，a、b 不共线）。也就是说：p 的分解式里 c 的系数必须为 0。

    用到：共面 ⇔ 能用平面内两个不共线向量表示。

  3. 第 3 步 · 比系数，一次定值

    p = 1·a + 2·b + z·c 与 p = m·a + n·b + 0·c 是同一个 p 关于同一组基底的两种写法。由分解唯一，系数必须逐项相等：m=1，n=2，z=0。

    用到：分解唯一 ⇒ 系数对应相等（这是「比系数法」的合法性来源）。

  4. 第 4 步 · 反面追问：z≠0 呢

    若 z≠0，则 p − a − 2b = z·c ≠ 0，即 c = (1/z)(p − a − 2b)。一旦 p 落在 a、b 张成的平面内，c 也成了 a、b 的线性组合，三个向量就共面，与「{a,b,c} 是基底」矛盾。所以 z≠0 时 p 一定不在该平面内。

    用到：反证 + 基底必须不共面。

1 / 4

标准答案（可抄进答题卡）

（1）因为 {a,b,c} 是空间的一个基底，所以 a、b、c 不共面，任一空间向量关于它的分解唯一。又 p 与 a、b 共面，故存在实数 m、n 使 p = m a + n b，即 p = m a + n b + 0·c。与 p = a + 2b + z c 比较系数，由分解唯一得 z = 0。
（2）不共面。若 z ≠ 0，由 p = a + 2b + z c 得 c = (1/z)·p − (1/z)·a − (2/z)·b。若 p 与 a、b 共面，则 c 可写成 a、b 的线性组合，于是 a、b、c 共面，与 {a,b,c} 是基底矛盾。故 z ≠ 0 时 p 不在 a、b 张成的平面内，三个基向量都得用上。
答：z = 0。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「基底到底要几个向量？两个不行吗？」

空间的基底要 三个，而且必须不共面。平面是二维，两个不共线就够；空间多了一维，就得多一个把向量「挑出平面」的基向量。少一个只能张成平面或直线。

「我随手拿三个向量，只要数量够就能当基底吧？」

不能。三个向量共面就只张成一张平面，秩仍是 2，平面外的向量写不出来，共面的三个向量不能作基底。判断只看一条：不共面。

「凭什么说 (x,y,z) 唯一？换种凑法不行吗？」

反证：若 p = x a+y b+z c = x′a+y′b+z′c，相减得 (x−x′)a+(y−y′)b+(z−z′)c = 0。三个向量不共面，这个等式只可能三个系数全为 0，故 x=x′、y=y′、z=z′，分解唯一。

「算出 z=0，是不是说明 c 没用、基底只剩两个？」

不是。z=0 只说明 p 与 a、b 共面，p 这个向量用不到 c；{a,b,c} 仍然是空间的一个基底。只有当所有要研究的向量都落在同一张平面内时，才谈得上「基底退化成两个」。此时 p = 1a + 2b + 0·c。

「零向量也能算基向量吧，反正凑够三个了？」

不能。零向量与任何向量共面，三个向量里夹一个零向量必然共面，作不了基底；而且它指不出任何方向，一个方向都张不开。

「同一个 p，换个基底坐标就不一样了？」

会变。坐标是「关于某组基底的分解系数」，p 本身不变，(x,y,z) 随基底变。分解唯一指的是「同一组基底内唯一」，不是「跨基底不变」。

六问其实是一件事：定理的两个词——「不共面」保证分解写得出来，「唯一」保证 (x,y,z) 配叫坐标。哪一问拿不准，就回到这两个词上找答案。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 任意三个向量都能作空间的一个基底。

✓ 任意三个不共面的向量都可以构成空间的一个基底。

错在哪：把「三个」当成了充分条件。三个共面向量只张成一张平面，秩是 2，作不了基底。

✗ 同一个 p 的分解不唯一，可以凑出好几种 (x,y,z)。

✓ 基底选定后，有序实数组 (x,y,z) 由空间向量基本定理唯一确定。

错在哪：漏掉「唯一」。不唯一，坐标就无从定义，后面的建系运算全部失效。

✗ p = a + 2b + 0·c，所以基底退化成 {a,b} 两个基向量。

✓ p 与 a、b 共面，z=0 只说明 p 用不到 c；{a,b,c} 仍是空间的一个基底。

错在哪：把「某个向量的系数为 0」当成「基底少了一个向量」。退化的是这向量的分解，不是基底。

✗ 再加个零向量，凑够三个就能当基底。

✓ 基向量都必须是非零向量；含零向量的三个向量必然共面。

错在哪：零向量与任何向量共面，一加进来整组就共面了，连方向都提供不了。

✗ 基向量必须是单位向量，最好还两两垂直。

✓ 基向量只要求三个向量不共面，长度、夹角都不限。

错在哪：把「单位正交基底」当成了唯一合法的基底。单位正交只是最方便的一种，不是必须的。

✗ 基底换了，p 的坐标还是 (x,y,z)。

✓ 换基底，同一个 p 的分解系数会变；坐标是「关于某组基底」的。

错在哪：把坐标当成向量本身的属性。向量是客观的，坐标依赖基底，写坐标必须说明用哪组基底。

✗ p 的坐标 (x,y,z) 就是点 P 的坐标。

✓ (x,y,z) 是 p 关于基底 {a,b,c} 的分解系数；只有取单位正交基底时，它才与点坐标一致。

错在哪：把「向量坐标」和「点坐标」混为一谈。点坐标要靠原点 + 单位正交基底才对得上。
