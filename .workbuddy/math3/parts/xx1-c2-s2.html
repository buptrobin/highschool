01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 点斜式人教A版选择性必修第一册 · 第二章第二节

经过点 P₀(x₀, y₀)、斜率为 k 的直线 l 的方程是 y − y₀ = k(x − x₀)，这个方程叫做直线的点斜式方程。

→ 翻成人话：这句话由两个条件组成（① 一个定点 P₀；② 斜率 k 存在且已知）。少一个都不行——斜率不存在时点斜式里 k 根本无处可放，那条竖直线只能另写成 x = x₀。

课本原话 · 斜截式人教A版选择性必修第一册 · 第二章第二节

斜率是 k、纵截距是 b 的直线的方程是 y = kx + b，这个方程叫做直线的斜截式方程。

→ 两个条件（① k 存在；② b 是纵截距，即直线与 y 轴交点 (0, b) 的纵坐标）。b 是一个坐标，不是一个长度：它可以为负、可以为 0，写 |b| 就已经错了。

课本原话 · 一般式人教A版选择性必修第一册 · 第二章第二节

关于 x、y 的二元一次方程 Ax + By + C = 0（A、B 不同时为 0）都表示一条直线，它叫做直线的一般式方程。

→ 三个条件（① A、B、C 是实数；② A、B 不同时为 0；③ 允许 A = 0 或 B = 0）。第三条正是一般式的价值：它把竖直线 x = x₀ 也收进来了，所以「所有直线都能写成一般式」。

形式成立要什么条件缺了这个条件会怎样
点斜式 y − y₀ = k(x − x₀)斜率 k 存在竖直线 x = x₀ 写不出来，只能单独写，答题时漏掉这一类就丢分
斜截式 y = kx + b斜率 k 存在；b 是纵截距b 取负值时若写成 |b|，直线会画到 y 轴另一侧；k 不存在时同样失效
两点式 (y − y₁)/(y₂ − y₁) = (x − x₁)/(x₂ − x₁)x₁ ≠ x₂ 且 y₁ ≠ y₂水平线、竖直线都不能用（分母为 0），要先单独判断
截距式 x/a + y/b = 1a ≠ 0 且 b ≠ 0（两个截距都不为 0）过原点的直线、与坐标轴平行的直线都不能用，因为截距是 0 或不存在
一般式 Ax + By + C = 0A、B 不同时为 0能表示平面上任意一条直线，包括竖直线——所以它是最保险的收尾形式

背法只有两句：先问「斜率存在吗」，再问「过不过原点」。第一个问题决定能不能用点斜式/斜截式，第二个决定能不能用截距式；两个问题都含糊，就直接写一般式。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 由点与斜率求方程必考

已知直线 l 经过点 P(1, 2)，且斜率为 −3。
（1）求直线 l 的方程，并化成一般式；
（2）判断点 Q(0, 5) 是否在直线 l 上。
陷阱：题目若改成「经过点 (1, 2) 且垂直于 x 轴」，斜率不存在，上面的解法整条作废。

  1. 第 1 步 · 审题：条件够不够用点斜式

    题目给了一个定点 P(1, 2) 和一个斜率 k = −3，正好是点斜式的两个条件。斜率给出且是个实数，说明斜率存在，不必讨论竖直线。

    用到：点斜式需要「定点 + 斜率」两个条件，缺一不可。

  2. 第 2 步 · 代点斜式

    把 x₀ = 1、y₀ = 2、k = −3 代进 y − y₀ = k(x − x₀)，得 y − 2 = −3(x − 1)。注意两个括号里都是「坐标减坐标」，别写成 x + 1。

    用到：点斜式的标准形式，减号是坐标差的意思。

  3. 第 3 步 · 化成斜截式看结构

    展开右边：y − 2 = −3x + 3，移项得 y = −3x + 5。由此读到 k = −3、b = 5，直线与 y 轴交于 (0, 5)，与 x 轴交于 (5/3, 0)。

    用到：斜截式 y = kx + b 中 b 是纵截距，5 是正数，交点在 y 轴正半轴。

  4. 第 4 步 · 化成一般式

    把 y = −3x + 5 全移到一边：3x + y − 5 = 0。整理标准是「x 项、y 项、常数项」依次排列，且让 x 的系数为正，这样同一根直线的写法才唯一。

    用到：一般式 Ax + By + C = 0，要求 A、B 不同时为 0，这里 A = 3、B = 1。

  5. 第 5 步 · 验算并回答第 (2) 问

    代 P(1, 2)：3×1 + 2 − 5 = 0 ✓。代 Q(0, 5)：3×0 + 5 − 5 = 0 ✓，所以 Q 在直线 l 上——它其实就是 y 轴截距点。

    用到：点在直线上 ⇔ 坐标满足方程，这一步能兜住前面所有的算错。

1 / 5

标准答案（可抄进答题卡）

（1）∵ 直线 l 经过点 P(1, 2)，斜率 k = −3，
∴ 由点斜式得 y − 2 = −3(x − 1)，
即 y = −3x + 5，
化成一般式得 3x + y − 5 = 0。
（2）将 Q(0, 5) 的坐标代入 3x + y − 5：3×0 + 5 − 5 = 0，等式成立，
∴ 点 Q(0, 5) 在直线 l 上。
【易错提醒】若题设为「垂直于 x 轴」，则斜率不存在，应直接写 x = 1，不能套点斜式。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「点斜式和斜截式不是万能的吗？竖直线怎么就不行了？」

因为竖直线没有斜率 k，点斜式与斜截式里那个 k 位置是空的。竖直线只能写成 x = x₀，或写成一般式 x − x₀ = 0。题目说「垂直于 x 轴」「倾斜角 90°」时，第一反应就该是它。

「纵截距 b 会是负的吗？截距不是长度吗？」

可以是负的，也可以是 0。截距是交点坐标，不是距离：直线与 y 轴交于 (0, b)，b < 0 就说明交点在 y 轴负半轴。只有问「距离」时才取 |b|，而且要写清是「原点到交点的距离」。

「截距式 x/a + y/b = 1 什么时候不能用？」

只要有一个截距为 0 就不能用：过原点的直线两个截距都是 0，垂直于 x 轴的直线没有 y 截距，垂直于 y 轴的直线没有 x 截距。所以截距式要求两个截距都不为 0，用之前先确认直线不过原点、也不与坐标轴平行。

「都有斜截式了，一般式还要它干什么？」

因为只有一般式能表示所有直线，包括 x = x₀ 这种没有斜率的。它还有个好处：判断平行与垂直时可以直接看系数（A₁B₂ − A₂B₁ = 0 为平行），不用先讨论斜率是否存在。所以课本把一般式当作最后的统一形式。

「题目给的截距是 3，那 b 就是 3 吧？」

要看是哪个截距。斜截式 y = kx + b 里的 b 只是纵截距；横截距是直线与 x 轴交点的横坐标，得令 y = 0 解出来，对 y = kx + b 就是 −b/k。两个都叫「截距」，但一个是 b，一个是 −b/k，混用会把直线画错一整格。

「两点式和点斜式是两个公式要背吗？」

只要背一个。两点式就是先用两点算出斜率 k，再代点斜式：k = (y₂ − y₁)/(x₂ − x₁)，然后 y − y₁ = k(x − x₁)，整理即得两点式。记住这个来源，就不必担心 x₁ = x₂ 或 y₁ = y₂ 时公式失效——那时你本来就知道该另写 x = x₀ 或 y = y₀。

收尾一句：这六问其实是同一件事——每个形式都有自己的「适用条件」，先查条件再用公式，比背五个公式管用。三处必踩的坑是：点斜式表示不了竖直线、b 是纵截距不是距离、截距式要求两个截距都不为 0。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 过点 (2, 3) 且垂直于 x 轴的直线：y − 3 = k(x − 2)，k 不存在就写 k = 0

✓ 斜率不存在时，直线方程为 x = 2（也可写成 x − 2 = 0，这是一般式）

错在哪：点斜式表示不了竖直线——竖直线根本没有斜率，不存在「k 取 0」这回事，k = 0 是水平线 y = 3。

✗ 直线 y = 2x − 4 的纵截距是 4，因为它到原点的距离是 4

✓ 纵截距 b = −4，直线与 y 轴交于 (0, −4)；到原点的距离 |b| = 4 是另一个概念

错在哪：b 是纵截距，是交点的纵坐标，可为负；把它当距离取绝对值，直线就被搬到了 y 轴正半轴，图画错、象限也全错。

✗ 过原点的直线斜率为 2，由截距式得 x/0 + y/0 = 1

✓ 截距式要求两个截距都不为 0，过原点时不能用，应写 y = 2x

错在哪：截距式要求两个截距都不为 0，a = 0 或 b = 0 时分母为 0，式子本身就没意义。

✗ 方程 Ax + By + C = 0 都表示直线，比如 0·x + 0·y + 1 = 0 表示 x 轴

✓ 一般式必须 A、B 不同时为 0；A = B = 0 时方程变成 C = 0，不是直线

错在哪：漏掉了「A、B 不同时为 0」这一条，这是判断一个方程是否为一般式的唯一门槛。

✗ 由 y = −3x + 5 得一般式：y = −3x + 5

✓ 移项整理为 3x + y − 5 = 0（x 的系数取正，按 x、y、常数排列）

错在哪：一般式必须是 Ax + By + C = 0 的规范形状；只移一半、留着等号右边的数，或把系数写成 −3x − y + 5 = 0，都不算化到一般式。

✗ 由点斜式 y − 2 = −3(x − 1) 直接读斜截距 b = 2

✓ 先化成 y = −3x + 5，再读 k = −3、b = 5

错在哪：把点斜式里的 y₀ = 2 当成了 b。b 只有在 y = kx + b 这个形状里才是纵截距，其他形式里的数字都有自己的身份。

✗ 直线在两轴上的截距相等，所以斜率一定是 −1

✓ 截距相等要分两类：a = b ≠ 0 时斜率 −1；a = b = 0（过原点）时截距式失效，斜率任意

错在哪：又一次倒在「截距可以为 0」上。截距相等 ⇒ 漏掉过原点这一类，是压轴小题的经典陷阱。
