ELI5-HIGH · 讲给要考试的人

这一节只有三句话要记死：直线先化成一般式、分子加绝对值、两平行线先统一 A、B。

上一节你会求两条直线的交点，这一节把「交点」和「距离」一起收口：交点就是方程组有没有解，距离则全部由同一条式子 A x + B y + C 撑起来。它也是后面圆、圆锥曲线里「弦长」「最值」的地基，几乎每道解析几何大题都要用到它。最容易错的一件事是形态错配 —— 公式只认一般式，你手上却拿着 y = k x + b，或者拿着两条系数不同的「平行线」直接减 C。

01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 两点间的距离公式人教A版选择性必修第一册 · 第2章第3节

两点 P₁(x₁, y₁)、P₂(x₂, y₂) 间的距离 |P₁P₂| = √((x₂−x₁)² + (y₂−y₁)²)。

→ 翻成人话：这句话由两个条件组成。① 已知两点的坐标（不是斜率、不是向量）；② 先作横、纵坐标之差，各自平方、相加、再开方，顺序不能换 —— 差的平方和平方的差完全不是一回事。

课本原话 · 点到直线的距离公式人教A版选择性必修第一册 · 第2章第3节

点 P(x₀, y₀) 到直线 l：Ax + By + C = 0 的距离 d = |Ax₀ + By₀ + C| / √(A² + B²)。

→ 翻成人话：这句话由三个条件组成。① 直线必须先写成一般式 Ax + By + C = 0（A、B 不同时为 0）；② 分子要加绝对值；③ 分母是 √(A² + B²)，不是 A² + B²。少任何一条，答案就废。

课本原话 · 两条平行线间的距离人教A版选择性必修第一册 · 第2章第3节

两条平行线 l₁：Ax + By + C₁ = 0 与 l₂：Ax + By + C₂ = 0 之间的距离 d = |C₁ − C₂| / √(A² + B²)。

→ 翻成人话：这句话由两个条件组成。① 两线已判定平行（A、B 成比例且 C 不成同一比例）；② 两式的 A、B 必须化成完全相同，才能直接拿 C₁ − C₂。

环节必须满足没做到会怎样
求交点联立两直线方程解二元一次方程组方程组无解 ⇔ 两线平行；有无数解 ⇔ 两线重合
用距离公式前直线写成 Ax + By + C = 0拿 y = kx + b 直接代，会把 k、b 错当 A、B，分母整个错
分子加绝对值 |Ax₀ + By₀ + C|代进去是负数时得负距离，答案直接判错
分母√(A² + B²)写成 A² + B² 少开一次方，数值全错
两平行线A、B 化成完全相同系数不同就减 C，|C₁ − C₂| 与实际距离差一个倍数
真正的通行证同一组 A、B，是三条公式共用的「尺子」三条公式其实是同一件事：都在这把尺子上量长度

背法：把 Ax + By + C 看成一个整体，叫它「代值」F(x, y)。那么点到直线的距离 = |F(x₀, y₀)| ÷ √(A² + B²)，平行线距离 = |F₁ − F₂| ÷ √(A² + B²)。先认一般式，再谈代值，两条公式就只剩一条。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 点到直线的距离（含斜截式陷阱）必考

（1）求点 P(2, 0) 到直线 3x + 4y − 10 = 0 的距离。
（2）把直线改写成 y = −(3/4)x + 5/2，求点 P(2, 0) 到这条直线的距离 —— 两问答案一样吗？为什么？

  1. 第 1 步 · 审题：先检查直线是不是一般式

    第（1）问已经是 Ax + By + C = 0 的形状，可以直接读系数：A = 3、B = 4、C = −10，且 A、B 不同时为 0，公式可用，分母 √(3² + 4²) 也就定了。

    用到：公式只对一般式成立，先确认形态再动笔。

  2. 第 2 步 · 代值：把点代进左边

    把 P(2, 0) 代进 3x + 4y − 10：3×2 + 4×0 − 10 = 6 − 10 = −4。结果是个负数，这正是 0.8 与 −0.8 的分岔口 —— 距离是长度，不能为负，所以下一步必须加绝对值。

    用到：代值 F(x₀, y₀) = Ax₀ + By₀ + C，允许为负。

  3. 第 3 步 · 算分母：√(A² + B²)

    A² + B² = 9 + 16 = 25，再开方得 5。注意是先平方相加、再开方，不是 3 + 4 = 7，也不是 25。这一步错，后面全错。

    用到：分母是 √(A² + B²)，单位长度的「刻度」。

  4. 第 4 步 · 加绝对值、作商

    d = |3×2 + 4×0 − 10| / √(9 + 16) = |−4| / 5 = 4/5 = 0.8。第（1）问答案：0.8。

    用到：分子必须加绝对值，把 −4 变成 4。

  5. 第 5 步 · 第（2）问：先化一般式，再看是不是同一条线

    y = −(3/4)x + 5/2 两边乘 4 得 4y = −3x + 10，移项即 3x + 4y − 10 = 0，与第（1）问是同一条直线，所以距离仍是 0.8。陷阱在于：直接把 k = −3/4、b = 5/2 当 A、B 代公式，会算出完全错误的数。

    用到：斜率式必须先移项成一般式，才能读出 A、B、C。

1 / 5

标准答案（可抄进答题卡）

（1）直线 3x + 4y − 10 = 0 中 A = 3，B = 4，C = −10。
点 P(2, 0) 到该直线的距离
d = |3×2 + 4×0 − 10| / √(3² + 4²)
　 = |−4| / 5
　 = 4/5 = 0.8。
（2）由 y = −(3/4)x + 5/2 得 4y = −3x + 10，即 3x + 4y − 10 = 0，与（1）是同一条直线，故 d = 0.8，两问答案相同。
另：因 3×2 + 4×0 − 10 = −4 ≠ 0，点 P 在直线外，垂线段长即为 0.8。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「公式对直线的写法有要求吗？我手上是 y = 2x − 1 能不能直接用？」

有要求，只能是 Ax + By + C = 0 的一般式。y = 2x − 1 要移项成 2x − y − 1 = 0，读出 A = 2、B = −1、C = −1 再代。直接把 k、b 当 A、B 用，是最常见的形态错配。

「绝对值能不能省掉？我算出来代值是正的，是不是就不用加了？」

不能省。分子要加绝对值是公式的一部分，不是补丁。代值正负取决于点在直线的哪一侧，与距离大小无关：P 在另一侧时代值就变负，绝对值把它拉回长度。写公式时先把绝对值写上，再代数。

「两平行线求距离，为什么非得把 A、B 弄成一样？我直接减 C 不行吗？」

不行。两平行线的 A、B 必须化成相同，因为分母 √(A² + B²) 依赖 A、B，而 C 是按各自系数配出来的。系数差 2 倍时，C 之差也跟着差 2 倍，必须先同除同一个数把 A、B 对齐，分子分母才在同一把尺子上。

「分母为什么是 √(A² + B²)，不是 A² + B²，也不是 |A| + |B|？」

因为 √(A² + B²) 是法向量 (A, B) 的模长，也是「把代值换算成长度」的换算比例。它来自 A、B 构成的直角三角形斜边，量纲与坐标一致；A² + B² 是模的平方，量纲已变，不能再当分母。

「点代进去刚好等于 0，说明什么？答案写 d = 0 对吗？」

对，且必须写 0。代值为 0 ⇔ 点在直线上，此时垂线段退化成一点，距离 d = 0。反过来，d = 0 也是判「点在线上」最省事的判据，比解方程组快。

「两条相交直线的距离是多少？没有平行，公式就不适用了吧？」

距离是 0。两条相交直线有公共点，两点间距离的最小值就是 0，所以不必套平行线公式。只有「平行且不重合」时才用 |C₁ − C₂| ÷ √(A² + B²)；重合时距离同样是 0。

六问其实是同一件事：三条公式都以「一般式 + 同一组 A、B」为前提，分子是差、分母是尺。凡是答案对不上，先回头查这三个前提，而不是重算一遍。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 直线 y = 2x − 1，A = 2，B = −1，C = −1，直接代公式。

✓ 由 y = 2x − 1 得 2x − y − 1 = 0，故 A = 2，B = −1，C = −1。

错在哪：公式要求一般式。斜截式里的 k、b 与 A、B、C 是两套记号，移项之后系数才认得出，位置对了数才可能对。

✗ d = (3×2 + 4×0 − 10) ÷ 5 = −0.8。

✓ d = |3×2 + 4×0 − 10| ÷ √(3² + 4²) = 4/5 = 0.8。

错在哪：分子要加绝对值。代值可正可负，距离是长度，必须非负；漏绝对值等于把「点在直线哪一侧」当成距离。

✗ 3x + 4y − 10 = 0 与 6x + 8y − 5 = 0，d = |−10 − (−5)| ÷ 5 = 1。

✓ 先把 l₂ 化为 3x + 4y − 2.5 = 0，d = |−10 − (−2.5)| ÷ 5 = 1.5。

错在哪：两平行线的 A、B 必须化成相同。系数差 2 倍时分子分母不在同一把尺子上，必须先除以 2 对齐，再减 C。

✗ d = |Ax₀ + By₀ + C| ÷ (A² + B²)。

✓ d = |Ax₀ + By₀ + C| ÷ √(A² + B²)。

错在哪：分母少开一次方。√(A² + B²) 是法向量的模长，A² + B² 是模的平方，两者差一个开方，结果全错。

✗ 求 P(1, 2) 到 l 的距离，先算 |P₁P₂| = √((x₂−x₁)² + (y₂−y₁)²)。

✓ 点到直线用 d = |Ax₀ + By₀ + C| ÷ √(A² + B²)；两点间才用 |P₁P₂|。

错在哪：把两条公式混用。判断依据是「输入是什么」：两个点用勾股型，一个点加一条线用代值型，别背串。

✗ 直线 3x + 4y = 0 过原点，C 不存在，公式写成 d = |3x₀ + 4y₀| ÷ 5。

✓ 3x + 4y = 0 即 3x + 4y + 0 = 0，C = 0，仍按 d = |3x₀ + 4y₀ + 0| ÷ 5 写。

错在哪：C = 0 不等于没有 C。一般式里 C 是常数项，取 0 也要写出来，答题时保留「+ 0」能避免自己漏项。

✗ x − y + 1 = 0 与 2x − 2y + 1 = 0 相交，所以没有距离。

✓ 两式 A、B 成比例而 C 不成比例，两线平行；对齐后 d = |1 − 0.5| ÷ √2 = √2/4。

错在哪：判平行只看 A、B 是否成比例，不看系数是否长得一样。两线平行才有「线线距离」，相交或重合时的距离都是 0。
