这一节是第二章的入口：后面点到直线的距离、两直线平行与垂直，全都要先会把「方向」翻译成数。翻译工具只有两件——倾斜角 α 和斜率 k=tanα，再加一条两点式公式。最容易错的一件事不是算错，而是把「斜率不存在」写成 0：0 是水平线（α=0°）的斜率，竖直线（α=90°）根本没有斜率，两者不是大小关系，是「有」和「没有」。

01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

倾斜角的定义与范围人教A版选择性必修第一册 · 第二章第一节

当直线 l 与 x 轴相交时，我们以 x 轴为基准，x 轴正向与直线 l 向上的方向之间所成的角 α 叫做直线 l 的倾斜角。当直线 l 与 x 轴平行或重合时，我们规定它的倾斜角为 0°。因此，倾斜角的取值范围是 0°≤α<180°。

→ 三个条件：① 顶点取 l 与 x 轴的交点（平行或重合时规定 α=0°）；② 一条边固定为 x 轴正方向；③ 另一条边取直线向上的方向，量出最小正角。少一个就会量到另一个角。终点是开区间上界：α=180° 与 α=0° 是同一条直线，所以范围不含 180°，写成 0°≤α≤180° 就错了。

斜率的定义人教A版选择性必修第一册 · 第二章第一节

直线 l 的倾斜角 α 的正切值叫做直线 l 的斜率，即 k = tan α（α ≠ 90°）。当 α=90° 时，直线 l 的斜率不存在。

→ 两个条件：① α 必须先算出来；② α≠90°。缺第二条，tan90° 没有定义，k 就不存在——不能补一个 0。0 是 α=0° 那条水平线的斜率，所以「k=0」和「k 不存在」是两种直线，一个躺平、一个站直。

经过两点的斜率公式人教A版选择性必修第一册 · 第二章第一节

经过两点 P₁(x₁,y₁)、P₂(x₂,y₂)（x₁≠x₂）的直线的斜率公式为 k = (y₂ − y₁) / (x₂ − x₁)。

→ 只有一个条件：x₁≠x₂，即分母不为 0。x₁=x₂ 时两点连线是竖直线，α=90°，斜率不存在；公式不是「算不出来」，而是这条直线本来就没有斜率，答题时必须写这句话，不能写分母为 0 就算了。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 由两点求斜率和倾斜角必考

已知直线 l 经过 A(1,2)、B(3,6) 两点。
（1）求直线 l 的斜率 k；（2）求直线 l 的倾斜角 α（精确到 0.1°）；
（3）若把 B 换成 B′(1,6)，直线 AB′ 的斜率与倾斜角各是什么？

  1. 第 1 步 · 审题：求倾斜角，先求斜率

    倾斜角不能直接由两点读出，路线固定：两点 → 两点式求 k → 解 tanα=k → 按 k 的符号定 α 的范围。先检查 x₁≠x₂：1≠3，分母不为 0，斜率存在。

    用到：两点式的前提 x₁≠x₂；k=tanα 的前提 α≠90°。

  2. 第 2 步 · 代两点式

    k = (y₂ − y₁) / (x₂ − x₁) = (6 − 2) / (3 − 1) = 4/2 = 2。分子是纵坐标之差、分母是横坐标之差，顺序写反会得到 1/2。

    用到：k=(y₂−y₁)/(x₂−x₁)；与取 A 为 P₁ 还是 P₂ 无关。

  3. 第 3 步 · 由 k 反求 α（判象限）

    由 tan α = 2 且 k=2>0，得 α∈(0°,90°)，在这个区间上 tan 单调递增，所以解唯一：α=arctan2≈63.4°。若算出 k=−2，则 α∈(90°,180°)，答案是 180°−arctan2≈116.6°，不是计算器上的 −63.4°。

    用到：k 的符号定 α 所在区间；tanα=m 求 α 要判象限，只按计算器会给错角。

  4. 第 4 步 · 检验范围

    63.4° 落在 0°≤α<180° 内，且不等于 90°，所以它确实是一个倾斜角；同时 k=2 是实数，说明斜率存在。两个条件都过，答案才算完。

    用到：倾斜角范围 [0°,180°)（不含 180°）；α=90° 时斜率不存在。

  5. 第 5 步 · 变式：横坐标相等

    A(1,2)、B′(1,6) 满足 x₁=x₂=1，Δx=0，两点式分母为 0，斜率不存在；此时直线是竖直线，倾斜角 α=90°。答题要写「斜率不存在」，不能写 0，也不能写 ∞。

    用到：x₁=x₂ ⇒ 斜率不存在、α=90°；「不存在」与「等于 0」是两回事。

1 / 5

标准答案（可抄进答题卡）

（1）因为 1≠3，所以直线 l 的斜率存在，k = (6 − 2) / (3 − 1) = 2。
（2）设倾斜角为 α，则 tan α = 2。因为 k=2>0，所以 α∈(0°,90°)；在此区间内 tanα 单调递增，解唯一，α = arctan 2 ≈ 63.4°。
（3）把 B 换成 B′(1,6) 后，x₁=x₂=1，Δx=x₂−x₁=0，两点式分母为 0，所以直线 AB′ 的斜率不存在；该直线垂直于 x 轴，倾斜角 α=90°。
答：k=2，α≈63.4°；变式的斜率不存在，α=90°。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

倾斜角写成 0°≤α≤180° 行不行？多一个等号而已吧？

不行。倾斜角范围是 0°≤α<180°，不含 180°。α=180° 与 α=0° 指的是同一条水平线，把 180° 收进来，一条直线就有两个倾斜角，倾斜角就不再唯一。

竖直线那么陡，斜率总该是 0 吧？或者无穷大？

都不是。α=90° 时 tan90° 无定义，所以斜率不存在；0 是 α=0°（水平线）的斜率，∞ 不是实数，也不能写。答案只写三个字：不存在。

两条直线斜率一样，它们就一定平行吗？

两条直线斜率都存在且相等时，它们平行或重合（还要看是否同一条直线）；斜率都不存在时，两条都垂直于 x 轴，也平行或重合。反过来，平行直线的斜率不一定相等——两条竖直线就都没有斜率。

由 tanα=−2 求 α，计算器给 −63.4°，直接抄行不行？

不行。倾斜角必须落在 [0°,180°) 内，负数不是倾斜角。先看 k 的符号定象限：k<0 ⇒ α∈(90°,180°)，所以 α = 180° − arctan 2 ≈ 116.6°。k>0 时 α∈(0°,90°)，直接取 arctan 值即可。

水平线的倾斜角是 0° 还是 90°？它的斜率呢？

与 x 轴平行或重合的直线，倾斜角规定为 α=0°，此时 k=tan0°=0，斜率存在且等于 0。90° 是竖直线，两条线正好差 90°，不要混。

两点式斜率的分母可以是 0 吗？算出来分母是 0 就写 0 行吗？

不行。x₁=x₂ 时分母 x₂−x₁=0，斜率不存在（直线垂直于 x 轴，α=90°）。分母为 0 不是「等于 0」，而是这个式子没有意义，必须改口说「斜率不存在」。

六问其实是同一件事：先问斜率在不在，再问斜率等于几。α 是否等于 90°（或 x₁ 是否等于 x₂）决定了这一步做不做，α 的区间决定了 k 的符号、也决定了由 k 反求 α 时取哪个角。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ 倾斜角的取值范围是 0°≤α≤180°。

✓ 倾斜角的取值范围是 0°≤α<180°，不含 180°。

错在哪：180° 与 0° 是同一条水平线的两个名字，收进 180° 倾斜角就不唯一；考试填空只认左闭右开。

✗ 竖直线很陡，所以它的斜率是 0。

✓ α=90° 时 tan90° 无定义，直线的斜率不存在。

错在哪：0 是 α=0° 那条水平线的斜率。竖直线与水平线差 90°，一个斜率不存在、一个斜率为 0，不是一回事。

✗ 由 tanα=−2 得 α=−63.4°。

✓ 由 tanα=−2 且 k<0 知 α∈(90°,180°)，故 α=180°−arctan2≈116.6°。

错在哪：倾斜角必须落在 [0°,180°) 内；tanα=m 求 α 要先判象限，只按计算器会给到区间外的角。

✗ 斜率不存在就是斜率无穷大，写成 k=∞。

✓ 斜率不存在指的是 tanα 无定义，此时直线的倾斜角 α=90°。

错在哪：∞ 不是实数，不能进答案；「不存在」是说这个数压根没有，不是「特别大的数」。

✗ 两点式 k=(x₂−x₁)/(y₂−y₁)。

✓ k=(y₂−y₁)/(x₂−x₁)，分子是纵坐标之差，分母是横坐标之差。

错在哪：写反得到的是斜率的倒数，正负与大小都错；记法只有一句——竖差 ÷ 横差。

✗ 每条直线都有斜率。

✓ 倾斜角 α≠90° 的直线才有斜率 k=tanα；α=90° 的直线没有斜率，但有倾斜角。

错在哪：倾斜角是「方向」，所有直线都有；斜率是「数」，竖直线没有。两条性质不绑定。

✗ 倾斜角是直线与 y 轴正方向所成的角。

✓ 倾斜角是 x 轴正方向与直线向上的方向所成的最小正角。

错在哪：换了基准轴，所有角都差 90°（k 与 1/k 互换），从图形到数值全错。
