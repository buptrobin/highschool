椭圆是「到两定点距离之和为定值」，双曲线把和换成差的绝对值，于是曲线从一条闭合的圈变成左右两支。位置在 3.1 椭圆之后、3.3 抛物线之前，是圆锥曲线里唯一「两条曲线 + 两条直线」一起考的一节。最容易错的一处：把椭圆的 a²=b²+c² 顺手写成双曲线的 c²=a²−b²。

01课本怎么说

先背标准表述，再拆关键词。答题时写左边这句，不是右边的人话。

课本原话 · 双曲线的定义人教A版选择性必修第一册 · 第3章第2节

平面内与两个定点 F₁、F₂ 的距离之差的绝对值等于常数（小于 |F₁F₂| 且大于 0）的点的轨迹叫做双曲线。这两个定点叫做双曲线的焦点，两焦点间的距离叫做焦距。

→ 翻成人话：这句话由五个条件组成：①在平面内；②到两个定点 F₁、F₂；③距离之差（不是和）；④取绝对值；⑤常数 0<2a<|F₁F₂|。少第④条只剩一支，少第⑤条轨迹不存在或退化成一条直线。

课本原话 · 标准方程与 a、b、c人教A版选择性必修第一册 · 第3章第2节

焦点在 x 轴上的双曲线的标准方程是 x²/a² − y²/b² = 1（a>0，b>0），其中 c² = a² + b²。

→ 注意这里是加号：c²=a²+b²（与椭圆相反）。椭圆里 a 最大，双曲线里 c 最大；算出 c 再写焦点 (±c, 0)。

课本原话 · 渐近线与离心率人教A版选择性必修第一册 · 第3章第2节

双曲线 x²/a² − y²/b² = 1 的渐近线是 y = ±(b/a)x，离心率 e = c/a > 1。

→ 渐近线 y=±(b/a)x，b 在分子：a 变大开口变窄，b 变大开口变开。e 只由 a、b 的比值决定，永远大于 1。

定义里的条件少写或写错会怎样
在平面内空间里得到的是双曲面，不是双曲线
到两个定点 F₁、F₂ 的距离没有焦点，c 无从算起，方程写不出
距离之差（不是和）距离之和对应的是椭圆，两条曲线完全不同
取绝对值不取绝对值只能得到一支（右支或左支），不是整条双曲线
0 < 常数 < |F₁F₂|常数 ≥|F₁F₂| 时轨迹不存在；常数 = 0 时退化成 F₁F₂ 的中垂线

背定义时把「绝对值」和「小于 |F₁F₂|」当成两个开关：前者决定有没有两支，后者决定有没有轨迹。做题先写这两句，再代公式。

04一道题走一遍

先自己读题干想 30 秒，再点「下一步」。

例题 · 由标准方程读 a、b、c、e 与渐近线必考

已知双曲线 x²/9 − y²/16 = 1。(1) 求 a、b、c 与焦点坐标；(2) 求离心率 e 与渐近线方程；(3) 求实轴长、虚轴长、焦距，并指出三者中谁最大。
陷阱：x² 下面的是 9 还是 16，决定焦点在哪个轴；c 要用加法算。

  1. 第 1 步 · 定型：谁在 x² 下面

    方程里 x² 项系数为正（9 在 x² 下），所以焦点在 x 轴上，a²=9、b²=16，即 a=3、b=4。若 16 在 x² 下面，焦点就跑到 y 轴，后面全要换。

    用到：标准方程 x²/a²−y²/b²=1 中 a² 是 x² 的分母。

  2. 第 2 步 · 求 c：只能用加法

    c² = a² + b² = 9 + 16 = 25，所以 c = 5。焦点为 F₁(−5, 0)、F₂(5, 0)，焦距 |F₁F₂| = 2c = 10。

    用到：c²=a²+b²（与椭圆相反）；若写成 c²=a²−b²=9−16=−7，根号里是负数，立刻矛盾。

  3. 第 3 步 · 离心率

    e = c/a = 5/3。检验范围：5/3 ≈ 1.67 > 1，符合双曲线 e>1；若算出 e<1 说明 a、c 用反了。

    用到：e=c/a，且双曲线恒有 e>1。

  4. 第 4 步 · 渐近线：b 在分子

    渐近线 y = ±(b/a)x = ±(4/3)x。检查：a=3、b=4，b>a，所以斜率大于 1、张口偏开，与图一致。

    用到：渐近线 y=±(b/a)x，b 在分子；写成 ±(3/4)x 是把分子分母写反。

  5. 第 5 步 · 三轴长与大小排序

    实轴长 2a = 6，虚轴长 2b = 8，焦距 2c = 10。排序：2c > 2b > 2a，即 c 最大——这正是 c²=a²+b² 的几何含义（c 是斜边）。

    用到：实轴对应顶点，虚轴对应矩形的高，焦距对应两焦点。

1 / 5

标准答案（可抄进答题卡）

(1) 由 x²/9−y²/16=1 得 a²=9，b²=16，故 a=3，b=4；c²=a²+b²=25，c=5，焦点 F₁(−5,0)、F₂(5,0)。
(2) e=c/a=5/3；渐近线 y=±(b/a)x，即 y=±(4/3)x。
(3) 实轴长 2a=6，虚轴长 2b=8，焦距 2c=10，其中 c 最大。

05会怎么考

六问，都是「你以为懂了、一写就错」的地方。

「c² 到底是 a²+b² 还是 a²−b²？椭圆那套能不能照搬？」

只能加。双曲线里 c 是斜边（a、b 为直角边），所以 c²=a²+b²（与椭圆相反）；写成减法会出现 c<a 甚至负数，与 c 最大矛盾。

「定义里为什么要加绝对值？不加会怎样？」

不加只剩一支。|PF₁−PF₂|=2a 给出左右两支；只写 PF₁−PF₂=2a 只得到靠近 F₂ 的那一支。必须加绝对值，否则只是一支。

「渐近线斜率是 b/a 还是 a/b？我怎么总写反？」

b/a，b 在分子。2a×2b 的矩形宽 2a、高 2b，对角线斜率 = 2b/2a = 渐近线 y=±(b/a)x，b 在分子；b 变大斜率变大，张口变开。

「双曲线的离心率能不能小于 1？什么时候等于 1？」

不能。c²=a²+b²>a² ⇒ c>a ⇒ e=c/a>1；e=1 只在 b=0 时出现，那时曲线退化成两条射线。e 越接近 1 张口越窄，e 越大张口越开。

「椭圆和双曲线的 a、b、c，到底谁减谁？」

椭圆 a²=b²+c²（a 最大）；双曲线 c²=a²+b²（与椭圆相反），c 最大。记法：谁最大，谁就单独待在等号左边。

「焦点在 y 轴上，方程和渐近线怎么变？」

把 y² 项放正：y²/a²−x²/b²=1，焦点 (0,±c)，c²=a²+b² 不变，但渐近线变成 y=±(a/b)x——此时仍是「a 在分子」，因为 a 是 y² 下面的数。

六问其实是同一件事：先认「谁是斜边 c」，再认「b 在分子」，最后别忘了绝对值。三步都对，双曲线的题就只剩代公式。

06易错清单

左边是学生真会写的错句，右边是应该写的样子。

✗ c² = a² − b²，所以 c=√(9−16)。

✓ c² = a² + b² = 9 + 16 = 25，c = 5，焦点 (±5, 0)。

错在哪：把椭圆的减法照搬到双曲线。双曲线 c²=a²+b²（与椭圆相反），c 最大，减出来根号里会是负数。

✗ 点 P 满足 PF₁−PF₂=2a，所以 P 的轨迹是双曲线。

✓ |PF₁−PF₂|=2a（0<2a<|F₁F₂|）的点的轨迹才是双曲线。

错在哪：没加绝对值只得到一支。必须加绝对值，否则只是一支；两支合起来才叫双曲线。

✗ x²/9−y²/16=1 的渐近线是 y=±(3/4)x。

✓ y=±(b/a)x=±(4/3)x，因为 b=4 在分子、a=3 在分母。

错在哪：分子分母写反。记住 渐近线 y=±(b/a)x，b 在分子：矩形的高是 2b。

✗ 算出 e = 4/5 = 0.8，所以这是双曲线。

✓ e = c/a > 1；0<e<1 是椭圆，e=1 是抛物线。

错在哪：e<1 说明分子分母用反了，或把椭圆结论套了过来。双曲线的 e 永远大于 1。

✗ 双曲线的焦点是 (±b, 0) 或 (±a, 0)。

✓ 焦点是 (±c, 0)，其中 c=√(a²+b²)，且 c>a。

错在哪：焦点由 c 决定，不是由 a 或 b 决定；c 必须比 a 大，算完要检验。

✗ 看到 x²/9−y²/16=1，谁大谁当 a，所以 a=4，b=3。

✓ a² 是 x² 下面的数：a²=9，a=3；b²=16，b=4。

错在哪：a、b 由位置决定，不由大小决定。只有椭圆才附带「a>b」的约定，双曲线的 a、b 谁大谁小都行。

✗ 焦点在 y 轴时，方程写成 x²/a²−y²/b²=1，渐近线还是 ±(b/a)x。

✓ 焦点在 y 轴：y²/a²−x²/b²=1，焦点 (0,±c)，渐近线 y=±(a/b)x。

错在哪：正项在哪个字母下，焦点就在哪个轴上；渐近线的斜率始终是「正项分母开根 ÷ 负项分母开根」，换轴就要跟着换。
