## xx1-c2-s4 圆的方程

**课本原话**
1. 圆的标准方程：(x−a)²+(y−b)²=r²，圆心 (a,b)，半径 r。
2. 圆的一般方程：x²+y²+Dx+Ey+F=0，当 D²+E²−4F>0 时表示圆。
3. 一般方程配方后圆心 (−D/2,−E/2)，半径 r=½√(D²+E²−4F)。

**三个扣分点**：一般方程要**先判 D²+E²−4F>0** 才是圆；标准方程里是 (x−a) 不是 (x+a)；半径要开方后除以 2。

**四张图**：① 标准方程的圆心与半径；② 一般方程配方过程；③ 判别式三种情况（圆、点、无轨迹）；④ 求圆方程的两种方法（待定系数、几何法）。

**互动模型**：滑块＝半径 r（0.5 到 5，step 0.5），圆心固定 (1,2)
```js
n = r < 2 ? 0 : r === 2 ? 1 : 2;    // 与 x 轴的交点个数（圆心纵坐标 2）
disc = r * r - 4;                   // 与 x 轴相交的判别量
```
`cases`：`{v:1,eq:{n:0,disc:-3}}`、`{v:2,eq:{n:1,disc:0}}`、`{v:3,eq:{n:2,disc:5}}`。
Autopilot：`[{t:0,v:3},{t:1.2,v:3},{t:4,v:2},{t:6.5,v:2},{t:9,v:1},{t:11.5,v:4},{t:13.5,v:3}]`，keys `[1,2,3,4]`。
**停留帧在 r=2**（圆与 x 轴相切，交点从 2 个变成 0 个的分界）。
状态：r<2「与 x 轴相离」；r=2「相切」；r>2「相交于两点」。

**例题**：「求过三点 O(0,0)、A(1,1)、B(4,2) 的圆的方程。」答案：设 x²+y²+Dx+Ey+F=0，代入三点得 F=0、D+E=−2、4D+2E=−20，解得 D=−8、E=6，圆的方程为 x²+y²−8x+6y=0，圆心 (4,−3)，半径 5。
**六问**：① 一般方程一定是圆吗；② 标准方程里圆心符号怎么读；③ 判别式等于 0 是什么图形；④ 半径公式里的 ½ 从哪来；⑤ 求圆方程有几种方法；⑥ 圆心在原点时方程长什么样。
**易错**：✗ 一般方程直接当圆 / ✗ 圆心写成 (D,E) / ✗ 半径忘记开方 / ✗ 标准方程符号读反 / ✗ 判别式算成 D²+E²−F / ✗ 三个点求不出圆（其实一定能，除非共线）。
