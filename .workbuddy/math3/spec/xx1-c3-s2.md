# 本节规格（只读这一节，不要读 SPEC.md 全文）

## xx1-c3-s2 双曲线

**课本原话**
1. 平面内与两个定点 F₁、F₂ 的距离之差的绝对值等于常数（小于 |F₁F₂| 且大于 0）的点的轨迹叫做双曲线。
2. 标准方程 x²/a²−y²/b²=1，且 c²=a²+b²。
3. 渐近线 y=±(b/a)x；离心率 e=c/a>1。

**三个扣分点**：这里是 c²=a²+**b²**（与椭圆相反，最容易记混）；必须加**绝对值**（否则只是一支）；渐近线是 y=±(b/a)x，注意 b 在分子。

**四张图**：① 双曲线的两支与定义（差的绝对值）；② a、b、c 的关系（c 最大）；③ 渐近线与开口；④ 椭圆与双曲线的 a、b、c 对照表。

**互动模型**：滑块＝虚半轴 b（1 到 4，step 0.5），实半轴 a=3 固定
```js
c = Math.sqrt(9 + b * b);      // c² = a² + b²
e = c / 3;                     // 离心率 >1
k = b / 3;                     // 渐近线斜率
```
`cases`：`{v:1,eq:{c:3.1623,e:1.0541}}`、`{v:3,eq:{c:4.2426,e:1.4142}}`、`{v:4,eq:{c:5,e:1.6667}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:3},{t:6.5,v:3},{t:9,v:4},{t:11.5,v:2},{t:13.5,v:1}]`，keys `[1,2,3,4]`。
**停留帧在 b=3**（渐近线斜率恰好为 1，等轴双曲线附近，最容易被问的一格）。
状态：b 越大「渐近线越陡，开口越开」；e 恒 >1。

**例题**：「双曲线 x²/9−y²/16=1，求 c、离心率与渐近线。」答案：a=3，b=4，c=√(9+16)=5，e=5/3，渐近线 y=±(4/3)x。
**六问**：① c² 与 a²、b² 的关系；② 为什么要加绝对值；③ 渐近线斜率是多少；④ e 的范围；⑤ 双曲线与椭圆的 a、b、c 有什么不同；⑥ 焦点在 y 轴时方程怎么写。
**易错**：✗ c²=a²−b²（记成椭圆）/ ✗ 不加绝对值只取一支 / ✗ 渐近线写成 y=±(a/b)x / ✗ e 小于 1 / ✗ 焦点坐标算错 / ✗ a、b 谁大不确定时乱设。

## 通用约定（所有页一致）

- 出处一律写「人教A版选择性必修第一册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
- 禁止写「请拖动滑块」——自动演示时滑块的圆点会自己动，这才是提示。
