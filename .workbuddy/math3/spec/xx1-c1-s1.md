# 本节规格（只读这一节，不要读 SPEC.md 全文）

## xx1-c1-s1 空间向量及其运算

**课本原话**
1. 与平面向量一样，空间向量也是既有大小又有方向的量，记作 a 或 AB。
2. 空间向量的加法、减法、数乘与平面向量完全相同（三角形法则、平行四边形法则）。
3. 数量积：a·b=|a||b|cos⟨a,b⟩。

**三个扣分点**：a·b 是**数**不是向量（写成 6 而不是 6e）；|a+b| 要用平方展开（不能直接 |a|+|b|）；夹角范围是 [0,π]。

**四张图**：① 三角形法则与平行四边形法则（空间中三个向量）；② 数乘：方向共线、长度缩放；③ 数量积的几何意义（投影）；④ |a±b|² 的展开与三个量（|a|、|b|、cosθ）的关系。

**互动模型**：滑块＝夹角 θ（0–180°，step 15°），|a|=2，|b|=3
```js
dot  = 6 * Math.cos(θ * Math.PI / 180);          // a·b
sum2 = 13 + 2 * dot;                             // |a+b|²  = 4+9+2·a·b
dif2 = 13 - 2 * dot;                             // |a−b|²
```
`cases`：`{v:0,eq:{dot:6,sum2:25}}`、`{v:90,eq:{dot:0,sum2:13}}`、`{v:180,eq:{dot:-6,sum2:1}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:90},{t:6.5,v:90},{t:9,v:180},{t:11.5,v:120},{t:13.5,v:0}]`，keys `[0,90,180]`。
**停留帧在 90°**（a·b=0，两向量垂直，此时 |a+b| 最小）。
状态：θ<90「a·b>0」；θ=90「a·b=0，垂直」；θ>90「a·b<0」。

**例题**：「已知 |a|=2，|b|=3，⟨a,b⟩=60°，求 |a+b| 与 |a−b|。」答案：|a+b|²=4+9+2×2×3×0.5=25，|a+b|=5；|a−b|²=4+9−6=7，|a−b|=√7。
**六问**：① a·b 是向量还是数；② |a+b| 能直接相加吗；③ 夹角范围；④ a·b=0 说明什么；⑤ (a+b)·c 能拆开吗；⑥ 空间向量与平面向量的运算有区别吗。
**易错**：✗ 把 a·b 写成向量 / ✗ |a+b|=|a|+|b| / ✗ 夹角取到 360° / ✗ a·b=0 就说 a、b 中有一个是零向量 / ✗ 数乘写成点乘 / ✗ 忘记夹角要共起点。

## 通用约定（所有页一致）

- 出处一律写「人教A版选择性必修第一册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
- 禁止写「请拖动滑块」——自动演示时滑块的圆点会自己动，这才是提示。
