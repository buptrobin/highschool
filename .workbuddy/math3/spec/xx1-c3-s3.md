# 本节规格（只读这一节，不要读 SPEC.md 全文）

## xx1-c3-s3 抛物线

**课本原话**
1. 平面内与一个定点 F 和一条定直线 l（F∉l）距离相等的点的轨迹叫做抛物线。
2. 标准方程 y²=2px（p>0），焦点 (p/2,0)，准线 x=−p/2。
3. 焦半径：抛物线 y²=2px 上一点 P(x₀,y₀)，则 |PF|=x₀+p/2。

**三个扣分点**：焦点是 (p/2,0) 不是 (p,0)；准线是 x=−p/2 要带负号；2p 是系数（y²=2px 里的 2p 不要读成 p）。

**四张图**：① 定义（到焦点与到准线等距）；② 焦点、准线、顶点；③ p 对开口的影响；④ 焦半径公式的几何来源。

**互动模型**：滑块＝参数 p（1 到 8，step 0.5），抛物线 y²=2px
```js
fx = p / 2;                    // 焦点横坐标
dir = -p / 2;                  // 准线
r1  = 1 + p / 2;               // 点 (1,y₀) 的焦半径 = x₀ + p/2
```
`cases`：`{v:2,eq:{fx:1,r1:2}}`、`{v:4,eq:{fx:2,r1:3}}`、`{v:8,eq:{fx:4,r1:5}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:4},{t:6.5,v:4},{t:9,v:8},{t:11.5,v:2},{t:13.5,v:1}]`，keys `[1,2,4,8]`。
**停留帧在 p=4**（焦点 (2,0)、准线 x=−2，焦半径 3，数字最干净的一格）。
状态：p 越大「开口越宽」；焦点与准线始终关于顶点对称。

**例题**：「抛物线 y²=8x 上一点 P 到焦点的距离为 5，求 P 的横坐标。」答案：2p=8，p=4，焦点 (2,0)，焦半径 |PF|=x₀+2=5，得 x₀=3。
**六问**：① 焦点坐标是什么；② 准线方程；③ 2p 与 p 的关系；④ 焦半径公式怎么来；⑤ p 越大开口越宽还是越窄；⑥ 抛物线有离心率吗。
**易错**：✗ 焦点写成 (p,0) / ✗ 准线漏负号 / ✗ 把 2p 当 p / ✗ 焦半径写成 x₀+p / ✗ 开口方向看错 / ✗ 认为抛物线没有离心率（e=1）。

## 通用约定（所有页一致）

- 出处一律写「人教A版选择性必修第一册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
- 禁止写「请拖动滑块」——自动演示时滑块的圆点会自己动，这才是提示。
