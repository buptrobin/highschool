## xx1-c2-s3 直线的交点坐标与距离公式

**课本原话**
1. 两点间距离：|P₁P₂|=√((x₂−x₁)²+(y₂−y₁)²)。
2. 点 P(x₀,y₀) 到直线 Ax+By+C=0 的距离 d=|Ax₀+By₀+C|/√(A²+B²)。
3. 两条平行线 Ax+By+C₁=0 与 Ax+By+C₂=0 的距离 d=|C₁−C₂|/√(A²+B²)。

**三个扣分点**：点到直线距离的**分子要加绝对值**；用公式前直线必须是**一般式**（y=kx+b 要先移项）；两平行线的 A、B 必须**化成相同**。

**四张图**：① 两点间距离；② 点到直线的垂线段；③ 两平行线间的距离（要求 A、B 相同）；④ 三条距离公式的对照。

**互动模型**：滑块＝点 P 的横坐标 t（−4 到 6，step 0.5），P(t,0)，直线 3x+4y−10=0
```js
d = Math.abs(3 * t - 10) / 5;      // |3t+4·0−10| / √(9+16)
onLine = Math.abs(3 * t - 10) < 1e-9 ? 1 : 0;
```
`cases`：`{v:0,eq:{d:2}}`、`{v:2,eq:{d:0.8}}`、`{v:5,eq:{d:1}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:2},{t:6.5,v:2},{t:9,v:5},{t:11.5,v:3.333},{t:13.5,v:0}]`，keys `[0,2,5]`（另含 t=10/3 处距离为 0）。
**停留帧在 t=10/3≈3.33**（点正好落在直线上，距离降到 0）。
状态：d>0「点在直线外」；d=0「点在直线上」。

**例题**：「求点 P(2,0) 到直线 3x+4y−10=0 的距离。」答案：d=|3×2+4×0−10|/√(9+16)=4/5=0.8。
**六问**：① 公式对直线形式有要求吗；② 绝对值可以省吗；③ 两平行线距离为什么要求 A、B 相同；④ 分母为什么是 √(A²+B²)；⑤ 点代入后为 0 说明什么；⑥ 两条相交直线的距离是多少。
**易错**：✗ 用斜截式直接代公式 / ✗ 忘记绝对值 / ✗ 平行线不统一 A、B / ✗ 分母写成 A²+B² / ✗ 把交点距离公式与点到直线混 / ✗ 直线过原点时 C=0 就不写。

## 通用约定（所有页一致）

- 出处一律写「人教A版选择性必修第一册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
- 禁止写「请拖动滑块」——自动演示时滑块的圆点会自己动，这才是提示。
