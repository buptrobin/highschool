## xx1-c2-s5 直线与圆、圆与圆的位置关系

**课本原话**
1. 直线与圆：圆心到直线的距离 d 与半径 r 比较，d<r 相交、d=r 相切、d>r 相离。
2. 圆与圆：圆心距 d 与 r₁+r₂、|r₁−r₂| 比较，判断外离、外切、相交、内切、内含。
3. 弦长公式：l=2√(r²−d²)。

**三个扣分点**：直线与圆用**圆心距**比较，不是把直线方程代进去乱算；圆与圆要考虑**|r₁−r₂|**这一侧；弦长公式里 d 是**圆心到直线**的距离。

**四张图**：① 直线与圆的三种位置（d 与 r）；② 圆与圆的五种位置（d 与 r₁±r₂）；③ 弦长、半弦、半径的直角三角形；④ 判定流程（先算 d，再比较）。

**互动模型**：滑块＝圆心到直线的距离 d（0 到 8，step 0.5），圆半径 r=5
```js
chord = d <= 5 ? 2 * Math.sqrt(25 - d * d) : 0;    // 弦长
state = d < 5 ? 0 : d === 5 ? 1 : 2;               // 0 相交 1 相切 2 相离
```
`cases`：`{v:0,eq:{chord:10,state:0}}`、`{v:3,eq:{chord:8,state:0}}`、`{v:5,eq:{chord:0,state:1}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:3},{t:6.5,v:3},{t:9,v:5},{t:11.5,v:7},{t:13.5,v:0}]`，keys `[0,3,5,7]`。
**停留帧在 d=3**（弦长 8，3-4-5 直角三角形，最好算也最容易记错公式的一格）。
状态：d<5「相交，弦长 2√(25−d²)」；d=5「相切，弦长 0」；d>5「相离，没有公共点」。

**例题**：「圆 x²+y²=25，直线 3x+4y−15=0，求弦长。」答案：圆心到直线距离 d=|−15|/5=3，弦长 2√(25−9)=8。
**六问**：① 直线与圆用什么量判断；② 圆与圆要比较几个量；③ 弦长公式里的 d 是什么；④ 相切时弦长是多少；⑤ 内含与内切的区别；⑥ 用代数法（判别式）判断可以吗。
**易错**：✗ 圆与圆只比 r₁+r₂ / ✗ 弦长直接用 r²−d² 不开方 / ✗ d 算成圆心到弦端点的距离 / ✗ 内含与内切混 / ✗ 相切时仍写两个交点 / ✗ 判别式法漏算二次项系数。
