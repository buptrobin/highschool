# 本节规格（只读这一节，不要读 SPEC.md 全文）

## xx1-c3-s1 椭圆

**课本原话**
1. 平面内与两个定点 F₁、F₂ 的距离之和等于常数（大于 |F₁F₂|）的点的轨迹叫做椭圆。
2. 标准方程 x²/a²+y²/b²=1（a>b>0），且 c²=a²−b²。
3. 离心率 e=c/a，0<e<1；e 越接近 1 越扁，越接近 0 越圆。

**三个扣分点**：2a 必须**大于** |F₁F₂|（否则不是椭圆）；a²=b²+c² 里 a 最大（别记成 c²=a²+b²）；离心率 e 的范围是 (0,1)。

**四张图**：① 椭圆的定义（绳子和两个焦点）；② 三个参数 a、b、c 的直角三角形；③ 离心率对形状的影响（一组椭圆）；④ 焦点在 x 轴与 y 轴的两种标准方程。

**互动模型**：滑块＝短半轴 b（1 到 4.5，step 0.5），长半轴 a=5 固定
```js
c = Math.sqrt(25 - b * b);      // c² = a² − b²
e = c / 5;                      // 离心率
```
`cases`：`{v:3,eq:{c:4,e:0.8}}`、`{v:4,eq:{c:3,e:0.6}}`、`{v:4.5,eq:{c:2.1794,e:0.4359}}`。
Autopilot：`[{t:0,v:1},{t:1.2,v:1},{t:4,v:4},{t:6.5,v:4},{t:9,v:4.5},{t:11.5,v:2.5},{t:13.5,v:1}]`，keys `[1,2.5,4,4.5]`。
**停留帧在 b=4.5**（b 逼近 a，椭圆越来越圆，离心率趋近 0）。
状态：b 越小「e 越大，越扁」；b→a「e→0，越接近圆」。

**例题**：「椭圆 x²/25+y²/9=1，求焦点坐标、离心率。」答案：a=5，b=3，c=√(25−9)=4，焦点 (±4,0)，e=4/5。
**六问**：① 2a 为什么要大于焦距；② a、b、c 谁最大；③ 离心率范围；④ 焦点在 y 轴时方程怎么写；⑤ e 越大越扁还是越圆；⑥ 椭圆上点到两焦点距离之和是多少。
**易错**：✗ c²=a²+b² / ✗ 2a 可以小于焦距 / ✗ e 取到 1 / ✗ 焦点坐标写反 / ✗ a 与 b 大小不分 / ✗ 把 e 写成 b/a。

- 出处一律写「人教A版选择性必修第一册 · 第X章第Y节」，**不写页码**。
