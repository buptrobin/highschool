# 本节规格（只读这一节，不要读 SPEC.md 全文）

## xx1-c1-s2 空间向量基本定理

**课本原话**
1. 如果三个向量 a、b、c 不共面，那么对任意一个空间向量 p，存在唯一的有序实数组 (x,y,z)，使 p=xa+yb+zc。
2. a、b、c 叫做空间的一个基底，它们都是基向量。
3. 任意三个不共面的向量都可以构成空间的一个基底。

**三个扣分点**：基底必须**不共面**（共面的三个向量不能作基底）；分解是**唯一**的；p 落在 a、b 张成的平面内时 z=0（此时只需两个基向量）。

**四张图**：① 三个不共面的基向量；② p 的分解（平行四边形叠加）；③ 共面的三个向量为什么不能作基底；④ z=0 时 p 落在平面内。

**互动模型**：滑块＝分解系数 z（−2 到 2，step 0.5），p=xa+yb+zc，取 x=1、y=2
```js
inPlane = z === 0 ? 1 : 0;     // z=0 时 p 落在 a、b 张成的平面内
coef    = [1, 2, z];           // 唯一的有序实数组
```
`cases`：`{v:0,eq:{inPlane:1}}`、`{v:1,eq:{inPlane:0}}`、`{v:-2,eq:{inPlane:0}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:1},{t:6.5,v:1},{t:9,v:-2},{t:11.5,v:2},{t:13.5,v:0}]`，keys `[0,1,-2,2]`。
**停留帧在 z=0**（p 恰好落在平面内，两个基向量就够，第三个系数是 0）。
状态：z=0「p 与 a、b 共面，基底退化成两个」；z≠0「必须用满三个基向量」。

**例题**：「已知 {a,b,c} 是基底，p=a+2b+zc，若 p 与 a、b 共面，求 z。」答案：共面意味着 c 的系数为 0，故 z=0；反过来若 z≠0，p 就不在 a、b 张成的平面内。
**六问**：① 基底需要几个向量；② 共面的三个向量能作基底吗；③ 分解为什么唯一；④ z=0 意味着什么；⑤ 零向量能作基向量吗；⑥ 基底换了，坐标会变吗。
**易错**：✗ 任意三个向量都能作基底 / ✗ 分解不唯一 / ✗ z=0 时还写「三个基向量」 / ✗ 零向量当基向量 / ✗ 基向量必须是单位向量 / ✗ 换了基底坐标不变。

## 通用约定（所有页一致）

- 出处一律写「人教A版选择性必修第一册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
- 禁止写「请拖动滑块」——自动演示时滑块的圆点会自己动，这才是提示。
