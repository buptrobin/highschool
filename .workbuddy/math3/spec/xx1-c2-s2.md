## xx1-c2-s2 直线的方程

**课本原话**
1. 点斜式：y−y₀=k(x−x₀)。
2. 斜截式：y=kx+b（b 为纵截距）。
3. 一般式：Ax+By+C=0（A、B 不同时为 0）。

**三个扣分点**：点斜式不能表示竖直线（x=x₀）；斜截式的 b 是**纵截距**不是距离（可为负）；截距式要求两个截距都不为 0。

**四张图**：① 点斜式的几何含义；② 斜截式的 b 与直线的位置（b 正负）；③ 几种形式的适用范围对照表；④ 一般式与斜截式的互化。

**互动模型**：滑块＝纵截距 b（−4 到 4，step 1），直线 y=2x+b
```js
x0 = -b / 2;                 // 与 x 轴交点
y0 = b;                      // 与 y 轴交点
quad = b > 0 ? 123 : b === 0 ? 13 : 134;   // 经过的象限（数字串）
```
`cases`：`{v:-2,eq:{x0:1,y0:-2}}`、`{v:0,eq:{x0:0,y0:0}}`、`{v:4,eq:{x0:-2,y0:4}}`。
Autopilot：`[{t:0,v:-4},{t:1.2,v:-4},{t:4,v:0},{t:6.5,v:0},{t:9,v:4},{t:11.5,v:2},{t:13.5,v:-4}]`，keys `[-4,0,2,4]`。
**停留帧在 b=0**（直线过原点，最特殊的位置，也是截距式失效的那一格）。
状态：b>0「过第一、二、三象限」；b=0「过原点」；b<0「过第一、三、四象限」。

**例题**：「求过点 (1,2) 且斜率为 −3 的直线方程，并化成一般式。」答案：y−2=−3(x−1)，即 3x+y−5=0。
**六问**：① 点斜式能表示竖直线吗；② 纵截距 b 能为负吗；③ 截距式的适用条件；④ 一般式有什么好处；⑤ 斜截式的 b 与「截距」是距离吗；⑥ 两点式与点斜式的关系。
**易错**：✗ 点斜式写竖直线 / ✗ 截距当成距离取绝对值 / ✗ 截距式不管是否为 0 / ✗ 一般式 A、B 同时为 0 / ✗ 化一般式不整理 / ✗ 斜截式与点斜式混用。

## 通用约定（所有页一致）

- 出处一律写「人教A版选择性必修第一册 · 第X章第Y节」，**不写页码**。
- 六区块 id 固定 a–f，顺序固定：A 课本怎么说 / B 拆开看 / C 自己拖一下 / D 一道题走一遍 / E 会怎么考 / F 易错清单。
- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
- 数值卡最后一个必须是「状态判断」，配色：蓝=主 #2563eb，绿=正常 #2f8a5b，琥珀=临界 #b8791f，红=错误/危险 #b8402f。
- 页脚写互动模型公式与端点，标注哪些是示意值。
- 断言挂在 `window.__model = {calc, cases}`（**不是** `__bio`）。
- 禁用语：简单来说 / 众所周知 / 其实很简单 / 只要记住。
- 禁止写「请拖动滑块」——自动演示时滑块的圆点会自己动，这才是提示。
