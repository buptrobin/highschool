## xx1-c1-s3 空间向量及其运算的坐标表示

**课本原话**
1. 若 a=(x₁,y₁,z₁)，b=(x₂,y₂,z₂)，则 a+b=(x₁+x₂, y₁+y₂, z₁+z₂)。
2. 数量积的坐标表示：a·b=x₁x₂+y₁y₂+z₁z₂。
3. a⊥b ⇔ x₁x₂+y₁y₂+z₁z₂=0；a∥b ⇔ x₁=x₂λ，y₁=y₂λ，z₁=z₂λ。

**三个扣分点**：垂直用**数量积为 0**、平行用**成比例**，两者不能混；模是 √(x²+y²+z²) 三项不是两项；平行要检验三个分量（含 z）。

**四张图**：① 空间直角坐标系的三个轴与点的坐标；② 坐标运算表（加、减、数乘、数量积）；③ 垂直与平行的判定对照；④ 模与夹角的坐标公式。

**互动模型**：滑块＝b 的横坐标 t（−2 到 2，step 0.5），a=(1,1,0)，b=(t,0,1)
```js
dot  = t;                                  // a·b = x₁x₂+y₁y₂+z₁z₂
perp = t === 0 ? 1 : 0;                    // 垂直 ⇔ 数量积为 0
absB = Math.sqrt(t * t + 1);
cos  = t / (Math.SQRT2 * absB);            // 夹角余弦
```
`cases`：`{v:0,eq:{dot:0,perp:1}}`、`{v:1,eq:{dot:1,perp:0}}`、`{v:-2,eq:{dot:-2,perp:0}}`。
Autopilot：`[{t:0,v:-2},{t:1.2,v:-2},{t:4,v:0},{t:6.5,v:0},{t:9,v:2},{t:11.5,v:1},{t:13.5,v:-2}]`，keys `[-2,0,1,2]`。
**停留帧在 t=0**（数量积为 0，两向量垂直，最容易被漏掉的判别）。
状态：t=0「垂直（数量积为 0）」；t≠0「不垂直，数量积不为 0」。

**例题**：「a=(1,1,0)，b=(t,0,1)，若 a⊥b 求 t；若 a∥b 求 t。」答案：垂直要求 t=0；平行要求 (1,1,0)=λ(t,0,1)，由 z 分量 0=λ 得 λ=0，与 x 分量 1=λt 矛盾，故**不存在**这样的 t。
**六问**：① 垂直与平行分别用什么判据；② 模是几项的平方和；③ 两个向量平行能不能只看 x、y；④ 数量积为 0 一定垂直吗（零向量）；⑤ 夹角公式的分母是什么；⑥ 空间坐标与平面坐标的差别。
**易错**：✗ 平行用数量积为 0 / ✗ 垂直只比前两个分量 / ✗ 模写成两项 / ✗ 平行不看 z 分量 / ✗ 零向量与任何向量都「垂直」（定义上不算）/ ✗ 夹角公式漏绝对值。

## 通用约定（所有页一致）

- 出处一律写「人教A版选择性必修第一册 · 第X章第Y节」，**不写页码**。

- 公式统一用 `<span class="gx-fml">…</span>`；行内符号用 Unicode（√ ² ³ · × ∠ ∥ ⊥ π θ λ μ ≠ ≤ ≥ ⇒ ⇔）。不用 MathJax、不用 `<sub>`/`<sup>`。
