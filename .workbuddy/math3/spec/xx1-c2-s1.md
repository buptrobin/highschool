## xx1-c2-s1 直线的倾斜角与斜率

**课本原话**
1. 直线向上的方向与 x 轴正方向所成的最小正角 α 叫做倾斜角，范围是 0°≤α<180°。
2. 倾斜角 α≠90° 时，k=tanα 叫做直线的斜率。
3. 经过两点 P₁(x₁,y₁)、P₂(x₂,y₂)（x₁≠x₂）的斜率 k=(y₂−y₁)/(x₂−x₁)。

**三个扣分点**：倾斜角范围是 [0°,180°)（**不含 180°**）；α=90° 时斜率**不存在**（不是 0）；由 tanα 求 α 要按象限取舍。

**四张图**：① 倾斜角的定义与范围；② 斜率随倾斜角变化的图象（tan 曲线的一段）；③ α=90° 时斜率不存在；④ 两点式斜率与 Δy/Δx。

**互动模型**：滑块＝倾斜角 α（0–180°，step 5°）
```js
k    = α === 90 ? null : Math.tan(α * Math.PI / 180);
ok   = α === 90 ? 0 : 1;            // 斜率是否存在
```
`cases`：`{v:45,eq:{k:1,ok:1}}`、`{v:135,eq:{k:-1,ok:1}}`、`{v:90,eq:{ok:0}}`。
Autopilot：`[{t:0,v:0},{t:1.2,v:0},{t:4,v:45},{t:6.5,v:45},{t:9,v:90},{t:11.5,v:135},{t:13.5,v:0}]`，keys `[0,45,90,135]`。
**停留帧在 90°**（竖直线，斜率不存在——最容易被学生写成 0 的一格）。
状态：0<α<90「k>0，上升」；α=90「斜率不存在」；90<α<180「k<0，下降」；α=0「k=0，水平」。

**例题**：「经过 A(1,2)、B(3,6) 的直线，求倾斜角。」答案：k=(6−2)/(3−1)=2，由 tanα=2 且 α∈[0°,180°) 得 α=arctan2≈63.4°。
**六问**：① 倾斜角能等于 180° 吗；② 竖直线的斜率是多少；③ 斜率相同两直线什么关系；④ 由 k 求 α 要注意什么；⑤ 水平线倾斜角是多少；⑥ 两点式斜率的分母能为 0 吗。
**易错**：✗ 倾斜角取到 180° / ✗ 竖直线斜率写成 0 / ✗ tanα 求 α 不判象限 / ✗ 斜率不存在与斜率为 0 混 / ✗ 两点式分子分母反了 / ✗ 认为所有直线都有斜率。
