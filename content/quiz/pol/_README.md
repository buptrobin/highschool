# 政治精练页 · 写作规范（写 spec 的人必读）

一页成品 = 一个 `content/quiz/pol/<slug>.json`（约 12—18 KB）。页面由 `tools/quizgen.py` 生成，
**不要手写 HTML**。分页清单见 `_plan.md`（102 页 = 5 册 95 节 + 7 专题）。

## 一、结构硬要求

| 项 | 要求 |
|---|---|
| 关卡 | **正好 5 关**，`levels` 里 `id` 1—5；第 5 关只放综合题（模板只认 `lv.id === 5` 渲染综合题） |
| 选择题 | **9 道**（`questions`），按难度分到第 1—4 关（每关 2—3 道） |
| 综合题 | **3 道**（`essays`），全部 `lv: 5` |
| 题量合计 | 12 题。确实没有第 9 道合适的真题时，用原创补，**不要为了凑数拿不沾边的题** |
| `star` | 只能 1、2、3（写 4 会抛 RangeError，整页崩） |
| `opts` | 正好 4 项，互不重复；`ans` 是 0—3（0=A） |
| `store_key` | `pol-<slug>-v1`，全站唯一 |

## 二、选题规则（用户定的，长期有效）

1. **北京卷最近 5 年（2022—2026）优先**，有就用。北京选择题在题库里有 73 道（2022 年 13 道、
   2023—2026 每年 15 道），北京主观题 2022—2026 共约 35 道。
2. 北京没有或只有一两道时，用**外地近 3 年**（2023—2025）：江浙沪 → 山东 → 湖北湖南 → 其余。
   外地选择题共 850 余道，2022 年的也可用，但要在页脚如实写年份区间。
3. 都没有才用原创（标 `orig`）。
4. **不要用合格考题、模拟题冒充真题。**
5. **一道题只进一节**：真题选择题全站只能出现一次。你在 spec 里写的
   `"src": "2024·北京 第3题"` 就是唯一凭据，格式必须严格
   `年份·地区 第N题`（如 `2023·北京 第7题`、`2024·山东 第11题`）。原创写 `"原创"` 或 `"原创·综合题"`。
6. **综合题可以跨册复用**（同一道主观题在必修与选必各出现一次是合理的），但**同一册内部不要重复**。

## 三、怎么查题

```
python tools/pol-find.py 关键词 [--bj] [--year 2024] [--kind 选择] [--n 20] [--full] [--unused]
```

- `--full` 打印选项、答案、解析——**选题必须看 `--full`**，只看题干会选到形式沾边实质跑题的题。
- 政治题的材料常带时政背景，判断标准是「**这道题考的原理/制度/法条，是不是本节的**」，
  不是材料里出现了哪个热词。
- 例题：`python tools/pol-find.py 政协 协商 --full`（→ 必修三 6.1）、
  `python tools/pol-find.py 矛盾 同一性 --full`（→ 必修四 3.3）。
- 题库字段：`bank`（编号，如 `bj2023#7`）、`year`、`area`、`kind`（选择/主观）、`stem`、`opts`、
  `ans`、`why`（原卷详解）、`material`/`ask`（主观题）、`src` 自己写。

## 四、每页文案要求

- `kicker`：`人教版 · 必修3 政治与法治 · 第六课第一框`（书的写法照 `_plan.md` 里的「位置」列）
- `book`：`{"book":"必修3 政治与法治","chapter":"第六课 ...","section":"第一框 ..."}`
- `freq` 卡片**必须说实话**：
  - `title`：`高考考频 · 北京 2022—2026 + 外地 2023—2025`（没有外地 2023 以后的题就写实际区间）
  - `badges`：北京命中几道、外地几道、收进本页几道
  - `conclusion`：一句话说明本节在高考里怎么考
  - `body`：点名 2—4 道最典型的真题（年份+题号+考什么）
- `map`：2 张示意图（手写 SVG，`svg` 字段）+ 说明文字。**不要画超出 viewBox 的文字**，
  两栏排版时左栏文字右端要留 20px 以上空隙。
- `traps`：6 条易错点，`items[].ps` 是段落数组，`<b>` 标关键。
- `footer`：两块——「怎么用这份材料」+「题目来源说明」（把本页每道真题的年份题号列清，
  原创题说清是自己编的）。
- `hero_art`：一张 300×300 的 SVG 封面图（徽标 + 关键词），照 `content/quiz/bio/bx1-c1-s1.json` 的写法。

## 五、`questions[].why` 写法

- 3—5 句，**每个错项都要说出错在哪里**，不能只解释正确项。
- 不要写「故选 A」这种空话；页面里已单独显示答案。
- `tip`：一句可迁移的方法（如「传导类题先看首尾环节对不对，再看中间链条」）。

## 六、`essays[]` 写法

```json
{"id": 10, "lv": 5, "src": "2024·北京 第17题", "star": 3,
 "title": "……（一句话概括）",
 "material": "材料原文（可压缩，但关键数据、主体、行为不能丢）",
 "asks": [{"q": "运用《经济与社会》知识，说明……", "pt": 6}],
 "points": [["要点一", "要点二", "要点三"]],
 "tip": "这题教的方法"}
```

- 优先用**真题主观题**：`pol-find.py 关键词 --kind 主观 --full`，`material`/`ask` 题库里有，
  答案要点参考 `ans_raw`（原卷参考答案）压缩成 3—5 条 `points`；**`ans_raw` 为空时**
  从 `why` 里找「关键词①……→可联系……」这类句子，那就是原卷的答案要点。
- 编不出真题时写原创（`src: "原创·综合题"`），材料自己写但要像高考题（有主体、有数据、有冲突）。
- 一道主观题在同一册里不要出现两次。

## 七、交付纪律

- 只写 `content/quiz/pol/<slug>.json`，不要碰别人的文件。
- 写完自查：`python tools/quizgen.py content/quiz/pol/<slug>.json out/polhtml/<slug>.html`
  （能生成、不报错即合格；**不要**跑 `quiz-install.py`、不要跑 `build.py`、不要用 git）。
- JSON 必须是 UTF-8、`ensure_ascii=False`（中文直接写）。
- 最后在回复里列出：每页用了哪几道真题（编号）、几道原创、有没有放弃的候选。
